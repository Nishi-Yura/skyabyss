導入の手順Installation

  1. NeoForge 1.21.1 を入れて、一度起動します。Install NeoForge 1.21.1 and launch it once.
  2. skyabyss-0.2.2.jar と GeckoLib の jar を、どちらも mods フォルダへ入れます。Put skyabyss-0.2.2.jar and the GeckoLib jar into the mods folder.
  3. サーバーで遊ぶときは、サーバーの mods にも同じものを入れます。みんなで同じ jar を使います。For a server, put the same files into the server's mods folder. Everyone must use the same jar.
  4. 新しいワールドを作ります。難易度はピースフル以外にします。Create a new world on any difficulty except Peaceful.
  5. 目覚めたら、画面の左上の目的の帯に従って進みます。When you wake, follow the objective strip at the top left.
jar は開発者から受け取るか、ソースから ./gradlew build で作ると build/libs/ に出ます。Get the jar from the developer, or build it from source with ./gradlew build; it appears in build/libs/.

/gamerule で決まりを変えられます。巨神の背中は専用のディメンションなので、ワールドのバックアップは通常どおりで構いません。Rules can be changed with /gamerule. Titan backs live in dedicated dimensions, so normal world backups work as usual.

よくある質問FAQ

どの Minecraft で遊べますか。Which Minecraft versions work?

Java 版 1.21.1 と NeoForge 1.21.1 の組み合わせだけです。Forge や Fabric、統合版では動きません。Only Java Edition 1.21.1 with NeoForge 1.21.1. Forge, Fabric and Bedrock are not supported.

既存のワールドで遊べますか。Can I use an existing world?

新しいワールドをおすすめします。長く遊んでいる世界でも、今の章から始まります。A new world is recommended. In a long-running world the mod simply starts from the current chapter.

世界を開いた直後が重いです。The game is heavy right after opening the world.

巨神の背中の島を裏で少しずつ建てています。数分で落ち着きます。そのあいだに岩鯨の背に乗ろうとすると、一瞬止まることがあります。The titan back islands are built in the background. It settles in a few minutes; boarding the Stone Whale in the meantime may freeze briefly.

ピースフルで遊べますか。Can I play on Peaceful?

いいえ。ピースフルでは巨神の背中の試練が眠ったままです。難易度を上げてください。No. On Peaceful the back trials stay dormant; raise the difficulty.

怖い演出を減らせますか。Can I reduce the scary effects?

設定ファイルの horrorEventFrequency、watcherFrequency、cloudEyeFrequency（0 で出なくなる）と、クライアント設定で、揺れや暗さを弱められます。Lower horrorEventFrequency, watcherFrequency and cloudEyeFrequency in the config (0 disables them); screen shake and darkness can be reduced in client settings.

キーがほかの mod とぶつかります。Keys clash with another mod.

設定の「操作」にある「天と淵のあいだ」の項目で変えられます。Rebind them under Controls in the "Between the Sky and the Abyss" category.

大事な品をなくしました。I lost a key item.

B の控え帳を開き、品の在りかと「呼び戻す」ボタンを使ってください。Open the record book (B) to see where it is and use the Recall button.

好きな順に巨神に挑めますか。Can I fight the titans in any order?

既定では順番があります。管理者がゲームルール skyabyssStoryGate を false にすると好きな順に乗れます。By default there is an order. An admin can set the game rule skyabyssStoryGate to false to board in any order.

他の mod と一緒に使えますか。Does it work with other mods?

ほかの mod との組み合わせは確かめていません。ブロックを壊す・置く mod は背中の中では効きません。Combinations with other mods are untested. Mods that break or place blocks do not work inside a titan's back.

既知の制限Known limits

これはベータ版です。作ったばかりで、人が通しで遊んでいない所があります。This is a beta. Some parts are brand new and have not been played through by people.

  • マルチは、まだ人の手で通しの確認をしていません（特に 2 つのパーティが同じ背中にいるとき）。Multiplayer has not yet been verified end to end by people (especially with two parties on one back).
  • 雷翼と余燼では、巨神に乗って移動する旅がまだありません。Traveling by riding Thunder Wing or Ember is not available yet.
  • 序盤の演出・予兆・仕掛けの濃さは、通しで確かめていません。The density of early-game staging, omens and small set pieces has not been playtested end to end.
  • 余燼の背中は、人が通しで遊んでいません。Ember's back has not been played through by a person.
  • 風見鶏と潮の真珠の絵は仮のものです。The art for the weathercock and the tide pearl is placeholder.
  • 五章以降は、まだ枠だけです。Chapter 5 onward is only a framework so far.

噛み合わない所や、おかしな動きを見つけたら、ぜひ教えてください。開いた直後の数分は、背中の島を建てるので少し重くなります。If you find something that does not fit or behaves oddly, please tell us. The first few minutes after opening a world are a little heavy while the back islands are built.
