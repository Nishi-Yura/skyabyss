1. UI の基盤の絵柄

今は「暗い石の板に骨の縁と青緑の玉」です。画面を並べると、どれも暗い地に淡い小さな字で沈んで見え、持ち物と預かり所だけはバニラの寸法と絵柄パック頼みで別物になっています（下の「今の画面」）。寸法の決まり（板 356×220、余白 3・5・8・13・21、行 13、等倍の字）はそのまま使い、絵柄だけを替える案です。どの案も縁と地はコードで描くので、絵柄パックを外しても崩れません。

A　夜空の硝子推奨

藍の半透明の板に金の細い線、角に小さな菱形、見出しの帯に星。選んだ行は空色の地と金の印。サイトの夜空と同じ世界で、後ろの景色が少し透けるので重くなりません。字は生成りで対比がいちばん取れます。

B　切り紙

墨の板に生成りの紙の見出し、桃色の下敷きがずれて重なる。心臓のあとの主（切り紙の絵柄）とそろいます。いちばん個性が強い一方、桃色が体力の色と重なり、長く見る画面では強すぎるかもしれません。

C　旅の手帳

紙の地に墨の字、青緑の判と朱の印。伝承の書と地図がもう紙なので、全部が一冊の手帳になります。明るい地は夜や洞窟でまぶしく、品のレア度の色が紙の上で弱くなります。
