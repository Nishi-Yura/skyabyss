# 潮殻の巨神が眠る場面 titan_end_tide_shell の見せ場と、潮門の光を撮る (docs/design/20_cinematics.md の 3.4、08 の 2.7)。普通の世界の深い海 (種 20261016 で (-1406, -1411) が深海。titan_end_scout.txt の locate)。
# ./gradlew runShots -Pscript=tools/shots/titan_end_tide.txt -PshotsName=<新しい名前>   絵は run/shots/<名前>/shots/titan_end_tide/ → docs/review/previews/titan_end_tide_*.png へ
# 海の上に石の足場 (浜の代わり) を置いて立ち、潮殻を呼んで休ませ (潮門が出る = 光る)、眠らせて場面を流す。場面は 16 秒 = 320 tick
world titan_end_tide normal
size 1280 720
timeout 1200
render 12
clouds on

cmd time set noon
cmd weather clear
cmd skyabyss cinematic stop
wait 20
cmd gamemode creative
cmd skyabyss progress grant @p stone_whale
camera minecraft:overworld -1406 64 -1411 0 0
waitchunks 900
wait 60
cmd fill -1410 62 -1415 -1402 62 -1407 minecraft:stone
camera minecraft:overworld -1406 63 -1411 0 0
hud off
wait 20
cmd skyabyss titan summon tide
wait 80
cmd skyabyss titan rest tide here
wait 100
shot tide_00_awake_gate_glow
cmd skyabyss titan end tide_shell sleep
cmd skyabyss cinematic play titan_end_tide_shell
wait 20
shot tide_01_song_stops
wait 100
shot tide_02_glow_fades
wait 90
shot tide_03_sinking
wait 80
shot tide_04_pullback
wait 40
shot tide_05_dormant
wait 120
shot tide_06_control
cmd skyabyss titan end tide_shell wake
cmd kill @e[type=skyabyss:tide_shell,distance=..900]
wait 10
quit
