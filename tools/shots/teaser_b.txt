# 録画は 1920x1080・30 fps、録るあいだはゲームの時計を 1/10 (tick rate 2)。敵は動かないようにして技を当てる

cmd skyabyss cinematic stop

cmd gamerule doDaylightCycle false
cmd gamerule doWeatherCycle false

cmd effect give @s resistance 99999 4 true
cmd effect give @s regeneration 99999 4 true
