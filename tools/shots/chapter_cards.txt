# 本番と同じ Notice の経路 (Notice.chapter / Notice.aftermath)。開発コマンド /skyabyss dev arc card|aftermath <章の ID> で送る。

size 1280 720
timeout 300
render 8
clouds off

cmd time set noon

cmd gamemode creative

waitchunks
