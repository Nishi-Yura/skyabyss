# 心臓の下の果てない深み (docs/design/36 の 9): 八つの区画の型を一つずつ。壁の内側から見下ろす眺め (top) と、下へ下がった所の眺め (mid)。
# ./gradlew runShots -Pscript=tools/shots/abyss_depths.txt -PshotsName=abyss_depths
# 区画は世界の種で決まるので、型で選ぶ (cmd skyabyss abyss depth kind <型>): その型の最初の区画の中へ、眺めの位置に置く
# mid は今の位置から 96 ブロック下へ (相対座標)
world opening_abyss_depths normal
size 1280 720
timeout 2400
render 10
clouds off

wait 100
cmd gamemode spectator
cmd time set 18000
cmd gamerule doDaylightCycle false
hud off
cmd skyabyss abyss depth kind inverted_forest
waitchunks
wait 80
shot d_inverted_forest_top
cmd tp @s ~ ~-96 ~ 45 10
waitchunks
wait 60
shot d_inverted_forest_mid
