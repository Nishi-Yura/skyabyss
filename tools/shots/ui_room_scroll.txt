# UI room: 送りと動かしの確認 (ホイール・ドラッグ)。途中の絵を撮る (mid-scroll / mid-pan)。

# ./gradlew runShots --no-daemon --offline -Pscript=tools/shots/ui_room_scroll.txt -PshotsName=ui_room_scroll
world ui_room_scroll flat
size 1280 720
timeout 1500
render 8
clouds off

cmd time set noon
cmd weather clear
cmd gamemode survival
hud on
cmd skyabyss cinematic stop
waitchunks

cmd skyabyss quest start @s main_song
