# 乗り物 (設計から彫った点の模型)。facility mount demo で全部の見た目を並べる
world splatmounts flat
size 1280 720
timeout 900
render 6
clouds off
wait 100
cmd skyabyss cinematic stop
wait 10
cmd skyabyss cinematic stop
close
cmd time set noon
cmd weather clear
cmd gamerule doDaylightCycle false
cmd gamemode creative
camera minecraft:overworld 0 -60 2 180 8
waitchunks
wait 200
cmd skyabyss cinematic stop
close
hud off
cmd tp @s 0 -60 -2 0 0
cmd skyabyss facility mount demo
wait 60
shot row
cmd tp @s -9 -60 -1 -50 12
wait 30
shot row_left
cmd tp @s 9 -60 -1 50 12
wait 30
shot row_right
quit
