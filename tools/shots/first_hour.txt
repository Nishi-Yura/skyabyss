# 最初の 1 時間の通し (rpg_brushup A10): 新しいプレイヤーが 序章 -> 岩鯨の初見 -> 鎖 を進む間の、目的の帯の文・画面・知らせを時刻つきで記録する。
#   ./gradlew runShots -Pscript=tools/shots/first_hour.txt        (約 20 分。音は自動で 0。毎回、新しい世界で流す: run/shots/first_hour/saves/opening_first_hour を消す)
#   NOTE: run with SKYABYSS_LANG=en_us (the waitband / waitnotice words below are the English band and notice texts; the shot client defaults to ja_jp)
#   記録: run/shots/first_hour/shots/first_hour/shots.log の "[watch]" (watch on のあいだ、帯・画面・知らせが変わるたびに) と "[band]" "[gap]" "[waited]" "[dialogue]" の行。
#         game= は総 tick (20 tick = 1 秒。ここが「何分目」)、day= / tod= はゲーム内の日と一日の時刻
#   読み方と結果: docs/review/first_hour_log.md
# 方針:
#   - 昼夜も影も足音も歌も岩鯨も本物の判断 (OpeningDirector / SkyEvents / TitanEvents) に任せ、拍子の強制 (opening <拍子>) は使わない。総 tick は本物の 60 分ぶん流す。
#   - 遅い所は cmd tick rate 100 でサーバーだけ 5 倍にする (台本の wait はクライアントの tick なので 1 wait tick = 5 総 tick。待ちは waitgame <総 tick> で書く)。
#   - 歩きは dev opening view / goto で体を運ぶ。会話は dev talk で本物の会話 (DialogueService) を開いて進める。破れた頁は拾って読む動きまで真似る。
#   - 台本が真似られない所 (自然に起きるまで時間のかかる所) は、そこで使った開発コマンドを docs/review/first_hour_log.md に書く。
