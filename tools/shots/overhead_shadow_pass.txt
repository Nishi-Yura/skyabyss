# 空の影 (上から落ちる影) の見え方: 開けた所・木の下・屋根の下・戸口・屋根の縁を外から。
# 影は動かない空の影をこのクライアントにだけ置き (skypass。サーバーなし。本体は遠くへ置く)、形は決まった円にする (skycircle)。overheadshadow on = 画素ごとの影 (今)、off = 昔の地面の板 (before)。
# ./gradlew runShots -Pscript=tools/shots/overhead_shadow_pass.txt -PshotsName=<名前>   絵は run/shots/<名前>/shots/overhead_shadow_pass/*.png
# 台本 overhead_shadow_pass_off.txt は off の版 (同じ世界を使い回す。世界は初回に作るので、2 回目から速い)。組み立て: python tools/sheets/overhead_shadow_sheet.py
world overhead_shadow_pass flat
overheadshadow on
size 960 540
timeout 900
render 12
clouds on

cmd gamemode spectator
cmd time set noon
cmd weather clear
hud off
waitchunks

# 家 (石れんが。中は x -3..3, y -60..-57。東の戸口)、庇つきの小屋 (x 8..22)、木 (x -20)
cmd fill -4 -61 -4 4 -56 4 stone_bricks hollow

cmd fill -24 -55 -4 -16 -52 4 oak_leaves[persistent=true]
cmd fill 12 -60 -6 12 -57 -6 oak_log
cmd fill 12 -60 6 12 -57 6 oak_log
cmd fill 8 -56 -7 22 -56 7 oak_planks
cmd skyabyss cinematic stop
camera 0.5 -60 0.5 270 0
wait 10
chat clear
