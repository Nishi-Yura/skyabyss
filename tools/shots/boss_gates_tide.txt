# 潮殻の背のボス部屋の大門 (潮招きの干潟の口・殻の底の心臓の間) を撮る。./gradlew runShots -Pscript=tools/shots/boss_gates_tide.txt
# 出力: run/shots/boss_gates_tide/shots/boss_gates_tide/*.png → python tools/boss_gates_sheet.py で docs/review/previews/boss_gates_sheet.png
# 四つの背を建て終えた専用サーバーへ入る (標準の平らな世界だと 4 つの背を一度に建てて、読み込みが間に合わない)。
# サーバー: run/server.properties の server-port=25726、先に OP を渡す: python tools/rcon.py --port 25826 "op Shooter"。起動: -PshotsUser=Shooter
server localhost:25726
size 1280 720
timeout 900
render 16
clouds off

cmd time set midnight
cmd weather clear
cmd gamemode spectator
hud off
fov 85
# 干潟の口: 前室 f0 の北の端から、トンネルの先の大門を見る (北向き。yaw 180)
camera skyabyss:tide_back 0.5 68.6 -31.5 180 -12
waitchunks 900
wait 60
shot gate_tide_flats
# 殻の底の心臓の間: 休み場の小部屋の南寄りから、前庭の先の大門を見る (北向き)
camera skyabyss:tide_back 0.5 52.6 -3.5 180 -22
waitchunks 900
wait 30
shot gate_tide_heart
quit
