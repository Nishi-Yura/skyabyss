# 心臓の下の果てない深み・不思議のダンジョン型の階 (docs/design/36 の 9): 八つの型の入口の眺めと、部屋の種類 (下り口・休み場・行商・敵の巣・宝の間・王の広間)。
# bash tools/dev/mc_run.sh runShots -Pscript=tools/shots/abyss_depths_v2.txt -PshotsName=depths_v2
# 階は組ごとに作るので、型・部屋は開発用の命令で探す: cmd skyabyss abyss depth kind <型> / feature <shop|house|treasure|rest> / at <entry|stairs|...> / go <階> / kingstart
# 見渡す向きは tp @s ~ ~ ~ <yaw> <pitch>。タイトル (序章の題) と HUD は、cinematic stop・title clear・hud off・huddemo off で消す
world opening_depths_v2 normal
size 1280 720
timeout 2400
render 10
clouds off

wait 120
cmd gamemode spectator
cmd time set 18000
cmd gamerule doDaylightCycle false
cmd skyabyss cinematic stop
cmd title @a clear
hud off
huddemo off
wait 120
cmd title @a clear
