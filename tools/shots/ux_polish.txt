# 使い心地の磨き (rpg_brushup A4 / A8 / A11) の確認: 石の「誰が鳴らしたか」の知らせ・自分の墓の標・仲間の札の記号。
# ./gradlew runShots -Pscript=tools/shots/ux_polish.txt   (音はランナーが消す。見本は /skyabyss dev ux ... で本番と同じ経路に出す)
world shots flat
size 1280 720
timeout 400
render 6
clouds off

cmd time set noon
cmd weather clear
cmd gamemode creative
cmd skyabyss dev ux clear
hud on
camera 0 -60 8 0 0
waitchunks
chat clear
wait 40
