# 出る絵: run/shots/boss_leftovers/ → python tools/sheets/boss_leftovers_sheet.py で docs/review/boss_leftovers/ へ
#   <心臓>_flinch      : 待ちの姿で当てた 1 tick 後 (被弾のひるみ。のけぞりと押しつぶれ)

#   tide_p2 / tide_p3 / storm_p2 : 描き直した 256 のアトラス (段階 2・3)
#   feather_fall / feather_hit   : 羽の雨 (人の目の高さから。降る羽と当たりの羽)

#   king_ash_summon    : 灰の王の「手下を呼ぶ」の溜め (腕を横へ開く)
#   w_flinch / w_claw_flinch : 心臓の番人 (光の中。待ちと爪の溜めの途中で当てる)
