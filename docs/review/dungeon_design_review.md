# 岩鯨の背 ダンジョン設計レビュー（全体の見直し）

- 日付: 2026-10-16
- 対象: 岩鯨の背のダンジョン全体（乗り込み、三つの試練、番兵長、岩鯨の心臓、報酬、周回）
- 基準: `docs/design/01_overview.md`（ブレない軸・ロードマップ・決定ログ）、`docs/design/02_stone_whale.md`、`docs/design/03_gear_and_endgame.md`
- 前提: バグの洗い出しは `docs/review/whale_completeness.md`（以下 W）で済んでいる。この文書は、バグではなく **設計として大丈夫か** を見る。W の M1〜M7 は「直る前提」で扱い、設計に関わるものだけ触れる
- 方法: 設計書とコード（`titan/**`、`entity/**`）を読んで判断した。所要時間やダメージは定数からの計算と推定で、実機では測っていない

---

## 1. 結論

**骨組みは良い。ただし、まだ「完成」とは呼べない。**

M1 の縦切り版として見ると、ダンジョンの形はできている。「三つの違う試練 → 三つの石 → 封印 → 奥のボス」という流れは分かりやすい。足場と迷路は毎回変わる。倒れても持ち物を失わない。ボスの技には予告がある。01 の軸（スケールと光、マイクラを壊さない、一人で作れる範囲）にもおおむね沿っている。

ただし、次の 5 点が足りない。どれも完成と呼ぶ前に決めるか直す必要がある。

1. **周回の導線が切れている。** 心臓を倒しても、すぐに次の周回へ入れない。島を全員が離れて 3 分待ち、さらに岩鯨がまた降りてくるまで待つ必要がある。報酬を周回前提に作り直している（L の作業）のに、周回そのものが重い。
2. **1 周が長い。** 毎回、三つの試練をすべてこなす必要があり、1 周は推定 20〜35 分かかる。最初の専用伝説までの平均は約 4 周（03 の 7.2節）なので、合わせて 2 時間前後になる。
3. **想定する強さが決まっておらず、ボスが人数で強くならない。** 一人なら心臓戦は約 4〜5 分、四人なら約 1 分で終わる（推定）。鉄の防具では、心臓の大技 2 発で倒れる。
4. **ボスの予告がパーティクルだけに頼っている。** 低スペックの PC でパーティクルを「最小」にすると、予告がほぼ見えなくなる。
5. **名前が 01 とずれている。** 01 の章の表では、1章のボスは「各巨神の守護者」になっている。「心臓」は、物語の核である「深淵の心臓」と同じ言葉で、関係が説明されていない。「欠片」も 3 種類ある。

優先度ごとの直し方は 3 章にまとめた。必須は 7 項目で、どれも一人で数日以内に収まる大きさにした。

## 2. 良いところ（変えないほうがよいもの）

| 観点 | 良い点 |
|---|---|
| 構成 | アスレ・戦い・迷路の三つの型がそろっている。どれからでも挑めて、最後に一つのボスへ集まる。01 の「ダンジョンはパズル、トラップ、中ボスで構成する」をそのまま満たしている |
| スケールと光（軸 2） | 空の鯨から鎖で引き上げられて背中へ乗り移る。巨大さを体で感じられる、このダンジョンにしかない体験になっている。体内の肉の壁、紫水晶と海のランタンの「脈の光」もシェーダーと相性がよい |
| マイクラを壊さない（軸 3） | 背中を専用ディメンションにしたので、地上の建築には触れない。ブロックの設置や破壊、近道の道具の禁止も、背中の中だけで効く |
| 理不尽にしない | 倒れても持ち物を失わない（W の M4 を直せば）。休み場から再開でき、焚き火で「あきらめる」こともできる。落下は 3 ダメージだけ |
| 毎回の変化 | 足場と迷路は毎回作り直される。足場の生成器は 5000 種で失敗 0 件、迷路は入口で必ず道が分かれ、正しい道は 26 マス以上ある（W の検査） |
| ボスの読みやすさ | 心臓の技はどれも 1 秒以上の予告がある。輪は跳べば避けられる。同じ技は続けて出ない。段階の変わり目の 3 秒は無敵で、押し返すだけ。殻が閉じた直後の 1 秒は「攻めどき」になる。覚えれば上達できる作りになっている |
| 人数への配慮 | 広間は人数で番兵が増える。報酬は個人ごとの抽選で、人の取り分を奪わない |
| 低スペックへの配慮 | 岩鯨のモデルは 3 段の LOD（64 ブロック未満は近景、160 未満は中景、それより遠くは遠景）。巨大な体を軽く描ける |
| 読みやすい文言 | 看板は 4 行以内で短い。チャットは用途ごとに色を分けている。迷路の入口の「青い光の下に息の泡がある」のように、必要な手がかりを看板で渡している |
| 一人で作れる範囲（軸 5） | 心臓はその場から動かない。移動の AI が要らないので、作りやすく壊れにくい |

## 3. 直すもの（優先度順）

### 3.1 必須（完成と呼ぶ前に）

#### 必須1 周回の導線をつなぐ

- **問題**
  - 心臓を倒すと光の柱で尾の台へ戻るが、試練は戻らない。戻るのは「島に誰もいなくなって 3 分たったとき」だけ（02 の 7.1節）。
  - そのため、もう一度挑むには、全員が地上へ降り、3 分待ち、岩鯨がまた降りてくるのを待って（次の降下まで 5〜7.5 分、降りている時間は 3 分）乗り直す必要がある。
  - マルチでは、島で誰か一人が放置しているだけで、誰も挑み直せない（W の S6）。
- **直し方（小さい案）**
  - 心臓を倒したあと、**封印の先（宝物庫より奥）に誰もいなくなって 30 秒たったら、試練を戻す**。尾の台や地上にいる人は数えない。尾の台の看板に「心臓が再び脈を打つまで、しばし待て」と出す。
  - 欠片の受け取り記録と巨神の記憶は今どおり残す。
  - W の M2（休み場の記録をリセットの番号で無効にする）と同時に入れる。番号を一つ増やすだけで、二つの問題をまとめて扱える。
- **確かめ方**: 一人で心臓を倒し、光の柱で尾の台へ戻る。30 秒後に祠から入り直すと、石が消えていて、足場の形も変わっていること。

#### 必須2 2周目以降の 1 周を短くする

- **問題**: 毎周、西・東・下の三つすべてと心臓が必要になる。推定の所要時間は次のとおり。

| 区間 | 推定（慣れた人） | 根拠 |
|---|---|---|
| 尾の台 → 鼓動の間、移動の合計 | 2〜3 分 | 島は全長 240 |
| 西の翼 | 4〜8 分 | 三つの谷で足場 24〜38 個。崩れるまで 0.6 秒、落ちると休み場から |
| 東の翼 | 5〜8 分 | 6 つの波と番兵長（HP 280） |
| 下の水路 | 4〜10 分 | 11×15 の迷路。正しい道は 26 マス以上、真っ暗、休み場なし |
| 心臓 | 4〜5 分（一人） | 下の必須3 |
| 合計 | **20〜35 分** | 初回は迷路と足場で倒れるので、さらに長い |

  周回が前提なら、1 周 15〜20 分が目安になる。今の長さでは、3 回目あたりから「作業」に感じやすい。

- **直し方（小さい案）**: **リセットのたびに、三つの試練のうち一つを「眠り」にする。** その石は最初から歌っている。
  - どれを眠らせるかは、リセットの種で選ぶ。尾の台の「三つの試練」の看板の 4 行目か、乗り込みのときの語りで知らせる（例:「今宵、西の石はすでに歌っている」）。
  - ワールドで心臓がまだ一度も倒されていない間は、三つとも必要にする。初回の達成感を守るため。
  - 実装は「リセット時に石を一つ点けておく」だけでよい。足場や迷路の生成を省く必要もない。
  - 余裕があれば、3.3節の「週替わりの兆し」とまとめる。
- **確かめ方**: 2 周目から、1 周を 15〜20 分で回れること。

#### 必須3 想定する強さを決め、心臓を人数で強くする

- **問題**
  - 岩鯨は 3 日目から現れる。この時期のプレイヤーは、鉄の装備かそれ以下のことが多い。01 のレベル（M1 の「レベル基盤」）はまだなく、強さはバニラの装備だけで決まる。
  - 心臓は HP 600、防御 12、靭性 6。プレイヤーが与える傷は、防御で約 4 割減る。
    - 鉄の剣（6）なら 1 発 約 3.5、全部で約 170 発。
    - ダイヤの剣（7）なら 1 発 約 4.2、全部で約 140 発。
    - 一人だと 4〜5 分かかる。避けながらなので、硬いだけの時間が長く感じやすい。
  - 心臓の大技（殻の突き 14、殻の落下 14、光線と鎖 12）を受けると、こうなる。
    - 鉄一式（防御 15、靭性 0）: 1 発 約 9.5。2 発でほぼ倒れる。
    - ダイヤ一式: 1 発 約 4.8。
    - 装備による差が大きく、どちらに合わせたのかが決まっていない。
  - 人数による強化がない（W の S5。03 の 1.1節「人数が増えると敵とボスを強く」と食い違う）。四人だと約 1 分で終わり、段階 3 の技をほとんど見ないまま倒せてしまう。
- **直し方（小さい案）**
  1. **想定を 01 か 02 に一行で書く。** 案:「初回は鉄一式＋鉄の剣か弓で、何度か倒れながらクリアできる。ダイヤなら周回が楽になる」。
  2. その想定に合わせて、数値だけを変える。案:
     - 心臓の防御を 12 から 8 に下げる。これで与える傷が約 2〜3 割増える（鉄の剣で 1 発 約 3.5 → 約 4.5）。
     - 心臓の HP は「450 × (1 + 0.6 ×（参加者 − 1））」にする。一人なら 450 で約 3 分、四人なら 1260 で約 2 分（推定）。
     - 大技は 14 を 12 に、12 を 10 に下げる。鉄一式でも 3 発までは耐えられる。
  3. 番兵長も同じ式で人数に応じて強くする。今は護衛の番兵だけが増える。
- **確かめ方**: 鉄一式で、一人で 3 回以内に倒せること。四人でも 2 分前後かかり、段階 3 の技を一通り見られること。

#### 必須4 予告を、パーティクルを減らした設定でも見えるようにする

- **問題**: 心臓と番兵長の予告は、色の粒（パーティクル）と音で出している。ビデオ設定でパーティクルを「最小」にすると、普通に送ったパーティクルはほとんど描かれない。低スペックの PC で遊ぶ人ほどこの設定にするので、予告なしの攻撃を受けることになる。これは「理不尽にしない」という方針に反する。
- **直し方（小さい案）**
  - 予告の粒だけ、`ServerLevel.sendParticles(ServerPlayer, options, true /*overrideLimiter*/, x, y, z, count, ...)` で送る。範囲内の人ごとに送る形にする。`overrideLimiter` を立てたパーティクルは、「最小」の設定でも描かれる。
  - その代わり、粒の数を今より減らしてよい（輪の点の間隔を 1.2 から 1.6 マスにする、など）。
  - 技ごとに別の音を出す（今もほぼそうなっている）。音だけでも技を見分けられる状態を保つ。
- **確かめ方**: パーティクル「最小」で、心臓の 9 つの技と番兵長の骨の噴出の予告が見えること。

#### 必須5 「心臓」と「守護者」の名前を 01 とそろえる

- **問題**
  - 01 の章の表では、1章のボスは「各巨神の守護者（4体）」とある。実装では、中ボスが番兵長で、最終ボスは岩鯨の心臓になっている。
  - 01 の世界観では、「心臓」は「深淵の心臓（世界の錨）」を指し、2章のボスは「心臓の番人」。プレイヤーは「岩鯨の心臓」を倒した時点で、「物語の心臓を倒してしまった」と誤解しかねない。
- **直し方（小さい案。名前は変えない）**: 01 の世界観に「巨神は心臓が生んだ守護者」とある。これを活かして、**「巨神の心臓は、深淵の心臓から分けられた鼓動」** と設定する。そうすれば、名前の重なりは謎への伏線になる。
  - 01 の章の表の 1章のボスを「各巨神の心臓（巨神の体の奥で脈打つ守護の核）」に直す。決定ログに一行足す。
  - 心臓の前室の看板か碑文（推奨3）で、一言だけほのめかす（例:「この鼓動は、地の底の大きな鼓動から分けられた」）。
  - 名前を変える案（例:「岩鯨の核」）もあるが、モデル、ボスバー、文言、ID の変更が多い。伏線にする案のほうが安い。

#### 必須6 ピースフルの扱いを決める

- **問題**: W の M7 のとおり、ピースフルでは心臓が消え続けて先へ進めない。直し方は二つあるが、どちらにするかは設計の判断になる。天の鍵の欠片は物語に必要なので、ピースフルで遊ぶ人が「物語を進められない」ことになる。
- **決め方（案）**: **ピースフルでは祠の入口で止め、「巨神は眠ったまま目を覚まさない（難易度を上げると試練が始まる）」と出す。** 島の上を歩くことと、岩鯨に乗ることはできる。
  - 理由: 三つの試練と二つのボス戦は、戦うことが前提になっている。敵だけを消すと、試練が成り立たない。
  - 01 の決定ログに「ピースフルでは物語のボスに挑めない」と一行足す。今後の巨神にも同じ決まりを使える。

#### 必須7 マルチの「参加」の決まりを一つにする

- **問題**: 誰が戦いに参加したか、扉はいつ閉じるか、報酬は誰に渡すか、が場所ごとにばらばらになっている（W の M3、S4）。修正は T と L が進めているが、決まりそのものを設計として書いておかないと、次の巨神でまたずれる。
- **決まり（案。FIX_PLAN の約束に合わせた）**
  1. 戦いの部屋（広間・心臓の間）は、一人目が入ると 5 秒の予告を出す。そのあと閉じる。閉じる瞬間に、前室と戸口にいる人も中へ入れる。
  2. 閉じた時点で中にいた人が「参加者」になる。途中で倒れても参加者のまま。報酬と人数による強化は、この人数で決まる。
  3. 参加者が倒れて前室で目を覚ましたら、戦いが続いている間は扉の内側へ戻れる。
  4. 尾の台や島の別の場所にいるだけの人は、参加者ではない。
- この 4 行を 02 の 4.2節（T）と 5.3節に書く。

### 3.2 推奨（完成の質を上げる）

#### 推奨1 迷路の「戻れない死」を減らす

- 息継ぎのくぼみは、正しい道の 4 マスごとにしかない。間違った枝の奥まで泳ぐと、息が足りずに溺れやすい。迷路の中には休み場がないので、倒れると鼓動の間から入り直しになる。しかも迷路の形は毎回変わるので、覚えて上達することもできない。真っ暗、溺れる、毎回違う、の三つが重なっていて、三つの試練の中でいちばん運に左右される。
- 案（どれか一つ）
  - 分かれ道のマスの天井にも、小さな息継ぎのくぼみを作る。間違えたらそこへ戻ればよい、と分かるようにする。
  - 正しい道の曲がり角の床に、かすかに光るもの（光る地衣類など）を置く。注意して見る人が報われる。
  - 出口の手前のマスに、息の泡の休み場（`maze` の休み場。lang に名前は残っている）を一つだけ置く。
- 水中呼吸の薬や水中呼吸のエンチャントで楽になるのは、準備した人へのごほうびとして残してよい。

#### 推奨2 碑文で物語を語る

- 今の看板は、祠の「この下に巨神の鼓動が眠っている」などを除けば、ほぼすべてが「遊び方の説明」になっている。01 には「巨神の背中に滅んだ古代文明」「天の鍵」「留まる者」とあるが、背中の上では誰が何のために作ったのかが一つも語られない。01 の軸 4 にある「謎が解ける快感」の入口がない。
- 案: **碑文を 4 枚足す。** 三つの共鳴石の横に 1 枚ずつと、心臓の前室に 1 枚。中身は lang に書くだけでよい。
  - 西: 背中に住んでいた人々のこと（例:「骨の道は、我らが巡礼の道だった」）。
  - 東: 番兵が何を守っているか。
  - 下: 水路と鯨の呼吸のこと。
  - 心臓の前: 深淵の心臓とのつながり（必須5）。
  - M2 で「伝承の書」を作るときに、この 4 枚をそのまま最初の項目として登録できる。
- 天の鍵の欠片の説明文に、使い道のほのめかしを一行足す（例:「四つそろえば、空の上へ続く何かが開く」）。今は効果がないので、持っている意味が伝わらない。

#### 推奨3 鼓動の間に進み具合を見せる

- 今は、石を鳴らしたときのチャット（「共鳴石が歌い出した（2 / 3）」）でしか進み具合が分からない。チャットを見逃すと、どの石が残っているか分からなくなる。
- 案: 宝物庫の封印の上に、三つの灯り（西・東・下）を置く。石が歌うと対応する灯りが点く。リセットで消える。

#### 推奨4 西のアスレをマルチで渡りやすくする

- 崩れる骨は、先に渡った人の後ろで崩れる。戻るまで 4.5 秒かかり、上に人がいる間は戻らない。四人だと、一人ずつ待ちながら渡ることになる。
- 案: 西の前室の看板の 4 行目を「一人ずつ渡れ」にする。仕様として受け入れ、そのことを看板で伝える。仕組みを変える必要はない。
- エリトラの滑空、跳躍とスローフォールの薬の禁止（W の S11）は、アスレの意味を守るのに必要。必須に近い。

#### 推奨5 岩鯨の出現を序章につなげる

- 今は 3 日目になると、序章の体験とは関係なく岩鯨が現れる。01 は「序章＝空の影の静かなホラー → 1章＝巨神」という順番にしている。空の影を一度も見ないうちに鯨に乗れてしまうと、「見えない巨大なものに怯える」段階を飛ばしてしまう。
- 案: 出現の条件を「3 日目以降、かつ、ワールドで空の通過（雲上の巡礼者の影）が一度起きたあと」にする。条件を一つ足すだけで済む。H の M1（出現と呼び直し）と一緒に入れる。

#### 推奨6 宝物庫の名前を中身に合わせる

- 宝箱を廃止したので、宝物庫は台座があるだけの通り道になった（W の N10）。名前から宝を期待させるのに何もない。
- 案: 「封印の間」に名前を変える（02 と看板を直す）。または、欠片を受け取った人の数だけ台座の周りが光るようにする。

#### 推奨7 用語の重なりを整理する

| 重なり | 例 | 案 |
|---|---|---|
