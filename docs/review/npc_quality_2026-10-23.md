# NPC のモデルの出来の監査 (2026-10-23)

ユーザーの指摘: 「NPC 系も雑なものが多い。語り部等に比べると。モデルのクオリティに差ができないようにして。」
基準は **語り部** (storyteller)。人の形の NPC をすべて洗い出し、語り部と同じ物差しで点を付けた。
点は 0〜5 (語り部 = 5)。**3 未満を基準より下** とした。

## 2. 直した後 (NPC v2)

作り方は語り部と同じ道具 (低ポリのメッシュ + 1 単位 2 画素の手描きアトラス + 語り部の `paint` の階調・縞・陰 + 顔のドット) を使い、
人ごとの仕様 (`tools/rough/lowpoly/npc2/cast.py`) から一人ずつ別の形を組む。

- **形**: 頭を語り部・イサナと同じ大きさ (首から 1.12 倍) にし、体の型 6 種 (普通・細身・女・太め・大柄・年寄り)、
  髪 8 種 (短い・ひっつめ・三つ編み・束ね・長い・髷・横の房・禿げ)、かぶり物 10 種 (鉢巻き・頭巾布・鳥打ち帽・ベレー・つば広・笠・高い帽子・フード・兜・押し上げ眼鏡)、
  ひげ 5 種、服の重ね (上着の裾・長衣・スカート・胴着・前掛け・肩掛け・帯・襟巻き・弾帯・肩当て・縄の巻き・袋・瓶・鍵束)。
- **顔**: 目 12 型 (白目・瞳・照り・まつげ・眠そう・眼帯 …)、眉 7 型、口 10 型、頬の赤み・そばかす・しわ・傷・煤・無精ひげ・覆面。
  形のある太い眉 (祭司・老兵・鐘守・船乗り)、眼鏡 (書記・薬師・書庫番・取引所・ハヤセ)。前髪の下の影、顎の下の影、髪の毛筋と照り。
- **持ち物**: 体とは別のメッシュ (受け口 `prop_r` / `prop_l` / `prop_back`、絵も別)。34 人全員に役の道具 (帳面・槌・道具の背負い・薬瓶・木箱・盆・鷹・鈴の杖・槍・本の山・木刀・銭袋・鋤・地図の巻き・瓶・天秤・熊手・銛・鐘・釣り竿・リュート・人形・反物・灰の桶・籠・縄・赤子・パン籠)。
  ミオの角灯は炎が光る (発光の絵)。
- **深淵の生き残り** はユーザーの選んだ案のとおり: 灯り番ミオ **B 抱えた大角灯**、測量士ハヤセ **B 三脚の測量器** (と画板)、薬師シズ **B 薬草籠と笠**、
  隊長トウヤ **A 肩のツルハシ** (縄の巻き・肩当て・赤い前掛け)、荷運びロク **C 巨大な荷袋** (毛布の巻き・鉄瓶・鍋)。
- **動き**: 肘の骨 (foreL / foreR)、裾 (hem)、後ろ髪 (hairB) を足した。持ち方の型 6 種 (free / hold_l / hold_r / hold2 / shoulder_r / ground_r) ごとに
  待機 (息・重心・裾と髪の揺れ)、話す (肘を曲げて手のひらを見せる手振りのキーフレーム。持ち物のない側の手で)、歩く (腕振り・上下・裾の返し) を一人ずつ書き出す
  (`animations/entity/npc_<名>.animation.json`)。頭は前と同じく相手を見てうなずく。
- **水密**: 全部の部品を閉じ、付け根は親の中へ沈める (肩の玉・肘の玉・腰の中の脚)。`tools/lib/mesh_close.py` で塞いで `tools/audit/mesh_audit.py` で確かめた。
- **旅の職人** も同じ作りに替えた (形は一つ・章ごとの絵 4 枚 `npc_artisan_ch1..4`)。

## 3. 確かめたこと

- `compileJava` が通る。
- 自己テスト `SKYABYSS_SELFTEST_ONLY="npc,lowpoly,town"`: 新しい段 **lowpoly npc** (`NpcModelSelfTest`) が 34 人の体・絵・骨の geo・動き 3 つ・水密の印・持ち物を確かめる。
- メッシュ監査: 開いた辺 0。裏面の透けはロクの荷袋 23・吟遊詩人の後ろ髪 63・闇商人のフード 51 画素など小さなものだけ (全体の 8110 画素に比べて小さい)。
  厩舎の番の両脚は、`mesh_close` の付け根の襟が股を越えて伸びたので襟なしに替えた (監査は「detach」と出すが、胴の重ね着で内外の判定が崩れているため。脚は胴の中へ 1.4 単位沈んでいる)。

## 4. 残り・次にやるとよいこと

- 会話の肖像 (`textures/gui/npc/face/*`) は前の 2D の絵のまま。色とかぶり物は揃えたが、生き残り 5 人の肖像は仮の絵 (灰色にくすませたもの) なので、新しい顔から描き直すとよい。
- 見張り (序章) は人の NPC ではないので今回は触っていない。
- 係の人の見た目の案 (`AttendantLook` の a/b/c) は v2 の人には使わない (v2 のメッシュが無いときだけ前の形に戻る)。
- 作り直し: `python -I tools/rough/lowpoly/npc2/build.py [名]` → `python -I tools/install/install_npc2.py [名]`。
