# 旅の地図（M）の見た目 3 案

仕様は `docs/design/33_world_and_map.md` の 4 章。印・輪・道しるべ・指したときの札は 3 案とも同じで、地と枠だけが違う。
切り替えはクライアントの設定 `mapStyle`（`config/skyabyss-client.toml`）。撮り直しは `./gradlew runShots -Pscript=tools/shots/travel_map.txt`（見本の印。画面のまん中に指した札が出ている）。

| 案 | 設定 | 絵 | ひとこと |
| --- | --- | --- | --- |
| **A 石板と海図（既定）** | `SLATE` | `map_a_slate.png`（町のまわり 600）、`map_a_voyage.png`（子に乗ったとき。右に行き先、行ける印は光の輪） | 共鳴の炉・護符の画面と同じ石板・骨の枠・四隅の青緑のひし形に、子の海図と同じ雲の海の丸い盤。mod の画面にいちばん近いので既定にした |
| B 羊皮紙 | `PARCHMENT` | `map_b_parchment.png` | 骨の枠の中に羊皮紙。輪と方位は墨の茶。設計書の最初の言い方（一枚の羊皮紙）に近いが、ほかの画面より明るく浮く |
| C 墨の夜図 | `INK` | `map_c_ink.png`（世界 2,400） | 枠なし。景色の上に墨の夜図を薄く敷き、青緑の細い輪だけ。いちばん軽いが、地の模様の繰り返しが見える |

印の絵（4 倍）: `marks_preview.png`（上が縁取りつき、下が体だけ）。並びは 町・野営地・足跡・骨・碑・章の場所・巨神・墓・仲間・目的・噂・自分・はじまりの地・祠・光の輪・積み石。素材は `python tools/gen_travel_map_assets.py`。
