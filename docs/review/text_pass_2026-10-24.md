## 確認して変えなかったもの

- 等級名は ja/en とも コモン・アンコモン・レア・エピック・ヒロイック・アーティファクト（伝説・神器は残っていない）。
- ギルド: 一般の党は「ギルド」、特定の組織は「鯨追いの組合」。ja で混ざっている箇所はなし。
- HP: ja は「HP」と「体力」を使い、ハート単位（黄ハート等）は ja に無し。
- 襲撃の入口の碑文・心の声（WR/TR/SR/ER）の ja/en は対応している。ER1 の「冷えた血は崩れる」は碑文（`lore_ember_west`）と一致しているので意図的とみて残した。
- 試練・深淵の「〜しよう」以外の命令形は、NPC の台詞・日誌・戦闘中の警告として残した。

## 追補（コードで確かめた決めごと）

- (1) 見回りの頼みの積み石: コードにもデータにも、一章の見回りの頼みが積み石を目的や地図の印に使う箇所は無い（`ch1_road_cairn` は `MapMarks` で地図に出さず、一章の道には並べない）。文は残っていない。歌石・塩の積み石・浜の碑は別の要素なので残した。変えたもの: なし。
- (2) 道しるべの石標: 変えず。`ChapterGrounds.registerRoads()` が起動時に `ch1_road_cairn` を二〜四章の道（`w2_road_*`）に並べている。コードが今も置くので、石標の文（`map.skyabyss.site.w2_road_titan_*`）は残した。「道しるべの鐘」は `now.trail`（開幕の道の拍 `OpeningBeat.TRAIL`）で、置く石標ではないので残した。
- (3) 試練の階: `objective.skyabyss.trial_deck` を削除（`TrialGuide` の目的 id は west / east_e1 / east_ck / east_e3 / east_stone / heart。deck は無い）。余燼の `sign.skyabyss.ember_board_deck_enter` / `_hall` と `checkpoint.skyabyss.ember_k0` も削除（余燼の休み場は throat / hub / w0 / w1 / wp / e0 / s0 / heart）。
- (3') 同じ理由で到達しない可能性が高く、保留: `objective.skyabyss.trial_storm_deck_*`（storm の lang 十数件）。コードの参照が無い。削除するか決めてほしい。
- (5) SR4.2「鍵は三つ」: 変えず。`ColumnChase.KEYS = 3`（甲板に散らばる鍵を三つ集める）で、文と一致している。
- (6) playtest.help.7: 旧 `/skyabyss playtest chapter` は 1〜4 のまま残っているので、その範囲は正しい。新しい `/skyabyss play chapter <0-5> [対象] [段階]`（`PlayCommands`）を併記した（ja/en）。
- 残した: 4（鐘の下の部屋）、7（en `__ember.H`）、8（once の黄ハート文）。
