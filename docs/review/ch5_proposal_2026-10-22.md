# 五章「深淵」の企画案（2026-10-22 夜の下書き。起きたら選んでほしい）

四章の終わりで鍵が「下」を指し、数え歌の「いつつ　いきづく　つちのそこ」が明かされる（34）。五章はそこから始まる。
01 の枠: 五章 = 深淵（ディメンション）、ボス = 心臓の番人、解放 = 深淵術。巨神編と同じ型（噂 → 支度 → 見る → 入る → 道筋 → 心臓 → 報告）で作る。

## 支度の段で通すバニラの進み
一章 鉄 → 二章 エンチャント → 三章 ダイヤ → 四章 醸造 と来たので、**五章はネザライト**が自然。
- 「前の私は、火の国の底の黒い鉄で鍵の器を作った」という頁で、ネザーへ行って古代の残骸を掘る理由をつくる。
- 鍛冶型（ネザライトへの強化）は、都の鍛冶場で「前の私の写し」として一枚もらえる形にする（砦の遺跡を探させない）。

## 入口と舞台（3 案）

### A 都の下から降りる大坑道（推奨）
- 入口は、四章で開く酒場の地下の奥の封じた戸（`abyss_door`。今は印だけ）。都そのものが深淵の蓋だった、という見せ方。
- 坑道を一層ずつ降りる。層ごとに巨神の名残があり、各層の奥に、四体から返った鼓動の「溜まり」がある。
- 降りきると深淵（ディメンション）。番人の間は一つの大きな部屋。
- よい所: 都が物語の中心に戻る。ずっと地上で準備してきた流れが「足もと」へ反転する（34 の主題）。
- 気になる所: 都の地下を広く使うので、都の建て直しと地下の部品が増える。

### B 鍵の指す所を掘る（ワールドのどこか）
- 鍵が脈を打つ方角へ歩き、そこで深く掘ると、深淵への裂け目がある。人ごとに違う場所ではなく、ワールドに一つ。
- よい所: マイクラらしい「掘る」体験になる。
- 気になる所: 場所を一つに決める仕組みと、掘った跡の扱い（荒らし）が要る。

### C 四つの眠りの跡から入る
- 四体の巨神が眠った場所（沈んだ・埋もれた・畳まれた所）の下に、それぞれ深淵への道がある。四つの道が深淵の中で一つになる。
- よい所: 巨神編との結びつきが強い。四章までの場所を振り返れる。
- 気になる所: 入口が四つになり、作る量が多い。

## 決めてほしいこと
1. 入口と舞台: A / B / C（推奨 A）
2. 支度でネザーへ行かせるか（推奨: 行かせる。ネザライトの支度の段 1 本）
3. 深淵の中の形: 巨神の背と同じ「道筋（歩 → 智 → 闘 → 心臓）」にするか、一続きの大きなダンジョンにするか（推奨: 道筋。試練の仕組みを使い回せる）
