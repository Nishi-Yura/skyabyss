# 鐘銭 (bell coin) の絵 — 3 案

生成: `python tools/gen_bell_coin.py` (入れるのは `--install <案>`)。比べ: `compare.png` (8 倍と、いまの品物と並べた 4 倍・原寸)。

| 案 | 絵 | 中身 |
|---|---|---|
| **A 角穴の丸い銭 (採用)** | `a.png` | 古い青銅の丸い銭。真ん中に角穴、その上に小さな鐘の浮き彫り。縁は一段高く、緑青の点 |
| B 鐘の形の銭 | `b.png` | 銭そのものが鐘の形。上に紐の穴、肩と口の帯、真ん中の筋 |
| C 紐に通した銭の束 | `c.png` | 角穴の銭三枚を紐で斜めに連ねる |

採用は A。いまの 32x32 の品物 (真珠・堅焼き・割り符) と同じく、丸い形に 1 画素の暗い縁取りと 3〜4 段の平らな色で、並べたときに一番なじむ。
「銭」と一目でわかり、鐘の浮き彫りで名前ともつながる。B は鐘の置き物に見え、C は原寸で銭の数が読めない。

入れた先: `src/main/resources/assets/skyabyss/textures/item/bell_coin.png`
