【デザイン概要】苔這いは、岩鯨の背に積もった苔の中で暮らす『鯨の遺骸から這い出した小さな骨』。岩鯨の素材 (鯨骨・石・苔) だけで体を作り、骨は象牙色、苔は厚くて丸い。役割は序盤の近接の群れ (足が速く、飛びかかって鈍足を与える、わりと弱い敵) で、10〜20 ブロック先でも輪郭で見分けられるよう、3 案とも体の形をはっきり変えた。覚えやすい特徴は 1 つに絞り、目を『光る・虹彩の輪のある丸い目玉』にして、参考にした目玉のボスと質感を合わせた。かわいさと不気味さの釣り合いは、丸くて素直な形に、じっと見る目と歯の列を足して静かな怖さを出している。 【数字】立方体の数は前回の B (628 箱 / 1,975 面) 近辺 (A 600 箱 / 1,927 面、B 672 箱 / 2,171 面、C 665 箱 / 2,511 面)。重なりは 3 案とも 0。骨の構成は A 14 本、B 27 本、C 23 本で、脚は上と下に分かれ、顎や爪も動かせる。
