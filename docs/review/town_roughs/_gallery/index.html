はじまりの町 ラフ選定

docs/design/33 の 2.2。空を見張る小さな国「鐘の国」の都。見取り図は案 A、建物の形は一棟ずつ採用済み。いまは「都の建築をもっと豪華に。壁の中ぎりぎりまで建物を詰め、建築の水準を参考画像くらいに」の作り直し中。まず作風を一つ選ぶ。直してほしい点はメモに。

ラフ 3案

都の作風（同じ一角を三つの作風で）

未選択

三案とも同じ一角（北に町家の並び、東の角に鐘の塔、南に張り出しと小塔のある館、南東に店とアーケード、真ん中に広場と噴水）。壁は二重で、柱型と帯が前に出て窓が一つ奥に入る。屋根は全段が階段の瓦で、妻の縁は白い縁石、屋根窓・煙突・隅の小塔つき。選んだ作風で都全体を建て直し、建物の種類を増やし（張り出し窓・露台・旗・橋・段の庭）、壁の中を詰める。いまの作り込みはまだ参考画像の手前。作風が決まったら一棟ずつ部品を足して上げていく。

採用する案
