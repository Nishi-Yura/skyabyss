防具を根本から作り直す低ポリのラフ。今の 4 組 (箱 245〜285・面 1,250〜1,463) は『体の箱に板をかぶせた』作りで、輪郭がプレイヤーの四角のままだった。ここでは、4 巨神 (岩鯨・潮殻・雷翼・余燼) の一式を 3 つの基盤で作った。骨は今と同じ (armorHead / Body / RightArm / LeftArm / RightLeg / LeftLeg / RightBoot / LeftBoot)。兜・胸 (腕と肩を含む)・脚・靴の 4 部位、非立方体、1 ブロック 32 テクセルのドット絵。顔は 3 案とも覆わない (額の環・耳・後頭だけ)。材質の言葉は敵と武器と同じ: 岩鯨 = 鯨骨・青灰の岩・苔 / 潮殻 = 珊瑚・真珠層・濡れた石 / 雷翼 = 銅・白い羽・紺の鋼 / 余燼 = 玄武岩 (割れ目が光る)・鍛冶の鉄。三角形 (一式 = 兜 + 胸 + 脚 + 靴): A: 岩鯨 788・潮殻 682・雷翼 858・余燼 546 / B: 岩鯨 762・潮殻 702・雷翼 816・余燼 595 / C: 岩鯨 842・潮殻 742・雷翼 864・余燼 627。予算は一式 900 以下 (伝説 1,100 以下)。★ の C は階級も作った (岩鯨): 通常 842 → レア 958 → 伝説 1110。階級のつけ方は武器の土台 (docs/review/weapon_design_base.md) と同じ: 通常 = 灰色の鉄の縁 / レア = 部品 +1 (胸の弧 1 段・側頭の飾り・前腕の飾り) + 青みの縁 + 短い光の筋 / 伝説 = 輪郭を変える大きな一点 (頭の後ろの環と背の布) + 金の縁 + 筋が増える。+5 / +10 はメッシュを変えず、絵と glowmask だけを差し替える (縁が一段ずつ明るい)。シートの 1 行 = 1 巨神。左から 現在 / A / B / C (それぞれ正面・背面・3/4)。最下段が階級。出力: docs/review/lowpoly_roughs/armor/{a,b,c}/<set>/<部位>_{mesh.json,atlas.png,glowmask.png} (<set> = stone_whale / tide_shell / thunder_wing / ember。★ の岩鯨はレア・伝説の *_rare_* *_legend_* と +5 / +10 の絵つき)。作り方は tools/rough/lowpoly/armor/ (build_all.py)。採りたい案の目安: C (輪郭が体の外へ出て、4 巨神が重ならず、敵と武器の材質の言葉と合う。面も少ない)。ただし B の頭巾の静けさ (物語・ホラー) も強いので、B の衣の裾と頭巾を C の骨組みに足す折衷もできる。
