- 絵: 1 単位 3 テクセル (基準の 2 より細かい)。錨鉄 (打ち跡・縁の摩耗・錆の垂れ)、真鍮 (磨かれた縁・緑青)、革 (斜めの巻きと縫い目)、骨 (成長線)、硝子 (枠の近くが暗い)、付着物。縁は階級の色。
- 強化: +5 で刃の中心に破線の光、+10 で端まで通る光と縁の光 (メッシュは同じ)。
- 持ち方: `tools/lib/weapon_display.py` の表に 3 品を足した (剣は片手、錨は大鎚、短剣は水路の牙と同じ型)。
- 動き: `tools/gen/items/gen_weapon_moves.py` に 3 品の連撃 (剣 3 段・錨 2 段・短剣 3 段、どの段も溜めの止め・収まり・光・体の傾きあり) と点検。`MoveSets.ITEMS` に足した。
- 身につけた位置: `AccessoryWornLayer` (聴き筒 = 胸、錘 = 腰の右の後ろ)。
