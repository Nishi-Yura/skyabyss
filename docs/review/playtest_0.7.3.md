# 試遊 0.7.3 の確かめ順

0.7.2 のあとに入れたもの（2026-10-28）。大きな変更は五つ:
- **見た目の選定を入れた**: 風見鶏（真鍮の鶏の持ち物）、小舟（低ポリの渡し舟）。
- **見どころ 24 か所を作り直した**（外れの建物・野営・門・塔・風車・灯台など）。町と都の壁の外は、まわりの土地になじむ地面と小物、都は畑と木立。
- **深淵**: 心臓の番人が最後のボスらしく（体力 1000・技 7 つ追加・段で解放）。層の主に技ごとの構えと打ちの動き。心臓の間に骨の肋、塩と灰の下り道に支え木の枠、骨と雷の層の部屋に小物、果てない深みの階に材料の斑と蛇腹。
- **組合の踏破の記録**: 背中の踏破の速さ（巨神ごと・人数ごとの上位 10）と、今週のギルドの心臓の数。
- 細かい直し: 深淵に入ったときの場所の名、塩・灰の頼みの文。

## 0. 始め方（全員）

- **新しい世界で始めること。** 専用サーバーは `server.properties` に `level-type=skyabyss\:continent` を書いてから世界を作る。
- jar は `skyabyss-0.7.3.jar`（サーバーと全員のクライアントに同じもの）。
- 前の版の世界でも動くが、都は前の作りのまま（町と深淵は建て直される）。

## 1. 地上

- 町に近づくと、壁の外の地面がまわりの土地（炎は赤い砂、潮は砂、雷は岩と雪、鯨は苔）になっているか。街道が途切れていないか。
- 都の壁の外に畑と木立があるか。
- 見どころ（野盗の野営・旅人の野営・巨神の肋・環状列石・風の門・玄武岩の門・灯台・避雷の塔・見張り塔・風車・塚・崩れた家・道の祠・坑口ほか）が前より作り込まれているか。中に入れる所は入れるか。

## 2. 品

- 鯨追いの頼みの報酬の風見鶏が、真鍮の鶏の形で手に持てるか。
- 市の道具屋の小舟が低ポリの渡し舟の形で、乗って漕げるか。向きは進む方に舳先か。

## 3. 組合の記録

- 巨神の心臓を止めたあと、記録に載ると一行の知らせが出るか。
- 組合の書記の「背中の踏破の記録を見せて」と `/skyroute runs` で、巨神ごとの速さと今週のギルドが出るか。

## 4. 深淵（五章）

- 入ったとき、左上の場所の名が「深淵」になっているか（前は英字のキーが出た）。
- 塩と灰の下り道に支え木の枠が並んでいるか。ロクとトウヤの護りがふさがれずに進むか。
- 骨と雷の層の部屋に骨の山・頭骨・避雷針・銅の板・垂れる鍾乳石や鎖があり、道をふさいでいないか。
- 層の主: 技ごとに構え（2 秒）と打ちの動きがあるか。
- 心臓の間: 壁の骨の肋が見えるか。番人の体力が多く（約 1000）、段ごとに新しい技（薙ぎ・叩き・肋の棘・鼓動の輪・影の挟み撃ち・闇からの跳びかかり・狂乱）が出るか。同じ技が続けて出ないか。
- 心臓の下の深み: 階の壁・床が単色でなく、壁の上に縁の段があるか。
