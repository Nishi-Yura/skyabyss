# 余燼の三つの試練 ラフ 3案 (A / B / C)

生成: `tools/rough/ember_trial.py` (ラフと採用の書き出し)。担当 C1・C2・C3 (13 の 4 章)。32px のブロックの面と品のアイコン 37 枚。

## 比較シート (左から A B C、3 倍)
- `compare_crust.png` 冷え殻 (段階 0〜2)・灰の壺の台・灰の壺
- `compare_forge.png` 大炉の口 (段階 0〜5 とひび入り)・鞴・金床・槽・火の鍵 2 つ
- `compare_hearth.png` 火床 (上面と側面、強さ 0〜4)・噴気の割れ目 (段階 0〜2)・熾

各案のフォルダ `<名前>/<a|b|c>.png` に 1 枚ずつある。採用されなかった案も残してある。ゲームの中の見え方は `ingame_ember_trial_*.png` (台本 `tools/shots/ember_trials.txt`)。

## 3 案の違い
- **A 層の岩 + 細い割れ目**: 玄武岩の地層の横筋。灰がかった黒に、橙〜黄の細い割れ目。余燼の背の壁 (玄武岩・黒石) と同じ系統
- **B 柱状節理**: 六角に近い柱の断面と、赤い継ぎ目。暖色寄りで火が強い
- **C 灰まみれ**: 青みの灰色の岩に白い灰の粒。火は小さく低い温度の色

## 推奨 (すべて A)
| 品 | 推奨 | 理由 | 弱いところ |
|---|---|---|---|
| 冷え殻 | A | 段階 0 は黒い岩の面、段階 1 で割れ目が橙に光り、段階 2 で黄まで光る。三つが一目で分かる。B は茶で、玄武岩の壁と別物に見える。C は白い粒が多く、溶岩の上で目立たない | 段階 0 の割れ目が見えにくい (割れる前の「まだ大丈夫」の合図なので、わざと) |
| 灰の壺・台 | A | 灰色の壺と、口の白い灰。B は茶で土器に見える。C は青白く冷たすぎる | 32px では口の灰が数画素 |
| 大炉の口 | A | 黒 → 赤 → 橙 → 黄 → 白の塊が、円で大きく読める。レンガの枠が黒石に近く、炉の口に見える。B は枠が茶で、色の区別が付きにくい。C は枠が青く、赤が沈む | ひび入りは黒い線が数本 (打ち損ねの合図) |
| 鞴・金床・槽 | A | 木の板に革の蛇腹と、踏む印の火。金床は鉄の面と欠けた縁。槽は上面が水で側面が黒石 | 金床は全面が同じ絵 (面ごとの違いは付けていない) |
| 火の鍵 2 つ | A | 焼き入れ前は橙〜黄に光る鍵、焼き入れ後は鉄の鍵に熾の点。二つがすぐ見分けられる | どちらも斜めの細い軸 |
| 火床・噴気 | A | 火の高さと色が 0〜4 で段階的。噴気の割れ目は暗い線 → 白 → 橙黄で、予告が分かる | 火床の側面は火が下から上がるだけ |
| 熾 | A | 暗い炭の塊に熾の点が散る | 暗い所で小さい |

推奨は人の判断で差し替えてよい。`python tools/rough/ember_trial.py --install --option <名前>=<b|c>` で書き出し直せる (名前の頭が合う全部が替わる。例 `ash_forge=b`)。
