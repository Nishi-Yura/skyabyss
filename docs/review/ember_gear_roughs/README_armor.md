# 余燼の鎧 (余燼の巨神の防具 4 部位) ラフ 3 案

余燼の巨神 (火蜥蜴の巨神、夜に地へ伏せて眠る) の皮から作った防具。兜・胸当て・脚当て・靴の 4 部位。
人型の台に着せた 3D と、インベントリ用の 32x32 アイコンを 3 案で比べる。
色は玄武岩 (黒)、灰の凝灰岩、溶岩の赤橙の光、溶けた黄。青と白は使わない。

## 案

- **A 火山の背** (推奨): 玄武岩の板。兜の頂に 2 段の火山と溶けた黄の火口。胸の中央に上から下へ溶岩の筋 (先は黄)。肩に噴気孔 (灰の輪と溶岩の核)。背は 4 段の背骨で、頂と尾に溶岩の口。
- **B 溶岩の縞**: 少し濃い玄武岩。胸の段の間に溶岩の縞が全幅に走る。兜は平らな背びれ、頬と腿に溶岩の点。肩は灰の縁と鱗の塊。
- **C 割れた殻**: やや明るい灰の板 (灰の凝灰岩寄り)。兜の頂が 2 つに割れている。胸の中央の割れ目と肩の噴気孔は暗い穴 (煙の孔)。光は少なく、溶岩の筋だけ。

## 推奨: A 火山の背

理由:
- 兜の火口・肩の噴気孔・胸の溶岩の筋・背骨の口で、火山の巨神の絵が 4 部位すべてに出る。背の火口が一人称の画面で見えないのは、3 案とも同じ。
- 溶岩の光が 3 案の中でいちばん目に入る (光る画素 1744) が、光の場所が体の中心 (胸・頭・肩) にまとまっているので、ごちゃごちゃしない。
- B は溶岩の縞が横に走り、胸が帯で区切られて見える。C は光が少なく、玄武岩の殻と灰の区別がつきにくい。

- 重なりは `voxel.check_overlaps` で調べた (回転は使わないので全箱を比べている)。体への食い込みは、人型の台 (頭・胴・両腕・両脚) の箱と比べた。
- 3 案の骨・寸法は同じ (`tide_armor.py` と同じ 8 本の骨、同じ台の位置)。違うのは飾りと材料の濃さ。
- 顔の正面は、額の庇とあごの間を開けてある (覗き穴)。目の高さの面は灰の台がそのまま見える。
- 箱は段差のある階段で作った (胸の 3 段、背骨の 4 段、兜の 2 段の錐、盛り上がりの鱗)。平らな 1 枚の板にはしていない。

## 自己レビュー

1. 1 周目 (3 案の比較シート): 顔の開き、胸の溶岩の筋・縞・割れ目の違いは出ている。箱の重なりが 1 組 (胸の板と縁) あったので、胸の板を縁の手前までに縮めた。背骨が背から見えず、背中が黒い壁に見えた。
2. 2 周目 (背と 3/4 の近景): 背骨を幅 3 単位・高さ 9 単位に太くし、頂と尾に溶岩の口を付けた。背から見て背骨と光の点が読める。A の兜の火口は、3/4 で灯り (ランプ) に見えるが、火山の頂として読めるので残した。

3. 3 周目 (A のみ。B / C は 2 周目のまま): 指示 (平らな面・溶岩の縞・アイコンの浮いた画素) を受けて直した。
   - 鱗と段: 背骨の両脇に段の板 (背の平らな壁をなくす)。袖の外側は千鳥の鱗 (0.5 単位の盛り上がり)。肘の板 (前に 0.5 出す)。
   - 兜: 頂のランプをやめ、玄武岩の火口の縁 (4 枚) の中に溶岩を 0.5 単位低く沈めた。額の上に面取りの段 (0.5 単位)。
   - 胸: 玄武岩の板の段を 0.5 単位の枡に分け、溶岩の筋を中央の幹から左右に枝分かれさせた (幹の先は溶けた黄)。小さな割れ目を 2 つ。
   - 色: 灰の凝灰岩を褐色寄りに暗くした (石鯨の灰色と離すため)。
   - アイコン: 兜の浮いた橙の画素と耳の光を外した。脚の光の筋は板の中に入れた。靴は足の形 (つま先の出た足と底)。胸のアイコンは 3D の枝分かれと同じ形。
   - 検査: 重なり 0、体への食い込み 0 (3 案とも)。光る画素 2016。
   - 残った弱さ: 肩と脛は面取りが少ない (肩の縁は 1 枚の板、脛は平ら)。火口の光は小さく、遠いと見えない。ゲームでは未確認。

## 注意

- 形はまだ角ばっている。段は階段状だが、曲面の丸みはない。鱗は 0.5 単位の盛り上がりの千鳥で、六角形の鱗そのものではない。
- A の兜の火口は、近くで見ると光る箱が 1 つ浮いて見える (ランプ)。ゲームで見て、灰の縁を足すか判断する。
- 灰の縁 (`ash`) は岩鯨の石の甲殻と似た灰色になる。ゲームで並べたとき区別がつくか確かめる。
- 顔の穴は、一人称の画面で兜の額の庇が視界を狭めないか確かめる (潮殻の鎧で、兜が顔を隠して直した経緯がある)。
- ゲームでは確かめていない (Gradle を動かしていない、ゲームは起動していない)。
- 光る画素は `glowmask.png` の 1744 画素 (A)。AutoGlowingGeoLayer で光る。
