## 推奨案と理由 (すべて A)

| 品 | 推奨 | 理由 | 弱いところ |
|---|---|---|---|
| 余燼の戦斧 | A | 刃先に沿う、ぎざぎざの熾火のひび。刃と火が一目で分かる。B は縁の線が短く、32px で光が点になる。C は鉄の箍が良いが、ひびが途切れる | 刃が大きくなったが、手に持つと頭が大きな塊に見える。32px では、ひびが数画素になる |
| 鍛え手の大鎚 | A | 中ボスの大鎚と同じ鉄の頭・錆の帯・橙黄の打つ面。B は頭がほぼ茶色の石で、中ボスと違う。C は打つ面が橙で、雑魚の火掻きと色がそろわない | 柄の長さは中ボスの比をそのまま写していない (全長 30 単位)。持ち方は要確認 |
| 灰被りの火掻き | A | 細い鉄棒、青銅の輪、先の橙の光。雑魚の火掻き棒 (`weapon_poker`) と同じ並び。B は先が赤すぎて、炉の熱より血の色に見える。C は黄で明るすぎる | 3D の鉤が細い |
| 熾火の外套 | A | 襟の留め金から裾へ広がる折り目、裾の不揃いな熾火の帯。外套と読める | 袋や服に見えることがある。B は玄武岩で暗い |
| 熾りの護符 | A | 玄武岩の円盤の中に炭が一つ光る。鉄の紐付きで護符と読める | B は四角で、護符より額縁に見える |
| 余燼の灯 | A | 鉄の籠の中に火。吊り手つきで灯と分かる | B は真鍮の丸灯で、火が白く見える |
| 熾火の角杯 | A | 暗い角の身、口の鉄の縁、革の帯、口に熾火の酒と立つ火の粉。牙には見えず、角の杯と読める | 口が小さく、32px では上の光が点になる |

| 余燼の欠片 | A | 玄武岩の欠片に熾火の筋。欠片としての形 | B は灰色の上半分が白く、灰の欠片に見える |
| 火の粉の粉 | A | 暗い縁、橙の本体、黄の芯の小さな山と、浮いた火の粉。動物には見えない | B は青銅の皿で、粉が見えにくい。C は散りすぎて粉に見えない |
| 燠の殻 | A | 玄武岩の殻の板と熾火の継ぎ目。cinder_roller の殻 (案 A) と同じ色 | 32px では暗くて板の形が読みにくい |

推奨は人の判断で差し替えてよい。`gen_ember_items.py --option <品>=<b|c>` で再書き出しできる。

## 3D の作り (採用案)
- 1 画素 = 3 ボクセル。立てた向きの絵を 3 倍の解像度にして、縁からの距離で断面を丸める (中心が厚く、縁へ薄くなる)。
- 盛り上がり (bump): 戦斧の刃・鉄の箍・青銅の輪・革の握りを、アイコンの色とは別に盛り上げる。
- 武器は -45 度に傾けて書き出す (刃先が右上)。
- 光る部分は `neoforge_data` の block_light / sky_light 15 (既存の武器と同じ)。
- 要素数 (上限 1500): 戦斧 243、大鎚 86、火掻き 91。重なりは 0 (`gen_ember_items.py` で確かめる)。
- 長さ: 戦斧 22 単位 (captain_pike と同じ)、火掻き 22 単位、大鎚 30 単位 (両手で振る重い武器として長めにした)。

## レビューの周回
- 1 周目 (描いて見た): 戦斧の刃が暗く小さく、背景に溶けた。角の口が小さく、杯に見えなかった。火掻きの棒が細く、32px で消えかけた。 → 戦斧の刃を大きく明るい玄武岩にし、刺しも大きくした。角の口を広げ、テーパーを強くした。火掻きの棒を鉄の明るい色にした。
- 2 周目 (直した絵を見た): 戦斧と火掻きは 32px で形が読めるようになった。角は直したあとも牙に近く、口の光は小さい。ここは弱いので、採用のまま残して README に書いた。大鎚は 1 周目から中ボスの形を保っていたので変えていない。
- 3 周目 (別の担当の指摘を受けて直した):
  - 戦斧: 刃の 2 つの光る点が目に見えた (顔に見える)。→ 刃先に沿う、途切れない熾火のひびに変えた (3D も同じ)。刃を大きく、刃先の縁を明るくした。要素 181 → 243。
  - 熾火の外套: 墓石や鐘に見えた。→ 首元の留め金、襟の陰、裾へ広がる折り目、不揃いな裾の熾火の帯に変えた。
  - 熾火の角杯: 骨の牙に見えた。→ 暗い角の色、口の鉄の縁、革の帯、口の熾火の酒と立つ火の粉に変えた。
  - 火の粉の粉: 動物 (ナメクジ) に見えた。→ 暗い縁・橙の本体・黄の芯の山と、浮いた火の粉にした。1 画素の点は輪郭線で暗くなるので、2 画素以上にした。
  - 手に持った絵の確認: 火掻き (`thrall_poker/a/hand.png`) は、先の光と輪が読めて良い。戦斧 (`ember_war_axe/a/hand.png`) は、頭が大きな塊に見える。ひびは読めるが、頭の大きさは次に直す余地がある。
  - 大鎚 (`smith_hammer/a/hand.png`) は、2 周目までの確認のまま。
- 推奨は変えず、すべて A のまま。

## 注意

- アイコンだけの品 (護符・灯・角杯・心核・欠片・粉・殻・外套) には 3D がない。
