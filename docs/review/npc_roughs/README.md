## アニメ

| 名前 | 動き |
|---|---|
| idle | 体のわずかな上下、肩掛け・腕・結縄・背の袋のゆらぎ |
| walk | 脚を振る (語り部は小さな歩幅でゆっくり、腕はほとんど振らない)、結縄が揺れる |
| talk | 右手を少し前へ上げてゆっくり振る。頭のうなずきと相手を見る向きはコード (`NpcRenderer`) |

GeckoLib はファイルの回転の X を反転して読むので、「腕を前へ上げる」はファイルに +X で書いた。左右対称に揺れる動きは符号を取り違えても見た目が変わらない。
