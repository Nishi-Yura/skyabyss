# 村の NPC ラフ (語り部・鯨追い)

生成: `python tools/rough/npc.py` (採用書き出しは `--install`)。各案は `<id>/<a|b|c>/` に geo.json と texture.png。

## 採用案

| NPC | 採用 | 理由 | 直したこと |
|---|---|---|---|
| 語り部 storyteller | A 肩掛けの老婆 | 肩掛けと結縄 (腰の縄の数え歌) と髷が一度に見え、要件の要素が最も揃う。B は前掛けが主役になり「巫女寄り」に寄りすぎた。C は背負い籠が形を大きく変える | 肩掛けの前に V 字の開き (喉元を見せる)、髷を追加、結縄に結び目 2 つを入れた |
| 鯨追い whale_chaser | A 長外套・広つば | 長い外套と背の袋 (丸めた地図・鍋) と遠眼鏡のケースが揃う。B は袋と遠眼鏡が無い。C は A と外形がほぼ同じで差が小さい | 鯨骨の留め具と羽を B から A の帽子へ移した |
