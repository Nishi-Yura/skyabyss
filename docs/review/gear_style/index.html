武器・防具の様式 選定（3 方向）

ユーザーの要望「防具・武器のモデルを見直して、もっとかっこよくしたい。ダサいものは少し変えたり作り直したり。アニメーションもかっこよく。名前は変えなくていい」への最初の提案です。ほかのゲームの調べ（docs/research/gear_art_research.md）と今の装備の診断（docs/review/gear_audit.md）から、方向を 3 つ作りました。

同じ条件で比べます。題材は岩鯨の一式（大剣・弓・槍・杖・短剣と、兜・胸・脚・靴）。どれも低ポリ + 1 ブロック 32 テクセル、階級は表示がレアの形（階級の並びは別に出します）。形・絵・光る画素はこのページ用のラフで、ゲームの設定ではありません。選ぶと、その方向で全装備を順に作り直します。名前・数値は変えません。

見方: 各方向の絵は ① 並べた姿 ② 武器 5 点の回転（正面・3/4・横・斜め後ろ）③ 防具の回転（正面・3/4・横・背中）と部位の近接 ④ 手に持った姿（三人称の模式）⑤ 階級の並び（大剣のコモン → レア → レジェンド）⑥ 黒塗り（遠目）。最後に、武器 5 種 x 3 方向の一人称の攻撃の動き（絵コンテ）があります。

3 方向の黒塗り比べ（遠目で読めるか）

黒く塗って、大きいサイズと小さいサイズ（遠目）で並べます。武器 5 点と防具の正面。上から A・B・C。

A 量塊 (Carved Mass)　骨と石の大きな塊。太く、止まって見える

参考モンスターハンター（大剣・素材の塊）、ダークソウル（単純で太い輪郭）

  • 輪郭は太く大きな 1 つ。細い棒・環・布は使わない
  • 材質は骨と石の 2 つが主役。苔は上向きの面だけ
  • 光は 1 か所（宝石・視き穴・樋の付け根）だけ
  • 防具は面の大きな板。肩は二段の石板、兜は視き穴 1 本

武器大剣 = 断ち切りの厚い板（背は直線、先は斜め）／弓 = 太く短い骨弓に石の握り／槍 = 広い葉の穂と下がり羽根／杖 = 骨の環に抱かれた核／短剣 = 肉厚の鉈

防具全面の兜（背びれの冠）、骨の胸板と石の殻、二段の石板の肩（右だけ大きな牙）、太い腿当てと膝の骨、重い鉄靴

面の数武器 大剣 212 / 弓 156 / 槍 170 / 杖 280 / 短剣 176 ／ 防具 4 部位 680（03 の予算: 通常 250・レア 300・レジェンド 350・防具 4 部位 3,000 以下）

良い点: 遠目で最も読める（黒塗りで 5 武器と防具がはっきり別）。作りやすく、面の予算に収まる（武器 156〜280 面・防具 680 面）。階級の差も大きな骨の板で出せる
気になる点: 「重い戦士」一本調子になりやすい。潮殻・雷翼・余燼の軽い巨神には重い。物語（使い込み）は少ない

動きの性格動き: 溜めが長く、命中で止まる（ヒットストップ 2〜3 tick）。画面が揺れる。重さが主役

B 祭具 (Ritual Grace)　細く長く、金の縁と垂れる布。動きが見える

参考原神（槍・弓・剣の長い輪郭、環と房）、ゼルダ ティアーズ オブ ザ キングダム（材質の言葉がそろった形）

  • 輪郭は細く長い。鍔は鯨の尾びれ、頭に環、柄頭に房
  • 材質は象牙の骨・淡い石・紺の布・金の縁
  • 光は核と、刃の中心の細い筋
  • 防具は布が輪郭を作る。頭巾と背に浮く環、長い外套、前垂れ

武器大剣 = 細い長刃と尾びれの鍔・日輪の環・吹き流し／弓 = 先が尾びれに反る長弓／槍 = 柳葉の穂と背の半月の環／杖 = 尾びれが抱く真珠／短剣 = 波刃と環の柄頭

防具頭巾と背の環の兜、金の帯の胴衣、小さな淡い石の肩当てと浮く環、背の長い外套、白い前垂れ、足首に小さな尾びれ

面の数武器 大剣 390 / 弓 276 / 槍 334 / 杖 396 / 短剣 294 ／ 防具 4 部位 1,048（03 の予算: 通常 250・レア 300・レジェンド 350・防具 4 部位 3,000 以下）

良い点: 優美で「特別な品」に見える。止まっていても布と環で動きが見える。レジェンドで環を増やすと階級が輪郭で分かる。軽い巨神（潮殻・雷翼）に向く
気になる点: 面が増える（レジェンドの大剣 632 面、防具 1,048 面）ので予算に収める作業が要る。細い線が多く、32px で潰れやすい。重さが出にくい

動きの性格動き: 流れる弧、袈裟 → 返しの二連、回して突く。布と環がたなびく。ヒットストップは短く、残像が長い

C 遺骸 (Grown Remains)　骨そのものを使う。非対称で、使い込まれている

参考エルデンリング・ブラッドボーン（素材そのものの武器、朽ちた装備）、モンスターハンター（怪物の部位を使う）

  • 輪郭は左右非対称で、欠け・ぎざぎざを 1 点持つ
  • 骨そのものが武器（顎骨の刃・肋の弓・牙の穂・椎骨の杖頭）
  • 縄・包帯・護符・ぼろ布・苔で来歴を語る
  • 光はひびの奥と核だけ（水色）

武器大剣 = 顎骨の欠けた刃（歯のぎざぎざ、折れた先の核）／弓 = 長さの違う肋の弓／槍 = ねじれた牙の穂と返し／杖 = 曲がった骨の杖に椎骨の頭／短剣 = 返しのある反った牙

防具頭骨と顎骨の兜（右に長い角、左は折れ）、肋の外骨格と背の椎骨、左だけ大きな椎骨の肩、包帯の脚と骨の膝、爪先の骨爪

面の数武器 大剣 302 / 弓 268 / 槍 306 / 杖 272 / 短剣 200 ／ 防具 4 部位 1,176（03 の予算: 通常 250・レア 300・レジェンド 350・防具 4 部位 3,000 以下）

良い点: 物語がある。巨神の素材らしさが最も出る。非対称で「手で作った品」に見える。レジェンドは肋の反りと鉤が増える
気になる点: 輪郭が複雑で、遠目では A より読みにくい。ぼろ布・護符は面が増える（防具 1,176 面）。やりすぎると散らかる

動きの性格動き: 引きずって薙ぎ上げ、叩きつけて反動でよろける。逆手で刺して裂く。乱暴で重心が崩れる

私（作った側）の見立て: 武器は A の太い輪郭の上に C の使い込み（巻き・護符・欠け）を足し、B の布と環はレジェンドだけに使う。防具は A の面の大きさを土台に、B の布（外套・前垂れ）を足して重さと動きの両方を出す。巨神ごとに重さを変える（岩鯨・余燼 = A 寄り、潮殻・雷翼 = B 寄り、深淵の専用伝説 = C 寄り）案も成り立つ。決め手は「遠目で読めること」と「面の予算」。

攻撃の動き（武器 5 種 x 3 方向。一人称の絵コンテ）

8 コマで、上段が一人称（透視。腕は箱の模式）、下段が横からの全身（刃先の軌跡 = 残像つき）。コマの下に、動きの名前と tick（1 tick = 1/20 秒 = 50 ms）。ヒットストップ・画面の揺れ・残像・溜めの長さが方向ごとに違います。これはキー姿勢の絵で、ゲームの動き（SwingMove）に落とすときは、コマの間を補間します。弓は引きの 4 段階の絵を使います。

見る所: ① 溜めの長さ（重さ）② 一閃の速さ ③ 命中の止まり（ヒットストップ）④ 残身（流れ）⑤ 武器種ごとの型の違い。一人称の絵は腕が太く見えます（模式）。

大剣　型: 溜めて断つ

A 量塊（断ち下ろし）: 断ち下ろし。頂点で一拍止め、一閃、命中で 3 tick 止まって画面が揺れ、刃が沈む。重さの見せ方が主役
B 祭具（袈裟斬りから返し）: 袈裟斬り → 切り抜け → 返しの逆袈裟。体をひねり、刃が弧を描いて残像が長い
C 遺骸（引きずり薙ぎ上げ）: 低く引きずって沈み、薙ぎ上げ → 頭上を越えて叩きつけ。反動でよろける
大剣の動き

槍　型: 引いて突く

A 量塊（大きく引いて一突き）: 大きく引いて一拍止め、一突き。命中で 2 tick 止まり、引き戻す
B 祭具（回してから二連の突き）: 頭上で回してから突き、返しながら引いて、小さく速い二の突き。吹き流しがなびく
C 遺骸（すくい上げて引っかける）: 低く沈んですくい上げ、返しの牙を引っかけて引き倒す。肩が痙攣する
槍の動き

弓　型: 引き・狙い・放ち

A 量塊（重く引いて、ためて放つ）: 重く構えて引く。満月で腕がわずかに震え、放つと反動で弓が跳ね、弦が震える
B 祭具（流れるように引き、放って弓を返す）: 腕を弧に開いて流れるように引き、放ったあと弓をくるりと返す
C 遺骸（肩をねじって乱暴に引き、放って弾かれる）: 肩をねじって乱暴に引き、放つと体ごと弾かれてよろめく
弓の動き

杖　型: 溜めて放つ

A 量塊（地を突いて核を叩き起こす）: 持ち上げて頂点で核が脈打ち、振り下ろして地を突く。衝撃で画面が揺れ、余波で止まる
B 祭具（円を描いて環を放つ）: 腕を開いて円を描き、前へ放つと環が広がって浮く。柄を返して戻る
C 遺骸（身を縮めて突き出す）: 身を縮めて眼（核）が脈動し、突き出して痙攣、引きずって戻す
杖の動き

短剣　型: 速い連続

A 量塊（重い一突きと横一文字）: 引いて重い一突き、命中で 2 tick 止まり、引き抜いて横一文字
B 祭具（X を描く連斬り）: 右上から斜め斬り、左下から切り返して X を描き、突きで止めてくるりと回す
C 遺骸（逆手で刺して引き裂く）: 逆手で振り上げて刺し、引き裂き、ねじり、もう一度裂いて振り払う
