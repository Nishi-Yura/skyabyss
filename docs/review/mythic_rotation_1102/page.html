神器と技の回し

「神器に特出した能力はある？」「武器の良さは出ている？」「楽しい技の回しはできる？」への見立てと、直す案です。方針の 4 つと、職ごとの神器 3 本・型 3 つを選んでもらえれば、その形で作ります。おすすめはどれも案 1 です。

いまの見立て

  • 神器: 固有効果は一つずつあるが、「数回に一度の追撃」「数秒の上乗せ」で、Lv 30 のヒロイックと同じくらい。1 秒あたりも神器どうしでそろえてあり、持ち替えても遊び方が変わらない。
  • 武器: 1 秒あたりを階級ごとにそろえているので、同じ職の武器の差は速さ・固有効果一つ・ランダムな特性（4〜10%）だけ。品ごとに決まった数値の行が無い。
  • 技: 4 本、待ち 6〜22 秒、マナ 4〜18。主の大技のあとの隙（3 秒、与える傷 ×1.6）・呪いの印・足止め・打ち手の泉・炉の記憶はあるが、技どうしのつながりが少なく「空いた技から押す」形になりやすい。
選んだ数 0 / 0 選ぶと保存されます（この画面を開いた人みなで同じ記録）。

方針

職ごとの案

方針 340 が A のときの神器 18 本の中身と、342 が A のときの型 18 の中身です。神器の数値は今の強さ（1 秒あたり）を基に、欠点のぶん少し強くしてあります。細かい数は作るときに測って直します。
