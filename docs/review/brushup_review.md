# mod 全体のブラッシュアップ・レビュー（2026-10-19）

対象: `m1-sky-pass`（0.2.1。今日入った作業の後）。コードは読んだだけで、ゲームは動かしていない（Java は動かしていない）。`docs/design/00_decisions_needed.md` は触っていない。

- **A** = ユーザーに聞かずに直してよい（文書・lang・テストの直し。ゲームの規則を変えない）
- **B** = ユーザーの判断が要る（選択肢つき）

先に、確かめて問題がなかったもの:

- lang: ja と en のキー数は同じ（3,256 ずつ、片方だけのキーは 0）。Java から文字列で引いているキー 1,001 個のうち、lang に無いものは、末尾に `.1`〜`.4` や ID を足して組み立てる接頭辞だけ（`sign.skyabyss.*`・`trial.skyabyss.ember_` など）で、実際の欠落は無い。`%s` の数も ja と en で合っている（en が `%1$s` の位置指定、ja が `%s` の違いだけで、並びは同じ）。
- 予告（Telegraph）の最短 0.8 秒・色の意味・再入場の 20 秒 / 3 秒 / 回数 3・復活の守り（3 秒・半径 8・30 秒）・備えの三灯のしきい値と目安の体力・旅の待ち（60 秒・延長 +30 秒）・停泊 20 分（`TitanStay.TICKS` = 24000）・クールダウン 3 分 / 30 秒は、設計書とコードの数字が一致している。
