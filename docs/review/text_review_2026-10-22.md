## 1. 決まり（今回そろえたこと）

| 項目 | 決まり |
| --- | --- |
| 心臓 | 巨神の心臓は「止める」。「倒す」「撃破」は使わない（戦いの記録の数え方「撃破」は残す） |
| 欠片と鱗片 | 「欠片」は天の鍵の欠片だけ。岩鯨の背の敵が落とす石は「鱗片」 |
| 背 | 「背」を基本にする。会話の中の「背中」（「背中には町がある」など）は話し言葉なので残す |
| 語り部 | 一人称は「あたし」。語尾は「〜さ」「〜よ」「〜おいき」「〜おおき」 |
| イサナ | 一人称は「俺」、相手は「あんた」（三章の「お前」をそろえた） |
| 施設の係 | 薬師・書庫番・祭司・預かり番・組合の書記は「です・ます」。ほかの係は常体で、決まり文句の「何にするかい」を役ごとに分けた |
| 画面の文 | 常体（「〜する」「〜できる」）。「ください」「です」「ます」は使わない。地の文で「あなた」と呼ばない（会話は別） |
| 数と単位 | 傷（ダメージ）は「傷」、距離は「ブロック」（「マス」は使わない）、要るものは「要る」（「いる」と読み違えない） |
| 品の名前 | バニラの品はバニラの日本語名にそろえる（コンパス・鉄塊・奇妙な薬・耐火・暗視・ネザーウォート） |
| 目的の帯 | メインの目的の文は「〜しよう」で終わる。誰に頼まれ、何のためかが分かる言い方にする（例:「頁のとおり、鉄の防具を作って着よう」「鉄と刃と盾で、鯨を迎える支度をしよう」） |

## 4. 直さなかったもの・気づいた点

- **四章（`skyabyss_ch4`）・背の試練と順路（`skyabyss_trial`・`skyabyss_route_long`）**: 別の作業の途中なので触っていない。試練の文に「ゴール」が多い（97 か所）。「光る印」「終わりの床」などの言い方に寄せるかは、試練の担当と決める。
- **背の中の部屋の説明**（`skyabyss_tide`・`skyabyss_storm`・`skyabyss_ember` の試練の札・ささやき）: 半角の括弧（`(…)`）が多い。読めるので残した。
- **余燼の開発コマンド**（`commands.skyabyss.ember.*`）が「です・ます」。開発用なので残した。
- **巨神の子の呼び名**は巨神ごとに違う（岩鯨の仔・潮殻の稚貝・雷翼の雛・余燼の仔）。設計どおりなので残した。
- **呼び笛の断り文**（`message.skyabyss.travel.refuse.*`「水の中では、笛を吹けない」など）が、笛の説明（「いつ吹いても子が来る」）と食い違う。今は使われていないはずの文。消すかどうかは笛の担当と確かめる。
- **鎖の一言**（`message.skyabyss.travel.chain_hint`「岩鯨の頭の乗り場へ」）は旧い乗り方の文。今の旅で出るか確かめる。
