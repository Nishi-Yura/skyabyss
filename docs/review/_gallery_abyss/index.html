五章「深淵」の敵のラフです (設計書 36 の 4、A3)。層ごとに 3 種ずつ: 骨 (骨拾い・肋の番・骨笛)、塩 (塩の抜け殻・潮だまりの手・白い貝守)、雷 (帯電の羽虫・避雷の像・焦げた鳥の影)。各案は基本の姿で、色の言葉は層ごと (骨は骨・方解石・灰、塩は白・塩の皮・海の緑、雷は凝灰岩・酸化した銅・白い雷)。「歪み」「崩れ」 (深いほど不気味な変わり果てた姿) は、各案の説明の末尾に一行ずつ書いてあります (今は決めるのは基本の案だけ)。メッシュは閉じた面 (開いた辺・向きの食い違い 0) で、光る材質は雷・鼓動の目印の所だけ。ラフなので登録・動きの実装はまだです。
