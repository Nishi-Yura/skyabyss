# 言伝ての板 (message_board) ラフ 3 案

村の掲示板。村人が日々の頼みを書いた紙片を留める。自由モードの日替わりサイドクエストの受け付けに使う。
ブロックの高さは 1 段 (y 0..16)、正面は北 (-Z) を向いた状態で描く。

比較画像: `compare.png` (上段は正面から斜め、下段はアイコンの見え方)。
各案のモデルとテクスチャ: `option_A/`、`option_B/`、`option_C/`。
生成元: `tools/gen_message_board.py`。

## 案

- **A 二本柱と小さな庇**: 二本の柱の上に板を掛け、板の上に二段の庇をのせる。紙は三枚。鯨骨の留め釘が一本。
- **B 横長の板 (庇なし)**: 横長の一枚板を二本柱で後ろから支える。紙は四枚で、麻紐を板に結んである。
- **C 中央の一本柱と釘掛け**: 中央の一本柱に板をのせ、上に釘掛けの横木を渡す。鯨骨の釘が二本、右端に小さな鉤。

## 推奨

**A を採用する。** 理由は次のとおり。

- 庇があるので、村の掲示板として一目で読める。板と柱と屋根の三つで「物」に見える。
- B は細い塀に見え、C は道標に近い。A は村の掲示板の形に最も近いと判断した (実物の鐘との並びは未確認)。
- 紙は板の前に 0.5 単位浮かせてあり、庇の影で立体感が出る。鯨骨の釘は一本だけなので、主張が弱い。
- 立体はすべて z 5..11、x 0..16、y 0..14 に収まる。重なる箱はない。

## 採用版 (A) の外形 (北向き)

- x 0..16、y 0..14、z 5..11 (単位)。VoxelShape の目安にする。
- 板と柱と庇の境は接しているだけで、重ならない。

## 注意

- 紙と釘と麻紐は、面の模様だけでなく箱として作ってある。遠くからは紙の立体感が弱く見えるかもしれない。
- 鯨骨の釘は、よく見ないと普通の白い棒に見える。ヒントとしては十分と考える。
- 形は確認用の描画だけで見ている。実際の描画、当たり判定、置いたときの向きは、ゲーム内で確かめる必要がある。
