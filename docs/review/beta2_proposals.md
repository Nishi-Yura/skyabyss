## 1. 序盤と巨神の間の「間」

### 1.1 何が退屈を作っているか（コードと 17 から）

- 序盤は**時間待ちで組まれている**。岩鯨は 3 日目の夕方（開始から実時間 約 48 分以降、`TitanEvents.whaleMayAppear`）。その前は一本道の拍子（17 の 2.1）で、拍子の間は「静かな歩く時間」と書いてある。
- 構造物は 4 つだけで、野営地から 140〜380 ブロック離れる（17 の 3.3〜3.5）。**スポーン次第で、最初の 10 分は景色しかない**。
- 17 の 3.6 が、序盤の敵・ダンジョン・サブクエストを意図して閉じている（板の頼みはイサナと話す日 2 まで閉じる。17 の 6.6）。1 時間で Lv 4 手前（17 の 7.1）。
- 巨神の間も同じ形。次の巨神は「出現の条件を満たしたら現れる」だけで、探す途中を埋めるものがない（10 の 3.2）。

### 1.2 小さな要素 12 案

どれも「人が去った跡」「ほのめかし」に寄せ、敵とジャンプスケアは増やさない。生成は新ワールドの起動時の場所探し（`SiteFinder` / `SiteJob` / `Blueprint`）を使い、野営地〜宿り〜骨の丘の経路に沿って置く。そのうえ**どのスポーン地点でも野営地から 150 ブロック以内に 3 つ以上**になるよう、扇形（3 方向）に分けて探す。プレイヤーが拠点から 300 ブロック以上離れた場合は、進行方向 60〜120 ブロック先へ 1 つ足す（高さと群系だけで決めるので、チャンクは作らない）。

### 2.2 推奨: (c)

- 伝承は `chapter1`〜`chapter3`・`finale` に分かれ、`chapter1/` を使う箇所が 86 ファイル・55 項目ある。**章番号の付け替えは安い作業に見えて高い**。幕なら付け替えない。

- 用語: 設計書は「1 章 第一幕（岩鯨）〜第四幕（余燼）」と書く。「章」の意味は変えない。

## 3. 死亡の扱い

### 3.1 今の仕様（コードと設計書）

- 地上: バニラのまま全部散らばる。大事な品（欠片・心核・呼び笛）は消えず、`DropLedger` に座標を控え、奈落から戻る（11 の 4.1。00 の 88 は未決）。
- 背中: 持ち物と経験値を預かり、休み場で復活（T5。`TitanBackTrials.keepBelongings`、`onClone`）。
- 装飾の枠は `keepInventory` と背中で残る（`Accessories`）。
- 成長の経験値・技は死んでも減らない。

### 3.2 案

### 3.3 推奨

- **(C) を既定にし、(D) のゲームルールで包む**。00 の 88 は「三つとも残す（欠片・心核・呼び笛。加えて天の鍵）」と答える。T5（背中は全部預かる）はそのまま。
- 先行パッチ（S）: ドロップのイベントで、装備・ホットバー・装飾・大事な品を残す。残りの扱いは今のまま（墓は後）。これだけで「全ロスで萎える」の大半は消える。
- 墓の決め（M）: 置き場は死んだ場所の最寄りの安全な地面。溶岩・奈落・水の中は一番近い陸へ。消えない・燃えない・爆発で壊れない（`Keepsakes` の守りを流用）。ほかの人は開けられない（パーティは 2 分後）。呼び戻しの費用は経験値レベル 3 か素材 1（`00` に追加する）。
- バニラ経験値: 墓に「経験値 50%」として預ける。成長の経験値は触らない。
- ホラーの原則との整合: 死は演出で起こさない（01）。墓は恐怖ではなく「取り戻す」手触りにする。
- 注意: `keepInventory` ルールが真のときは何もしない。クリエイティブ・観戦者は対象外。
