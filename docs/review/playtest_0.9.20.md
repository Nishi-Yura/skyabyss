# 試遊 0.9.20 の確かめ順

0.9.19 からの直し: はじまりの島を要素の紹介だけに、蜂の巣の音、係の人の見直し（書庫番・地図屋を消した、店の品ぞろえ）、振り分けの文の残り、ヒロイックの防具、封切り師の町ごとの挨拶。野の装備と封の箱の確かめは `playtest_0.9.19.md`、ほかは `playtest_0.9.4.md`（六章 `playtest_0.9.1.md`、終章 `playtest_finale.md`）のまま。

## 0. 始め方

- jar は `build/libs/skyabyss-0.9.20.jar`（サーバーと全員のクライアントに同じもの）。**新しい世界**で始める（島の地形を作り直したので、前の世界では消した寄り道の建物が残る）。

## 1. はじまりの島

- 目的の順が 職 → 帳面 → 足跡 → 峠の野盗 → 休み場 → 祠 → 渡し守 だけになっているか。見張り塔の跡・大樹・洞窟・漁師小屋・旅人の野営の目的と建物が無いか。
- 島の道が途切れたり、行き止まりの脇道が残ったりしていないか。地図に消した所の印が出ないか。
- 一つひとつの場所が、ゲームの要素を一つ教えているか（教えていない所があれば挙げてほしい）。

## 2. 音

- 木のそばで蜂の巣の音がしないか（大陸のどこでも）。

## 3. 町の人と店

- 都・四つの町に書庫番と地図屋がいないか（空見の館の書庫と地図屋の屋根裏は人のいない部屋）。
- M の地図に、祠と開いた章の跡地が最初から載っているか。
- 都の案内人に「まだ行っていない所の噂」「地図に描き足してもらう（鐘銭 5）」があり、働くか。
- 町の案内人の一覧に「封切り師」があり、鍛冶場まで灯りで案内するか。
- 封切り師の挨拶が都と町で違うか（都 = 封蝋の匂い、鯨見 = 鯨骨の留め、汐守 = 湿った封、風待 = 風で鳴る封、灰炉 = 燠で焼き切る）。
- 道具屋に松明・ランタン・寝台・蝋燭が無いこと、鍛冶場の誂えに炉・道標・言伝ての板が無いこと。穴の粉は素材屋で、砥石は鍛冶場で買えるか。
- 止まり木の番の会話に「地図を見る」が無いこと。

## 4. 成長の知らせ

- レベルが上がったとき「技の点が n 増えた」と出るか（「振り分けられる力」が出ないか）。J の記録に振り分けの行が無いか。

## 5. ヒロイックの防具

- 焼け砦の重鎧・縄の人の吊り衣・星詠みの法衣・雲上の騎士鎧を着て、外套・光る継ぎ目・頭の上の飾りが見えるか。歩くと外套が体にめり込まないか。
