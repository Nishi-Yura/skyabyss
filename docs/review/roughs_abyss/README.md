# 深淵 層の主・歪んだ王・生き残り ラフ (各 3 案)

シートは前 / 3/4 / 横 (動きのある主は構えの行も) を一枚に並べ、上に案の名前と一行の案を書いた。メッシュ・アトラスは `<名前>/{a,b,c}/`。
生成: `tools/rough/lowpoly/abyss/` (`ab_common.py` `hum.py` 共通、`lord_*.py` `king_*.py` `npc_survivors.py`)。実行は `python -I tools/rough/lowpoly/abyss/<名前>.py`。
深い層の王の下の二行 (周が進んだ姿) は、高く伸ばし・傾け・うねらせた見本で、本番の崩れの絵ではない。
