# 遊びのレビュー（2026-10-23 夜明け前の m1-sky-pass）

- 誰のため: 朝に読むデザイナー（試遊者）向け。今の作りを、プレイヤーの順に読んで評価した。
- 読んだもの: `docs/design`（README・00・32 の 7〜9・34・36 の 8〜9・38）、`docs/HANDOFF.md` の 10〜11、`data/skyabyss/quest/**`（メイン 6 本と章ごとの支度・町・依頼）、ja の lang（全体を引いて調べ、会話は抜き出して読んだ）、`trial/raid/**` の各部屋の頭のコメント、クエストの進め方（`quest/Quests.java`）、順路（`trial/TrialRoute.java`）、レベルの上限・転生・鐘銭の数字。
- 限界: ゲームは動かしていない。データとコードから読める範囲の評価で、「要確認」は実機で確かめてほしい所。
- 重さ: **高** = 進めなくなる・遊びの芯が欠ける／**中** = 目に見えて楽しさを削る／**低** = 磨けばよい所。

---

## 0. ひと目で（全体の所感）

- この夜の作り直しで、試遊の不満のうち「背は階段を歩いて印を追うだけ」「深淵が退屈」には、遊びの形がちゃんと入った。レイドの部屋は「運ぶ／解く／守る」がはっきりしていて、帯に今やることと数が出る。深淵の層には、野営・三本の道・印・門・層の主・生き残りの話の筋がある。
- 一方で、**作り直しのせいで、古い作りに頼っていた所が切れた**。背の中の碑文（物語の担い手）、試練の経験値と依頼の合図、メインのクエストの段の三つ。とくに一章のメインは、進めなくなるおそれが高い（P1-1）。
- 「なぜやるのか」は、地上（語り部・イサナ・支度の段）ではよく伝わる。ところが**背のレイドの部屋と深みには物語がない**。部屋は 25×30 ほどの閉じた箱で、巨神の体の中にいる感じがしない。ここは前の試遊の「mod らしさがない」「ボスの意味がわからない」がまた出そうな所。
- クリア後は、**レベルの上限が 40 で止まるため、Lv 50 からの転生に届かない**（P7-1）。

## 11. ユーザーにしか決められないこと

- **Q1** レイドの部屋は「巨神の体の外の箱」のままでよいか。体の中（古い試練の翼の場所）に建て直す、または飾りだけ足す（P1-4）、のどちらか。
- **Q2** 古い試練の翼の碑文（背中の民の話）は、レイドの部屋の入口へ移すか（推奨）、背の到着の台から部屋までの道に並べ直すか。
- **Q3** 五章の支度（ネザライトのインゴット）は鍵のままか、34 の 7 の「勧め」にそろえるか（P5-1）。
- **Q4** クリア後のレベルの上限: 番人を倒したら 50（推奨）か、深みの節目ごとに少しずつ上げるか（P7-1）。
- **Q5** 四つの層の骨組みを二種に分けてよいか（逃げ道・護衛の層を入れる。P5-2）。
- **Q6** 初回の乗り込みの時刻の決まり（雷翼の午後・余燼の夜）を残すか、待てば来るようにするか（P3-1）。
- **Q7** 乗り物の値段を下げるか、鐘銭の入りを増やすか（P7-4）。乗り物の笛の名前（乗り笛・厩舎の笛・ほか）。
- **Q8** 世界の中では「組合」、画面の見出しでは「ギルド」という分け方でよいか（P5-7）。
- **Q9** 帯の文の言い方は「〜しよう」に統一してよいか。戦いの最中の警告だけ命令形にする案（P0-4）。
