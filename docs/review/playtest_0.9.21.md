# 試遊 0.9.21 の確かめ順

0.9.20 からの変わり: あいだの塔（超大型レイド）、神器の二本目・防具・装飾と雲の箱、秘伝と技の変化の見え方、裏ボス「初代の空見」、エンドコンテンツの仕組み（巡り路・大陸の大事件・名声と旅帳・職の熟練・組合の旗取りと塔の順位・図鑑の報い・武器の見た目替え・旅の記録の画面）。前の版の確かめ（島・町の人・店、野の装備と封の箱、0.8.1 の巨神の居場所・戦い・心臓の間）は、末尾の「13. 前の版から持ち越す確かめ」に移した。ほかは `playtest_0.9.4.md`（六章 `playtest_0.9.1.md`、終章 `playtest_finale.md`）のまま。

## 0. 始め方

- jar は `build/libs/skyabyss-0.9.21.jar`（サーバーと全員のクライアントに同じもの）。0.9.20 の世界のままでよい。
- 終盤の確かめは手早く進めるために、管理者の命令を使ってよい: `/skyabyss admin level 50`、`/skyabyss admin chapter 5`（一覧は `/skyabyss admin help`）。巡り路・大事件・名声を早める命令（`/skyabyss circuit start 2`・`/skyabyss event start 2`・`/skyabyss fame add whale 100`）は開発環境だけ。

## 1. あいだの塔（結末のあと。都の受付）

- 終章まで進んでいない世界で試すときは、管理者が `/skyabyss admin tower ending calm @a` で結末を選んだことにすると、受付が見えて入れる。何度も試すなら `/skyabyss admin tower day @a`（今日の一回を戻す）か `/skyabyss admin tower start @a`（一日一回を数えずに入る）。落ちる月は `/skyabyss admin tower hp 51` のあと少し削ると早く見られる。
- 受付の塔守に話すと、隊（1〜12 人）・週の賭け・記録の板・塔の店が選べるか。入場は一人一日一回か。
- 橋の上の主「あいだに座すもの」: 右手の払い・合掌・落ちる月・横の目・縛り手が読めるか（予兆が見えて避けられるか）。強すぎ・弱すぎはどの段か。
- 越えたとき: 塔の欠片・鐘銭・まれに塔の箱・秘伝の巻。塔の装備（武器 6・防具 3 式・装飾 2）の形と持ち方。
- 週の賭けを付けると欠片が増えるか。記録の板に人数ごとの最速と組合の回数が出るか。

## 2. 神器と雲の箱

- 巡礼者を初めて倒すと雲の箱が一つ出るか（神器そのものではなく）。雲の箱から二本目の神器・神器の防具 3 式・装飾 2 が出るか。
- 神器のレア度の色（神器 = 桃紫）と、塔の装備も神器になっていること。
- ハンマーの打つ面が前を向いているか（前後が逆でないか）。

## 3. 秘伝と技の変化の見え方

- 秘伝の巻を読むと、今の職の秘伝を一つ覚えるか（III まで）。師範の「秘伝の枠を見る」と技の画面の下の段の枠から一覧が開き、付け外しできるか（チャットの窓が開いて全部見えるか）。
- 刻印・逸品の書き換え・変異・秘伝が付いている技に、技の帯と技の画面の枠で色の菱形が付くか。技の説明の一番上に「いまの変化:」が出るか。書き換えの武器を持っていないとき灰色で「その武器を利き手に持つと効く」と出るか。
- 秘伝の効き（例: 二の太刀で巨神斬りがもう一太刀）を、手ごたえとして感じられるか。

## 4. 裏ボス「初代の空見」（鐘の中）

- 入り方が分かるか、戦いの手ごたえ、勝ったあとの記録と肩掛け。

## 5. 巡り路（土地の町の案内人）

- 鯨見・汐守・風待・灰炉の案内人に「巡り路を歩く」があり、話の中で中身が分かるか。「歩き出す」で始まり、今日の報いの残りが出るか。
- 左上の帯に「巡り路 19:33・印 1：〜」と距離・方角、行き先に金色の光の柱が出るか。
- 倒す（着くと敵が湧く）・守る（柱のそばにいるあいだ進む）・運ぶ（荷を背負って届ける、半ばで待ち伏せ）が分かりやすく、20 分が長すぎ・短すぎないか。
- 課題のあとに柱が二本立ち（白・金・青）、近づいた方が次の課題になるか。金（印が二つ・手ごわい）と青（残り時間 +2 分）を選ぶ楽しさがあるか。
- 終わると印 × 鐘銭と封の箱（印 6 以上で巨神の箱）。一日 3 回を超えると報いが出ないか。組で歩くと全員に報いがあるか。

## 6. 大陸の大事件

- 二章からの人に「大陸の大事件: 〜に大いなる〜が来た」と出て、赤い光の柱と地図の印で場所が分かるか（`/skyabyss event start` で早められる）。
- 近づくと現れる大いなるもの: 大きさ・体力の帯・30 秒ごとの手下。何人で何分くらいか。与えた分が少ない人には報いがないこと。
- Lv 50 で鯨見の大事件に行っても、すぐ倒れずに手応えがあるか（来た人のいちばん高い Lv に合わせて強くなる）。
- 15 分で去るか。

## 7. 名声・旅帳・旅の記録の画面

- 記録・技の上に「旅」のつまみ（Lv 10 から）。土地ごとの名声の段とバー・名所の数・今週の旗、図鑑、熟練が一枚で分かるか。行に乗せると点・週の点・値引きが出るか。
- 名声が上がると知らせと贈り物（鐘銭と封の箱）。その土地の町の店の値段が下がるか（3 段で 10%）。
- 土地の名所をすべて見つけると旅帳の褒美と称号。

## 8. 職の熟練

- Lv 50 で、左上が「Lv 50・熟練 n」になり、バーが熟練の進みになるか。
- 技を使うと足もとに職の色の光（段 4 から輪、7 から昇る光、10 は頭上の冠）。うるさすぎないか。

## 9. 組合の旗取りと塔の順位・図鑑・見た目替え

- 組合の人が土地の点を稼ぐと、週が替わったときに一番の組合がその土地の旗を持つか（旅の記録に旗の印、店で 10% 引き、組合の倉庫に品）。塔の上位 3 組合に欠片。
- 巨神の装備の表をそろえると鐘銭と称号。敵の図鑑（`/skyabyss_codex`）。
- 鍛冶屋の「武器の見た目を替える」: 図鑑の同じ種類の武器の形になり、強さはそのままか。説明に「見た目: 〜」。元に戻せるか。

## 10. 称号

- 称号が 48 個。名声・旅帳・熟練・図鑑の称号が解けるか（`/skyabyss fame add` などで早められる）。

## 11. プロフィールと名札の称号・ギルドの旗の模様

- 持ち物の画面の右上に「プロフィール」の札（付けている称号が出る）。押すと画面が開き、E で持ち物へ戻るか。
- わたし・称号・見え方の三つのつまみ。称号を選ぶと、札と画面の左の名前の上（か下）にすぐ出るか。
- 名札の称号が名前の上に出るか（ほかの人から見て。二人で）。転生していない人の称号も出るか。
- ギルドの旗の模様が 67 種（はじめから 57・功績で 10）。この世界の紋 12（岩鯨・鐘・巨神の目など）が旗の見本・受け取った旗・名札まわりで正しく出るか。気に入らない形がないか。
- 町の旗: 旗を取った週は、その土地の町の四つの門の旗がギルドの旗になり、広場の依頼の板のそばに旗が二本立つか（`/skyabyss townflag set whale` で早められる）。週が替わる・旗を外すと町の色に戻るか。
- 巡り路の「壊す」: 柱の課題に「壊す」が出るか。淵の杭が立ち、打つと割れ目が広がり、7 秒ごとの脈（地面の輪の予告）を避けられるか。壊すと越えるか。杭の硬さ。

## 12. 釣り

- 道具屋で釣り竿（120 鐘銭）を買い、水辺で投げて浮きが沈んだら引く。釣れるのがその土地の魚だけか（バニラの魚・がらくた・宝が出ないか）。投げているあいだ竿の絵が替わるか。
- 釣れた魚の説明に大きさ・土地・まれさ。初めての魚・一番大きい一匹の知らせ。食べ物屋で買い取り、「釣り大会の番付を見る」で今週の上位が出るか（`/skyabyss fishing catch` で早められる）。
- 釣れる割合（ふつう・ときどき・まれ・ごくまれ 1％）と、釣れるまでの時間は気持ちよいか。

### 13.1 0.9.20 から（島・町の人・店・成長・ヒロイックの防具）

0.9.19 からの直し: はじまりの島を要素の紹介だけに、蜂の巣の音、係の人の見直し（書庫番・地図屋を消した、店の品ぞろえ）、振り分けの文の残り、ヒロイックの防具、封切り師の町ごとの挨拶。

- 始め方: 島の地形を作り直したので、**新しい世界**で始める（前の世界では消した寄り道の建物が残る）。
- はじまりの島: 目的の順が 職 → 帳面 → 足跡 → 峠の野盗 → 休み場 → 祠 → 渡し守 だけになっているか。見張り塔の跡・大樹・洞窟・漁師小屋・旅人の野営の目的と建物が無いか。
- 島の道が途切れたり、行き止まりの脇道が残ったりしていないか。地図に消した所の印が出ないか。
- 一つひとつの場所が、ゲームの要素を一つ教えているか（教えていない所があれば挙げてほしい）。
- 音: 木のそばで蜂の巣の音がしないか（大陸のどこでも）。
- 町の人と店: 都・四つの町に書庫番と地図屋がいないか（空見の館の書庫と地図屋の屋根裏は人のいない部屋）。M の地図に、祠と開いた章の跡地が最初から載っているか。
- 都の案内人に「まだ行っていない所の噂」「地図に描き足してもらう（鐘銭 5）」があり、働くか。
- 町の案内人の一覧に「封切り師」があり、鍛冶場まで灯りで案内するか。
- 封切り師の挨拶が都と町で違うか（都 = 封蝋の匂い、鯨見 = 鯨骨の留め、汐守 = 湿った封、風待 = 風で鳴る封、灰炉 = 燠で焼き切る）。
- 道具屋に松明・ランタン・寝台・蝋燭が無いこと、鍛冶場の誂えに炉・道標・言伝ての板が無いこと。穴の粉は素材屋で、砥石は鍛冶場で買えるか。
- 止まり木の番の会話に「地図を見る」が無いこと。
- 成長の知らせ: レベルが上がったとき「技の点が n 増えた」と出るか（「振り分けられる力」が出ないか）。J の記録に振り分けの行が無いか。
- ヒロイックの防具: 焼け砦の重鎧・縄の人の吊り衣・星詠みの法衣・雲上の騎士鎧を着て、外套・光る継ぎ目・頭の上の飾りが見えるか。歩くと外套が体にめり込まないか。

### 13.2 0.9.19 から（箱が落ちる・封切り師・旅嚢・野の装備）

0.9.18 からの足し: 野の装備（武器 102 本・防具 18 式・装飾 26 品。設計 51）と、装備が封の箱で落ちる仕組み（封切り師とルーレット。設計 52）。
- 始め方: 新しい世界で始める。前の世界でも遊べる（持っている装備はそのまま。箱は新しく落ちる分から）。

- 箱が落ちる: 土地の敵をしばらく倒すと、まれに「〇〇の封の箱 [Lv …]」が手に入るか（品の名前は出ない）。箱は旅嚢に入るか。
- 名のある強敵・層の主を初めて倒すと、箱が必ず一つ出るか。
- 巨神の背の敵・中ボス・心臓から、その巨神の印の箱が出るか（岩鯨・潮殻・雷翼・余燼で見た目が違う）。
- 同じ箱が重なるか。階級の箱は帯（Lv の幅）ごとに別になっているか。
- 二人で倒したとき、それぞれが自分の箱を受け取るか（相手の当たりで自分の分が減らない）。
- 封切り師で開ける: 都と四つの町（鯨見・汐守・風待・灰炉）の鍛冶屋の中、鍛冶師の隣に封切り師がいるか。頭の上の印（箱の絵）。
- 話す → 「箱を開けてもらう」で画面が開くか。持っている箱が並び、選ぶと右に名前と中身。
- 「開ける」: 帯が回ってゆっくり止まり、当たりのカード（名前・階級・特性・必要 Lv）が出るか。刻みの音と、止まったときの音。
- 「まとめて開ける」: 一つずつ速く回り、最後に一覧。Enter（か Esc）で飛ばせるか。
- 開けた品が手もと（持ち物）に入っているか。途中で閉じても品があるか。長さはちょうどよいか（一つ約 4 秒）。まとめての速さは。
- 封切り師から離れると開けられないか。
- 旅嚢の「封の箱」: E の画面の上のつまみが「持ち物 / 装飾 / 旅嚢 / 封の箱」の四つになり、四つ目で持っている箱が見えるか（巨神の箱・階級 × 帯の表・金の箱）。
- 旅嚢から箱を出せないこと（開けるのは封切り師）。倒れても旅嚢の箱が残るか。
- 野の装備: 開けた武器・防具・装飾が今の職と Lv に合っているか（武器は 2/3 で今の職）。能力（ツールチップの「〜のとき」）が効いている手ざわりか。強すぎ・弱すぎの品。
- 鍛冶屋でアンコモンが買えるか（帯 I は一章、帯 II は二章から）。装飾を装飾の枠に付けると体に見えるか、護符が H で使えるか。
- 箱にならないもの: 共鳴の炉の交換、心臓の初回の選択、深淵の層の主・月の区画の主の初回の部位は、今までどおりそのまま手に入るか。

### 13.3 0.8.1 から（巨神の居場所・戦い・画面・ヒロイック武器・心臓の間）

0.8.0 の試遊の声への直し（巨神の居場所の固定、戦いの手ごたえ、心臓の報酬の選ぶ画面をなくす、月の旅の地図、巨神のヒロイック武器 17 本、心臓の間の大広間、試練の難しさをそろえた）。

- 始め方: 新しい世界で始める（巨神の居場所の地形は、新しく作る地面にだけ入る）。
- 巨神の居場所と祠: 岩鯨（鯨見の跡地の北の空）・潮殻（汐守の跡地の東の沖。潮門は浜の側）・雷翼（風待の跡地の北東の尾根）・余燼（灰炉の跡地の北東の台地に伏せて、口を跡地へ向ける）。体が地面や木にめり込んでいないか。まわりの地面の下がり方が不自然でないか。
- 前の巨神の心臓を誰かが止めると、次の巨神が居場所に出る（日数や時刻は待たない）。
- 祠: 心臓を止めると、土地の町から跡地へ向かう道を町から 90 ほど出た道ばたに建つ。台座の広場が平らで、道から見えるか。
- `/skyabyss admin raid tide 1` などで、巨神の居場所のそばへ運ばれてから背の試練の部屋へ着くか。
- 戦い: 心臓の主・中ボス・名のある敵はふだん殴ると鈍い音で傷が少ない。技（床の予告）が終わった直後に白い火花と澄んだ音が出て、その 3 秒は大きく削れるか。領域を解いた直後に大きく削れるか。
- 主と名のある敵が殴っても後ろへ下がらないか。ふつうの敵を連打すると身構える（盾の音）か。
- 主との戦いの最中に食べ物を続けて食べようとすると「息が整うまで、口にできない」が出るか。戦いの外では今までどおりか。
- 心臓の戦いで全員倒れると、物語の一度目は地上の巨神の前、祠から挑んだ周回は祠の前で目覚めるか。
- 画面: 武器を持ち替えても右下のスキルの帯が消えないか（武器でない物を持つ間は前の職の帯が薄く出る）。左上の章の表示が今の章になっているか。緑の経験値バーが出ないか。月で M を開くと月の絵（着く所・クレーター・新月の谷）になるか。心臓を初めて止めても、遺物を選ぶ画面が出ないか。
- ヒロイック武器: クリエイティブの欄に 17 本があり、手に持つと形が出るか（一人称・三人称・弓の引き）。名前が橙（ヒロイック）か。技の画面で、その武器を持つと書き換え（刻印の 4 番目）が選べて効くか（例: 鯨唄の鎚 → 焼き入れが「鯨唄の鍛え」）。試すときは `/give @s skyabyss:whale_choir_hammer` など。
- 心臓の間と試練: 潮殻・雷翼・余燼の心臓の間が大広間になっているか（`/skyabyss admin boss tide|storm|ember`）。欄干を越えて谷へ落ちられないか。前室から入れるか。試練の部屋で、帯に残り時間が出るか。謎解きの部屋で邪魔の敵が出るか。全滅を重ねると敵が弱くなるか。どの部屋がまだ簡単すぎるか・難しすぎるかを、部屋の名前で教えてほしい。

## 14. 正式版の前の直し（0.9.22。2026-11-02）

- jar は `build/libs/skyabyss-0.9.22.jar`（サーバーと全員のクライアントに同じもの）。0.9.21 の世界のままでよい。
- 版の引き継ぎ: 0.9.21 で遊んだ世界を 0.9.22 の jar で開き、`/skyabyss admin version` で世界と自分のデータの版が 1 になっているか。町・係の人・クエストの進みが残っているか。
- コマンド: OP でない人が `/skyabyss help` で一覧を見られ、`/skyabyss admin …` は使えないか。OP は `/skyabyss admin help` が出るか。`/skyabyss play …` は製品版では出ない。
- 場面の飛ばし: 巨神が眠る場面などの場面は Enter 長押しで飛ばせるか（Space では飛ばない）。絵芝居は Enter で飛ばし、クリックか Space で進むか。封の箱のルーレットと天の鍵の場面も Enter で飛ばせるか。
- 置く品: 松明・額縁などが宝箱・跡地の宝・報酬から出ないか。前から持っていた松明が持ち物から消えるか。頼みで集める品（ランタン・蝋燭・避雷針など）と採集で売る品（丸太・丸石・砂など）は今までどおり手に入るか。花やきのこは採れない。
- 落とし物: 地面に品が落ちていないか（葉の枯れ・置き物が外れたときも落ちない）。
- 破れた頁と伝承の書: 落ちてきたあと歩き回っても、自分のほうへ寄ってきて拾えるか。壁の向こうに落ちても数秒で足もとへ来るか。
- 島: 峠に柵が立っていないか（前の版の世界でも、峠に近づくと消える）。休み場と祠に着いたときに目的が進むか。
- 都: 案内人の一覧に空見の館が無いか。厩舎の建物の上に名札が出ないか（碑は「乗り物は止まり木の旅の番」）。鍛冶師の会話に「手に持った品を直す」が無いか。係の人がそれぞれの店の中（受付の向こう）に立っているか。前の版の世界でも、市の四人（道具・食べ物・武具・素材）がそろっているか。
- 町のクエストの「〜へ行こう」: 印の前に着くと済むか（前の版の世界で、町のクエストの家 10・11 の頼みが進むか）。
- 道: 新しく建つ見どころ・章の跡地・道しるべが道の上にかかっていないか（前の版の世界ですでに建った物はそのまま）。
