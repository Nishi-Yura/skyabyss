# 試遊 0.9.4 の確かめ順

0.9.2 の二人での試遊の声への直し。六章（月）の確かめは `playtest_0.9.1.md` のまま。

## 0. 始め方

- jar は `build/libs/skyabyss-0.9.4.jar`（サーバーと全員のクライアントに同じもの）。
- 導入と大樹の直しは、**新しい世界**で始めると確か。前の世界では、建ってある大樹はそのまま。島のまわりに置かれてしまった一章の場所（旅の職人の荷車など）は、大陸で置き直される。

## 1. はじまりの島（二人で同時に始める）

- 開幕の絵芝居 → カメラの場面 → そのあとで職選びの画面が開くか（途中で飛ばされないか）。二人とも。
- 島の道の間、左上の章が「序章」のままか（一章にならないか）。
- 島で敵が時間で湧かないか（目的の場所で出る決まった敵だけ）。
- 島の道の間、空に岩鯨が見えないか。都の門の前で初めて渡るか。
- 南東の大樹: 大きくなったか、幹を巻く階段で樹上の床と小屋へ上がれるか。
- 野営地の箱・休み場の樽: 二人とも右クリックで中身を受け取れるか。同じ箱をすぐもう一度触ると「あと n 分ほどで…」と出るか。

## 2. 大陸

- 一章の「旅の職人に、刃のことを聞こう」の行き先が大陸にあるか（島を指さないか）。
- 土地の町（鯨見など）の広場の「町の案内人」: 話すと店の一覧が開き、灯りで係の人まで連れていくか。
- 割れ殻の洞: 棘の間の鳴り石が光って見えるか、格子や鳴り石に近づくと手がかりが出るか。
- 骨玉運び（WR1）: 敵の数がちょうどよいか。
- 弓でボスを遠くから射ると傷が減るか（近ければ今までどおり）。
- ボスで倒れたとき、近い休み場で目覚めるか（宿の寝台が遠ければ使わない）。
- BGM が途切れたままにならないか（倒れたあと・背や月から戻ったあとも）。

## 3. 持ち方（0.9.4）

- 一人称の宿り木の短剣と採取の斧: 刃が前（画面の真ん中の側）を向いているか。ほかの短剣で逆に見えるものがあれば名前を。
