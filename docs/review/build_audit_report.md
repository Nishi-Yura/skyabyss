# 建築の監査の報告（拡張版）

自己テスト `build audit`（`titan/audit/BuildAudit*`）が、建てた構造物ぜんぶに同じ検査を流した結果。シード 4242・新しい世界。
各担当は、自分の背の項目を直して、`BuildAuditSelfTest.BUDGETS` の数を下げる（0 になったら行を消す）。

## 検査の種類（BuildAudit に足したもの）

| 種類 | 見るもの |
|---|---|
| STAIR_* / DOOR_* / LADDER_* | これまでの階段の向き・段差・埋まり・戸・はしご |
| FLOAT_BLOCK | まわり 26 マスに固いブロックが無い、浮いた 1 個（木・葉・崩れる骨は除く） |
| ATTACH_SUPPORT | 松明・ランタン・鎖・看板・旗・ボタン・レバー・カーペット・感圧板・レール・つた・花・背の高い草が、支え無しにある |
| ATTACH_FACING | 壁の松明・看板・ボタンの表が壁、箱・かまどの前が壁、箱の上が固い |
| GATE_ALONE / GATE_BLOCKED | 柵の戸の隣に柵が無い、戸の前後が壁 |
| STACKED_FLAT | カーペット・感圧板・レールの重なり（面が重なって z ファイティング） |
| HEAD_DENT | 幅 1 の廊下の真ん中だけ頭の高さにブロック（天井の出っぱり） |
| STAIR_HEAD | 通り道の階段の頭の上が塞がっている |
| FLOOR_DIMPLE | 四方が 1 高い床の中で 1 マスだけ 1 低い（1 つ低く埋まったブロック） |
| FLUID_LEAK | 水・溶岩の源の横・下が空気 |
| SIGN_OVERFLOW | 看板の行が 90 px 超（ja・en 両方） |
| LIGHT_DARK | 歩ける所（BackReach の到達点）で光度 0〜2 のかたまり（4x4x4 ごとに 1 件） |

穴・一方通行・目標に着くか・はしごの登れ方は、これまでどおり各背の `BackReach`（`*BackAudit`）が見る。

開発コマンド（開発環境のみ）: `/skyabyss dev buildaudit here [半径]`・`/skyabyss dev buildaudit <whale|tide|storm|ember>`・`/skyabyss dev buildaudit clear`。
指摘の場所に 60 秒、粒が立つ（階段=炎、取りつけ・戸=青い炎、浮き=白い光、流体=しぶき、暗さ=煙）。チャットの行を押すとそこへ飛ぶ。
テストの出力は、サーバーのフォルダの `build_audit_report.txt`（構造物ごと・種類ごと・座標つき）。

## 直したもの（潮殻・余燼・地上の構造物）

- 余燼・潮殻の体（`TitanBodyBlocks` が読む .bin）: 宙に浮いた 1 ブロック（余燼 2・潮殻 1）を読み込みで消し、1 つ低いくぼみ（余燼 5・潮殻 3）を同じブロック 1 個で平らにした。`LAYOUT_VERSION` を潮殻 13・余燼 10 に上げた。
- 地上の足跡: 雨水の張り方（`waterOk`）が隣へ伝わらず、張られなかった隣へ水が流れ出す形になっていた（足跡 1〜4・足跡の終わり ほか 8 件前後）。`SiteJob` が建て終わりに、横・下が空気の雨水を止まるまで消す。掘った穴の隣の自然の水（浜）も、穴へ流れないよう足もとの石で 1 マス埋める。
- 地上の部品 `ribs`: 宙に浮いた骨 2 個と載っていた苔のカーペット 1 枚を `ribs.json` から消した。建て終わりに、取り残された浮いた 1 個（`SiteJob.pruneStrayBlocks`）と、支えを失ったつる（`pruneOrphanVines`）を消す。
- `lang` の自己テスト: `sign.skyabyss.library_` は `WingsBuilder` が番号を足して作るキーで、`TitanBackSelfTest` に頭だけが文字列で出ていたための誤検出。許可リスト（`LangSelfTest.ALLOW`・`tools/check_lang_keys.py`）に足した。書庫の看板 1〜12 の ja・en は揃っていて、幅の検査も通る。

## 許した例（理由つき。BuildAuditSelfTest.ALLOW）

- 潮殻の体 40,125,-41: 黄色い羊毛の盛り上がりの 1 マス（模型の薄い壁の中を埋めた結果。歩く所ではない）。
- `built:ribs` の浮いた骨 1 個（例: -207,80,-212）: 地形に沿って建つ部品で、起伏の上に肋骨の先が残る。調べて直すなら `RibBuilder` / `ribs.json`。

## 岩鯨（版 18 で直した）

- ATTACH_SUPPORT（鎖が空中からぶら下がる）: 錨石の鎖は骨の梁の腕から垂らす・祠の屋根の灯りの屋根石を欠かさない・天井の灯りは天井が固く下が空いているときだけ吊るす・足場の頭上の飾りは天井まで消す・鍾乳石が鎖や灯りと同じ柱に重ならない。0 件。
- FLOOR_DIMPLE（1 マスだけ 1 低い床）: 背の殻の模型の窪みとひれの道の縁を `TitanBackBuilder.smoothDimples` で埋めた。0 件。
- FLOAT_BLOCK: 谷の飛び石（光る石。跳ぶ道の部品）は、わざと浮いている。`BuildAuditSelfTest.ALLOW`（理由つき）。
- LIGHT_DARK 385 → 約 160 件: 内訳は闇の水路の約 126（灯の台の遊びのため暗いまま）と、広間・祠の階段の影の数件。道は光度 4 以上（鼓動の間の灯りを低く吊るして増やし、床に灯りの道、広間の柱に灯りを埋め込み、通路・休み場の隅に灯り）。`BUDGETS` は 175。
- 壁の穴（`WhaleScaleSelfTest.wallHoles`）: どの部屋の壁・床・天井の輪にも、戸口か別の部屋の内側でない空気がないこと。

## 雷翼（版 20）

26 の拡大で全部を建て直した。`build audit`（嵐）は 0 件（`BUDGETS` に嵐の行は無い）。歩く道の灯りは `route_lamps.json` の 160 本（肋の間の層の灯りの石は `RouteLamps.reserved` で除く）と、灯りの柱・床の灯り。
直したもの: 楕円の門の中の浮いた灯り（FLOAT_BLOCK）、天井の灯りの間で光度 3 になる所（尾の間・広間の北）、風よけの柱が梁の外に浮いていた、東の大門が屋根を抜いて背に穴が開いた、鳥の形の細い塔の先の浮き。

## 暗さ（設計の判断待ち）

`LIGHT_DARK` は 3 体ぶん（岩鯨・潮殻・余燼。雷翼は版 20 で 0）が残る。内部の広間（潮殻は上段の広間 UPPER_1〜3 = y 100〜127 で 400 件近く、余燼は y 64〜85 の洞）に灯りが少なく、空の光も無い。
演出としての暗さか、灯りを足すかは見た目の判断なので、直さず `BUDGETS` で「いまの数まで」許している（増えたら失敗）。灯りを足したら数を下げる。
