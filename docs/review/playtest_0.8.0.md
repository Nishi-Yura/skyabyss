# 試遊 0.8.0 の確かめ順

0.7.3 のあとに入れたもの（2026-10-28 昼〜夕方）。大きな変更は四つ:
- **六章「月」の入口と区画 1「新月の谷」**（docs/design/46）: 大鐘楼の鐘の間の門から月へ。月の面・空・位相・軽い重さ。谷の野営・前のループの自分・星の灯・影の橋・鏡の窪・落ちた星の穴・敵 3 種・区画の主「影抱き」。
- **五章から六章への引き「近づく月」**: 深淵のあと、夜に外で月を見上げると始まる。
- **深淵の朝の三つ**: 心臓の間の入口が戦いのあいだ黒い幕で閉じる、深みの順位の石の画面、番人の絵（古い骨・大きく・背と胸の棘）。
- **見比べの直し**: 一章の素材の絵 4 つ、初めの旅装・鉄張りの旅装、土地の町の 8 人の体と肖像、持ち物のクラフト枠を消した、仲間と称号の画面、章の小要素 39 か所の作り直し。天の鍵の終わりの札は「巨神編　了」（前は「ベータ版はここまで」）。

## 0. 始め方（全員）

- **新しい世界で始めること。** 専用サーバーは `server.properties` に `level-type=skyabyss\:continent` を書いてから世界を作る。
- jar は `skyabyss-0.8.0.jar`（サーバーと全員のクライアントに同じもの）。
- 前の版の世界でも動くが、月の門は都を建て直さないと無い（都は前の作りのまま）。
- 月まで早く行くとき（試遊用。権限 2）: `/skyabyss story key @s` → `/skyabyss quest start @s main_moon_near` → `/skyabyss quest next @s main_moon_near` を三回 → 都の大鐘楼の鐘の間の天然磁石を右クリック。`/skyabyss moonworld gate` で門の前へ行ける。

## 1. 一〜四章の見比べの直し

- 一章の素材（骨片・野兎の針・岩殻の欠片・岩殻の糸）の絵、初めの旅装・鉄張りの旅装の見た目。
- 土地の町の人（島と内海の渡し守・灯台守・長老・小屋番・灰炉の二人）がそれぞれ自分の体と顔か。
- 章の小要素（見張り台・道の祠・骨の隠し場・道の石塚・歌の石の輪・潮だまり・風の崖・温かい岩ほか）が作り込まれ、印（宝箱・碑）がそのまま使えるか。
- 持ち物の画面にクラフトの枠が出ないか。仲間と称号・転生の画面の枠と高さ。
- 天の鍵がそろった終わりの札が「巨神編　了 / 物語は、淵の底へ続く。」か。

## 2. 深淵（五章）

- 心臓の間: 戦いが始まると入口が黒い幕で閉じ、終わると開くか。
- 番人の見た目（古い骨。前より大きく、背と胸に骨の棘）。
- 深みの順位の石を右クリックすると画面が開き、組の顔ぶれの名前が出るか。
- 深淵を終えたあと、夜に外で月を見上げると「近づく月」が始まり、語り部のもとで続くか。月が大きく、銀青に見えるか。

## 3. 月へ（六章の入口）

- 都の大鐘楼の鐘の間の天然磁石を右クリック: 鍵が無い・まだのときは一言。そろうと光の柱が 2 秒立って月の着く所へ。
- 月の空: 真っ黒な空に星、北東に地上の大陸。暗視を飲んでも空が青くならないか。
- 体が軽い（高く跳び、落ちても痛くない）。月の位相の知らせ（新月・上弦・満月・下弦。20 分で一巡り）。
- 着く所の帰りの台（天然磁石）で都へ戻れるか。左上の章の札が「六章　月」か。

## 4. 新月の谷（六章 区画 1）

- 着く所の南へ下る谷。入口の西の岩陰に野営の灯り。顔を隠した旅人（前のループの自分）と話すと頼み「新月の谷」が進むか。会話の文と顔の絵。
- 野営の奥の星の溜まり（紫に光る鉢）を右クリック → 星の灯をもらえるか。手に持って右クリックで足もとに星の印（同時に 2 つ・30 秒）。まわりが本当に照らされるか。
- 谷の中: 暗い。輪の谷・真ん中の台地・踏み跡・岩の尖りの群れ。迷わずに一周できるか。
- 敵:
  - 砂這い: 砂が盛り上がって近づき、足もとで跳び出して噛むか。
  - 殻背の兎: 跳び上がって影の円が出て、上から落ちてくるか。円から出れば当たらないか。
  - 影の綴じ手: 暗がりでは輪の頭だけ見え、斬ってもほとんど効かないか。腕で引き寄せられるか。星の印の中に入れると姿を見せて竦み、斬れるか。
- 探す場所 3:
  - 影の橋（西の裂け目）: 暗がりにだけ架かる黒い硝子の橋。星の印で照らすと消えるか。新月でないと細くなるか。真ん中の柱の欠片の台。
  - 鏡の窪（東の白い窪み）: 鏡の石を右クリックで回す。三つとも真ん中を向くと光が集まり、台から欠片を取れるか。
  - 落ちた星の穴（南）: 螺旋の岩棚で下る。巣の兎を払うまで台が取れないか。
  - 裂け目に落ちると野営へ戻るか。
- 星の門（台地の北の根元）: 欠片 3 つで主の間へ上がれるか。足りないときの一言。上の帰り口で下りられるか。
- 影抱き（主の間）: ボスバー。暗がりでは刃がほとんど通らず、灯りの台を星の灯で灯して（右クリック）その中へ引き出すと固まって効くか。潜る（床を影が走る）・掴む・影を投げる（円）・影の波（跳べば越せる）・分身（段が変わるたび）。強すぎ・弱すぎ。
- 倒したあと野営の旅人と話すと約束の会話で頼みが終わり、旅人がいなくなるか。

## 5. 気づいたら教えてほしいこと

- 谷が暗すぎて進めない所、迷う所、落ちて戻れない所。
- 戦いの数字（敵の体力・傷、影抱きの長さ）。
- 文の分かりにくい所、出てこない文（英字のキー）。
