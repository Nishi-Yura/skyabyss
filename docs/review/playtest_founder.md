# 試遊 裏ボス「初代の空見」の確かめ順

設計は `docs/design/53_founder.md`。終章を三つの結末まで遊んだセーブで確かめる（足りなければ開発用の `/skyabyss founder seen` で三つ見たことにできる）。

## 1. 出会い方

- 三つ目の結末を見終えると、頼み「やっつめ」が始まるか。二つまでは始まらないか。
- 語り部の話（ななつめが最後だと思っていた、ばあさまの言葉）が、語り部の声として自然か。
- 大鐘楼の門に触れると、選びに［鐘の内へ］が出るか。組の人が門のそばにいれば一緒に入るか。

## 2. 鐘の内

- 大鐘の内側に見えるか（壁の色、緑青の筋、上の舌、床の七つの刻み）。暗すぎ・明るすぎないか。
- 床の縁から落ちると、床へ戻されるか。南の帰りの台で都へ戻れるか。
- 鐘の内で倒れると、起きたとき都の門のそばにいるか。

## 3. 戦い（手応えはここで決める）

- 鐘の拍子が聞き取れるか。歌の一行が鐘と一緒に字幕に出るか。
- 歌の七行それぞれ、言葉どおりに動けば避けられるか（ひとつ 影の帯から横へ／ふたつ しゃがむ／みっつ 見上げない／よっつ 月の円の外へ／いつつ 鼓動に合わせて跳ぶ／むっつ 蓋の内へ／ななつ 小鐘の鳴るほうを打つ）。初めて当たったときの一言で分かるか。
- 聞き耳の最中に打つと返されること、待つと大きな隙ができることが分かるか。
- しゃがんで離れていると、始祖が前に聞こえた所を打つか。
- ごり押しで勝てないか。強すぎ・長すぎないか（一人で、二人で）。
- 体力が尽きると膝をついて、やっつめを歌ってから消えるか。

## 4. 報酬

- 称号「やっつめを聞いた者」、空見の肩掛け、始祖の小鐘、伝承 2 項（初代の空見・数え歌のやっつめ）がもらえるか。二度目は品が増えないか。
- 肩掛けを右クリックで着る・脱ぐ。背中と肩に見えるか（ほかの人からも）。倒れても脱げないか。
- 小鐘を都で鳴らすと、大鐘楼が遅れて応えるか。
- J の記録の巨神のつまみに、最速の時間が出るか。
- 語り部に知らせると頼みが済み、最後の言葉が出るか。
