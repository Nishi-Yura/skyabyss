# 試遊 0.5.0 の確かめ順

一気に作ったもののうち、**ゲームの中で人の目で見ていないもの**を、上から順に。各項目の「見る所」だけ確かめて、気になった所を一言ずつメモしてもらえれば十分です。
コマンドは `/skyabyss play …`（一覧は docs/design/37_playtest_commands.md）。OP の権限で使う。

## 0. 始める前に

- 新しい世界を作る（深淵の大縦穴は最初に入ったときに建つ。一分ほどかかる）。
- `/skyabyss play status` で今の段が出ることを確かめる。

## 1. UI のゆとり（どの章でも。5 分）

| 見る所 | どうやって |
| --- | --- |
| 技の画面: 地図のようにドラッグ・ホイールで拡大・R で戻る。説明が送れる（右の目盛り） | K |
| ステータス（記録）の画面の大きさ・文字の読みやすさ | J |
| クエストログ・知らせの記録・伝承の書: 長い中身がスクロールで送れる。窓が窮屈でないか | U・伝承の書 |
| 仲間の画面: 招待の一覧が「完了」の釦と重ならない | 仲間の画面 |

## 2. 五章の入口（10 分）

`/skyabyss play chapter 5` → 語り部に話す → ネザライトを鍛冶師に見せる（`/give @s netherite_ingot`）→ 酒場の地下の封じた戸を天の鍵で開ける → 大坑道を降りる → 底の格子の門が溶けて開く → くぐると深淵へ。

- 目的の帯が、毎段どこへ行けばいいか分かるか。
- 大坑道の踊り場（作業場・野営）と、底の門の見え方。

## 3. 深淵の層（20〜30 分。ここが一番見てほしい所）

| 層 | 見る所 |
| --- | --- |
| 骨 | 崩れた道と、縦穴を渡る肋の橋（狭い・骨拾いが前後から）。巣の肋の番を倒すと鎖の近道が開く。縦穴の肋の弧と、吊った灯り |
| 塩 | 満ち引きの湖（数分で水位が上下する）。重さの術で浮いて高い棚へ。結晶の房 |
| 雷 | 銅の吊り橋に拍子で落ちる雷（床に赤い予告）。鼓動の術で拍が聞こえるか。避雷の像を壊すと止まる区間。銅の輪 |
| 灰 | 真っ暗な迷路。光の術の灯りの中でだけ道が見えるか。足音・見る者。出口の燠の番人 |
| 全部 | 脇の洞（各層 2）の墓と刻みを右クリック。層の四つの刻みで伝承の書に載る。休み場の灯りと、倒れたら戻る所 |

- 「階段を降りるだけ」に感じないか。暗すぎ・明るすぎはないか。迷う所はないか。
- 上り（重さ）と淵の声（暗さ）が、きつすぎ・ゆるすぎではないか。
- 近道: `/skyabyss play goto abyss-rest_1` などで休み場へ飛べる。

## 4. 心臓の番人（10 分）

`/skyabyss play boss warden`

- 灯りを点けた光の中でだけ姿（肋の獣）が見えるか。闇の中では心臓だけかすかに。
- 灯りを吹き消しに来る・二段目の写し・三段目の闇の波が、分かるか。予告は赤だけで正直か。
- 倒したあと、台の心臓に触れて三つの言葉 → 語り部に報告。

## 5. クリア後（各 5 分）

| 遊び | どうやって | 見る所 |
| --- | --- | --- |
| 番人の悪夢 | 台の心臓を右クリック → 「悪夢へ入る」 | 段 1→2 で技が増えるのが分かるか。報酬 |
| 前の私の遺品 | 墓を弔うと遺品がもらえる | 2・4・6 つ持ったときの効き目。絵（B 二色の縁） |

## 6. 言葉（読みながら）

- 灯は全部「灯り」、灰の番人の呼び名、目的のイサナ表記に変えた。違和感のある言い回しがあればメモ。

## 7. 重さ

- 都の真ん中と深淵で、カクつきがないか（HUD の描き方を軽くした）。
- 深淵に入った直後（縦穴を建てている間）に止まらないか。

## 既知の弱い所（直す前提で、見なくてよい）

- 深みの浮かぶ墓場の島の下が、まだ少し暗い。
- 遺品の絵の模様はまだ粗い（選んだ B で描き込む予定）。
- 番人の倒れたあとの場面は言葉だけ（カメラの場面はまだ）。
