巨神の防具シリーズ — 統一案の選定

岩鯨の防具は作り直す前の版に戻しました (ゲームに入っているのはその版です)。A 量塊の言葉は二度と使いません。B 祭具 (布が輪郭を作り、板は要所だけ) を土台に、4 巨神が同じ言葉で揃い、素材と飾りだけが巨神ごとに違うシリーズを作りました。より滑らかに・より細かく・重く見えないように、面取りした板と丸い断面、層になった縁、帯と外套、控えめな光の筋でまとめています。S1 / S2 / S3 は飾りの量・布の量・兜の形の違いです。まだゲームには入れていません (選んでから入れ、インベントリの絵もそれに合わせて作り直します)。

見る順: ① 3 案の一覧 (下の「全体」) → ② 回転して見る → ③ 着た姿 → ④ 巨神ごとに選ぶ。画像はドット絵の拡大のため、少しにじんで見えます。

全体: 3 案を並べて (レア・4 巨神の正面と背面)

S1 凛 — 飾りを絞った細身

頭巾は頭に沿うキャップ。額の前へ立つ刃が 1 枚と、耳の上の小さな側翼だけ。肩は 1 段の丸い板で、外套は腰まで、前垂れはなし。静かで軽く、ひと目で「祭具の人」と分かる最小の形。レアで側翼が増え、伝説で背の環が付く。

S2 祭 — 標準 (B 祭具にいちばん近い)

頭の弧に沿って 3 枚並ぶ冠 (額 → 頭頂 → うなじ) と耳の上の側翼、頬当て。肩は 2 段で右が大きく、右肩に大きな刃。帯の垂れが 2 本、膝上まで広がる外套と背の飾り帯、鈴口の袖、脚の前垂れ。飾りと布の量はいちばん釣り合っている。

S3 盛 — 布と飾りが多い (祭礼の盛装)

後頭に 7 枚の刃が放射状に開く冠 (光背)。肩は 3 段、胸に 2 枚目の板、袖に帯、外套は足首近くまで、帯の垂れが 3 本、前垂れも長い。遠目にいちばん輪郭が大きく、伝説の背の環と合わせると神官の姿になる。そのぶん面は多い。
