# 0.5.6 の試遊の声と、直す順（2026-10-25）

ユーザーと、はじめて遊ぶ人の試遊。まとめると「全体に眠い・当てた手ごたえがない・作業感が強い・試練が分かりにくく、釣り合いが取れていない・文で説明しすぎ・作り込みが足りない」。

## 方針の変更（決まったこと）

- マインクラフトと混ぜることはやめ、完全に RPG にする（Wynncraft のように）。
- 地形・生物群系をいじること、構造物を固定にすることを、すべて解禁する（この作品を入れた世界は、この作品の世界）。
- 地図は、本物の地図のような描いた地図にしてよい。
- 文で説明しすぎない。見て分かる・触って分かる作りにする。
- いろいろな MMO・RPG を調べてから作る。

## A. すぐ直す（作りの手直し）

| # | 声 | 直し方 |
|---|---|---|
| A1 | 野生の語り部などはいらない | 野に立つ語り部の焚き火を出さない |
| A2 | 常に効く技はパッシブに | 「常に効く」を枠に置かない受け身の技にする |
| A3 | 字はマイクラのものでいい | 字のパックを外す（本文・題字とも） |
| A4 | 仲間同士で攻撃できないように | パーティの中は PvP なし |
| A5 | 町に灯りが多すぎる | 街灯を間引く |
| A6 | 鐘銭も旅嚢に | 鐘銭を旅嚢に入れられるようにする |
| A7 | 岩鯨の試練: 最初の階段の向き・上る部屋が簡単・真ん中の骨を守る戦いが難しい | 階段を直す、上る部屋を足す、骨守りを緩める |
| A8 | 岩鯨の 3 つ目は中ボスだけ。番兵長が出ている（その下の中ボスのはず） | 3 つ目の部屋を外して中ボスへ、中ボスの取り違えを直す |
| A9 | 潮殻の領域が長い・攻撃が避けられない | 領域を短く、予告を長く・避けられる形に |
| A10 | 雷翼の「あなたの番だ」が全員に出る・待つ人が出る | 番を本人だけに、待ち時間をなくす |
| A11 | 雷翼の羽を運ぶ部屋が分かりにくい | 見て分かる形に作り直す |
| A12 | 炉の圧合わせが難しい・その前の橋が簡単 | 釣り合いを直す |
| A13 | 与えた傷の数字が欲しい | 傷の数字を敵の上に出す |
| A14 | 余燼の焦げは、前もって道具がないと防げない | 道具ではなく、動きで避けられるものにする |
| A15 | ボスは一撃を重く、攻撃を遅く（回復しながら押し切れる） | 一撃の傷を上げ、間を長く |
| A16 | 段階のあるボスは最初をもっと遅く | 段階ごとに速くなる幅を広げる |
| A17 | 深淵でブロックが壊せる | 深淵を壊せないようにする |
| A18 | 深淵の暗闇の理由が分からない | 理由を見せる・外す |
| A19 | 深淵のボスが弱すぎる | 強くし、仕掛けを作り込む |

## B. 設計から考える（案を作って選んでもらう）

| # | 声 | 進め方 |
|---|---|---|
| B1 | 一つのキーを長押しして、出す画面を選べるように（原神のように） | 輪の形の選び画面の案を 3 つ |
| B2 | 序盤が難しい・食べ物や武器・店に何があるかの説明がない | 序盤の流れ（はじめの 1 時間）を作り直す |
| B3 | 途中から作業になって眠い | 章ごとの山場と、繰り返しの見直し |
| B4 | 新しいエンチャントの仕組み | 案を作る |
| B5 | 完全に RPG の世界（固定の地図・地形・構造物） | 世界の作りの設計（案を 3 つ） |
| B6 | 試練が分かりにくい・説明しすぎ | 試練を見て分かる作りに。数を減らして作り込む |
| B7 | 深淵の説明がない・試練が分かりにくい | B5・B6 と一緒に |
| B8 | 日本語の質 | 文を全体に読み直す |
