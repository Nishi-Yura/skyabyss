# 試遊 0.5.6 の確かめ順

0.5.5 のあとに入れたものだけ。0.5.5 の確かめ順（`playtest_0.5.5.md`）で見ていない所があれば、そちらも。

## 1. 表示を消す操作（2 分）

- F1 を押すと、この作品の表示も全部消えるか: 左上のレベルの札、目的の帯、章の札、技の枠、仲間の札。
- もう一度 F1 で、全部戻るか。
- 画面の暗転（場面の切り替え）は、F1 の間も出てよい。

## 2. 二人で順路の部屋（15 分。二人で）

`/skyabyss play raid whale 1 @a` などで、二人で同じ部屋へ。

- 入口で二人が横に並んで立つか（同じ所に重ならず、前が見えるか）。
- 一人が倒れても、もう一人が立っていれば部屋は続くか。二人とも倒れたら、入口へ戻って部屋が最初からになるか。
- 一人が抜けて入り直す: 仲間のいる部屋へ戻ってくるか。
- 部屋の外で目を覚ました・外へ出てしまったとき: 3 秒ほどで部屋の入口へ戻され、「仲間のいる部屋へ戻った」と出るか。
- 部屋の報いが二人ともに出るか。

## 3. 看板の文字（5 分）

字の形を変えてはみ出していた看板の文を短くした。はみ出さず、意味が通るか。英語の表示でも見る。

- 余燼の背の試練の板（溶ける鎖橋・熾の運び・鋳型の間・灰荷車の護送・大燠虫の巣）
- 深淵の門・大坑道・地上へ戻る碑・北の下り道
- 深みの前の私の手記（骨・塩・雷）
- 一章の骨の坑・背の風の戸、二章の塩の蔵、都の風門・道具屋

## 4. 技の見た目（10 分。弓と、淵・灰の技）

- 天の驟雨: 狙った先（敵がいればその足もと）に雲と輪が出て、光の筋が最後まで降り続けるか。自分の足もとに出ないか。
- 雲穿ち: 撃った瞬間に足もとの輪、矢の道に光の輪が奥へ続くか。壁に当たるとそこで閃くか。
- 合図: 光の標が、狙った地面・相手の足もとに立つか（宙に立たないか）。
- 淵の顎・雷星・熾火の罠: 空を向いて撃っても、地面に出るか（罠が宙に浮かないか）。
- ほかの技も、長く続く技の光が途中で消えないか。

## 5. 試練の板の頁（1 分）

- 「いまの三つ」「図鑑」「歌片を作る」「深淵」の札が、重ならずに四つ並ぶか。「図鑑」を押して頁が変わるか。
