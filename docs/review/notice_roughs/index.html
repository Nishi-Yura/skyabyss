画面の知らせ ラフ 3 案 (17 の判断 12)

下の三つの場面を、案ごとに並べる。上から、語りの字幕 (下中央) と場所の名前の帯 (上中央)、獲得の札 (右上)、目的の帯 (左上)。実際の寸法・音・出入りの時間は docs/design/18_notices.md。

案 A 暗い石板 (クエストや伝承の札と同じ作り)

巨神の記憶: 岩鯨
◆ 煙を追う　　　　40m 北東
獲得
岩鯨の心臓が遺したものが、あなたの手に渡った
背骨に沿って、古い石の門と塔が残っている。
頭はずっと北、胸びれの先は雲の上だ
A

既存の札・クエストの札と見た目がそろう。暗い帯は背景の明るさに左右されず読める。

案 B 枠なしの細い文字 (Elden Ring 風)

巨神の記憶: 岩鯨
◆ 煙を追う　　　　40m 北東
獲得
岩鯨の心臓が遺したものが、あなたの手に渡った
背骨に沿って、古い石の門と塔が残っている。
頭はずっと北、胸びれの先は雲の上だ
B

世界に溶ける。ただし昼の明るい空や雪の上では文字が埋もれ、日本語の細字は読みにくい。既存の札と見た目が分かれる。

案 C 青い窓と白い縁 (ドラクエ風)

巨神の記憶: 岩鯨
◆ 煙を追う　　　　40m 北東
獲得

C

RPG らしさは最も強いが、この作品の静かな恐怖と合わない (青い窓が明るすぎ、世界観の色を壊す)。

推奨: 案 A。理由: (1) 伝承・クエストの札と同じ暗い石板で、画面の言葉づかいが一つにそろう。(2) 暗い下地があるので、昼の空でも夜の闇でも文字が読める。(3) 静かな恐怖を壊さない (大きな音・原色の窓を使わない)。実装は A (client/notice)。字幕・帯の文字だけは案 B の「枠なし」に寄せる余地がある (判断は 18 の 9 章)。
