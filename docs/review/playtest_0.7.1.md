# 試遊 0.7.1 の確かめ順（マルチ）

0.7.0 の試遊（2026-10-27）の声を受けて入れたもの。大きな変更は四つ:
- **はじまりの島 v2**: 広い谷、寄り道 5 か所、島の敵。
- **道**: 町と都の門へつなぐ。
- **装備**: クリエイティブの欄と階級の色、足りなかった職の武器、一人称の持ち姿、作り直したモデル 12 本。
- **土地の町の作り直し**: 街道と市場の町、上の町、町ごとの目印、都と同じ施設が全部そろう。

## 0. 始め方（全員）

- **新しい世界で始めること。** 専用サーバーは `server.properties` に `level-type=skyabyss\:continent` を書いてから世界を作る。
- jar は `skyabyss-0.7.1.jar`（サーバーと全員のクライアントに同じもの）。
- 前の版の世界で入ると、土地の町は近づいたときに建て直される（町の版 `town_v3`）。

## 1. はじまりの島（15 分）

- 谷が広く、低い丘を歩いて越えられるか（崖で行き止まらない）。
- 寄り道の 5 か所（見張り塔の跡・丘の洞窟・漁師小屋・旅人の野営・大樹）へ、分かれ道の札から行けるか。
- 島に蟹・野犬・棘兎が出るか。
- **船着き場の渡し守と話すと、会話の左に顔が出るか**（前は出なかった）。

## 2. 道と門（10 分）

- 島から都、都から土地の町まで、道が途切れずに門へつながるか。
- 道の上に雪・草・木・見どころの飾りが乗っていないか。

## 3. 土地の町（20 分。みんなで回る）

- 四つの町（鯨見・潮・風・灰）の並べ方:
  - 一本の大通りが曲がりながら抜け、真ん中に市場の広場がある。
  - 家どうしがくっついていない（必ず 1〜2 マスあいている）。
  - 裏が詰まりすぎていない。
- 上の町:
  - 町の片側が 3 段高く、苔むした石垣と蔦がある。
  - 道が段を越える所が階段で、引っかからずに上り下りできる。
- 町ごとの目印が上の町に見えるか:
  - 鯨見 = 鯨の肋の塔
  - 潮 = 海の岩の灯台
  - 風 = 傾いた鐘の大樹
  - 灰 = 黒い玄武の岩と篝火
- 仕上げ: 窓の鎧戸と花の箱、戸の脇の灯り、煙突の煙、小路を渡る鎖の灯り、上の階の露台。
- **都と同じ施設が全部あるか**（都に戻らなくてよいか）:

| 建物 | 場所 | 確かめること |
|---|---|---|
| 宿 | 壁の内 | 寝台を決めると、倒れたときにこの宿で目覚める |
| 市の店 | 壁の内 | 道具屋と薬師で売り買いできる |
| 組合会館 | 壁の内 | 組合・取引所・預かり所が開く。預けた品は都と同じものが見える |
| 社 | 壁の内 | 鍵の欠片を納め・返せる。書庫番から伝承の書と地図の写しをもらえる |
| 裏の店 | 壁の内 | 闇市で買える |
| 鍛冶場 | 門の外 | 直し・誂えができる |
| 旅の館 | 門の外 | 厩舎で乗り物を買える。止まり木で巨神の子を呼べる。地図屋が開く |
| 訓練所 | 門の外 | 師範で技と力を振り直せる。古兵が記録を見せる |

- 土地の町の係の人が「鐘の宿」「空見の砦」「転生の台座」など、都にしかない物の名を自分の町の物のように言わないか。
- 町の頼み（都の町の人の筋）の選びものは、都の係の人にだけ出るか。
- 訓練の的（木偶）と師範の稽古は都だけ。

## 4. 装備（10 分）

- クリエイティブの欄が五つ（武器・防具と飾り・敵の卵・ブロック・素材と品）に分かれ、装備の名前が階級の色か。
- 一人称で、構えていないとき武器が手元に見えるか（型ごとに向きが合っているか）。
- 作り直した 12 本と新しい 4 本（鯨歯の短剣・馬刀貝の短剣・雷翼の剣・稲妻の短剣）の持ち姿がおかしくないか。

## 5. 気づいたことの書き方

- どの町・どこで・何をしたら・どうなったか、を一行で。画面の写しがあれば添える。
