# 試遊 0.9.0 の確かめ順

0.8.1 のあとに作った六章「月」の全部（docs/design/46）と月の装備（03 の 12.2）。

## 0. 始め方

- jar は `build/libs/skyabyss-0.9.0.jar`（サーバーと全員のクライアントに同じもの）。新しい世界で始めるのがいちばん確か。前の世界でも、月へ入ると谷・崖・野・淵が新しい形に流し直される。
- 月へすぐ行く（権限 2）:
  - `/skyabyss play chapter 5` で五章の用意 → `/skyabyss play quest done main_moon_near`（近づく月）→ `/skyabyss moonworld enter`
  - 帰りは着く所の帰りの台（天然磁石）か `/skyabyss moonworld leave`
- 区画を飛ばすとき: `/skyabyss play quest done main_moon_valley` など（`main_moon_valley`・`main_moon_cliff`・`main_moon_field`・`main_moon_rift`・`main_moon_core`）。
- 月の位相を進める: `/skyabyss moonworld phase <0〜3>`（0 新月・1 上弦・2 満月・3 下弦）。

## 1. 四つの区画と核（物語の順）

- 新月の谷: 入口の石柱と段々の下り、野営の前の自分、星の溜まり、欠片 3、影の橋、台地の上の主「影抱き」（立ち石の輪）。
- 上弦の崖: 軽身（宙でもう一度跳ぶ）、跳び石の塔・崩れる棚・天秤、頂の皿の主「月秤」。頂の尖りと裾の崩れ斜面。
- 満月の野: 満ち引き（光の石・影の石）、一瞬止め、降る光の溝、影の塔、満月の台の主「望の灯守」。
- 下弦の淵: 自分の残像（下弦の鏡・残像の板）、二つの板の門、残像の渡り、灯りの回廊、主「残月の剣守」。縁の歯と鏡の柱。
- 月の核: 着く所の北の門 → 四人の前の自分 → 核（欠片の盾 → 巻き戻し → 満月落とし）→ 語り → 「完」の札。
- 見てほしい所: 迷わずに次へ行けるか、仕掛けの手ざわり、主の難しさ、前の自分の言葉。

## 2. 記憶の断片と伝承（新しい）

- 区画ごとに 3 つ: 前の自分と初めて話す・区画の隠れた所の「記憶の石」に触れる・区画の主を倒す。取るたびに「（n / 12）」。
- 記憶の石の場所: 谷 = 落ちた星の穴の底、崖 = 張り出しの棚、野 = 南の石柱の陰、淵 = 東の柱のそば。見つけられるか。
- 12 そろうと伝承の書に「見る者」、核のあとに「月の核」。

## 3. 月の装備（新しい）

- 6 職それぞれにレア 1 本とヒロイック 1 本。鎧「月渡りの装束」4 部位、満月の環、月の涙。素材は月の欠片・月の心核・共鳴の欠片（月）。
- 手に入れ方: 区画の主（初回はその主の鎧の一部位）、月の核（図鑑の品、ヒロイック 5 本は別枠で一本ずつ 2%）。すぐ見るなら クリエイティブのタブ。
- 見てほしい所: 一人称・三人称の持ち方、効果（例: 月秤の鎚は相手のほうが体力の割合が高いと +15%、残月の太刀は 3 度に 1 度の残像、星落ちの弓は落ちる星）、ヒロイックの技の書き換え（技を極めてから）。

## 4. クリア後「位相の挑戦」（新しい）

- 核のあと、着く所の南の「月の暦」を右クリック → チャットの名前を押すと、その主の間へ跳んで強い主（段 1〜5）。
- 段 3 から技の間が短く、段 5 は区画の決まりが強くなる（谷 = 影の手、崖 = 傾きが強い、野 = 満ち引きが速い、淵 = 残像が 2 秒、核 = 欠片が速い）。
- 段 5 を越えると記念の銀の札（伝承）。
- 試しに: `/skyabyss moonworld trial <valley|cliff|field|rift|core> <段>`。
