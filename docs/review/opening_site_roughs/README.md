# 序盤の構造物 4 つのラフ (docs/design/17 の 4 章、担当 2)

3 案ずつ。ブロックの構造物なので、ブロックの配置をそのまま描いた図 (上から・斜め・人の目線)。
`python tools/rough/opening_sites.py` で作り直せる。採用案は `--install` でゲームの部品 (`src/main/resources/data/skyabyss/opening/*.json`) になる
ので、ラフに描いた物と、ゲームに建つ物は同じブロックの配置。

| 構造物 | 比較画像 | 推奨 | 選んだ理由 |
| --- | --- | --- | --- |
| 旅の野営地 (9x9) | `camp.png` | **A 焚き火を囲む輪** | 「人が去った跡」が一目で読める。消えた焚き火 + 石の輪 + 倒れた丸太 + 倒れた荷車 + 開いた寝袋 + 木箱 + 切り株の上の帳面、がそれぞれ 1 ブロック単位で別の物として見える。B は白い布で目立ちすぎ (静かなホラーの色にならない)、C は荷車が大きく、スポーンの視界が壁になる |
| 鐘の宿り | `shelter.png` | **A 小屋と柵の庭** | 唐檜の暗い色で、碑文の青緑や空の灰色と並べても浮かない。庭の鐘の柱と、煙の焚き火 (わら束の上) が遠くから見え、近づくと小屋の窓が見える。B の黄色いわらの屋根は村の「明るさ」が出すぎる。C は鐘楼が高く、鐘の音の目印としては良いが、小屋が二つに割れて小さく見える |
| 巨大な足跡 | `footprint.png` | **A 足の形** | 5 本の指・母指球・土踏まず・かかとが分かる。B は楕円の池にしか見えず、巨大な何かの足だと気づけない。C は乾いて割れた跡で、雨水の仕様 (17 の 4.3) と合わない |
| 巨神の骨 | `ribs.png` | **B 片側だけ立つ肋骨** | 北側の弧だけが内側へ曲がって立ち、南側が崩れて地に埋もれる。生き物の骨に見える (A は石のアーチ列、ストーンヘンジに見える。C は三本だけが目立ち、「体の一部」より「門」に見える)。「巨神にも終わりがある」という含みが出る |

- 世界観: 静かなホラー (どれも動かない、音のない痕跡)、巨大な物の痕跡 (足跡は人の足の形、骨は 18 の高さ)、碑文の青緑 (石板の看板は薄青の光る文字。BuildKit と同じ)、看板は石板の 1 枚だけ (4 行、`SignFit` で幅を測る)。
- 野営地には看板を置かない。帳面 (拾う物) だけが語る。
- 積み石 (40 ブロックおき) は `cairn.json` の 1 種類 (石 + 丸石 + 安山岩の板)。
