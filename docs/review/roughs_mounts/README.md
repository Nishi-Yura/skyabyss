# 乗り物の見た目 ラフ (3 案 × 7 つ)

`docs/design/38_mounts.md` の七つの見た目それぞれに、形・背丈・鞍と馬具・巨神ゆかりの飾りが違う 3 案。ゲームのモデルはまだ替えていない。
各シート: 上に案の名前と一行、下に 前 / 3/4 / 横 と「乗った人」の行。左の黄色い目盛りが人 (1.8 ブロック)。メッシュは閉じていて、脚・頭・飾りは体に沈めてある (浮いた部品の検査は全部 0)。
鞍は座面が背に半分沈み、前後の山・腹帯・あぶみ付き。座面の高さ (px、1 ブロック = 16) は括弧内。

## 案の一行

- 角の荷獣: A 肩にこぶ、前へ張る角、荷袋と胸の鈴 / B 低い楔形、骨の板、鼻の一本角と牙 / C 背高、巻いた角、たてがみ、荷の縄
- 灰色の鹿: A 高い枝角と白い胸毛 / B 肩のこぶ、垂れた鼻先、手のひら形の角 / C 角なし、大きな耳、灰の房、背の熾の斑
- 大トカゲ: A 低く広げた脚、長い尾 / B 脚を立て、赤い襟と背の棘の帆 / C 平たく幅広、骨の粒、大きな顎
- 岩の子鯨: 石の肌とフジツボの石。A 四つ足 / B 前ひれで歩く、鞍はフジツボの輪の中 / C 一本の巻き角、柱の脚にフジツボの輪
- 殻の亀: 珊瑚の殻。A 丸い高い甲羅 / B 平たい海亀、背の後ろに珊瑚の庭 / C 渦巻きの殻の塔、はさみの前脚
- 雷の雛: 羽の先が雷 (青白く光る)。A 駆ける背高の雛 / B 綿毛の玉 / C サギのように脚長、稲妻形の冠と尾
- 炉の狐: 尾の先と体の割れ目が熾 (光る)。A 大きな尾を掲げる / B 竈と煙突と火口 / C 三本の尾の扇と灰の房

## 作り直し

`python -I tools/rough/lowpoly/mounts/run_all.py` (順に作る。メッシュ・アトラスは一時の場所 `MOUNT_WORK`、コミットしない)。
共通部品は `tools/rough/lowpoly/mounts/mt_common.py` (abyss のラフの `ab_common.py` / `ck_ab.py` の写しを同じ場所に置いてある)。
