# 雷翼の装備 ラフ 3案 (A / B / C)

生成: `tools/rough/storm_items.py` (ラフ) / 採用: `tools/install_storm_gear.py` (推奨案で書き出し)。羽衣 (防具) は `README_armor.md`。

## 比較シート
- `compare_thunder_wing_bow.png` 雷翼の弓 (アイコン・3D・引き絵 3 枚・いっぱいに引いた 3D)
- `compare_raiju_claw.png` 雷獣の爪
- `compare_warden_glaive.png` 羽守の鉤槍
- `compare_icons.png` 嵐の護符・嵐纏の足環・嵐の目の羽根・雷翼の欠片・雷翼の心核・雲間の干し果・鱗粉 (アイコンだけ。行が A / B / C)

各案のフォルダ `<item>/<a|b|c>/` には `icon.png` (32px)、`upright.png`、3D の品は `voxels.npz`・`front.png`・`hand.png`、弓は `icon_pull_<n>.png` もある。採用されなかった案も残してある。

## 推奨案と理由

色は雷翼の巨神 (採用案 A 嵐の大鷲) に揃える: 灰青の羽、白い羽に灰の横縞、銅の冠、稲妻の白金と青白。赤・橙の炎の色は使わない (余燼と分ける)。

| 品 | 推奨 | 理由 |
|---|---|---|
| 雷翼の弓 | A | 灰青の弓幹に羽根が並び、弦が青白く光る。巨神の翼がそのまま弓になったと読める。B は銅の弓幹で余燼の色に寄る。C の骨色は岩鯨の装備と見分けにくい |
| 雷獣の爪 | A | 骨色の 3 本爪の先が青白く光る。32px でも爪の本数が読める。B は爪まで灰青で暗く、黄色の稲妻が雷翼の色から外れる。C は 1 本だけ長く、爪 (手の武器) より鎌に見える |
| 羽守の鉤槍 | C | 銅の鉤に灰青の羽の房。「羽守」(羽の番人) の名が絵で読める。A は形はきれいだが房がなく、ただの鉤竿に見える。B の二重の鉤はアイコンで潰れる |
| 嵐の護符 | B | 銅の縁の円盤に稲妻。32px で一番はっきり護符と読める。A は燭台、C は弓に見える |
| 嵐纏の足環 | C | 銀の輪に青白い火花。足環と読める。A は脚つきの台、B は円盤に見える |
| 嵐の目の羽根 | A | 白い羽根の根元に青い目。「嵐の目」が読める。B・C は灰色で、雷翼の欠片と見分けにくい |
| 雷翼の欠片 | A | 灰青の羽根の形の欠片 (巨神の羽の一片)。B は氷の結晶で別の品に見える。C は銅の先が余燼に寄る |
| 雷翼の心核 | A | 岩鯨・潮殻と同じ八角の石の枠に、白金の稲妻の結晶。心核の系統が揃う。B は銅の枠で別系統、C は結晶が小さい |
| 雲間の干し果 | A | 紫の果実に小さな雲。食べ物と読め、名の「雲間」も出る。B は焼き菓子、C は葡萄の房に見える |
| 鱗粉 | C | 青白くきらめく粉の山。矢に混ぜる素材と読める。A は壺、B は水の瓶に見える |

推奨は人の判断で差し替えてよい。`install_storm_gear.py --option <品>=<a|b|c>` で再書き出しできる (選んだ案は `tools/sources/storm_gear/` に写る)。

## 3D の作り

潮殻と同じ。1 画素 = 3 ボクセルで縁からの距離で断面を丸め、盛り上がりの層を足す。ボクセルを直方体にまとめ、外に見える面だけ書く。手に持つと 3D、インベントリは 32px の平たい絵 (`neoforge:separate_transforms`)。武器は -45 度 (刃先が右上) でバニラの handheld の持ち方、弓は同じ向きでバニラの `item/bow.json` の持ち方と引き絵の切り替え (pull / pulling)。光る画素 (稲妻・爪の先・弦) は明るさ 15。ゲームでの見た目は確かめていない (試遊をしない決まり)。

| 品 | 直方体 | 色 |
|---|---|---|
| 雷翼の弓 | 517 (引き絵 550 / 557 / 575) | 8 |
| 雷獣の爪 | 391 | 7 |
| 羽守の鉤槍 | 161 | 7 |

静電避け (雲間の干し果の効き目) の印 `textures/mob_effect/static_ward.png` (18x18、灰青の丸に稲妻) も `install_storm_gear.py` が書く。
