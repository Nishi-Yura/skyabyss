# 雷翼の羽衣 (thunder_wing 防具 4 部位) ラフ 3 案

兜・胸当て・脚当て・靴の 3 案。人型の台に着せた 3D と、インベントリ用の 32x32 アイコン (3D の箱を正面から描いたもの) を比べる。

## 案

- **A 羽重ねの外套** (推奨): 灰青の羽を重ねた外套。兜の頂に銅の冠毛、背に白羽の垂れ、胸に銅の留め金と稲妻の折れ線。袖・脚・靴の縁は白羽。
- **B 鷲の頭巾**: 暗い灰青の頭巾に銅のくちばし。肩は翼の形に外へ広がる段。胸は白羽の V と銅の帯、背に稲妻の筋。
- **C 雷縞の衣**: 白い布と羽の長い衣。前に稲妻の縦縞、袖は広め。全体が明るく、発光の筋が目立つ。

## 推奨: A 羽重ねの外套

理由:
- 雷翼の大鷲 (A 案) の色 (灰青の羽、白い綿毛、銅の冠毛、青白い稲妻) をそのまま使っている。
- アイコンで色の面が分かれる。灰青・白・銅・青白い光の 4 色で、32px でも部位の違いが読める。
- B は鷲のくちばしが特徴的だが、アイコンでは胸が暗い灰青の面になり、32px で形が沈む。
- C は白い面が大きく、発光の筋より布の白さが先に目に入る。雷の光として弱く、布の服に見えやすい。

## 検査

| 案 | 箱の数 | テクスチャ | 重なり | 体への食い込み | 光る画素 |
|---|---|---|---|---|---|
| A (推奨) | 210 | 512x512 | 0 | 0 | 272 |
| B | 199 | 512x512 | 0 | 0 | 640 |
| C | 222 | 512x512 | 0 | 0 | 1576 |

- 重なりは `voxel.check_overlaps` で調べた (回転は使っていない)。食い込みは人型の台 (頭・胴・両腕・両脚) と比べた。
- 顔の覗き穴は、額の庇 (y 29.5 より上) の下を開けてある。
- 3D 比較: `compare_armor.png` (行: 正面 / 背面 / 3/4)。アイコン比較: `compare_armor_icons.png` (行: 兜 / 胸 / 脚 / 靴)。
- 各案の素材: `armor/<a|b|c>/` (geo.json、本体テクスチャ、発光マスク、アイコン、バニラ層、check.json)。

## 注意

- 採用案 A はゲームに入れてある (`tools/install_storm_armor.py`、素材は `tools/sources/storm_armor/`)。ゲームでは確かめていない。
- 羽の房と鱗の盛り上がりは 0.5 単位の箱で、実際の羽の形ではない。
- 防具の層 (`layers/`) は 64x32 で作った (tide と同じ形式)。
