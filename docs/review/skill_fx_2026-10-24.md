# 技の見た目 (2026-10-24 第三版)

能動の技 25 本の見た目。主役は「形」 (板で描く)、粒は当たりの火花と煙だけの脇役。
段取りは 溜め → 放ち → 当たり → 残り の四段で、手元 (client/skill/SkillFx) で組む。
サーバーは発動が決まったとき SkillFxPayload を一通だけ送る (持ち主と近くの人へ)。数値・当たり判定・音は変えていない。

## 作りの構成

| 部品 | 場所 | 中身 |
|---|---|---|
| 形の道具 | `rpg/client/skill/fx/FxDraw.java` | 八種の `Prim`: ARC (三日月・振り軌跡)、LINE (筋・突き)、RING (地面の輪)、DISC (地面の円盤)、FAN (地面の扇)、BEAM (縦の光の柱)、BOLT (稲妻)、SHELL (衝撃の殻) |
| 形の付け方 | `Prim.arc(...)` などの後に `.color .width .life .ease .glow .trail .alpha` | 色・幅・寿命・進み方 (LINEAR / OUT / OUT3 / IN2 / SMOOTH)・光のにじみ・尾の長さ・濃さ |
| 描き方 | `FxDraw.onRenderLevel` (RenderLevelStageEvent AFTER_PARTICLES) | 板 (quad) を積んで一度に描く。加算合成・深度は読むが書かない。テクスチャは 2 種 |
| テクスチャ | `textures/fx/glow.png` (円盤・扇)、`textures/fx/band.png` (帯の断面) | `tools/gen/fx/gen_fx_textures.py` が作る |
| 段取り | `fx/FxFrontline.java`・`fx/FxSupport.java`・`fx/FxRanged.java` | 技ごとに c.at(tick, …) で形と粒を置く |
| 撮影の台本 | `tools/shots/skill_fx.txt` | `tools/gen/shots/gen_skill_fx_shots.py` が作る (的・視点・時刻もここで決める) |
| コンタクトシート | `tools/sheets/skill_fx_sheet.py` → `docs/review/previews/skill_fx_sheet.png` | 行 = 技、列 = 三人称の放ち・当たり・残り、一人称の当たり |

| 項目 | 上限 | 場所 |
|---|---|---|

| 一つの形の区切り | 16 (板は 1 区切り 1 枚・glow は二枚目) | `FxDraw.Painter` |
| 一発動の粒 | 48 | `SkillFx.CAST_CAP` |
| 一 tick の粒 | 160 (画面の粒の設定で 1/2・1/5) | `SkillFx.BASE_BUDGET` |

計測: `SKYABYSS_SKILLFX_LOG` を入れると、発動ごとに形と粒の数、フレームごとに板の数を log に出す。`SKYABYSS_PROF=1` で `client.skillfx` の描く時間 (ms) が出る。
(数値は撮影の後に追記する: 下の「計測」)

## 既知の制約

- 刻印 (ルーン) の違いは手元では分からない。既定の形で描いている。刻印の技のサーバー側の粒 (地を走る衝撃波など) は残している。
- 三人称の撮影は、カメラが体の向き (視線) に従うため、真横からは撮れない。的を前 3.8・右 2.2 に置いて、後ろ 4 ブロックから見る (的まで 6〜8 ブロック)。
- 仲間・敵の判定は手元の近似 (当たりの位置は発動の向きから決める)。合図の標の先は視線の 32 ブロック先。
- 一人称の近くの形は CLEAR (1.2 ブロック) より近い区切りを描かない。

## 昼と夜のシート (第四版、2026-10-24 の撮影)

- 昼: `docs/review/previews/skill_fx_sheet.png`、夜: `docs/review/previews/skill_fx_night_sheet.png` (`python tools/sheets/skill_fx_sheet.py --night`)。
- 粒は白い十字をやめ、柔らかい光の点にした (`rune_spark_*`・`sky_mote_*`、`tools/gen/ui/gen_skill_assets.py`)。空の粒は他の技とボスの効果でも使うため、その見え方も変わる。
- 撮影台本は天候の周期を止めて、毎技 晴れにそろえる (雨が混ざらないように)。

### 読めるか (一枚で見分けられるかの見立て。目視の判断)

- 読める (昼・夜とも): 巨神斬り、岩呼び、薙ぎ払い、跳び退き、二連の斬り、守りの歌、引き潮、循環の歌、武器を熾す、熾の打ち下ろし、灰を被せる、骨の罠、合図の標、蒸気の鐘、火の矢の一斉、淵の引き、淵の残響、淵の顎 (夜は紫の縁で読める)、遺響の一撃、墓鐘、最期の光。
- 弱い (三人称で形が点に近い): 突進 (視線と同じ向きの道筋は、円盤を並べても三人称の放ちで薄い)、雲穿ち (途中の柱が三人称で細い)、天の驟雨 (落ちる光の筋が細く、雨粒に紛れる)。
- 未解決: 砂の突進の右端に、黒い箱と大きな白い粒が出る。サーバー側 (`ExtActions.dustCharge`) はブロックを置かず粒も出さないので、描画の板ではない。撮影の床か別の物の可能性が高いが、まだ確かめていない。

### 計測

- 予算 (1 発動の形 24、粒 48) は今回変えていない。描画の時間 (`SKYABYSS_PROF`) と形の数の実測は、まだ取っていない。
