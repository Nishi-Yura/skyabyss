# 試遊 0.6.0 の確かめ順

0.5.6 のあとに入れたもの。大きな変更は二つ: **完全な RPG の決まり**（アドベンチャー・すり減らない・落とさない）と、**天と淵の大陸**（手で描いた一枚の大陸の世界）。0.5.6 の試遊の声で直したもの（傷の数字・輪の選び画面・心臓の重さ・試練の手直しなど）も入っている。

**新しい世界で始めること。** 一人で遊ぶなら、新しい世界を作る画面の「ワールドの種類」が最初から「天と淵の大陸」になっている。専用サーバーは `server.properties` に `level-type=skyabyss\:continent` を書いてから世界を作る（前の世界はそのまま使えるが、大陸にはならない）。

## 1. 遊び方の決まり（5 分）

- 入ると、アドベンチャー（ブロックを壊せない・置けない）になっているか。
- 初めて入ったとき、石の剣・革の防具（身に着けている）・パン 10 を持っているか。
- 剣で敵を叩いても、防具で攻撃を受けても、耐久が減らないか。
- 倒れても、持ち物と経験値が残るか（墓は出ない）。
- 木（丸太）・石・鉱石・実った作物・花を右クリックすると、壊れずに品が手に入るか。すぐもう一度だと「まだ採れない（あと何秒）」と出るか。
- 鉄鉱石を素手で右クリックすると「この道具では採れない」と出て、石のつるはしなら採れるか。
- 空のバケツで水を右クリックすると、水入りになるか（水は減らない）。
- 都の中では採れないか。
- 試練の部屋の「叩く」仕掛け（余燼の圧力計など）が、アドベンチャーでも左クリックで動くか。

## 2. 大陸の世界（15 分）

- 外れの谷の野営地で目覚めるか。都（西の岸、内海のそば）へ土の道が続いているか。
- 地形: 北の丘陵・東の浜と内海・西の雪の峰・南の赤い荒野と火山。見た目の良し悪しと、歩きやすさ。
- 村・砦などのマインクラフトの構造物が出ないか。地上に溶岩の池が無いか。
- M の地図: 丸い盤に描いた大陸の絵が出るか。引くと土地の名前と「Lv 4-12」などの目安が出るか。寄せる・引く・動かすで崩れないか。
- 土地の町（鯨見の町・汐守の港・風待の里・灰炉の村）: 地図に印と名前が出るか。町に宿・店・家・言伝ての板・井戸・名前とレベルの札があるか。宿の主人と道具屋が立っているか。板で頼みを受けられるか。
- 都のまわりの敵（夜のゾンビなど）は弱く（二〜三回で倒れる）、灰の荒野の敵は強いか。
- 地上で倒れたら、いちばん近い町・都・野営地で目覚めるか（寝台で寝た人は寝台）。
- 世界の縁（大陸から 2,200 ほど外の海）より先へ行けないか。
- 初めて都の門の前に着いたとき、空を巨神の影が渡るか。
- 初めて都に入ると「町を回ろう 1/4: 鍛冶場 へ」と出て、灯りの道が出るか。鍛冶場 → 宿 → 道具屋 → 組合 と着くたびに鐘銭（宿ではパンも）がもらえるか。
- 道具屋に、章の頼みの品（一章なら鉄の剣・盾・鉄の防具など）が並ぶか。先の章の品は伏せてあるか。
- 野に羊や牛がいるか（羊を連れ戻す頼み）。

## 3. 章の跡地（10 分）

- 四つの跡地が、地図の決まった場所のそばにあるか（岩鯨 = 北の丘陵、潮殻 = 東の浜、雷翼 = 西の峰、余燼 = 南の荒野）。
- 一章の岩鯨の跡地まで、都から歩いて遠すぎないか（約 1,100 ブロック）。遠ければ近づける。

## 4. 前の世界（2 分。前の版で遊んでいた世界があれば）

- 開くと、倒れても落とさない・すり減らない決まりに一度だけ切り替わるか（ゲームルール `skyabyssDeathMode` が 2）。
