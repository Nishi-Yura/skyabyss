# 試遊 0.6.0 の確かめ順

0.5.6 のあとに入れたもの。大きな変更は二つ: **完全な RPG の決まり**（アドベンチャー・すり減らない・落とさない）と、**天と淵の大陸**（手で描いた一枚の大陸の世界）。0.5.6 の試遊の声で直したもの（傷の数字・輪の選び画面・心臓の重さ・試練の手直しなど）も入っている。

**新しい世界で始めること。** 一人で遊ぶなら、新しい世界を作る画面の「ワールドの種類」が最初から「天と淵の大陸」になっている。専用サーバーは `server.properties` に `level-type=skyabyss\:continent` を書いてから世界を作る（前の世界はそのまま使えるが、大陸にはならない）。

## 1. 遊び方の決まり（5 分）

- 入ると、アドベンチャー（ブロックを壊せない・置けない）になっているか。
- 初めて入ったとき、石の剣・革の防具（身に着けている）・パン 10 を持っているか。
- 剣で敵を叩いても、防具で攻撃を受けても、耐久が減らないか。
- 倒れても、持ち物と経験値が残るか（墓は出ない）。
- 木（丸太）・石・鉱石・実った作物・花を右クリックすると、壊れずに品が手に入るか。すぐもう一度だと「まだ採れない（あと何秒）」と出るか。
- 鉄鉱石を素手で右クリックすると「この道具では採れない」と出て、石のつるはしなら採れるか。
- 空のバケツで水を右クリックすると、水入りになるか（水は減らない）。
- 都の中では採れないか。
- 試練の部屋の「叩く」仕掛け（余燼の圧力計など）が、アドベンチャーでも左クリックで動くか。

## 2. 大陸の世界（15 分）

- はじまりの島の野営地で目覚めるか。島の道の終わりの船着き場で、桟橋の先に立つと鐘の都の南の門の外へ渡るか（島へは戻らない）。
- 道の途中に「旅の休み場」（焚き火と食べ物の樽）と「宿り木の祠」（そばにいると傷が癒える）があるか。札の字が読めるか。
- 地形: 北の丘陵・東の浜と内海・西の雪の峰・南の赤い荒野と火山。見た目の良し悪しと、歩きやすさ。
- 村・砦などのマインクラフトの構造物が出ないか。地上に溶岩の池が無いか。
- M の地図: 丸い盤に描いた大陸の絵が出るか。引くと土地の名前と「Lv 4-12」などの目安が出るか。寄せる・引く・動かすで崩れないか。
- 土地の町（鯨見の町・汐守の港・風待の里・灰炉の村）: 地図に印と名前が出るか。町に宿・店・家・言伝ての板・井戸・名前とレベルの札があるか。宿の主人と道具屋が立っているか。板で頼みを受けられるか。
- 都のまわりの敵（夜のゾンビなど）は弱く（二〜三回で倒れる）、灰の荒野の敵は強いか。
- 地上で倒れたら、いちばん近い町・都・野営地で目覚めるか（寝台で寝た人は寝台）。
- 世界の縁（大陸から 2,200 ほど外の海）より先へ行けないか。
- 初めて都の門の前に着いたとき、空を巨神の影が渡るか。
- 初めて都に入ると「町を回ろう 1/4: 鍛冶場 へ」と出て、灯りの道が出るか。鍛冶場 → 宿 → 道具屋 → 組合 と着くたびに鐘銭（宿ではパンも）がもらえるか。
- 道具屋に、章の頼みの品（一章なら鉄の剣・盾・鉄の防具など）が並ぶか。先の章の品は伏せてあるか。
- 野に羊や牛がいるか（羊を連れ戻す頼み）。

## 3. 章の跡地（10 分）

- 四つの跡地が、地図の決まった場所のそばにあるか（岩鯨 = 北の丘陵、潮殻 = 東の浜、雷翼 = 西の峰、余燼 = 南の荒野）。
- 一章の岩鯨の跡地まで、都から歩いて遠すぎないか（約 1,100 ブロック）。遠ければ近づける。

## 4. 前の世界（2 分。前の版で遊んでいた世界があれば）

- 開くと、倒れても落とさない・すり減らない決まりに一度だけ切り替わるか（ゲームルール `skyabyssDeathMode` が 2）。

## 5. 昼の作り込み（2026-10-25）

- 野・丘陵・浜・高地・荒野を歩いて、見どころ（風車・灯台・巨神の肋骨・焼けた砦・野盗の野営など）が見つかるか。宝箱に鐘銭・糧・粉があるか。野盗の野営に近づくと野盗が出るか。
- 見つけた見どころが地図に印で出るか（指すと名前）。地図が枠いっぱいの四角で見やすいか。
- 道の中ほどの道しるべに、行き先と道のりが書いてあるか。
- 地面に四角い穴がもう無いか。
- 都: 鍛冶場の口が正面だけになったか。灯りが散らばって見えないか。
- 土地の町: 入口の門・二階建ての宿・煙突の煙・畑。

## 6. 夕方の作り込み（2026-10-25）

- はじまりの島: 船着き場の桟橋が海の上まで出ていて、桟橋の先で渡し船に乗れるか。島にも岩や茂みがあるか。
- 土地の町（鯨見・汐守・風待・灰炉）: 壁と四つの門楼に囲まれた大きな町になっているか。広場の記念碑・市の屋台・宿と道具屋の看板。家の中に入れるか（寝台・机・梯子）。町で倒れたら広場で目覚めるか。
- 野: 岩・茂み・倒木・岩の柱・崩れた石垣が散っていて、平原ばかりに見えないか。
- 見どころ: 古い坑道（下に掘り場と骨の兵）・崩れた塔（はしごで上へ）・旅の一座の野営・丘の墓所・大樹の小屋。坂でも段々の台地になっていないか。
- 地図（M）: 行く前から見どころの印が出るか。引くと小さな点になり、見やすいか。
- 内海の渡し船: 都の側の港と汐守の港を、桟橋の先で行き来できるか。
- 発見: 見どころに初めて近づくと、名前と「見どころを見つけた（n / 100）」の札と経験値が出るか。地図で、まだ行っていない見どころが薄く、名前に「（未発見）」と出るか。
- 地図: 巨神・祠・章の場所の印が、見どころが多くても消えていないか。
- 土地の町: 広場に猫や鶏がいるか。
- 土地と町の名前: 土地（鐘の野・岩鯨の丘陵など）に入ると名前と目安 Lv、町に入ると町の名前が出るか。境目で何度も出ないか。
- 倒れて起き上がる → 入り直す: はじめの持ち物が二度もらえないか。大陸で都へ渡ったあとに倒れても、はじまりの島ではなく都・町・休み場で目覚めるか。町めぐりがやり直しにならないか。

## 7. 闘の試練の中ボス（00 の 277）

- 三つ目（闘）の部屋で波を越えると、同じ部屋に中ボスが現れるか（岩鯨 = 番兵長、潮殻 = 潮招きと砂の床・岩の小島、雷翼 = 雷獣と避雷の柱、余燼 = 灰の鍛え手と焼き入れの槽・炉の扉）。
- 中ボスが怒りの段に入らず、前より少し早く倒せるか（体力 7 割）。中ボスで全滅すると部屋が元に戻り、波からやり直しになるか。
- 倒すと心臓へ進むか（中ボスだけの間は無くなった）。報い（素材・共鳴の欠片・結晶）がもらえるか。
- 部屋ごとの出方（2026-10-26）: 核の部屋 = 番兵長が核を削りに来る（核の体力が帯に残る）／縮む輪 = 輪の外へ追い込むと番兵長が削れる／苗 = 招き潮のあいだ苗の台に乗れる／群れの母 = 潮招きに影が二体（足もとの影と足跡で見分ける）／帯電 = 光る敵を雷獣のそばで倒すと雷が跳ぶ／嵐の目 = 雷獣のあいだも突風が吹く／炉 = 鍛え手が炉の火を消しに来る／弟子 = 三人のあと師。強すぎ・弱すぎ・わかりにくい所。

## 8. 土地の町の人の頼みと五章の入口（2026-10-26）

- 汐守・風待・灰炉の広場の二人に「困っていることは？」が出るか（その章から）。頼みの見どころ（難破船・岬の灯台・避雷の塔・風の門・炉の跡・焼けた砦）が、言われた方角にあるか。着くと目的が進むか。渡すと鐘銭がもらえるか。
- 五章: 鍛冶師・語り部の黒い鉄の話が「灰の荒野」になっているか（火の国・ネザーの話が残っていないか）。
