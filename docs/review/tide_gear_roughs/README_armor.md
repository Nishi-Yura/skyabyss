# 潮殻の鎧 (tide_shell 防具 4 部位) ラフ 3 案 (2 周目の直し)

4 部位 (兜・胸当て・脚当て・靴) の 3 案。人型の台に着せた 3D と、インベントリ用の 32x32 アイコンを比べる。

## 2 周目の直し (B 珊瑚の鎧)

1 周目の B は、箱を平らに並べただけの角ばった装甲で、鱗はつぶの模様、珊瑚は 1 画素の点だった。
2 周目で B の形だけを作り直した (A / C は 1 周目のまま、形も素材も変えていない)。

- 甲羅の形: 兜は段々の甲羅 (真珠色の縁、3 段の甲羅、頂に珊瑚の枝)。背は 3 段で膨らむ甲羅。
- 顔: 兜の額の庇は目の上だけ、頬当ては耳の側。顔の正面は目の高さまで開けてあり、胴の板と同じ向きで見える。
- 胸: 大きな板 4 枚を 0.5 だけ前に出し、中央に珊瑚の竜骨と青い核。胸の縁は真珠色。
- 肩: 3 段の板 (段ごとに 0.5 ずつ中へずらして重ねる) と珊瑚の枝。
- 脚: 太ももは板 (前・後・外)、膝は 2 段の盛り上がり、すねは鱗の盛り上がり。
- 靴: 外側に厚い底、つま先の覆い、かかとの段、足首の縁は真珠色。
- 珊瑚はすべて 3〜4 箱の枝 (幹・枝・先) で、点ではない。
- 鱗は 0.5 単位の盛り上がりで、板の面に千鳥に並べた (`tiles`)。

## 案

- **A 甲羅の鱗**: 青緑の甲羅に、淡い鱗の段と真珠色の縁。胸の中央に青い核。兜の頂に鱗の稜。
- **B 珊瑚の鎧** (推奨、2 周目で形を作り直し): 少し濃い青緑の甲羅。段々の兜と背の甲羅、胸の大板。珊瑚の枝を兜の頂・両肩・背に立てる。胸の核と額は青く光る。
- **C 潮門の殻**: 真珠白の殻に、藤壺 (灰茶) のびょうを散らす。肩の縁は月銀色。胸の核は青く光る。

## 推奨: B 珊瑚の鎧

理由:
- 巨神の採用案 B (珊瑚礁の背) の、珊瑚・青緑・真珠・青い光という 4 色をそろえて使っている。装備を見ても巨神の背の絵がつながる。
- A は青緑一色で、甲羅の鱗は出るが、珊瑚の色が出ない。
- C は真珠白と灰色で、岩鯨の甲殻の防具 (石と骨の色) に近い。同じ系統の防具が並ぶと区別がつきにくい。

## 注意

- 鱗は 1 単位のつぶの格子と、テクスチャの継ぎ目で表した。六角形そのものではない。
- 兜と肩は段の箱を階段状に重ねた形 (面で接する) で、まだ角ばっている。曲面の段差は 0.5 単位。
- 防具の層 (`layers/`) は 64x32 で作った。リポジトリの `stone_whale_layer_*.png` は 16x16 で、形式が違う。
- アニメーションは空のファイルを作った (`animations/armor/tide_shell_armor.animation.json`)。
- ゲームでは確かめていない (Gradle を動かしていない)。
