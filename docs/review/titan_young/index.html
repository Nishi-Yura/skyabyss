いまの困りごと

笛を吹くと、世界に一体の本物の巨神が、吹いた人のもとへ動きます。背で別のパーティが戦っていても、外の位置や乗り込み口が変わり、旅の最中はほかの人が呼べません。

いまの仕組み: 笛が成体を動かす
