# 巨神 1 体 = 1 章 への組み替え計画

- 性格: 提案書。コードと設計書（`docs/design`）は変えていない。決まった案は設計書へ現行仕様として書き直す
- 元: ユーザーの決定「巨神ごとに章を分け、一体ずつのスケールを大きくする」（`beta2_proposals.md` 2.1 の案 (b)）。ベータ第 2 回の感想（序盤と巨神の間が退屈、1 章が巨神だけ、スポーン地点で体験が変わる）
- 守る軸（01 の 1）: 見せない恐怖が先／物語が先／引き算。**足すのは「跡・頼み・音・小さな異変」で、敵とジャンプスケアは足さない**
- 見積もり: S = 半日〜1 日、M = 2〜4 日、L = 1 週間以上、XL = それ以上
- 注: `beta2_proposals.md` はこのブランチにはなく（コミット 68b7d50 にある）、小要素 E1〜E12 の番号はそこの 1.2 のもの。この書類の N1〜N5 は新しく足す案

## 0. 結論（先に読む）

1. 章は **序章／一章 岩鯨／二章 潮殻／三章 雷翼／四章 余燼／五章 深淵／六章 月／終章 雲海**。今の「1 章」は「**巨神編**（一〜四章の総称）」と呼び、旧「2 章 = 深淵」「3 章 = 月」は五章・六章に繰り下げる。
2. **内部の ID は変えない**（`chapter1/…` の伝承 ID、クエスト ID、段階 0〜4、レベル上限 15/21/27/33/40）。章は「段階から導く写像」と「伝承の `chapter` 欄」だけで作る。変えるのは表示・データの `chapter` 欄・設計書。これで 100 ファイルの `chapter1` を触らずに済む。
3. 「スケールを大きくする」は、まず **存在感・予兆・出来事・背の外の探索・NPC の筋**で作る（L）。モデル・LOD・背中の島の拡大（XL）は、試遊のあとに巨神ごと別フェーズで判断する。
4. 章ごとに同じ型を回す: **題字 → 小要素 3〜5 → 予兆 3 拍 → 中盤の出来事 → 背中の試練 → 心臓 → 余韻 → 次への引き**。
5. スポーン地点に左右されないよう、小要素は**章が開いたときに「人の拠点」を基準に扇形で置く**（ワールド生成時ではない）。既存ワールドにも効く。

### 1.4 一章 岩鯨「空を泳ぐもの」（Lv 4 → 12、上限 15）

- **主題**: 見えないものが、痕跡から全身へ近づく。ホラーの順番（01 の 7）を章ぜんぶで一回りする。
- **導入**: 日 2 朝、イサナの焚き火（B7）。題字の札。
- **小要素（E 案から 5 つ + N）**:
  - E9 見張りの丘: 高台の望遠鏡。夕方に覗くと遠い雲に影の端。岩鯨の方角と「大きさ」を比べる物なしで先に見せる。
  - E4 歌石: 地上に 5 つ。順に叩くと、5 つ目で宿りの鐘が応える。数え歌（いつつ）の先取り。
  - E2 失せ物の旅人: 荷車の持ち主を探す頼み。足跡のくぼみを辿り、日記の頁へ。筆跡が自分に似る（N1 の最初の 1 頁）。
  - E10 歩哨の巡回: 骨の歩哨が夜だけ骨の丘の近くを歩く（既存の敵。昼は眠る）。
  - E6 破れた頁の散布 12 枚。控え帳の「縁と頁」が埋まる。
  - 加えて E7（毎日 1 つ）、N2、N4。
- **スケールが大きくなるところ**:
  - 地上の存在感: 日 2 骨（B8）→ 夜 2 歌（B9）→ 日 3 夕方に尾びれ（B10）に、「雲の下の影が一度だけ地面を横切る」を足す（岩鯨の体の影。巡礼者の影と形・濃さで区別。12 の 1.2 と同じ見分け方）。
  - 中盤の出来事: 岩鯨が初めて降りるとき、ちょうど空の影（巡礼者）が通る。**岩鯨が歌をやめ、世界が静かになる**（引き算の演出）。影が去ると鎖が降りる。見せるのは「巨神でさえ静かになる」。
  - 背の外: 背の飾り（背中の外側）に碑と頁を足し、体の中に入らなくても読める話を 3 つ。試練の数は増やさない。
  - NPC の筋: **イサナ**。追う理由を語りはじめ（ほのめかしのみ）、鯨骨の船長の日誌（`captain`）と繋がる。
- **山場**: 背の三つの試練 → 番兵長 → 岩鯨の心臓（今のまま。報酬・欠片 1/4）。
- **余韻**: 心臓が止まると岩鯨は空へ戻り、歌が一節だけ欠けて鳴る。碑文「この鼓動は地の底から預かったもの」。語り部の一言。段階 1、上限 21。
- **引き**: 夜、風に潮の匂い。干潟に足跡（二章の痕跡 = E11 の 1 拍目）。

### 1.5 二章 潮殻「引く海」（Lv 12 → 18、上限 21）

- **主題**: 待つ・読む。島が昨日と違う場所にある。
- **導入**: 心臓を止めた翌朝、宿りの井戸の水が少ししょっぱい（N3）。題字の札。
- **予兆 3 拍**: ①干潟の足跡と塩の積み石（痕跡）→ ②遠い貝の音（N4）、海鳥が一方向へ飛ぶ（間接）→ ③沖の島が昨日より動いている、甲羅の縁（一部）。
- **小要素**: 潮見の貝（08 の 2.6。未実装を**ここで作る**。海辺で呼べて、巨神の方角を示す）／漂着の荷（E1 の海辺版。箱と頁 1 枚。N1）／浜の潮の民の碑（地上で読める 3 枚）／塩の積み石の謎（E4 の海辺版。積み石の高さで干潮の刻を知る）。
- **スケールが大きくなるところ**:
  - 存在感: 一日二回の干潮の刻に、浅瀬へ寄る姿を遠くから見られる（08 の 2.3 のまま）。浜から見て「甲羅の縁が水の上に出る」ことが予兆の 3 拍目。
  - 中盤の出来事: **大干潮**。巨神が現れて最初の夜、海がいつもより遠くまで引き、浅い海底に遺跡の道が現れる。一度きり、安全に歩ける（水は膝まで。死なない）。道の先に 1 つ、潮の民の頁。
  - 背の外: 甲羅の上（外）の探索（08 の 3.7）に、潮鳴り石の頁と眺めの場所を足す。
  - NPC の筋: **語り部**。村の記憶が語られ、帳面の字が自分の筆跡に似ていると気づきはじめる（01 の「この字、どこかで見た気がする」）。
- **山場**: 三つの試練 → 潮招き → 潮殻の心臓（欠片 2/4）。
- **余韻**: 潮が戻り、水の底で何かが「下から押している」と碑が言う（「誰が押しているのか、下の深いところから」）。段階 2、上限 27。
- **引き**: 遠くの嵐が風に逆らって動く（三章の予兆 1 拍目）。

### 1.6 三章 雷翼「風に逆らう嵐」（Lv 18 → 24、上限 27）

- **主題**: 見誤り。「あれは空の影か?」（12 の 1.2。風の民も同じ誤りをした）。
- **導入**: 翌朝、風が逆向きに吹く。題字の札。風見鶏（12 の 2.6）が逆を指す（N3）。
- **予兆 3 拍**: ①一直線に焼けた岩・倒れた木の筋（痕跡）→ ②動物が低く伏せる（影と同じ仕草だが昼夜と音で区別）、遠雷（N4）→ ③嵐の稲妻に一瞬だけ翼の形（一部）。
- **小要素**: 風見鶏の丘（E9 の嵐版。いちばん高い峰が止まり木の候補。望遠鏡で嵐の動きを追う）／雷に焼かれた旅の荷（E1。N1）／避雷の塔の跡（避雷の柱の使い方を、バニラの避雷針で先に教える）／風の碑（地上で 3 枚）。
- **スケールが大きくなるところ**:
  - 存在感: 嵐の通り道が日ごとに近づく（3 日かけて）。巨神は雲の下の自分の嵐の中にいて、稲妻の光でだけ姿が見える。
  - 中盤の出来事: **巨神が影から隠れる**（12 の 1.2 の COWER を一度きりの見せ場にする）。巡礼者の影が通るとき、雷翼が峰に降りて翼で頭を覆う。**影と巨神を同時に見て、巡礼者の大きさを初めて知る**。巨神編でいちばんスケールの大きい場面。
  - 背の外: 竜骨の間の前の「羽根の門」周辺に外の探索（風の民の頁 3 枚）。
  - NPC の筋: **イサナ**。追う人から見送る人へ。夕立の刻に峰で一緒に待つ。乗るのは自分だけだと決める。
- **山場**: 風切り・雷・眼の間 → 雷獣 → 雷翼の心臓（欠片 3/4）。
- **余韻**: 嵐が割れ、一瞬だけ空が晴れる。雲の上にあの影がいたことを、見る者が（N2）空に向かって立つことで示す。段階 3、上限 33。
- **引き**: 畑の向こうの丘が少し近づく。灰が降る（四章の 1 拍目）。

### 1.7 四章 余燼「足もとから来るもの」（Lv 24〜27 → 30、上限 33、止めた後 40）

- **主題**: 下。空の恐怖が足もとの恐怖に反転する（深淵＝五章への橋）。巨神編の山場であり、余韻がいちばん長い。
- **導入**: 翌朝、地面が温かい。雪が円形に溶ける。題字の札。
- **予兆 3 拍**: ①灰が降る範囲・地面の温かさ（痕跡）→ ②地の底のうなり、井戸水がぬるい（間接）→ ③丘が昼に動く（一部）。
- **小要素**: 温石（13 の 2.6。未実装なら作る）／灰の民の炉跡（E1。N1）／灰降り観測点（E9 の灰版。灰の濃さの地図が控え帳に出る）／足もとの温かさ（自分の拠点の下だけ温かい。建築は触らない）。
- **スケールが大きくなるところ**:
  - 存在感: 灰の降る円が日ごとに広がり、最初の夜に初めて浮上して眠る。
  - 中盤の出来事: **夜の浮上**。丘が持ち上がって巨神の形になり、地面が一度だけ揺れる（見た目は粒と音。ブロックは崩さない）。眠った巨神の口が息に合わせて開く様子が、乗り込みの前に見られる。
  - 背の外: 火の井戸・背の飾り（13 の 3.7）に外の探索と頁。
  - NPC の筋: **語り部とイサナ**。鍵が一つだったこと、四つの欠片を持つ意味を二人が別々に語る。
- **山場**: 灰の道・鍛え・火守り → 灰の鍛え手 → 余燼の心臓（欠片 4/4）→ 天の鍵がそろう場面（`SkyKey`）。
- **余韻**: 巨神編の終わり。第五の詩（`fifth_verse`）、鍵が空ではなく足もとを指す。語り部が最後の一言。上限 40。
- **引き（五章）**: 鍵の指す方へ掘ると、鼓動が聞こえる（深淵。未着手）。ベータはここまで。

### 1.8 五章 深淵／六章 月／終章 雲海

- 内容は変えない。名前と順番だけ繰り下げる（旧 2 章 → 五章、旧 3 章 → 六章、終章はそのまま）。
- 巨神編の型（題字・予兆 3 拍・中盤の出来事・余韻）を使う。五章の入口が四章の引きと繋がる。

### 2.2 移行の方針（変更を最小にする）

1. **ID は据え置き**: 伝承 `chapter1/…`、クエスト、段階、上限、背のディメンション、コマンド `chapter1` は変えない。内部名の「chapter1」は「巨神編」の ID として残す（コメントで明記）。
2. **章の写像層を 1 か所に**: `story/Chapters`（新規、状態に触れない計算だけ）。`chapterOf(段階, 序章を終えたか, 鍵がそろったか) → 序章/一〜四章/五章…`、章の名前キー、次の章。通知・クエストログの見出し・控え帳・空の異変の段はここだけを見る。**保存は増やさない**（段階から毎回導く。既存ワールドに移行が要らない）。
3. **伝承の章**: 新しい章 ID を足す（`titan_whale/tide/storm/ember`、順番 1〜4）。53 項目の `"chapter"` 欄だけをスクリプト（`tools/` に 1 本）で振り分ける（ID と本文は変えない）。`chapter2`・`chapter3` は順番を 5・6、`finale` を 7 にして、言語で「五章」「六章」「終章」。旧 `chapter1` の章定義は消す（項目が 0 になるため）。自己テスト 2 か所を直す。人ごとの保存は ID だけなので何も壊れない。
4. **クエスト**: ID は変えず、`QuestDef` に任意の `"chapter"` 欄を足し、クエストログの見出しとメインの目的の帯に章名を出す（クライアントの画面は 1 か所）。古い JSON は欄がなくても動く。
5. **章の演出**: 題字と余韻は `Notice`（18）、予兆 3 拍は序盤の拍子と同じ形の小さな枠（`story/arc/`、人ごとの段階をキーにする。拍の完了は伝承の書の記録で数えるので、順番を外しても詰まらない）。拍は冪等で、すでに先の段階にいる人には出さない。
6. **小要素の生成**: 章が開いたときに `SiteJob` で建てる（ワールド生成ではない）。基準は**野営地ではなくその人の拠点（ベッド、なければ復活地点、なければ今の位置）**。拠点から 150 ブロック以内に扇形 3 方向で探し、拠点から 300 ブロック以上離れた人には進行方向 60〜120 ブロック先に 1 つ（高さと群系だけで決める。チャンクは作らない）。`SiteData` に「章 n の分は生成済み」の印を持つ。
7. **設計書**: 章の呼び名を揃える（「1 章」→「巨神編」、「2 章」→「五章（深淵）」、「3 章」→「六章（月）」）。コード内コメントの「2 章」「3 章」は触らない（触るなら最後に一括）。

### 2.3 既存ワールドの扱い

| 場面 | 扱い |
| --- | --- |
| 段階・伝承・クエストの保存 | そのまま。章は段階から導くので、読み込み時に正しい章になる |
| すでに先の章にいる人（例: 段階 2） | 過去の章の予兆・小要素は出さない（遠景として残るだけ）。今の章の分だけ、最初のログインで生成する |
| 序盤を終えた人（legacy） | 題字の札は出さない（`OpeningState` の legacy と同じ扱い）。今の章の小要素は出す |
| 新しい世界 | 序章から全部走る |
| 古い世界で建物がすでにある所 | 小要素は建てる直前に実際のブロックで確かめる（`SiteFinder` と同じ。水・人の建物を避ける） |
| 「N1 の頁」「小要素の経験値」 | 持っていない人にだけ渡す（`LORE_XP` の記録済みを見る） |
