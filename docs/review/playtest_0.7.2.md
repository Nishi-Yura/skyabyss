# 試遊 0.7.2 の確かめ順

0.7.1 の試遊（2026-10-27）の声を受けて入れたもの。大きな変更は五つ:
- **試練で即死しない**: 巨神の背の試練の部屋に入った瞬間に倒れていた不具合を直した（世界の縁が部屋より内側にあった）。
- **ブロック以外の品はすべて mod の品**: 盾・採集の道具・防具、薬・食べ物・矢、素材と道具類（羅針盤・海図・舟・水筒など）。
- **市の四人**: 道具屋・食料屋・武具屋・素材屋。薬師は薬だけ。
- **名のある強敵の棲み家**: 地図に髑髏の印、光の柱。巨神が早く休む（鯨が降りてくる）。
- **クエストの見直し**: 初日のお使いと風の道の旗を消し、墓守を 2 段に、時刻で閉じる二本をいつでも行ける形に、折れた剣は自分の得物を研ぐ形に。報酬はみな mod の品。

## 0. 始め方（全員）

- **新しい世界で始めること。** 専用サーバーは `server.properties` に `level-type=skyabyss\:continent` を書いてから世界を作る。
- jar は `skyabyss-0.7.2.jar`（サーバーと全員のクライアントに同じもの）。
- 前の版の世界で入ると、狭まっていた世界の縁は元の広さに戻る（試練に入れるように）。

## 1. はじまりの島

- 初めの持ち物が「初めの旅装」（革の胴着の 4 つ）と麦のパンになっているか。
- 弓の職を選ぶと「旅の矢」が来るか。射った矢が mod の絵で飛び、拾うと旅の矢に戻るか。
- 「白く霞む丘」の寄り道が出ないか。

## 2. 鐘の都の市

- 市に四人が並ぶか（道具屋・食料屋・武具屋・素材屋）。
- 武具屋に旅の盾・鉄張りの旅装・空石の鱗の胴、道具屋に伐り斧・鶴嘴・土掘り・小舟・方位盤・海図、食料屋に麦のパン・干し魚・蜂蜜の小壺、薬師に 7 つの薬があるか。
- 旅の盾を左手で構えられるか。着た防具が 3D で見えるか。

## 3. 採集

- 斧で丸太、鶴嘴で石と鉱石、土掘りで土・砂・砂利・粘土が採れるか。素手では採れないか。
- 鉄鉱石から「鉄の塊」、銅鉱石から「銅の塊」が出るか。素材屋が買い取るか。
- 瓢箪の水筒を水場で使うと水入りになるか。

## 4. 地図と道

- 旅の地図に、名のある強敵の髑髏の印が土地ごとに出るか。近づくと棲み家に現れ、光の柱が見えるか。
- 町の四つの門すべてから道が出ているか（使わない門からは近くの見どころへ）。

## 5. 巨神と試練

- 岩鯨を見つけると、すぐ降りてくるか。
- 巨神の背の試練の部屋に入っても倒れないか（一人でも）。

## 6. クエスト

- 二章: 小舟で沖の難破船へ渡れるか。大干潮が昼でも起きるか。
- 三章: 「空の石」を市で手に入れて済むか。峰で待つと雷翼が降り、「峰の足もとで」が進むか。
- 四章: 火除けの薬を 2 つで「火除けの薬」が済むか。
- 墓守の頼みが二つ（花と水、足跡と蝋燭）になっているか。
