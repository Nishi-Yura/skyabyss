# 武器の 3D と動きの見直し (2026-10-23)

- 依頼: 「武器のモデルによってはインベントリの texture と見た目違うことある。3D モデルの方に合わせて」。あわせて、武器の 3D と動きを、いちばんよくできた武器の水準へそろえる。
- 基準にした武器: **鯨骨の大剣** (`whalebone_greatsword`)。段ごとに「構え → 溜め → 溜めの止め → 当たり → 振り抜き → 収まり → 戻り」の 7〜8 キー、体 (BY・LEAN)・光 (GLOW)・軌跡 (TRAIL) をすべて使う。メッシュは面取り・柄と鍔の輪・宝石・光る線 1 本 (D2)。
- 見たもの: 低ポリのメッシュをアトラスごと写した絵 (`tools/rough/lowpoly/weapons/icon_from_mesh.py`)、ゲーム内の撮影 `tools/shots/weapon_quality.txt` (全 17 武器を品の階級で。一人称の構え・連撃 3 段の止め絵・点検、三人称の構え・横・振り、盾の構え、弓 2 本の引き、持ち物の画面)。まとめは `python tools/sheets/weapon_quality_sheet.py` → `docs/review/weapon_quality/`。
- 動きの数の表は `weapon_moves/*.json` から (段のキー数、溜めの止め・収まり・光・体の傾きの有無)。

## 1. アイコン (インベントリの絵) と 3D の食い違い

比較シート: `docs/review/weapon_icons_v2/compare_weapons.png`・`compare_accessories.png` (3D | 旧 | 新)。3D の写しは `ref/<id>_ref.png`、32px の案は `ref/<id>_auto.png`。

| 品 | 食い違い | 対応 |
|---|---|---|
| 潮殻の三叉槍・珊瑚の銛・潮招きの大鋏 | 旧は細い棒の絵。3D は返し・珊瑚・殻の大きな頭 | 3D から描き直し |
| 珊瑚の盾 | 旧は赤い丸盾。3D は真珠と緑の扇の殻 | 表 (-Z) から描き直し |
| 雷翼の弓・羽守の鉤槍・雷獣の爪 | 旧は細い弓・杖・三本爪。3D は翼の羽・銅の刃・羽の扇 | 描き直し (弓は弧が左上のバニラの向き) |
| 余燼の戦斧・鍛え手の大鎚・灰被りの火掻き | 旧は木の柄の斧・槌・細い火かき棒。3D は玄武岩の頭・鎖・熾火 | 描き直し (下の 3.1 の明るさ直しのあとの 3D から) |
| 鯨骨の大剣・番兵長の鉾・水路の牙 | 形は同じだが旧は左右反転 (刃先が左上) | 刃先を右上 (バニラの剣と同じ) にそろえて描き直し |
| 深淵の灰鎌 | 刃の形が違う (旧は太い曲刃) | 描き直し |
| 深淵の大剣・沈み鐘の杖・雷淵の弓 | 形・色とも 3D と合う手描き | **そのまま** (`KEEP`) |
| 装飾品 16 点 | 旧は平絵の時代の絵 (青い玉・丸い札・円盤など)。3D は枠・吊り輪・羽・灯 | 3D (表から) で描き直し |

描き方: 3D を品の向き (武器は z まわり -45 度、盾と装飾は立てたまま) で 8 倍に写し、升ごとの中央値 → 14 色 (光る画素は別に 4 色) にまとめ、孤立した 1 画素をならし、左上の縁を明るく・右下を暗く、外に暗い 1 画素の縁。暗い品は平均の明るさ 78 まで持ち上げる。強化 (+5・+10) はアイコンを変えない (メッシュの階級も品ごとに固定) ので、品ごとに 1 枚。

## 3. 直したこと

### 3.1 余燼の 3 武器の色 (`tools/rough/lowpoly/weapons/paint.py` の `lift`、`build_storm_ember.py` の `EMBER_LIFT = 0.14`)
玄武岩 (main)・鉄 (edge・spine)・焦げ岩 (guard・acc) の段を 0.14 上げる (パレットのおよそ 1 段)。割れ目の光と階級の縁の色はそのまま。`python build_storm_ember.py ember_war_axe smith_hammer thrall_poker` → `python tools/install/install_lowpoly_weapons.py`。

### 3.2 灰被りの火掻きの鉤の先
鉤の曲線の先の太さを 0.2 → 0.5 にして先を閉じ、伝説の熾火の塊 (gem) を抱えて見えるようにした (`item_thrall_poker.py`)。

### 3.3 連撃の段の仕上げ (`tools/gen/items/gen_weapon_moves.py` の `POLISH`・`polish_step`)
キーが 5 つの段に、当たる時刻を変えずに次を足す: 溜めの止め (溜めと当たりの間の 55%、溜めを 6〜8% 深く、linear)、収まり (振り抜きから戻りの 70%、out。最後の戻りは smooth)、段に無ければ光 (当たり 0.6・振り抜き 0.25) と体の傾き (溜め -2・当たり 4・振り抜き 3)。対象は水路の牙・雷獣の爪・灰被りの火掻きの全段と、三叉槍・銛・大鋏・鉤槍・大鎚・灰鎌・鐘の杖の 2 段目。

### 3.4 道具の直し
`tools/install/*.py` ほか 12 本の `sys.path` の足し方 (`('../lib')` が文字の並びになっていた) と、`tools/lib/mesh_close.py` が `tools/audit/mesh_audit.py` を見つけられなかったのを直した (repo-tidy のあと、武器の取り込みが動かなかった)。

## 4. 残した弱いところ (次の候補)

- 雷獣の爪: 羽の扇が混み合い、握りと爪の関係が弱い (前の診断の tweak)。メッシュの組み直しが要るので今回は動きだけ。
- 深淵の灰鎌: 368 面で一番薄い。刃の内側の縁の光を 1 本足すと鎌と読みやすい。
- 潮殻の三叉槍の一人称: 構えで穂先が画面の右下を大きく占める。display の一人称の倍率を 0.9 倍にする案。
- 番兵長の鉾・羽守の鉤槍の 1 段目と、深淵の大剣の両段: 溜めの止めのキーが無い (7〜8 キーなので軽さは目立たない)。
