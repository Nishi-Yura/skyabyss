# 試遊 0.7.0 の確かめ順（マルチ）

0.6.0（2026-10-25）のあとに入れたもの。大きな変更は五つ: **新しい敵 16 体と名のある強敵 6 体**（バニラの敵は出ない）、**作らない遊び**（作業台なし。鍛冶場の誂え）、**都と同じ作りの土地の町**、**一品一案の武器と防具**、**語りの紙芝居**（開幕と章の変わり目）。進捗の画面は控え帳の「記し」に替わった。

## 0. 始め方（全員）

- **新しい世界で始めること。** 専用サーバーは `server.properties` に `level-type=skyabyss\:continent` を書いてから世界を作る。jar は `skyabyss-0.7.0.jar`（サーバーと全員のクライアントに同じもの）。
- 初めて入ると、黒い画面にドット絵の紙芝居（9 枚・およそ 45 秒）が流れる。クリックで進む、Esc で飛ばす。そのあと、まぶたが開いて目を覚ます。**人ごとに流れるか**（ほかの人が見ている間、見終わった人は動けるか）。途中で抜けて入り直すと、最初から流れ直すか。
- 管理者向けの試遊の命令: `/skyabyss dev named`（今いる土地の名のある強敵をそばに出す）、`/skyabyss reel opening`・`/skyabyss reel chapter_titan_whale` など（語りを見直す）、`/skyabyss play`（章・場所へ飛ぶ。37 の木）。

## 1. はじまりの島（15 分）

- 野営地で**先に職を選ぶ**画面が出るか（石の剣は渡されない）。選ぶまで島の道と野盗が始まらないか。
- 島の端の砂・砂利が落ちてこないか（道がふさがらない）。爆発で地形が壊れないか。
- 峠の野盗が新しい姿か: 野盗（鉈・頭巾）・野盗の弓手（編み笠）・名札の「峠の頭目」（大きな手斧）。どの技も**床に予告が出てから当たる**か。予告の外へ出れば当たらないか。
- 頭目が斧を掲げて吠えると、まわりの野盗が速くなるか。体力の減った野盗が斬ったあと後ずさるか。
- 島の草地に穂かじり鼠の群れ（昼）、夜に迷い灯（浮く。明滅で視界が暗くなる）が出るか。

## 2. 都と土地の町（15 分）

- 町めぐり（鍛冶場 → 宿 → 道具屋 → 組合）で、着いたら次へ進むか（前は「鍛冶場へ向かおう」で止まった）。
- **作業台で何も作れない**か（レシピが無い）。鍛冶場の人の「誂え」で、章の装備や品を素材と鐘銭で頼めるか。薬師・道具屋にも誂えの品があるか。
- 土地の町（鯨見・汐守・風待・灰炉）が、都と同じく壁・四つの門・広場・宿・鍛冶場・道具屋・薬師・社・町家のある大きな町か。中に敵が来ない・壊せない（都と同じ決まり）か。
- 土地の町に初めて入ると「記し」の町の行が済になるか（L）。

## 3. 野の敵と名のある強敵（20 分。みんなで）

- 土地ごとに出る敵（設計書 44）: 草原 = 鼠（昼）・迷い灯・骸の歩兵・骸の弓兵（夜）・野犬（森、群れ）、岩鯨の丘 = 今までの敵＋苔の亡者（夜）、潮の浜 = 霧の漁り火（夜、浜・沼）、嵐の高地 = 雷狼（夜、群れ）。**バニラのゾンビ・スケルトン・クリーパーが出ない**か。
- 町と道の上に敵が湧かないか。四人で固まっても敵が多すぎないか（一人のまわり 64 に 10 体まで）。
- 骸の歩兵は前からの攻撃を盾で受けて、横・後ろが弱いか。骸の旗手（亡者の野営）が旗を突き立てると、そばの骸が一度だけ起き上がるか。
- 野犬の群れの一頭が吠えると、ほかの野犬が一斉に跳ぶか。雷狼が吠えると狙われた人の足もとに雷の円が出るか。
- 霧の漁り火の網（円）で鈍るか、灯を揺らすと目がくらむか。苔の亡者の胞子で毒と鈍足になるか。
- **名のある強敵**: 土地にいると、まれに（平均 3 分に一度ほど）一体だけ現れて「近くに名のある強敵が現れた」と出るか。名札と画面上の体力の帯（40 ブロック以内の人みなに）が出るか。倒すと**そばの全員**に鐘銭と「記し」が付くか。島 = 峠の頭目 赤帯、草原 = 最後の旗手（夜）、岩鯨 = 岩背の大猪、潮 = 潮招きの大蟹、嵐 = 雷角の大羊、灰 = 灰被りの大蜥蜴。待てなければ `/skyabyss dev named`。
- 大物の技: 大猪の突進（床の長い帯）と背の震え（円）、大蟹の叩きつけと泡（押し流し）、大羊の突進と雷の輪（足もとは安全）、大蜥蜴の火を吐く扇と尾の輪（体のすぐそばは安全）。強すぎ・弱すぎ・わかりにくい所。

## 4. 装備（10 分）

- 防具 8 組（巨神 4・旅装 4）が一品一案の新しい形か。絵（アイコン）が 3D の形と合っているか。
- 職の武器・伝説の武器・五章の武器が新しい形か。伝説は深淵からだけ出るか。

## 5. 記し（L）と控え帳（B）

- L で、バニラの進捗ではなく控え帳の「記し」が開くか。一覧（全体と分けごとの数・帯）と、旅・巨神・強敵・成長・町の頁。行を選ぶと右に説明と報酬が出るか。まだ見えない記しは「？？？」か。
- 島の段（戦い方を選ぶ・足あと・峠・海を渡る）・都めぐり・土地の町・名のある強敵で、その人の記しが済になるか。鐘銭がもらえるか。
- バニラの進捗のお知らせ（石器時代など）が出ないか。

## 6. 章の変わり目の語り

- 一章の題字（「一章　岩鯨」）の前に、5 枚の紙芝居が流れるか。見終わる（Esc で飛ばす）と題字が出るか。
- 先の章の語り（二〜四章）は `/skyabyss reel chapter_titan_tide` などで見られる。文の長さ・読みやすさ・絵が伝わるか。

## 気になったら教えてほしいこと

- 物語が伝わったか（開幕の語りのあと、何のために島から都へ行くのかわかったか）。
- 敵の数・強さ・予告の見やすさ。名のある強敵が出る頻度（多すぎ・少なすぎ）。
- 誂えで欲しい品が手に入ったか（足りない品）。
