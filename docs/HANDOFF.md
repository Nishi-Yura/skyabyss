# 作業の引き継ぎ（2026-10-20 時点・0.2.2）

別の PC からすぐ再開するためのメモ。区切りがついたら、このファイルを書き直す。

## 0. 再開の手順

1. `git fetch origin` → `git checkout m1-sky-pass` → `git pull`
2. ブランチは `main` と `m1-sky-pass`。途中の作業（wip ブランチ）は無い。エージェントの worktree（`.claude/worktrees/`）の中身は全部 m1-sky-pass に取り込み済み。
3. ビルド: `./gradlew compileJava --offline`（初回は `--offline` を外す）。jar は `./gradlew build --offline -x test` → `build/libs/skyabyss-0.2.2.jar`。
4. 自己テスト: `SKYABYSS_SELFTEST=1 ./gradlew runServer`（一部だけは `SKYABYSS_SELFTEST_ONLY=<段の名前の頭>[,<頭>…]`。カンマで複数。合う段が無いとエラーで止まる）。**新しい level-name と `level-seed=4242`、`max-tick-time=-1`** で回す。結果は「5. 自己テスト」。
5. 設計書は `docs/design/README.md` から。未決 `docs/design/00_decisions_needed.md` は空。ユーザーに聞くことは下の「3. ユーザーの判断待ち」。

## 5. 続けるときの注意

- **やり方**: 大きな作業はサブエージェントに分けて並列（担当するファイルを分ける）。Haiku 5.5 は機械的な作業、Sonnet 5.5 は設計・モデル・コード・不具合調べ。各エージェントは worktree で動かし、終わったら m1-sky-pass に取り込む。エージェントの作業用スクリプトは共有の scratchpad ではなく自分の worktree に置かせる（名前がぶつかって別の worktree を書き換えた事故があった）。
- **見た目の決め方**: モブ・武器・防具・画面は、3 案のラフを選定ページで選んでもらってから作る。非立方体の低ポリ＋1 ブロック 32 画素のドット絵、軽さ重視。巨神ごとに形と色の言葉を分ける。公開は `Artifact` の publish に `files` で画像を渡す（公開するファイル名は `_` で始められない）。
- **設計書**: `docs/design/` は今の仕様だけ（決定ログは作らない）。00 はサブエージェントに触らせない。新しい未決は 200 番から。
- **自己テスト**: 毎回新しい level-name と `level-seed=4242`、`max-tick-time=-1`。並列のときは `server-port` と `rcon.port` をエージェントごとに分ける。重いと読み込みが間に合わずに落ちる段がある（岩鯨・墓・余燼の心臓・雷翼の網）。単独で流し直して通れば負荷のせい。`SKYABYSS_SELFTEST_ONLY=freequest` だけは落ちる（全体なら通る）。
- **通しの台本**: `tools/shots/first_hour.txt` は毎回新しい世界で（`run/shots/first_hour/saves/opening_first_hour` を消す）。`cmd tick rate 100` でサーバーを 5 倍にし、待ちは `waitgame <総 tick>`（`wait` はクライアントの tick）。会話・歩きの開発コマンドは `dev talk`・`dev opening goto`。同じ世界を `-PshotsName=first_hour` で開いて続きだけ確かめられる。足跡が建たない世界があるので、屋外で待つ所は `goto notebook`（野営地）にしてある。
- **撮影**: `./gradlew runShots -Pscript=tools/shots/<台本>.txt`。新しいワールドの 1 回目はカメラが間に合わないことがある（待ちを延ばした）。音は自動で 0。
- **テストで Minecraft を開くときは音量 0**（`runClientTest` と台本は自動）。
- **java を全部落とさない**。止めるのは自分が立てたプロセスだけ（ユーザーの CurseForge の Minecraft は絶対に止めない）。使っていない java（終わったエージェントのサーバー、古い Gradle デーモン）はこまめに止める。
- **ゲームの窓を OS のキー操作で動かさない**。ボスの通しのプレイはユーザーがする。
- **取り込みでよくぶつかる所**: `SelfTestRunner` の段の一覧、lang、`SkyAbyss.java` のコンストラクタの登録、`Config.java`、各背の `LAYOUT_VERSION`（岩鯨 15・潮殻 12・雷翼 10・余燼 9・雷獣の巣 3）、`combat/Telegraph`。両方を残す形で直す。
- **Windows の Python**: 日本語の長い行を含む .py を heredoc で渡すと文字コードで失敗することがある。ファイルに書いて `python <file>`。
- **古いワールド**: `LAYOUT_VERSION` を上げると次の起動で背が建て直され、試練の進みと休み場の記録が戻る。
- **版**: ネットワークの版 = mod の版。マルチは全員同じ jar が要る。
- **このメモの更新**: セッションの残りが少なくなったら、このファイルを今の状態に書き直して push する。
