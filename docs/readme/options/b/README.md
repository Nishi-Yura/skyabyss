  <img src="b_sky.png" alt="天と淵のあいだ　BETWEEN THE SKY AND THE ABYSS　v0.2.2。高さ Y320 から、下へ降りていく地図の始まり">
</p>

<p align="center">
  <em>空を、何かが通った。</em><br>
  <em>山より大きな影が、雲の上を、音もなく。</em>
</p>

<p align="center">
  Minecraft Java 版 1.21.1（NeoForge）向けの RPG mod です。<br>
  この頁は、空の高みから地の底の淵まで、上から順に降りていく地図です。<br>
  下へ降りるほど、遊ぶための細かい話になります。
</p>

<p align="center"><sub>ベータ版 v0.2.2　序章と四つの章、天の鍵がそろうところまで</sub></p>

<p align="center">
  <img src="b_storm.png" alt="Y280 雷雲。巨神は、四体。">
</p>

<p align="center">
  雲より高いところには、嵐をまとうものがいます。<br>
  空を泳ぐもの、海を歩くもの、嵐をまとうもの、地の底を泳ぐもの。<br>
  <b>一章 岩鯨　二章 潮殻　三章 雷翼　四章 余燼</b><br>
  巨神 1 体につき 1 章。背中はそれ自体がダンジョンで、三つの試練と、奥で待つ守護者がいます。
</p>

<p align="center">
  <img src="b_clouds.png" alt="Y220 雲海。旅の支度。">
</p>

<p align="center">
  雲の海を渡るには、これだけあれば足ります。<br>
  Minecraft Java 版 <b>1.21.1</b>　・　NeoForge <b>1.21.1</b>　・　GeckoLib（NeoForge 用）　・　Java <b>21</b><br>
  <sub>仲間と遊ぶなら、全員が同じ版の jar を入れてください。版が違うと、接続のときに断られます。</sub>
</p>

<p align="center">
  <img src="b_ground.png" alt="Y64 地表。はじめかた。">
</p>

<p align="center">
  <code>skyabyss-0.2.2.jar</code> と GeckoLib の jar を、<code>mods</code> フォルダへ入れて起動します。<br>
  サーバーなら、サーバーの <code>mods</code> にも同じものを。<br>
  新しいワールド、ピースフル以外の難易度で始めてください（6 人まで）。
</p>

<p align="center">
  目覚めるのは、人が去った野営地です。<br>
  遠い煙、鐘の音、道の脇の巨大な足跡をたどると、鐘の宿りに着きます。<br>
  迷ったら「目的の帯」を見るか、<kbd>U</kbd> でクエストログを。
</p>

<p align="center">
  <img src="b_sea.png" alt="Y62 海。手の動き。">
</p>

<p align="center">
  <kbd>J</kbd> ステータス　<kbd>K</kbd> 技　<kbd>U</kbd> クエストログ　<kbd>B</kbd> 控え帳（墓の場所もここ）<br>
  <kbd>O</kbd> パーティ　<kbd>H</kbd> 護符を使う　<kbd>N</kbd> 知らせの記録<br>
  <kbd>R</kbd> <kbd>G</kbd> <kbd>V</kbd> <kbd>Z</kbd> 技の枠 1〜4<br>
  <sub>キーは、設定の「操作」→「天と淵のあいだ」で変えられます。</sub>
</p>

<p align="center">
  <img src="b_under.png" alt="Y-40 地の底。見張り番のために。">
</p>

<p align="center">
  サーバーの管理者へ。<code>/gamerule</code> で決まりを変えられます。
</p>

<div align="center">

| ゲームルール | 内容 |
| :-- | :-- |
| `skyabyssStoryGate` | `false` で巨神の順番と乗る資格の決まりを切る |
| `skyabyssStoryLevelCap` | `false` でレベル上限を切る |
| `skyabyssPartyShare` | その場にいなかった仲間への経験値の分け前（50〜80 %） |
| `skyabyssDeathMode` | 倒れたときの型（0 墓 / 1 バニラ / 2 全部残す / 3 耐久だけ。既定 0） |
| `skyabyssHeartReentryLimit` | 戦いで倒れた人が戻れる回数（既定 3） |

</div>

<p align="center">
  <sub>墓まわりのルール（<code>skyabyssGrave*</code>）や、詰まったときの <code>/skyabyss</code> コマンドは、<a href="../../../beta_how_to_play.md">beta_how_to_play.md</a> にまとめています。</sub>
</p>

<p align="center">
  いちばん下は、まだ作りかけです。<br>
  マルチプレイは、人の手で通しの確認をしていません（特に 2 つのパーティが同じ背中にいるとき）。<br>
  雷翼と余燼は、巨神に乗って移動する旅がまだできません。<br>
  五章以降は、枠だけです。
</p>
