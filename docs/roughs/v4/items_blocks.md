# items_blocks 32x32: アイテム9種・武器4種・防具アイコン4種・ブロック12面 (3案)

ユーザーの指示「やっぱりブロックやインベントリでの texture 解像度 32*32 でいいかも」を受けて、採用済みの 16x16 を 32x32 にした。
形と配色は 16x16 の採用案のままにした。3案の違いは、増えた解像度の使い方だけ。

- 元の絵: アイテムとブロックは `docs/roughs/items_blocks/a/` (16x16 で採用された A 案)。武器は `docs/roughs/weapons/<名前>/a/icon.png`。防具は `docs/roughs/armor/a/{helmet,chestplate,leggings,boots}.png`
- 生成スクリプト: `tools/rough/items_blocks_32.py` (乱数なし。再実行で同じ結果)
- 素材: `docs/roughs/v4/items_blocks/<a|b|c>/item/*.png` (17枚) と `block/*.png` (12枚)。ファイル名は本実装と同じ (防具は `stone_whale_helmet.png` など)
- タイルの確認用: `docs/roughs/v4/items_blocks/<a|b|c>/preview/*_tile3x3.png`
- 比較シート: `docs/roughs/v4/items32.png`、`weapons32.png` (防具アイコンを含む)、`blocks32.png`。列は「現在の 16x16 | A | B | C」。拡大は 16x16 も 32x32 も同じ大きさにそろえた。右の小さい絵は GUI 倍率 4 の見え方 (灰色の枠の上)

## 共通の作り方

1. 16x16 の各色を「材質の段」に割り当てる (例: 骨 = 暗い順に5色、輪郭 = 1色)。割り当ては色を見て手で決めた (`SOURCES`)
2. Scale2x (EPX) で 32x32 にする。画素を混ぜない拡大なので、ぼけない。斜めの段差は自動でなめらかになる。輪郭の色は中身の色に削られないようにした (斜めの輪郭が切れないため)
3. 2倍で2画素の太さになった外の輪郭を、1画素に細くする
4. 案ごとの手直し (下記)

使う色は、元の段の色、隣の段との中間色、段の上下に1色ずつ足した色だけにした (C の輪郭と発光の照り返しは例外)。
ブロックは上下左右がつながる計算 (端の隣は反対側の端) で処理したので、継ぎ目は出ない。3x3 の並びで確認した。

## A 忠実2倍 + 手直し

- コンセプト: 16x16 をそのまま2倍にし、手で直すような処理だけを足す。16x16 と並べたとき、一番違和感が少ない
- 斜めのギザギザを Scale2x で直し、外の輪郭を1画素にした
- 段の境目に中間色を1段足した (広い面だけ。小さな鋲や穴は消さない)
- 光は左上。暗いもの (輪郭や溝) に接する縁を、左上は半段明るく、右下は半段暗くした。共鳴石の輪は、筒のように上が明るく下が暗くなる
- 骨ブロックの割れ線は、16x16 の線を1画素の線でつないで描き直した。左の壁に影の色を1画素添えて、太さと深さを出した
- 色数: 1枚あたり 3〜21 色 (平均 12)

## B 材質の描き込み

- コンセプト: A に、材質ごとの模様を手で置いた小さな型で加える。近くで見たときの情報量が一番多い
- 骨: 小さな穴 (暗い点と、右下の光る縁)。石: 短い横の筋と、その上の光る縁。結晶: 面の境目に光る稜線と斜めの筋。縄・柄巻: 2x2 の織り目。金属: 擦り傷の線。金: 光の粒。苔: 盛り上がりと窪みの粒。干し肉: 斜めの繊維
- 武器: 大剣の刃に骨の小穴と光の粒、槍と矢の柄に一定の間隔の巻き、牙に成長線
- 光沢: 結晶・発光・金属・金・骨の一番明るい塊の左上の角に、もう一段明るい光の点を置いた
- 型は 32 を割り切る大きさ (4, 8, 16) なので、ブロックの継ぎ目でずれない
- 色数: 1枚あたり 4〜22 色 (平均 13)

## C 柔らかい塗り

- コンセプト: A の明暗を、同じ材質の中だけでぼかして、なめらかな階調にする。塗り絵に近い柔らかさ
- 階調は半段ごとの色に落とす。中間の値だけ 2x2 の規則的な網点にした (ばらばらの点にはしない)。網点は、周り8画素が同じ材質の所だけに置く
- アイテムには、左上が明るい弱い傾きを全体に足した
- 輪郭は、隣の中身の暗い色に寄せた (左上の光の側は多めに寄せる)。割れ線と炉の黒も同じ
- 発光の周り1〜2画素を、発光の色にわずかに寄せた (2画素目は網点)
- 色数: 1枚あたり 3〜33 色 (平均 18)。混色のぶん、ほかの案より多い

## 防具アイコンについて

元の絵は v1 A の 16x16 アイコン。採用された防具は v2 B (装飾・彫刻) なので、32x32 では v2 B の目印を2つ、全案に同じ形で足した。

- 兜: 頭頂の段のついた鶏冠
- 胸当て: 中央の水色の結晶を囲む鯨骨の檻 (縦の骨2本と下の横骨)

配色 (石板の紺灰・鯨骨の帯・水色の結晶) は v1 A と v2 B で同じなので、そのまま使った。目印が不要なら、スクリプトの `ARMOR_HINTS` を空にすれば元の形だけになる。

## 見直し (シートを読んで直した点)

1. 1回目: ブロックが items32.png に混ざっていた → シートの分け方を直した
2. 1回目: 斜めの輪郭が Scale2x で中身に削られ、胸当てと結晶の下側の輪郭が切れていた → 輪郭の色を削られない色にした
3. 1回目: 共鳴の炉の底の鋲と縁が、中間色の処理で消えていた → 中間色は広い面 (奥に2画素以上続く所) だけに入れるようにした
4. 1回目: 割れ線が1画素で細く、16x16 より弱く見えた → 左に影の画素を添えた
5. 2回目: B の武器が A とほぼ同じだった (細い刃には型が入らない) → 刃と柄の向きに沿った描き込み (小穴・巻き・成長線) を足した。型は「同じ材質に囲まれた所」に入れるようにして、細い部分にも入るようにした
6. 2回目: C の網点が細い帯に入って、点線のように見えた → 網点は周り8画素が同じ材質の所だけにして、網点にする値の幅を狭めた
7. 3回目: シートの見出しが切れていた → 見出しを名前だけにした

## 残り・注意

- C のブロック (骨の側面、守りの石) は、横の帯の境目に網点の列が残る。近くで見ると布の目のように見える。気になる場合は、ブロックだけぼかしを弱くする
- 天の鍵の欠片は、16x16 の水色の模様の縁が不ぞろいなので、32x32 でもその凹凸が細かい突起として残る (元の絵に忠実)
- 武器は 16x16 でも細い絵なので、どの案でも 32x32 の差は小さい。違いが一番よく見えるのはアイテムとブロック
- 武器と防具の 3D モデルは「16x16 のアイコンの画素をボクセルにする」決まりで作っている。アイコンを 32x32 にする場合、3D との対応 (画素の密度) をどうするかは本実装の前に決める必要がある
- src/ は変更していない。git commit もしていない
