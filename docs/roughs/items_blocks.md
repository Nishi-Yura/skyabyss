# items_blocks: アイテム9種・ブロック12面 (16x16 ピクセルアート 3案)

生成スクリプト: `tools/rough/items_blocks.py` (手で置いた文字配列 + 案ごとのパレット。乱数なし。再実行で同じ結果)

## 案の方向

- **A (王道・バニラ寄り)**: バニラに近い彩度と明暗。左上光源、輪郭は暗い茶色や紺。共鳴の水色は落ち着いた #3fb8e8 系。
- **B (高コントラスト・共鳴強め)**: 輪郭を濃く、明暗の差を大きくする。共鳴の水色 (#00d8ff) を飽和させて発光を強く見せる。紫と赤も彩度を上げる。
- **C (くすみ・古代風)**: 彩度を落として、風化した石と青銅の色にする。金は緑がかった青銅、水色は抑えめ、苔は枯れた色。

## ブロック (12面、16x16 タイル可能)

各案、`block/*.png`。タイル確認は `preview/*_tile3x3.png` (3x3 に並べた図)、立方体は `preview/*_cube.png` (`voxel.render`、骨と共鳴の炉)。

- **crumbling_bone_top / side**: 小さな穴 (2x2) が 8px 周期で並ぶ骨。バニラの骨ブロック (同心円の年輪) と見た目が違う。側面は横の縞と穴。
- **crumbling_bone_*_cracking**: 上の通常の面に、黒い割れ線を重ねた版。割れ線は面の内側だけに置き、タイルの継ぎ目に出ないようにした。
- **resonance_stone**: 暗い石板に、水色の輪の紋様。
- **resonance_stone_active**: 同じ紋様の線を白っぽい水色に変え、周りを発光色で少し照らした版。
- **sealed_gate**: 紫の X 格子の封印。背景は暗い紫の石。
- **warded_stone**: 灰色の石積み。目地 (横の線) と、中央の小さな水色の紋。
- **resonance_forge_top / side / front / bottom**: 上は金属の縁と水色の核。横は水色の帯。正面は炉の口 (紫の枠に水色の光)。下は鋲のある板。

## 確認

- 立方体の重なり検査: 対象外 (2D テクスチャのみ。3D の部品は作っていない)
- タイル確認: 全12面を 3x3 に並べて、継ぎ目の段差がないことを目で確認
- 比較シート: `docs/roughs/items.png` (アイテム)、`docs/roughs/blocks.png` (ブロック)。列は A / B / C
- 見直し: シートを3回見て、次を直した
  - 干し肉を丸い塊から、平たい塊に変えた
  - 骨の面を、砂のような点から、周期的な穴の並びに変えた
  - 共鳴石の紋様を「2」に見える形から、輪の形に変えた
  - 立方体の面の法線 (向き) を直し、内側に凹んで見える不具合を解消した

## 残り・注意

- 案 B と C の一部は、色を変えただけに近い。方向の差は、A (王道) と B (強い発光) に比べると小さい。
- 共鳴の炉の上面は、輪の中心がやや小さく見える。本実装前に拡大して確認したい。
- アイテムの 3D は、ボクセルの厚みの決め方 (縁から内側へ) をそのまま使っている。段の差が強すぎないか要確認。
