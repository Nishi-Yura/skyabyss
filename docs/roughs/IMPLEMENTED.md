## GearLayer (武器を別モデルとして描く共通の層) と whalebone_captain 第4回

### GearLayer (`client/entity/GearLayer.java`)
- `new GearLayer<>(renderer, socketBone, gearName, Function<T,String> animation)`: `geo/gear/<gearName>.geo.json` + `textures/gear/<gearName>.png` を受け口の骨に描く。`textures/gear/<gearName>_glowmask.png` があれば AutoGlowingGeoLayer で光らせる (無ければ付けない)。アニメーションは `animations/gear/<gearName>.animation.json` の `animation.<gearName>.<名前>`。名前は関数が毎フレーム返す。繰り返し (loop / hold_on_last_frame) は JSON の設定に従う (RawAnimation.thenPlay)。
- モブ一体ごとに状態 (GearAnimatable, 自分の AnimatableInstanceCache) を WeakHashMap<Entity, …> で持つ。描画は GeoObjectRenderer の派生 (ブロック中心への 0.5 ずらしを除いたもの)。
- 位置: 受け口の骨の処理中 (GeckoLib が骨の変換を掛けた後) に、pivot へ移すだけ。武器モデルの原点 (0,0,0) = 握りの中心。向きは受け口の骨の回転。
- `GearLayer.item(renderer, socketBone, Function<T,ItemStack>)`: アイテムを THIRD_PERSON_RIGHT_HAND で描く (バニラの ItemInHandLayer と同じ回し方。受け口の回転 0 = 腕を下ろした手)。
- `GearLayer.item(renderer, socketBone, stackFn, ItemDisplayContext, Consumer<PoseStack> adjust)`: 表示の種類と、握りを受け口に合わせる変換を指定する。
- 注意: GeckoLib の BlockAndItemGeoLayer はそのままだと骨の回転を二重に掛ける。GearLayer.item はそこを上書きして一度だけにしている。
- `GuardRenderers.geo(ctx, name, scale, Consumer<GeoEntityRenderer<T>> extra)` を足した (モブごとに層を足す)。
