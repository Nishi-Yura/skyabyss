# 武器ラフ (weapons) v2

4 品目 × 3 案 (A 王道 / B 重厚 / C 異形) の 16x16 アイコンと、厚みの地図から作った 3D ボクセルのラフ。
生成: `tools/rough/weapons.py` (乱数なし、再実行で同じ結果)。

出力
- 素材: `docs/roughs/weapons/<品目>/<a|b|c>/icon.png` (16x16 RGBA) と `depth.png` (グレースケール。1 段 = 60 の明るさ)
- 比較シート: `docs/roughs/weapons_<品目>.png` (列 = A/B/C、行 = 16px 拡大 / 3D yaw30 pitch25 (520px) / 側面 yaw90)

厚みの決め方 (領域ごと。パレットの文字に 1 つずつ割り当て)
- 刃の縁・外縁 = 1、本体 = 2、稜線 (中央 1px) = 3、鍔 = 4、宝石 = 4 (発光)、柄頭 = 3、柄 = 2、柄の縁 = 1。
- 生成後、4 近傍がすべて違う孤立画素は、近傍の中央値にする (ギザギザ防止)。
- 縁の色は、本体と同じ色相で暗くした色 (暗い骨の茶、暗いスレート、暗い青緑)。ほぼ黒は使わない。

重なり検査: ボクセル生成のため立方体の部品は使っていない。`check_overlaps` の対象外。

---

## 1. 鯨骨の大剣 (whalebone_greatsword)
斜めに右上へ伸びる両手剣。刃は対角方向に約 4px 幅。鍔は刃に直角。柄と柄頭。

- **A 王道**: 明るい鯨骨色 (クリーム〜ベージュ)。中央に明るい稜線。縁は茶色の骨。鍔は茶の骨、柄は暗い革巻き。鍔の中央の宝石が水色に発光。
- **B 重厚**: 灰スレートの骨。鍔は濃い灰で縁の帯あり。柄は苔色。柄頭は灰。宝石が発光。
- **C 異形**: 青緑の骨。中央の稜線と宝石が発光する。鍔は青緑。

## 2. 番兵長の鉾 (captain_pike)
斜めの柄の先に刃と、左上へ張り出す大きな三日月の鉤。

- **A 王道**: 乳白の柄、骨色の刃と鉤。
- **B 重厚**: 灰スレートの刃と柄。柄の付け根に発光する宝石。
- **C 異形**: 青緑。鉤と刃の稜線が発光。

## 3. 水路の顎牙 (waterway_fang)
アビサルウナギの牙を削った短剣。形を 3 案で変えた。

- **A 王道**: まっすぐな短い刃。鍔なし。白い骨、青灰の縁、灰の柄。
- **B 重厚**: 返し (かえし) つき。刃の右下側に 3 つの返しが出る。血の染みた赤い稜線。柄は暗い茶。
- **C 異形**: 上がくるりと曲がった牙。背の線が発光する。柄は暗い青緑。

## 4. 骨棘の矢 (bone_spike_arrow)
矢じりが骨のとげになった矢。斜めの矢柄、左下に羽根。羽根の形も 3 案で変えた。

- **A 王道**: 白い骨の矢じり。羽根は 2 枚の斜めの帯 (白灰)。
- **B 重厚**: 返しつきの矢じり。発光する芯。羽根は濃い灰の一枚羽 (ふた筋の帯)。
- **C 異形**: 青緑の矢。切っ先が発光。羽根は魚の背びれ状の青緑の 2 枚。

## 残りの課題 (次の段階)
- 鉾 A/B/C は形が近い。鉤の形をさらに変える余地がある (B は別の鉤、C は二股など)。
- 3D の側面で鍔と宝石が厚い (厚み 4)。鍔の見え方はこのままでよいか確認が必要。
- 矢の A/B/C は、羽根の形と返しで差をつけた。矢じりの形はまだ似ている。
