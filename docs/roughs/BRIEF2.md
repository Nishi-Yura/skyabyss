# 第2回ラフの共通ルール (高解像度の3D)

docs/roughs/BRIEF.md のルールはそのまま有効。そのうえで、ユーザーの指摘を最優先で守る。

## ユーザーの指摘 (原文)
「3dのもっと解像度高く。ただ厚くしただけの見た目はやめてほしい。」

## これをどう解釈するか
- **解像度**: 3Dモデルの細かさを上げる。立方体の最小単位を 0.5 単位 (1/32 ブロック) まで使い、テクスチャ密度は「1単位 = 2画素」(1ブロック = 32画素) にする。geo の texture_width/height は実際の画素数で書き、面ごとの uv (per-face uv) で、各面に 立方体の大きさ×2 の画素を割り当てる。
  - ただしアイテム・ブロックのテクスチャ (16x16) は変えない。上げるのは3Dモデルだけ。
- **「ただ厚くしただけ」をやめる**: 平らな板・箱をそのまま厚くした形は不可。形を彫り出す。
  - 面の向きが変わる所 (角・縁・ふち) を、段 (0.5 単位の階段) で面取りして丸み・傾きを出す。
  - 板金は重ね (重なりではなく、段差で接する層)、縁の盛り上がり、鋲、溝、割れ目を、形 (立方体) と塗り (テクスチャ) の両方で入れる。
  - 骨は節・関節のふくらみ・細くなる軸を持たせる。頭蓋は眼窩のくぼみ・頬骨・顎の段を形で作る。
  - 布・外套は、裾に向かって段で広がり、裂け目を形で切る。
- 選ばれた案のデザイン (色・モチーフ・シルエット) は保つ。3案は「同じデザインの、作り込みの方向の違い」にする。例: A=忠実に高解像度化、B=装飾・彫刻を足す、C=形をより有機的・ダイナミックに。
- **立方体の重なりは禁止** (check_overlaps が空)。0.5 単位の部品も面で接するだけにする。
- 品質の目標は、参考画像 (色鮮やかなボクセルの剣) の作り込み。

## 道具
tools/rough/voxel.py をそのまま使える (per-face uv、小数の大きさの立方体に対応)。
大きいモデルは描画が遅いので、シートの解像度は必要に応じて下げてよい。

## 出力
- スクリプト: tools/rough/<subject>_v2.py
- 素材: docs/roughs/v2/<subject>/<a|b|c>/ (geo.json, texture.png, glowmask.png)
- シート: docs/roughs/v2/<subject>.png (列 A/B/C。左端に「前回の採用案」を比較用に1列足してもよい)
- 説明: docs/roughs/v2/<subject>.md (日本語。各案で何を高解像度化・彫刻したか、立方体の数、重なり検査の結果)
- シートは Read で必ず見て、少なくとも2回直してから完了にする。src/main は触らない。git commit しない。
