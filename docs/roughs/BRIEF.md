# ラフ作成の共通ルール (全担当が守る)

目的: 「天と淵のあいだ」(NeoForge 1.21.1, mod id skyabyss) の見た目を作り直す前に、対象ごとに **3案** のラフを作り、ユーザーに選んでもらう。この段階ではゲーム本体のファイル (src/main/**) を一切変更しない。

## 必須ルール
1. アイテム・ブロックのテクスチャはすべて **16x16**。
2. Mob・防具・ボスのテクスチャ密度は「モデルの1単位 = テクスチャ1画素」(バニラと同じ密度。1ブロック=16画素)。高解像度の塗りでごまかさない。
3. **立方体の重なり・埋まりは禁止**。部品どうしは面で接する (くっつく) だけにする。`check_overlaps()` が空リストを返すこと。回転させた部品も、相手に食い込まないよう関節で接する位置に置く (目で確認)。
4. 武器・防具の3Dは **16x16 のアイテムテクスチャにできるだけ沿う**。武器は「アイコンの画素をそのまま厚みのあるボクセルにしたもの」が基本で、段のある厚み (縁は薄く、芯は厚い) で立体感を出す。
5. 目標の品質: 色鮮やかな「ボクセル化したピクセルアート」の剣の参考画像 (段のある厚み、はっきりした配色、刃の明暗の帯、宝石の発光)。のっぺりした単色の箱、不自然な形、ノイズだけの塗りはNG。
6. 3案は、方向性がはっきり違うものにする (例: A=王道・素直、B=重厚・威圧、C=異形・神秘)。ただし世界観 (空を泳ぐ岩の鯨の背中の遺跡。鯨骨・岩・苔・水色の共鳴の結晶) から外れない。
7. パレット: 1つの対象につき色数を絞る (6〜12色)。輪郭は暗い色、光は左上から。

## 道具
`tools/rough/voxel.py` を使う (読んでから使うこと)。
- `extrude(icon16, depth=None, glow=None)` → ボクセル格子。`voxel_faces(grid, glow)` → 面。
- `load_geo(geo_json_dict_or_path, texture, glowmask=None, pose={...})` → 面。GeckoLib の geo 形式 (format 1.12.0、骨・pivot・cubes・box uv か per-face uv)。
- `render(faces, yaw, pitch, size)` → PIL 画像。`check_overlaps(geo)` → 重なりの一覧。
- `icon_big(icon16, px)`、`sheet(title, [(見出し, [画像...]), ...], note)` で比較シートを作る。
- 実行: リポジトリ直下で `python tools/rough/<あなたのスクリプト>.py`

## 出力 (担当ごと)
- 生成スクリプト: `tools/rough/<subject>.py` (seed 固定。再実行で同じ結果)
- 素材: `docs/roughs/<subject>/<a|b|c>/` に 16x16 アイコン PNG、geo.json、テクスチャ PNG など、選ばれたらそのまま本実装に使える形で置く
- 比較シート: `docs/roughs/<subject>.png` (横に A/B/C の3列。各列にアイコン拡大・3D の2方向以上)
- 説明: `docs/roughs/<subject>.md` (日本語。各案のコンセプト1〜3行、色、特徴、重なり検査の結果)
- 自分のシート画像は必ず Read ツールで目で見て、不自然な所 (浮き・食い込み・穴・つぶれた形) を直してから完了にする。最低2回は見直す。
- git commit はしない。src/main は触らない。
