# 岩鯨の甲殻 (armor) ラフ

岩の鯨の背で見つかる甲殻。石板の鎧に鯨骨の縁取りと、共鳴の水色の小さな光を付ける。
3案。シートは `docs/roughs/armor.png` (列 A/B/C)。素材は `docs/roughs/armor/<a|b|c>/`。

共通の決まり: テクスチャ 128x64 (1画素 = 1単位)。骨は頭・胴・右腕・左腕・右脚・左脚・右足・左足の 8 つ。
アイコンの形は `docs/roughs/vanilla_ref/iron_*.png` の輪郭を型にし、その中を石板・鯨骨・水色の模様で塗った。
3D の前面は、アイコンの画素をそのまま板にする (1 画素 = 1 単位)。アイコンの透明な所は輪郭色で埋める。
甲殻はプレイヤーの体の外側に置き、部品どうしは面で接する (重なりなし)。

注意: 脚は 4 単位幅で、前面の上 5 行 (腰の帯) は 3D に入らない (脚の高さ 6 単位のため)。

## A 王道・素直

- コンセプト: ヴァニラの兜・胸当て・脚絆・靴の形を、鉄灰の石板で作った。兜の前に鯨骨の帯、額の水色の結晶。胸の中央にも結晶。
- 色: 石板: 鉄灰 (M / L / D)。鯨骨の帯: 白 (W)。共鳴: 水色 (C / c)。
- 特徴: 形は一番素直。肩当ては 4x4 の箱で、腕の上に乗る。前面はアイコンの画素をそのまま板にした。
- 重なり検査 (check_overlaps): 0 件 (重なりなし)

## B 重厚・威圧

- コンセプト: 同じ形を、濃い板金と苔で重くした。兜の両側に角、胸の前に鯨骨の肋 (リブ) の板。腕は 1 単位太い。
- 色: 石板: 濃い鉄灰 (M / D)。苔: 深緑 (G / g)。鯨骨: 黄みの白 (W / w)。共鳴は少なめ。
- 特徴: 角と肋の板が、他の案より大きい輪郭を作る。角は前面のアイコンの外に出る。
- 重なり検査 (check_overlaps): 0 件 (重なりなし)

## C 異形・神秘

- コンセプト: 頭の上に背びれ型のクレスト、背中に噴気口の箱、つま先は前に出る鰭。ティール系のうろこ模様。
- 色: 石板: ティール (M / L / D)。鯨骨: 白 (W / w)。共鳴: 明るい水色 (C / c) を多めに。
- 特徴: 形はヴァニラに近いが、背びれ・噴気口・つま先の鰭で異形にした。左右は同じ形。
- 重なり検査 (check_overlaps): 0 件 (重なりなし)
