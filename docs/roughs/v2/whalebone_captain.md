## A 忠実・高解像度
B の形をそのまま 0.5単位で彫り直した案。3層の肩当て (段のある縁、上は苔)、骨の棘、竜骨の隆起と宝石、

鉾 (三日月の鉤)。

## B 装飾・彫刻
A に、骨板の彫り (斜めの溝)、頭骨の飾り 2つ (腰の前)、鎖 (左右の肩の下から垂れる輪)、棘を 3本ずつに増やした案。
- 箱: 1365 / 面: 3217 / 重なり: 0

## C 異形・非対称
左肩に大きな骨の成長 (3本)、右の角は途中で折れた短いもの、左の角は長い。背骨の棘は節ごとに高さを変え、
2か所に横の棘。竜骨は中心から右へずれ、右の肋から突き出し。苔と青い結晶を増やした。
- 箱: 1555 / 面: 3341 / 重なり: 0

- 脚が短く、体の下が細い。
- 鉾の鉤が小さい。
- 2回見直したが、まだ細部の完成度は低い。
