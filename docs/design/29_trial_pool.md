## 0. 要約

- **今**: 試練は巨神ごとに三つで固定。二周目からは「静かな試練」と既知の道で短くなるが、**同じ三つを同じ順で何度も遊ぶ**。ランダムなのは足場の並び・巣の場所・鏡の配置など「中の細部」だけで、何を遊ぶかは変わらない。周回しても新しい驚きが来ない（1 章）。
- **案**: 巨神ごとに **十二の試練のプール**（歩・智・闘の三つの枠に各四つ）。**周回（心臓を止めるたび）に、グループごとに各枠から一つ、合わせて三つ**を引く。初回の周は今の三つ（原型）で固定。二周目から引く。四周で巨神ごとの十二をすべて見る（2 章）。
- **さらに各試練に乱数の要素**: 配置の型・仕掛けの数字・敵の組・障害・任意の目標。まれに出る「稀」「極」の修飾は、素材が増える。同じ試練でも毎回違う遊びになる。引いた三つと修飾は**「試練の板」にアイコンで出る**ので、備えができる（2.5〜2.7）。
- **共有の背での収容**: 四十八の試練は **「セル」**（入口・出口・石の差し口・休み場の決まった口を持つ部屋）として背に**常設**し、グループごとの扉（`GroupGates`）で、引いた三つだけ開ける。水・鏡・溶岩のように世界が変わるセルは 2 レーン。ほかはグループごとの上書きと敵の持ち主で、同じ部屋に二つのグループが同時にいられる（2.4。26 の作りを使う）。
- **四十八の試練**は 3 章に一覧（巨神ごとに、名前・内容・核の仕掛け・一人／複数・乱数・流用）。今の十二の試練（原型）は全部残り、新しく作るのは三十六。
- **作り方**: セルの雛形（`TrialCell`）、修飾の機構、板、図鑑、検査（全変種を作って詰みを調べる）を先に作り（P1）、試練を 16 → 32 → 48 と増やす（5 章）。作業量はおよそ 68 エージェント日（4 並列で壁時間は約 3 週。26 の枠のあと）。
- **越えたあと（4.6）**: 試練を越えると、その試練の中にいる仲間だけが少し待って鼓動の間へ戻り、鼓動の間の碑がそのグループの画面で光る。越えた試練はそのグループには封じられる。分かれて進めば速く終わる。
- 採用した方針（6 章）: **各枠から一つずつ引く／常設のセル／初回は原型固定／修飾は全部見える／装備の確率は変えず素材と図鑑で報いる／岩鯨から 16 → 32 → 48**。

## 1. 今の試練と、周回で飽きる理由

### 1.1 今の仕組み（事実）

| 項目 | 内容 |
| --- | --- |
| 数 | 巨神ごとに三つ（岩鯨: 西・東・下、潮殻: 西・東・前、雷翼: 西・東・前、余燼: 西・東・南）。四体で 12 |
| 型 | 一つはアスレチックや運び（西）、一つは謎解きや工作（東・下）、一つは戦い（岩鯨の東・潮殻の前・余燼の南）。**雷翼だけ戦いの試練がなく**、中ボス雷獣が東の終わりにいる |
| ランダム | 足場の並び（岩鯨の西）、迷路の形（岩鯨の下）、巣の場所（潮殻の前）、鏡と受け羽の配置（雷翼の前）、水位の配置（潮殻の東）、島の並び・打つ順（余燼）。**いずれも「同じ試練の中の並べ替え」で、遊びの種類は変わらない** |
| 周回 | 初回は 21 の「初回の延長」（鐘楼・詰所・影・第二の広間など）で長い。周回（`keep.first_cleared`）は既知の道＋三つのうち一つが静かな試練（敵が少ない）。誓い（Vow）で自分に縛りを足せる（21 の 1.8） |
| 共有の背 | 背は巨神ごとに一つの共有。進みはグループ（パーティ・一人）ごと。扉・敵・心臓は閉じたグループだけが見る |
| 心臓を止めたあと | 巨神は眠り、運び出される。やがて鼓動が戻って目覚め、試練は新しい形で待つ（02 の 2.11・7.1） |

### 1.2 周回の問題

1. **何を遊ぶかが決まっている**。二周目に岩鯨へ戻ると「西は崩れる骨、東は番兵、下は灯」と分かっている。足場の並びが変わっても、跳ぶことは同じ。
2. **周回を短くする仕組み（既知の道・静かな試練）は、飽きを減らすが、驚きを増やさない**。20 分で終わるぶん、毎回同じ 20 分になる。
3. **試練の数が三つなので、増やすと「全部必須」になる**。一つ足すと初回が長くなる。選ぶ数と作る数が一対一で、作った分が全部毎回の負担になる。
4. **戦い・謎・足場の割合が固定**で、好みでない試練は毎周逃げられない。逆に好みの試練は、一周に一度しかない。
5. **雷翼は初回から戦いの試練が無い**ので、闘が好きな人は雷獣まで我慢する。

→ 解く方向は「作る数を増やして、選ぶ数は三つのまま」。必須の長さは変わらず、周回ごとに中身が替わる。

## 2. プール方式

### 2.1 全体像

```
巨神 1 体
  プール = 12 の試練 = 歩 4 + 智 4 + 闘 4      （3 章）
     │  周回（心臓を止めるたび）の最初の乗り込みで、グループごとに引く
     ▼
  今の周の三つ = 歩 1 + 智 1 + 闘 1          （初回の周は原型の三つで固定）
     │  それぞれに修飾（配置・数字・敵・障害・任意）を引く
     ▼
  試練の板に表示 → 三つを済ませる → 心臓
```

三つの枠は、遊びの種類の骨組み。**歩**は足・拍・運びで体を動かす試練、**智**は謎解きと分担で頭を使う試練、**闘**は戦いと護りで武器を使う試練。今の三つ（西・東・前）がおおむねこの三種なので、「三つ遊ぶ」という形は変えない。

七つの類（渡る・拍・運ぶ・解く・合わせる・戦う・護る）は、枠の中の味付けで、図鑑と板のアイコンに使う。

| 枠 | 類 | 遊びの芯 |
| --- | --- | --- |
| 歩 | 渡る | 足場・道を読んで渡る（アスレチック） |
| 歩 | 拍 | 周期・拍に合わせて動く（タイミング） |
| 歩 | 運ぶ | 物（真珠・熾）を壊さず届ける |
| 智 | 解く | 仕掛けを理解して解く（謎解き） |
| 智 | 合わせる | 同時・分担で解く（協力。重り・留め・時間で一人でも解ける） |
| 闘 | 戦う | 敵を倒す（広間・巣・闘技場） |
| 闘 | 護る | 運ぶ物・隊列を敵から守る（護送） |

### 2.2 引き方の決まり

「周回」は、そのグループが**その巨神の心臓を止めるたびに一つ数える**（`keep.clears.<巨神>`。周回の番号は 1 から）。

1. **周回 1（初回）は今の三つ（原型）で固定**。引かない（原型は「引いた」扱いでプールの履歴に入る）。21 の「初回の延長」は原型にだけ付いているので、初回の長さ・場面・宝は今の設計のまま。雷翼だけ 歩1・智2・闘0 になる（この周だけ枠の決まりを外す）。
2. **周回 2 から、枠ごとに引く**。各枠のプールから、**その枠でまだ引いていない試練**（`keep.pool.<巨神>.<枠>`）を候補にする。**プールが尽きたらその枠だけ**、直前に引いた試練を除いて元へ戻す（尽きるのは、どの巨神も歩と智と闘は周回 4。雷翼だけ、智は周回 3、闘は周回 5）。
3. **各枠から一つずつ**。三つの試練は必ず歩・智・闘の一つずつ（雷翼の初回だけ例外）。したがって**三つの類はいつも違う**（渡る＋解く＋戦う、拍＋合わせる＋護る、…）。三枠のうち二つが似る事故はない。
4. **難度の段**（2.3）で候補を絞る: 周回 N のとき、段が N 以下の試練だけ。段が合う候補がなければ段の制限を外す。
5. **重み**: 段が周回と同じ試練は重み 1.5、それ以外は 1.0（上がるときに難しいものが当たりやすい）。
6. **種**: `seed = hash(世界の種, グループの鍵, 巨神, 周回)`。グループの鍵はパーティなら `partyId`、パーティでない一人なら `playerUUID`。枠ごとに `seed + 枠` の乱数で引く。引いた結果は最初の乗り込みでグループの記録（`keep.draw.<巨神>`）に保存する。
7. **同じ周のうちは変わらない**。倒れて戻る・背を出て入り直す・試練のリセット（`epoch`）では、引いた三つと修飾は同じ。**足場の並びなど「箱の中の細部の種」だけ epoch で替える**（今と同じ）。
8. **パーティの出入り**: 記録はグループごと。パーティに入ると、パーティの記録（引いた三つ）に従う（10 の「記録ごと写る」）。パーティを抜けた人は、自分の記録が先の周の途中なら続きから、なければ新しく引く。パーティでの周回数と個人の周回数が違っても、引く種は「グループの鍵」ごとなので混ざらない。
9. **静かな試練**は修飾「静」として残す。周回 2 以降は、引いた三つのうち一つ（その枠は種で決まる）に「静」が付く。静の試練は敵が少なく、石は自分で鳴らす（今と同じ。08 の 7.2）。
10. **誓い（Vow。21 の 1.8）はそのまま**かかる。段（重さ）は修飾と別に数える。

> 擬似コード（枠 s ごと）  
> `cand = pool[s] − seen[s]; if empty: seen[s] = {last[s]}; cand = pool[s] − seen[s]`  
> `cand = cand.filter(tier ≤ cycle) or cand`  
> `pick = weightedChoice(cand, w = 1.5 if tier == cycle else 1.0, rng = hash(seed, s))`

### 2.3 難度の段

| 段 | 意味 | 効くもの | 素材の倍率 |
| --- | --- | --- | --- |
| ★1 | 学ぶ（原型と、やさしい新作） | 敵の数と体力は今の標準。猶予が長い | ×1.0 |
| ★2 | 手ごたえ | 敵 +20%、猶予 −15%、休み場が一つ少ない | ×1.2 |
| ★3 | 腕試し | 敵 +40%、猶予 −30%、任意の目標が出やすい。**予告の最短 0.8 秒は割らない**（既存の決まり） | ×1.5 |

- 段は**周回の数**で解禁される（周回 N で段 N まで）。**必要 Lv や装備では閉じない**。段は同じ巨神の中の相対で、巨神ごとの手ごたえの曲線（03）はそのまま。
- 段が上がるのは数字の標準が変わるだけ。**どの段も一人で解ける**（26 の原則）。
- 各枠の段の並びは `[1, 2, 2, 3]` か `[1, 1, 2, 3]`（3 章）。周回 2〜4 で、各枠は残りを一つずつ引くので、★3 は遅くても周回 4 で当たる。

### 2.4 セル：共有の背での収容

四十八の試練を、背に作る「**試練のセル**」（`TrialCell`）として扱う。

**セルの雛形（どの試練も同じ口を持つ）**

| 口 | 内容 |
| --- | --- |
| 入口 | グループごとの封印の扉（`GroupGates`）。引いていないグループには閉じて見える |
| 出口 | 試練を終えると開く、休み場へ戻る光る床 |
| 石の差し口 | 共鳴石・潮鳴り石・風鳴り石・熾り石のどれか。鳴らすとそのグループの「試練の記録」が済む |
| 休み場 | 一つ以上（段が上がると減る）。記録は試練の番号つき |
| 箱 | 縦横高さの決まった大きさの等級（M・L）。26 の部屋の拡大のあと、`dev backmetrics` で測る |
| 詰み防止 | 戻しの鏡・戻しの栓などの「戻す口」。`BuildAudit` が全変種で届くことを確かめる |

**背の中の並べ方**: 一体の背の試練の区域を三つの**広間（ホール）**に分け、歩・智・闘それぞれの広間に四つのセルを並べる。広間の真ん中のハブから各セルの入口へ（鼓動の間 → 三つの広間 → セル）。26 で作る体の「詰まった石」の空きを使う（岩鯨は足あとの 11% しか使っていない）。

```
            鼓動の間 ─ 試練の板
        ┌────────┼────────┐
      歩の広間   智の広間   闘の広間
     ┌─┬─┬─┬─┐ ┌─┬─┬─┬─┐ ┌─┬─┬─┬─┐
     │1│2│3│4│ │5│6│7│8│ │9│…│…│12│   ← 常設の 12 セル
     └─┴─┴─┴─┘ └─┴─┴─┴─┘ └─┴─┴─┴─┘
       引いた 1 つだけ入口が開く（グループごと）
```

**複数のグループが同じ背にいるとき**（26 の 4.4・10 の 10 章）:

- セルは**常設**（作り直さない）。グループごとの扉が「引いた三つ」だけ開けるので、グループ A が歩の W01、グループ B が歩の W03 を同時に遊べる。
- **世界が変わるセル**（足場が崩れる・水位・鏡・灰の道・溶岩など。四体で 19 室、巨神ごとに 4〜5。3 章の冒頭に一覧）は、同時に二つのグループが入ると互いの変化が見えてしまうので、**2 レーン**（同じセルを 2 部屋）にして、二つ目のグループは別の部屋へ。三つ目は 26 の待ち行列のとおり待つ（待ちの間の景色つき）。
- **世界が変わらないセル**（グループごとの上書きと敵の持ち主で動くもの。戦い・護送・多くの謎解き）は、同じ部屋に複数のグループが同時にいられる。敵・荷・光は持ち主のグループにだけ見える（`GroupOverlays`・`GroupOwned`）。
- 引いたセルの数は三つ。グループが歩き回って**引いていないセルの扉は閉じて見える**（見えるだけで中に入れない。手前の碑が一行言う）。
- 部屋数は、巨神ごとに常設の 12 + 2 レーン分の 4〜5 = **16〜17 室**。今の三室からは増えるが、26 で体が足あと ×2.6 になり、使われていない「詰まった石」が大半（岩鯨は 11% しか使っていない）なので入る見込み。足りるかは `dev backmetrics` で確かめる。

### 2.5 試練ごとの乱数（修飾）

同じ試練を毎回違う遊びにするため、試練ごとに五種類の修飾の「口」を持つ。

| 種類 | 何を変えるか | 例 | 出方 |
| --- | --- | --- | --- |
| **配置の型** | 部屋の骨組み。手で作った型 3〜4 つのうち一つ（手作り＋生成の組み合わせ） | 迷路の形・島の並び・鏡の配置・巣の候補地 | 必ず 1 つ |
| **数字の振り** | 猶予・周期・数・速さ。`やさしい／標準／きびしい` の 3 段（段の補正に足す） | 崩れの遅さ・鐘の周期・取っ手の猶予・波の数 | 2 つ（各 3 段） |
| **敵の組** | 同じ敵の種類の組み合わせ（新しい敵は足さない。26 の原則） | 剣と盾の波 / 弓と盾の波 | 戦う・護るの枠は必ず 1 つ。ほかは 0〜1 |
| **障害** | 余計な危険。**遊び方を変えるだけで入れなくはしない** | 落石・誤射・突風・小魚の群れ・噴気 | 0〜1（稀） |
| **任意の目標** | 達成すると報酬が増える（失敗しても進む） | 一度も落ちずに・無傷・手数を少なく | 0〜1（稀） |

**稀さ**: 引いた修飾の最大が、その試練の稀さになる。

| 稀さ | 出る確率（修飾 1 つごと） | 例 | 報いの上乗せ |
| --- | --- | --- | --- |
| 常 | 約 70% | 標準の数字、普通の配置 | なし |
| 稀 | 約 25% | 障害・任意の目標が付く。やさしい／きびしい | その巨神の素材 +1 個ずつ。任意の目標を達成するとさらに +1 |
| 極 | 約 5% | **鏡像**（配置を左右反転）、**逆走**（出口と入口を入れ替える）、**二つの障害** | 素材 +2、共鳴の欠片が 8% で出る |

| 深淵 | 引かない。**板のつまみで選ぶ**（転生 3 回以上の人が、グループごと。2.9） | 極のすべて（数字は一番きびしい・障害二つ・任意の目標）に、さらに数字の底上げ 15%。猶予・周期は短く、数・長さは 1 つ増える（底は解ける線） | 素材 +3、共鳴の欠片が 12% で出る |

- **組み合わせの数**: 一つの試練で、配置 3〜4 × 数字 9 × 敵 2〜3 × 障害 3〜4 × 任意 3〜4 ≒ **数百通り**。三つの組み合わせは 64 通り（歩 4 × 智 4 × 闘 4）なので、巨神ごとに **数万通りの遊び**になる。
- **状態は遊び方を変えるだけ**: 拍・潮・熱・時刻・天気・背の状態は、修飾としては「遊び方を変える数字」にだけ使う（凪／嵐の固定、満潮の別の道など）。**修飾が試練に入れなくする・解けなくすることはしない**（原則。26 の 2 章）。
- **解けない組み合わせを作らない**: 各試練に「禁止の組み合わせ」を登録し、生成のときに外す。検査は 5.3 の全変種の総当たり。
- 修飾の数は段で増える: ★1 は 3 つ（配置・数字 2）まで、★2 は 4 つまで、★3 は 5 つまで。

### 2.6 種と再現性

- 引き方も修飾も**種で決まる**（2.2 の 6）。同じグループが同じ周に同じ巨神へ来ると、同じ三つと同じ修飾。
- 運営側の再現（開発・試遊）: `/skyabyss trial draw <巨神> <グループ> <周回>`（開発用）で引き直し、`/skyabyss trial force <ID>` で試練を指定、`/skyabyss trial mods <ID> <修飾>` で修飾を指定する。試遊の `playtest trials` と併用。

### 2.7 読める札：試練の板

### 2.8 守ること

- **深淵も同じ決まり**（2.9）。数字の標準だけを上げ、一人で解け、時間・状態で閉じず、予告は変えない。

- **試練に状態の鍵をかけない**。全セルは常にそこにあり、引いたグループは引いた直後から入れる。待たせる条件は、世界の変わるセルの二グループ同時のときの 2 レーンだけ。
- **一人でも解ける**。協力の試練は、重り・留め・時間の三つの代わりで一人にも用意する。幕で広間を狭める（26 の判断 3）。
- **新しい敵の種類は足さない**。21 の敵（骨の砲手・老番兵・灯り魚・真珠守り・嵐の仔・羽守長・鞴持ち・大燠虫）を、26 の方針で配り直す。
- **心臓の戦いの内容は変えない**。ボスの扉（三つの石 → 心臓）は例外のまま。どの試練を引いても、石を三つ鳴らすのは同じ。
- **装備の確率と天井は変えない**（03）。報いは素材・図鑑・称号（4 章）。
- **戦いの部屋の強さは、その試練に入った人の数で決まる**（パーティの人数ではない）。広間の参加者・砦の中の人・干潟の中の人・火床の部屋の人を数える（`TitanBackTrials` の広間の参加者、`W10Fort.gunners`、`TideFlats.inFlats`、`EmberTrials.playersIn`）。パーティが分かれて別々の試練に入れば、それぞれの戦いは少人数のまま小さくなる。分かれて速く終える、がパーティの利点。

### 2.9 深淵（31 の B04。`abyss/Abyss`・`TrialDraw.abyssify`）

## 4. 報酬と周回

### 4.1 基本の報い

- **道中の落とし物**は今のまま（個人の抽選。02・08・12・13 の 6 章）。**装備の確率・天井・巨神の記憶は変えない**（03）。
- **試練の報い**（試練を済ませた人ごと。`TrialPool.onCleared`）: その巨神の素材を `基本 × 段の倍率（2.3）` ＋稀・極の上乗せ（2.5）。任意の目標を達成すると、さらに +1 と称号の数え。
- **初めて済ませた試練**（その人にとって）: 共鳴の欠片が少し出る。図鑑の札が一枚増える。全員に（パーティの途中参加も含め）人ごとに出る。
- **図鑑の完成**（その巨神の十二を一度ずつ）: 称号「〇〇の十二の試練」と、背の飾り（旅嚢に入る見た目だけの品）。四体 48 で称号「四十八の試練を渡る者」。

### 4.2 試練の図鑑

控え帳（11）に頁を足す。巨神ごとに十二枚の札（名前・類・段・済んだ回数・一番良い成績）。札は初めて**引いたとき**に名前だけ出て、**済ませたとき**に絵（枠のアイコン）と内容の一行が出る。さらに**出会った修飾の数**（その試練で見た修飾の種類 / 全部）が出る。

- 収集の動機: 十二のどれが残っているか・どの修飾をまだ見ていないかが見える。
- 図鑑は人ごと（共有しない）。パーティで済ませると、その人の分が全員に付く。

### 4.3 稀な修飾に報いる

- 稀・極・深淵は素材が増える（2.5・2.9）。**極は 5%** なので、一つの巨神を 20 周するうちに平均 1 回出会う。出会ったときの高揚を作るため、板で「極」の枠が光る。
- 任意の目標は成功・失敗が報告に出る（「一度も落ちなかった」）。達成率が称号の数えになる（例: 任意の目標 50 個達成）。

### 4.4 今週の試練

実時間の週ごとに、巨神ごとの十二の試練から一つを「今週の試練」にする（種 = 世界の種 + 週 + 巨神）。板の下に一行出る。

- **周回の引きとは別**。今週の試練は、引いていなくても**挑める**（常設のセルなので。扉が板の操作で開く）。
- **一人につき週一回**、済ませると素材が倍・共鳴の欠片が 1 回出る。
- **ロックではない**。今週の試練をやらなくても進行に影響はなく、やると少し得をするだけ。実時間の週は報いの上乗せにだけ使い、入れる・入れないには使わない（原則）。

### 4.5 ビルド（27）との関係

27 は案（未決）。27 が決まったあとの接続だけ書いておく。

- **試練の役割**（誘い・切り替え・運び・護り・射る・読み上げ）を、27 の木の技にひも付ける。例: 岩守り（護る・押さえる＝護送・闘技場）、風読み（拍を読む＝拍の試練の「先読みの線」）、潮歌い（合わせる・運ぶ＝連動を保つ）、灰の鍛え人（熱・炉＝余燼の鍛え・鞴）、骨の射手（遠くの切り替えを射る＝砲手の砦・回路）。
- **見せ場は近道だけ**。技があると速くなる・楽になるだけで、**技が無いと解けない試練は作らない**（原則）。どのビルドでも十二すべてが遊べる。
- **刻印・要は試練を選ばない**。引き方（2.2）には刻印も職も入れない（種は世界の種・グループ・巨神・周回のみ）。

### 4.6 試練を越えたあと（鼓動の間・碑・封）

背は巨神ごとに一つの共有で、進み・戸・敵の持ち主はグループ（パーティ・一人）ごとに別（`BackGroupData`・`GroupGates`・`GroupOverlays`・`GroupOwned`）。次の流れもグループごとに動き、同じ背にいる別のグループには触れない。

1. **越えた**（石が鳴ると。原型の石も新作の石も `TrialSteles.onRung` を通る）: 80 tick（4 秒）待つ。そのあいだに石の演出・素材・報いの知らせが出る。
2. **戻る**: そのグループの、**その試練の中にいる**人だけが鼓動の間（休み場 "hub"）へ戻される。別の試練にいる仲間・鼓動の間にいる仲間は動かない。「中」は試練ごとの範囲（`TrialRegions`。岩鯨の新作のセルは引いたセルの床の範囲）。**「真ん中へ戻る光」の手順（光の中でしゃがむ）はなくした**。心臓を止めたあとも、光は出さない（人は巨神に降ろされる。20 の 3.4）。
3. **碑が光る**: 鼓動の間に、試練の枠ごとに一つ、石の碑が立つ（岩鯨・潮殻・雷翼は 歩・智・闘の三つ、余燼は西・東・南。`trial_tablet`、`HubTablets`）。碑は鼓動の間の休み場のまわり（半径 4〜9）の開いた床から、決まった手順で選ぶ（作りが変わっても追う）。越えたグループの画面でだけ光る（見かけの上書き。当たり判定は同じ）。戻った人は **短い場面**（約 3.4 秒、カメラが碑へ向き直って寄る・鐘と水晶の音。`Scenes.TABLET_REVEAL`。台詞なし）を見る。場面中は無敵。始められないときは音と一行（「試練を越えた。鼓動の間の碑が光った」）だけ。これで「どこへ行って、どこへ行っていないか」が分かる。**最後の試練を中心の近くに置かなくてよい**（戻りは自動）。
4. **封**: 越えた試練の中へ入った人は、10 tick ごとの見張りで鼓動の間へ戻され、一行（「この試練は越えた。もう入れない」）が出る。**そのグループにだけ**閉じる（別のグループは同じ試練に入れる。越えていない試練にも入れる）。封は石の記録と同じ寿命で、心臓を止めて試練が戻るときに消える。観戦者・クリエイティブは対象外。
5. **一人でも**: 一人のグループも同じ。自分が越えた試練が封じられ、碑が光る。

範囲は鼓動の間・入口・宝物庫・心臓へ続く道を含まない。背の作りを変えたら、自己テスト `trial hub` が「石が自分の範囲の中・ほかの範囲の外／鼓動の間が全部の外／休み場が正しい試練の中」を確かめて知らせる。

## 5. 作り方

### 5.1 セルの雛形（`TrialCell`）

```
interface TrialCell {
  String id();                 // "W01" など
  Titan titan(); Slot slot();  // 歩・智・闘
  Category category(); int tier();
  BoxClass box();              // M / L
  boolean physical();          // 世界が変わる（2 レーン）
  List<LayoutVariant> layouts();           // 3〜4 の配置の型
  ModifierSpace modifiers();               // 数字・敵・障害・任意の口と禁止の組
  void build(Box box, LayoutVariant v, long seed);   // 常設を作る（版ごと）
  void arm(Group g, Mods m, long seed);                // 引いたグループ用に仕掛けを置く（上書き・敵・記録）
  void reset(Group g, long epochSeed);                 // 試練のリセット（細部の種を替える）
  Audit audit(LayoutVariant v, Mods m);                // 検査（5.3）
}
```

- 三つの原型は、今の `*Builder`・`*Trials` を `TrialCell` の実装へ薄く包む（内部はそのまま）。
- **グループの記録**（`BackGroupData.Record`）に、`keep.draw`・`keep.pool`・`keep.clears` を足す（引き方の保存）。

### 5.2 手作り・生成・組み合わせ

| 作り方 | 例 | 変種の作り方 |
| --- | --- | --- |
| **生成が中心**（箱の大きさから作る） | 足場の谷（W01）・迷路（W05）・灰の島（E01） | 種で毎回変わる。修飾は生成の数字に通す |
| **手作りの骨組み＋数字** | 鐘楼（W02）・噴気（W04）・回路（S05） | 配置の型 3〜4 を手で作る。数字は実行時 |
| **完全な手作り** | 影絵（W08）・標本棚（T08） | 配置の型は手で作り、部品（灯・柱・鉢）の置き場を差し替える |

- 部品の共通化: 「押す・引く護送」（W11・T11・E11・S11）、「重りで留める協力」（W07・T07・S07・E07）、「予告つきの周期」（W02・W04・S02・S03・E02）。これらは 1 つのクラスにして、各試練は数字の束を渡す。**作る量は 36 本ぶんの半分以下**になる見込み。
- **部品の再利用で新しい敵・ブロック・モデルは足さない**（26 の原則）。絵は修飾のアイコン 15 枚だけ。

### 5.3 検査（BuildAudit・到達の検査・自己テスト）

- **全変種を作って調べる**: 試練ごとに、配置の型 × 修飾の端の値の組（ペアワイズ網羅。全組み合わせではなく、「どの二つの修飾も、すべての値の組で一度は検査する」）を、生成器で作って調べる。数は 48 試練 × 配置 3〜4 × 修飾のペア ≒ **1,700 通り**。
- **調べること**: ①入口から石・出口までの到達（背の移動の決まりで経路探索。西の翼なら跳躍できないなど）、②詰みがない（戻す口が全変種で届く）、③箱の外へ何も置かない・液体が漏れない、④休み場に入口から届く、⑤任意の目標が達成可能、⑥一人の人数で全部できる（幕の内側で到達）、⑦熱・水位・拍など数字の収支（余燼は `EmberHeat`）。
- `SELFTEST trial pool`: 引き方（枠ごと・段・重み・プールの尽きと戻し・種の再現・パーティの出入り・初回の固定・雷翼の例外）、全セルの全変種の生成と到達、修飾の禁止の組が出ない、板の表示データ（三つ・修飾・稀さ）、図鑑の更新、報い（素材の倍率・稀の上乗せ）、週替わりの種。

## 7. 守ること（書き手の確認）

- 試練に状態の鍵をかけない。ボスの扉だけが例外（26 の 7 章と同じ）。

- 心臓の戦いの内容、天の鍵の流れ、初回の延長（原型に付く）は変えない。
