## 0. 要約

- **今**: 試練は巨神ごとに三つで固定。二周目からは「静かな試練」と既知の道で短くなるが、**同じ三つを同じ順で何度も遊ぶ**。ランダムなのは足場の並び・巣の場所・鏡の配置など「中の細部」だけで、何を遊ぶかは変わらない。周回しても新しい驚きが来ない（1 章）。
- **案**: 巨神ごとに **十二の試練のプール**（歩・智・闘の三つの枠に各四つ）。**周回（心臓を止めるたび）に、グループごとに各枠から一つ、合わせて三つ**を引く。初回の周は今の三つ（原型）で固定。二周目から引く。四周で巨神ごとの十二をすべて見る（2 章）。
- **さらに各試練に乱数の要素**: 配置の型・仕掛けの数字・敵の組・障害・任意の目標。まれに出る「稀」「極」の修飾は、素材が増える。同じ試練でも毎回違う遊びになる。引いた三つと修飾は**祠の画面と段の札にアイコンで出る**ので、備えができる（2.5〜2.7）。
- **共有の背での収容**: 四十八の試練は **「セル」**（入口・出口・ゴール・休み場の決まった口を持つ部屋）として背に**常設**し、順路の今の段のセルだけをグループごとの扉（`GroupGates`）で開ける。グループごとの上書きと敵の持ち主で、同じ部屋に別のグループが同時にいられる（待ちなし。2.4。26 の作りを使う）。
- **四十八の試練**は 3 章に一覧（巨神ごとに、名前・内容・核の仕掛け・一人／複数・乱数・流用）。今の十二の試練（原型）は全部残り、新しく作るのは三十六。
- **作り方**: セルの雛形（`TrialCell`）、修飾の機構、札の画面、図鑑、検査（全変種を作って詰みを調べる）を先に作り（P1）、試練を 16 → 32 → 48 と増やす（5 章）。作業量はおよそ 68 エージェント日（4 並列で壁時間は約 3 週。26 の枠のあと）。
- **越えたあと（4.6）**: 試練を越えると、4 秒後に順路の参加者全員が次の段の入口の休み場へ運ばれる（32 の 2.3）。
- 採用した方針（6 章）: **各枠から一つずつ引く／常設のセル／初回は原型固定／修飾は全部見える／装備の確率は変えず素材と図鑑で報いる／岩鯨から 16 → 32 → 48**。

## 1. 今の試練と、周回で飽きる理由

### 1.1 今の仕組み（事実）

| 項目 | 内容 |
| --- | --- |
| 数 | 巨神ごとに三つ（岩鯨: 西・東・下、潮殻: 西・東・前、雷翼: 西・東・前、余燼: 西・東・南）。四体で 12 |
| 型 | 一つはアスレチックや運び（西）、一つは謎解きや工作（東・下）、一つは戦い（岩鯨の東・潮殻の前・余燼の南）。**雷翼だけ戦いの試練がなく**、中ボス雷獣が東の終わりにいる |
| ランダム | 足場の並び（岩鯨の西）、迷路の形（岩鯨の下）、巣の場所（潮殻の前）、鏡と受け羽の配置（雷翼の前）、水位の配置（潮殻の東）、島の並び・打つ順（余燼）。**いずれも「同じ試練の中の並べ替え」で、遊びの種類は変わらない** |
| 周回 | 初回は 21 の「初回の延長」（詰所・影・第二の広間など）で長い。周回（`keep.first_cleared`）は既知の道＋三つのうち一つが静かな試練（敵が少ない）。誓い（Vow）で自分に縛りを足せる（21 の 1.8） |
| 共有の背 | 背は巨神ごとに一つの共有。進みはグループ（パーティ・一人）ごと。扉・敵・心臓は閉じたグループだけが見る |
| 心臓を止めたあと | 巨神は眠り、運び出される。やがて鼓動が戻って目覚め、試練は新しい形で待つ（02 の 2.11・7.1） |

### 1.2 周回の問題

1. **何を遊ぶかが決まっている**。二周目に岩鯨へ戻ると「西は崩れる骨、東は番兵、下は灯」と分かっている。足場の並びが変わっても、跳ぶことは同じ。
2. **周回を短くする仕組み（既知の道・静かな試練）は、飽きを減らすが、驚きを増やさない**。20 分で終わるぶん、毎回同じ 20 分になる。
3. **試練の数が三つなので、増やすと「全部必須」になる**。一つ足すと初回が長くなる。選ぶ数と作る数が一対一で、作った分が全部毎回の負担になる。
4. **戦い・謎・足場の割合が固定**で、好みでない試練は毎周逃げられない。逆に好みの試練は、一周に一度しかない。
5. **雷翼は初回から戦いの試練が無い**ので、闘が好きな人は雷獣まで我慢する。

→ 解く方向は「作る数を増やして、選ぶ数は三つのまま」。必須の長さは変わらず、周回ごとに中身が替わる。

## 2. プール方式

### 2.1 全体像

```
巨神 1 体
  プール = 12 の試練 = 歩 4 + 智 4 + 闘 4      （3 章）
     │  周回（心臓を止めるたび）の最初の乗り込みで、グループごとに引く
     ▼
  今の周の三つ = 歩 1 + 智 1 + 闘 1          （初回の周は原型の三つで固定）
     │  それぞれに修飾（配置・数字・敵・障害・任意）を引く
     ▼
  祠の画面に表示 → 順路で三つを越える（歩 → 智 → 闘 → 中ボス）→ 心臓
```

三つの枠は、遊びの種類の骨組み。**歩**は足・拍・運びで体を動かす試練、**智**は謎解きと分担で頭を使う試練、**闘**は戦いと護りで武器を使う試練。今の三つ（西・東・前）がおおむねこの三種なので、「三つ遊ぶ」という形は変えない。

七つの類（渡る・拍・運ぶ・解く・合わせる・戦う・護る）は、枠の中の味付けで、図鑑と祠の画面のアイコンに使う。

| 枠 | 類 | 遊びの芯 |
| --- | --- | --- |
| 歩 | 渡る | 足場・道を読んで渡る（アスレチック） |
| 歩 | 拍 | 周期・拍に合わせて動く（タイミング） |
| 歩 | 運ぶ | 物（真珠・熾）を壊さず届ける |
| 智 | 解く | 仕掛けを理解して解く（謎解き） |
| 智 | 合わせる | 同時・分担で解く（協力。重り・留め・時間で一人でも解ける） |
| 闘 | 戦う | 敵を倒す（広間・巣・闘技場） |
| 闘 | 護る | 運ぶ物・隊列を敵から守る（護送） |

### 2.2 引き方の決まり

「周回」は、そのグループが**その巨神の心臓を止めるたびに一つ数える**（`keep.clears.<巨神>`。周回の番号は 1 から）。

1. **周回 1（初回）は今の三つ（原型）で固定**。引かない（原型は「引いた」扱いでプールの履歴に入る）。21 の「初回の延長」は原型にだけ付いているので、初回の長さ・場面・宝は今の設計のまま。雷翼だけ 歩1・智2・闘0 になる（この周だけ枠の決まりを外す）。
2. **周回 2 から、枠ごとに引く**。各枠のプールから、**その枠でまだ引いていない試練**（`keep.pool.<巨神>.<枠>`）を候補にする。**プールが尽きたらその枠だけ**、直前に引いた試練を除いて元へ戻す（尽きるのは、どの巨神も歩と智と闘は周回 4。雷翼だけ、智は周回 3、闘は周回 5）。
3. **各枠から一つずつ**。三つの試練は必ず歩・智・闘の一つずつ（雷翼の初回だけ例外）。したがって**三つの類はいつも違う**（渡る＋解く＋戦う、拍＋合わせる＋護る、…）。三枠のうち二つが似る事故はない。
4. **難度の段**（2.3）で候補を絞る: 周回 N のとき、段が N 以下の試練だけ。段が合う候補がなければ段の制限を外す。
5. **重み**: 段が周回と同じ試練は重み 1.5、それ以外は 1.0（上がるときに難しいものが当たりやすい）。
6. **種**: `seed = hash(世界の種, グループの鍵, 巨神, 周回)`。グループの鍵はパーティなら `partyId`、パーティでない一人なら `playerUUID`。枠ごとに `seed + 枠` の乱数で引く。引いた結果は最初の乗り込みでグループの記録（`keep.draw.<巨神>`）に保存する。
7. **同じ周のうちは変わらない**。倒れて戻る・背を出て入り直す・試練のリセット（`epoch`）では、引いた三つと修飾は同じ。**足場の並びなど「箱の中の細部の種」だけ epoch で替える**（今と同じ）。
8. **パーティの出入り**: 記録はグループごと。パーティに入ると、パーティの記録（引いた三つ）に従う（10 の「記録ごと写る」）。パーティを抜けた人は、自分の記録が先の周の途中なら続きから、なければ新しく引く。パーティでの周回数と個人の周回数が違っても、引く種は「グループの鍵」ごとなので混ざらない。
9. **静かな試練**は修飾「静」として残す。周回 2 以降は、引いた三つのうち一つ（その枠は種で決まる）に「静」が付く。静の試練は敵が少なく、石は自分で鳴らす（今と同じ。08 の 7.2）。
10. **誓い（Vow。21 の 1.8）はそのまま**かかる。段（重さ）は修飾と別に数える。

> 擬似コード（枠 s ごと）  
> `cand = pool[s] − seen[s]; if empty: seen[s] = {last[s]}; cand = pool[s] − seen[s]`  
> `cand = cand.filter(tier ≤ cycle) or cand`  
> `pick = weightedChoice(cand, w = 1.5 if tier == cycle else 1.0, rng = hash(seed, s))`

### 2.3 難度の段

| 段 | 意味 | 効くもの | 素材の倍率 |
| --- | --- | --- | --- |
| ★1 | 学ぶ（原型と、やさしい新作） | 敵の数と体力は今の標準。猶予が長い | ×1.0 |
| ★2 | 手ごたえ | 敵 +20%、猶予 −15%、休み場が一つ少ない | ×1.2 |
| ★3 | 腕試し | 敵 +40%、猶予 −30%、任意の目標が出やすい。**予告の最短 0.8 秒は割らない**（既存の決まり） | ×1.5 |

- 段は**周回の数**で解禁される（周回 N で段 N まで）。**必要 Lv や装備では閉じない**。段は同じ巨神の中の相対で、巨神ごとの手ごたえの曲線（03）はそのまま。
- 段が上がるのは数字の標準が変わるだけ。**どの段も一人で解ける**（26 の原則）。
- 各枠の段の並びは `[1, 2, 2, 3]` か `[1, 1, 2, 3]`（3 章）。周回 2〜4 で、各枠は残りを一つずつ引くので、★3 は遅くても周回 4 で当たる。

### 2.4 セル：背での収容と順路

四十八の試練を、背に作る「**試練のセル**」（`TrialCell`）として扱う。どの試練も [32 巨神の順路](32_titan_raid_route.md) の一段として遊ぶ（歩 → 智 → 闘 → 中ボス → 心臓。越えると次の段の入口の休み場へ運ばれる）。

**セルの雛形（どの試練も同じ口を持つ）**

| 口 | 内容 |
| --- | --- |
| 入口 | グループごとの封印の扉（`GroupGates`）。順路の今の段のセルだけ、そのグループに開く（ほかのセル・越えたセルは閉じて見える）。順路は入口の休み場へ運ぶので、戸を探して歩くことはない |
| 入口の休み場 | 運ばれた先。新作はセルの最初の休み場（なければ戸の前の広間の休み場）、原型は今までの入口の休み場（`TrialRoute.entryRest`） |
| 出口 | 試練を終えると開く、休み場へ戻る光る床 |
| ゴール | 試練の終わりの床の光る印（石ではない。`TrialGoal`）。着く（近づく）か、セルが終わる（`run.cleared`）と、そのグループの「試練の記録」が済む。共鳴石・潮鳴り石・風鳴り石・熾り石のブロックは無い |
| 休み場 | 一つ以上（段が上がると減る）。記録は試練の番号つき |
| 箱 | 縦横高さの決まった大きさの等級（M・L）。26 の部屋の拡大のあと、`dev backmetrics` で測る |
| 詰み防止 | 戻しの鏡・戻しの栓などの「戻す口」。`BuildAudit` が全変種で届くことを確かめる |

**背の中の置き場**: セルは背の体の中に一組だけ常設する（岩鯨・潮殻・余燼は「試練の階」、雷翼は「試練の甲板」。原型の三つは今までの翼）。セルのあいだの広間と回廊は残っているが、順路が段ごとに入口の休み場へ運ぶので、歩いて行き来はしない。

**複数のグループが同じ背にいるとき**（26 の 4.4・10 の 10 章）:

- 順路ごとに区画（`TrialSlot`。1〜32）を取り、引いた新作のセルを背の次元の遠くの区画へ写して、そのグループはその写しだけを使う（32 の 5 章）。背の中の手本のセルは写しの元。**2 レーンと待ち行列は無い**。
- 体の中の原型（「物理」の印のあるものを含む）を初回の順路が使うあいだは、別のグループの初回の順路は入口で待つ（32 の決定 207）。周回で原型を引いたグループは、上書きのまま同じ部屋を使う。
### 2.5 試練ごとの乱数（修飾）

同じ試練を毎回違う遊びにするため、試練ごとに五種類の修飾の「口」を持つ。

| 種類 | 何を変えるか | 例 | 出方 |
| --- | --- | --- | --- |
| **配置の型** | 部屋の骨組み。手で作った型 3〜4 つのうち一つ（手作り＋生成の組み合わせ） | 迷路の形・島の並び・鏡の配置・巣の候補地 | 必ず 1 つ |
| **数字の振り** | 猶予・周期・数・速さ。`やさしい／標準／きびしい` の 3 段（段の補正に足す） | 崩れの遅さ・鐘の周期・取っ手の猶予・波の数 | 2 つ（各 3 段） |
| **敵の組** | 同じ敵の種類の組み合わせ（新しい敵は足さない。26 の原則） | 剣と盾の波 / 弓と盾の波 | 戦う・護るの枠は必ず 1 つ。ほかは 0〜1 |
| **障害** | 余計な危険。**遊び方を変えるだけで入れなくはしない** | 落石・誤射・突風・小魚の群れ・噴気 | 0〜1（稀） |
| **任意の目標** | 達成すると報酬が増える（失敗しても進む） | 一度も落ちずに・無傷・手数を少なく | 0〜1（稀） |

**稀さ**: 引いた修飾の最大が、その試練の稀さになる。

| 稀さ | 出る確率（修飾 1 つごと） | 例 | 報いの上乗せ |
| --- | --- | --- | --- |
| 常 | 約 70% | 標準の数字、普通の配置 | なし |
| 稀 | 約 25% | 障害・任意の目標が付く。やさしい／きびしい | その巨神の素材 +1 個ずつ。任意の目標を達成するとさらに +1 |
| 極 | 約 5% | **鏡像**（配置を左右反転）、**逆走**（出口と入口を入れ替える）、**二つの障害** | 素材 +2、共鳴の欠片が 8% で出る |

| 深淵 | 引かない。**板のつまみで選ぶ**（転生 3 回以上の人が、グループごと。2.9） | 極のすべて（数字は一番きびしい・障害二つ・任意の目標）に、さらに数字の底上げ 15%。猶予・周期は短く、数・長さは 1 つ増える（底は解ける線） | 素材 +3、共鳴の欠片が 12% で出る |

- **組み合わせの数**: 一つの試練で、配置 3〜4 × 数字 9 × 敵 2〜3 × 障害 3〜4 × 任意 3〜4 ≒ **数百通り**。三つの組み合わせは 64 通り（歩 4 × 智 4 × 闘 4）なので、巨神ごとに **数万通りの遊び**になる。
- **状態は遊び方を変えるだけ**: 拍・潮・熱・時刻・天気・背の状態は、修飾としては「遊び方を変える数字」にだけ使う（凪／嵐の固定、満潮の別の道など）。**修飾が試練に入れなくする・解けなくすることはしない**（原則。26 の 2 章）。
- **解けない組み合わせを作らない**: 各試練に「禁止の組み合わせ」を登録し、生成のときに外す。検査は 5.3 の全変種の総当たり。
- 修飾の数は段で増える: ★1 は 3 つ（配置・数字 2）まで、★2 は 4 つまで、★3 は 5 つまで。

### 2.6 種と再現性

- 引き方も修飾も**種で決まる**（2.2 の 6）。同じグループが同じ周に同じ巨神へ来ると、同じ三つと同じ修飾。
- 運営側の再現（開発・試遊）: `/skyabyss trial draw <巨神> <グループ> <周回>`（開発用）で引き直し、`/skyabyss trial force <ID>` で試練を指定、`/skyabyss trial mods <ID> <修飾>` で修飾を指定する。試遊の `playtest trials` と併用。
- 種を表示する `/skyabyss trial seed`。報告があったとき、その種で再現できる。

### 2.7 読める札：祠の画面・段の札

引いた三つ・修飾・段・稀さは、プレイヤーが**入る前に読める**。

- **祠の画面**（地上の巨神の祠を右クリック。32 の 3.1・6 章）: 引いた三つが歩・智・闘の順に縦に並び、それぞれに: 枠のアイコン、類のアイコン、名前、段の星、**修飾のチップ**（配置・数字・敵・障害・任意の五種の印。稀は金縁、極は赤紫縁）、図鑑のしるし（初めて・済み・修飾を揃えた）。下に順路の記録（越えた回数・最速）・持っている歌片の数・称号。深淵のつまみ（2.9）もここ。
- **段の札**（32 の 6 章）: 段が始まると、上の帯に試練の名前・枠と、段の星・稀さ・修飾のチップ（周回は「〇周目」）が出る。入ると「目的の帯」（18）に試練の名と任意の目標が出る。
- **全部見える**（判断 4 の推薦）。ただし「極」のうち一つは、祠の画面では「？」で、段の札（入ってから）で分かる。
- ほかのメンバーにも同じ画面が見える（パーティで共有）。
- アイコンは 32×32 を 7 類 + 5 修飾 + 3 段 = 15 枚、巨神の色の縁取り。**ラフを先に出す**（3 案ずつ）。試練ごとのアイコンは作らず、名前で見分ける（アセットを増やさない）。

### 2.8 守ること

- **深淵も同じ決まり**（2.9）。数字の標準だけを上げ、一人で解け、時間・状態で閉じず、予告は変えない。

- **試練に状態の鍵をかけない**。全セルは常にそこにあり、順路はいつでも始められる（祠は時間・天気・背の状態で閉じない）。待たせるのは、体の中の原型を初回の順路が二組同時に使うときだけ（32 の決定 207）。
- **一人でも解ける**。協力の試練は、重り・留め・時間の三つの代わりで一人にも用意する。広間は狭めず、敵を入口側に寄せ罠と柱で広さを使わせる（26 の 8.7）。
- **新しい敵の種類は足さない**。21 の敵（骨の砲手・老番兵・灯り魚・真珠守り・嵐の仔・羽守長・鞴持ち・大燠虫）を、26 の方針で配り直す。
- **心臓の戦いの内容は変えない**。ボスの扉（三つの石 → 心臓）は例外のまま。どの試練を引いても、石を三つ鳴らすのは同じ。
- **装備の確率と天井は変えない**（03）。報いは素材・図鑑・称号（4 章）。
- **戦いの部屋の強さは、その試練に入った人の数で決まる**（パーティの人数ではない）。広間の参加者・砦の中の人・干潟の中の人・火床の部屋の人を数える（`TitanBackTrials` の広間の参加者、`W10Fort.gunners`、`TideFlats.inFlats`、`EmberTrials.playersIn`）。順路ではグループ全員が同じ試練にいるので、実質パーティの人数になる。
- **部屋の大きさは人数で変えない**（26 の 8.7 の B）。少人数のときは、敵の湧き場所を入口側に寄せる（1 人 45%・2 人 60%・3 人 80%・4 人から全部。砦・炉は口の順、嵐の巣は縁の角度、円い闘技場は入口の橋の側）。広さは、床の罠の板（敵を誘い込む・押し込めるが、予告 40 tick・円の外は無傷・人への傷は 3）と遮蔽の柱（2×2・半分は常設、3 人・5 人からそのグループにだけ増える）で使わせる。罠の数は人数で増える（1 人 35% → 6 人 100%）。円い闘技場は、一人・二人でも円は全面で、崩れる床の順は同じ（幕で半分にして外の輪を先に崩す作りはやめた）。実装は `combat/RoomPlay`。

### 2.9 深淵（31 の B04。`abyss/Abyss`・`TrialDraw.abyssify`）

極の上の修飾の段。**引くものではなく、選ぶもの**。

- **開く条件**: 転生 3 回以上（`RebirthView.count`）。つまみを入れられるのはその人だけ。**入れたあとは、未転生の仲間も同じ試練を遊べ**、報いは全員に入る（時間・状態・装備で閉じない）。切るのは誰でもよい。
- **つまみ**: 祠の画面の右上（「深淵: 選ぶ／選択中」。転生 3 回未満は灰色の「深淵（転生 3 回〜）」で押せない）。グループの記録 `keep.trial.abyss`（巨神の背ごと。いま見ている祠の巨神の分。試練のリセットでは消えない）。入れ切りを変えると、動いている試練は止まり、次に入るとき組み直す。サーバーが転生の数を確かめる。
- **何が変わるか**（引いた三つの試練はそのまま。配置・敵の組・静も変えない）: 数字はすべて「きびしい」（段 2）にし、障害を二つ（禁止の組み合わせは除く）、任意の目標を必ず一つ付ける。さらに実行のとき数字の底上げ（`Abyss.NUMBER_STEP` = 1.15）: 拍の周期・窓・水門の猶予は 1/1.15（周期・猶予は 60 tick、窓は 0.35〜0.40 を下限）、水門の保つ時間は ×1.15、並べる音と砲手と波は +1。祠の画面では全部見える（極の「？」は出さない。選んだ人への驚きではなく、覚悟の札）。
- **報い**: 素材 +3（極の +2 の代わり。任意の目標で +1）、共鳴の欠片 12%（極は 8%）、称号「深淵を渡る者」。
- **保存しない**: 引き自体は変えず、表示と実行のたびに重ねる（つまみを戻せば元の引きに戻る。同じ種で再現できる）。
- 自己テスト `abyss`（`abyss/AbyssSelfTest`。`SKYABYSS_SELFTEST_ONLY="abyss"`）: 転生での開閉・つまみの決まり・全試練 × 160 の乱数での段の数式（数字・障害・目標・往復・冪等・報い +3）・つまみで引きが重なり戻る・数字の底上げと下限・心臓の湧き・落とし表・四つの書き換えの効き。

## 5. 作り方

### 5.1 セルの雛形（`TrialCell`）

```
interface TrialCell {
  String id();                 // "W01" など
  Titan titan(); Slot slot();  // 歩・智・闘
  Category category(); int tier();
  BoxClass box();              // M / L
  boolean physical();          // 世界が変わる（物理の印）
  List<LayoutVariant> layouts();           // 3〜4 の配置の型
```

## 7. 守ること（書き手の確認）

- 試練に状態の鍵をかけない。ボスの扉だけが例外（26 の 7 章と同じ）。
- 引き方の種に装備・職・刻印・レベルを入れない（種は世界の種・グループ・巨神・周回）。
- どの試練も一人で解ける。協力の試練に重り・留め・時間の代わりを付ける。
- 新しい敵・ブロック・モデルを足さない。修飾は既存の敵と部品の組み替えと数字。
- 心臓の戦いの内容、天の鍵の流れ、初回の延長（原型に付く）は変えない。
- 全変種を検査してから出す。解けない組み合わせを作らない。
