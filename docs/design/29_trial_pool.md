# 天と淵のあいだ 試練の引き方と修飾（周回・段・深淵・図鑑・報い）

- 文書番号: 29
- 範囲: 巨神の背の試練を、周回ごとにどう引くか。段・修飾・稀さ・種・読める札・深淵・図鑑・報い。
- 状態: 引き方と修飾は実装済み（`trial/TrialDraw`・`trial/TrialData`・`abyss/Abyss`）。順路の中身（部屋・中ボス・心臓）は [32 巨神の順路](32_titan_raid_route.md)。
- 関連: [32](32_titan_raid_route.md)（順路・部屋・区画）、[26](26_backs_scale_up.md)（背の作り）、[21](21_content_expansion.md)（初回の延長・誓い）、[27](27_builds_and_classes.md)、[31](31_freedom_and_rebirth.md)（深淵の入口）

---

## 0. 要約

- 巨神ごとに試練は三つ（歩・智・闘）。周回（そのグループがその巨神の心臓を止めるたび）ごとに、各枠のレイドの部屋を引く。
- 試練ごとに、配置・数字・敵の組・障害・任意の目標の修飾が乗る。
- 引いた三つと修飾、段、稀さは、祠の画面と段の札で入る前に読める。
- 深淵は引くものでなく、転生 3 回以上の人が選ぶ修飾の段。
- 引き方は種で決まり、同じ周のあいだは変わらない。状態（拍・潮・天気・時刻）は遊び方を変えるだけで、試練を閉じない。

---

## 1. 引き方

### 1.1 周回と枠

- 「周回」は、そのグループがその巨神の心臓を止めるたびに一つ数える（`keep.clears.<巨神>`。1 から）。
- 枠は三つ: **歩**（足・拍・運び）、**智**（謎解き・分担）、**闘**（戦い・護り）。枠の中の類は七つ（渡る・拍・運ぶ・解く・合わせる・戦う・護る）で、図鑑と祠の画面の印に使う。

| 枠 | 類 | 遊びの芯 |
| --- | --- | --- |
| 歩 | 渡る | 足場・道を読んで渡る |
| 歩 | 拍 | 周期・拍に合わせて動く |
| 歩 | 運ぶ | 物（真珠・熾）を壊さず届ける |
| 智 | 解く | 仕掛けを理解して解く |
| 智 | 合わせる | 同時・分担で解く（一人でも解ける形を用意する） |
| 闘 | 戦う | 敵を倒す（広間・巣・闘技場） |
| 闘 | 護る | 運ぶ物・隊列を敵から守る |

### 1.2 引く決まり

1. **枠ごとに、その枠に登録したレイドの部屋から一つ引く**（`RaidRooms.drawOf`。枠ごとに一つか二つ。32 の 9 章）。三つの並びは歩 → 智 → 闘。初回も周回も同じ引き方で、部屋の中身は初回も周回も同じ。
2. **種**: `hash(世界の種, グループの鍵, 巨神, 周回)`。グループの鍵はパーティなら `partyId`、一人なら `playerUUID`。枠ごとに `種 + 枠` で混ぜて引く。引いた結果はグループの記録（`keep.draw.<巨神>`）に、最初の乗り込みで保存する。
3. **同じ周のあいだは変わらない**。倒れて戻る・背を出て入り直す・リセット（`epoch`）でも、引いた三つと修飾は同じ。
4. **パーティの出入り**: 記録はグループごと。パーティに入ると、パーティの記録に従う。抜けた人は、自分の記録が途中の周なら続きから、なければ新しく引く。
5. **修飾**: 周回 1 は修飾なし。周回 2 からは試練ごとに修飾を引く（2 章）。
6. **静かな試練**: 周回 2 以降、引いた三つのうち一つ（種で決まる）に修飾「静」が付く。戦い・護りの試練に当たったときだけ効き、敵が少ない。
7. **誓い（Vow）** は、21 の 1.8 のとおり自分に縛りを足す。段（重さ）とは別に数える。

### 1.3 試練の数

- 巨神ごとに、枠ごとのレイドの部屋（`RaidRooms` が `TrialCatalog.addRaid` で足す）。部屋の数と中身は 32 の 9 章。
- 原型の定義（W01・T01 など 12、`trial/TrialCatalog`）は、記録・図鑑の古い id のために残す。遊ぶことはない。

## 2. 段・修飾・稀さ

### 2.1 難度の段

| 段 | 意味 | 効くもの |
| --- | --- | --- |
| ★1 | 学ぶ | 敵の数と体力は標準。猶予が長い |
| ★2 | 手ごたえ | 敵 +20%、猶予 −15% |
| ★3 | 腕試し | 敵 +40%、猶予 −30%、任意の目標が出やすい。予告の最短 0.8 秒は割らない |

- 段は周回の数で解禁される（周回 N で段 N まで）。必要 Lv や装備では閉じない。
- 段が上がると数字の標準が変わるだけ。どの段も一人で解ける。
- 段の並びは、各枠で `[1, 2, 2, 3]` か `[1, 1, 2, 3]`。

### 2.2 修飾

試練ごとに五種類の修飾の口を持つ。

| 種類 | 何を変えるか | 例 | 出方 |
| --- | --- | --- | --- |
| 配置の型 | 部屋の骨組み（手で作った型の一つ） | 迷路の形・島の並び・鏡の配置・巣の候補地 | 必ず 1 つ |
| 数字の振り | 猶予・周期・数・速さ。やさしい／標準／きびしい の三段 | 崩れの遅さ・周期・取っ手の猶予・波の数 | 2 つ |
| 敵の組 | 既存の敵の組み合わせ（新しい敵は足さない） | 剣と盾の波 / 弓と盾の波 | 戦う・護る は必ず 1 つ。ほかは 0〜1 |
| 障害 | 余計な危険。遊び方を変えるだけで、入れなくはしない | 落石・誤射・突風・小魚の群れ・噴気 | 0〜1（稀） |
| 任意の目標 | 達成すると報いが増える（失敗しても進む） | 一度も落ちずに・無傷・手数を少なく | 0〜1（稀） |

- 修飾の数は段で増える: ★1 は 3 つまで、★2 は 4 つまで、★3 は 5 つまで。
- 状態（拍・潮・熱・時刻・天気・背の状態）は、修飾として「遊び方を変える数字」にだけ使う（凪／嵐の固定、満潮の別の道など）。修飾が試練を閉じる・解けなくすることはしない。
- 禁止の組み合わせを試練ごとに登録し、生成のときに外す。検査は全変種の総当たり。

### 2.3 稀さ

引いた修飾の最大が、その試練の稀さになる。

| 稀さ | 出る確率（修飾 1 つごと） | 例 |
| --- | --- | --- |
| 常 | 約 70% | 標準の数字、普通の配置 |
| 稀 | 約 25% | 障害・任意の目標が付く。やさしい／きびしい |
| 極 | 約 5% | 鏡像（配置を左右反転）、逆走（出口と入口を入れ替える）、二つの障害 |

- 組み合わせは、配置 3〜4 × 数字 9 × 敵 2〜3 × 障害 3〜4 × 任意 3〜4 で、一つの試練につき数百通り。三つの組み合わせは巨神ごとに数万通り。

### 2.4 種と再現

- 引き方も修飾も種で決まる。同じグループが同じ周に同じ巨神へ来ると、同じ三つと同じ修飾になる。
- 運営側の再現（開発）: `/skyabyss dev trial list`（いまの周・三つ・修飾・種）、`cycle <n>`（周を n にして引き直す）、`force <id> <id> <id>`（三つを決める）、`mods <id> <符号>`（修飾を決める）、`board [巨神]`（祠の画面を開く）。

## 3. 読める札

引いた三つ・修飾・段・稀さは、入る前に読める。

- **祠の画面**（地上の巨神の祠を右クリック。32 の 3.1）: 引いた三つが歩・智・闘の順に並ぶ。それぞれに枠のアイコン、類のアイコン、名前、段の星、修飾のチップ（配置・数字・敵・障害・任意の五種の印。稀は金縁、極は赤紫縁）、図鑑のしるし（初めて・済み・修飾を揃えた）。下に順路の記録（越えた回数・最速）・持っている歌片の数・称号。深淵のつまみ（3.4）もここ。
- **段の札**（32 の 6 章）: 段が始まると、上の帯に試練の名前・枠と、段の星・稀さ・修飾のチップ（周回は「〇周目」）が出る。入ると目的の帯に試練の名と任意の目標が出る。
- 極のうち一つは、祠の画面では「？」で、段の札で分かる。
- パーティの全員に同じ画面が見える。
- アイコンは 7 類 + 5 修飾 + 3 段 の 15 枚で、巨神の色の縁取り。試練ごとのアイコンは作らず、名前で見分ける。

## 4. 深淵

極の上の修飾の段。引くものではなく、選ぶもの。

- **開く条件**: 転生 3 回以上（`RebirthView.count`）。つまみを入れられるのはその人だけ。入れたあとは、未転生の仲間も同じ試練を遊べる。切るのは誰でもよい。
- **つまみ**: 祠の画面の右上（「深淵: 選ぶ／選択中」。転生 3 回未満は灰色の「深淵（転生 3 回〜）」で押せない）。記録は `keep.trial.abyss`（巨神の背ごと）。入れ切りを変えると、動いている試練は止まり、次に入るとき組み直す。サーバーが転生の数を確かめる。
- **何が変わるか**（引いた三つはそのまま。配置・敵の組・静も変えない）: 数字はすべて「きびしい」（段 2 の相当）にし、障害を二つ（禁止の組み合わせは除く）、任意の目標を必ず一つ付ける。実行のときは数字の底上げ（`Abyss.NUMBER_STEP` = 1.15）をかける: 拍の周期・窓・水門の猶予は 1/1.15（周期・猶予は下限 60 tick、窓は 0.35〜0.40 が下限）、水門の保つ時間は ×1.15、並べる音と砲手と波は +1。祠の画面では全部見える（覚悟の札）。
- **保存しない**: 引きは変えず、表示と実行のたびに重ねる。つまみを戻せば元の引きに戻る。
- 自己テスト `abyss`（`SKYABYSS_SELFTEST_ONLY="abyss"`）: 転生での開閉・つまみの決まり・乱数での段の数式・つまみで引きが重なり戻る・数字の底上げと下限。

## 5. 報い・図鑑

- **道中の落とし物**は個人の抽選（02・08・12・13 の 6 章）。装備の確率・天井・巨神の記憶は 03。
- **部屋を越えたとき**（順路の参加者ごと。`TrialRoute.onCleared`）: 試練の経験値（`GrowthRewards.onRouteTrialCleared`。居合わせなかった仲間には分け前）、クエストの「試練を踏破する」の合図、その試練の紋 1 つ（同じ試練では一度だけ。31 の A14）、部屋の入口の碑の伝承（`RaidLore`）。
- **心臓を止めたとき**: 戦った人に歌片 1 つ（次の周の鍵。32 の 3.2）、順路の記録（越えた回数・最速。図鑑の巨神の頁に出る）。

### 5.1 試練の図鑑

控え帳（11）の頁。巨神ごとに、順路を越えた回数と最速の時間、称号を出す。図鑑は人ごと（共有しない）。

---

## 6. 越えたあと

- 越えた試練は、4 秒（80 tick）後に次の段へ進む（順路の流れは 32 の 2 章）。越えた試練へは戻れない。
- 戸と進みはグループごと（`BackGroupData`・`GroupGates`）。同じ背にいる別のグループには触れない。

---

## 7. 守ること

- **試練に状態の鍵をかけない**。祠は時間・天気・背の状態で閉じない（21・26 の原則）。
- **一人でも解ける**。協力の試練は、重り・留め・時間の代わりを一人にも用意する。
- **新しい敵の種類は足さない**。既存の敵を配り直す（26 の方針）。
- **装備の確率と天井は変えない**（03）。
- **戦いの部屋の強さは、その試練に入った人の数で決まる**（パーティの人数ではない）。部屋の大きさは人数で変えない（26）。少人数のときは、敵の湧き場所を入口側に寄せる。
- **ビルドとの関係**（27）: 試練の役割（誘い・切り替え・運び・護り・射る）を木の技にひも付けてよい。技があると速くなるだけで、技が無いと解けない試練は作らない。刻印・要は引き方に入れない（種は世界の種・グループ・巨神・周回だけ）。
