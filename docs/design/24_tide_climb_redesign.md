# 天と淵のあいだ 潮殻の背の「上り」（甲羅の上と予約の間）

- 文書番号: 24
- 範囲: 潮殻の背の上り（浜の西の壁の段から甲羅の上・予約の間・頂の塔まで）。
- 関連: [32 巨神の順路](32_titan_raid_route.md)（任意の翼の扱い。7 章）、[08 潮殻の背](08_tide_shell.md)
- 状態: **現行の背にはない。** 上りの道（息の間・ひれの道・殻の上の迂回・予約の部屋・洞）は任意の翼で、今の背には置かない（32 の 7 章）。

---

## 1. 現行の扱い

- 潮殻の背の順路は、浜から三つの試練（歩・智・闘）と中ボス（潮招き）を経て心臓へ（32 の 2.1）。上りの道は順路に入らない。
- 封印の戸と予約の間の空気は、現行の背に無い。
- 潮殻の背の現行の配置は [08](08_tide_shell.md) を読む。ただし 08 の上りの節が上の任意の翼を前提にしている場合は、32 に従って読む。
