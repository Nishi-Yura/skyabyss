## 1. 方針の出どころ

ユーザーの要望:

- 前の巨神を倒さずに次へ行けてしまうのを防ぐ（前を倒さないと出ない、出ても前を倒していない人は行けない）。マルチでここを固めないと飽きられる。
- マルチでも全員が同じ体験をする。ストーリーと自由のような形。ただし自由でも、物語を進めないとできないことが多い。
- パーティで経験値を分ける（全く同じではなく 5〜8 割、離れすぎたら分けない、大きいダンジョンではみんなで分ける）。ギルド（競う、ワールドのギルドの情報、ダンジョンのランキング）もほしい。
- バニラの敵の経験値は日ごとの上限 100。物語の進みでレベルの上限を決めてよい。
- 巨神編（一〜四章）の巨神の推奨レベルは 12・18・24・30。

他のゲームの調べ（Terraria、FTB Quests、Monster Hunter、FF14、WoW、DQX、Diablo IV、mcMMO。第三者のサイトや検索の要約で、数値の根拠にはせず形の参考だけ）から取ったこと:

| 調べで見えたこと | このmodでの使い方 |
|---|---|
| ワールドが進みを持つ形（Terraria、FTB Quests のチーム）は、一人が進むと全員が先へ行ける。「先回り」の不満の元 | **出現はワールド、乗る資格は個人**の二段にする（3 章） |
| 個人が進みを持つ形（MH、FF14）は、参加できる内容を自分の進みで絞る。仲間に「連れていってもらう」ことはできない | 乗る資格は自分で前の心臓を止めた人だけ。仲間の例外はなし（3.4） |
| 上限を物語で開く形（MH のランク、DQX の上限解放） | レベルの上限を、止めた心臓の数で決める（5 章） |
| 分け前は「等分」（mcMMO・WoW）と「全員が満額に近い」（Diablo）の両極。距離は 64〜100 前後 | 居合わせた人は等分（+25%）のまま、居合わせなかった仲間に 7 割。距離 64（6 章） |
| レベル差の扱い（WoW の灰色、Diablo の増減、FF14 のシンク） | 「推奨 +3 から減る」補正をそのまま使い、仲間の分け前は 10 レベルを超えて低い人には渡さない（引き上げの抜け道） |
| 畑対策は記録が消えると抜け道になる（mcMMO のスポナー） | バニラの上限 100 に加え、レベルの上限がそもそも物語で止める |
| サブクエスト: FF14 の友好部族（物語で開く・日ごとの枠・開いたものから抽選）、WoW のワールドクエスト（物語の節目で開く・入れ替わり）、MH の任意クエスト（何度でも・報酬は素材） | 8 章 |

## 2. 方針の要点

| # | 決めたこと | 理由 |
|---|---|---|
| 1 | 巨神は **岩鯨 → 潮殻 → 雷翼 → 余燼** の順に目を覚ます | 「前を倒さないと出ない・行けない」には順番が要る。推奨レベル 12・18・24・30 も順番を前提にしている |
| 2 | **世界の進み**（ワールドの誰かが止めた心臓）で次の巨神が現れ、**個人の進み**（自分で止めた心臓）で乗れる | 出現をワールドで決めると全員が同じ空と海を見る。乗る資格を個人にすると物語の順番を一人一人が守る |
| 3 | 乗る資格に、仲間に連れていってもらう例外は**設けない**。岩鯨は誰でも乗れ、心臓の戦いに参加すれば「止めた」に数える | 例外があると「強い人に連れていってもらう」が抜け道になる。遅れた人は仲間と前の心臓を止めれば正規の道で追いつける |
| 4 | **レベルの上限**を止めた心臓の数で決める（15・21・27・33・40） | 畑・引き上げで物語より強くなりすぎない。上限は「次の巨神の推奨 +3」で、経験値の補正の線と同じ |
| 5 | モードは分けない。**物語の決まりは一つ**で、サーバーがゲームルールで切れる | 全員が同じ体験をするのが一番大事。プレイヤーごとのモードは別の決まりの人が混ざる |
| 6 | パーティは 6 人まで。**居合わせなかった仲間に 70%**（ゲームルールで 50〜80） | 6 人は背中の試練の人数の数え方（最大 6 人）と合う |
| 7 | バニラの敵の日ごとの上限は **100**（超えた分は 20%） | 00 の 26 の決定 |

## 3. 物語の進み（個人）と世界の進み（サーバー）

### 3.1 定義

| 名前 | 持ち主 | 中身 | どこに残るか |
|---|---|---|---|
| 個人の進み（段階） | プレイヤー | 順番どおりに止めた巨神の心臓の数（0〜4）。前が欠けていればそこで止まる | `ProgressData`（`skyabyss_progress`）の人ごとの記録と、巨神の記憶（`TitanMemoryData`）の撃破の記録のどちらか |
| 世界の進み | ワールド | 誰かが心臓を止めた巨神と、最初に止めた人の名前と日 | `ProgressData` のワールドの記録 |

- 個人の進みは、心臓を倒した瞬間に参加者全員（倒れて復活を待つ人、戦いの途中で切断した人も含む）へ書く。**撃破の報酬より先に**書くので、心臓の経験値は上がった上限で受け取れる。4 体の心臓（中ボスの報酬も）とも UUID の集合で渡す。進み・欠片・報酬はオフラインの人にも付き、品は報酬の預かりに入って次にログインしたとき渡る。経験値はオンラインの参加者に渡す。
- 古いワールドは巨神の記憶の撃破の記録から読む。ログイン時、その人の記録を世界の進みにも写す。

### 3.2 巨神の順番

| 順 | 巨神 | 推奨 Lv | 現れる条件（世界の進み） | 乗れる人（個人の進み） |
|---|---|---|---|---|
| 1 | 岩鯨 | 12 | 3 日目以降 | 誰でも |
| 2 | 潮殻の巨神 | 18 | 4 日分たち、空の通過のあと（08）**かつ、誰かが岩鯨の心臓を止めたあと** | 自分で岩鯨の心臓を止めた人 |
| 3 | 雷翼の巨神 | 24 | 誰かが潮殻の心臓を止めたあと（ほかの条件は 12） | 自分で潮殻の心臓を止めた人 |
| 4 | 余燼の巨神 | 30 | 誰かが雷翼の心臓を止めたあと | 自分で雷翼の心臓を止めた人 |

- 世界で初めて心臓を止めたとき、**同じ巨神をもう止めたことのあるほかの人**にだけ、画面の語り（18）で一行知らせる（「〜が〜の心臓を止めた。どこかで、次の鼓動が目を覚ます」）。チャットには流さない。まだ止めていない人には巨神の名前を明かさず、次の巨神の名前も出さない（08 の「自分で気づく」を守る）。
- 天の鍵（4 つの欠片）は順番に揃う。五章（深淵）の入口の条件は「4 つすべて」。

### 3.3 乗る資格の確かめ方（実装）

入口で断るだけではテレポートの道が残る。入口・ディメンションを移る前・背中にいる間の 3 か所で見る。

| 場所 | 何をするか | コード |
|---|---|---|
| 入口 | 潮門をくぐったとき、`/skyabyss titan board tide`、岩鯨の鎖（`TitanTravel.board`） | `Progression.checkBoard`。断ると理由を一行（画面の下）と、何をすればよいか（チャット）。潮門は舟から降ろす前に断り、3 秒は反応しない |
| ディメンションを移る前 | `/tp`・`/execute in`・ほかの Mod のテレポート・ポータルなど、どの道で背中へ移ろうとしても取り消す | `EntityTravelToDimensionEvent` を取り消す |
| 背中にいる間（1 秒ごと） | 取り消せなかった移動、背中でログアウトしていた人、資格を取り上げられた人 | 地上へ戻す（`TideTravel.leave` / `TitanTravel.leave`） |

- クリエイティブと観戦者は問わない（作る人・見る人のため。サバイバルの抜け道にはならない。レベルの上限はかかる）。
- 資格があっても、心臓を止めた直後の巨神（眠っているあいだ。01 の 4.3、`titan/end/TitanDormancy`）には乗れない。入口の断り（`Progression.checkBoard`）が「…は深い眠りの中にいる。鼓動が戻るまで、乗れない」を出す。背中にいる人の見回り・ディメンション移動の取り消しは資格だけを見るので、眠りでは外へ出さない。
- ゲームルール `skyabyssStoryGate`（既定 true）を false にすると順番と乗る資格をすべて切る。ベータの配布でも入れたまま渡し、詰まったら管理者が切る（00 の 178。切り方は `docs/beta_how_to_play.md`）。

### 3.4 先回りの抜け道と、塞ぎ方

すべて実装済み。

| 抜け道 | 塞ぎ方 |
|---|---|
| 仲間に乗せてもらう（一緒に潮門をくぐる） | 潮門は一人ずつ資格を見る。仲間の例外はない |
| 岩鯨の鎖で次の巨神へ | 鎖は岩鯨だけ。乗り込みの共通の入口（`TitanTravel.board`）でも資格を見る |
| 潮門・潮見の貝で呼んでおいて、資格のない人がくぐる | 潮門の判定で断る |
| 呼び笛（巨神での移動） | 笛は自分で心臓を止めた巨神だけ渡る（09）。旅に同乗するのは地上の移動で、背中へは入らない |
| コマンド（`/skyabyss titan board`、`/tp`、`/execute in`）、ポータル、ほかの Mod のテレポート | 入口とディメンション移動の取り消しで断る。クリエイティブは除く |
| 背中で死んで背中で目を覚ます／背中でログアウトして資格のない時期にログイン | 背中にいる間の見回りで地上へ戻す |
| 後の巨神の心臓だけを止める（コマンドで呼んだなど） | 段階は順番どおりに続いている所までしか数えない |
| 強い仲間に心臓を倒してもらう | 心臓の戦いに参加すれば止めた扱い（3.5）。参加するには自分も背中に入る資格が要る |

### 3.5 仲間と一緒に止める（正規の追いつき方）

心臓の戦いの参加者（02 の決まり: 予告の 5 秒、前室の人、途中で倒れた人）は全員「自分で止めた」に数える。岩鯨は誰でも乗れるので、遅れて来た人は仲間と岩鯨の心臓を止めれば潮殻へ進める。潮殻の心臓は岩鯨を止めた人しか戦えないので、段階は飛ばせない。

### 3.6 章の数え方（個人の進みから導く）

章（01 の 4）は**個人の進み**から導く。保存は増やさない（段階と序章を終えたかから毎回出す）。巨神の出現はワールドのまま（3.2）。

| 段階 | 序章を終えた（B7 以降） | 章 |
| --- | --- | --- |
| 0 | いいえ | 序章 |
| 0 | はい | 一章 |
| 1 | — | 二章 |
| 2 | — | 三章 |
| 3 | — | 四章 |
| 4 | — | 四章の余韻、そのあと五章（天の鍵が下を指してから） |

- 予兆 3 拍（01 の 4.1）は人ごとの段階で数える。世界が先へ進んでいても、その人が前の心臓を止めるまでは出ない。すでに先の章にいる人には過去の章の予兆と小要素は出さない（遠景として歩いて見られるだけ）。
- 小要素は、その人が章に入ったとき（前の心臓を止めた直後）に、その人の拠点（ベッド、なければ今いる位置）を基準に、扇形の 3 方向へ 150 ブロック以内に置く。同じ拠点を使う人（120 ブロック以内）は同じ場所を共有し、離れた人は自分の分が置かれる。拠点と置いた場所のどれからも 300 ブロック以上離れた人には、進行方向の先に 1 つだけ足す。建物や水のある所は避け、すでにあるものは壊さない。置き方・登録の口・保存は [17 の 3.8](17_opening_and_rpg_feel.md)。
- 小要素の頁と経験値は、持っていない人にだけ渡す。
- 古い世界で段階が先に進んでいる人には、題字の札は出さず（序盤の既存者と同じ扱い）、今の章の小要素だけを最初のログインで置く。
- ゲームルール `skyabyssStoryGate` を切っても、章の表示は段階から導くだけなので変わらない。

章の導出は `story/Chapters.of(player)`、題字・余韻の札は `story/arc/ChapterCards`（18 の 9 章）、予兆の枠は `story/arc/Foreshadow`（01 の 4.1）、小要素を置く共通基盤は `opening/site/ChapterSites`（17 の 3.8）。題字の札は、すでに遊んでいた人（`OpeningState.legacy`）と序章には出さず、先の章にいる人には今の章の札だけを出す。

**まだ作っていない**: 各章の小要素そのもの（共通基盤に登録するだけ）。内部の ID（伝承の `chapter1/…`、メインのクエスト、段階、背中のディメンション）は章を作るときも変えない。

## 4. 「ストーリー」と「自由」

### 4.1 モードを分けない。物語の決まりは一つ

> **順路（[32](32_titan_raid_route.md)）での扱い**: 「自由」の面の周回は、地上の巨神の祠から専用の品（歌片。パーティで一つ）を使って挑む（32 の 3 章）。乗り込み口は初回だけ。成体の巨神は、その章を遊んでいる人とそのパーティにしか見えない（32 の 3.3）。

- 二つのモード（ワールド作成時に選ぶ）は採らない（自由で全部開くと物語の山場が消え、二通りの調整が要る）。プレイヤーごとの選択も採らない（同じワールドに別の決まりの人が混ざり、「全員が同じ体験」が崩れる）。
- 採ったのは、サーバー設定で決まりを切れる形（ゲームルール）。普通は一つの体験で、作る人・自由に遊びたいサーバーは切れる。

「ストーリー」と「自由」は、モードではなく**遊び方の二つの面**:

| 面 | 中身 | 物語との関係 |
|---|---|---|
| ストーリー | メインクエスト、巨神の順番、心臓、天の鍵、見る者・空の影・月のループ | 個人の進み（段階）が進む |
| 自由 | 止めた巨神の背中の周回、装備集め・強化、バイオームの探検、巨神での移動、サブクエスト（8 章）、（将来）ランキング | **物語で開く**: 呼び笛は心臓を止めた巨神だけ、潮殻の背は岩鯨のあと、レベルの上限は段階で上がる |

### 4.2 全員が同じ体験をするための同期

| もの | 持ち主 | 方針 |
|---|---|---|
| 空の影・見る者の頻度・月のループ | ワールド | 全員が同じ空と同じ夜を見る（01 のループ: サーバー全体で一つの月） |
| 巨神の出現と位置 | ワールド | 種類ごとに一体だけ（`TitanKeeper`）。世界の進みで目を覚ます |
| 背中の試練の進み | グループ（パーティ、または一人。10 章） | 背中は巨神ごとに一つを共有し、扉・敵・記録・リセットはグループごと。誰でも挑め、グループの誰もいなくなって 3 分で元に戻る |
| クエストの段階・伝承の書・成長・技 | 個人 | 一人一人が自分で進める。見る者・空の影はワールドで起き、クエストはそれを各自の書に記録して数える（07） |
| 乗る資格・レベルの上限 | 個人 | 3・5 章 |

### 4.3 遅れて参加した人

| 場面 | どうなるか |
|---|---|
| 世界の進みが先にある（潮殻が目を覚ましている） | 潮殻は見えるが乗れない。断るとき「岩鯨の心臓を自分で止めること」と示す。その人の章は一章のまま（章は個人の進み。3.6） |
| 追いつき方 | 岩鯨は誰でも乗れる。仲間と心臓を止めれば段階が進む（3.5）。岩鯨の背中の周回で経験値と装備を集める |
| 序盤の拍子（空の影・足音・歌・岩鯨を見る） | 人ごとに全部走る。空の影は、最初の一回だけワールドの影（全員に送る）。遅れて来た人の影は**その人にだけ**送る個人の影で、ほかの人の空・足音・歌・岩鯨の出現を止めない（`SkyEvents.startPersonal`・`activePassFor`）。個人の影は影の通過数に数えない |
| 岩鯨の呼び直し | 見失ったり誰からも遠いときの宛先は、**まだ岩鯨を見ていない人**（伝承 `chapter1/stone_whale` がない人）を先に選ぶ。背中に「だれかいる」と数えるのは、観戦者・クリエイティブ・5 分以上動いていない人を除いた人（`Activity.anyoneAboard`）。そのため、観戦者や放置の人が一人いるだけで呼び直しや試練のリセットが止まることはない |
| クエスト | 見る者・空の影はワールドで繰り返し起きるので、遅れた人も自分の書に記録できる |
| 経験値の追い風（段階が世界より遅れている間 +50%） | 入れていない（00 の 75。試遊してから） |

## 5. レベルの上限

| 段階（止めた心臓） | 章 | 上限 | 根拠 |
| --- | --- | --- | --- |
| 0（序章〜岩鯨） | 序章・一章 | 15 | 岩鯨の推奨 12 + 3 |
| 1（岩鯨のあと） | 二章 | 21 | 潮殻 18 + 3 |
| 2（潮殻のあと） | 三章 | 27 | 雷翼 24 + 3 |
| 3（雷翼のあと） | 四章 | 33 | 余燼 30 + 3 |
| 4（巨神編を終えた） | 四章の余韻・五章 | 40 | 五章を作るときに 50 まで広げる |

- 章を長くしても上限は変えない。章の小要素の経験値は 1 章あたり「そのときの 1 レベル分の 1〜1.5 倍」までに抑える（L→L+1 は 50 + 25k + 2k²。Lv 18 で約 1,050）。小要素で稼ぎすぎて、次の上限に早く当たらないため。

- 上限のレベルでは経験値のバーは**満ちる 1 手前まで**貯まり、あふれた分は捨てる。物語が進んで上限が上がると、次の経験値ですぐ 1 つ上がる（1 レベル分の貯め。全部貯めると畑で貯めて一気に上がれるため）。
- 上限に届いたとき、チャットに一行（「これ以上は強くなれない（上限 Lv 15）。岩鯨の心臓を止めれば、その先へ進める」）。
- すでに上限より高い人（古いセーブ）は下げない。それ以上は上がらないだけ。
- ゲームルール `skyabyssStoryLevelCap`（既定 true）で切れる。
- 岩鯨の初回クリアは Lv 9 前後、図鑑を埋めるころ Lv 19 前後なので、上限 15・21 は普通の遊びでは当たらず、畑や引き上げのときにだけ効く。
- バニラの敵: 日ごとに 100 までは満額、超えた分は 20%（`GrowthRules.VANILLA_DAILY`）。スポナーの敵は数えない。

## 6. パーティ

### 6.1 作り方

| 項目 | 決まり |
|---|---|
| 人数 | 6 人まで（00 の 74）。背中の試練の人数による強さの数え方も 6 人までを数える（敵の増え方・心臓と番兵長の体力の倍率 1 + 0.6 × (人数 − 1)） |
| 作る | 誰かを招待すると、まだ組んでいなければ自分がリーダーのパーティができる（相手が受けた時点で） |
| 招待 | リーダーだけ。60 秒で切れる。別のパーティにいる人は誘えない。届くと右上の札（「進展」）に出る。札の本文に受け方（O の画面・`/party accept`）を書く。招待した側の確認・断った・加わった・抜けた・外れた・リーダーの交代も画面の知らせ（18）。断られた理由はアクションバー |
| 受ける・断る | `/party accept`・`/party decline`、または O の画面のボタン（O の画面の右に「受ける」「断る」） |
| 抜ける | 誰でも。二人のパーティなら解散。リーダーが抜けたら次の人がリーダー。背中の試練の進みの引き継ぎは 10.8 |
| 外す・リーダーを渡す | リーダーだけ |
| 保存 | サーバーを止めても組んだまま（`skyabyss_parties`）。オフラインの仲間も一覧に残る |

### 6.2 経験値の分け前

| 場面 | 居合わせた人 | 居合わせなかった仲間 |
|---|---|---|
| 道中の敵 | 32 ブロック以内の全員で等分、一人増えるごとに全体 +25%（04 の 3.3） | 居合わせた人の取り分の **70%**（ゲームルール `skyabyssPartyShare`、50〜80 に収める） |
| ボス（番兵長・心臓） | 参加者それぞれに満額（初回の上乗せも） | 同じ背中にいれば、満額の 70%（初回の上乗せなし） |
| 試練の踏破（共鳴石） | 石の 16 ブロック以内の人に 40 | 同じ背中にいれば 70% |
| 一度だけの経験値（バイオーム・休み場・ディメンション）、クエストの報酬 | 本人だけ | 分けない |

居合わせなかった仲間の条件（`Parties.absentMates`）:

- 同じディメンションで、居合わせた仲間の誰かから **64 ブロック以内**。
- **巨神の背中では距離を問わない**。同じ背中にいれば、西の谷・東の回廊・下の迷路に分かれていても分け前を受ける。ただし**放置の仲間には渡さない**: 直近 60 秒に動いた・戦った・ブロックやアイテムに触れた人（`Activity.active`）か、居合わせた仲間から **128 ブロック以内**の人だけ（拠点で立っているだけで経験値が入る抜け道を塞ぐ）。
- 居合わせた仲間のいちばん高いレベルより **10 を超えて低い**人には分けない（強い人に経験値だけもらう抜け道）。
- 倒れている人・観戦者には分けない。
- 上がりすぎの補正（推奨 +3 から減る）は受け取る人のレベルで掛かる。バニラの敵は受け取る人の日ごとの上限に数える。

例（骨の番兵 12、二人のパーティ、Lv 12）:

| 場面 | A | B |
|---|---|---|
| A だけが近くで倒した（B は 50 ブロック先） | 12 | 8.4（70%） |
| 二人とも近く | 7.5 | 7.5 |
| A は東の回廊、B は下の迷路（同じ背中、B は動いている） | 12 | 8.4 |
| B は同じ背中で 5 分立ったまま、A から 300 ブロック | 12 | 0 |
| B が 100 ブロック先の地上 | 12 | 0 |

### 6.3 クエストの共有

- 撃破の目的は「倒した人」と「目的の範囲にいた人」が数える（07）。パーティの仲間も、分け前と同じ条件（64 ブロック、同じ背中なら距離なし）で数える（8.5）。
- 物語の段階（話を聞く・書に記録する）は共有しない。一人一人が自分で見る（4.2）。

### 6.4 画面と表示

- O キー: 「物語と仲間」の画面。上に自分の段階・レベルの上限・次の巨神・ワールドの進み、左に仲間（レベルと体力。リーダーには ★ と ×）、右に招待できる人（同じサーバーにいる人）、届いた招待に「受ける」「断る」。
- 画面の右、高さの 1/3 から: 仲間の名前・レベル・体力のバー（小さく）。別のディメンションにいる仲間は灰色。不在の仲間は名前だけ。
- `/party` で一覧（チャット）。

### 6.5 倒れたときの墓

> **順路（[32](32_titan_raid_route.md)）での扱い**: 順路のあきらめは全員の同意制で、成立するとグループ全員が背の外へ出される（32 の 2.4）。

- 墓は個人のもの。パーティの仲間でも、既定では他人の墓を開けられない（ゲームルール `skyabyssGraveOwnerOnly`。false にすると仲間に限らず誰でも開けられる。パーティ専用の例外は作らない）。
- 語り部の救いも本人の墓だけ。物語の決まり（順番・上限）と同じく、倒れたときの型（`skyabyssDeathMode` など）は世界で一つ（プレイヤーごとには選べない）。詳しくは [11](11_record_screen.md) の 6 章。

## 8. 自由なモードのサブクエスト

序章〜巨神編の分は実装済み（本体は [07](07_npc_quest.md) の 15・16 章、`jp.revati.skyabyss.quest.free`）。

### 8.1 考え方

「自由」は止めた巨神の背中の周回、探検、装備集めに「やること」を足し、物語の合間にも 巨神編を終えたあとにも遊べるようにするもの。決まりは三つ。

1. **物語を追い越さない。** サブクエストは自分の段階（3.1）で行ける所・会える敵だけを使う。次の巨神の背中や、まだ止めていない心臓を目的にしない。
2. **物語より強くしない。** 経験値はレベルの上限（5 章）の内側。品は今の段階の装備（03）を超えない。繰り返しで稼げる量に枠を作る。
3. **一人でも終えられる。マルチなら速く、楽しく。** 仲間がいないと終えられないクエストは作らない。仲間の数え方は 6 章と同じ。

### 8.2 種類

| 種類 | 依頼の場所 | 繰り返し | 中身の例 | 報酬の形 |
|---|---|---|---|---|
| 依頼（一度きり） | NPC（語り部・鯨追い） | なし | 話と伝承、探検、納品 | 経験値（一人一回）、伝承の項目、小さな品 |
| 日替わり | 村の言伝ての板（新しいブロック `MessageBoardBlock`。語り部の「村の頼みごと」でも同じ画面） | ゲーム内の 1 日ごと | 背中の敵、採集、見回り | 少しの経験値、巨神ごとの素材 |
| ループごと（今は 7 日の「週替わり」`repeat: "weekly"`。月のループの本体ができるまで） | 板と NPC | 7 日ごと | 背中の踏破、心臓をもう一度、名付きの敵 | 素材、再鍛造の品（03） |
| 探索・記録 | 伝承の書・巨神での移動 | なし | 道標、潮の時刻、空の影の観測 | 伝承の項目、称号 |
| ギルドの依頼 | ギルドの画面（7 章） | ループごと | 団員の合計で心臓 N 回など | ギルドの記録（ランキングに載る） |

### 8.3 解放条件と、物語の進みとの関係

07 の条件に三つ足した（`start_when` と、板に出すかどうかの両方で使う）。実装済み。

| 条件 `type` | 欄 | 意味 |
|---|---|---|
| `stage` | `min`, `max` | 個人の段階（`Progression.stage`） |
| `stilled` | `titan` | 自分でその巨神の心臓を止めた（`Progression.stopped`） |
| `world_stage` | `min` | 世界の進み |

| 段階 | 開くサブクエスト | 理由 |
|---|---|---|
| 0（序章〜岩鯨） | 村と空の依頼、日替わりの地上のもの | まだ背中は岩鯨だけ。ここで遊び方を覚える |
| 1（岩鯨のあと） | 岩鯨の背中の周回、潮の見張り、呼び笛の道標 | 岩鯨の背は止めた人のもの。潮殻の背にも入れる |
| 2（潮殻のあと） | 潮殻の背の周回、古い地図（雷翼の手がかり） | 次の巨神は「手がかり」までで、背中には入らない |
| 3・4 | 雷翼・余燼の背のもの（その巨神の担当が足す。14 の 5.2） | 同じ形 |

- **まだ開かないものの見せ方**: クエストログに、一つ先の段階のものだけ題を伏せて灰色で出す（「？？？ 岩鯨の心臓を止めると」）。先がある、と分かることが「物語を進めたい」につながる。二つ先は出さない。
- 遅れて来た人: 一度きりのものはいつまでも残る。日替わりは段階が届いた日から受けられる。

### 8.4 繰り返し

| 型 | 区切り | 一人が受けられる数 | 経験値 | 品 |
|---|---|---|---|---|
| 一度きり | なし | 全部 | 07 の決まり（`quest:<名前>` の鍵で一人一回） | 一度だけ |
| 日替わり | ゲーム内の 1 日（夜明け） | 一日 3 つまで（`Board.QUOTA`。枠なしだと周回の作業になるため） | 段階の推奨レベルの敵 5 体ほど | 巨神ごとの素材 |
| 週替わり | 7 日 | 種類ごとに 1 回（枠に数えない） | 日替わりの 3 倍ほど | 再鍛造の素材 |

- 日の数え方（`Repeats.day`）は、昼夜の時刻（寝る・`/time set` で進む）と、経ったゲーム時間（24000 tick で 1 日。`doDaylightCycle` を切っていても進む）の大きいほう。日替わりの入れ替えも「次の入れ替えまで」の表示もこれで決まる。
- 板に出る日替わりは**ワールドの日数で決まる抽選**（その日に開いているものから 5 つ。`Board.DRAW`）。同じ日は全員が同じ顔ぶれを見る。受けられるかは人ごとの段階で決まり、届いていないものは灰色。
- 経験値はふつうの決まり（上限、推奨 +3 からの減り）を通る。上限にいる人は品だけを受け取る。
- 繰り返しの報酬は、鍵を日ごとに増やさず、クエストごとに「最後に払った周期」を一つ持って二度は渡さない。
- 07 の `loop_reset`（月のループで戻す）はそのまま使える。

### 8.5 マルチでの共有

| もの | 決まり |
|---|---|
| クエストの記録 | 人ごと（07） |
| 撃破・近く（`kill`・`near`） | 本人と、6.2 の分け前と同じ条件の仲間（64 ブロック以内、同じ背中なら距離を問わない）が数える。目的に `party: true` を書いたものだけ（既定は true） |

## 10. 背中のグループごとの進み

背中（巨神ごとのディメンション）は一つを共有する。進みは**グループごと**に持つ。グループ = パーティ、またはパーティに入っていない一人（一人のグループ）。同じ背中に二つのグループがいても、片方が開けた扉はもう片方には閉じたまま、片方の敵はもう片方には見えず、片方が倒した心臓はもう片方の進みに影響しない。コードは `titan/group/`。

### 10.1 グループの鍵と記録

- 鍵（UUID）: パーティなら**パーティの id**、一人ならプレイヤーの UUID（`Groups.keyOf`）。
- 記録（`BackGroupData.Record`、背中のディメンションごとに保存 `skyabyss_back_groups`）: 試練の番号（epoch。グループがリセットされるたびに +1。休み場の記録に同じ番号を書き、違えば無効）、心臓を倒したか、宝物庫の封印を解いたか、制圧した広間、周回の数、扉の上書き、巨神ごとの進み（鳴らした石・受光・灯・巣・拠点の状態などを自由な欄 `data` に旗・数・文字列で書く）、最後にだれかが背中にいた時刻。
- 共有のまま（グループに分けない）もの: 背中の建物と配置の版、アスレチックと迷路の形（`TitanBackData`）、潮や雷の時計（環境）、天の鍵の欠片を受け取った人（個人）、報酬と欠片は人ごと（これまでどおり）。

### 10.2 扉（封印の扉 `SealedGateBlock`）

- 扉はいつもブロックとして置いてある。ブロックの `OPEN` は、グループの上書きがないときの状態（建てたときの形。潮で開く扉のようなワールド全体の決まりもここ）。
- グループが開ける・閉めるのは、そのグループの記録の**上書き**（`GroupGates.open/seal/release/isOpen`）。ワールドのブロックは書き換えない。
- **サーバーの当たり判定**: `getCollisionShape` が動く者（人・グループ付きの敵・その飛び道具）のグループの上書きを見て、開いていれば通す、閉じていれば止める。サーバーの移動の検査も同じ判定なので引き戻しは起きない。
- **見た目とクライアントの当たり判定**: サーバーが人のグループの上書きを送り（`GroupOverlays`）、クライアントが自分の画面のワールドのブロックの状態を上書きする（開いた扉は何もない状態、閉じた扉は見える状態）。クライアントの当たり判定はそのブロックの状態そのものなので、サーバーの判定と合う。上書きは毎 tick 見直し、サーバーのブロック更新で戻されても当て直す。グループが変わる・次元を移る・ログイン・倒れて復活したときは送り直す（`GroupEvents.resync`）。送り直しは、復活や次元の移動ではクライアントのワールドが作り直されて古い状態が消えるので、届くのが作り直しと同じ tick でもよいよう約 1 秒後にもう一度送り、念のため背中にいる人には 10 秒ごとにも送る。クライアントは、ワールドが変わったとき、受け取った上書きが新しいワールドのものなら残す（古い版は変わった瞬間に全部捨てていたため、倒れて戻ると封印の扉が透けて見え、サーバーでは通れなかった。同じパーティの人でも起きた）。見えなくする他グループの人の一覧も同じ。
- 扉の状態: 閉じて始まる（宝物庫の封印・奥の扉・出口）、開いて始まる（広間の入口・心臓の間の入口。戦いのあいだ、そのグループにだけ閉じる）。開いて始まる扉もブロックとして置く（`GroupGates.place`）。

### 10.3 見かけだけの仕掛け

当たり判定も水も変わらない仕掛け（鳴った共鳴石・石の灯・戻りの床・棒の電球・受光器・鏡の向き・花台の光など）は、グループの記録から「そのグループに見せたい状態」を出して、扉と同じ仕組みでそのグループの画面にだけ当てる（`GroupOverlays.register`）。ワールドのブロックは「まだ何も進んでいない」姿のままなので、サーバーの判断は記録を読む。

### 10.4 部屋の占有（`RoomLocks`）

水・溶岩・足場・水路・床の割れ方のように、当たり判定や水の動きが変わる仕掛けは、見る人ごとに変えられない。そういう部屋は**一度に一つのグループだけ**が入れる。

> **順路（[32](32_titan_raid_route.md)）での扱い**: 周回の三つのセルは区画を分けず一組を共有し、グループごとの上書き・敵の持ち主・戸で分かれるので、占有しない。占有するのは初回（物語）の体の中の原型だけ（32 の 5 章。決定 207）。
- 占有する部屋では、最初に入ったグループが持ち主になる。ほかのグループが入ると入口の外へ戻し、「別のパーティーがこの試練に挑んでいる。出てくるのを待とう」を出す。
- 持ち主の誰かが中にいるあいだは持ち主のまま。全員が出て 20 秒たつと手放し、部屋を最初に戻す。次に入ったグループが持ち主になるとき、部屋はそのグループの記録（種・進み）から作り直す。
- 部屋の進み（解けたか）はグループの記録にあるので、解いたグループは部屋に戻る必要がない（試練の部屋は行き止まりの枝で、解いたあとに要るのは石を鳴らした記録だけ）。
- どの部屋がこれにあたるかは、巨神ごとの文書（岩鯨 02、潮殻 08、雷翼 12、余燼 13）。岩鯨の背は、部屋の物理が戦いで変わらないので占有を使わない。

### 10.5 敵とボス（`GroupOwned`）

試練の敵・ボスは、湧かせたグループの印を持つ（`GuardMob` と潮殻の巣）。

- 見えない: 他グループの人には、その個体のパケットを送らない（`broadcastToPlayer`）。描かれず、当たらず、鳴き声・足音も届かない。
- 狙わない・傷を受けない: 最寄りの探索から他グループの人を除く（`canAttack`）。他グループの人・敵が与える傷は取り消す（背中の中だけ）。飛び道具は持ち主のグループで数える。
- ボスの体力バー・技の対象の一覧は、そのボスのグループの人に絞る。
- 他グループの人は、お互いの画面で描かれない（名前札・影ごと。`GroupNetwork.Hidden`）。当たり判定の押し合いは残る（チャットの近さも変えない）。
- 限り: ゲームの粒（`sendParticles`）は近くの全員に届く（敵の技の予告の粒など）。音は敵の鳴き声・足音を絞るが、技の効果音は近くの全員に届く。

戦いは**グループごとに別の部屋**で動く（`GroupBossRooms`・`GroupBossRoom`）。同じ空間でグループごとに別のボスが同時に戦える。戦いの参加者は、倒れる瞬間に部屋にいた人・部屋で倒れた人・部屋にいたまま切断した人（M6）。戦いの途中から入った人が参加者になるには、30 tick 以上部屋にいること。部屋で倒れた参加者は、前室で目を覚まして 20 秒たつと扉から戻れ（戻った直後は 3 秒の守り）、戻れる回数は人ごとに戦い 1 回につきゲームルール `skyabyssHeartReentryLimit`（既定 3、0 = 数えない）まで。使い切ると戦いが終わるまで通れない。中に生きた参加者がいなくなる（全滅）と戦いのやり直しで回数も戻る（参加者には残る。`GroupBossRoom.fallen()`・`rejoinable(level)`・`Reentry`。02 の 4.2）。四つの心臓の間（`GroupBossRoom`）と岩鯨の広間（`TitanBackTrials`）に共通の決まり。

**倒したあと**: 心臓を倒したグループには、人が部屋に残っていても、集合も湧かせ直しもしない（`GroupBossRoom.Host.defeated`。四体の心臓の部屋すべてが、そのグループの撃破の記録で答える）。運び出しは撃破の 9.5 秒あとなので、それまで部屋にいる人のために心臓がもう一度出ることはない。試練が戻って記録が消えれば（10.6）、また挑める。心臓のボスゲージは、倒れ始め・消えたとき・別のディメンションへ移ったとき・切断・復活のどれでも、その人から外す（`HeartBoss`。部屋が空で心臓が動かなくても外れる）。

### 10.6 リセット

- グループごとに戻す: グループの動いている人が背中にいないまま 3 分、または心臓を倒したあと心臓の間の入口より奥に 30 秒だれもいない、で、そのグループの試練だけが戻る（番号 +1、進みと扉の上書きを消す、そのグループの敵と戦いを片付ける、体内のそのグループの人を安全な所へ出す）。ほかのグループには触れない。
- 世界で戻す: 背中に動いている人が一人もいなくなって 3 分たつと、みんなで共有するアスレチックと迷路を新しい種で作り直す（進みのない古い記録も捨てる）。進みのあるグループの記録は残る。
- 背中を建て直したとき（配置の版が変わった）は、全グループの進みを戻す。

### 10.7 パーティを組む・入る・抜ける

進みはグループの記録にあるので、途中でグループが変わるときの決まり:

| 場面 | 記録 |
|---|---|
| 組む（リーダーが招待して受けられた） | パーティの記録は、**リーダーの一人の記録の写し**から始まる |
| 入る（できているパーティへ） | パーティの記録をそのまま使う。入った人の元の一人の記録は使わない（残るが、抜けるまで見えない） |
| 抜ける・外される | 抜けた人の一人の記録は、**そのときのパーティの記録の写し**になる。進みは取り上げない |
| 解散（一人に戻る） | 残った人の一人の記録も、そのときのパーティの記録の写しになる |
| 背中の体内にいるとき | 記録が変わるので、順路の途中の人は、今の段の入口の休み場へ移して知らせる（先の部屋に取り残さない）。休み場の記録は番号が違えば無効 |

心臓を倒した参加者の「止めた」の記録（乗る資格）と欠片・報酬は個人のもので、グループの引き継ぎとは別（3.3）。引き継いだ進みで扉を通れても、報酬と資格は戦った人にだけ付く。

### 10.7.1 ギルド（パーティとは別。35 の 6.5）

- パーティ（6 人まで・背中の進みを分ける）とは別の、プレイヤーが作る長い付き合いの集まり（30 人まで）。背中の進み・報酬・乗る資格には関わらない。ギルドの中からパーティを組みやすくするだけ。
- 作る・申請・受ける・抜けるは組合の受付の書記の画面か `/guild`。名札・チャット・Tab の名前の頭に「[印]」。記録はワールド（`GuildData`）。ギルドの倉庫・週替わりの頼みはまだ。

### 10.8 負荷

- 敵の数: 一つのグループが同時に相手にする敵は、岩鯨の広間で最大 15 体前後（6 人のとき）。3 グループが同時に試練の戦いをしても、全体で 50 体前後。敵は湧かせたグループにしか送られないので、通信は増えない（サーバーでの AI は動く）。心臓はグループごとに 1 体。
- 扉: ブロックの当たり判定は、動く者が扉に当たったときだけグループの上書きを引く（ハッシュの引き）。クライアントの上書きは数十〜数百座標で、毎 tick 見直すのは範囲内の読み込まれた座標だけ。
- 記録: グループごとに小さな NBT と扉の上書き（座標の配列）。使われない記録は 10 分で捨てる。

| `titan/group/FightBadges`・`record/FightBadgeData` | 倒れた回数の札（10.14） |

**試練のあとの石はパーティのもの**（`TrialSteles`）: 共鳴石・潮鳴り石・風鳴り石・熾り石は、だれかが鳴らせばそのグループ（パーティ、一人ならその人）の全員が「踏破した」ことになる。石の状態はもとからグループの記録にある。人ごとのクエストの石の合図（`<tide|storm|ember>_trial_<west|east|front|south>`、岩鯨は `whale_trial_<0|1|2>`）は、`Quests.poll`（1 秒ごと）が**その人のグループの記録から数える**（種類 `signal` の目的の数 = 鳴っている石の数、増えるだけで戻らない）。だから、別の場所・別の次元にいる仲間、あとからログインした人、あとからパーティに入った人（10.7 の引き継ぎ）のクエスト・目的の帯・次の段階も更新される。抜けた人は持っていた数を保つ。パーティに入っていない人は他のグループの石を数えない。鳴らした瞬間、石のある背中の外にいるオンラインの仲間には、静かな知らせを一度だけ出す（`message.skyabyss.steles.party_rung`。背中の中の人は「石が鳴った」の知らせをすでに受けている）。個人の報酬（経験値）は変えない: 鳴らした瞬間に、石の近くの人へ満額・オンラインの仲間へ分け前（`Parties.absentMates`）を一度だけ。記録から合わせるだけの人・あとから入った人・オフラインだった人には追加で出さない（石の鳴らし直しや記録を使った稼ぎはできない）。石が鳴ったことで開く扉はグループの記録にあるので、全員に開く。

**石の「誰が鳴らしたか」**（表示だけ。共有の仕組みは変えない）: 石を鳴らした人を `SteleRingers`（オーバーワールドの保存。グループ → 石の合図 → 人）に控える。すでに鳴っている石に触ると、画面の下（BAR）に「石: あなたが鳴らした」「石: ○○ が鳴らした（あなたは踏破として数える）」と出す（まだ鳴っていない石は鳴らす操作になる）。控えがない石（この機能より前・コマンド）は「仲間が鳴らした」。石を戻せば控えは見えない（「まだ」）。控え帳の巨神の頁に「試練の石」の行（自分 n・仲間 n・まだ n と、石ごとの一行。11 の 3.1）。

**仲間の位置**（`PartyLocator`、パケット `party_pos`）: 同じパーティの人にだけ、ほかの仲間の次元・位置（1 ブロック刻み）・体力（10% 刻み）を送る。0.5 秒（10 tick）ごとに見て、受け取る人ごとに中身が前に送ったものから変わったときだけ送る（だれも動かなければ送らない）。抜ける・解散・ログアウトのときは空の一覧を一度だけ送って止める。パーティの外の人の位置は、だれにも送らない。6 人まで。別の次元（別の背中）の仲間は、次元の名前だけを使う。
クライアント（`PartyMarkers`）は HUD に投影して描く（光る輪郭ではない）: 画面の中の仲間は頭の上に記号・名前・距離（m）の小さな札（壁の向こうでも出る。4 m 以内は出さない）、画面の外の仲間は画面の縁の小さな矢印と名前・距離、別の次元の仲間は右の仲間の一覧の行の下に「別の場所: 〇〇」。札・矢印は体力で色が変わる。置き場は 18 の 8.1。場面（シネマティック）の最中・画面を開いている間・F1・デバッグ画面では出さない。クライアント設定 `partyMarkers`（既定 true）で消せる。絵: `docs/review/previews/party_marker_*.png`。 色だけに頼らないよう、札・矢印の名前の左に体力の記号（無事 = 塗りつぶし・傷 = 枠と下半分・瀕死 = 感嘆符。しきい値 50% / 20%）と、札の下に体力の長さの棒を描く（`PartyMarkers.Symbol`・`drawMarker`。墓の標と共用）。

自己テスト: `SELFTEST party locator`（パーティの外へ送らない・一覧に自分と外の人が入らない・変化がなければ送らない・抜けたら空を一度だけ・解散後は止まる）、`SELFTEST party steles`（一人が鳴らすと離れた仲間も数える・パーティ外と一人のグループは数えない・あとから入った人は引き継ぐ・抜けた人は保つ・何度合わせても数も経験値も増えない・四つの巨神の石の記録を引ける）、`SELFTEST group`（部屋の占有・戦いの参加者・個人の影・乗っている人・放置の分け前）、各背中の `titan back (groups)`・`tide back (groups)`・`storm back (groups)`・`ember back (groups)`（二つのグループ: 扉の当たり判定がグループで分かれる・上書きの見かけ・敵が見えず狙わず傷を受けない・心臓と広間の記録が混ざらない・六人のパーティ・組む・抜ける引き継ぎ）。

### 10.10 初回と周回の共通部品（`FirstRun`）

21 の 1.7 の「初回/周回」の土台。部屋そのもの（P8/P13/P17/P21）はここへ登録するだけで、周回の挙動が揃う。

- **初回の定義**: グループの記録（`BackGroupData.Record`）の `keep.first_cleared`（`isFirstCleared()`／`markFirstCleared()`）。心臓を止めた瞬間に、戦った人と同じパーティのグループへ立つ（`TitanEnd.onHeartStopped` → `FirstRun.onFirstCleared`）。`keep.` の欄なので試練のリセットで残る。パーティの組む・入る・抜けるは 10.7 のとおり記録ごと写る（組む＝リーダーの写し、入る＝パーティの記録、抜ける＝パーティの写しで進みは取り上げない）ので、道（初回か周回か）はそのとおりにグループの記録に従う。巨神ごとの背中のディメンションに一つずつ持つので、巨神ごとに独立。
- **部屋の登録**: `FirstRun.register(Room.firstRun(id, 次元, 範囲))`。周回でも初回の部屋は、ふつうの部屋として遊ぶ（「既知の道」の戸・光る床はない。32 の 0 章）。部屋の敵・仕掛けを湧かせる所は、`FirstRun.allowSpawn(level, group, roomId)`／`allowSpawnAt(level, group, pos)` の結果が false なら出さない形を保つ。
- **任意の翼**: 置かない（32 の 0 章）。`Room.optional(...)` の使い道はない。素材の報酬は `FirstRun.grantMaterials(人, 品)` で何度でも渡す。
- **場面**: `FirstRun.registerScene(Scene)` で場面（20 の台本の形。名前＝Scene の id）を足し、`FirstRun.playFirstScene(人, 名前, 狙う物, 向き)` で出す。人ごとの記録 `cine_seen.<名前>`（`CinematicState` に頭をつけて持つ。`sceneSeen`）が立っていない人にだけ出て、出した時点で立つ。スキップは場面の仕組みのとおり（`onSceneEnd` で終わりの効果を掛ける）。場面が未登録なら何もしない（見たことにもしない）。道はグループ、場面は人ごと: 周回のグループにいる初めての人には出る。
- **追憶の宝**: `FirstRun.grantKeepsake(人, id, 品)`。人ごとに一度きり（`FirstRunData`＝オーバーワールドの記録。死んでも・パーティが変わっても残る）。備えの品・素材・小さな装飾だけで、巨神の装備（`ModGear`・武器・防具）が混ざると何も渡さず拒む（`keepsakeAllowed`）。グループの初回・周回には関わらず、初めての人が受け取る。
- 自己テスト: `SELFTEST back first`（first_cleared の前後・グループごと・リセットで残る・パーティの組む入る抜ける・場面が人ごとに一度・宝が人ごとに一度で装備は拒む・素材は繰り返す）。

### 10.12 仲間が起こせる仕組み（`party/Downed`。rpg_brushup B1）

背中の中（戦いの部屋を含む）で、**起こせる仲間が残っている**人の致命の傷（`LivingDamageEvent.Pre`。体力 + 吸収以上の傷）は、傷を「体力 1 が残る量」に抑えて**倒れた状態**にする。虚空・`/kill` など無敵を貫く傷は耐えない。起こせる仲間とは、同じパーティで、同じ次元にいて、生きていて、倒れていない人（`Downed.rescuers`）。一人用・パーティの仲間が地上にいる・全員が倒れている人は、倒れずに死ぬ（そのあとは 02 の 4.2 の再入場）。

| 項目 | 決まり |
|---|---|
| 倒れている時間 | 15 秒（300 tick）。残りは本人の画面中央下に棒で出る |
| 倒れた人 | その場で這う姿勢（強制ポーズ）・ほぼ動けない（鈍足）・攻撃・使う・ブロックの操作・壊すは受け付けない・敵の狙いは外れ（新しく狙われもしない。`GuardMob.canAttack`・`LivingChangeTargetEvent`）・傷を受けない（戦いの予告の判定の傷も。虚空と `/kill` は別）。体力は 1 のまま、足もとに輪の粒 |
| 起こす | 起こす人が倒れた人（3.5 ブロック以内）を見て「使う」を押し続ける。クライアントが 2 tick ごとに `revive_hold` を送り、サーバーが距離・同じパーティ・倒れた状態かを検める。3 秒（60 tick）で起きる。傷を受けた（`hurtTime`）・横に 1.5 ブロック超動いた・離れた（4.5 ブロック超）・押すのをやめた（信号が 8 tick 途切れる）と、進みは 0 に戻る |
| 起きたとき | 体力 3 割、`ReentryRules.guard` の短い守り（3 秒光る・傷を受けない・狙われない）。**再入場の回数に数えない**（死んでいない） |
| 時間切れ・全滅 | 15 秒たった・起こせる仲間がいなくなった（全員倒れた・離れた・退出）と、その場で死ぬ。死の知らせは通常どおり（`GroupEvents.onPlayerDeath`）で、`GroupBossRoom.noteDeath` → `Reentry.fell`（20 秒の待ち・回数の決まりに入る） |
| 後始末 | ログアウト・次元の移動・サーバー停止で状態を捨てる（ポーズ・鈍足も戻す） |
| ゲームルール | `skyabyssRevive`（既定 true）。false だと倒れた状態を使わず、これまでどおり死ぬ。倒れている最中に false にされたら、そのまま時間切れと同じに死ぬ |

見せ方: 倒れた本人は画面の縁に薄い赤み・中央下に「倒れている」と残り秒の棒・「仲間が起こしに来るまで あと N 秒」（起こされている間は「起こされている…」と緑の進みの棒）。仲間には、倒れた人の頭の上（画面の外なら縁の矢印）に **×** の札「名前　倒れた N 秒　距離」（`PartyMarkers.drawMarker`・`Symbol.DOWNED`。クライアント設定 `partyMarkers` で札だけ消せる）、倒れた人を見ると「〇〇 を起こす: 使うを長押し」と照準の周りの進みの輪。倒れた瞬間、仲間にはアラートの帯「〇〇 が倒れた。使うを長押しで起こせる」。サーバー → 人のパケット `downed_sync`（パーティの倒れた人の一覧。残り時間は 5 tick 刻み・進みは 5% 刻みで、変わったときだけ 0.25 秒ごとに。パーティの外には送らない。誰も倒れなくなったら空を一度だけ送って止める）と、人 → サーバーの `revive_hold`（対象の UUID だけ。サーバーが検め直す）。

自己テスト: `SELFTEST party revive`（倒れる → 起こす 3 秒・体力 3 割・守り・ポーズが戻る・同期は仲間にだけで変化なしは送らない／傷・離れる・やめるで中断／時間切れ → 死 → 再入場の記録・倒れた回数を二重に数えない／起こされた人が再入場の回数を使わない／全滅と退出で即死／一人用・別の次元の仲間・ルール false・無視できない傷では倒れない）。

### 10.13 「ここ」の印（`party/Ping`。rpg_brushup B10）

キー 1 つ（`key.skyabyss.ping`、既定 **'**（日本語配列では : の位置。M は旅の地図（33 の 4 章）。バニラは X = 「ホットバーを読み込む」、C = 「保存」なので避けた。バニラ・Mod の既定と重ならない。設定で変えられる）で、**見ている先**（ブロック・生き物。64 ブロックまで。サーバーが視線を調べる。クライアントの値は信じない）を、同じパーティの仲間と自分の画面に、名前と距離つきの印として 8 秒（160 tick）出す。敵（`Enemy`）を見ていれば**敵の印**（印は生き物を追う）。何も当たらなければ出さない。背中でも地上でも使える（印は同じ次元の仲間にだけ。別の背中の仲間には送らない）。

- **制限**: 0.5 秒（10 tick）あける・10 秒（200 tick）の窓に 5 回まで（人ごと）。パーティの外・一人のパーティは何も送らず、「仲間のいるときだけ使える」の字幕を本人にだけ出す。一人の送り主につき印は一つ（新しく出すと置き換わる）。見えない個体（別グループの敵。`GroupOwned.visibleTo`）は指せない。
- **見せ方**（`PartyMarkers.drawMarker` と同じ描き方。HUD）: 友の印は **菱形**・淡い青、敵の印は **下向きの三角**・朱（色に頼らない形。A11）。ラベルは「名前  距離m」「名前: 敵  距離m」。短い音（友: 高い玉の音、敵: 低い音）がクライアントで鳴る。クライアント設定 `partyMarkers` で描画を消せる。
- パケット: 人 → サーバー `party_ping_request`（中身なし）、サーバー → 人 `party_ping_show`（送り主・名前・次元・位置・生き物の id・敵か・残り tick）。

自己テスト: `SELFTEST party revive` の後半（本人と同じ次元の仲間にだけ届く・別の次元の仲間とパーティの外には届かない・敵の印・クールダウン・窓の上限・窓が過ぎれば戻る・人ごとに別の制限・一人は送らない）。

### 10.14 倒れた回数の札（`titan/group/FightBadges`。rpg_brushup B6）

心臓・中ボスの戦い（`GroupBossRoom`。四つの心臓、灰の鍛冶、雷獣）に勝ったとき、**その戦いでパーティが倒れた回数**で称号の一行を付ける。見た目だけで、報酬・強さは変えない（ソフトな死の罰を保つ）。

- **数え方**: 戦いの間に、参加者が倒れた状態に入った回数（`GroupBossRoom.noteDown`）+ 倒れずに死んだ回数（`noteDeath`）。倒れた状態のまま時間切れで死んだ分は、倒れたときに数えているので二重にしない。起こされた人は 1 回（倒れた分だけ）。戦いの始まり・やり直しで 0 に戻る。
- **札**: 0 回「無傷の誓い」、2 回まで「堅き歩み」、それより多ければ札なし（回数だけ見せる）。
- **見せ方**: 勝った瞬間に、参加者それぞれの画面に右上の札（GAIN）「札「無傷の誓い」　この戦いで倒れた回数 0」（最良を更新したら字幕で「控え帳の最良を更新した」）。札なしのときは字幕で「この戦いで倒れた回数 N」。
- **記録**: 人ごと・巨神ごと・戦いの種類（心臓 `heart` / 中ボス `mid`。`HeartBoss` かどうか）ごとの**最良（最少）**を `FightBadgeData`（オーバーワールドの保存）に控え、控え帳の巨神の頁（11 の 3.1）に「倒れた回数の札: 心臓」「同: 中ボス」の行で出す。岩鯨の番兵長の広間（`TitanBackTrials` の番兵の波）も、`HallState.falls` で同じ数え方をして、番兵長に勝ったとき中ボスの札を付ける（第一の広間は対象外）。

自己テスト: `SELFTEST party revive`（札の境目 0・1〜2・3 以上、最良だけが更新される、巨神・種類の取り違えがない、`GroupBossRoom` が倒れた状態と倒れずに死んだ回数を数え二重にしない、勝ったときに記録される）、`SELFTEST record`（控え帳の符号化に新しい行が耐える）。

### 10.15 誓い（`titan/vow`）

> **順路（[32](32_titan_raid_route.md)）での扱い**: 誓いは祠で選ぶ（碑をしゃがんで右クリック。選べるのは祠のそば・順路が動いていないあいだだけ。32 の 3.1）。周回の言い回しはない。

21 の 1.8 の実装。`FirstRun` の初回/周回（10.10）の上に載り、周回のグループにだけ働く。

- **誓い**: `Vow`（数字の束）を `Vows` の登録表に持つ。選択は `Vows.add / remove / clear`（`canChange`: 背中がある・周回・`Record.hasProgress` が false。結果は `Vows.Result`）。置き場はグループの背中の記録の `keep.vows`（id のコンマ区切り）と `keep.vow_start`（時間制限の始まり）。`keep.` なので試練のリセットでは残り、パーティの組む・入る・抜けるでは記録ごと写る（10.7）ので、全員が同じ誓いを見る。
- **効き**: 体力は `VowEvents.applyFoeHealth`（1 秒ごとに背中の `GroupOwned` の敵へ、そのグループの誓いの分の属性修飾を一度だけ）、傷は `LivingIncomingDamageEvent`、野営禁止は `BlockEvent.EntityPlaceEvent`（`CampBlocks.isCamp`）、時間制限は背中に最初に誰かが入った時刻から（`Vows.timerRemaining`・`effective`）、予告の短縮は `Telegraph` の組み立てが持ち主の `Vows.telegraphWarn` を通す（最短 16 tick）。
- **報酬**: `TitanEnd.onHeartStopped` が `FirstRun.onFirstCleared` のあとに `Vows.onHeartStopped` を呼ぶ。戦ったグループごとに、背中にいるそのグループの人へ `Vows.reward`（素材の上乗せ・共鳴の欠片・最高の段の記録・称号の知らせ）、そのあと誓いを降ろす。最高の段は `FirstRunData.vowBest`（人 → 巨神 → 段。オーバーワールドの記録）。
- **帯**: `VowNetwork.Sync`（巨神・誓いの id・段・時間制限の残り秒）をグループの全員へ送る（変えたとき・ログイン・次元の移動・時間制限中は 5 秒ごと）。画面は `client/vow/VowHud`（右上）。
- **lang**: 誓い・帯・語り部・控え帳の行はすべて名前空間 `skyabyss_vow`（ja/en）。
- 自己テスト: `SELFTEST vow`（登録・段・倍率・称号・予告の短縮と最短・選べる条件・パーティで揃う・体力と傷と野営禁止・時間制限・報酬と最高の段と降ろす・ja/en の文）。居座りの早じまいは `SELFTEST stay leave`（08 の休息、`TitanStay.Vacancy`）。

### 10.16 試練を越えたあと・戦いの人数・湧きの安全（`trial/TrialHub`・`util/SpawnSafety`）

> **順路（[32](32_titan_raid_route.md)）での扱い**: 越えると次の段の入口の休み場へ運ばれる（32 の 2.3）。順路ではグループ全員が同じ試練にいるので、戦いの人数は実質パーティの人数。セルの部屋は一組を共有し、グループごとの上書き・敵の持ち主・戸で分かれる（32 の 5 章）。湧きの安全はそのまま。

- **パーティごとの進みは共有の背でもグループごと**（既存。10.1〜10.3）: 石・扉・見かけの上書き・敵の持ち主・引いた三つはすべて `BackGroupData` のグループの記録から出る。別のグループと混ざらない（自己テスト `trial pool` が二グループの戸と進みを確かめる）。
- **越えたあと**（32 の 2.3）: 試練を越えると（ゴールの印に着くと）、そのグループの順路の参加者のうち、その背にいる人が 4 秒後に次の段の入口の休み場へ運ばれる。越えた試練へは戻らない。個人の「真ん中へ戻る光」は出さない。
- **戦いの強さは、その試練に入った人の数**で決まる（パーティの人数ではない）。広間の参加者（`HallState.participants`）・砦の中・干潟の中・火床の部屋の人を数える。パーティが分かれて別々の試練に入れば、それぞれの戦いは小さくなる。

### 10.4 一つのグループが心臓を止めたとき、まだ背中にいるグループ

巨神の眠りは世界に一つ（`TitanDormancy`）。ただし、背中の中のグループの進みは、眠りのせいで切られない。

- **去る**: どれかのグループが心臓を止めると、巨神は元の世界から去る（眠りの姿は巨神ごと。01 の 4.3）。乗り込み口の光は消え、**新しく乗ることはだれにもできない**（`Progression.checkBoard`、`BoardGlow`、呼び笛）。乗ろうとした人には「元の世界から去って、深い眠りの中にいる」と一行。
- **中のグループはそのまま続ける**: すでに背中にいるグループの試練・中ボス・心臓は止まらず、リセットもされない。心臓を止めれば、同じ報酬、欠片（一人一つ）、運び出し（戦った人とそのパーティの人のうち同じ背中にいる人）、初めての人には眠りの場面。降ろされるのは眠っている巨神のそば（降ろす先は巨神ごと。`TitanEnd.landing`）。眠りは数え直さない（`TitanDormancy.begin` は眠っていれば何もしない）。
- **背中の人の出入り**: 背中の中で倒れて戻る、ログアウトして入り直すは、これまでの休み場の決まりのまま（背中の中に戻る）。背中から出た人は、巨神が目覚めるまで乗り直せない。
- 停泊（`TitanStay` の 20 分）の最中の岩鯨が眠りに入ったときは、沈む余地がほとんど無いので、巡航の高さまで昇って去る（秒速 5 ブロック。眠りが勝つ）。他の三体は、停泊の姿のまま海へ沈む・峰へ降りる・土へ埋まる。
- **目覚め**: `TitanDormancy.tickWake`（1 秒に 1 回）が、次の二つがそろったときに起こす。(1) 眠りが始まって最短 90 秒（`MIN_TICKS`。どれかのグループの試練が戻る `requestWake` で時刻が決まる）。(2) 背中の中で続けているグループが 0（`GroupProgress.activeInside`）。続けているグループ = 動いている人（観戦者と 5 分動いていない人を除く）がその背中にいるグループ、または試練が進んでいて心臓をまだ止めていないグループ（全員が背中を離れていても、放置のリセット（3 分）までは続けている扱い。ログアウトや再起動をまたぐ）。心臓を止めたグループ（運び出されたあと）と、進みのないグループは数えない。
- 安全弁: 眠りが 15 分を超えても、続けているグループがいなければ起こす。いても 60 分（`HARD_MAX_TICKS`）で起こす。起こすことは、背中の中のだれも動かさない（地上に目覚めの一行が出て、試練の復活は各グループのリセットで起きる）。
- **保存**: 眠りの始まりと目覚めの時刻（オーバーワールドのゲーム時間）は `skyabyss_titan_rest` に保存する。続けているグループは背中の記録（`BackGroupData`）から毎回数えるので、再起動をまたいでも同じ答えになる。全体のリセットはない。
- 自己テスト: `SELFTEST titan end`（02 の 9.2）の最後の段。A が心臓を止める間 B が試練の途中にいる → 巨神は去り、新しい人は乗れず光も出ない、最短を過ぎても B がいるあいだは起きない、眠りの保存、B が心臓を止めると運び出される、眠りは数え直さない、B が終わっても最短の前は眠る、最短を過ぎて B が終われば目覚めて乗れる、進みが残るあいだは起きず最後のグループが戻ると起きる。
