# 45 町と建物の作り（並べ方と家の形）

- 状態: **作りかけ**。土地の町の並べ方を 3 案（A 街道と市場・B 環の道と高台・C 小路の旧市街）で作り、選ぶところ。家の形の部品（`tools/capital/massing.py`）はできた。
- 関連: [40 大陸の世界とはじめ](40_rpg_world_and_start.md)（土地の町の場所・門・道）、[35 都の施設](35_capital_facilities.md)（施設の中身）

## 1. 手本と、そこから取った決まり

手本にしたもの:
- 名のある大型の街: WesterosCraft の王都（地区ごとに家の作りが違う）、ElysiumFire の Novigrad（赤い屋根の詰まった町並み・細い路地・大聖堂・港）、Wynncraft の町。
- 建築の手引き: 形が先、奥行き、屋根の出と色の対比。
- 中世の町割り: 道に面した細長い区画（burgage plot）、市場のくさび形の広場、裏の小路。

### 1.1 建物

- **形が先**: 足もとの形（細長い・L 字・塔）、棟の向き（妻入りと平入りを混ぜる）、階の数で、屋根の線を揃えない。
- **奥行き**: 上の階を通りへ一つ張り出す（持ち送りの木）。軒を 1 出す。屋根の裾を反らせる（一段目だけ緩い）。壁は柱型と帯で凹凸を付ける（`vox.Body` のまま）。
- **屋根の形**: 急な切妻・緩い切妻・反りの切妻・寄棟・半切妻・段の妻（商家）・尖り屋根（塔の家）。
- **屋根の色**: 土地の瓦を主に、二〜三の色を混ぜる（`Style.roof_alts`）。
- **飾りの棘**（避雷の棒の頂）は商家・塔・施設だけに付ける。普通の家に付けると、町の屋根の線が騒がしくなる。

### 1.2 並べ方

- **道に格を付ける**: 大通り（幅 7）・通り（5）・小路（3）・裏の路地（1）。
  - 大通りは門から市場へ通す。途中で曲げて、先が真っ直ぐ抜けないようにする。
  - 曲がりの先には目印の建物（見張りの塔・社）を置く。
- **区画**: 通りに面した間口は狭く（5〜9）、奥に長くする。
  - 家は通りの線に揃えて寄せる。
  - 裏は庭（柵・畑・木・物置）で、奥行きは区画ごとに違う。
- **密度の勾配**:
  - 市場のまわり: 隙間なく、3〜4 階、商家と張り出しの家。
  - 中ほど: 隙間 1、2〜3 階。
  - 外れ: 隙間 2、1〜2 階、小屋と L 字の家、緩い屋根。
- **市場は四角にしない**。通りが太って広がる形にし、宿・社など良い建物で囲む。
- **囲いは多角形**にし、角に塔を置く。門の外にも小屋と畑を置き、町の外れから野へ徐々につなぐ。
- **空き地を残しすぎない**: 大きく空いた所には小路を通して家を並べる。奥の家には、戸から道まで路地を引く。

## 2. 作り（ツール）

- `tools/capital/massing.py`（家の形）: `build_house(town, kind, rect, front, floors, roof_kind, …)` と `roof(…)`。
  - 型: row（平入りの町家）・gable（妻入りの町家）・jetty（上の階の張り出し）・ell（L 字。袖は庭へ一階低く）・tower（塔の家）・cottage（小屋）・merchant（段の妻の商家、一階は店）。
  - 屋根: steep・low・bell・kick・hip・hip_low・half_hip・stepped。
- `tools/capital/town_plans.py`（並べ方）: `PlanTown`（`RegionTown` を元にする）。
  - 通りの折れ線から、片側ずつ区画を並べる（`frontage`）。
  - 施設は、戸の前が道か広場に面する所と向きを探し、回して建てる（`facilities_at` / `build_fac`）。
  - 空き地への小路（`auto_lanes`）、奥の家と路地（`infill`）、裏庭（`yards`）、門の外の畑と小屋（`outskirts`）。
  - 多角形の壁（`poly_wall`）。
  - ラフは `python -I tools/capital/town_plans.py rough whale` で作る（設計図 `town_rough_<a|b|c>.json`、上から見た図 `docs/review/town_roughs/plan_<a|b|c>.png`）。
  - 撮影は `tools/shots/town_plans.txt`。
- 家の型の見本: `tools/capital/house_sheet.py`（`town_rough_houses.json`、撮影は `tools/shots/town_houses.txt`）。
- 土地の町の宿は 21×15（客室 2 つ）。都の宿（27×17）より一回り小さくし、曲がった通りにも入るようにした。

## 3. 案（2026-10-27）

- **A 街道と市場**: 一本の大通りが南の門から北の門へ曲がりながら通り、真ん中でくさびの市場に太る。東西の通りは市場から少しずれて門へ向かう。大通りの裏には平行な小路を通す。
- **B 環の道と高台**: 真ん中に石垣の高台を置き、上に名物と広場を載せる。高台を巻く環の道に、四つの門からの大通りが入る（南と東は一度折れる）。斜めに抜ける小路が二本ある。
- **C 小路の旧市街**: ゆがんだ碁盤の小さな街区で、大通りは十字だが街区ごとに折れる。小路の交わりに小さな広場を三つ置き、街区は町家で囲む。
