# 45 町と建物の作り（並べ方と家の形）

- 状態: **決まり**（2026-10-27）。土地の町の並べ方は **A 街道と市場**。家の型 7 つと屋根の形はそのまま使う。四つの町は A 案を町ごとに鏡写しにして建てる（`python -I tools/capital/town_plans.py towns`）。
- 建築の水準: [§4](#4-建築の水準) の手本を、この mod のすべての建物の基準にする。
- 関連: [40 大陸の世界とはじめ](40_rpg_world_and_start.md)（土地の町の場所・門・道）、[35 都の施設](35_capital_facilities.md)（施設の中身）

## 1. 手本と、そこから取った決まり

手本にしたもの:
- 名のある大型の街: WesterosCraft の王都（地区ごとに家の作りが違う）、ElysiumFire の Novigrad（赤い屋根の詰まった町並み・細い路地・大聖堂・港）、Wynncraft の町。
- 建築の手引き: 形が先、奥行き、屋根の出と色の対比。
- 中世の町割り: 道に面した細長い区画（burgage plot）、市場のくさび形の広場、裏の小路。

### 1.1 建物

- **形が先**: 足もとの形（細長い・L 字・塔）、棟の向き（妻入りと平入りを混ぜる）、階の数で、屋根の線を揃えない。
- **奥行き**: 上の階を通りへ一つ張り出す（持ち送りの木）。軒を 1 出す。屋根の裾を反らせる（一段目だけ緩い）。壁は柱型と帯で凹凸を付ける（`vox.Body` のまま）。
- **屋根の形**: 急な切妻・緩い切妻・反りの切妻・寄棟・半切妻・段の妻（商家）・尖り屋根（塔の家）。
- **屋根の色**: 土地の瓦を主に、二〜三の色を混ぜる（`Style.roof_alts`）。
- **飾りの棘**（避雷の棒の頂）は商家・塔・施設だけに付ける。普通の家に付けると、町の屋根の線が騒がしくなる。

### 1.2 並べ方

- **道に格を付ける**: 大通り（幅 7）・通り（5）・小路（3）・裏の路地（1）。
  - 大通りは門から市場へ通す。途中で曲げて、先が真っ直ぐ抜けないようにする。
  - 曲がりの先には目印の建物（見張りの塔・社）を置く。
- **区画**: 通りに面した間口は狭く（5〜9）、奥に長くする。
  - 家は通りの線に揃えて寄せる。
  - 裏は庭（柵・畑・木・物置）で、奥行きは区画ごとに違う。
- **密度の勾配**:
  - 市場のまわり: 隙間なく、3〜4 階、商家と張り出しの家。
  - 中ほど: 隙間 1、2〜3 階。
  - 外れ: 隙間 2、1〜2 階、小屋と L 字の家、緩い屋根。
- **市場は四角にしない**。通りが太って広がる形にし、宿・社など良い建物で囲む。
- **囲いは多角形**にし、角に塔を置く。門の外にも小屋と畑を置き、町の外れから野へ徐々につなぐ。
- **空き地を残しすぎない**: 大きく空いた所には小路を通して家を並べる。奥の家には、戸から道まで路地を引く。
- **家どうしは決してくっつけない**: 軒の先から測って、空気のマスを必ずあける（市場のまわりと中ほどは 1、外れは 2）。
  - 裏は詰めない。奥の家は町に 6 軒までとし、まわりに 3 マス以上の空きを取る。
  - 区画は、軒の分（1）と空きを足して検査する。
  - 建てた家のブロックの柱を覚えておき（`owner`）、最後に違う家の柱どうしが 1 マスより近くないかを数える（`check_gaps`）。

## 2. 作り（ツール）

- `tools/capital/massing.py`（家の形）: `build_house(town, kind, rect, front, floors, roof_kind, …)` と `roof(…)`。
  - 型: row（平入りの町家）・gable（妻入りの町家）・jetty（上の階の張り出し）・ell（L 字。袖は庭へ一階低く）・tower（塔の家）・cottage（小屋）・merchant（段の妻の商家、一階は店）。
  - 屋根: steep・low・bell・kick・hip・hip_low・half_hip・stepped。
- `tools/capital/town_plans.py`（並べ方）: `PlanTown`（`RegionTown` を元にする）。
  - 通りの折れ線から、片側ずつ区画を並べる（`frontage`）。
  - 施設は、戸の前が道か広場に面する所と向きを探し、回して建てる（`facilities_at` / `build_fac`）。
  - 空き地への小路（`auto_lanes`）、奥の家と路地（`infill`）、裏庭（`yards`）、門の外の畑と小屋（`outskirts`）。
  - 多角形の壁（`poly_wall`）。
  - 壁の外の地面（`tools/gen/world/town_outskirts.py`。設計図に直接書く。二度は塗らない）: 設計図の縁から、柔らかい地面で上に何も無い列をたどり（道・壁・家・畑は越えない）、まわりの土地の地面へ斑で塗る（炎は赤い砂とテラコッタ、潮は砂、雷は石・砂利・雪、鯨は苔とポドゾル、都は草に少しの土）。小物（枯れ草・草・羊歯・花・小岩）は道・壁・家・畑・印の 1 まわりに置かない。大陸の道（`continent/layout.json`。設計図には入っていない）の芯から 5.5 は塗らない。都は壁の外が空なので、門のそばの畑（11 × 7、柵と水路と干し草）と木立（樫と白樺）も置く。
  - 均した台の縁: 輪 14 で、まわりの地面へなめらか（smoothstep）につなぐ（`SiteJob.buildColumns`。見どころの輪も同じつなぎ方）。
  - ラフは `python -I tools/capital/town_plans.py rough whale` で作る（設計図 `town_rough_<a|b|c>.json`、上から見た図 `docs/review/town_roughs/plan_<a|b|c>.png`）。
  - 撮影は `tools/shots/town_plans.txt`。
- 家の型の見本: `tools/capital/house_sheet.py`（`town_rough_houses.json`、撮影は `tools/shots/town_houses.txt`）。
- 土地の町の宿は 21×15（客室 2 つ）。都の宿（27×17）より一回り小さくし、曲がった通りにも入るようにした。

## 3. 案（2026-10-27）

- **A 街道と市場**: 一本の大通りが南の門から北の門へ曲がりながら通り、真ん中でくさびの市場に太る。東西の通りは市場から少しずれて門へ向かう。大通りの裏には平行な小路を通す。
- **B 環の道と高台**: 真ん中に石垣の高台を置き、上に名物と広場を載せる。高台を巻く環の道に、四つの門からの大通りが入る（南と東は一度折れる）。斜めに抜ける小路が二本ある。
- **C 小路の旧市街**: ゆがんだ碁盤の小さな街区で、大通りは十字だが街区ごとに折れる。小路の交わりに小さな広場を三つ置き、街区は町家で囲む。

## 4. 建築の水準

2026-10-27 に作り手が八つの手本を示し、これをこの mod の建築の水準にすると決めた（`docs/review/build_refs/ref_1〜8.jpg`）。

手本:
- 審判の札の大聖堂（黒地に白い石の彫り、赤の差し色）
- 彫った岩の島に積み上がる木組みの町
- 水の底の像の谷
- 洞の社（鳥居・滝・苔）
- 盆栽の大木と、縦に詰まった町の壁
- 宙の崖の町（橋と蔦）
- 肉の岩の塔と一本の道
- 血の池の上の翡翠の塔

そこから取った決まり。新しい建物はすべてこれで見る。古い町と比べて良し悪しを決めない。

- **一つの面を一つのブロックで塗らない**。色と手触りの近いブロックを、点ではなく斑（かたまり）で混ぜ、下ほど苔とひびを多くする。
- **地面にも形を持たせる**。岩の層・苔・張り出し・段・石垣を使い、建物を平らな地面に置くだけにしない。
- **縦に積む**。段・橋・階段・張り出しで、上の方にも人の居る場所を作る。
- **強い輪郭を一つ置く**。塔か大木か像を一つ選び、町や場所の目印にする。
- **細かい物を詰める**。鎖・灯り・旗・樽・木箱・露台・庇・管・足場・蔦・花の箱・鎧戸。
- **差し色と、窓の暖かい灯り**。地の色が静かなほど、少しの赤や金が効く。

### 4.1 町の仕上げ（`tools/capital/dress.py`）

土地の町は、建て終えたあとに次の仕上げを足す。呼ぶのは `PlanTown.finish()` の最後、`connect` の前。

- **風化の斑**（`weather`）: 石・瓦・銅・砂岩を、同じ仲間の中で 3 マスのかたまりのノイズで替える。階段・半ブロック・塀は、替えの石にも同じ形がある時だけ替える。
- **窓**: 家ごとに、鎧戸（開いた落とし戸）と窓の下の花の箱（ツツジの葉）を付けるかを決める。
- **戸**: 脇の壁に腕木（柵）を出し、灯りを吊る。
- **蔦**: 三割の家で、通りに面しない石の壁に上から垂らす。
- **煙突**: 頂を焚き火にして煙を上げる。
- **鎖の灯り**: 両側の家の壁が近い小路にだけ、上を渡る鎖を張って灯りを吊る。

### 4.2 町の段（`tools/capital/terrace.py`）

- 町の北側（鏡写しの町では南側）を 3 マス持ち上げて「上の町」にする。門のまわり（半径 10）は持ち上げない。
- 上の町の範囲は建てる前に決める（`PlanTown.set_upper`）。区画と施設は段の境をまたがない（`rect_free` が段のそろいを確かめる）。
- 段の縁は苔むした石垣にする（下は荒い石、上は切り石）。縁の上は石で押さえて土を見せず、ところどころ蔦を垂らす。道でない縁には胸壁を置く。
- 道が段を越える所は、低い側の道に階段を刻む（3 段）。
- 印・張りぼての戸・煙突も、柱ごと一緒に持ち上げる。

### 4.3 町ごとの目印（`tools/capital/landmarks.py` の `TOWN`）

2026-10-27 に決めた。ラフ 3 案から一つを全部の町に使うのではなく、町ごとに象徴を一つ置く。目印は上の町に建て、まわり（半径 15）は上の町に含める。

| 町 | 目印 |
|---|---|
| 鯨見 | 鯨の肋の塔（低い見張りの塔に、鯨の骨の背骨と 4 対の肋が覆いかぶさる。肋の間に鎖の灯り） |
| 潮 | 海の岩の灯台（砂岩と海の石を層にした岩の上に、白と青緑の帯の灯台。頂に海の灯り） |
| 風 | 風に傾いた鐘の大樹（根が地を這い、幹を巻く床が二つ。枝から鎖で鐘を吊る） |
| 灰 | 黒い玄武の岩と篝火（割れ目に熾火、頂に篝火の台。四隅の柱に灯り） |

広場の飾り（鯨骨の門と古井戸・噴水と魚の市・銅の柱・熾火の炉）は前のまま残す。

## 5. 土地の町の施設（都と同じ）

2026-10-27 の声「始まりの町にわざわざ戻らなくてもいいように、全ての町に全部の施設」。四つの町すべてに、都と同じ係の人を置く。案内人・墓守・酔っ払いは都だけ。

| 建物 | 場所 | 係の人 |
|---|---|---|
| 宿 | 壁の内 | 宿の主人（寝台 inn_bed） |
| 市の店 | 壁の内 | 道具屋・薬師 |
| 組合会館 | 壁の内 | 組合の受付・取引所・預かり所 |
| 社 | 壁の内 | 社の守り（鍵の間） |
| 裏の店 | 壁の内（名は浮かべない） | 闇市 |
| 鍛冶場 | 門の外（東か西） | 鍛冶 |
| 旅の館 | 門の外（上の町と反対の門） | 厩舎の番・子の止まり木の番 |
| 訓練所 | 門の外（東か西） | 師範・砦の古兵 |

- 一つの建物に何人も並ぶ所は、受付の机を一本にして、役ごとの持ち場の後ろに棚を置く（`RegionTown.hall`）。
- 門の外の建物は、門から出る道の脇に、戸を道へ向けて建て、戸から道まで小道を引く（`PlanTown.outside_fac`）。
- 建てたとき、設計図の `npc_<役>` と `inn_bed*` の印は全部写す。施設の碑には `sign.skyabyss.town_fac.<建物>` を書く（`ContinentTowns`）。町の版は `town_v3` に上げたので、前の版の町は建て直る。
- 自己テスト `continent` が、四つの町の設計図に係の人の印がそろうことを確かめる。
- 訓練の的（`TrainingYard`）は都だけに置く（2026-10-27 に決めた）。
- 係の人の言葉: 都にしかない物や場所の名を出す台詞（宿の名・空見の砦・転生の台座・四つの鍵の石・書庫・本丸の頁）は、都の外では別の言葉を出す。都の外かは会話の条件 `in_capital`（都から 200 ブロック以内）で分ける。本丸の頁の話は都の外では出さない。
- 都の家並みと道ばたの見どころにも、同じ家の型と仕上げを使う。
