## 1. 方針と階級

### 1.1 目標

| 目標 | 具体策 |
|---|---|
| 周回する理由を作る | 専用装備はダンジョンごとに固有。1回の走破では揃わない構成にする |
| 公平性 | 専用装備の入手は個人単位の抽選。他プレイヤーの取得で自分の機会が減らない |
| マルチプレイ向き | 各プレイヤーが個別にドロップを受け取る。人数が増えると敵とボスを強くし、報酬は減らさない |
| 単調な周回を避ける | 毎回ランダムな裂け目・配置に加え、日替わりの変化を入れる（14章） |
| 絶望感を防ぐ | 「巨神の記憶」の天井（保証）を専用装備に設定する（2.4節） |

### 1.2 階級

六段。名前の色・ツールチップの縁・箱の画面の枠の色が階級で決まる。階級は品ごとに決まり、セーブには書かない（品の ID が同じなので、前のセーブの装備も新しい階級で読む）。決まりはすべて `item/GearTier` の表にある。

| 階級 | 色 | 特性の数 | 特性の幅 | 穴 0/1/2 個 | 分解 | 必要 Lv | 立体の形 | 主な入手元 | 役割 |
|---|---|---|---|---|---|---|---|---|---|
| コモン | 白 `E4E4E4` | 0 | — | — | 素材 0 | 推奨 −4 | コモン | 依頼の報酬・旅の職人の店 | 備えの小物（鼓動守） |
| アンコモン | 緑 `7BD66B` | 0 | — | — | 素材 1 | 推奨 −4 | コモン | 地上で作る（旅の覚書・職人） | 章ごとの橋渡し（旅装） |
| レア | 青 `5AA9FF` | 1〜2（1 個が 60%） | ×1.0 | 50 / 38 / 12% | 素材 3・結晶 1 | 推奨 −4 | レア | 背の敵 1%・層の主（中ボス）・心臓（部位ごと 25%）・苔這い | 巨神の鎧一式、苔の護石 |

- 名前: 日本語「コモン / アンコモン / レア / エピック / ヒロイック / ★ アーティファクト」、英語「Common / Uncommon / Rare / Epic / Heroic / ★ Artifact」。翻訳キーは `gear.skyabyss.tier.<common|uncommon|rare|epic|heroic|artifact>` の六つだけ（自己テストが余分な鍵を見つける）。
- 案の神器（七つの心核から作る、強化 +15。13.2節）は七段目を作らず、アーティファクトの品として作る。初回の選択・交換の 3 点は**専用の逸品**と呼び、階級はヒロイック。
- **全職のヒロイック武器（2026-10-28 の試遊「なぜ巨神のヒロイック武器、暗殺者と戦士しかないの」）**: 巨神ごとに、6 職すべてに専用の逸品の武器を一本ずつ持たせる。足すのは 17 本（岩鯨・潮殻・雷翼 = 鍛冶師の鎚・魔術師の杖・弓・呪術師の鈴杖、余燼 = 戦士の大刃・暗殺者の小刀・魔術師の杖・弓・呪術師の鈴杖）。形は一本ずつ 3 案のラフから選ぶ（`tools/rough/lowpoly/weapons/heroic/`、`docs/review/roughs_heroic/`）。入手は今の専用の逸品と同じ（心臓でまれに・中ボス・交換）。初回の選択はもうない（30）。数値は同じ巨神のエピックより強く（`item/TierFloor`）、技の書き換えを一つずつ持つ（43 の終わりの書き換えの表に足す）。
- 階級の色を使う所: ツールチップの名前と「+3」、階級の行（3.4節）、ツールチップの縁（上が階級の色、下が同じ色を暗くしたもの。背景は UI の絵柄のまま）、箱の画面（持ち物・チェスト・炉・装飾）で装備の入った枠の薄い地と 1 画素の縁（アンコモン以上。コモンの白は枠の灰に溶けるので描かない）、心臓の遺物の選択の札、共鳴の炉の階級の行。実装は `client/ui/GearTierFrames`。
- 強化の光（+5・+10 の光る画素。下の表）は品の絵の中にあるので、枠と縁の色とは重ならない。橙（ヒロイック）と金（アーティファクト）は色相が 25° ほど離れていて、並べても読み分けられる。
- 特性が付くのはレア以上の武器と防具（3.1節）。アスペクトの芯を刻めるのはレアとエピック（ヒロイック以上は自分の書き換えを持つ。3.6節）。分解で共鳴の欠片（交換の通貨）が出るのはヒロイック以上（4.3節）。
- 鎧一式（心臓で部位ごと 25%）はどの巨神でも**レア**のまま。エピック以上にすると、重なりの分解の素材と結晶が増えて強化が早まる。ヒロイックにすると共鳴の欠片が 10 個ずつ出て交換が早まりすぎる。
- **立体の形の段**（手に持つ・落ちている・額縁・装飾の体の上の姿。13 の武器。実装は 15 の 4.6.2）: モデルは前と同じ三つ（コモン・レア・伝説）を使う。コモン・アンコモン → コモン、レア・エピック → レア、ヒロイック・アーティファクト → 伝説（`GearTier.meshTier`）。強化でアトラスと光る画素だけが変わる。

  | 段 | 変わるもの |
  |---|---|
  | 形 | コモン → レア: 部品が 1 つ増え（大剣の背の副刃・槍の枝・弓の小さな羽・斧の上の棘）、縁の金属が青みになる。レア → 伝説: 輪郭を変える大きな部品（大剣の背びれの冠・槍の珊瑚の冠・弓の大きな羽の翼・斧の下のひげ）と金の縁、光る筋が増える。三角形はコモン 134〜240、レア 186〜294、伝説 234〜348 |
  | 強化 +0〜+4 | 変わらない（基準の絵） |
  | 強化 +5〜+9（覚醒） | 縁の金属が一段明るくなり、刃の中心に破線の光の筋が入る（余燼は割れ目が太くなる）。メッシュと階級の色は変わらない |
  | 強化 +10 | 縁の金属がもう一段明るくなり、光の筋が刃の端まで通って刃の縁が光る（余燼は割れ目がさらに増える） |

  形の段は品の階級から決まる（エピックの武器 = レアの形、ヒロイックとアーティファクト = 伝説の形）。メッシュを選ぶのは `ModGear#tier`、段は `skyabyss:enhance`（+0〜+4、+5〜+9、+10 の三つの絵）。粒子は使わず、光る画素は明るさ最大で描く。

### 1.5 階級の決め方（2026-10-24）

- **入手元で階級を決める**: 作る・店で買う品はコモン〜アンコモン、背の敵・中ボス・層の主から出る鎧はレア、心臓の周回で 5 回に 1 回ほど出る品はエピック、心臓の 2〜4%・中ボスの 5%・初回の選択・交換・悪夢の品はヒロイック、転生 3 回からの深淵の心臓だけが落とす品はアーティファクト。心臓の確率は階級が上がるほど低い（自己テスト: どの図鑑でもヒロイックの最大の確率 < ほかの品の最小の確率）。
- **同じ段の中で数値が逆転しない**: 同じ章の武器は、上の階級のいちばん弱い品が下の階級のいちばん強い品を +0 でも +10 でも下回らない。アーティファクトは同じ章のヒロイックの最強の +0 を 5% 以上上回る。防具は旅装（アンコモン）< 巨神の鎧（レア）。
- **差は数値より仕組みで出す**: エピックはレアと同じ幅で特性が 2 個になりやすく（65%）、穴も増える。ヒロイック以上は特性の幅が 1.25 倍、技の書き換えを持ち、分解すると共鳴の欠片になり、必要 Lv が推奨の 2 下。アーティファクトはさらに特性・穴・結晶が増える。巨神の段の伸び（次の巨神の +0 が前の巨神の +5 ほど）は 5.5節のまま。
- **逆転を避けるために合わせた値**（ほかの品は 5.5節の目安のまま）:

  | 品 | 値 | 理由 |
  |---|---|---|
  | 鍛え手の大鎚（ヒロイック） | 攻撃力 19（17.7 / 24.7） | +0 でもエピックの戦斧 17.6 を下回らない |
  | 灰被りの火掻き（ヒロイック） | 速さ 1.65（18.2 / 23.6） | エピックの戦斧より一段上（同じ値にしない） |
  | 灰喰いの鎌（アーティファクト） | 攻撃力 16（19.2 / 25.0） | 余燼のヒロイックの最強（火掻き 18.2）の 1.05 倍以上 |
  | 雷淵の弓（アーティファクト） | 矢 ×2.0 | ×1.8 だと満月の矢の傷の切り上げが雷翼の弓（×1.75）と同じ 11 になり、差が出ない |

  余燼のヒロイックの +10 は目安 22.8 の 1.10 倍まで（エピックは ±5% のまま。`EmberGearSelfTest`）。
- **前のセーブ**: 階級は品の ID で決まるので移行は要らない。付いている特性・穴はそのまま読める（エピックはレアと、ヒロイックとアーティファクトは互いに、特性の数の範囲と幅が同じ）。

### 2.4 巨神の記憶（天井システム）

- 目的: 専用装備が出るまでの周回を有限にし、「運が悪いだけで永遠に出ない」状態を防ぐ。
- 単位: プレイヤー×巨神ごとに 1 つのカウンタ。
- カウンタの数え方: 「図鑑（その巨神の心臓の品 10 品。岩鯨は 9 品）に新しい品が増えなかった心臓の撃破」の数。新しい品を手にすると 0 に戻る。重複では戻さない。ボスを倒さず退出したときは変わらない。

| カウンタ | 効果 |
|---|---|
| 0〜2 | 通常の確率 |
| 3 以上 | 図鑑の品の確率が 2 倍（ソフト天井） |
| 5 | 図鑑にない品を 1 つ保証（ハード天井） |

- 当初案の 5 / 8 は、図鑑全体を対象にして 3 / 5 に縮めた。
- 岩鯨の図鑑 9 品 = 甲殻 4 部位・大剣・護符・専用の逸品 3 種。潮殻・雷翼・余燼は 10 品（鎧 4・基本の武器・もう一つのエピックの品・護符・専用の逸品 3。各 9〜11 章の表）。
- 全部持っている場合は共鳴の欠片に変換される。
- 交換は天井のカウンタを戻さない（欠片で買った品で天井が戻ると、欠片を使うほど損に感じるため。00 の 22）。

岩鯨の模擬（自己テスト、1〜4人 × 1万組）:

- 一人あたりの平均撃破数: 甲殻 4 部位 6.6 回、甲殻＋大剣＋護符 8.0 回、図鑑 9 品すべて 13.4 回（最悪 25〜27 回）。
- 組の全員が甲殻 4 部位を揃えるまで: 1人 6.6 回、2人 8.1 回、3人 8.9 回、4人 9.5 回。一人あたりの数字は人数で変わらない。
- ハード天井の発動は全撃破の約 7.8%。新しい品の出ない撃破は最長 4 回。
- 図鑑が揃うまでの平均撃破数: 潮殻 14.7、雷翼 13.0、余燼 13.0。

### 2.5 初回クリアの選択報酬

- 各巨神の心臓を初めて倒すと、専用の逸品 3 種から一つを選ぶ。巨神の眠りの場面が終わると専用の画面が開く（[30](30_heart_reward_ui.md)）。「あとで」にしても、旅嚢の「遺物」・控え帳・`/titanmemory reward` から選ぶまで開ける。`/titanmemory choose <装備>`（潮殻は `/titanmemory tide choose`）は同じ決まりを通る古い入口として残す。

## 3. 特性（Affix）

### 3.1 付く品と決まり

| 項目 | 決定 |
|---|---|
| 付く品 | レア以上の**武器**（剣の類・盾を含む）と**防具**だけ。護符・護石・補強板・装飾には付けない（重ねて持てるため。00 の 20） |
| 付く数 | レア・エピック 1〜2、ヒロイック・アーティファクト 2〜3。少ないほうはレア・ヒロイック 60%、エピック・アーティファクト 35%（`GearTier`） |
| 重なり | 一つの装備に同じ種類は二度付かない（重みつきで引き、引いた種類を外して次を引く） |
| 値 | 種類ごとの幅の中で、刻みごとに同じ確率。ヒロイック以上は幅の上下を 1.25 倍 |
| 効く場所 | 武器の特性は利き手に持つとき（盾は左手）、防具の特性はその部位に着ているとき |
| 付く時点 | 出た時点で決まる（報酬・初回の選択・交換）。特性の項目がない古い装備は、持ち物に入ったとき（1 秒ごと）に一度だけ抽選する（00 の 24）。鍛えた段階はそのまま |
| 知らない種類 | 将来消した種類を持つ装備は読み込めて、効かないだけ。ツールチップは「（失われた特性）」 |
| 弓 | 雷翼の弓には付けない。特性は攻撃力の修飾子で効くので矢には効かない（10.1節） |
| アーティファクトの候補 | ダメージ反射・全被ダメ軽減などは案の神器（アーティファクト）で作る（未実装） |

- 実装: `item/affix/AffixType`（種類の表）、`Affix`、`AffixRules`（抽選・検め・再鍛造・表示）、`AffixEvents`（修飾子、守り・渇き・冴え、古い装備の抽選）、`AffixCommands`、`AffixSelfTest`。データは `skyabyss:affixes`。
- 画面の名前（鋭さ・迅さ…）は内部と書類の呼び名。画面には効果だけを出す（「攻撃力 +5%」）。
- 数値の特性はバニラの「利き手に持ったとき」の欄にも修飾子として出る。特性の行は品の性格、バニラの欄は合計として読める。

### 3.3 強さへの効き

岩鯨の心臓との模擬（Lv 9、筋力 24 で攻撃 ×1.144、武器 +5、甲殻 4 部位 +0、心臓の一撃 12）。

| 武器 | 特性なし（心臓 450 を倒す秒） | 平均の特性 | いちばん良い特性 |
|---|---|---|---|
| 鯨骨の大剣 | 34.2 秒 | ×1.05 | ×1.19 |
| 番兵長の鉾 | 36.6 秒 | ×1.10 | ×1.24 |
| 水路の顎牙 | 28.3 秒 | ×1.10 | ×1.24 |

| 守り | 特性なし | 平均 | いちばん良い（4 部位とも 頑健 1.0 と 守り 3%） |
|---|---|---|---|
| 心臓の一撃に耐える回数 | 6.5 回 | ×1.08 | ×1.33 |

- 難しさ（倒す時間 ÷ 耐える回数）は平均の特性で ×0.84、すべて最良で ×0.61。強化 +10（武器 ×1.3）より小さい。強くなる主役は強化と専用装備のまま、特性は「当たりを引いた」楽しみの幅。
- 04 の技と筋力を足したときの +15〜20% と、平均の特性（攻め +5〜10%、守り +8%）は同じくらい。どれか一つで攻略が決まらない。
- 攻撃力を「+1.5」のような足し算にすると、速い顎牙（素の 6）だけが ×1.48 まで伸びた。割合にして、どの武器でも上限 ×1.24 にそろえた。
- 防御力を足す特性はない。甲殻 4 部位で防御力 20（バニラの効きの上限の手前）にあるので、+1 ごとに受ける傷が 13% ずつ減る。防具の特性は防具強度（+4 で傷 −6%）。
- 守りの上限 10% は、4 部位で最大 12% になるところを甲殻の耐性 I（20%）の半分に収めるため。
- 吸血は 0.25 秒に一度・1 回 2 までなので、範囲で何体に当てても 1 秒に最大 8（実際は傷の 2〜5% で 1 秒に 1 前後）。

| 潮招きの大鋏 | 鯨尾薙ぎ | 挟み切り: 当てた敵を 1 秒、動けなくする（大きな相手は 0.5 秒） |
| 珊瑚憑きの銛 | 引き潮 | 銛打ち: 引かずに結ぶ。結ばれた敵が動くと近くの敵が引かれる（3 秒） |
| 雷獣の爪 | 跳び退き | 雷の輪: 着地すると、元の場所とのあいだの敵に ×0.8 |
| 羽守の鉤槍 | 岩呼び | 鉤寄せ: 引いた敵を前の 1 か所へ寄せる |
| 鍛え手の大鎚 | 熾火の槌 | 二度打ち・火床: 熾火が 8 秒、中の敵の攻撃力 −10% |
| 灰被りの火掻き | 焼き入れ | 火移し: 自分と仲間 2 人まで同時に焼き入れ |

- 実装: `Rune`（4 番目の刻印と要る武器の id）、`SkillActions`、`SkillManager.runeOf`（持っていなければ 0）。自己テストは `BuildsSelfTest.legendary`。

### 3.6 アスペクト・ソケット・ルーン・世代（31 の A02・A06・A07・B15）

特性の外側の刻み。装備のデータ `skyabyss:gear_extras`（穴・差したもの・アスペクト・抜け殻・世代・形見の特性）に入れる。対象は特性の付く装備（3.1 節）。付いていない装備（古いセーブ・コマンドで出した品）は、手にしたとき（1 秒ごと）と報酬が出たときに穴を一度だけ抽選する。装備の落ちる確率（図鑑・天井）は変えない。

| 仕組み | 決まり |
|---|---|
| 穴（A07） | レア 50%・38%・12%、エピック 40%・42%・18%、ヒロイック 30%・45%・25%、アーティファクト 20%・45%・35%（0・1・2 個）。**打ち直しで必ず足せる**（共鳴の結晶 2 と由来の巨神の素材 8、2 つ目は 16。最大 2） |
| 欠片（A07） | 岩・風・潮・灰・骨の 5 種。巨神の素材 4 ＋ 共鳴の結晶 1 で作る（岩=岩鯨の鱗片、風=雷翼の羽軸、潮=潮殻の殻片、灰=余燼の燠石、骨=骨のかけら）。差すと **その木のタグが 1 つ数えられ**（31 の A03、`SkillBuild.tagPower`）、武器・防具で別の小さな数字が付く（岩: 攻撃力 +2%／強靭 +0.25、風: 攻撃速度 +2%／移動 +1%、潮: 最大マナ +3／+2、灰: 技の待ち −2%／守り 1%、骨: 吸血 1%／不動 3%）。数字は特性と同じ道（`AffixRules.effective`）で効く |
| 技の修飾ルーン（A06） | 品 `skill_rune`。使う技 1 つに、力 +10〜30%（刻み 5%）か待ち −10〜20%。穴に差す。**1 つの技に 1 枚**（同じ装備に同じ技は二枚差せず、複数の装備に付けても最もよい一枚だけ）。力の合計は `SkillBuild` で +100%（×2.0）が上限。差す・外す（結晶 1）は炉 |
| アスペクト（A02） | ヒロイック以上の書き換え（3.5 節・3.7 節）を炉で**抽出**して「アスペクトの芯」にする。「抽出」は品を壊す（結晶 2）、「印を残す」は品が残り書き換えだけ抜け殻になる（結晶 4。強化・特性は残る）。芯は **レアかエピックの武器か防具に刻む**（結晶 1。1 装備に 1 つ）。刻んだ装備を持つ（武器）か着ている（防具）あいだ、その技の書き換えが選べて効く（`Rune.held`）。分解しても芯は戻る |
| 世代（B15） | 転生を終えるたびに（`Rebirths.onRebirth`）、持ち物にある特性付きの装備の世代が 1 上がる（同じ転生で二度は上がらない。上限 12）。**世代 3 ごとに形見の特性の枠が 1 つ開き**、付いていない種類から小さな特性（幅の下端）が一つ付く。差は 1 枠の特性だけ |

- **落ち方**: 心臓（一人ずつ別々）は巨神の属性の欠片 55%（1〜2 個）、岩鯨は骨の欠片 25% も、ルーン 10%。試練は済ませるたびにルーン（初めて 12%、以後 4%、極の修飾は 2 倍）、初めてのときだけ欠片 35%。実装は `item/extra/GearFreedomLoot`。
- **炉の画面**: つまみが 4 つ（強化・再鍛造・交換・**刻み**）。刻みの中は 抽出・刻印・穴 の 3 頁。左の板の装備の枠の左に「素材」の枠（欠片・ルーン・芯）。ツールチップに穴（◆/◇）・アスペクト・第 N 世代・形見の特性が出る。
- **保存**: すべて装備のデータ。欠けたフィールドは既定で読める。炉の操作はサーバーが毎回検める。
- 実装: `item/extra/`（`GearExtras`・`Gem`・`Element`・`RuneData`・`GearFreedom`・`GearFreedomItems`・`GearFreedomLoot`・`GearSkillModifier`）、`forge/ForgeRules`（刻みの費用）、`ResonanceForgeMenu`/`Screen`。画像の生成元 `tools/gen/items/gen_gear_freedom_assets.py`。自己テスト `SELFTEST gear freedom`。

### 3.7 深淵のアーティファクト（31 の B04。`abyss/AbyssSetup`・`AbyssLoot`）

深淵の心臓（その巨神の心臓をグループが「深淵」で倒したとき）からだけ出るアーティファクトが、巨神ごとに 1 点。27 の書き換えと同格で、**まだ書き換えのない 4 つの技**を別の形にする（同じ技に二つの書き換えは付かない。書き換えは 8 → 12）。通常の図鑑・天井・共鳴の欠片での交換の対象外。強化・特性・必要 Lv はアーティファクトの階級の決まり（`ModGear`・`GearTier`）。

## 4. 共鳴の炉（強化・分解・再鍛造・交換）

### 4.1 置き場と画面

炉は地上の巨神の祠の台座の東の縁に置く（[32](32_titan_raid_route.md) の 3.1）。レシピはそのまま。

- 炉はブロック設備。各巨神の祠の台座の東の縁に 1 基（32 の 3.1）。レシピでも作れる（骨ブロック、共鳴の結晶、岩鯨の鱗片、磨かれた深層岩）。
- 炉は何も預からないので、何人でも同時に使える。再鍛造の候補は装備に付くので人ごとに別。
- 画面（`client/forge/ResonanceForgeScreen`、メニュー `forge/ResonanceForgeMenu`）。テクスチャ `textures/gui/forge/forge.png`、生成元 `tools/gen/items/gen_forge_assets.py`（2 倍密度。骨の枠と石板は成長・技の画面と同じ作り）。

| 場所 | 中身 |
|---|---|
| 左の板（176×166） | 装備の枠（炉の光と熾の弧）、名前・階級・強化の段・特性、持ち物 |
| 右の板（152×166） | つまみ 3 つ（槌の「強化」、渦の「再鍛造」、天秤の「交換」）。最後に開いたつまみを覚える |
| 強化 | 次の段と費用、「強化」。分解で得るもの（欠片・結晶）と「分解」（二度押し） |
| 再鍛造 | 候補の数と結晶の数、「試す」。候補の札 3 枚（押すと金の縁で選ぶ）、「選んで確定」、「今のまま」（二度押し） |
| 交換 | 切り替えた巨神の共鳴の欠片の数（古い欠片も足す。名前を添える）、交換の状態の一文、専用の逸品 3 つ（持っているものは「所持」、ないものは「選ぶ」を二度押し）。巨神は炉の交換のつまみの下のボタンで切り替える（「岩鯨の専用装備 ▸」） |

- 実装: `forge/ForgeRules`（費用・ボタン・分解の結晶）。創造モードは結晶・欠片を払わない。

### 4.2 強化と覚醒

- +n → +n+1 に、その巨神の素材 4+2n 個、共鳴の結晶 1 個（+5 以降は 2 個）。失敗なし。上限 +10。+10 まで合計で素材 130、結晶 15。
- 武器は 1 段ごとに**武器の攻撃力（素手の 1 を含む）の 3%**（どの武器も +10 で ×1.3。大剣 +0.30、鉾 +0.255、顎牙 +0.165 /段）。
- 防具は 1 段 1 部位ごとに**強靭 +0.3 だけ**（4 部位 +10 で強靭 +12）。防御は足さない。
- 強化の修飾子の ID は部位ごとに分けてある（同じ ID だと重なって上書きし合うため）。
- 盾は修飾子を足さず、防ぐ割合と棘が伸びる。護符・装飾・食料は鍛えない。
- 盾は正面の傷を止める（`combat/ShieldRules`）。ふつうの敵は全部、大物（最大体力 150 以上。心臓・中ボス・番人）と床の予告の技は 60%。珊瑚の盾は大物にも +15%。一度に 10 以上を受けると 2 秒構えられない。
- mod の雑魚（最大体力 150 未満の敵）は、体力が各敵の作りの 8 割、人へ与える傷が 9 割（`combat/MobTuning`）。大物は変えない。
- 覚醒（+5）: 品ごとの固有効果が強まる（7〜11章の表）。+10 で範囲などが広がるものもある。
- 案の神器（アーティファクト）は上限 +15（13.2節。未実装）。
- 強化の上乗せは装備を見るたびに `GearEvents` が品の既定の攻撃力から計算する。段は `skyabyss:enhance`。

### 4.4 再鍛造

- 共鳴の結晶 1 つで候補を一組（特性ぜんぶを振り直したもの）作る。3 組まで。
- 候補のどれか、または「今のまま」を選んで確定する。「今のまま」があるので、振り直しで弱くなることはない（払った結晶は戻らない）。確定のあとはまた 3 組試せる。
- 候補は装備に持たせる（`skyabyss:reforge_offers`）。炉を閉じても、ログアウトしても、払った分は消えない。
- 結晶 1 = 1 回なので、心臓 1 回の撃破でおよそ 1.4 回試せる。

### 4.5 交換

- その巨神の共鳴の欠片 30 で、まだ持っていないその巨神の専用の逸品を一つ。巨神ごとに、その巨神の心臓を 1 回倒すごとに 1 回（「1 周回」を「心臓の撃破 1 回」と読んだ。月のループを作るときに決め直す。未決）。
- 対象は未所持の専用の逸品だけ（00 の 23）。天井のカウンタは戻さない。
- 状態は巨神の記憶に持つ（「最後に交換した撃破数」「交換した回数」。古い記録は 0）。画面へは数の枠（DataSlot）で、所持の印と状態だけ送る。サーバーが毎回状態を見るので、同じ周回に二度は通らない。
- 実装: `loot/GearExchange`（巨神ごとの交換。表を登録すれば炉に出る）。

### 4.6 欠片と結晶の収支（岩鯨、4000 人の模擬。心臓と番兵長だけ、重なった装備は分解）

| 項目 | 結果 |

| 最初の 10 回で集まる共鳴の結晶 | 平均 14.3 個（心臓の 40% で約 4、残りは重なった装備の分解） |
| 専用の逸品 3 つがそろう撃破数 | 交換なし 13.0 回 → 交換あり 10.6 回 |
| +10 に要る結晶 15 個 | 分解を入れて 11 回ほどの撃破で集まる（入れないと 37 回） |

- 交換は「天井が届く前に一つ早める」くらいの効き目。強化の速さは欠片（+10 で 130 個）が決めるので、強化が速くなりすぎることはない。

## 5. 強さの曲線

### 5.1 前提と式

| 項目 | 前提 |
|---|---|
| 難易度 | Normal |
| ステータス | 力の半分を筋力、4 分の 1 を耐久に振る（上限 50）。Lv 12 で筋力 16（攻撃 ×1.096）・最大体力 22、Lv 18 で ×1.15・23、Lv 24 で ×1.204・24、Lv 30 で ×1.258・25 |
| 攻め | 攻撃の目盛りが満ちてから振る。「1 秒あたり」= 攻撃力 × 攻撃速度 × 固有効果の上乗せ。相手の防具（バニラの式）を通す |
| 固有効果の上乗せ | 鉾: 噴出（攻撃力の 60%）が斬った相手にも当たる。3 回に 1 度で ×1.2、+5 から 2 回に 1 度で ×1.3。顎牙: 出血は振りの無敵時間に半分ほど食われるとみて 1 秒に 0.5（+5 から 1.0） |
| 守り | バニラの防具の式（防御・強靭）× 一式の耐性 I（×0.8）× 特性の守り。「耐える回数」= 最大体力 ÷ 一撃の傷 |
| 心臓との手ごたえ | 殴っていられるのは戦いの 6 割、心臓の技は 2.5 秒に一度。**手ごたえ = 戦いの間に受ける技の数 ÷ 耐えられる数**。1 を切ると避けずに殴り合っても勝てる（作業）。高いほど避ける腕が要る |

- 実装: `item/GearCurve`（式と目安の表 `STAGES`）、`item/GearCurveSelfTest`。
- このModの武器と防具は、バニラのエンチャントの対象（`#minecraft:enchantable/...` の札）に入っていない。鋭さ・ダメージ軽減は付かない。その代わりが強化と特性。
- 目標: 岩鯨の +10 はバニラの終盤（ネザライト + 鋭さ V）に届かない。バニラの終盤に並ぶのは潮殻（推奨 18）の +10 から。心臓は最後まで「避けて戦う相手」のまま。

### 5.4 調整の方針と岩鯨の最終値

| 項目 | 決定 | 理由 |
|---|---|---|
| 強化（武器） | 1 段で武器の攻撃力の 3%（足し算にしない） | 足し算（+0.6/段）では速い顎牙だけが +10 で ×2.0 になり、1 秒あたり 26.4 でバニラの終盤（17.6）の 1.5 倍に。割合にして、どの武器も ×1.3、+10 でバニラの終盤の 0.74〜0.90 倍 |
| 強化（防具） | 強靭 +0.3/段だけ | 防御を足すと +10 で防御 36（属性の上限 30）になり、心臓の一撃の 80%（バニラの効きの上限）を超えてしまう。強靭は重い一撃ほど効くので、後の巨神でも価値が残る（心臓の一撃 12 で ×1.17、20 で ×1.24） |
| 番兵長の鉾 | 攻撃力 8.5 | 噴出の上乗せ込みで、一体へダイヤの剣と同じ（11.2）。扇で群れに強いのが個性 |
| 水路の顎牙 | 攻撃力 5.5 | 出血込みでダイヤの剣の 1.1 倍。速さと水中・出血が個性 |
| 鯨骨の大剣 | 攻撃力 10 | 1 秒あたりはダイヤの剣の 0.9 倍。一撃の重さと鈍足 II が個性 |
| 岩鯨の甲殻 | 強靭 1 部位 2.0（ダイヤと同じ） | 素の硬さはダイヤにそろえ、一式の耐性 I を個性として残す |
| 岩鯨の補強板 | 甲殻 2 部位で防具強度 +3 | 防御の上限の手前で +2 は重い（1 つで受ける傷が 1 割以上減る）。強靭は重い一撃に効き、「補強」らしい |
| 防具の強化は強靭だけ | 武器 ×1.3 より効きが小さい（+10 で耐える回数 ×1.17） | 後の巨神ほど一撃が重く効きが増す。「防具の強化が効かない」と感じたら、割合の軽減（1 段 1 部位 0.25%）を足す（未決。00 の 66） |

- 結果（Lv 12）: 手に入れた直後の手ごたえは 4.0〜4.8（ダイヤの装備の 5.6 より少し楽）、+10 で 2.5（ダイヤ + 鋭さ III・軽減 III の 2.2 と同じくらい）、+10・最良の特性・筋力全振りでも 1.35〜1.59。
- 手に入れた直後（+0）は、大剣・鉾・顎牙がダイヤの剣の 0.9〜1.2 倍、甲殻がダイヤの防具より 2 割ほど硬い（耐性 I）。バニラの終盤は大きく下回る。推奨 Lv 12 ではダイヤ前後を持って来る前提なので、素の強さは大きく変えない。
- 特性・ステータス・技は、どれも ×1.1〜1.3 の範囲で一つで攻略が決まらないので変えない。
- 鉾の噴出は、斬った相手の無敵時間を消してもう一度当たり、一体へ ×1.2〜1.3 の上乗せになる。素の攻撃力を少し下げて合わせた（上の表）。
- **敵の無敵の間（mod 全体）**: 人（と人の矢・技）が当てた、人でない者の傷のあとの無敵は 0 tick（`combat/MobHitFrames`。同じ tick の二人の一撃も両方通る）。人が受ける傷の無敵はバニラのまま。自己テスト `combat rules`

### 5.5 巨神ごとの目安（各段階の基準値）

`item/GearCurve.STAGES` に同じ表を置いた。自己テストで、段ごとに伸びていること、前の巨神の +10 が次の巨神の +10 を超えないことを検める。

|---|---|---|---|---|---|---|---|---|
| 岩鯨 | 12 | 11.5（実際 10〜12.1） | 15.0（実際 13〜15.8） | 20 / 8 | 耐性 I（×0.8） | 12 | 450 | +0 がダイヤ、+10 がダイヤ + 鋭さ IV |
| 潮殻 | 18 | 13.2 | 17.2 | 20 / 12 | ×0.8 相当まで | 13.5 | 540 | +10 がネザライト + 鋭さ V |

## 6. 必要レベルと装飾の枠

### 6.1 必要レベル

決め方: **その巨神の推奨 Lv から、エピック以下は −4、ヒロイック以上は −2**（`GearTier.levelMargin`）（`item/GearLevel.defaultRequired`。推奨 Lv は `GearCurve.STAGES`）。

- 全差を「推奨 −6」や「推奨ちょうど」にしなかったのは、初めて倒す Lv 9 ごろに鎧と基本の武器を使え、ヒロイックは推奨の手前から使えるようにするため（推奨ちょうどだと、心臓から出た品を Lv 12 まで使えない）。
- 食料・矢・素材・鍵・心核・呼び笛には付けない（強さを飛び越す品ではない）。

- 今のところレベルは下がらない。もし下げる仕組みができたら、枠の品は残ったまま効かなくなり、防具は持ち物へ戻る。

### 6.2 足りないときの扱い

バニラの仕組みを壊さないよう、「手に入れる・動かす」は止めず、「身につける・力を出す」だけを止める。

| 品 | 足りないとき | 仕組み |
|---|---|---|
| 防具 | 身につけられない。防具の枠に入らない、右クリックで着られない。何かの拍子に着ていたら（発射装置・コマンド）、0.5 秒ほどで持ち物へ戻す（入らなければ足もとへ） | `canEquip` と `use`、`GearLevel.enforceArmor` |
| 武器（左手の盾を含む） | 手に持てる・振れる。ただし品の修飾子（攻撃力・速さ・鉾の間合い・強化・特性）をちょうど打ち消すので、素手と同じ（攻撃力 1、速さ 4）。固有効果と特性も出ない | プレイヤーに逆向きの一時的な修飾子（`skyabyss:gear_lock/…`）を毎 tick 合わせる |
| 護符・装飾 | 枠に付けられない。右クリックでも付かない。枠に入っていても（コマンドなど）効かない | 枠の `mayPlace`、`Accessories.worn` |
| どれも | 拾う・渡す・チェストに入れる・強化・再鍛造・交換・分解はできる | — |
| 創造モード | 問わない | — |

- 武器を「持てない」にしなかったのは、手の枠を塞ぐとバニラの持ち替えやブロックの設置の流れが崩れ、鍛えるために炉へ持って行く道も止まるため。
- バニラの「利き手に持ったとき」の欄は、足りないときも品の数（例「+8.5 攻撃力」）のまま出る。赤い行で読めるようにした。

### 6.4 方式（自前の枠）

| 案 | 中身 | 良い点 | 悪い点 |
|---|---|---|---|
| (a) 自前（採用） | プレイヤーに Data Attachment（`skyabyss:accessories`）で 3 枠を持たせ、専用の画面（メニュー）で出し入れ | 依存が増えない（配布は jar 一つ）。保存・死亡・同期を岩鯨の背の預かりや成長の記録と同じ作りで決められる | 画面・メニュー・死亡・移し替えを自分で書く（約 1,250 行。自己テストを含む） |
| (b) Curios API | Curios の枠の種類に品を登録 | 他の Mod と枠を共有できる | 任意依存だと入れない人のための代わりが要り二重になる。保守が増え、画面の見た目がそろわない。死亡の扱いが岩鯨の背の預かりと合わせにくい |

- 枠は 3 つで他の Mod と共有する必要が薄く、配布と保守を軽くする方針（ユーザーの決定）にも合うので (a)。Curios は使わない。
- 画面は、バニラの持ち物の画面（`InventoryMenu`）に枠を足すのでなく別の画面にした。足すには Mixin が要り（このModは使っていない）、枠の番号がずれて他の Mod や創造モードの画面が崩れやすいため。ステータス画面のつまみ（`RpgTabs`）に足す案は、装飾の画面が持ち物を動かすメニューで記録を見る画面とは性格が違うので採らなかった。

### 6.6 死亡・保存・同期・前のセーブ

| 場面 | 扱い |
|---|---|
| 死んだとき | 持ち物と同じに足もとへ落ちる（`LivingDropsEvent` に足すので、墓の Mod などとも同じ流れ）。消滅の呪いの品は消える |
| keepInventory | 落ちない（枠の記録が `copyOnDeath` で新しい体へ移る） |
| 四体の背（岩鯨・潮殻・雷翼・余燼） | どの背でも落ちない。背中の預かりの仕組み（`TitanBackTrials`）が落ちる品の知らせを止めるので、枠の中身はそのまま残り、休み場で目を覚ましたときも付いている。判定は背中の一覧 `TitanBacks.isBack`（持ち物の預かりと同じ） |
| 保存 | プレイヤーのデータ（`skyabyss:accessories`）。品はバニラの形で保存されるので、強化の段・特性もそのまま |
| 同期 | 画面の中はメニューの同期。記録そのものは持ち主にだけ送る。ログイン・復活・次元の移動で送り直す |
| 前のセーブ | 持ち物にある護符・補強板・護石を、最初の 1 秒で一度だけ空いた枠へ移し、チャットで知らせる。必要 Lv に届かない品と、枠が埋まっている分は持ち物に残る |
| マルチ | 枠の出し入れ・護符を使う・右クリックで付けるは、どれもサーバーで種類・重なり・Lv・待ちを検める |

### 6.5 基礎の要求値（2026-10-29。[48](48_skill_tree_v2.md) の 2.2）

レア以上の職の武器には、その職の主な基礎（戦士・鍛冶師 = 筋力、弓使い・暗殺者 = 敏捷、魔法使い・呪術師 = 精神）の要求値がある。届いていないと**近接の攻撃力が半分、木の印が効かない**（持てはする。倒れても落とさない決まりはそのまま）。基礎は技の木の基礎の節（+4）でしか上がらないので、値は木の主な基礎の節だけで届く数にした（戦士の筋力は 24 まで）。`rpg/skill/GearRequirement`。説明の 3 行目に「要る基礎: 筋力 10（いま 8）」。

| 由来 | 要る基礎 | 木で届く目安 |
| --- | --- | --- |
| 岩鯨（一章） | 10 | 幹の基礎 2 つと枝の 1 つ |
| 潮殻（二章） | 14 | 4 節 |
| 雷翼（三章） | 18 | 5 節 |
| 余燼（四章） | 22 | 6 節（戦士は筋力の節を全部） |
| 深淵（五章） | 24 | 6 節 |

- 祠の品・ふつうの階級・バニラの武器・防具・装飾品には要求値がない。

### 9.3 強さの曲線（`TideGearSelfTest`）

**1 秒あたり（一体へ、固有効果の上乗せ込み）**

| 武器 | +0 | +5 | +10 |

| 珊瑚憑きの銛 | 13.50 | 15.53 | 17.55 |
