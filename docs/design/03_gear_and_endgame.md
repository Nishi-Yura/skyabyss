## 1. 方針と階級

### 1.1 目標

| 目標 | 具体策 |
|---|---|
| 周回する理由を作る | 専用装備はダンジョンごとに固有。1回の走破では揃わない構成にする |
| 公平性 | 専用装備の入手は個人単位の抽選。他プレイヤーの取得で自分の機会が減らない |
| マルチプレイ向き | 各プレイヤーが個別にドロップを受け取る。人数が増えると敵とボスを強くし、報酬は減らさない |
| 単調な周回を避ける | 毎回ランダムな裂け目・水路に加え、週替わり・日替わりの変化を入れる（14章） |
| 絶望感を防ぐ | 「巨神の記憶」の天井（保証）を専用装備に設定する（2.4節） |

### 1.2 階級

| 階級 | 表示色 | 特性（Affix）数 | 主な入手元 | 役割 |
|---|---|---|---|---|
| コモン | 白 | 0 | 雑魚、通常の宝箱 | 素材、入門用（色と名前だけ。使う品はまだない） |
| アンコモン | 緑 | 0 | 宝箱、ホール撃破 | 序盤の繋ぎ（食料・矢など） |
| レア | 青 | 1〜2 | 心臓の図鑑の品（甲殻・鎧一式・基本の武器・護符） | 各ダンジョンの主力 |
| 伝説 | 金 | 2〜3 | 心臓・中ボスの低確率、初回の選択、天井保証、交換 | 専用装備の本体。ダンジョンごとの固有効果 |
| 神器 | 紫（虹色の縁） | 3〜4 ＋ 固有特性1つ | 七つの心核から作る（13.2節。未実装） | 最終到達点。アクティブ効果を持つ |

- 階級の色はツールチップの名前と階級の行に使う（3.4節）。コモンと神器は色と名前だけ実装。
- 鎧一式のように心臓で部位ごと 25% の品は、岩鯨・潮殻・雷翼・余燼のすべてで**レア**。伝説にすると、重なりの分解で共鳴の欠片が 10 個ずつ出て交換が早まりすぎるため。
- ダンジョン固有の効果は階級に関係なく付くが、伝説の専用装備ほど個性が強い。
- **武器の見た目の段**（手に持つ・落ちている・額縁。13 の武器。実装は 15 の 4.6.2）: 階級でメッシュ（輪郭）が変わり、強化でアトラスと光る画素だけが変わる。

  | 段 | 変わるもの |
  |---|---|
  | 階級 | コモン → レア: 部品が 1 つ増え（大剣の背の副刃・槍の枝・弓の小さな羽・斧の上の棘）、縁の金属が青みになる。レア → 伝説: 輪郭を変える大きな部品（大剣の背びれの冠・槍の珊瑚の冠・弓の大きな羽の翼・斧の下のひげ）と金の縁、光る筋が増える。三角形はコモン 134〜240、レア 186〜294、伝説 234〜348 |
  | 強化 +0〜+4 | 変わらない（基準の絵） |
  | 強化 +5〜+9（覚醒） | 縁の金属が一段明るくなり、刃の中心に破線の光の筋が入る（余燼は割れ目が太くなる）。メッシュと階級の色は変わらない |
  | 強化 +10 | 縁の金属がもう一段明るくなり、光の筋が刃の端まで通って刃の縁が光る（余燼は割れ目がさらに増える） |

  どの武器も階級は品で決まっている（鯨骨の大剣・潮殻の三叉槍・珊瑚の盾・雷翼の弓・余燼の戦斧 = レア、そのほか = 伝説）。メッシュを選ぶのは `ModGear#tier`、段は `skyabyss:enhance`（+0〜+4、+5〜+9、+10 の三つの絵）。粒子は使わず、光る画素は明るさ最大で描く。

|---|---|---|
| 宝箱 | 全ダンジョン | 通常はコモン〜レア。専用の隠し宝箱は伝説を含む（1ランに0〜1個）。未実装 |

### 2.2 素材と通貨

| 素材 | 由来 | 用途 |
|---|---|---|
| 巨神ごとの素材（岩鯨の鱗片・潮殻の殻片・雷翼の羽軸・余燼の燠石） | 通常戦闘、心臓、レア以下の分解 | その巨神の品の強化の燃料、修理 |
| 共鳴の欠片（岩鯨・潮殻・雷翼・余燼。「共鳴の欠片（岩鯨）」など） | その巨神の心臓、中ボス、背の敵、その巨神の伝説の分解 | その巨神の専用伝説との交換（30個）。巨神をまたいでは使えない |
| 共鳴の結晶 | 心臓 40%、特性付きの品の分解 | 強化（+5 以降は 2 個）、再鍛造、ステータスの振り直し |
| 〇〇の心核（巨神ごと） | 心臓。初回は必ず、以後 25% | 神器の材料（13.2節） |
| 天の鍵の欠片 | 1章の四巨神。プレイヤーごとに一つ | 次章の扉を開く。周回で再取得しない |

- 強化の素材は巨神ごと（強化は由来の巨神の素材だけを使う）。名前は巨神ごとに違う言葉にした（鱗・殻・羽軸・燠）。「〇〇の欠片」は、共鳴の欠片と天の鍵の欠片とまぎらわしいので、素材には使わない。「欠片」は共鳴の欠片（通貨）と天の鍵の欠片（章の鍵）だけに残す。
- 共鳴の欠片（交換の通貨）も巨神ごと（`resonance_shard_stone_whale` / `_tide_shell` / `_thunder_wing` / `_ember`。絵は共通の欠片の色味を巨神の色に替えたもの）。落とすのはその巨神の心臓・番兵・背の敵・週と日の依頼、伝説を分解して戻るのもその巨神の欠片。交換は、その巨神の専用伝説に、その巨神の共鳴の欠片 30。
- 以前の共通の共鳴の欠片（`resonance_shard`。名前は「共鳴の欠片（古い）」）は残してある。新しくは落ちない。どの巨神の交換にも使え、炉は、その巨神の共鳴の欠片から先に払い、足りない分を古い欠片で払う（`ForgeRules.payExchange`）。炉の画面の数は、その巨神の欠片と古い欠片の合計。創造モードは払わない。

### 2.3 個人抽選と預かり

- 番兵長・心臓・道中の敵のすべてで、参加者が一人ずつ別々に抽選する（周回前提）。
- 倒れていた人・持ち物がいっぱいの人の分は預かり、目を覚ましたときや `/titanmemory claim` で渡す（`TitanLoot.handOver`）。
- 出た装備には出た時点で特性が付く（3.1節）。チャットの名前にカーソルを合わせると特性まで見える。
- 保存先はオーバーワールドの保存データ `skyabyss_titan_memory`。背中のリセットでもループでも消えない。

### 2.4 巨神の記憶（天井システム）

- 目的: 専用装備が出るまでの周回を有限にし、「運が悪いだけで永遠に出ない」状態を防ぐ。
- 単位: プレイヤー×巨神ごとに 1 つのカウンタ。
- カウンタの数え方: 「図鑑（その巨神の心臓の品 10 品。岩鯨は 9 品）に新しい品が増えなかった心臓の撃破」の数。新しい品を手にすると 0 に戻る。重複では戻さない。ボスを倒さず退出したときは変わらない。

| カウンタ | 効果 |
|---|---|
| 0〜2 | 通常の確率 |
| 3 以上 | 図鑑の品の確率が 2 倍（ソフト天井） |
| 5 | 図鑑にない品を 1 つ保証（ハード天井） |

- 当初案の 5 / 8 は、図鑑全体を対象にして 3 / 5 に縮めた。
- 岩鯨の図鑑 9 品 = 甲殻 4 部位・大剣・護符・専用伝説 3 種。潮殻・雷翼・余燼は 10 品（鎧 4・基本の武器・もう一つのレアの品・護符・専用伝説 3。各 9〜11 章の表）。
- 全部持っている場合は共鳴の欠片に変換される。
- 交換は天井のカウンタを戻さない（欠片で買った品で天井が戻ると、欠片を使うほど損に感じるため。00 の 22）。

岩鯨の模擬（自己テスト、1〜4人 × 1万組）:

- 一人あたりの平均撃破数: 甲殻 4 部位 6.6 回、甲殻＋大剣＋護符 8.0 回、図鑑 9 品すべて 13.4 回（最悪 25〜27 回）。
- 組の全員が甲殻 4 部位を揃えるまで: 1人 6.6 回、2人 8.1 回、3人 8.9 回、4人 9.5 回。一人あたりの数字は人数で変わらない。
- ハード天井の発動は全撃破の約 7.8%。新しい品の出ない撃破は最長 4 回。
- 図鑑が揃うまでの平均撃破数: 潮殻 14.7、雷翼 13.0、余燼 13.0。

### 2.5 初回クリアの選択報酬

- 各巨神の心臓を初めて倒すと、専用伝説 3 種から一つをチャットで選ぶ（`/titanmemory choose <装備>`。潮殻は `/titanmemory tide`）。
- この贈り物ではカウンタを戻さない。

### 2.6 コマンド

| コマンド | 内容 |
|---|---|
| `/titanmemory` | 自分の記憶・撃破数・図鑑を見る（誰でも）。交換ができるか・この周回は済んだかの一行も出る |
| `/titanmemory claim` | 預かっている報酬を受け取る |
| `/titanmemory choose <装備>` | 初回の選択（チャットのクリックで実行される） |
| `/skyabyss memory set <人> <0-5>`、`memory clear <人>` | 管理者・テスト用 |
| `/skyabyss affix show` | 手の装備の特性と候補（内部の値つき） |
| `/skyabyss affix reroll` | 特性を抽選し直す（候補は消す） |
| `/skyabyss affix clear` | 特性を外す（持ち物にあると 1 秒ほどで抽選される） |
| `/skyabyss affix set <種類> <値>` | 特性を一つ足す・置き換える（幅と数の決まりは見ない） |
| `/skyabyss affix trial [回数]` | 結晶を払わずに候補を作る |
| `/skyabyss exchange show <人>` | 交換の状態 |
| `/skyabyss exchange reset <人>` | この周回の交換をやり直せるようにする |

## 3. 特性（Affix）

### 3.1 付く品と決まり

| 項目 | 決定 |
|---|---|
| 付く品 | レア以上の**武器**（剣の類・盾を含む）と**防具**だけ。護符・護石・補強板・装飾には付けない（重ねて持てるため。00 の 20） |
| 付く数 | レア 1〜2、伝説 2〜3。少ないほうが 60% |
| 重なり | 一つの装備に同じ種類は二度付かない（重みつきで引き、引いた種類を外して次を引く） |
| 値 | 種類ごとの幅の中で、刻みごとに同じ確率。伝説は幅の上下を 1.25 倍 |
| 効く場所 | 武器の特性は利き手に持つとき（盾は左手）、防具の特性はその部位に着ているとき |
| 付く時点 | 出た時点で決まる（報酬・初回の選択・交換）。特性の項目がない古い装備は、持ち物に入ったとき（1 秒ごと）に一度だけ抽選する（00 の 24）。鍛えた段階はそのまま |
| 知らない種類 | 将来消した種類を持つ装備は読み込めて、効かないだけ。ツールチップは「（失われた特性）」 |
| 弓 | 雷翼の弓には付けない。特性は攻撃力の修飾子で効くので矢には効かない（10.1節） |
| 神器の候補 | ダメージ反射・全被ダメ軽減などは神器で作る（未実装） |

- 実装: `item/affix/AffixType`（種類の表）、`Affix`、`AffixRules`（抽選・検め・再鍛造・表示）、`AffixEvents`（修飾子、守り・渇き・冴え、古い装備の抽選）、`AffixCommands`、`AffixSelfTest`。データは `skyabyss:affixes`。
- 画面の名前（鋭さ・迅さ…）は内部と書類の呼び名。画面には効果だけを出す（「攻撃力 +5%」）。
- 数値の特性はバニラの「利き手に持ったとき」の欄にも修飾子として出る。特性の行は品の性格、バニラの欄は合計として読める。

### 3.2 特性の表

値の幅はレア。伝説は 1.25 倍（例: 鋭さ 5〜10%）。

|---|---|---|---|---|---|---|---|
| `sharp` 鋭さ | 武器 | 攻撃力 +5% | 攻撃力に掛ける（素の値＋武器＋強化の和に掛ける） | 4〜8% | 0.5% | 30 | 筋力とは別の掛け算。技の傷も攻撃力から出るので乗る |
| `swift` 迅さ | 武器 | 攻撃速度 +6% | 攻撃速度に掛ける | 4〜10% | 0.5% | 25 | 敏捷 50 の +10% と同じくらいが上限 |
| `thirst` 渇き | 武器 | 吸血 3% | 手の武器で直接与えた傷の割合だけ回復。0.25 秒に一度、1 回 2 まで | 2〜4% | 0.5% | 15 | 回復の技は作らない方針（04 の 7.7節）なので小さく、範囲技で稼げないよう間を置いた |
| `resonant` 共鳴 | 武器 | 最大マナ +7 | 最大マナ（`skyabyss:max_mana`）に足す | 4〜10 | 1 | 20 | 精神 2〜5 ぶん |
| `keen` 冴え | 武器 | 技の待ち −6% | 技を使ったときの待ちを縮める（上限 15%） | 4〜10% | 0.5% | 15 | 巨神斬りの 8 秒が 7.2 秒。マナの縛りは変えない。武器を持たないと効かない。技の枠の覆いも縮めた長さで描く（`SkillHud` が `AffixEvents.scaleCooldown` を使う） |
| `bulwark` 堅牢 | 防具 | 防具強度 +0.5 | 防具強度（強靭）に足す | 0.5〜1.0 | 0.5 | 30 | 防御力そのものは足さない（3.3節） |
| `vigor` 頑健 | 防具 | 最大体力 +1（表示は +0.5❤） | 最大体力に足す | 0.5〜1.0（表示 +0.25〜0.5❤） | 0.5 | 25 | 耐久 2〜4 ぶん。4 部位でも最大 +4 点（表示 +2❤） |

### 3.3 強さへの効き

岩鯨の心臓との模擬（Lv 9、筋力 24 で攻撃 ×1.144、武器 +5、甲殻 4 部位 +0、心臓の一撃 12）。

| 武器 | 特性なし（心臓 450 を倒す秒） | 平均の特性 | いちばん良い特性 |
|---|---|---|---|
| 鯨骨の大剣 | 34.2 秒 | ×1.05 | ×1.19 |
| 番兵長の鉾 | 36.6 秒 | ×1.10 | ×1.24 |
| 水路の顎牙 | 28.3 秒 | ×1.10 | ×1.24 |

| 守り | 特性なし | 平均 | いちばん良い（4 部位とも 頑健 1.0 と 守り 3%） |
|---|---|---|---|
| 心臓の一撃に耐える回数 | 6.5 回 | ×1.08 | ×1.33 |

- 難しさ（倒す時間 ÷ 耐える回数）は平均の特性で ×0.84、すべて最良で ×0.61。強化 +10（武器 ×1.3）より小さい。強くなる主役は強化と専用装備のまま、特性は「当たりを引いた」楽しみの幅。
- 04 の技と筋力を足したときの +15〜20% と、平均の特性（攻め +5〜10%、守り +8%）は同じくらい。どれか一つで攻略が決まらない。
- 攻撃力を「+1.5」のような足し算にすると、速い顎牙（素の 6）だけが ×1.48 まで伸びた。割合にして、どの武器でも上限 ×1.24 にそろえた。
- 防御力を足す特性は外した。甲殻 4 部位で防御力 20（バニラの効きの上限の手前）にあるので、+1 ごとに受ける傷が 13% ずつ減る。代わりに防具強度にした（+4 で傷 −6%）。
- 守りの上限 10% は、4 部位で最大 12% になるところを甲殻の耐性 I（20%）の半分に収めるため。
- 吸血は 0.25 秒に一度・1 回 2 までなので、範囲で何体に当てても 1 秒に最大 8（実際は傷の 2〜5% で 1 秒に 1 前後）。

## 4. 共鳴の炉（強化・分解・再鍛造・交換）

### 4.1 置き場と画面

- 炉はブロック設備。岩鯨の背の尾の台（到着地点）に 1 基。レシピでも作れる（骨ブロック、共鳴の結晶、岩鯨の鱗片、磨かれた深層岩）。
- 炉は何も預からないので、何人でも同時に使える。再鍛造の候補は装備に付くので人ごとに別。
- 画面（`client/forge/ResonanceForgeScreen`、メニュー `forge/ResonanceForgeMenu`）。テクスチャ `textures/gui/forge/forge.png`、生成元 `tools/gen_forge_assets.py`（2 倍密度。骨の枠と石板は成長・技の画面と同じ作り）。

| 場所 | 中身 |
|---|---|
| 左の板（176×166） | 装備の枠（炉の光と熾の弧）、名前・階級・強化の段・特性、持ち物 |
| 右の板（152×166） | つまみ 3 つ（槌の「強化」、渦の「再鍛造」、天秤の「交換」）。最後に開いたつまみを覚える |
| 強化 | 次の段と費用、「強化」。分解で得るもの（欠片・結晶）と「分解」（二度押し） |
| 再鍛造 | 候補の数と結晶の数、「試す」。候補の札 3 枚（押すと金の縁で選ぶ）、「選んで確定」、「今のまま」（二度押し） |
| 交換 | 切り替えた巨神の共鳴の欠片の数（古い欠片も足す。名前を添える）、交換の状態の一文、専用伝説 3 つ（持っているものは「所持」、ないものは「選ぶ」を二度押し）。巨神は炉の交換のつまみの下のボタンで切り替える（「岩鯨の専用装備 ▸」） |

- 実装: `forge/ForgeRules`（費用・ボタン・分解の結晶）。創造モードは結晶・欠片を払わない。

### 4.2 強化と覚醒

- +n → +n+1 に、その巨神の素材 4+2n 個、共鳴の結晶 1 個（+5 以降は 2 個）。失敗なし。上限 +10。+10 まで合計で素材 130、結晶 15。
- 武器は 1 段ごとに**武器の攻撃力（素手の 1 を含む）の 3%**（どの武器も +10 で ×1.3。大剣 +0.30、鉾 +0.255、顎牙 +0.165 /段）。
- 防具は 1 段 1 部位ごとに**強靭 +0.3 だけ**（4 部位 +10 で強靭 +12）。防御は足さない。
- 強化の修飾子の ID は部位ごとに分けてある（同じ ID だと重なって上書きし合うため）。
- 盾は修飾子を足さず、防ぐ割合と棘が伸びる。護符・装飾・食料は鍛えない。
- 覚醒（+5）: 品ごとの固有効果が強まる（7〜11章の表）。+10 で範囲などが広がるものもある。
- 神器は上限 +15（13.2節。未実装）。
- 強化の上乗せは装備を見るたびに `GearEvents` が品の既定の攻撃力から計算する。段は `skyabyss:enhance`。

### 4.3 分解

| 分解するもの | 結果 |
|---|---|
| 伝説 | その巨神の共鳴の欠片 10 ＋ 強化に使った素材の半分 |
| レア以下 | その巨神の素材（階級値＋強化に使った素材の半分） |
| 特性の付く品 | 共鳴の結晶も出る（レア 1、伝説 2）。重なった装備の使い道になり、再鍛造の燃料が足りるようになる（00 の 21） |

### 4.4 再鍛造

- 共鳴の結晶 1 つで候補を一組（特性ぜんぶを振り直したもの）作る。3 組まで。
- 候補のどれか、または「今のまま」を選んで確定する。「今のまま」があるので、振り直しで弱くなることはない（払った結晶は戻らない）。確定のあとはまた 3 組試せる。
- 候補は装備に持たせる（`skyabyss:reforge_offers`）。炉を閉じても、ログアウトしても、払った分は消えない。
- 結晶 1 = 1 回なので、心臓 1 回の撃破でおよそ 1.4 回試せる。

### 4.5 交換

- その巨神の共鳴の欠片 30 で、まだ持っていないその巨神の専用伝説を一つ。巨神ごとに、その巨神の心臓を 1 回倒すごとに 1 回（「1 周回」を「心臓の撃破 1 回」と読んだ。月のループを作るときに決め直す。未決）。
- 対象は未所持の専用伝説だけ（00 の 23）。天井のカウンタは戻さない。
- 状態は巨神の記憶に持つ（「最後に交換した撃破数」「交換した回数」。古い記録は 0）。画面へは数の枠（DataSlot）で、所持の印と状態だけ送る。サーバーが毎回状態を見るので、同じ周回に二度は通らない。
- 実装: `loot/GearExchange`（巨神ごとの交換。表を登録すれば炉に出る）。

### 4.6 欠片と結晶の収支（岩鯨、4000 人の模擬。心臓と番兵長だけ、重なった装備は分解）

| 項目 | 結果 |
|---|---|

| 最初の 10 回で集まる共鳴の結晶 | 平均 14.3 個（心臓の 40% で約 4、残りは重なった装備の分解） |
| 専用伝説 3 つがそろう撃破数 | 交換なし 13.0 回 → 交換あり 10.6 回 |
| +10 に要る結晶 15 個 | 分解を入れて 11 回ほどの撃破で集まる（入れないと 37 回） |

- 交換は「天井が届く前に一つ早める」くらいの効き目。強化の速さは欠片（+10 で 130 個）が決めるので、強化が速くなりすぎることはない。

## 5. 強さの曲線

### 5.1 前提と式

| 項目 | 前提 |
|---|---|
| 難易度 | Normal |
| ステータス | 力の半分を筋力、4 分の 1 を耐久に振る（上限 50）。Lv 12 で筋力 16（攻撃 ×1.096）・最大体力 22、Lv 18 で ×1.15・23、Lv 24 で ×1.204・24、Lv 30 で ×1.258・25 |
| 攻め | 攻撃の目盛りが満ちてから振る。「1 秒あたり」= 攻撃力 × 攻撃速度 × 固有効果の上乗せ。相手の防具（バニラの式）を通す |
| 固有効果の上乗せ | 鉾: 噴出（攻撃力の 60%）が斬った相手にも当たる。3 回に 1 度で ×1.2、+5 から 2 回に 1 度で ×1.3。顎牙: 出血は振りの無敵時間に半分ほど食われるとみて 1 秒に 0.5（+5 から 1.0） |
| 守り | バニラの防具の式（防御・強靭）× 一式の耐性 I（×0.8）× 特性の守り。「耐える回数」= 最大体力 ÷ 一撃の傷 |
| 心臓との手ごたえ | 殴っていられるのは戦いの 6 割、心臓の技は 2.5 秒に一度。**手ごたえ = 戦いの間に受ける技の数 ÷ 耐えられる数**。1 を切ると避けずに殴り合っても勝てる（作業）。高いほど避ける腕が要る |

- 実装: `item/GearCurve`（式と目安の表 `STAGES`）、`item/GearCurveSelfTest`。
- このModの武器と防具は、バニラのエンチャントの対象（`#minecraft:enchantable/...` の札）に入っていない。鋭さ・ダメージ軽減は付かない。その代わりが強化と特性。
- 目標: 岩鯨の +10 はバニラの終盤（ネザライト + 鋭さ V）に届かない。バニラの終盤に並ぶのは潮殻（推奨 18）の +10 から。心臓は最後まで「避けて戦う相手」のまま。

### 5.4 調整の方針と岩鯨の最終値

| 項目 | 決定 | 理由 |
|---|---|---|
| 強化（武器） | 1 段で武器の攻撃力の 3%（足し算にしない） | 足し算（+0.6/段）では速い顎牙だけが +10 で ×2.0 になり、1 秒あたり 26.4 でバニラの終盤（17.6）の 1.5 倍に。割合にして、どの武器も ×1.3、+10 でバニラの終盤の 0.74〜0.90 倍 |
| 強化（防具） | 強靭 +0.3/段だけ | 防御を足すと +10 で防御 36（属性の上限 30）になり、心臓の一撃の 80%（バニラの効きの上限）を消した。強靭は重い一撃ほど効くので、後の巨神でも価値が残る（心臓の一撃 12 で ×1.17、20 で ×1.24） |
| 番兵長の鉾 | 攻撃力 8.5 | 噴出の上乗せ込みで、一体へダイヤの剣と同じ（11.2）。扇で群れに強いのが個性 |
| 水路の顎牙 | 攻撃力 5.5 | 出血込みでダイヤの剣の 1.1 倍。速さと水中・出血が個性 |
| 鯨骨の大剣 | 攻撃力 10 | 1 秒あたりはダイヤの剣の 0.9 倍。一撃の重さと鈍足 II が個性 |
| 岩鯨の甲殻 | 強靭 1 部位 2.0（ダイヤと同じ） | 素の硬さはダイヤにそろえ、一式の耐性 I を個性として残す |
| 岩鯨の補強板 | 甲殻 2 部位で防具強度 +3 | 防御の上限の手前で +2 は重い（1 つで受ける傷が 1 割以上減る）。強靭は重い一撃に効き、「補強」らしい |
| 防具の強化を強靭だけにした点 | 武器 ×1.3 より効きが小さい（+10 で耐える回数 ×1.17） | 後の巨神ほど一撃が重く効きが増す。「防具の強化が効かない」と感じたら、割合の軽減（1 段 1 部位 0.25%）を足す（未決。00 の 66） |

- 結果（Lv 12）: 手に入れた直後の手ごたえは 4.0〜4.8（ダイヤの装備の 5.6 より少し楽）、+10 で 2.5（ダイヤ + 鋭さ III・軽減 III の 2.2 と同じくらい）、+10・最良の特性・筋力全振りでも 1.35〜1.59。
- 手に入れた直後（+0）は、大剣・鉾・顎牙がダイヤの剣の 0.9〜1.2 倍、甲殻がダイヤの防具より 2 割ほど硬い（耐性 I）。バニラの終盤は大きく下回る。推奨 Lv 12 ではダイヤ前後を持って来る前提なので、素の強さは大きく変えない。
- 特性・ステータス・技は、どれも ×1.1〜1.3 の範囲で一つで攻略が決まらないので変えない。
- 鉾の噴出は、斬った相手の無敵時間を消してもう一度当たり、一体へ ×1.2〜1.3 の上乗せになる。素の攻撃力を少し下げて合わせた（上の表）。

### 5.5 巨神ごとの目安（各段階の基準値）

`item/GearCurve.STAGES` に同じ表を置いた。自己テストで、段ごとに伸びていること、前の巨神の +10 が次の巨神の +10 を超えないことを検める。

- 潮殻の心臓は目安どおり 540、鎧の「2 部位で強靭 +3」も目安に寄せた（00 の 68）。

## 6. 必要レベルと装飾の枠

### 6.1 必要レベル

決め方: **その巨神の推奨 Lv から、レア以下は −4、伝説以上は −2**（`item/GearLevel.defaultRequired`。推奨 Lv は `GearCurve.STAGES`）。

- 心臓を初めて倒すのは Lv 9 ごろ、推奨は 12。レアはそれより前から使え、伝説は推奨の少し手前から使える。強い仲間に連れて行ってもらって Lv 3〜4 で伝説を拾っても、Lv 10 までは力が出ない。
- 全差を「推奨 −6」や「推奨ちょうど」にしなかったのは、初めて倒す Lv 9 ごろにレアを使え、伝説は推奨の手前から使えるようにするため（推奨ちょうどだと、心臓から出た品を Lv 12 まで使えない）。
- 食料・矢・素材・鍵・心核・呼び笛には付けない（強さを飛び越す品ではない）。

| 巨神（推奨） | レア以下 | 伝説以上 | 品 |
|---|---|---|---|
| 岩鯨（12） | **8** | **10** | Lv 8: 鯨骨の大剣、岩鯨の甲殻（4 部位）、共鳴の護符、苔の護石。Lv 10: 番兵長の鉾、水路の顎牙、岩鯨の補強板 |
| 潮殻（18） | 14 | 16 | Lv 14: 三叉槍、珊瑚の盾、潮殻の鎧、潮鳴りの護符。Lv 16: 潮招きの大鋏、珊瑚憑きの銛、月潮の真珠 |
| 雷翼（24） | 20 | 22 | Lv 20: 雷翼の弓、羽衣、嵐の護符、嵐纏の足環。Lv 22: 雷獣の爪、羽守の鉤槍、嵐の目の羽根 |
| 余燼（30） | 26 | 28 | Lv 26: 余燼の戦斧、熾火の外套、余燼の鎧、熾りの護符。Lv 28: 鍛え手の大鎚、灰被りの火掻き、余燼の灯 |
| 深淵・月・雲海、四巨神の装備、神器 | （仮） | （仮） | 推奨 Lv が決まっていない。案は深淵 36・月 42・雲海 48 で、同じ決め方（未決。00 の 94） |

- 品の側は `ModGear.requiredLevel()`（既定は上の決め方）。後の巨神の品は `dungeon()` を返せば自動で決まる。特別な品だけ上書きする。
- 今のところレベルは下がらない。もし下げる仕組みができたら、枠の品は残ったまま効かなくなり、防具は持ち物へ戻る。

### 6.2 足りないときの扱い

バニラの仕組みを壊さないよう、「手に入れる・動かす」は止めず、「身につける・力を出す」だけを止める。

| 品 | 足りないとき | 仕組み |
|---|---|---|
| 防具 | 身につけられない。防具の枠に入らない、右クリックで着られない。何かの拍子に着ていたら（発射装置・コマンド）、0.5 秒ほどで持ち物へ戻す（入らなければ足もとへ） | `canEquip` と `use`、`GearLevel.enforceArmor` |
| 武器（左手の盾を含む） | 手に持てる・振れる。ただし品の修飾子（攻撃力・速さ・鉾の間合い・強化・特性）をちょうど打ち消すので、素手と同じ（攻撃力 1、速さ 4）。固有効果と特性も出ない | プレイヤーに逆向きの一時的な修飾子（`skyabyss:gear_lock/…`）を毎 tick 合わせる |
| 護符・装飾 | 枠に付けられない。右クリックでも付かない。枠に入っていても（コマンドなど）効かない | 枠の `mayPlace`、`Accessories.worn` |
| どれも | 拾う・渡す・チェストに入れる・強化・再鍛造・交換・分解はできる | — |
| 創造モード | 問わない | — |

- 武器を「持てない」にしなかったのは、手の枠を塞ぐとバニラの持ち替えやブロックの設置の流れが崩れ、鍛えるために炉へ持って行く道も止まるため。
- バニラの「利き手に持ったとき」の欄は、足りないときも品の数（例「+8.5 攻撃力」）のまま出る。赤い行で読めるようにした。

### 6.3 装飾の枠

| 枠 | 数 | 入る品（今） | 入る品（予定） | 効き方 |
|---|---|---|---|---|
| 護符 | 1 | 共鳴の護符、潮鳴りの護符、嵐の護符、熾りの護符 | — | 使って効く（待ちは品ごと）。**H キー**で使う |
| 装飾 | 2 | 岩鯨の補強板、苔の護石、月潮の真珠、嵐纏の足環、嵐の目の羽根、熾火の外套、余燼の灯、鼓動守（巨神ごと 4 種） | ループの刻印、巡礼者の翼、深淵の灯 | 付けているあいだ効く |

- 同じ品は二つの装飾の枠に入らない。
- **鼓動守**（`heartbeat_ward_<巨神>`。アンコモン、鍛えない・特性なし、必要 Lv はその巨神の推奨 Lv −4）: 付けているあいだ、心臓の戦いで一度だけ致命の一撃を体力 1 で耐える（人ごと・1 回の戦い。使うと光って消える。02 の 4.2）。備えの糧の灯に 0.2 足す（11 の 9.1）。入手は備えの頼み 3 の報酬、補充は旅の職人（21 の 1.4。職人は P4）。
- 持ち物にあるだけでは効かない。手で右クリックすると合う枠へ付き、前に付いていた品は手に戻る（防具の右クリックと同じ）。
- 護符を 1 枠にしたのは、使う護符を選ぶ楽しみを残すため。強い効果ばかりなので、二つ同時に使えると重なる。
- 巡礼者の翼は装飾の枠に入れる前提（終章を作るときに「雲海を越えたら 3 枠目が開く」案も考える）。
- 満月の冠は兜、珊瑚の盾はバニラの左手、月の涙は消耗品なので枠には入らない。
- 護符＝使って効く、装飾＝付けているあいだ効く（自動で働く品は装飾）。
- 護符の待ちは画面に出さない（キーを押すと残りの秒を知らせる）。技の枠 `SkillHud` の隣に小さな護符の枠を出す案は、HUD の場所がぶつかるため未実装（未決。00 の 93）。
- 創造モードの持ち物の画面には装飾のつまみがない（既知の制限）。
- 見た目: 装飾品・補助の品 16 個（4 巨神の護符・装飾・手に持つ補助の品）は、持つ・落とす・額縁・頭では低ポリの立体（階級のコモン・レア・伝説で形が変わる。GUI は 32x32 の平面）。**鍛えない**ので強化の段の見た目はない。装飾の枠（1・2 番）に付けた品は、プレイヤーの体にも描く（足環 = 右足首、嵐の目の羽根 = 右耳の後ろ、外套 = 背中、余燼の灯 = 腰の左、苔の護石 = 腰の右、補強板 = 背中、月潮の真珠 = 胸）。護符は身につけない品なので体には描かない。ほかのプレイヤーにも見え、一人称では自分の体が出ないので見えない。形・面数・仕組みは [15](15_high_poly.md) の 4.6.4。

### 6.4 方式（自前の枠）

| 案 | 中身 | 良い点 | 悪い点 |
|---|---|---|---|
| (a) 自前（採用） | プレイヤーに Data Attachment（`skyabyss:accessories`）で 3 枠を持たせ、専用の画面（メニュー）で出し入れ | 依存が増えない（配布は jar 一つ）。保存・死亡・同期を岩鯨の背の預かりや成長の記録と同じ作りで決められる | 画面・メニュー・死亡・移し替えを自分で書く（約 1,250 行。自己テストを含む） |
| (b) Curios API | Curios の枠の種類に品を登録 | 他の Mod と枠を共有できる | 任意依存だと入れない人のための代わりが要り二重になる。保守が増え、画面の見た目がそろわない。死亡の扱いが岩鯨の背の預かりと合わせにくい |

- 枠は 3 つで他の Mod と共有する必要が薄く、配布と保守を軽くする方針（ユーザーの決定）にも合うので (a)。Curios は使わない。
- 画面は、バニラの持ち物の画面（`InventoryMenu`）に枠を足すのでなく別の画面にした。足すには Mixin が要り（このModは使っていない）、枠の番号がずれて他の Mod や創造モードの画面が崩れやすいため。ステータス画面のつまみ（`RpgTabs`）に足す案は、装飾の画面が持ち物を動かすメニューで記録を見る画面とは性格が違うので採らなかった。

### 6.5 画面とキー

- 持ち物の画面（サバイバル）の上の右に「持ち物」「装飾」のつまみ。「装飾」で装飾の画面、「持ち物」で戻る。つまみはレシピ本を開いて画面が右へ寄っても付いていく。
- 装飾の画面（176×166）: 真ん中に人形（マウスを追う）、左に護符の枠（金の輪）と「[H] で使う」（キー設定に合わせて変わる）、右に装飾の枠 2 つと今の Lv、下に持ち物。シフトクリックで合う枠へ入る。採用した配置は「人形を囲む」案（重なりがなかった）。
- テクスチャは 32px 密度、骨の枠と石板は共鳴の炉と同じ（`tools/gen_accessory_assets.py`、`textures/gui/accessory/accessory.png`）。空の枠には、護符は首飾り、装飾は輪の印を薄く描く。
- 護符を使うキーは **H**（バニラは使っていない。J・K・U・B（控え帳）・O（パーティ）・R・G・V・Z とも別）。設定の「天と淵のあいだ」の欄で変えられる。待ちの最中は「休んでいる（あと 42 秒）」、枠が空なら「護符の枠が空いている」と画面の下に出す。
- 文字は名前空間 `assets/skyabyss_gear/lang/`（キー `skyabyss_gear.…`）。共有の lang には護符・補強板・護石の説明（「装飾の枠に付けると」）だけ手を入れた。
- 実装: `item/accessory/`（`Accessories`、`AccessoryData`、`AccessoryMenu`、`AccessorySetup`、`Accessory`、`AccessoryKind`、`AccessorySelfTest`）、`client/accessory/`（`AccessoryScreen`、`AccessoryClient`）、`item/GearLevel`、`item/ResonanceCharmItem`、`GearItem`。

### 6.6 死亡・保存・同期・前のセーブ

| 場面 | 扱い |
|---|---|
| 死んだとき | 持ち物と同じに足もとへ落ちる（`LivingDropsEvent` に足すので、墓の Mod などとも同じ流れ）。消滅の呪いの品は消える |
| keepInventory | 落ちない（枠の記録が `copyOnDeath` で新しい体へ移る） |
| 四体の背（岩鯨・潮殻・雷翼・余燼） | どの背でも落ちない。背中の預かりの仕組み（`TitanBackTrials`）が落ちる品の知らせを止めるので、枠の中身はそのまま残り、休み場で目を覚ましたときも付いている。判定は背中の一覧 `TitanBacks.isBack`（持ち物の預かりと同じ） |
| 保存 | プレイヤーのデータ（`skyabyss:accessories`）。品はバニラの形で保存されるので、強化の段・特性もそのまま |
| 同期 | 画面の中はメニューの同期。記録そのものは持ち主にだけ送る。ログイン・復活・次元の移動で送り直す |
| 前のセーブ | 持ち物にある護符・補強板・護石を、最初の 1 秒で一度だけ空いた枠へ移し、チャットで知らせる。必要 Lv に届かない品と、枠が埋まっている分は持ち物に残る |
| マルチ | 枠の出し入れ・護符を使う・右クリックで付けるは、どれもサーバーで種類・重なり・Lv・待ちを検める |

### 7.2 図鑑と報酬の決まり

- 図鑑に記すのは心臓の品。中ボス・道中の敵の品も、出れば図鑑に記す（初めての品なら記憶を 0 に戻すが、記憶は進めない）。
- 抽選はすべて一人ずつ（2.3節）。
- 記録の画面（11）の「巨神」に、記憶・撃破・図鑑・交換の行を出す（記録がある人だけ）。

### 9.3 強さの曲線（`TideGearSelfTest`）

**1 秒あたり（一体へ、固有効果の上乗せ込み）**

| 珊瑚憑きの銛 | 13.50 | 15.53 | 17.55 |
