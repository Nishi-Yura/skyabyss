## 1. ねらい

Wynncraft のアスペクトに近い、巨神の祠のルートを回る理由。Lv 50 になってからも、祠ごとにしか出ないミシックと、同じ品を重ねて上げる Lv が残る。

## 2. 品

- 6 職 × 40 品 = 240 品。職ごとに、どの祠でも出るレア 4・エピック 4、祠ごとのレア 3・エピック 3（4 祠で 24）、祠ごとのミシック 2（4 祠で 8）。一つの祠で出るのは 16 品。
- id: `<職>_r1..4`・`<職>_e1..4`（どの祠でも）、`<職>_r_<巨神><1..3>`・`<職>_e_<巨神><1..3>`（その祠だけのレア・エピック）、`<職>_m_<巨神><1|2>`（ミシック）。
- 祠ごとの品の名前は「祠の字の<名>・技」（例: 鯨の岩肌・盾殴り）。効き目は祠の色（鯨 = 守り、潮 = マナと待ち、雷 = 速さ、熾 = 力と次の一撃）。
- 一つの品は一つの技を変える。効き目（`Aspect.Verb`）:

| 効き目 | 中身 |
|---|---|
| POWER | 技の力 + |
| COOLDOWN | 技のクールダウン − |
| MANA | 技のマナ − |
| HASTE | 使ったあと 3 秒、移動 + |
| SURGE | 使ったあとの次の一撃 + |
| GUARD | 使ったあと 3 秒、受けるダメージ − |
| ECHO | 0.6 秒後にもう一度（力は値の割合。ミシックの短剣の写しと同じ口 `MythicAbilities.withPowerScale`） |
| RESET | 値の確率でクールダウンがすぐ戻る |

- 値は Lv 1 から Lv 5 まで一直線に上がる（`Aspect.Fx.at`）。一つの技への力とマナは、重ねても `SkillRules.ASPECT_POWER_MAX`（0.35）・`ASPECT_MANA_MAX`（0.25）で止める（`Aspects.power`・`mana`）。全部の上限は `SkillBuild` の力 +100%・マナ ±50% のまま。

## 3. Lv と枠

- 同じ品を重ねると Lv が上がる。Lv ごとに要る数（累計）: 1・2・4・7・11（`Aspects.COPIES`）。Lv 5 が最高で、11 を越えた分は数えない。
- 枠はプレイヤーの Lv 20・30・40・50 で 1〜4、転生 3 回で 5 つ目（`Aspects.slots`）。
- 付けられるのは今の職の品だけ。職を替えると、ほかの職の品は枠に残っても効かない。同じ品は一つの枠だけ。
- K 画面の 3 ページ目「アスペクト」（`ExtPage`）: 左は祭壇。五つの枠を輪に並べ、真ん中に今の職の木の印（閉じた枠は開く Lv、空きの枠は小さな菱）。枠を押すと外す。下に付けた数とミシックまでの回数。右は棚。「どの祠でも」と祠ごとの段（一段 8 品）を縦に送る（ホイール・右の目盛り）。品は技の絵の札で、縁は稀さの色（ミシックは光る二重の縁）、下に Lv の点 5 つ、付けている品は左上に金の三角。名前と効き目は重ねた説明に出す。まだ持っていない品は「？」の札で、名前も効き目も伏せる（説明は稀さと出る所だけ）。持っている品を押すと空いた枠へ付く。

## 4. 出る

- 祠のルートを越えたとき（`RaidRewards.grantRoute` → `AspectNet.grant`）、参加した人それぞれに今の職の品が 1 つ。崩れ（全滅）なしならもう 1 つ。周回でも減らない。
- 稀さはレア 60%・エピック 30%・ミシック 10%。品はその稀さの、どの祠でも出るものとその祠のものから一様に。ミシックなしが 8 回続いたら、次は必ずミシック（`SkillData.aspectPity`。ミシックで 0 に戻る）。
- オフラインの仲間の分は、次に入ったとき（そのときの職で）引いて、報いの祭壇を開く（`AspectPending`。一人 32 回分まで）。

## 5. 報いの祭壇（出たものを見せる画面）

- `AspectNet.Reveal` を受けて `AspectRevealScreen` が開く。心臓の遺物の画面や場面（シネマ）が開いているあいだは待ち、何も開いていなくなってから開く。
- 暗転 → 題字「報いの祭壇」と巨神の名 → 裏返しの札が上がる。クリック・Space・Enter で一枚ずつめくる（2 秒待てば自分でめくれる）。ミシックは別の音。
- 表: 稀さ・名前・「新しい」か「Lv a → b」・変える技・効き目・次の Lv までの帯。全部めくったらクリックで閉じる。Esc はいつでも閉じる。
- チャットの帯にも「手に入れた」で名前と Lv を出す。

## 6. 祭司の「報い」の頁

- 祠の画面（祭司に話しかけて開く）の 4 つ目の頁。その祠で出る品（今の職の 16 品）を「どの祠でも」と「この祠だけ」の二段の札で並べる（K 画面と同じ札。持っていない品は「？」）。
- 上に出る割合とミシックまでの残りの回数。品に重ねると K 画面と同じ説明。

## 7. 開発用

- `/skyabyss skill aspect <player> <id> <copies>`: 品の数を足す。
- 自己テストは `skills` の段（`DeepSkillsSelfTest.aspects`）: 品の数・祠ごとの品・Lv の数・枠・ミシックはその祠だけ・必ずミシック・崩れなしで 2 つ・数の上限・枠の鍵・同じ品は一つの枠・職替えで効かない。
