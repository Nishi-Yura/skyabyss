# 天と淵のあいだ 画面の知らせ

- 文書番号: 18
- 範囲: チャットに流していた世界の声・獲得・警告を、画面の決まった場所に種類ごとの見せ方で出す仕組み（通知の仕分け、レベルアップ、目的の帯、知らせの記録）。
- 関連: [17](17_opening_and_rpg_feel.md)（5.1〜5.3 の元の設計。実装は 18 が正）、[04](04_growth_and_skills.md)（レベル）、[07](07_npc_quest.md)（クエストの札・ログ）、[11](11_record_screen.md)

## 1. 方針

- チャットは「人の声」と「コマンドの結果」だけにする。世界の声・獲得・警告は、画面の決まった場所に、種類ごとの見せ方で出す（試遊で「レベルアップやいろんな文がチャットに流れて見づらい」と言われたため）。
- 同じ場所には一度に一つだけ映る（順番待ち）。混んだら一つあたりを縮め、あふれたら手がかりから捨てる。
- 見逃しても、N の「知らせの記録」で読み返せる。
- 文言（翻訳キー）は変えない。送り方だけを変えた。
- 見た目は案 A（暗い石板。クエスト・伝承の札と同じ作り）。ラフは `docs/review/notice_roughs/index.html`。参考: ゼルダ（下中央の語りの字幕、右上の獲得）、ドラクエ（獲得の窓）、FF（場所名のタイトル）、Elden Ring（場所名・撃破の大きな帯、獲得の札）。

## 2. 何をどこに出すか

`sendSystemMessage` / `displayClientMessage` / `ModText.*` の呼び出し（コマンド `*Commands.java` と開発用 `dev/` は対象外）を、次のように分けた。

| 種類（ModText） | 例 | 頻度 | 新しい見せ方 |
| --- | --- | --- | --- |
| lore（語り・囁き） | 背の囁き（BackWhispers）、伝承の書が落ちる、心臓が止まる、記憶の保証 | 場所ごとに一度、戦いの終わり | 下中央の字幕 |
| hint（手がかり） | 「J でステータス」、休み場の焚き火、錨石、報酬が保留中 | 初めの数回 | 同じ字幕（灰色。同じ文は 3 回まで） |
| hint（足もと） | 試練の手応え、渡りの案内、風見鶏の状態 | 行動のたび | アクションバー |
| progress（前進） | 封印が解けた、石が鳴った、欠片を得た、装備を得た、チェックポイント | 試練ごと | 右上の札（「進展」） |
| 戦果（rewardLine・memoryLine） | 受け取ったもの、巨神の記憶 ◆◆◇ | 巨神ごと | 右上の札（「獲得」） |
| レベル（growth.level_up、技の点、技を覚えた） | レベル N、振り分けの力、技の点が増えた | レベルごと | 画面中央の演出 + 既存の「Lv」文字と鈴の音 |
| battle（戦い） | 扉が閉ざされた、波が来る、巨神の怒り、伝説を手にした | 戦いの区切り | 上の帯（小さめ） |
| 場所の名前 | 背に着いた（TitanTravel など 5 か所のタイトル） | 到着ごと | 画面中央上のタイトル（大）+ 副題 |
| deny（拒否・失敗） | 必要レベル不足、扉が開かない、待ち時間 | 行動のたび | アクションバー（赤紫） |
| クエストの始まり・終わり | クエスト開始・完了 | 進行ごと | 既存のクエストの札があるので、チャットの重複を削除 |
| 墓（倒れたとき） | 墓が立った（字幕）、開けた・救われた（札）、他人の墓・一部だけ（アクションバー）。11 の 6.5 | 倒れるたび、墓を開けるたび | それぞれの種類の見せ方（チャットには出さない） |
| カウントダウン | あと N 秒で扉が閉じる | 毎秒 | アクションバー（もとからそう） |
| 章の題字・余韻 | 章が替わった（「一章　岩鯨」「空を泳ぐもの」）、章の終わり（見出し「一章　岩鯨　終」と一言） | 章ごとに各 1 回（人ごと） | 上の帯の列（場所の名前と同じ順番待ち。大きめ・長め）。9 章 |
| 世界の最初・パーティ | 誰が心臓を倒した（世界の最初。同じ巨神を止めた人にだけ。次の巨神の名前は出さない）、天の鍵がそろった（心臓を一つ以上止めた人にだけ）、パーティの招待（札に受け方つき）・参加・脱退・断り | まれ | 語り（世界の最初）、右上の札（招待・参加）、手がかり（ほか）。失敗はアクションバー |
| **チャットに残すもの** | `/titanmemory` の表示、記憶の選択肢（押せる名前）、コマンドの返事（`/party` の一覧など） | まれ | チャット（押せる・コマンド） |

呼び出し約 520 行のうち、プレイヤーへの通知として置き換えたのは 388 か所（63 ファイル）。タイトルパケット 5 か所は `Notice.place`、クエストの重複 2 か所は削除。

## 3. 種類と画面の配置

| 種類（`Notice.Kind`） | 場所 | 見せ方 | 長さ（標準） |
| --- | --- | --- | --- |
| NARRATE | 下中央（アクションバーの上） | 暗い帯の上に青緑の斜体。折り返し 4 行まで。細い線で挟む | 字数に応じて 2.6〜7.5 秒 + 出入り 0.45/0.65 秒 |
| HINT | 188 | 灰色。同じ文は 3 回まで | 2.2〜5.5 秒 |
| LEVEL_UP | 画面の上から 36% | 金の線で挟んだ一行（「Lv」の文字のすぐ下）。音つき | 2.6 秒 |
| GAIN / UNLOCK | 右上の札 | 暗い石板、金/青緑の縦の線、見出し「獲得」/「進展」。伝承・クエストの札と同じ列（重ならない）。幅 160、本文 3 行まで | 4.5 秒 |
| PLACE | 上から 16% | 金の見出し文字（HEADING、1.5 倍）+ 副題。線が左右へ伸びる | 3.4 秒 |
| ALERT | 上から 10% | 金の太字の一行（等倍）。PLACE と同じ順番待ち | 2.3 秒 |
| CHAPTER | 上から 16%（PLACE と同じ列） | 章の題字の札。「一章　岩鯨」を TITLE（2.2 倍）の金の文字、線が左右へ伸び、下に題字「空を泳ぐもの」を HEADING（1.5 倍） | 5.0 秒 |
| AFTERMATH | 上から 16%（同上） | 章の余韻の札。小さな金の見出し「一章　岩鯨　終」を線で挟み、その下に一言を HEADING（1.5 倍）で（3 行まで） | 4.5〜8 秒（字数に応じて） |
| WARN / BAR | アクションバー | 一行（警告は赤紫） | バニラの長さ |

- 画面の「Lv」の文字（`GrowthHud`）は残し、その下に LEVEL_UP の一行が出る。F1 で隠れる。画面を閉じている間も進む。
- レベルアップの音と光（`Growth.celebrate` の鈴と光の粒）は残す。
- 札の音は既存の鈴（アメジストの鳴り）を流用。

## 4. 順番待ち（`NoticeQueue`）

- 字幕・中央・上の帯は種類ごとの列。いつも一つだけ映る。先に来たものから。
- 混むと一つあたりの長さが縮む（待ち 1 件ごとに 1/(1+0.35n)、下限 40%）。設定の速さで全体を伸縮（0.5〜2 倍）。
- 待ちは 6 件まで。あふれたら手がかり（HINT）から古い順に捨て、なければ一番古い待ちを捨てる。
- 同じ文が続けて来たら一度だけ。
- 札は `ToastComponent` の列（バニラの仕組み）に並ぶ。

- 画面の中央まわりは一つの寸法で積む（`NoticeClient`）。上から、上の帯（PLACE・ALERT。ボスバーがあればその下へ）→ レベルアップの文字（`GrowthHud`。帯・ボスバーの下へずれる）→ 中央の演出（LEVEL_UP の知らせ。レベルアップの文字の下）→ 字幕（下中央。中央の下端より上へは伸びず、狭い画面では行を減らす）。場所の名前の最中にレベルが上がっても重ならない。ボスバーの下端は `CustomizeGuiOverlayEvent.BossEventProgress` で知る。

## 5. API（`jp.revati.skyabyss.notice.Notice`）

- サーバー側: `Notice.narrate / hint / levelUp / gain / unlock / alert / warn / place / bar / send`、章の札は `Notice.chapter(player, 見出し, 題字)` と `Notice.aftermath(player, 見出し, 一言)`（直接は呼ばず、9 章の `ChapterCards` を使う）。引数は `(player, 文の鍵, 引数...)` か、`ModText` の文。
- `ModText.lore/hint/progress/deny/battle` が返す文には種類の印が付く（空の部品の insertion）。`Notice.send(player, 文)` は印から種類を決め、印がなければチャット。コマンドの返事やツールチップに `ModText` をそのまま使っても見た目は変わらない。
- `Notice.send(player, kind, 文)` で種類を決めて送る。`Notice.bar` はアクションバー。クライアントだけの呼び出し（本人の画面）は、プレイヤーがサーバー側でなければバニラの表示に落ちる。
- パケットは `NoticePayload`（版 notice-1、`NoticeNetwork`）。クライアントは `client/notice/`（`NoticeClient`、`NoticeToast`、`NoticeLog`、`NoticeLogScreen`）。
- 開発用（OP）: `/skyabyss dev notice <narrate|hint|levelup|gain|unlock|alert|warn|bar> <文の鍵>`、`… place <題の鍵> <副題の鍵>`（`NoticeDev`）。章の札は `/skyabyss dev arc <card|aftermath> <章の ID>`、記録の確認・消去は `/skyabyss dev arc <status|reset>`（`ArcSetup`）。台本から `cmd` で使う。
- `NoticeQueue` は `CHAPTER`・`AFTERMATH` を上の帯の列に積む。`Notice.Kind` の追加はパケットが順番の番号で送るので必ず末尾に。

## 6. 設定（クライアント）

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| `notifyMode` | `TOAST` | TOAST = 画面の演出だけ、CHAT = 今までどおりチャットだけ、BOTH = 両方 |
| `noticeSpeed` | 1.0 | 字幕・中央・帯の出ている長さの倍率（0.5〜2） |
| `objectiveStrip` | true | 左上のメインの目的の帯 |

## 7. 知らせの記録（N）

流れた語り・獲得・場所の名前を、時刻つきで新しい順に 200 件まで（この遊びの間）。クエストログと同じ暗い石板の窓。ホイールで送る。台本では `open notices`。実装: `NoticeLog`、`NoticeLogScreen`。

## 8. 目的の帯（`ObjectiveStrip`）

- 左上（クエストの小さな表示の位置）に、メインの目的を細い一行で出す。目的が変わると一度だけ光る。傷を受けた直後と画面を開いている間、ホラー演出（足音・歌・影）の最中は薄くする。
- 追跡中のクエストがメインのときは、この帯が代わりに出す（サブのクエストの表示は帯の下へ下がる）。全文は U のクエストログ。
- 距離（10 ブロック単位）と八方位は、目的ごとの位置につく。位置は序盤の構造物（野営地・宿り・骨の丘・岩鯨）をサーバーが人ごとに送る（`OpeningDirector.target`。17）。
- 場面（シネマティック）の間は HUD ごと隠れる（`hideGui`）ので、知らせは出ない。台詞は場面の画面が自分で描く（[20](20_cinematics.md)）。
- 開幕の暗転と題字（`OpeningOverlay`）は 17 の 13.5。表示の部品は `Notice.place`（題字）と `NoticeClient` の帯を使う。
- `sky/`・`lore/`・titan の出現条件は、文を出す呼び出しの置き換えだけにした（条件は触っていない）。

## 9. 章の題字と余韻（`story/arc/ChapterCards`）

章（`Chapters`。01 の 4）が替わったことと終わりを、上の帯の列に大きな札で出す。チャットには流さない。ほかの上の帯（場所の名前・戦いの知らせ）と同じ順番待ちに並ぶので重ならない。レベルアップの文字・中央の演出・字幕は、札の下端（`bannerBottom`）より下へずれる。知らせの記録（N）には「題 + 副題」「見出し + 一言」の一行で残る。絵は `docs/review/previews/chapter_card_with_levelup_and_caption.png`（題字の札・レベルアップ・字幕が同時）、`chapter_aftermath_whale.png`（余韻の札）。

**題字の札（自動）**
- 人の章（`Chapters.of`）が、まだ札を出していない章になったとき、見てから 5 秒（`TITLE_DELAY` = 100 tick）空けて一度だけ出す。5 秒空けるのは、前の章の余韻の札などを先に出すため。見出し = `Chapters.label()`（「一章　岩鯨」）、副題 = `Chapters.titleKey()`（「空を泳ぐもの」）。
- 場面（シネマティック）の最中・死んでいる間・観戦中は出さず、終わってから出す（20 の場面と重ならない）。札は使い切りにならない。
- 出さずに「出した」ことにする: 序章（開幕の題字は `OpeningOverlay`）、五章以降（中身がない）、すでに遊んでいた人（`OpeningState.legacy`）。すでに先の章にいる人は、今の章の札だけで、前の章の札は出さない。
- 「出した」の記録は人ごと（`ArcData`、プレイヤーのデータ。死んでも引き継ぐ）。再ログイン・再起動でも二度出ない。

**余韻の札（各章の担当が呼ぶ）**
- `ChapterCards.aftermath(player, Chapters.WHALE, 一言の Component)`。一言を省くと翻訳キー `chapter.skyabyss.aftermath.<章の ID>` を使う（その章の担当が自分の lang に足す）。見出しは `chapter.skyabyss.aftermath.head`（「%s　終」）。
- 人ごとに章ごと一度（記録は `ArcData`）。場面の間は預かり、終わってから出す（ログアウトで預かりは消える。記録していないので、もう一度呼んでよい）。受け付けたら true、すでに出した・預かっているなら false。
- 語り部の一言は、札のあとに `Notice.narrate` を続ける（字幕は別の列）。

**章の予兆の枠・空の段** は 01 の 4.1 の「予兆 3 拍」「空の異変の段」。コードは `story/arc/Foreshadow`（使い方は頭のコメント。01 の 4.1 に API の要約）と `sky/ChapterSky.Stage`。

## 7. 文字の決まり（`client/ui/TextStyle`）

- この mod は字を絵にせず、いつもバニラのフォントを `Component`（lang の鍵）で描く。カスタムフォントも使わない（試遊で「凝るなら全体でフォントをそろえる、そうでなければバニラでいい」と言われ、バニラにそろえた）。題字の絵（旧 `textures/gui/opening/`）と生成スクリプトは廃止。
- 大きさと色は `TextStyle` に一か所で決める。大きい字はポーズの拡大で描き、光は同じ字を色つきで少しずつずらして重ねる（`drawGlowCentered`）。

| 種類 | 倍率 | 使う場所 |
| --- | --- | --- |
| TITLE | 2.2 | 開幕の題字（画面の高さで更に拡大）、章の題字、スカイキーの終わりの題 |
| HEADING | 1.5 | 場所の名前、章の題字の副題、章の余韻の一言、レベルアップの数字、成長画面のレベル、開幕の副題 |
| BODY | 1.0 | 本文・字幕・札・開幕の一行 |
| CAPTION | 1.0（灰色） | 注記・手がかり・案内 |

- ボスバー・控え帳・伝承の書・技の画面・成長の画面の字は、もとからバニラのフォントで `Component` として描いている（画像に焼いた字はない）。
