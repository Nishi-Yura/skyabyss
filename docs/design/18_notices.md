# 天と淵のあいだ 画面の知らせ

- 文書番号: 18
- 範囲: チャットに流していた世界の声・獲得・警告を、画面の決まった場所に種類ごとの見せ方で出す仕組み（通知の仕分け、レベルアップ、目的の帯、知らせの記録）。
- 関連: [17](17_opening_and_rpg_feel.md)（5.1〜5.3 の元の設計。実装は 18 が正）、[04](04_growth_and_skills.md)（レベル）、[07](07_npc_quest.md)（クエストの札・ログ）、[11](11_record_screen.md)

---

## 1. 方針

- チャットは「人の声」と「コマンドの結果」だけにする。世界の声・獲得・警告は、画面の決まった場所に、種類ごとの見せ方で出す（試遊で「レベルアップやいろんな文がチャットに流れて見づらい」と言われたため）。
- 同じ場所には一度に一つだけ映る（順番待ち）。混んだら一つあたりを縮め、あふれたら手がかりから捨てる。
- 見逃しても、N の「知らせの記録」で読み返せる。
- 文言（翻訳キー）は変えない。送り方だけを変えた。
- 見た目は案 A（暗い石板。クエスト・伝承の札と同じ作り）。ラフは `docs/review/notice_roughs/index.html`。参考: ゼルダ（下中央の語りの字幕、右上の獲得）、ドラクエ（獲得の窓）、FF（場所名のタイトル）、Elden Ring（場所名・撃破の大きな帯、獲得の札）。

## 2. 何をどこに出すか

`sendSystemMessage` / `displayClientMessage` / `ModText.*` の呼び出し（コマンド `*Commands.java` と開発用 `dev/` は対象外）を、次のように分けた。

| 種類（ModText） | 例 | 頻度 | 新しい見せ方 |
| --- | --- | --- | --- |
| lore（語り・囁き） | 背の囁き（BackWhispers）、伝承の書が落ちる、心臓が止まる、記憶の保証 | 場所ごとに一度、戦いの終わり | 下中央の字幕 |
| hint（手がかり） | 「J でステータス」、休み場の焚き火、錨石、報酬が保留中 | 初めの数回 | 同じ字幕（灰色。同じ文は 3 回まで） |
| hint（足もと） | 試練の手応え、渡りの案内、風見鶏の状態 | 行動のたび | アクションバー |
| progress（前進） | 封印が解けた、石が鳴った、欠片を得た、装備を得た、チェックポイント | 試練ごと | 右上の札（「進展」） |
| 戦果（rewardLine・memoryLine） | 受け取ったもの、巨神の記憶 ◆◆◇ | 巨神ごと | 右上の札（「獲得」） |
| レベル（growth.level_up、技の点、技を覚えた） | レベル N、振り分けの力、技の点が増えた | レベルごと | 画面中央の演出 + 既存の「Lv」文字と鈴の音 |
| battle（戦い） | 扉が閉ざされた、波が来る、巨神の怒り、伝説を手にした | 戦いの区切り | 上の帯（小さめ） |
| 場所の名前 | 背に着いた（TitanTravel など 5 か所のタイトル） | 到着ごと | 画面中央上のタイトル（大）+ 副題 |
| deny（拒否・失敗） | 必要レベル不足、扉が開かない、待ち時間 | 行動のたび | アクションバー（赤紫） |
| クエストの始まり・終わり | クエスト開始・完了 | 進行ごと | 既存のクエストの札があるので、チャットの重複を削除 |
| 墓（倒れたとき） | 墓が立った（字幕）、開けた・救われた（札）、他人の墓・一部だけ（アクションバー）。11 の 6.5 | 倒れるたび、墓を開けるたび | それぞれの種類の見せ方（チャットには出さない） |
| カウントダウン | あと N 秒で扉が閉じる | 毎秒 | アクションバー（もとからそう） |
| 章の題字・余韻 | 章が替わった（「一章　岩鯨」「空を泳ぐもの」）、章の終わり（見出し「一章　岩鯨　終」と一言） | 章ごとに各 1 回（人ごと） | 上の帯の列（場所の名前と同じ順番待ち。大きめ・長め）。9 章 |
| 世界の最初・パーティ | 誰が心臓を倒した（世界の最初。同じ巨神を止めた人にだけ。次の巨神の名前は出さない）、天の鍵がそろった（心臓を一つ以上止めた人にだけ）、パーティの招待（札に受け方つき）・参加・脱退・断り | まれ | 語り（世界の最初）、右上の札（招待・参加）、手がかり（ほか）。失敗はアクションバー |
| **チャットに残すもの** | `/titanmemory` の表示、記憶の選択肢（押せる名前）、コマンドの返事（`/party` の一覧など） | まれ | チャット（押せる・コマンド） |

呼び出し約 520 行のうち、プレイヤーへの通知として置き換えたのは 388 か所（63 ファイル）。タイトルパケット 5 か所は `Notice.place`、クエストの重複 2 か所は削除。

## 3. 種類と画面の配置

| 種類（`Notice.Kind`） | 場所 | 見せ方 | 長さ（標準） |
| --- | --- | --- | --- |
| NARRATE | 下中央（アクションバーの上） | 暗い帯の上に青緑の斜体。折り返し 4 行まで。細い線で挟む | 字数に応じて 2.6〜7.5 秒 + 出入り 0.45/0.65 秒 |
| HINT | 188 | 灰色。同じ文は 3 回まで | 2.2〜5.5 秒 |
| LEVEL_UP | 画面の上から 36% | 金の線で挟んだ一行（「Lv」の文字のすぐ下）。音つき | 2.6 秒 |
| GAIN / UNLOCK | 右上の札 | 暗い石板、金/青緑の縦の線、見出し「獲得」/「進展」。伝承・クエストの札と同じ列（重ならない）。幅 160、本文 3 行まで | 4.5 秒 |
| PLACE | 上から 16% | 金の見出し文字（HEADING、1.5 倍）+ 副題。線が左右へ伸びる | 3.4 秒 |
| ALERT | 上から 10% | 金の太字の一行（等倍）。PLACE と同じ順番待ち | 2.3 秒 |
| CHAPTER | 上から 16%（PLACE と同じ列） | 章の題字の札。「一章　岩鯨」を TITLE（2.2 倍）の金の文字、線が左右へ伸び、下に題字「空を泳ぐもの」を HEADING（1.5 倍） | 5.0 秒 |
| AFTERMATH | 上から 16%（同上） | 章の余韻の札。小さな金の見出し「一章　岩鯨　終」を線で挟み、その下に一言を HEADING（1.5 倍）で（3 行まで） | 4.5〜8 秒（字数に応じて） |
| WARN / BAR | アクションバー | 一行（警告は赤紫） | バニラの長さ |

目的を伝える一行（開幕の「目的: …」。`Notice.objective` / `ModText.objective`）は ALERT ではなく HINT の列に、目的の帯と同じ型（金の「◆」と明るい文字、太字にしない）で出す。「⚔」と金の太字は戦いの知らせだけ。

- 画面の「Lv」の文字（`GrowthHud`）は残し、その下に LEVEL_UP の一行が出る。F1 で隠れる。画面を閉じている間も進む。
- レベルアップの音と光（`Growth.celebrate` の鈴と光の粒）は残す。
- 札の音は既存の鈴（アメジストの鳴り）を流用。

## 4. 順番待ち（`NoticeQueue`）

- 字幕・中央・上の帯は種類ごとの列。いつも一つだけ映る。先に来たものから。
- 混むと一つあたりの長さが縮む（待ち 1 件ごとに 1/(1+0.35n)、下限 40%）。設定の速さで全体を伸縮（0.5〜2 倍）。
- 待ちは 6 件まで。あふれたら手がかり（HINT）から古い順に捨て、なければ一番古い待ちを捨てる。
- 同じ文が続けて来たら一度だけ。
- 札は `ToastComponent` の列（バニラの仕組み）に並ぶ。
- **関所（`NoticeGate`。`NoticeClient.gate`）**: 右上の札（クエスト・伝承・獲得・解放）、経験値とレベルアップの文字（`GrowthClient`）、中央の演出（LEVEL_UP）、手がかり（HINT）は、NPC との会話画面（`DialogueScreen`）か場面（`CinematicClient.active` / 開幕の目覚め）が開いている間は溜め、閉じたあとに優先の順（札 → 経験値・レベルアップ → 中央の演出 → 手がかり）で、一つずつ間隔をあけて出す（札は 0.7 秒、レベルアップのあとは 2.6 秒、中央は 1.5 秒、手がかりは 0.4 秒）。画面が開いておらず、前の一つから間隔がたっていれば遅れずに出る。溜めは 16 件まで（あふれたら手がかり、なければ古い順に捨てる）。会話の画面の上に札・経験値・レベルアップ・手がかりが積まれない（first_hour_log B-2・B-9）。知らせの記録（N）とチャットは溜めない。
- クエストの札は題を枠の幅で折り返して 2 行まで（2 行のとき札は 10 px 高くなる）。伝承の札は一行で、長い題は「…」で切る。

- 画面の中央まわりは一つの寸法で積む（`NoticeClient`）。上から、上の帯（PLACE・ALERT。ボスバーがあればその下へ）→ レベルアップの文字（`GrowthHud`。帯・ボスバーの下へずれる）→ 中央の演出（LEVEL_UP の知らせ。レベルアップの文字の下）→ 字幕（下中央。中央の下端より上へは伸びず、狭い画面では行を減らす）。場所の名前の最中にレベルが上がっても重ならない。ボスバーの下端は `CustomizeGuiOverlayEvent.BossEventProgress` で知る。

## 5. API（`jp.revati.skyabyss.notice.Notice`）

- サーバー側: `Notice.narrate / hint / levelUp / gain / unlock / alert / warn / place / bar / send`、章の札は `Notice.chapter(player, 見出し, 題字)` と `Notice.aftermath(player, 見出し, 一言)`（直接は呼ばず、9 章の `ChapterCards` を使う）。引数は `(player, 文の鍵, 引数...)` か、`ModText` の文。
- `ModText.lore/hint/progress/deny/battle` が返す文には種類の印が付く（空の部品の insertion）。`Notice.send(player, 文)` は印から種類を決め、印がなければチャット。コマンドの返事やツールチップに `ModText` をそのまま使っても見た目は変わらない。
- `Notice.send(player, kind, 文)` で種類を決めて送る。`Notice.bar` はアクションバー。クライアントだけの呼び出し（本人の画面）は、プレイヤーがサーバー側でなければバニラの表示に落ちる。
- パケットは `NoticePayload`（版 notice-1、`NoticeNetwork`）。クライアントは `client/notice/`（`NoticeClient`、`NoticeToast`、`NoticeLog`、`NoticeLogScreen`）。
- 開発用（OP）: `/skyabyss dev notice <narrate|hint|levelup|gain|unlock|alert|warn|bar> <文の鍵>`、`… place <題の鍵> <副題の鍵>`（`NoticeDev`）。章の札は `/skyabyss dev arc <card|aftermath> <章の ID>`、記録の確認・消去は `/skyabyss dev arc <status|reset>`（`ArcSetup`）。台本から `cmd` で使う。
- `NoticeQueue` は `CHAPTER`・`AFTERMATH` を上の帯の列に積む。`Notice.Kind` の追加はパケットが順番の番号で送るので必ず末尾に。

## 6. 設定（クライアント）

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| `notifyMode` | `TOAST` | TOAST = 画面の演出だけ、CHAT = 今までどおりチャットだけ、BOTH = 両方 |
| `noticeSpeed` | 1.0 | 字幕・中央・帯の出ている長さの倍率（0.5〜2） |
| `bossAttackNames` | `SMALL` | ボスの技の名前。`SMALL` = ボスバーのすぐ下に小さな一行（印 8px。1 秒あまりで消える）、`FULL` = 従来の大きな印と名前と残りの帯、`OFF` = 出さない（床の予告だけ） |
| `objectiveStrip` | true | 左上のメインの目的の帯 |
| `chapterLabel` | true | 左上の目的の帯の上の、今の章の札（8.4） |
| `questSound` | true | クエストが始まった・進んだ・終わったときの小さな音（メインとサブで音が違う。8.4） |
| `npcMarkers` | true | NPC の頭の上の印（話すことがあるとき。その人にだけ見える。07 の 8.5） |
| `partyMarkers` | true | 仲間の札・矢印 |
| `graveMarker` | true | 自分の墓の標（札・矢印と距離） |
| `questArrow` | true | 目的の帯の方角を、向きに合わせて回る矢印にする（false = 北東などの文字）。8.3 |
| `questTrail` | `ON` | 地面の道しるべ。`ON` = いつも、`NEAR` = 目的まで 64 ブロック以内のときだけ、`OFF` = 出さない。キー ;（セミコロン。既定。「道しるべ」）で ON/OFF をすばやく切り替え（設定に保存） |

### 6.1 ボスの技の名前（`BossAttackCue`）

- 心臓・中ボス共通の部品（`client/titan/BossAttackCue`）。サーバーが技の始まりに送る名前と印（`show(印, 名前, 予告の長さ)`）を、設定 `bossAttackNames` に従って出す。今、技の名前を送っているのは雷翼の心臓（`StormHeartNetwork.Warn`）だけ。ほかの心臓・中ボスで名前を出すときも、この口に渡す。
- SMALL（既定）: ボスバーの直下（`NoticeClient.lastBossBottom`）に中央揃えで一行。小さな印（8px）+ 名前、薄い暗い帯の上。予告の長さ（14〜40 tick）+ 10 tick で消え、出入りは淡く。続けて技が来たら下へ最大 3 行まで積み（古いほうから消える）、同じ名前は一行にまとめて延ばす。画面の中央・足もとには届かないので、床の予告をふさがない。
- FULL: 従来の大きな表示（上から 62px、印 24px、残りの帯）を一つだけ。
- OFF: 出さない。F1 で隠れる。

## 7. 知らせの記録（N）

流れた語り・獲得・場所の名前を、時刻つきで新しい順に 200 件まで（この遊びの間）。クエストログと同じ暗い石板の窓。ホイールで送る。台本では `open notices`。実装: `NoticeLog`、`NoticeLogScreen`。

## 8. 目的の帯（`ObjectiveStrip`）

- 左上（クエストの小さな表示の位置）に、メインの目的を細い一行で出す。目的が変わると一度だけ光る。傷を受けた直後と画面を開いている間、ホラー演出（足音・歌・影）の最中は薄くする。
- 追跡中のクエストがメインのときは、この帯が代わりに出す（サブのクエストの表示は帯の下へ下がる）。全文は U のクエストログ。
- 距離（10 ブロック単位）と八方位は、目的ごとの位置につく。位置は序盤の構造物（野営地・宿り・骨の丘・岩鯨）をサーバーが人ごとに送る（`OpeningDirector.target`。17）。
- 場面（シネマティック）の間は HUD ごと隠れる（`hideGui`）ので、知らせは出ない。台詞は場面の画面が自分で描く（[20](20_cinematics.md)）。
- 開幕の暗転と題字（`OpeningOverlay`）は 17 の 4.4。表示の部品は `Notice.place`（題字）と `NoticeClient` の帯を使う。
- `sky/`・`lore/`・titan の出現条件は、文を出す呼び出しの置き換えだけにした（条件は触っていない）。

### 8.1 仲間の位置の置き場（`party/client/PartyMarkers`）

頭の上の札は世界に重なる HUD。画面の外の矢印は、左上の目的の帯（上から 46 まで）・右の仲間の一覧（幅 84 と余白）・下のホットバー（下から 56）を避けた長方形の縁にだけ置く。札・矢印の名前は重なったらずらす。別の次元の仲間は右の仲間の一覧の行に一行足す。場面（シネマティック）の最中は出さない。設定は `partyMarkers`。

頭の上の札の記号: 仲間は体力の記号（無事 = 塗りつぶし・傷 = 枠と下半分・瀕死 = 感嘆符）と札の下の体力の棒、墓の標は十字。色だけで区別しない。同じ描き方（`PartyMarkers.drawMarker`）を墓の標（`client/grave/GraveMarkerHud`）が使う。

**扉の予告の準備確認**（A2。11 の 9.2 の 4）は BAR に「扉が閉まるまで N 秒　備え　身● 刃■ 糧▲」を 1 秒ごと（赤の本人にだけ、最初に一度、HINT の字幕で「理由 + 手段」の一行。赤でない人には BAR の末尾に「仲間の誰かの備えが低い」）。**乗り込みの一度目の確認**は、三灯の一行に続けて一番低い赤の灯の「理由 + 手段」の一行（HINT、A7）。出発の待ちの帯（ボスバー。09 の 4.2.1）は、近くの全員が乗ったら緑の「全員乗った。N 秒で出発」（A6）。

**石の「誰が鳴らしたか」**（すでに鳴っている石に触ったとき）は画面の下（BAR）に「石: あなたが鳴らした／○○ が鳴らした（あなたは踏破として数える）」。

### 8.2 倒れた仲間・「ここ」の印・倒れた回数の札（10 の 10.12〜10.14）

どれも新しい画面は足さず、既存の置き場に載せる。
- **倒れた仲間の札・「ここ」の印**は、仲間の位置の札と同じ描き方（`PartyMarkers.drawMarker`。8.1 の置き場・重なったらずらす）。形で区別する: 倒れた仲間 = ×、「ここ」 = 菱形、敵の印 = 下向きの三角（仲間の体力の記号 = 塗り・枠・感嘆符、墓 = 十字と並ぶ）。場面の最中・画面を開いている間・F1・デバッグ画面では出さない。設定 `partyMarkers` で札と印の描画を消せる。
- **自分が倒れている間**: 画面の縁の薄い赤み、中央下（高さの 5/8）に「倒れている」・残りの棒・「仲間が起こしに来るまで あと N 秒」。起こされている間は緑の進みの棒。BAR に「倒れた… 仲間が起こしてくれるのを待とう（15 秒）」を一度。
- **仲間が倒れた**: ALERT の帯「〇〇 が倒れた。使うを長押しで起こせる」（一度）。起こしたとき、起こされた人の BAR「〇〇 に起こされた」と、起こした人の BAR「〇〇 を起こした」。
- **起こす操作**: 倒れた仲間を見ている間は、照準の周りに輪（進み）と「〇〇 を起こす: 使うを長押し」「〇〇 を起こしている…」。
- **勝ったときの札**: 札を得たら TOAST（GAIN）「札「無傷の誓い」　この戦いで倒れた回数 0」、最良を更新したら HINT「控え帳の最良を更新した」、札なしは HINT「この戦いで倒れた回数 N」。
- **「ここ」を一人で押した**: HINT「「ここ」の印は、仲間のいるときだけ使える」。

### 8.3 目的の道しるべ（矢印と地面の道。`guide/nav/`・`client/guide/`）

「クエストの行く場所がわからない」への答え。帯の方角を矢印にし、地面にも道を引く。どちらも人ごと（パーティでも各自の目的）。

- **行き先**（`ObjectiveStrip.resolve`）: 序盤の目的の目印 → メインのクエストの今の段（`SiteTargets` の「クエスト/段」→「クエスト」→ 済んでいない最初の「話す」目的の相手）。追跡中のメインでないクエストも同じ求め方（`resolveTracked`。札の右上に矢印を出す。`QuestHud`）。話す相手の居場所は `SiteNetwork` が `npc.storyteller`（宿りの鐘）・`npc.whale_chaser`（外れの焚き火）で送る。旅の職人は `npc.artisan`（`ArtisanSpawner` の立つ所の印の場所。一章は失せ物の荷車のそば）。背中・ほかの次元の中では、位置のある目的に「背中の中」の文（`gui.skyabyss.guide.inside`）を出し、矢印・道は出さない。
- **矢印**（`GuideArrow`、9×9 のドット絵、金色に暗い縁取り）: カメラの向き（yaw）に対して、真上 = いま向いている方向、右 = 右手。角度は `NavMath.arrowDegrees`。距離の札（10 ブロック単位）の左に置く。目印が 12 ブロック超上・下にあるときは小さな三角（上・下）を矢印の左に足す。5 ブロック未満では札ごと消える。`questArrow` が false なら従来の方位の文字。
- **地面の道**: クライアントが 10 tick ごとに行き先を見て、変わったとき（と 5 秒ごと）`GuideTarget` をサーバーへ送る（`questTrail` が OFF、または NEAR で 64 ブロックより遠いときは「不要」を送る）。サーバー（`GuideNetwork`、`GuideScheduler`）が `PathFinder`（A*）で歩ける道を探し、**その人だけ**に `GuideTrail`（先頭の座標 + 次の点ごとに 1 バイト）を返す。
  - 探索: 立てる場所（足・頭が空き、足もとが固い。水の中は泳ぐ）の格子を八方向。段差は +1 まで上がり、3 までは降りる。溶岩・火・サボテン・マグマなどは通らない。水は 1 マスあたり +3〜5 の費用で、迂回が長ければ通る。読み込まれたチャンクだけ（読み込みは起こさない）。出発点から半径 96、道は最大 192 点。目印まで着けなければ、いちばん近づけた所までの道（6 ブロック以上近づけなければ「道なし」）。目印が空にあるとき（巨神）はその真下へ。
  - 予算: 1 tick に全員で合計 800 ノード（`BUDGET_PER_TICK`）、1 人 1 tick 400、1 回の探索は 6000 ノードまで。何 tick かに分けて、人ごとに持ち回り。やり直す条件: 目印が変わった／前の出発点から 8 ブロック動いた／5 秒たって 2 ブロック以上動いた／道なしのときは 10 秒ごと。同じ結果は送らない。クライアントの知らせが 30 秒途絶えたら捨てる。同じ人からは 10 tick に 1 回まで。目印の水平 3 ブロック以内に着いたら空の道。
  - 描画（`GuideTrailRenderer`）: 道の点に沿って、柔らかい金色のひし形の足あと（左右にずらして 1.5 ブロックおき）と、5 つめごとに前を指す山形。プレイヤーに近い点から約 40 ブロック先まで、手前ほど濃く遠いほど薄れ、目的の方へ光が流れる。床の高さは道の点の高さ（段差は中間で切り替え）、暗い縁取りつき、`AFTER_TRANSLUCENT_BLOCKS` で深度は見て書かない。形（ひし形・山形・破線）で読めるので色に頼らない。技の予告（橙・赤・青白）とは色も形も別。
  - 道が無い・古い（25 秒）・目印と合わない間は、足もとの地面に沿った**破線**を目印の向きへ 16 ブロック。矢印はそのまま。
  - 描かない場面: 場面（シネマティック）・開幕の目覚め・画面を開いている間・F1・オーバーワールド以外・目印が 3.5 ブロック以内（近づくと薄れる）・設定 OFF。
- 自己テスト `SELFTEST guide nav`（`guide/nav/GuideNavSelfTest`）: 矢印の角度（八方・yaw の巻き戻り・範囲）、探索（平ら・段差 1・壁 2・穴・落差 3/4・全面の壁・池を避ける/湖を渡る・溶岩・読み込み外・遠い目印・空の目印・出発点が空中・上限）、予算（1 tick の上限・何 tick かに分散・持ち主にだけ届く・動かなければ送り直さない・8 ブロックで再計算・目印の変更・止めたら送らない・途絶えで捨てる）、パケットの往復と大きさ。

## 9. 章の題字と余韻（`story/arc/ChapterCards`）

章（`Chapters`。01 の 4）が替わったことと終わりを、上の帯の列に大きな札で出す。チャットには流さない。ほかの上の帯（場所の名前・戦いの知らせ）と同じ順番待ちに並ぶので重ならない。レベルアップの文字・中央の演出・字幕は、札の下端（`bannerBottom`）より下へずれる。知らせの記録（N）には「題 + 副題」「見出し + 一言」の一行で残る。絵は `docs/review/previews/chapter_card_with_levelup_and_caption.png`（題字の札・レベルアップ・字幕が同時）、`chapter_aftermath_whale.png`（余韻の札）。

**題字の札（自動）**
- 人の章（`Chapters.of`）が、まだ札を出していない章になったとき、見てから 5 秒（`TITLE_DELAY` = 100 tick）空けて一度だけ出す。5 秒空けるのは、前の章の余韻の札などを先に出すため。見出し = `Chapters.label()`（「一章　岩鯨」）、副題 = `Chapters.titleKey()`（「空を泳ぐもの」）。
- 場面（シネマティック）の最中・死んでいる間・観戦中は出さず、終わってから出す（20 の場面と重ならない）。札は使い切りにならない。
- 出さずに「出した」ことにする: 序章（開幕の題字は `OpeningOverlay`）、五章以降（中身がない）、すでに遊んでいた人（`OpeningState.legacy`）。すでに先の章にいる人は、今の章の札だけで、前の章の札は出さない。
- 「出した」の記録は人ごと（`ArcData`、プレイヤーのデータ。死んでも引き継ぐ）。再ログイン・再起動でも二度出ない。

**余韻の札（各章の担当が呼ぶ）**
- `ChapterCards.aftermath(player, Chapters.WHALE, 一言の Component)`。一言を省くと翻訳キー `chapter.skyabyss.aftermath.<章の ID>` を使う（その章の担当が自分の lang に足す）。見出しは `chapter.skyabyss.aftermath.head`（「%s　終」）。
- 人ごとに章ごと一度（記録は `ArcData`）。場面の間は預かり、終わってから出す（ログアウトで預かりは消える。記録していないので、もう一度呼んでよい）。受け付けたら true、すでに出した・預かっているなら false。
- 語り部の一言は、札のあとに `Notice.narrate` を続ける（字幕は別の列）。
- 心臓を止めた章の余韻は、巨神に地上へ降ろされたあと（初めての人は、地上から眠りを見る場面 20 の 3.4 のあと）に出る。背中にいる間は、各章の余韻が見る条件（地上にいる）を満たさないので出ず、場面の間は `ChapterCards` が預かる。四章は、さらに天の鍵が一つになる場面（`SkyKey`）のあと。

**章の予兆の枠・空の段** は 01 の 4.1 の「予兆 3 拍」「空の異変の段」。コードは `story/arc/Foreshadow`（使い方は頭のコメント。01 の 4.1 に API の要約）と `sky/ChapterSky.Stage`。

## 12. 文字の決まり（`client/ui/TextStyle`）

- この mod は字を絵にせず、いつもバニラのフォントを `Component`（lang の鍵）で描く。カスタムフォントも使わない（試遊で「凝るなら全体でフォントをそろえる、そうでなければバニラでいい」と言われ、バニラにそろえた）。題字の絵（旧 `textures/gui/opening/`）と生成スクリプトは廃止。
- 大きさと色は `TextStyle` に一か所で決める。大きい字はポーズの拡大で描き、光は同じ字を色つきで少しずつずらして重ねる（`drawGlowCentered`）。

| 種類 | 倍率 | 使う場所 |
| --- | --- | --- |
| TITLE | 2.2 | 開幕の題字（画面の高さで更に拡大）、章の題字、スカイキーの終わりの題 |
| HEADING | 1.5 | 場所の名前、章の題字の副題、章の余韻の一言、レベルアップの数字、成長画面のレベル、開幕の副題 |
| BODY | 1.0 | 本文・字幕・札・開幕の一行 |
| CAPTION | 1.0（灰色） | 注記・手がかり・案内 |

- ボスバー・控え帳・伝承の書・技の画面・成長の画面の字は、もとからバニラのフォントで `Component` として描いている（画像に焼いた字はない）。

## 13. 初回の手引き（`tutorial/TutorialHints`）

試遊の「伝承の書を手に入れたとき、どうすればいいかわからなかった」に応える仕組み。ある品を持った・ある出来事が起きたとき、**その操作を一度するまで**、画面の隅に実際のキー名つきの案内を出し続ける。チャットには流さない。

- **登録（`TutorialHints.ALL`）**: ID、始まる品（持ち物か旅嚢にあれば始まる。なければ出来事で `start`）。済みは操作の場所が `done` を呼ぶ。並びが画面の優先（同時に出るのは 2 行まで）。
- **記録**: 人ごと（`TutorialData`、Data Attachment `skyabyss:tutorial`。出ている ID と済んだ ID。死んでも・再ログインしても残る）。済んだ手引きは二度と出ない。操作を先に済ませた人には、あとから品を得ても出ない。
- **送り**: サーバーは「今出ている ID」と「いま済んだ ID」だけを送る（`TutorialHints.Sync`、版 tutorial-1。変わったときと、ログイン・復活・次元移動のときだけ）。持ち物の見回りは 20 tick ごと（人ごとにずらす）。
- **文面とキー名**: クライアントが作る（`client/tutorial/TutorialClient`）。キー名は今のキー設定から `KeyMapping.getTranslatedKeyMessage()`、lang は `assets/skyabyss_tutorial/lang`（`tutorial.skyabyss.<ID>` に `%s` でキー名）。使う品は持ち方で 3 通り: 持ち物にある = 「右クリックで…」（`.hand`）、旅嚢にあって使える道具が一つだけ・前回の道具・まだ何も使っていない先頭 = 「[Y] を短く押して…」（`.short`）、それ以外 = 「[Y] 長押しで旅嚢の輪 → … を選んで離す」（`.wheel`）。
- **表示**: ホットバーの上、字幕（下から 84）のすぐ下。暗い帯に金の「◆」と白い字、ゆっくり呼吸するように濃さが揺れる。済むと緑の「✔ できた」を 1.8 秒出して消える。会話（`DialogueScreen`）・場面（シネマティック・開幕の目覚め）・画面を開いている間・F1・デバッグ画面では出さず（`NoticeClient.busy`、`NoticeGate` と同じ関所）、閉じたあとにまた出る（出し続ける札なので溜めはしない。「できた」の時計も止まる）。

| ID | 始まり | 済み |
| --- | --- | --- |
| `pouch` | 旅嚢に何か入った | 旅嚢の画面を開いた（I）。「[I] で旅嚢を開く」 |
| `lore_book` | 伝承の書を持った（開幕で渡される） | 書を開いた（右クリック・旅嚢の輪・短押し。`LoreBookItem`） |
| `lore_page` | 破れた頁を持った | 頁を読んだ（`LorePageItem`） |
| `whistle` | 呼び笛・呼び貝を持った | 吹いた（`TitanCallItem`。「呼ぶ」） |
| `record` | 初めての墓ができた、または石碑の「誰が鳴らしたか」を見た | 控え帳（B）を自分で開いた（`RecordService.open`） |
| `ping` | パーティに入った | 「ここ」の印（X）を押した（`Ping.request`） |

- 新しい手引きは `ALL` に足し、始まりの場所で `start`（品なら述語）、済みの場所で `done`、lang に鍵（品なら `.hand/.short/.wheel`、そうでなければ鍵一つ）を足す。`TutorialClient.text` に ID の分岐を足す。
- 自己テスト `SELFTEST tutorial`（`tutorial/TutorialSelfTest`。品で始まる・済むまで出続ける・人ごと・済んだら二度と出ない・先に済ませた人には出ない・出来事で始まる・保存の往復・優先の並び・日英の鍵）。
