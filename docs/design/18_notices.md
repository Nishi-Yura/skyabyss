# 18 画面の知らせ (チャットをやめて、RPG の見せ方へ)

試遊の感想:「レベルアップやいろんな文がチャットに流れてきて、とても見づらかった。もっと RPG 感を大事にしたい」。
17 の 5.1〜5.3 (通知の仕分け・レベルアップ・目的の帯) の担当 1 (画面) の実装書。00 は編集しない。

## 1. 方針

- チャットは「人の声」と「コマンドの結果」だけにする。世界の声・獲得・警告は、画面の決まった場所に、種類ごとの見せ方で出す。
- 同じ場所には一度に一つだけ映る (順番待ち)。混んだら一つあたりを縮め、あふれたら手がかりから捨てる。
- 見逃しても、N の「知らせの記録」で読み返せる (チャットを消す条件)。
- 文言 (翻訳キー) は変えない。送り方だけを変えた。
- 参考にした作り: ゼルダ (下中央の語りの字幕、右上の獲得)、ドラクエ (獲得の窓)、FF (場所名のタイトル)、Elden Ring (場所名・撃破の大きな帯、獲得の札)。見た目は 3 案のラフから選んだ (`docs/review/notice_roughs/index.html`、推奨は案 A = 暗い石板。クエスト・伝承の札と同じ作り)。

## 2. 洗い出し (チャットに出していた文)

`sendSystemMessage` / `displayClientMessage` / `ModText.*` の呼び出し。コマンド (`*Commands.java`) と開発用 (`dev/`) は対象外。

| 種類 (ModText) | 例 | 頻度 | 重要度 | 新しい見せ方 |
| --- | --- | --- | --- | --- |
| lore (語り・囁き) | 背の囁き (BackWhispers)、伝承の書が落ちる、心臓が止まる、記憶の保証 | 場所ごとに一度、戦いの終わり | 中 (読み返したい) | 下中央の字幕 |
| hint (手がかり) | 「J でステータス」、休み場の焚き火、錨石、報酬が保留中 | 初めの数回 | 低 | 同じ字幕 (灰色。同じ文は 3 回まで) |
| hint (足もと) | 試練の手応え、渡りの案内、風見鶏の状態 | 行動のたび | 低 | アクションバー |
| progress (前進) | 封印が解けた、石が鳴った、欠片を得た、装備を得た、チェックポイント | 試練ごと | 高 | 右上の札 (「進展」) |
| 戦果 (rewardLine・memoryLine) | 受け取ったもの、巨神の記憶 ◆◆◇ | 巨神ごと | 高 | 右上の札 (「獲得」) |
| レベル (growth.level_up、技の点、技を覚えた) | レベル N、振り分けの力、技の点が増えた | レベルごと | 高 | 画面中央の演出 + 既存の「Lv」文字と鈴の音 |
| battle (戦い) | 扉が閉ざされた、波が来る、巨神の怒り、伝説を手にした | 戦いの区切り | 高 | 上の帯 (小さめ) |
| 場所の名前 | 背に着いた (TitanTravel など 5 か所のタイトル) | 到着ごと | 高 | 画面中央上のタイトル (大) + 副題 |
| deny (拒否・失敗) | 必要レベル不足、扉が開かない、待ち時間 | 行動のたび | 中 | アクションバー (赤紫) |
| クエストの始まり・終わり | クエスト開始・完了 | 進行ごと | 高 | 既存のクエストの札があるので、チャットの重複を削除 |
| カウントダウン | あと N 秒で扉が閉じる | 毎秒 | 中 | アクションバー (もとからそう) |
| 残すもの | 誰が心臓を倒した (世界の最初)、パーティの招待・参加・脱退、`/titanmemory` の表示、記憶の選択肢 (押せる名前) | まれ | — | チャット (他の人に伝える・押せる・コマンド) |

数: 呼び出し 約 520 行のうち、プレイヤーへの通知として置き換えたのは 388 か所 (63 ファイル)、タイトルパケット 5 か所は `Notice.place`、クエストの重複 2 か所は削除。残したのは、コマンドの返事・パーティ・世界の最初の撃破・押せる記憶の選択肢と `/titanmemory` 表示。

## 3. 種類と画面の配置

| 種類 (`Notice.Kind`) | 場所 | 見せ方 | 長さ (標準) |
| --- | --- | --- | --- |
| NARRATE | 下中央 (アクションバーの上) | 暗い帯の上に青緑の斜体。折り返し 4 行まで。細い線で挟む | 字数に応じて 2.6〜7.5 秒 + 出入り 0.45/0.65 秒 |
| HINT | 同上 | 灰色。同じ文は 3 回まで | 2.2〜5.5 秒 |
| LEVEL_UP | 画面の上から 36% | 金の線で挟んだ一行 (「Lv」の文字のすぐ下)。音つき | 2.6 秒 |
| GAIN / UNLOCK | 右上の札 | 暗い石板、金/青緑の縦の線、見出し「獲得」/「進展」。伝承・クエストの札と同じ列 (重ならない)。幅 160、本文 3 行まで | 4.5 秒 |
| PLACE | 上から 16% | 大きな金の文字 (1.8 倍) + 副題。線が左右へ伸びる | 3.4 秒 |
| ALERT | 上から 10% | 金の太字の一行 (等倍)。PLACE と同じ順番待ち | 2.3 秒 |
| WARN / BAR | アクションバー | 一行 (警告は赤紫) | バニラの長さ |

画面の「Lv」の文字 (GrowthHud) は残し、その下に LEVEL_UP の一行が出る。F1 で隠れる。画面を閉じている間も進む。

## 4. 順番待ち (`NoticeQueue`)

- 字幕・中央・上の帯は種類ごとの列。いつも一つだけ映る。先に来たものから。
- 混むと一つあたりの長さが縮む (待ち 1 件ごとに 1/(1+0.35n)、下限 40%)。設定の速さで全体を伸縮 (0.5〜2 倍)。
- 待ちは 6 件まで。あふれたら手がかり (HINT) から古い順に捨て、なければ一番古い待ちを捨てる。
- 同じ文が続けて来たら一度だけ。
- 札は `ToastComponent` の列 (バニラの仕組み) に並ぶ。

## 5. API (`jp.revati.skyabyss.notice.Notice`)

サーバー側 (`Notice.narrate / hint / levelUp / gain / unlock / alert / warn / place / bar / send`)。引数は `(player, 文の鍵, 引数...)` か、`ModText` の文。

- `ModText.lore/hint/progress/deny/battle` が返す文には種類の印が付く (空の部品の insertion)。`Notice.send(player, 文)` は印から種類を決め、印がなければチャット。コマンドの返事やツールチップに `ModText` をそのまま使っても見た目は変わらない。
- `Notice.send(player, kind, 文)` で種類を決めて送る。`Notice.bar` はアクションバー。クライアントだけの呼び出し (本人の画面) は、プレイヤーがサーバー側でなければバニラの表示に落ちる。
- パケットは `NoticePayload` (版 notice-1)。
- 開発用: `/skyabyss dev notice <narrate|hint|levelup|gain|unlock|alert|warn|bar> <文の鍵>`、`… place <題の鍵> <副題の鍵>`。台本から `cmd` で使う。

## 6. 設定 (クライアント)

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| `notifyMode` | `TOAST` | TOAST = 画面の演出だけ、CHAT = 今までどおりチャットだけ、BOTH = 両方 (17 の判断 9) |
| `noticeSpeed` | 1.0 | 字幕・中央・帯の出ている長さの倍率 (0.5〜2) |
| `objectiveStrip` | true | 左上のメインの目的の帯 |

## 7. 知らせの記録 (N)

流れた語り・獲得・場所の名前を、時刻つきで新しい順に 200 件まで (この遊びの間)。クエストログと同じ暗い石板の窓。ホイールで送る。台本では `open notices`。

## 8. 目的の帯 (`ObjectiveStrip`、17 の 5.3)

左上 (クエストの小さな表示の位置) に、メインの目的を細い一行で出す。目的が変わると一度だけ光る。傷を受けた直後と画面を開いている間は薄くする。追跡中のクエストがメインのときは、この帯が代わりに出す (サブのクエストの表示は帯の下へ下がる)。
距離 (10 ブロック単位) と八方位は、`ObjectiveStrip.targets` (クエストの id → 位置) に登録された目的に付く。位置の登録は、野営地・宿り・骨の丘・岩鯨を作る担当 (17 の担当 2・3) が行う。

## 9. 担当 3・4 との境界・未決

- 開幕の暗転と題字 (B0、`OpeningOverlay`): 表示の部品は `Notice.place` (題字) と `NoticeClient` の帯で足りる。暗転だけは担当 3 が作る。
- `sky/`・`lore/`・titan の出現条件は、文を出す呼び出しの置き換えだけにした (条件は触っていない)。
- 判断: 字幕・帯を案 B (枠なし) に寄せるか (推奨は A のまま)。音: 札の音は既存の鈴 (アメジストの鳴り) を流用、帯の専用音は未作成。
- 記録の窓はこの遊びの間だけ。ワールドをまたいで残すかは未決。
