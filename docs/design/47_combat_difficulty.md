# 47 戦いの手ごたえ（ソウル型 + 主ごとの仕掛け）

2026-10-28 の試遊の声:「巨神の心臓ボスめっちゃ弱い？ FF、ダークソウル位むずくしてもいいのでは。正直眠い」「巨神のボス以外にも、全部の戦いに共通するんだけど、ごり押しでは絶対に倒せないようにしてほしい」。
決めたこと（ユーザーの答え）: **ソウル型 + 主ごとの仕掛け**。主と名のある敵は殴られても下がらない。

この書類は、すべての戦い（心臓の主・中ボス・名のある敵・ふつうの敵）に共通する決まりを書く。主ごとの技と仕掛けは、それぞれの巨神の書類（02・08・12・13）と 36（深淵）にある。

## 1. ねらい

- 立ったまま殴り合うと負ける。**技を見て避け、隙に打ち込む**と勝てる。
- 主の一撃は重い（想定の装備で 2〜3 回で危ない）。避けそこねを回復で帳消しにはできない。
- 主には、それぞれ一つ「解かないと倒せない仕掛け」がある（今の「領域」= 心臓が守られる間。解くと崩しゲージが半分溜まる）。
- 戦いの長さは今の帯（一人 3〜5 分）のまま。強さは長さではなく、間違いの重さで出す。

## 2. 主（心臓の主・中ボス・名のある敵・体力の大きい敵）

主の見分けは `combat/BossFooting.planted`（名のある敵の印・ボスの帯を持つ型・体力が `ShieldRules.BIG_HEALTH` 以上）。

### 2.1 崩しゲージ（`combat/BreakGauge`・`combat/BossOpenings`）

2026-11-04 に、構え ×0.3 と隙 ×1.6（ならすと ×0.95 で倍率が見えない）を崩しゲージに置き換えた。

| 項目 | 決まり |
| --- | --- |
| ふだんの傷 | 人から受ける傷 ×0.8 |
| 溜まり方 | 満ちた近接の一撃（溜め 0.9 超え）は与えた傷のぶん溜まる。満ちていない近接の一撃は溜まらない |
| 技（スキル）・矢・魔法 | 溜まり ×0.7 |
| 技のあとの隙（3 秒） | 主の技（予告 `Telegraph` を出した技）が当たり終わった瞬間から 3 秒。その間の溜まり ×3（避けてから叩くのがいちばん早い）。白い火花と澄んだ音 |
| 背中 | 主の体の向きから後ろ 120 度（左右 60 度）で打つと溜まり ×1.5 |
| 仕掛けを解く | 心臓の領域が解けた瞬間、ゲージの半分が一度に溜まり、6 秒の大きな隙（`BreakGauge.solved`） |
| 減り | 4 秒当てないと、1 秒にゲージの 8% ずつ減る |
| ゲージの大きさ | 主の最大体力 × 0.22（人数で体力の増える主はゲージも同じに増える）。崩れるたびに次は 1.25 倍、三回目から 1.5 倍 |
| 崩れ | 満ちると 5 秒崩れる。崩れの間は主の tick を止めるので、主が持つボスバー（`ServerBossEvent` の欄）の長さは `BreakGauge.refreshBars` が 2 tick ごとに体力に合わせる（前は崩れの終わりまでバーが減らなかった）。その間、受ける傷 ×2.0。技を止める: 出ている予告を消し、新しい予告を出さず（`Telegraph.start` が `BreakGauge.silenced` を見る）、主の直の傷・放った矢も人に届かず、歩かない（頭の上に星の粒）。崩れの間はゲージが溜まらない |
| 見せ方 | ボスバーの下の帯（太さ 3。`client/combat/BreakGaugeClient`）。描き換えたバー（`PhasedBossBar.drawHp` が下の端を `BOTTOM` に残す）ではその下の端のすぐ下に描き、帯の分だけ次のバーを下げて重ねない（2026-11-08 の声「スタンゲージがボスバーに重なってとても見にくい」）。琥珀色で溜まり、85% を超えると金に脈打つ。崩れると割れる音（ガラスと金床）と白い光の粒、帯が白く光ってから白金の帯が崩れの残りで縮む。帯はバーの名前と同じ名の体（名が合わなければ残りの体力とバーの長さが合う体）の下に描く |
| 教え | 主のゲージを初めて溜めた人に手がかり「満ちた一撃で主の崩しの帯が溜まる。満ちると主が崩れる」（一人に一度。人の永続データ `skyabyss_break_tip`、倒れても残る） |

- 環境の傷（落下・溶岩・仕掛けの傷）は倍率も溜まりもない。巨神の心臓・中ボス・名のある敵、どれも同じ決まり。
- 主を倒すまでの時間の目安（一人）: 岩鯨の心臓 150〜180 秒（崩れ 2〜3）・潮殻 170〜200 秒（3）・雷翼 190〜220 秒（3〜4）・余燼 210〜240 秒（4）・中ボス 60〜90 秒（1〜2）・名のある敵 30〜45 秒（1）・月の主 200〜240 秒（3〜4）・雲海の主と巡礼者 6〜7 分（形態ごとに 2）・あいだに座すもの 四人で 12〜15 分（6〜8）。

### 2.0 固さは体力だけ（`combat/Hardness`。2026-11-09）

2026-11-09 の声「多分、hp 増やすんじゃなくて、耐えを増やしているので、強く感じない。耐えはこのゲームから消していい。hp 増やすのだけで敵を固くする」。

- 最大体力の上限（バニラの 1024）を 1,000 万に上げた（`mixin/MaxHealthCapMixin`）。主を固くする倍率は、人から受ける傷を割る形をやめ、すべて最大体力に掛ける。
- 倍率は名前つきで主の永続データに持つ（`Hardness.set(主, 名, 倍率)`）: `party`（人数。`PartyScale.apply`）・`resist`（主の硬さ。`PartyScale.resist`）・`type`（中ボスの型ごと。湧いたとき）・`level`（入る人のレベル。`LevelScale.apply`）・`own`（心臓の硬さ × 一人の上乗せ 1.25。番人の TOUGH と段。鍛冶の人数）・`abyss`（深淵の心臓 ×1.2）・`armor`（防具の分。下）。最大体力 = 元の体力 × 倍率の積。割合は保つ。主が自分で体力を作り直したら（段・形態）、その値を新しい元にする。
- 防具（鎧の値・鎧の強さ）で傷を減らすのもやめた。mod の敵は湧いたとき防具を 0 にし、ふつうの一撃（12）で減っていた分を体力に掛ける（`MobTuning.armorToHealth`）。
- 攻撃（`MobTuning`）: 雑魚は体力 1.1 倍・攻撃 1.2 倍（前は 0.8・0.9）。主（ボスの帯・大物）は攻撃 1.3 倍、入る人のレベルで固くした主はさらに体力の倍率の 0.6 乗（`LevelScale.attack`）。2026-11-09 の声「ソロでの敵が弱かったらパーティー組む意味ない」「巨神の心臓めっちゃ弱かった（Lv 23 で岩鯨）」。
- 崩しゲージ: 崩れの最中に体力が次の段階へ入ったら、崩れを解いて段階の変わり目（咆哮）を先にする（`BreakGauge.onEntityTick`。四つの心臓の `phaseForHealth`）。2026-11-09 の声「スタン中でも、形態変化を優先して」。

### 2.1.1 入る人のレベルに合わせた硬さ（`combat/LevelScale`）

2026-11-08 の声「再挑戦できる系のボスは、入る人のレベルに合わせて最適な hp になる様にして。周回が楽になりすぎないように」。

- 主ごとに想定のレベルを持つ。背中の心臓と中ボスはその巨神の章の推奨レベル（`GearCurve.STAGES`: 岩鯨 12・潮殻 18・雷翼 24・余燼 30。`LevelScale.stageLevel`）、地下の迷宮の主は迷宮のレベル。
- 戦いの始め（`GroupBossRoom.start`・`DungeonFloor` の主を出すとき）に、挑む人の平均のレベルで見込める 1 秒あたりの傷（`expectedDps`: 装備の段の dps0 × 筋力 × 技の木の上乗せ。段の先は 6 レベルごとに ×1.15）を、想定のレベルの見込みで割った倍率 k を主に書く（`skyabyss_level_scale`。1〜4）。人から受ける傷を k で割る。上のレベルで来ても、戦いの長さは推奨のレベルとほぼ同じ。下のレベルでは楽にしない。人数（`PartyScale`）や型ごとの硬さとは別に掛かる。
- 参考: Wynncraft のボス・レイドは体力を変えず、入れるレベルの下限とレベルで変わる報酬で回している（上のレベルで行くと楽になる）。ここは FF14 のレベルシンクのように、主の側を上げて手ごたえを残す。
- まだ掛けていない: 塔、月の試練の再戦、深淵の層の主（深淵は層ごとの伸びを持つ）。

### 2.2 下がらない

主と名のある敵は殴られても下がらない（`BossFooting`。2026-10-28 に入れた）。

### 2.3 一撃の重さ

- 心臓の一撃のねらい（`HeartBalance.HEAVY_SHARE`）は想定の体力の 0.38（帯 0.30〜0.48）のまま。2026-10-28 に一律 1.2 倍（`HIT_SCALE`）を試したが、手ごたえの式の公平の決まり（避けそこね 4 回で体力の 1.5 倍まで、九割避ける人は予算の 6 割まで）を越えたので 1.0 に戻した。
- 重さは変えず、ごり押しは崩しゲージ（2.1）と戦いの中の食事の間（2.4）で防ぐ。避けそこねを食べ物で帳消しにできないので、一撃の重さが今より効く。
- 自己テスト（`HeartBalanceSelfTest`）が人数ごとの長さの帯と一撃の重さを確かめる。

### 2.4 戦いの中の回復

- 主と戦っている間（主から 48 以内で、主か人が 10 秒以内に傷を受けた）、食べ物と薬は**ひとつ食べたら 20 秒**、次を口にできない（`combat/FightRations`）。
- 待つ間に口にしようとすると、上の帯に「息が整うまで、口にできない（あと n 秒）」。
- 戦いの外では今までどおり。

### 2.5 遠くからの矢

- 体力 100 以上の敵（主・中ボス・心臓）には、遠くから射た矢が弱まる（`combat/RangedFalloff`。2026-10-29 の声「弓強すぎるかも。ボスとかそんなに遠くまで攻撃しないから」）。射手と的の距離が 10 まではそのまま、26 で 0.55 倍、その間はまっすぐ下がる。ふつうの敵には掛けない。

### 2.6 どの主にも効く（2026-11-02 の全体監査）

- 崩しゲージは主の全部に掛かる（`BossFooting.planted` = 帯を持つ型・体力 150 以上・名のある敵）。隙を開ける口は二つ: `Telegraph` の技が当たり終わる（`BossOpenings.moveEnded`）か、主ごとの仕掛けを解く（`BreakGauge.solved`、主が自分で持つ弱い時間は `BossOpenings.open`）。
- 予告を `Telegraph` で出さない主は、技の終わりで自分から `moveEnded` を呼ぶ: 月の主 5 体（`story/ch6/mob`）、雲海の島の主と巡礼者の三形態と始祖（`story/finale/mob`）、塔の主と側の目（`tower/TowerFight`）、深みの王（`DepthBoss.endMove`）、淵の杭（脈のあと）。それまで（0.9.21 まで）はこれらが Telegraph を使っておらず、隙が一度も来なかった。
- 主が自分で持つ弱い時間: 人が仕掛けを解いて起こすもの（月秤が倒れる・望の灯守が膝をつく・影抱きが固まる・月の核が崩れる・残月の剣守が崩れる）は `BreakGauge.solved(主, その長さ)`（ゲージが半分溜まり、その間は隙）。技の終わりの弱い時間（灯守の目が目を閉じる・巡礼者の手が床に手を突く・望の灯守の放ったあと）は `BossOpenings.open(主, その長さ)`（隙と同じく溜まり ×3）。主ごとの硬い時間（溜め ×0.35・錘 ×0.35・影の中 ×0.2）はそのまま掛かる。
- 壊すのが目的の的（塔の落ちる月・動かない繋ぎ手）は印 `skyabyss_no_guard` を付け、主として扱わない（倍率もゲージもない）。
- **人数**: 人数の強さは `HeartBalance.partyScale(人数)` を体力に掛ける（2.0。前は人から受ける傷を割っていた）。舞台が湧かせるときに `combat/PartyScale.apply(主, 人数)`（月の舞台は 64 ブロック内の人数、雲海の舞台は `present`、名のある敵は棲み家 72 ブロック内）。自分で割っている主（心臓・始祖・塔・深みの王・淵の杭）には使わない。
- **硬さ**（`PartyScale.resist`）: 体力に掛ける（2.0。心臓の `BASE_RESIST` と同じ役。見積もりの式は前と同じで、割る代わりに掛ける）。値は崩しゲージ込みの見積もり（`combat/BreakModel`）で 2.1 の目安の長さに合わせた（2026-11-04。体力の数字は変えない）。
  - 技の木の上乗せ（`HeartBalance.treeBonus`）: 2026-11-04 に木の節を大きくした（48 の 4.1）ので、見積もりの人の傷に足す。木のデータから、レベル（= SP）で幹と型ひとつを傷の節から取ったときの上乗せ（近接・矢 0.6 + 技 0.4）を六職で平均した値の 0.75 倍（ふつうの取り方）: Lv 12 で +5.5%・18 で +16.4%・24 で +23.5%・30 で +26.6%・46 から +28.4%（技の木 v3 の木で数え直した。前提の道の SP を輪なしで数える）。
  - 見積もり（`BreakModel`）: ふだんの削り ×0.8、与えた傷 × 1.6（満ちた近接 ×1 と隙 ×3 の混ざり）だけゲージが溜まり、満ちると 5 秒 ×2.0（止まった主を殴っていられる割合 0.85）。殴っていられる割合はふだん 0.55。仕掛けで溜まる半分は入れない（その分、実際は少し短い）。
  - 月・雲海の島の主（一人 200〜240 秒）は一人 220 秒に合わせる。巡礼者の三形態は合わせて 6〜7 分、あいだに座すもの（塔の主）は四人で 12〜15 分。

### 2.7 倒れたときの弱り（`combat/DeathWeakness`）

- 倒れて目覚めたとき（休み場・宿・寝台）、2 分の「弱り」: その人が与える傷 ×0.85、受ける傷 ×1.15。持ち物と経験値は失わない（2026-11-04 の表 5-1）。
- 効き目の欄にひびの入った心臓の絵と残りの時間（`textures/mob_effect/weakened.png`、`tools/gen/icons/gen_weakened_icon.py`）。目覚めたときに手がかり「弱っている（2 分）。与える傷 −15%・受ける傷 +15%。宿で休むと治る」。
- 宿で休むと（宿の主人の「休む」）消え、「宿で休んで、弱りが抜けた」。仲間に起こされたとき（倒れずに済んだ）は付かない。創造・観戦では付かない。

## 3. ふつうの敵

- 受ける傷に倍率は掛けない（2026-11-04 に身構えを外した。全員の一撃を合わせて数えていたので二人で殴るとすぐ硬くなった。連打は近接の決まり 3.1 で効かない）。
- 技（予告のある攻撃）は今の 44 の決まりのまま。

### 3.1 近接の一撃（`combat/MeleeHits`）

2026-11-04 の声「敵の無敵時間が短すぎて、敵すぐ死んでしまう。連打が最強すぎる」「プレイヤーが同じ敵を殴れるクールタイムがあった方がいい」「チャージ0の時は攻撃力0でもいいかも」「HP回復の武器はフルチャージじゃないと、発動しないようにして」。

| 決まり | 中身 |
| --- | --- |
| 敵の無敵の間 | 今のまま（`MobHitFrames`。人が当てたあとの無敵はほぼ無く、仲間の一撃は同じ tick でも全部通る） |
| 同じ敵を殴れる間 | 人ごと・敵ごと。当てたあと、その人はその敵を「振りの長さ（20 ÷ 攻撃速度 tick）× 0.6」（最短 3 tick）のあいだ殴れない（空振り。ほかの敵とほかの人の一撃は通る） |
| 溜めの強さ | 傷 = 満ちた一撃の傷 × 溜め²（溜め 0 でほぼ 0、半分で 2.5 割）。バニラの「溜め 0 でも 2 割」を無くした。その一撃の中で武器の効き目が与える傷にも同じく掛かる。技・矢の傷には掛けない |
| 回復は満ちた一撃だけ | 溜めが 0.9 以下（バニラの薙ぎ払い・会心の境と同じ）の一撃の中では、人の回復（吸血・当てて癒す・仲間を癒す・再生の効き目を付ける）が起こらない。技・矢・身に着けた品の時間ごとの回復はそのまま |
| 武器の効き目は満ちた一撃だけ | 溜め 0.9 以下の一撃では、武器・装飾・技の木の「当てたとき」の効き目が起こらない: 武器の上乗せと追加効果（野の武器の効き目の表・固有の武器 13 本の当てたときの効果・月と神器の武器・嵐の護符の雷）、溜まりと数え（型の溜まるもの・返し刃・孤り・熾・岩の返り・何回目かの効果）、マナ吸い・回復。数えや溜まりは弱い一撃で減らない（満ちた一撃のために残る）。防具の組の効き目・技・矢・時間ごとの効き目は対象外。`MeleeHits.weakHit`、武器の当てたときの口は `GearLevel.proc`（必要レベルと合わせて見る） |

## 4. 自己テスト

- `combat rules`（`CombatRulesSelfTest`）: 主は ×0.8 でふつうの敵は何度打たれても ×1、主に当てるとゲージが溜まり隙の間は ×3、満ちると崩れて ×2.0・技を出せない・崩れの間は溜まらない、次のゲージは 1.25 倍から 1.5 倍、仕掛けを解くと半分溜まって隙が開く、戦いの中の食べ物は 20 秒待つ、戦いの外は待たない。
- `heart balance`: 一撃の重さの帯（今のまま）。
- `melee hits`（`MeleeHitsSelfTest`）: 同じ人が同じ敵をすぐ殴ると空振り、ほかの人は同じ tick でも通る、溜め 0 は満ちた一撃の 5% 未満、溜め半分は約 2.5 割、満ちていない一撃の中の回復は起こらず満ちた一撃では起こる（自分も仲間も）。二人: 同じ tick の満ちた一撃はどちらも通り、一人の弱い一撃の中でももう一人の傷は弱まらない。溜めの手がかりは戦いが落ち着いてから出て、満ちた一撃に慣れた人には出ない。
- `ttk audit`（`TtkAuditSelfTest`）: 上の「倒すまでの時間」。
- `melee hits` に足した: 満ちていない一撃の最中だけ `weakHit` が真で `GearLevel.proc` が偽（振った人だけ）、水路の牙の出血は満ちた一撃でだけ付く。

## 5. 三人称の視点（肩越し）

2026-11-02 の声「3人称視点をオリジナルの物にして、3人称視点でも戦いやすくして」。`client/camera/ShoulderCam`（カメラの置き場は `mixin/CameraShoulderMixin`、マウスは `mixin/MouseHandlerShoulderMixin`）。

- **切り替え**: F5 は 一人称 → 肩越し → 一人称（前から映す視点は飛ばす）。設定 `shoulderCamera`（既定 true。false でバニラの三人称）。
- **置き場**: 体の目から、肩の高さ（0.5 上）・片側（0.75 横。既定は右、F6 で左右を替える。替えるときはなめらかに寄る）・後ろへ `shoulderDistance`（既定 4.0、1.5〜6。床の予告とまわりが見えるように少し引いて高め）。乗り物の上では乗り物の幅の分（3 まで）引く。途中に壁や天井があれば手前（0.2）で止まる（八隅を少しずらして探す）。
- **向き**: マウスはカメラの向きを回す。体は毎フレーム「画面の真ん中の照準の先」（カメラから見ている向きに 64 まで、ブロックか生き物に当たる所。自分とカメラの間のものは数えない）を向く。肩越しのずれがないので、殴る・技・弓・使う品は照準の所へ当たる。場所移し・乗り物・技の向き合わせなどで体が外から回されたら、カメラもその分回る。
- **歩く向き**: 動きの入力 (前・横) を、体の向きからカメラの向きへ回す (`ShoulderCam.onMovementInput`)。体は照準の先を向くので、近い所を見ると肩のずれの分だけ体とカメラがずれ、W で斜めに歩いていた (2026-11-09 の声「3人称操作しづらい」)。乗り物の上はそのまま。
- **引きのなめらかさ**: 壁や天井に寄るときはすぐ手前へ (壁の中を映さない)、離れたあとは少しずつ (1 秒でおよそ戻る) 引きを戻す。
- **照準**: バニラは三人称で照準を描かないので、画面の真ん中に照準を出す。照準の先が敵（生きている）なら四隅に赤い角。
- 場面（シネマティック）の最中・眠り・カメラが自分でないときは効かない。ほかのカメラの mod（Shoulder Surfing Reloaded。mod の ID `shouldersurfing`）が入っていれば使わない（そちらのカメラに任せる）。
