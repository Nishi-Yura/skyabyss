# 47 戦いの手ごたえ（ソウル型 + 主ごとの仕掛け）

2026-10-28 の試遊の声:「巨神の心臓ボスめっちゃ弱い？ FF、ダークソウル位むずくしてもいいのでは。正直眠い」「巨神のボス以外にも、全部の戦いに共通するんだけど、ごり押しでは絶対に倒せないようにしてほしい」。
決めたこと（ユーザーの答え）: **ソウル型 + 主ごとの仕掛け**。主と名のある敵は殴られても下がらない。

この書類は、すべての戦い（心臓の主・中ボス・名のある敵・ふつうの敵）に共通する決まりを書く。主ごとの技と仕掛けは、それぞれの巨神の書類（02・08・12・13）と 36（深淵）にある。

## 1. ねらい

- 立ったまま殴り合うと負ける。**技を見て避け、隙に打ち込む**と勝てる。
- 主の一撃は重い（想定の装備で 2〜3 回で危ない）。避けそこねを回復で帳消しにはできない。
- 主には、それぞれ一つ「解かないと倒せない仕掛け」がある（今の「領域」= 心臓が守られる間。解くと大きな隙）。
- 戦いの長さは今の帯（一人 3〜5 分）のまま。強さは長さではなく、間違いの重さで出す。

## 2. 主（心臓の主・中ボス・名のある敵・体力の大きい敵）

主の見分けは `combat/BossFooting.planted`（名のある敵の印・ボスの帯を持つ型・体力が `ShieldRules.BIG_HEALTH` 以上）。

### 2.1 構えと隙（`combat/BossOpenings`）

| 状態 | 人から受ける傷 | 始まり | 長さ |
| --- | --- | --- | --- |
| 構え（ふだん） | ×0.3 | — | — |
| 隙 | ×1.6 | 主の技（予告 `Telegraph` を出した技）が当たり終わった瞬間 | 3 秒 |
| 大きな隙 | ×1.6 | 主ごとの仕掛けを解いた（領域が解けた）瞬間 | 6 秒 |

- 技を出すたびに隙が来るので、技の間合いの外で待ち、終わりに踏み込んで打つのが基本の形。技がおよそ 6 秒に一度なら、ならした手ごたえは今とほぼ同じ（0.5 × 1.6 + 0.5 × 0.3 ≒ 0.95）。
- 隙の間は、主の体に白い火花が散り、音が鳴る（見て分かる）。構えの間に打つと、鈍い音と小さな火花（硬い）。
- 巨神の心臓・中ボス・名のある敵、どれも同じ決まり。環境の傷（落下・溶岩・仕掛けの傷）は構えに関わらずそのまま。

### 2.2 下がらない

主と名のある敵は殴られても下がらない（`BossFooting`。2026-10-28 に入れた）。

### 2.3 一撃の重さ

- 心臓の一撃のねらい（`HeartBalance.HEAVY_SHARE`）は想定の体力の 0.38（帯 0.30〜0.48）のまま。2026-10-28 に一律 1.2 倍（`HIT_SCALE`）を試したが、手ごたえの式の公平の決まり（避けそこね 4 回で体力の 1.5 倍まで、九割避ける人は予算の 6 割まで）を越えたので 1.0 に戻した。
- 重さは変えず、ごり押しは構えと隙（2.1）と戦いの中の食事の間（2.4）で防ぐ。避けそこねを食べ物で帳消しにできないので、一撃の重さが今より効く。
- 自己テスト（`HeartBalanceSelfTest`）が人数ごとの長さの帯と一撃の重さを確かめる。

### 2.4 戦いの中の回復

- 主と戦っている間（主から 48 以内で、主か人が 10 秒以内に傷を受けた）、食べ物と薬は**ひとつ食べたら 20 秒**、次を口にできない（`combat/FightRations`）。
- 待つ間に口にしようとすると、上の帯に「息が整うまで、口にできない（あと n 秒）」。
- 戦いの外では今までどおり。

### 2.5 遠くからの矢

- 体力 100 以上の敵（主・中ボス・心臓）には、遠くから射た矢が弱まる（`combat/RangedFalloff`。2026-10-29 の声「弓強すぎるかも。ボスとかそんなに遠くまで攻撃しないから」）。射手と的の距離が 10 まではそのまま、26 で 0.55 倍、その間はまっすぐ下がる。ふつうの敵には掛けない。

### 2.6 どの主にも効く（2026-11-02 の全体監査）

- 構えと隙は主の全部に掛かる（`BossFooting.planted` = 帯を持つ型・体力 150 以上・名のある敵）。隙を開ける口は二つ: `Telegraph` の技が当たり終わる（`BossOpenings.moveEnded`）か、主ごとの仕掛けを解く（`BossOpenings.open`）。
- 予告を `Telegraph` で出さない主は、技の終わりで自分から `moveEnded` を呼ぶ: 月の主 5 体（`story/ch6/mob`）、雲海の島の主と巡礼者の三形態と始祖（`story/finale/mob`）、塔の主と側の目（`tower/TowerFight`）、深みの王（`DepthBoss.endMove`）、淵の杭（脈のあと）。それまで（0.9.21 まで）はこれらが Telegraph を使っておらず、隙が一度も来ないまま ×0.3 で削り切る形だった。
- 主が自分で持っていた「膝をつく・目を閉じる・固まる・床に手を突く」の弱い時間（×1.5〜1.6）は、`BossOpenings.open(主, その長さ)` に寄せた（隙 ×1.6 と同じ）。構えの硬さ（溜め ×0.35・錘 ×0.35・影の中 ×0.2）はそのまま掛かる。
- 壊すのが目的の的（塔の落ちる月・動かない繋ぎ手）は印 `skyabyss_no_guard` を付け、構えを掛けない。
- **人数**: 主の体力には 1024 の上限があるので、人数の強さは「人から受ける傷を `HeartBalance.partyScale(人数)` で割る」形にそろえる（四つの心臓・始祖と同じ）。舞台が湧かせるときに `combat/PartyScale.apply(主, 人数)`（月の舞台は 64 ブロック内の人数、雲海の舞台は `present`、名のある敵は棲み家 72 ブロック内）。自分で割っている主（心臓・始祖・塔・深みの王・淵の杭）には使わない。
- **硬さ**（`PartyScale.resist`。2026-11-02）: 月・雲海・塔の主の体力は、隙の決まりが入る前（×0.3 で削り切る形）に 3〜5 分になるよう置かれていた。隙が来るようになって一人の戦いが 80〜100 秒に縮むので、心臓の `BASE_RESIST` と同じ役の硬さで割り、一人 200 秒前後（心臓の帯 180〜300）に戻す。体力の数字は変えない（上限 1024）。
  式: 硬さ = dps(Lv) × 0.55（殴れる割合）× 200 秒 ÷ 体力 ÷ 平均の倍率（構え 0.3 と隙 1.6 をならして 0.95。主ごとの硬い時間があればその分を掛ける）。dps(Lv) は 51 の 2 章の E(L)（Lv 46 ≈ 21.3、Lv 50 = 23.0）。

  | 主 | 体力 | 平均の倍率 | 硬さ |
  | --- | --- | --- | --- |
  | 望の灯守 | 850 | 0.70（溜めのあいだ ×0.35） | 1.9 |
  | 月秤 | 850 | 0.70（倒れていないと ×0.35） | 1.9 |
  | 影抱き | 1100 | 0.68（影の中 ×0.2） | 1.5 |
  | 欠けの刃 | 850 | 0.95 | 2.6 |
  | 月の核 | 850 | 0.95 | 2.6 |
  | 灯守の目 | 1000 | 0.95 | 2.4 |
  | 最後の鐘守 | 980 | 0.95 | 2.5 |
  | 巻き戻し手 | 1010 | 0.95 | 2.4 |
  | 巡礼者の羽 | 1060 | 0.95 | 2.3 |
  | 巡礼者の手・目・月 | 760×2・1500・1800 | 0.95 | 1.3（三形態で 8〜9 分） |
  | あいだに座すもの | 6000（人数で伸びる） | 0.95 | 2.0（四人で 15〜20 分） |
  | 初代の空見 | 1000 | — | 変えない（53 の「強さは増やさない」。一騎打ちの手ごたえは試遊で） |

- 数字は、この決まりを入れたあとで試遊して詰める（長すぎれば硬さを下げる）。

## 3. ふつうの敵

- 殴られ続けると身構える（`combat/BossOpenings` の身構え）: 3 秒の間に 5 回打たれると、2 秒のあいだ受ける傷 ×0.4（下がらない）。連打だけで押し切れない。身構えの間は盾を構えたような音と粒。
- 技（予告のある攻撃）は今の 44 の決まりのまま。

### 3.1 近接の一撃（`combat/MeleeHits`）

2026-11-04 の声「敵の無敵時間が短すぎて、敵すぐ死んでしまう。連打が最強すぎる」「プレイヤーが同じ敵を殴れるクールタイムがあった方がいい」「チャージ0の時は攻撃力0でもいいかも」「HP回復の武器はフルチャージじゃないと、発動しないようにして」。

| 決まり | 中身 |
| --- | --- |
| 敵の無敵の間 | 今のまま（`MobHitFrames`。人が当てたあとの無敵はほぼ無く、仲間の一撃は同じ tick でも全部通る） |
| 同じ敵を殴れる間 | 人ごと・敵ごと。当てたあと、その人はその敵を「振りの長さ（20 ÷ 攻撃速度 tick）× 0.6」（最短 3 tick）のあいだ殴れない（空振り。ほかの敵とほかの人の一撃は通る） |
| 溜めの強さ | 傷 = 満ちた一撃の傷 × 溜め²（溜め 0 でほぼ 0、半分で 2.5 割）。バニラの「溜め 0 でも 2 割」を無くした。その一撃の中で武器の効き目が与える傷にも同じく掛かる。技・矢の傷には掛けない |
| 回復は満ちた一撃だけ | 溜めが 0.9 以下（バニラの薙ぎ払い・会心の境と同じ）の一撃の中では、人の回復（吸血・当てて癒す・仲間を癒す・再生の効き目を付ける）が起こらない。技・矢・身に着けた品の時間ごとの回復はそのまま |
| 武器の効き目は満ちた一撃だけ | 溜め 0.9 以下の一撃では、武器・装飾・技の木の「当てたとき」の効き目が起こらない: 武器の上乗せと追加効果（野の武器の効き目の表・固有の武器 13 本の当てたときの効果・月と神器の武器・嵐の護符の雷）、溜まりと数え（型の溜まるもの・返し刃・孤り・熾・岩の返り・何回目かの効果）、マナ吸い・回復。数えや溜まりは弱い一撃で減らない（満ちた一撃のために残る）。防具の組の効き目・技・矢・時間ごとの効き目は対象外。`MeleeHits.weakHit`、武器の当てたときの口は `GearLevel.proc`（必要レベルと合わせて見る） |
| 溜めの輪 | 近接の武器（振りのある預かりの武器と、剣・斧・槌・三叉槍）を振ったら、照準のまわりに点の輪（半径 10）。溜まった分だけ上から時計回りに明るくなる。満ちた瞬間は金に光って少し広がりながら消え、小さな澄んだ音。同じ敵を殴れる間に空振りしたら（サーバーの `MeleeHits.Miss`）輪が灰色になって左右に揺れ、鈍い音。満ちて光り終えたら消える。輪を出す手のあいだは、バニラの照準の下の溜めの印を隠す。一人称と肩越しで描き、仲間を起こす輪が出ている間・場面・画面・F1・F3 では出さない。`client/weapon/ChargeRing`、設定 `chargeRing`・`chargeSound`。撮影 `tools/shots/charge_ring.txt` |
| 溜めの教え | はじまりの島で足跡を見たあと（次は峠の野盗）に手がかり「峠に野盗がいる。照準の輪が満ちてから振ると、一撃が強い」。どこでも、溜め 0.5 未満の一撃を 4 回振った人には、戦いが落ち着いてから（近接が 4 秒なく、傷を 10.5 秒受けていない。手がかりの字幕は戦いの最中は出ないため）手がかり「照準の輪が満ちてから振ると一撃が強い。満ちる前はほとんど効かない」。一人に 2 回まで、満ちた一撃を 20 回当てた人には出さない（人の永続データ `skyabyss_charge_tips`・`skyabyss_full_hits`。倒れても残る） |
| 倒すまでの時間 | 自己テスト `ttk audit`（`TtkAuditSelfTest`）: 土地ごとに湧きの表の敵を土地の強さで出し、その土地の目安のレベルの近接の野の武器で満ちた一撃を振りの長さごとに当てたときの一撃の数と秒（中央値）を記録に出す。ふつうの敵は 6 回・4.5 秒まで、夜の番人（体力 100 以上）は 18 秒まで。2026-11-04 の測り: ふつうの敵は 1〜5 回・3.3 秒まで（前の連打の見積もりより 1〜2 割遅いだけ）、番人は 13〜15 秒（前の連打で 11〜13 秒）。どの土地も直しは要らなかった |
| 範囲 | 近接の一撃（`Player.attack`）。預かりの武器（`weapon/WeaponStrikes`）は当たる tick に `MeleeHits.attack` を呼ぶ。素手・弓や盾で殴るなどもここで包む。偽のプレイヤーは対象外 |

## 4. 自己テスト

- `combat rules`（`CombatRulesSelfTest`）に足す: 構えの主は ×0.3、技が当たり終わると 3 秒 ×1.6、仕掛けを解くと 6 秒、ふつうの敵は 5 回で身構える、戦いの中の食べ物は 20 秒待つ、戦いの外は待たない。
- `heart balance`: 一撃の重さの帯（今のまま）。
- `melee hits`（`MeleeHitsSelfTest`）: 同じ人が同じ敵をすぐ殴ると空振り、ほかの人は同じ tick でも通る、溜め 0 は満ちた一撃の 5% 未満、溜め半分は約 2.5 割、満ちていない一撃の中の回復は起こらず満ちた一撃では起こる（自分も仲間も）。二人: 同じ tick の満ちた一撃はどちらも通り、一人の弱い一撃の中でももう一人の傷は弱まらない。溜めの手がかりは戦いが落ち着いてから出て、満ちた一撃に慣れた人には出ない。
- `ttk audit`（`TtkAuditSelfTest`）: 上の「倒すまでの時間」。
- `melee hits` に足した: 満ちていない一撃の最中だけ `weakHit` が真で `GearLevel.proc` が偽（振った人だけ）、水路の牙の出血は満ちた一撃でだけ付く。

## 5. 三人称の視点（肩越し）

2026-11-02 の声「3人称視点をオリジナルの物にして、3人称視点でも戦いやすくして」。`client/camera/ShoulderCam`（カメラの置き場は `mixin/CameraShoulderMixin`、マウスは `mixin/MouseHandlerShoulderMixin`）。

- **切り替え**: F5 は 一人称 → 肩越し → 一人称（前から映す視点は飛ばす）。設定 `shoulderCamera`（既定 true。false でバニラの三人称）。
- **置き場**: 体の目から、肩の高さ（0.5 上）・片側（0.75 横。既定は右、F6 で左右を替える。替えるときはなめらかに寄る）・後ろへ `shoulderDistance`（既定 4.0、1.5〜6。床の予告とまわりが見えるように少し引いて高め）。乗り物の上では乗り物の幅の分（3 まで）引く。途中に壁や天井があれば手前（0.2）で止まる（八隅を少しずらして探す）。
- **向き**: マウスはカメラの向きを回す。体は毎フレーム「画面の真ん中の照準の先」（カメラから見ている向きに 64 まで、ブロックか生き物に当たる所。自分とカメラの間のものは数えない）を向く。肩越しのずれがないので、殴る・技・弓・使う品は照準の所へ当たる。場所移し・乗り物・技の向き合わせなどで体が外から回されたら、カメラもその分回る。
- **照準**: バニラは三人称で照準を描かないので、画面の真ん中に照準を出す。照準の先が敵（生きている）なら四隅に赤い角。
- 場面（シネマティック）の最中・眠り・カメラが自分でないときは効かない。ほかのカメラの mod（Shoulder Surfing Reloaded。mod の ID `shouldersurfing`）が入っていれば使わない（そちらのカメラに任せる）。
