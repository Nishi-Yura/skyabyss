# 天と淵のあいだ 全体設計

- 文書番号: 01
- 範囲: コンセプト、守る軸、技術、世界観と物語、章とボス、ループ、RPG の柱、ホラーの原則、アートの基準、ロードマップ。詳しい中身は各書類にある
- 関連: [README（書類の索引）](README.md)、[00 未決の一覧](00_decisions_needed.md)

## 1. ブレない軸

**コンセプト: 見えない巨大なものに怯える静かなホラーが、世界の謎を解く RPG に変わっていく。** 最後に「それ」と雲の上で対峙する。

迷ったときは次の 5 つに照らして判断する。

1. **見せない恐怖が先、戦いは後。** 巨大な存在は序盤では痕跡・影・音でしか出さない。全身は最後まで見せない。
2. **壮大さは「スケール」と「光」で出す。** 空の広さ、巨神の大きさ、月の近さ。
3. **マイクラらしさは壊さない。** 建築や拠点づくりは守る。ループで巻き戻すのは物語だけ。
4. **RPG は「強くなる実感」と「謎が解ける快感」を両立させる。** レベルを上げるだけのゲームにはしない。
5. **一人で完成させられる範囲で作る。** 縦切り版を先に作り、章を 1 つずつ足す。

始まった瞬間から mod の世界だと分かるようにする（序盤は偶然に頼らず、必ず起きる拍子で組む。[17](17_opening_and_rpg_feel.md)）。

**やらないこと**

- ジャンプスケア（急に大きな音と顔が出る演出）に頼る
- 序盤から巨大ボスと戦わせる
- プレイヤーの建築物を消す・巻き戻す
- バニラの戦闘やクラフトを大きく作り変える（足すのはよいが、置き換えない）
- 演出でプレイヤーを死なせる

## 2. 技術

| 項目 | 採用 | 理由 |

| ローダー | NeoForge 1.21.1、JDK 21 | 情報が多く、GeckoLib が安定している |
| モデル・アニメ | GeckoLib（`.geo.json`・`.animation.json`） | 高密度のモデルと立体防具を動かせる |

| 効果音 | 既存の音を使わず独自に合成（`tools/gen_sky_sounds.py` など） | 奇妙で記憶に残る音にするため |
| パッケージ | `jp.revati.skyabyss` | — |

**シェーダー**: Java 1.21.1 に Vibrant Visuals はないので、Iris＋シェーダーパック（基準は Complementary Shaders）で狙う。テクスチャには LabPBR の `_n`・`_s` を添える。**シェーダーなしでも成り立つこと**が必須。影や空の演出はエンティティとパーティクルで作る。

**設定**: サーバー設定（頻度・ループ・ゲームルール）とクライアント設定（揺れ・画面効果・表示）に分ける。マルチプレイが前提。

**確かめ方**: `./gradlew compileJava --offline`、自己テスト `SKYABYSS_SELFTEST=1 ./gradlew runServer`（一部だけは `SKYABYSS_SELFTEST_ONLY=<名前の頭>`）、画面は `./gradlew runClientTest`（手順は `tools/README.md`）。

## 3. 世界観と物語

世界は、空の「巡礼者」と地の底の「心臓」が引き合うことで保たれている。心臓が弱り、巡礼者が降りてくる。その兆しが、近づいてくる月。

| 存在 | 正体 | プレイヤーからの見え方 |
| --- | --- | --- |
| 雲上の巡礼者 | 空を統べる古き神。月を引きずって空を**飛ぶ**（歩かない） | 雲の上を通る翼の影、羽ばたきの音、削られた山頂。全身は最後まで見えない |
| 止まった月 | 巡礼者の降臨の兆し。内部に時間を縛る核がある | 毎夜少しずつ大きくなる。落ちると物語が巻き戻る |
| 深淵の心臓 | 世界を地上につなぎとめる錨。弱っている | 深く掘るほど大きくなる鼓動。壁の向こうの足音 |
| 巨神たち（4 体） | 心臓が生んだ守護者。心臓から分かたれた鼓動を体の奥に抱える。背中に滅んだ古代文明を乗せている | 空・海・嵐・地の中をゆっくり進む山のような生き物 |
| 見る者 | 前のループの自分（留まる者）が残した影 | 夜、外にいると、遠くの丘に自分に似た人影が立ってこちらを見ている。目を合わせると消える |

**鐘の国（仮の名）と都「鐘の宿り」**: 主人公が目を覚ます地上は、空を見張る小さな国の跡。代々「空見」の一族が国を預かり、影が通れば大鐘楼の鐘を鳴らし、見たものを帳面に記してきた。その一族は絶え、語り部が最後の鐘守として都に残る。都は大きいのに人が少ない（空き家・静かな通り・市に村人が少し）。国は建物・名前・記録で見せ、生きた政治や群衆では見せない（「絶えかけの国の都」。33 の 2.2）。章が進むと都の施設が一つずつ開く。

**主人公「留まる者」**: 月が落ちて時間が巻き戻っても記憶を保てるただ一人。なぜ残るのかが物語の核心の謎。伝承の書の最初の一行「忘れないうちに書け。次は、もっと早く気づけるように」（前のループの自分が書いた、と六章で分かる）、宝物庫の碑文「留まる者が来る」、語り部の「この字、どこかで見た気がする」が同じ方向をほのめかす。

**分かたれた鼓動（巨神の心臓）**

- 深淵の心臓は弱りはじめたころ、鼓動の一部を分けて四体の巨神に一つずつ預けた。これが「巨神の心臓」で、**各巨神の守護者（巨神編のボス）**。名前は「岩鯨の心臓」のように巨神の名＋心臓。
- 天の鍵の欠片は、背中の民が鼓動のそばに納めたもの。心臓が止まると手に取れる。
- 「心臓」という同じ言葉は深淵の心臓への伏線。巨神編では説明せず、碑文が「この鼓動は地の底から預かったもの」とほのめかすだけ。五章で「あの鼓動は借りものだった」と気づかせる。
- **心臓を止めても、巨神は死なない。** 巨神は 4 体だけで、増えない。心臓は借りものの鼓動で、止まると巨神は**深い眠りに落ちる**（歌をやめ、光が消え、巨神ごとの形で沈み・埋もれ・畳まれる）。鼓動は遠い下からゆっくり戻ってきて、巨神はまた目を覚ます。背中に何度でも挑める理由はこれ（背中の試練が元に戻る時＝鼓動が戻る時）。語りは「下から戻ってくる」とほのめかすだけで、なぜ戻るかは説明しない（五章への静かな伏線）。眠りの決まりは 4.3。
- 心臓を止めたことが深淵の心臓にどう響くかは 五章で決める（巨神編では解決しない）。伝承の「止まった鼓動」は「この鼓動はどこから来て、どこへ行ったのか」という問いで終える。

**見る者の扱い**: 序章から五章までは遠くから見て、目を合わせると消えるだけ（近さは段階 2 で止める）。六章でループの仕組みが分かり正体に気づく。ラスボス第 3 形態の「過去の自分の幻影」はこれまでの見る者たちで、はじめて近くに来て一緒に戦う。裏ボスにはしない（[06](06_prologue.md)）。

**物語の流れ**

1. 地上で異変に気づく（野営地、足跡、空の影、鐘の宿りの語り部、見る者）
2. 巨神の背を巡り、体の奥の心臓を止めて「天の鍵」の欠片を集める
3. 深淵へ潜り、心臓が弱った理由と、巨神に分けた鼓動の意味を知る
4. 月へ渡り、ループの仕組みと主人公の正体を知る
5. 雲海で巡礼者と対峙する

**エンディング（3 種）**: **鎮める**（心臓を癒し均衡を戻す。王道）／**壊す**（心臓を壊し巡礼者を封じる。世界が変容する）／**受け入れる**（巡礼者を地上に招く。隠し、条件付き）。

## 4. 章とボス

序盤はホラー色が強く、章が進むほど RPG 色が強くなる。**巨神 1 体につき 1 章**。章を重ねるほど一体ごとの「大きさ」を、存在感・予兆・出来事・背の外の探索・NPC の筋で積み上げる（4.2）。

| 章 | 題字 | 舞台 | ボス | 報酬 |
| --- | --- | --- | --- | --- |
| 序章 | 空の影 | 地上（日 1 だけ） | なし（気配だけ） | 伝承の書 |
| 一章 | 空を泳ぐもの | 地上と岩鯨の背 | 岩鯨の心臓（中ボス: 鯨骨の番兵長） | 岩鯨の装備、岩鯨での移動、欠片 1/4 |
| 二章 | 引く海 | 海辺と潮殻の背 | 潮殻の心臓（中ボス: 潮招き） | 潮殻の装備、潮殻での移動、欠片 2/4 |
| 三章 | 風に逆らう嵐 | 峰と雷翼の背 | 雷翼の心臓（中ボス: 雷獣） | 雷翼の装備、欠片 3/4 |
| 四章 | 足もとから来るもの | 灰の降る地と余燼の背 | 余燼の心臓（中ボス: 灰の鍛え手） | 余燼の装備、欠片 4/4、天の鍵 |
| 五章 | 深淵 | 深淵（ディメンション） | 心臓の番人 | 深淵術の解放 |

| 終章 | 雲海 | 雲海（ディメンション） | 雲上の巡礼者 | 神器 |
| 結末 | — | 選択で 3 種のエンディング | — | エンド別の世界変化 |

- **巨神編**: 一〜四章の総称（巨神 4 体を順に止め、天の鍵をそろえるまで）。コードや伝承の ID にある `chapter1` は巨神編を指す（ID は変えない）。
- 序章は日 1（拍子 B0〜B6）だけ。日 2 の朝、イサナと会う（B7）ところから一章。
- 巨神の順番は「前の心臓を止めた人から先へ」（10）なので、章の順番もこれに従う。
- 五章から終章は今は枠だけ。巨神編の型（4.1）で作る。

### 4.1 章の数え方と、全章に共通の型

**章は個人の進み**。段階（止めた心臓の数。10 の 3.1）と序章を終えたかから導く。保存は増やさない。巨神の出現は今まで通りワールドの進みで決まる。遅れて入った人は自分の章から始まり、前の章の小要素は遠景として歩いて見られる。予兆の拍は人ごとに数える。

| 章 | 開く時点 | 閉じる時点 | 段階 | 上限（着いたとき） | 目安の Lv |
| --- | --- | --- | --- | --- | --- |
| 序章 | 目覚め（B0） | 夜 1 の足音（B6） | 0 | 15 | 日 1 の終わりで 3〜4 |
| 一章 | 日 2 朝、イサナと会う（B7） | 岩鯨の心臓を止める | 0 | 15 | 初回クリアで 9〜12 |
| 二章 | 岩鯨の心臓を止める | 潮殻の心臓を止める | 1 | 21 | 初回クリアで 15〜18 |
| 三章 | 潮殻の心臓を止める | 雷翼の心臓を止める | 2 | 27 | 初回クリアで 21〜24 |
| 四章 | 雷翼の心臓を止める | 余燼の心臓を止め、天の鍵がそろう | 3→4 | 33（止めたあと 40） | 着いたとき 27〜31 |
| 五章 | 天の鍵が下を指す | 未着手 | 4 | 40（50 へ広げる） | — |

- 長さの目安（試遊で調整）: 序章 25〜30 分、一章 90〜120 分、二〜四章は各 2〜3 時間（周回を含まない初回）。
- レベルの上限は変えない（段階 0〜4 の 15・21・27・33・40）。章の小要素の経験値は 1 章あたり「そのときの 1 レベル分の 1〜1.5 倍」までに抑え、上限を超えさせない（L→L+1 は 50 + 25k + 2k²。Lv 18 で約 1,050）。

**全章の型**（巨神編の各章はこの部品を一通り持つ。部品の中身は章ごとに違う）

| 部品 | 中身 |
| --- | --- |
| 題字と余韻 | 開くとき画面の札に「一章　空を泳ぐもの」。閉じるとき「章の終わり」の札と語り部の一言（18 の `Notice`。チャットには流さない） |
| 小要素（3〜5 つ） | 章が開いたときに、**その人の拠点**（ベッド、なければ復活地点、なければ今の位置）を基準に、扇形の 3 方向へ置く。ワールド生成時には置かない。経験値は上の枠内 |
| 予兆 3 拍 | ①痕跡 → ②間接（音・動物・水）→ ③一部。前の心臓を止めた直後から始まり、巨神が現れる前に済む。人ごとの段階で数える。見せるのは跡・音・小さな異変だけで、敵とジャンプスケアは足さない |
| 前の私の足取り | 章ごとに 1 頁、巨神の予兆の場所に前のループの自分の頁が落ちている。筆跡が自分に似る（語り部の「この字、どこかで見た気がする」と同じ方向） |

| 暮らしの変化 | 章ごとに村と語り部の何か一つだけが変わる（塩の匂い、風見鶏、灰、井戸の温かさ）。建築は触らない |
| 縁の音 | 合成音だけの予兆（遠い貝、風に逆らう雷、地の底のうなり） |
| 中盤の出来事 | 章に 1 つ。巨神が地上にいる間の見せ場 |
| 空の異変の段 | 章ごとに空の異変を 1 段強める（月の近さの仮の値に足す） |
| 試練・心臓 | 背中の三つの試練 → 中ボス → 心臓（4.3。各巨神の書類） |
| 余韻と引き | 心臓を止めたあとの一幕と、次の章の 1 拍目（痕跡）を置いて閉じる |

- 既存のワールドでも効く。段階が先に進んだセーブは、導いた章がそのまま今の章になり、前の章の予兆は出ず（`Foreshadow.fireForCurrentChapter` は今の章の拍だけを調べる）、小要素は今の章の分だけ最初のログインで置く。すでに遊んでいた人（伝承・好感度・クエストの記録がある、または巨神を止めた段階が 1 以上）には題字の札を出さず、先の章で始めた人には前の章の札を出さずに今の章の札だけを一度出す（自己テスト `story` の移行の項）。
- クエスト・会話の追加ファイルは各章に `quest/ch1〜ch4`・`dialogue/ch1〜ch4` がある。

**まだ作っていない**（正直な一覧）

- 章ごとの「見る者の向き」（夜、遠くの見る者がその章の巨神の方角を向く）。一章の担当が「別の担当に残す」とした
- 章ごとの「縁の音」を独立した部品としては作っていない（予兆の拍と小さな異変の中の音だけ）
- 章ごとの「暮らしの変化」は四章（寝床のまわりの温かさ）だけ。ほかの章（塩の匂い、風見鶏など）は、小要素の置き物として持つが、村と語り部の変化としては未着手
- 「前の私の足取り」の頁は、各章に筆跡が自分に似る頁を置いたが、章ごとに必ず 1 頁という保証（検査）はまだない
- 背の外の探索の頁（一章 3・四章の火の井戸まわり）は、二章の浜の碑・三章の風の碑のようには揃っていない
- 小要素・中盤の出来事・夜の浮上の見え方は、ゲーム内で人が通して見ていない（自己テストは登録・条件・段階・ブロックが変わらないことまで）
- 五章以降（深淵・月・雲海）の中身と、巨神の見た目の拡大（試遊のあとに判断）

実装は序盤の拍子（B0〜B10。17）、各章の型（一〜四章）、巨神 4 体・背中・天の鍵（`story/SkyKey`）まで。コードや伝承の ID の `chapter1` は巨神編の全体を指す（伝承の章は一〜四章に振り分け済み）。

### 4.2 各章の型

大きくするのは存在感・予兆・出来事・背の外の探索・NPC の筋まで。巨神のモデルや背中の島の拡大は、試遊のあとに巨神ごとに判断する。**四つ目の試練は足さない**。

**序章「空の影」**（日 1。Lv 1〜5）

- 主題: ここは何かおかしい。人がいない。
- 小要素（日 1 に限る）: 初日のお使い 2 本（宿りに着いた直後。積み石の見回りと薪集め）、旅の跡（野営地から 150 ブロック以内に 3 つ以上、扇形 3 方向）、帰る場所（宿りのベッドとかまど）、小さな異変の束（日 1 は 1 つ）。
- 山場: B4 最初の空の影、B6 夜の足音。
- 余韻: 朝、語り部が「昨日の足音の話を、来る人にする」。目的の帯が「鯨追いを探す」に変わる。
- 引き: 村外れの焚き火の煙（一章 B7）。

**一章「空を泳ぐもの」 岩鯨**（Lv 4 → 12、上限 15）

- 主題: 見えないものが、痕跡から全身へ近づく。ホラーの順番（7）を章ぜんぶで一回りする。
- 小要素: 見張りの丘（高台の望遠鏡。夕方に雲の影の端が見える）、歌石（地上に 5 つ。順に叩くと 5 つ目で宿りの鐘が応える。数え歌の先取り）、失せ物の旅人（荷車の持ち主を探す頼み。日記の頁の筆跡が自分に似る）、歩哨の巡回（骨の歩哨が夜だけ骨の丘の近くを歩く）、破れた頁の散布 12 枚。ほかに毎日 1 つの小さな異変、見る者の向き、縁の音。
- 存在感: 日 2 骨（B8）→ 夜 2 歌（B9）→ 日 3 夕方に尾びれ（B10）に、雲の下の影が一度だけ地面を横切る（岩鯨の体の影。巡礼者の影と形と濃さで区別する）。
- 中盤の出来事: 岩鯨が初めて降りるとき、ちょうど空の影（巡礼者）が通る。**岩鯨が歌をやめ、世界が静かになる**。影が去ると鎖が降りる。
- 背の外: 背の飾りの外側に碑と頁を足し、体の中に入らなくても読める話を 3 つ。
- NPC の筋: イサナ。追う理由を語りはじめる（ほのめかしのみ。鯨骨の船長の日誌と繋がる）。
- 試練・心臓: 背の三つの試練 → 番兵長 → 岩鯨の心臓（[02](02_stone_whale.md)）。
- 余韻: 心臓が止まると岩鯨は空へ戻り、歌が一節だけ欠けて鳴る。碑文「この鼓動は地の底から預かったもの」。
- 引き: 夜、風に潮の匂い。干潟に足跡（二章の予兆 1 拍目）。

**二章「引く海」 潮殻**（Lv 12 → 18、上限 21）

- 主題: 待つ・読む。島が昨日と違う場所にある。
- 導入: 心臓を止めた翌朝、宿りの井戸の水が少ししょっぱい。
- 予兆 3 拍: ①干潟の足跡と塩の積み石 → ②遠い貝の音、海鳥が一方向へ飛ぶ → ③沖の島が昨日より動いている、甲羅の縁が水の上に出る。
- 小要素: 潮見の貝（[08](08_tide_shell.md) の 2.6。海辺で呼べて、巨神の方角を示す）、漂着の荷（箱と頁 1 枚）、浜の潮の民の碑（地上で読める 3 枚）、塩の積み石の謎（積み石の高さで干潮の刻を知る）。
- 存在感: 一日二回の干潮の刻に、浅瀬へ寄る姿を遠くから見られる。
- 中盤の出来事: **大干潮**。巨神が現れて最初の夜、海がいつもより遠くまで引き、浅い海底に遺跡の道が現れる。人ごとに一度ずつ（二章の人それぞれに自分の大干潮が来る。近くの人とは共有）、安全に歩ける（水は膝まで）。道の先に潮の民の頁。
- 背の外: 甲羅の上の探索に、潮鳴り石の頁と眺めの場所を足す。
- NPC の筋: 語り部。村の記憶が語られ、帳面の字が自分の筆跡に似ていると気づきはじめる。
- 試練・心臓: 甲羅の三つの試練 → 潮招き → 潮殻の心臓（[08](08_tide_shell.md)）。
- 余韻: 潮が戻り、水の底で何かが「下から押している」と碑が言う。
- 引き: 遠くの嵐が風に逆らって動く（三章の予兆 1 拍目）。

**三章「風に逆らう嵐」 雷翼**（Lv 18 → 24、上限 27）

- 主題: 見誤り。「あれは空の影か?」（[12](12_thunder_wing.md) の 1.2）。
- 導入: 翌朝、風が逆向きに吹く。風見鶏が逆を指す。
- 予兆 3 拍: ①一直線に焼けた岩・倒れた木の筋 → ②動物が低く伏せる、遠雷 → ③嵐の稲妻に一瞬だけ翼の形。
- 小要素: 風見鶏の丘（いちばん高い峰が止まり木の候補。望遠鏡で嵐を追う）、雷に焼かれた旅の荷（頁 1 枚）、避雷の塔の跡（バニラの避雷針で避雷の柱の使い方を先に教える）、風の碑（地上で 3 枚）。
- 存在感: 嵐の通り道が日ごとに近づく（3 日かけて）。巨神は嵐の中にいて、稲妻の光でだけ姿が見える。
- 中盤の出来事: **巨神が影から隠れる**。巡礼者の影が通るとき、雷翼が峰に降りて翼で頭を覆う。影と巨神を同時に見て、巡礼者の大きさを初めて知る。巨神編でいちばんスケールの大きい場面。
- 背の外: 「羽根の門」の周辺に外の探索（風の民の頁 3 枚）。
- NPC の筋: イサナ。追う人から見送る人へ。夕立の刻に峰で一緒に待ち、乗るのは自分だけだと決める。
- 試練・心臓: 風切り・雷・眼の三つの試練 → 雷獣 → 雷翼の心臓（[12](12_thunder_wing.md)）。
- 余韻: 嵐が割れ、一瞬だけ空が晴れる。雲の上にあの影がいたことを、見る者が空に向かって立つことで示す。
- 引き: 畑の向こうの丘が少し近づく。灰が降る（四章の予兆 1 拍目）。

**四章「足もとから来るもの」 余燼**（Lv 24〜27 → 30、上限 33、止めたあと 40）

- 主題: 下。空の恐怖が足もとの恐怖に反転する（五章への橋）。巨神編の山場で、余韻がいちばん長い。
- 導入: 翌朝、地面が温かい。雪が円形に溶ける。
- 予兆 3 拍: ①灰が降る範囲・地面の温かさ → ②地の底のうなり、井戸水がぬるい → ③丘が昼に動く。
- 小要素: 温石（[13](13_ember.md) の 2.6。作ってある）、灰の民の炉跡（頁 1 枚）、灰降り観測点（灰の濃さの地図が控え帳に出る）、足もとの温かさ（自分の拠点の下だけ温かい。建築は触らない）。
- 存在感: 灰の降る円が日ごとに広がり、最初の夜に初めて浮上して眠る。
- 中盤の出来事: **夜の浮上**。丘が持ち上がって巨神の形になり、地面が一度だけ揺れる（見た目は粒と音。ブロックは崩さない）。眠った巨神の口が息に合わせて開く様子が、乗り込みの前に見られる。
- 背の外: 火の井戸・背の飾りに外の探索と頁。
- NPC の筋: 語り部とイサナ。鍵が一つだったこと、四つの欠片を持つ意味を二人が別々に語る。
- 試練・心臓: 灰の道・鍛え・火守りの三つの試練 → 灰の鍛え手 → 余燼の心臓（[13](13_ember.md)）→ 天の鍵がそろう場面（`story/SkyKey`）。
- 余韻: 巨神編の終わり。第五の詩、鍵が空ではなく足もとを指す。語り部が最後の一言。
- 引き: 鍵の指す方へ掘ると鼓動が聞こえる（五章。ベータはここまで）。

**五章 深淵・六章 月・終章 雲海**: 中身は 3・7・14 のまま。巨神編の型（題字・予兆 3 拍・中盤の出来事・余韻）を使い、五章の入口を四章の引きと繋げる。

### 4.3 巨神編の巨神

巨神は**決まった順に目を覚ます**。前の心臓をワールドの誰かが止めると次が現れ、乗れるのは自分で前の心臓を止めた人だけ。物語の進みでレベルの上限が決まる（15・21・27・33・40）。順番と上限はゲームルールで切れる（[10](10_progression_multiplayer.md)）。

| 順 | 章 | 巨神 | 姿 | 乗り方 | 推奨 Lv | 中ボス | 書類 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 一章 | 岩鯨 | 空を泳ぐ岩の鯨 | 垂れた鎖を右クリック | 12 | 鯨骨の番兵長 | [02](02_stone_whale.md) |
| 2 | 二章 | 潮殻の巨神 | 珊瑚礁を背負う大亀。海を歩く | 潮門 | 18 | 潮招き | [08](08_tide_shell.md) |
| 3 | 三章 | 雷翼の巨神 | 嵐をまとう鳥 | 昇り風 | 24 | 雷獣 | [12](12_thunder_wing.md) |
| 4 | 四章 | 余燼の巨神 | 地の中を泳ぐ熾火の蜥蜴 | 口 | 30 | 灰の鍛え手 | [13](13_ember.md) |

**全巨神に共通の決まり**

- 背中のダンジョンは巨神の外見と同じ形にし、試練・広間・心臓の間は体の中に埋める。
- 構成（順路。[32](32_titan_raid_route.md)）: 三つの試練を歩 → 智 → 闘の順に一つずつ越える（アスレ・戦い・謎解きや水路など）→ 中ボス → 心臓。試練の形は毎回少し変わる。
- 何度でも挑める。背中に誰もいなくなってしばらくすると、仕掛け・広間・宝箱が元に戻る。欠片は一人一つ。
- **心臓を止めたあと（巨神の眠り。`titan/end`、各巨神の書類の「眠り」の節）**: 心臓の倒れる演出と報酬のあと、短い静けさ → 背中が震える → 約 9.5 秒後、**戦った人（参加者）とそのパーティの人（同じ背中にいる人だけ）**が、暗転のなか巨神に「吐き出され」、巨神の足もとの安全な地面へ降ろされる（岩鯨 = 影の下の地面、潮殻 = 浜、雷翼 = 眠る峰の足もと、余燼 = 丘のかたわら。ブロックの中・水の中・溶岩・木の上には降ろさない）。戦わなかった人は背中に残る（人ごと・パーティごと。マルチでも安全）。
  - 初めて止めた人（その巨神の `titan_end_<巨神>` を見ていない人）には、地上から眠りを見る場面（約 16 秒、スキップ可。[20](20_cinematics.md) の 3.4）。そのあとに章の余韻の札と、次の章の引き（[18](18_notices.md) の 9 章）。二回目からは場面なしで、運び出しと一行の字幕だけ。
  - 巨神は眠っているあいだ（最短 90 秒。あとの二つの条件がそろうまで）、動かず・歌わず・光らず、乗り込み口は消える（鎖は巻き上がり、潮門は出ず、昇り風は立たず、口は開かない）。呼び笛にも応えず、乗ろうとすると「深い眠りの中にいる」と断る。目覚めると動きだし、背中の「…の心臓が、再び脈を打ち始めた」で試練の復活が伝わる。
  - **眠りは世界に一つ、でも中のグループは続けられる**: どれかのグループが心臓を止めると、巨神は元の世界から去り（眠りの姿）、新しく乗ることはだれにもできなくなる（乗り込み口の光が消え、乗ろうとすると「元の世界から去って、深い眠りの中にいる」と断る）。すでに背中にいるグループは何も変わらず、試練・中ボス・自分の心臓をそのまま続けられる。止めれば同じ報酬・欠片（一人一つ）・運び出し・初めてなら眠りの場面で、降ろされるのは巨神が眠っている所（降ろす先は巨神ごと）。眠りは数え直さない。巨神が目覚めるのは、最短 90 秒を過ぎ、かつ背中の中で続けているグループが一つもなくなったあと（10 の 10.4）。眠りと目覚めの時刻は保存され、再起動をまたぐ。
- **乗り込み口の光（全巨神共通）**: 岩鯨の鎖・潮殻の潮門・雷翼の昇り風・余燼の口が、**乗る資格のある人にだけ**、遠く（220 ブロック）から見えるほのかな脈打つ光と粒を出す（人ごとに粒を送る。ほかの人の画面は変わらない）。資格がない人・巨神が眠っているあいだは出ない。実装は `titan/end/BoardGlow`。
- **乗り込みの一言と確認（全巨神共通）**: 乗り込み口に触れると、乗る資格のある人にだけ備えの三灯（身・刃・糧）の一行が出る。赤が一つでもあれば、一度は乗らず「このまま乗る？」を出し、5 秒以内の二度目（鎖は右クリック、潮門・昇り風・口は出て入り直す）で乗る。ふさがない確認で、赤でも乗れる。実装は `readiness/BoardReadiness`（11 の 9 章）。
- 背中ではサバイバルのブロック設置・破壊と、近道（水バケツ・エンダーパール・ウィンドチャージ・花火など）を禁止。
- 背中で倒れても持ち物と経験値を失わず、直前の休み場から再開する（背中の次元だけの例外）。
- 敵はすべて新しいキャラ。壁をすり抜ける敵は使わない。
- ピースフルでは試練を祠で封じ「巨神は目覚めない」と伝える（島を歩く・乗ることはできる）。
- 文字を刻むのは碑文と試練の入口の一言だけ。バニラの看板は置かず、石の碑（`skyabyss:tablet`、[19](19_advancements_and_tablets.md)）にして、目を向けるか右クリックすると画面の字幕に文が出る。使い方は形・光・音と最初の一度だけの囁きで伝える。
- 報酬は周回で集める（個人抽選・天井。[03](03_gear_and_endgame.md)）。

### 4.4 ラスボス「雲上の巡礼者」

- 全身は画面に収まらない。手・目・胸の核など部位ごとに戦う。遠景は簡易モデル、近景は部位モデル。
- 第 1 形態: 雲の下から伸びる巨大な手。足場の雲を削る。
- 第 2 形態: 雲が割れて目が現れる。視線に入るとデバフ。
- 第 3 形態: 月を引き寄せ時間が乱れる。攻撃が巻き戻る。過去の自分の幻影（見る者たち）が加勢する。
- 裏ボスは別の題材（未定）。

## 5. ループ

**月の落下はゲームオーバーではなく、物語だけを巻き戻す「章の時限」。** 地形と建築は巻き戻さない。

| 巻き戻るもの | 残るもの |
| --- | --- |
| 月の位置（初日の大きさ） | 地形、建築物、拠点 |
| 章内のストーリーイベント | レベル、ステータス、技 |
| NPC の状態・会話フラグ・好感度（好感度は今は 0 に戻す。会話の印は「記憶」として残り、次のループの最初の会話で NPC が既視感を口にする） | 記憶の断片（永続強化） |
| 一部ダンジョンの宝箱と仕掛け | 攻略済みの章とボス、巨神の記憶（天井）と図鑑 |
| 一部のクエストアイテム、`loop_reset` を付けた未完のクエスト | 装備と持ち物、伝承の書の記録 |

- 1 ループはゲーム内 7 日（設定で変更可）。月は毎夜大きくなり、7 日目の夜に落ちる。落ちると全画面の演出のあと、リスポーン地点で「初日の朝」。
- ループを重ねるほど NPC のセリフが変わり、選択肢が開く。月の落下を遅らせる道具や儀式がある。
- 序章ではループは起きない。初めて落ちるのは 巨神編の途中（ベータでは落とさない）。
- マルチでは全員が同じループを共有する（サーバーで一つの月）。
- 今あるのは器だけ: ループの回数 `WorldLoop`（今は 0）と、それを読む会話の条件。月が落ちたら `WorldLoop.advance` を呼ぶと会話の印が記憶へ移る。成長・技・伝承の記録にはループの処理から触れない。

## 6. RPG の柱

どれもバニラの仕組みを置き換えず、上に足す。強くなる実感の主役は装備と共鳴の炉の強化で、ステータスと技は下支え（どれか一つで攻略が決まらない）。

**成長**（[04](04_growth_and_skills.md)）

- レベル上限 50（物語の進みで 15〜40 に縛る）。経験値はバニラの XP と別。L→L+1 に **50 + 25k + 2k²**（k = L − 1）。Lv 10 までに 1,758、50 までに 107,898。
- 入り口: 背中の敵、ボス（初回は上乗せ）、試練の踏破、初めての場所、バニラの敵（日ごとの上限 100）、クエスト。
- マルチ: 道中の敵は近く（32 ブロック）の人で分ける（一人増えるごとに全体 +25%）。ボスは参加者それぞれに満額。パーティで分け合う（[10](10_progression_multiplayer.md)）。
- 上がりすぎの補正: 推奨 Lv +3 を超えると 1 レベルごとに取り分 −10%（最低 20%）。
- ステータス: 筋力・敏捷・精神・耐久。1 レベルにつき力 3（Lv 50 で 147）、一つ 50 まで。筋力 1 で近接 +0.6%、敏捷 1 で移動・攻撃の速さ +0.2% と射撃 +0.4%、精神 1 で最大マナ +2、耐久 2 で最大体力 +0.5。振り直しは共鳴の炉のそばで結晶（初回無料）。
- 記憶の断片: ループをまたぐ永続強化。器（はじめ 12）だけあり、効果の枝を決めるまで渡さない。

**クラスと技**（[04](04_growth_and_skills.md)）

| 木 | 効果の元 | 技 | 解放 |
| --- | --- | --- | --- |
| 剣士 | 筋力 | 巨神斬り、返し刃、踏み込み、岩の構え、鯨尾薙ぎ | 最初から |
| 弓使い | 敏捷 | 雲穿ち、遠矢の心得、跳び退き、鷹の目、天の驟雨 | 最初から |
| 星術師 | 精神 | 未定 | 六章（封じた枠だけ） |
| 深淵術師 | 精神・耐久 | 未定 | 五章（封じた枠だけ） |

- クラスは選ばない混合型。技の点はステータスと別に、Lv 1 と奇数のレベルごとに 1（50 で 25）。一つの木は 13 段なので二つは極められない。
- 各木に使う技 3・常に効く技 2（3 段）。使う技はホットバーと別の 4 枠（R・G・V・Z）。マナは素の 20 + 精神 ×2、1 秒に 0.4 + 最大の 2%（静かなとき 2.5 倍）。
- 技は敵にだけ当たり、ふつうの攻撃に上乗せする。回復・無敵・耐性の技は作らない。

**装備**（[03](03_gear_and_endgame.md)）

- レアリティ: コモン（白）→ アンコモン（緑）→ レア（青）→ 伝説（金）→ 神器（紫）。
- 特性（ランダム効果）はレア以上の武器と防具だけ（11 種、割合が中心）。
- 専用装備は周回で集める: 参加者ごとの個人抽選、巨神の記憶（天井）、初回クリアの選択報酬、共鳴の欠片での交換。
- 共鳴の炉: 強化（+10 まで）、分解、特性の再鍛造、交換。
- 全装備に必要 Lv（推奨 Lv からレア以下 −4、伝説以上 −2）。装飾品は専用の枠（護符 1・装飾 2）、護符は H キー。
- 巨神ごとに立体の防具と武器（防具の決まりは [16](16_armor_design.md)）。神器は七つの心核から作る。

**NPC とクエスト**（[07](07_npc_quest.md)）

- mod の村人は独自エンティティ（バニラの村人は残す）。鐘の宿り・村の鐘のそばに「語り部」、メインの途中で焚き火とともに「鯨追いのイサナ」。役名で呼び、何度も出会う重要人物だけ固有の名前。傷つかない。
- 会話画面（顔アイコン・表情・選択肢）。サーバーが進めるデータ駆動で、クエスト・好感度・伝承・ループ回数・見る者に気づいた回数で分岐する。
- メインクエスト（序章〜天の鍵）、サブクエスト、自由なモードの依頼。目的は伝承の書の記録で数えるので、順番を外しても詰まらない。

**探索と記録**

- 伝承の書（[05](05_lore_npc_quest.md)）: 碑文・破れた頁・出来事・NPC の話で記される。本文はほのめかしだけで答えは書かない。プレイヤーごとで、死んでもループでも消えない。
- 控え帳（[11](11_record_screen.md)）: 巨神の進み（巨神の頁の「順路」の行を含む）、大事な品の在りかと呼び戻し。
- 移動は「巨神に乗る」（[09](09_titan_travel.md)。岩鯨と潮殻）。

**知らせ**（[18](18_notices.md)）: チャットに流さず、語りは画面下の字幕、レベルアップは中央の演出、獲得は右上の札、今の目的は「目的の帯」。流れた知らせは N キーで読み返せる。

## 7. ホラーの原則

**怖さは「世界がいつもと違う」ことから生まれる。** 敵を出すより、音が消えるほうが怖い。

- **順番**: ①痕跡（足跡・骨・削れた地面）→ ②間接（影・音・地鳴り・動物の怯え）→ ③一部だけ → ④巨神。全身は見せない。
- **引き算**: 動物が鳴き止む、BGM が途切れる、風が止まる。
- **頻度を絞る**: 同じ演出は数日空ける。一度に一つ。拍子の間は静か。
- **段階的に強める**: 月が近づくほど、章が進むほど異変が増える。
- **殺さない**: 演出にダメージ・拘束を含めない。戦闘中・体力が低いときは後ろへずらす。
- **自分だけが見る**: 見る者は見せる一人の画面にだけ現れる。
- **弱められる**: サーバー `horrorEventFrequency`・`watcherFrequency`、クライアント `screenShake`・`screenEffectStrength`・`watcherVisible`。

| 演出 | 発生 | 章 | 状態 |
| --- | --- | --- | --- |
| 序盤の拍子（暗転と題字、野営地、煙と鐘、足跡、夜の足音、骨の丘、星の欠け） | プレイヤーごとの状態で必ず起こす | 序章 | 実装済み（[17](17_opening_and_rpg_feel.md)） |
| 雲上を通る翼の影。切れ間から暗い姿、その人の周りだけ天気が荒れる、地鳴り | 晴れた昼・屋外 | 序章〜 | 実装済み（[06](06_prologue.md)） |
| 動物と村人がうずくまって震え、空を見上げ、鳴き止む（見た目だけ） | 影の通過中 | 序章〜 | 実装済み |
| 見る者（近づく・見つめ続ける・目を離すと消える。現れると音楽と動物の声が止む） | 夜、一人で屋外（数日おき） | 序章〜 | 実装済み |
| 山頂が削られる（プレイヤー建築は対象外） | 巨神編に入った人の近くを影が通ったあと | 一章〜 | 実装済み（[06](06_prologue.md)） |
| 雲の切れ間の巨大な目 | 月が半分以上近づいた夜（月の近さは M4 まで日数の仮の値） | 一章〜 | 実装済み（[06](06_prologue.md)） |
| 心臓の鼓動、並走する足音、閉じるトンネル、消える松明 | 深い地下・深淵 | 五章 | 未着手 |

## 8. アートの基準

**4D スキン級の立体感を、マイクラの世界から浮かない解像度で。** モデルとテクスチャは Claude が作り、ユーザーがゲーム内で確かめて直しを頼む。

| 項目 | 基準 |
| --- | --- |
| テクスチャ | 1 ブロック幅 = 32 px（バニラの 2 倍）。巨大ボスも GUI も同じ密度。アイテム・ブロックは 32×32 |
| 形 | 骨の階層を持つキューブのモデル。角・マント・浮く部品でシルエットを崩す。キューブは重ならない。ベータの後、全モデルを細かいキューブでハイポリ化した（[15](15_high_poly.md)） |
| アニメ | 待機・移動・攻撃・被弾・死亡の 5 種以上。ボスは形態変化も |
| 発光 | 目・核・模様を発光テクスチャで |
| PBR | 主要モデルとブロックに `_n`・`_s` |
| 色調 | 地上＝自然色、深淵＝深紅と黒、月＝青白と銀、雲海＝金と白。碑文・伝承・技の光は淡い青と青緑 |
| 巨大モデル | 遠景は簡易モデル、近景は部位モデル（LOD） |
| 武器 | 敵のモデルとは別に作る |

**作り方**: スクリプトで `.geo.json`・`.animation.json`・PNG を生成（Blockbench 用の `.bbmodel` も）→ ラフを 3 案並べて比べ、1 つを選んで仕上げる（比較ページ、`docs/review/`）→ ゲームの暗さと距離で見て直す（見る者の最初の案は夜にエンダーマンに見えた）。
