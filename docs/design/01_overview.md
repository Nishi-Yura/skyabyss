## ブレない軸

**コンセプト：見えない巨大なものに怯える静かなホラーが、世界の謎を解くRPGに変わっていく。** 最後に「それ」と雲の上で対峙する。

迷ったときは次の5つに照らして判断する。

1. **見せない恐怖が先、戦いは後。** 巨大な存在は序盤では影・音・痕跡でしか出さない。全身は最後まで見せない。
2. **壮大さは「スケール」と「光」で出す。** 空の広さ、巨神の大きさ、月の近さ。シェーダー環境で最大限に映えるように作る。
3. **マイクラらしさは壊さない。** 建築や拠点づくりは守る。ループで巻き戻すのは物語だけで、プレイヤーの建築は残す。
4. **RPGは「強くなる実感」と「謎が解ける快感」を両立させる。** レベルを上げるだけのゲームにはしない。
5. **一人で完成させられる範囲で作る。** 縦切り版を最初に完成させ、章を1つずつ足していく。

**やらないこと**

- ジャンプスケア（急に大きな音と顔が出る演出）に頼ること
- 序盤から巨大ボスと戦わせること
- プレイヤーの建築物を消す、巻き戻すこと
- バニラの戦闘やクラフトを大きく作り変えること（足すのはよいが、置き換えない）

## 技術仕様

対象は **Minecraft Java 1.21.1 + NeoForge**。一人で開発する。

| 項目 | 採用 | 理由 |
| --- | --- | --- |
| Modローダー | NeoForge（1.21.1） | 情報が多く、大規模Modの実績がある |
| Java | JDK 21 | 1.21.1の動作に必須 |
| モデル・アニメ | GeckoLib | Blockbenchで作った高密度モデルとアニメを動かせる。立体防具にも使える |
| データ管理 | Data Attachments / SavedData | レベル、ステータス、ループ状態を保存する |
| 地形・構造物 | Datapack（worldgen JSON）+ Structure | 巨神の背やダンジョンをNBT構造物で置く |
| ディメンション | 独自ディメンション ×3（＋巨神の背） | 深淵、月、雲海。巨神の背中の島も専用ディメンション（岩鯨の背は実装済み） |

**シェーダー方針（Vibrant Visualsについて）**

- Vibrant Visualsは公式の新グラフィックスで、Java 1.21.1には入っていない。そのため直接の対応はできない。
- 代わりに **Iris（NeoForge版）+ シェーダーパック** で同じ方向の見た目を狙う。動作確認は Complementary Shaders を基準にする。
- Modのテクスチャは **LabPBR形式** の法線マップ（`_n`）とスペキュラーマップ（`_s`）を添える。光沢、凹凸、発光がシェーダー上で再現される。
- **シェーダーなしでも成り立つこと**を必須にする。影や空の演出はエンティティとパーティクルで作り、シェーダーは上乗せとして扱う。
- 将来Java版にVibrant Visualsが来て、そのバージョンへ移行する場合は、PBRテクスチャを流用して対応を検討する。

## 世界観と物語

世界は、空の「巡礼者」と地の底の「心臓」が引き合うことで保たれている。心臓が弱り、巡礼者が降りてくる。その兆しが、近づいてくる月である。

| 存在 | 正体 | プレイヤーからの見え方 |
| --- | --- | --- |
| 雲上の巡礼者 | 空を統べる古き神。月を引きずって空を飛ぶ | 雲の上を通る翼の影、羽ばたきの音、削られた山頂。全身は最後まで見えない |
| 止まった月 | 巡礼者の降臨の兆し。内部に時間を縛る核がある | 毎夜少しずつ大きくなる。落ちると物語が巻き戻る |
| 深淵の心臓 | 世界を地上につなぎとめる錨。弱っている | 深く掘るほど大きくなる鼓動。壁の向こうの足音 |
| 巨神たち（4体） | 心臓が生んだ守護者。心臓から分かたれた鼓動を体の奥に抱えて守る。背中に滅んだ古代文明を乗せている | 空や海をゆっくり泳ぐ・歩く山のような生き物。体の奥で、何かが脈打っている |
| 見る者 | 前のループの自分（留まる者）が残した影。3 章で気づく（06 の 8.1節） | 夜、一人で外にいると、遠くの丘に自分に似た人影が立ってこちらを見ている。目を合わせると消える |

**分かたれた鼓動（巨神の心臓）**

- 深淵の心臓は、弱りはじめたころに自分の鼓動の一部を分け、四体の巨神に一つずつ預けた。巨神はその鼓動を体の奥に抱え、守っている。
- 巨神の体の奥で脈打つこの鼓動を「巨神の心臓」と呼ぶ。**巨神の心臓が、その巨神の守護者である。** 1章で各巨神の最後に戦うのはこれで、第一の巨神では「岩鯨の心臓」になる。
- 天の鍵の欠片は、背中の民が鼓動のそばに納めたもの。巨神の心臓が止まると、はじめて手に取れる。
- 「心臓」という同じ言葉は、深淵の心臓への伏線として使う。1章ではつながりを説明しない。背中の碑文が「この鼓動は地の底から預かったもの」とほのめかすだけにする。2章で深淵の心臓の前に立ったとき、プレイヤーが「あの鼓動は借りものだった」と気づく形にする。
- 巨神の心臓を止めたことが深淵の心臓にどう響くか（鼓動が還るのか、失われるのか）は、2章で明かす。ここでは決めない。伝承の書の「止まった鼓動」は、心臓を止めたあとに何が起きたかを書かず、「この鼓動はどこから来て、どこへ行ったのか」という問いで終える。前にあった「地の底から遅れて一つだけ拍が届く」描写は消し、2章の決定後に書き足す（00 の 12、05）。

**主人公：「留まる者」**。月が落ちて時間が巻き戻っても、記憶を保てるただ一人の存在。なぜ記憶が残るのかは、物語の核心の謎にする。伝承の書の最初の頁（「忘れないうちに書け。次は、もっと早く気づけるように」）、宝物庫の碑文の「留まる者が来る」、語り部の「この字、どこかで見た気がする」が、同じ方向をほのめかす。

**物語の流れ**

1. 地上で異変に気づく（空の影、村の語り部と言い伝え、見る者）
2. 巨神の背を巡り、体の奥の心臓を止めて「天の鍵」の欠片を集める
3. 深淵へ潜り、心臓が弱った理由と、巨神に分けた鼓動の意味を知る
4. 月へ渡り、ループの仕組みと主人公の正体を知る
5. 雲海で巡礼者と対峙する

**エンディング分岐（3種）**

- **鎮める**：心臓を癒し、均衡を取り戻す（王道エンド）
- **壊す**：心臓を破壊し、巡礼者を封じる。代償として世界が変容する
- **受け入れる**：巡礼者を地上に招き、新しい世界の始まりとする（隠しエンド、条件付き）

**ラスボス「雲上の巡礼者」の設計**

- 全身は画面に収まらない。手、目、胸の核など、部位ごとに戦う
- 第1形態：雲の下から伸びる巨大な手。足場の雲を削り取る
- 第2形態：雲が割れて目が現れる。視線に入るとデバフを受ける
- 第3形態：月を引き寄せ、時間が乱れる。攻撃が巻き戻ったり、過去の自分の幻影が加勢したりする。幻影は、これまでの「見る者」たち（前のループの自分）。ずっと遠くから見ていた影が、ここではじめて近くに来て一緒に戦う
- 裏ボスは別の題材にする（見る者は使わない。答えが第3形態と重なるため）。題材はあとで決める（00 の 64）
- 巨大さは「遠景の簡易モデル＋近景の部位モデル」で表現する

## ループシステム

**月の落下はゲームオーバーではなく、物語だけを巻き戻す「章の時限」として扱う。** ワールドの地形と建築は巻き戻さない。

| 巻き戻るもの | 残るもの |
| --- | --- |
| 月の位置（初日の大きさに戻る） | 地形、建築物、拠点 |
| 章内のストーリーイベント | レベル、ステータス、技（技の点・枠・マナ） |
| NPCの状態と会話フラグ、好感度。ただし会話の印は「記憶」として残り、次のループの最初の会話で NPC が既視感を口にする（07 の 4.5節） | 記憶の断片（永続強化） |
| 一部ダンジョンの宝箱と仕掛け | 攻略済みの章とボス撃破記録、巨神の記憶（天井）と図鑑 |
| 章内で得た一部のクエストアイテム、`loop_reset` を付けたまだ終えていないクエスト（今の 3 本は付けていない） | 装備とインベントリ、伝承の書の記録 |

**仕様**

- 1ループはゲーム内で7日（設定で変更可）。月は毎夜大きくなり、7日目の夜に落ちる
- 月が落ちると全画面の演出の後、プレイヤーはリスポーン地点で「初日の朝」を迎える
- ループをより重ねるほど、NPCのセリフが変化し、新しい選択肢が開く
- 月の落下を遅らせるアイテムや儀式で、時限を伸ばせる
- 序章ではループは起きない。初めて月が落ちるのは1章の途中とし、「何かがおかしい」という驚きにする
- マルチプレイでは全員が同じループを共有する（サーバー全体で一つの月）
- 今あるのは器だけ。ループの回数（`WorldLoop`、今は 0）と、それを読む会話の条件。月が落ちたときに `WorldLoop.advance` を呼べば、会話の印が記憶へ移る。成長・技・伝承の書の記録には、ループの処理から触れない（各書類の「ループの担当へ」）

## RPGシステム

RPG要素は5つの柱で構成する。どれもバニラの仕組みを置き換えず、上に足す形にする。強くなる実感の主役は装備と共鳴の炉の強化で、ステータスと技はその下支えにする（どれか一つで攻略が決まらない）。

**成長**（詳細は 04 の 2〜6章）

- レベル（上限50）。経験値はバニラのXPとは別に持つ。L→L+1 に要る量は **50 + 25k + 2k²**（k = L − 1）。Lv 10 までに 1,758、Lv 50 までに 107,898
- 経験値の入り口: 背中の敵（骨の番兵 12 など）、ボス（番兵長 100、岩鯨の心臓 300、初回は上乗せ）、試練の踏破 40、初めての休み場・ディメンション・バイオーム、バニラの敵（日ごとの上限あり）、クエスト（07）
- マルチプレイ: 道中の敵は近くの人で分ける（一人増えるごとに全体 +25%）。ボスは参加者それぞれに満額
- 上がりすぎの補正: 内容ごとに推奨レベル（1 章の巨神は岩鯨 12・潮殻 18・雷翼 24・余燼 30。攻略順は自由）を持ち、推奨 +3 を超えると 1 レベルごとに取り分が 10% 減る（最低 20%）。岩鯨の初回クリアは Lv 9 前後、図鑑を埋めるころ Lv 19 前後
- ステータス：筋力・敏捷・精神・耐久。1レベルにつき力を3つ振り分ける（Lv 50 で 147）。一つ 50 まで
  - 筋力 1 につき近接 +0.6%、敏捷 1 につき移動・攻撃の速さ +0.2% と射撃 +0.4%、精神 1 につき最大マナ +2、耐久 2 につき最大体力 +0.5
- 記憶の断片：ループをまたいでも消えない永続強化。ボス撃破や隠し要素で手に入る。今は器（はじめ 12）だけを作り、効果の枝は未定

**クラスとスキル**（詳細は 04 の 10章）

| 木（クラス） | 効果の元 | 技 | 解放 |
| --- | --- | --- | --- |
| 剣士 | 筋力 | 巨神斬り（大型敵への特効）、返し刃、踏み込み、岩の構え、鯨尾薙ぎ | 最初から（実装済み） |
| 弓使い | 敏捷 | 雲穿ち（貫通射撃）、遠矢の心得、跳び退き、鷹の目、天の驟雨 | 最初から（実装済み） |
| 星術師 | 精神 | 未定（例: 月光の障壁、時の遅延） | 3章（今は封じた枠だけ） |
| 深淵術師 | 精神・耐久 | 未定（例: 鼓動の衝撃波、影潜り） | 2章（今は封じた枠だけ） |

- クラスは選ばない。どの木にも技の点を振れる混合型にする。技の点はステータスの力とは別に、Lv 1 と奇数のレベルごとに 1（Lv 50 で 25）。一つの木は 13 段なので、二つの木を両方極めることはできない
- 各木に「使う技」3 つと「常に効く技」2 つ（3 段の木）
- 使う技は、ホットバーとは別の4枠（R・G・V・Z）に置いて使う。マナは独自ゲージ（素の 20 + 精神 ×2。1 秒に 0.4 + 最大の 2%、静かなときは 2.5 倍で満ちる）
- 技は敵にだけ当たり、ふつうの攻撃に上乗せする。回復・無敵・耐性の技は作らない（装備のアクティブ効果と重ねない）
- 技の振り直しは共鳴の炉のそばで（初回無料、以後共鳴の結晶 1〜5）

**装備**（詳細は 03）

- レアリティ：コモン（白）→ アンコモン（緑）→ レア（青）→ 伝説（金）→ 神器（紫）
- ランダム効果（特性）は、レア以上の武器と防具にだけ付く（レア 1〜2、伝説 2〜3、神器 3〜4 ＋固有）。コモン・アンコモンと、護符・護石・補強板のような持っているだけで効く品には付かない。11 種類で、値は割合が中心
- 専用装備は周回で集める。参加者ごとの個人抽選（取り合いにならない）、巨神の記憶（天井。新しい品の出ない撃破が 3 で確率 2 倍、5 で未所持の品を保証）、初回クリアの選択報酬、共鳴の欠片 30 での交換（心臓の撃破ごとに一度）
- 共鳴の炉：強化（+10 まで、+5 で覚醒）、分解、特性の再鍛造（結晶 1 で候補一組、3 組から選ぶか今のまま）、交換
- 巨神セット：巨神ごとに素材とセット効果が違う。観て分かる立体モデルにする（岩鯨の甲殻は一式で耐性 I）
- 神器：七つの心核から作る。専用スキル付き

**NPCとクエスト**（詳細は 07）

- このModの村人は独自エンティティにする（バニラの村人はそのまま残す）。最初の二人は、村ごとに鐘のそばに立つ「語り部」と、メインの途中で村の外れに焚き火をして現れる「鯨追い」。名前は付けず役で呼ぶ。傷つかない
- 会話画面（顔アイコンと表情 3 種、選択肢）。会話はサーバーが進めるデータ駆動で、クエスト・好感度・伝承の書・ループの回数・見る者に気づいた回数で分岐する
- 好感度：プレイヤー × NPC の役ごとに -100〜100。段階で呼び方と話題が変わる
- メインクエスト「雲の下の歌」（空の影から岩鯨の欠片まで 7 段）とサブクエスト 2 本。目的は伝承の書の記録で数えるので、順番を外しても詰まらない。クエストログ（U）と、画面左の追跡表示
- ループ前の会話を「覚えているような」NPC：ループで会話の印が記憶に移り、次のループの最初の会話で既視感を口にする

**探索**

- ダンジョンはパズル、トラップ、中ボスで構成する
- 書物や石碑を集めると「伝承の書」に登録され、世界の謎が少しずつ解ける。碑文を読む、破れた頁を読む、出来事に立ち会う、NPC の話を聞くと記される。本文はほのめかしだけで、答えは書かない。記録はプレイヤーごとで、死んでもループでも消えない（05）

## ホラー演出の原則

**怖さは「世界がいつもと違う」ことから生まれる。** 敵を出すより、音が消えるほうが怖い。

- **引き算**：動物が鳴き止む、BGMが途切れる、風が止まる
- **痕跡**：削られた山頂、巨大な足跡、引きずった溝、消えた松明
- **間接**：影、地鳴り、遠い音、壁の向こうの足音。本体は見せない
- **頻度を絞る**：同じ演出は少なくとも数日は空ける。慣れたら怖くなくなる
- **段階的に強める**：月が近づくほど、章が進むほど異変が増える
- **プレイヤーを即死させない**：演出で死なせない。怖さと理不尽を混同しない
- **設定で弱められる**：ホラー演出の頻度・画面揺れをコンフィグで調整できるようにする（サーバー: horrorEventFrequency、watcherFrequency。クライアント: screenShake、screenEffectStrength、watcherVisible）
- **自分だけが見る**：見る者は、見せる一人の画面にだけ現れる。ほかの人には見えない

**導入する演出の一覧**

## モデル・アート方針と品質基準

**4Dスキン級の立体感を、マイクラの世界から浮かない解像度で作る。** モデルとテクスチャはClaudeが制作し、ユーザーがBlockbenchとゲーム内で確認して修正を依頼する。

**品質基準**

| 項目 | 基準 |
| --- | --- |
| テクスチャ解像度 | バニラの2倍（1ブロック幅 = 32px）で統一。巨大ボスも同じ密度を守る。GUI も 2 倍密度 |
| 形状 | ボーン階層を持つキューブモデル。角、マント、浮遊パーツなどでシルエットを崩す。キューブは 0.5 単位で、重ならない |
| アニメ | 待機、移動、攻撃、被弾、死亡の5種を最低限。ボスは形態変化も |
| 発光 | 目、核、模様を発光テクスチャで光らせる |
| PBR | 主要モデルとブロックに法線マップ（`_n`）とスペキュラーマップ（`_s`）を添える |
| 色調 | 章ごとにパレットを決める。地上＝自然色、深淵＝深紅と黒、月＝青白と銀、雲海＝金と白。碑文・伝承・技の光は淡い青と青緑 |
| 巨大モデル | 遠景は簡易モデル、近景は部位モデルに切り替えて負荷を抑える |

**立体防具（4Dスキン風）**

- GeckoLibのアーマーレンダラーで、着ると立体シルエットになる防具を作る
- マントや装飾は動きに合わせて揺れるアニメを付ける

**制作フロー**

1. ClaudeがGeckoLib形式のモデル（`.geo.json`）、アニメ（`.animation.json`）、テクスチャ（PNG、スクリプトで生成）を作る
2. Blockbenchで開ける `.bbmodel` も同時に書き出す
3. ラフは 3 案を並べて比べ、1 つを選んで仕上げる（`docs/review/` に比較シート）
4. ユーザーがBlockbenchとゲーム内で確認し、スクショと言葉で修正を依頼する
5. 品質基準を満たすまで繰り返す

注意：Claudeはコードと数値でモデルを組むため、細部の印象は実際に見て調整する必要がある。特にテクスチャの描き込みは、反復回数が品質を左右する。見る者の最初の案が夜にエンダーマンに見えたように、ゲームの中の暗さと距離で見てはじめて分かることがある。
