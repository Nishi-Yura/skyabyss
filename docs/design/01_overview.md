## ブレない軸

**コンセプト：見えない巨大なものに怯える静かなホラーが、世界の謎を解くRPGに変わっていく。** 最後に「それ」と雲の上で対峙する。

迷ったときは次の5つに照らして判断する。

1. **見せない恐怖が先、戦いは後。** 巨大な存在は序盤では影・音・痕跡でしか出さない。全身は最後まで見せない。
2. **壮大さは「スケール」と「光」で出す。** 空の広さ、巨神の大きさ、月の近さ。シェーダー環境で最大限に映えるように作る。
3. **マイクラらしさは壊さない。** 建築や拠点づくりは守る。ループで巻き戻すのは物語だけで、プレイヤーの建築は残す。
4. **RPGは「強くなる実感」と「謎が解ける快感」を両立させる。** レベルを上げるだけのゲームにはしない。
5. **一人で完成させられる範囲で作る。** 縦切り版を最初に完成させ、章を1つずつ足していく。

**やらないこと**

- ジャンプスケア（急に大きな音と顔が出る演出）に頼ること
- 序盤から巨大ボスと戦わせること
- プレイヤーの建築物を消す、巻き戻すこと
- バニラの戦闘やクラフトを大きく作り変えること（足すのはよいが、置き換えない）

## 技術仕様

対象は **Minecraft Java 1.21.1 + NeoForge**。一人で開発する。

| 項目 | 採用 | 理由 |
| --- | --- | --- |
| Modローダー | NeoForge（1.21.1） | 情報が多く、大規模Modの実績がある |
| Java | JDK 21 | 1.21.1の動作に必須 |
| モデル・アニメ | GeckoLib | Blockbenchで作った高密度モデルとアニメを動かせる。立体防具にも使える |
| データ管理 | Data Attachments / SavedData | レベル、ステータス、ループ状態を保存する |
| 地形・構造物 | Datapack（worldgen JSON）+ Structure | 巨神の背やダンジョンをNBT構造物で置く |
| ディメンション | 独自ディメンション ×3 | 深淵、月、雲海 |

**シェーダー方針（Vibrant Visualsについて）**

- Vibrant Visualsは公式の新グラフィックスで、Java 1.21.1には入っていない。そのため直接の対応はできない。
- 代わりに **Iris（NeoForge版）+ シェーダーパック** で同じ方向の見た目を狙う。動作確認は Complementary Shaders を基準にする。
- Modのテクスチャは **LabPBR形式** の法線マップ（`_n`）とスペキュラーマップ（`_s`）を添える。光沢、凹凸、発光がシェーダー上で再現される。
- **シェーダーなしでも成り立つこと**を必須にする。影や空の演出はエンティティとパーティクルで作り、シェーダーは上乗せとして扱う。
- 将来Java版にVibrant Visualsが来て、そのバージョンへ移行する場合は、PBRテクスチャを流用して対応を検討する。

## 世界観と物語

世界は、空の「巡礼者」と地の底の「心臓」が引き合うことで保たれている。心臓が弱り、巡礼者が降りてくる。その兆しが、近づいてくる月である。

| 存在 | 正体 | プレイヤーからの見え方 |
| --- | --- | --- |
| 雲上の巡礼者 | 空を統べる古き神。月を引きずって空を歩く | 雲の上を通る影、地鳴り、削られた山頂。全身は最後まで見えない |
| 止まった月 | 巡礼者の降臨の兆し。内部に時間を縛る核がある | 毎夜少しずつ大きくなる。落ちると物語が巻き戻る |
| 深淵の心臓 | 世界を地上につなぎとめる錨。弱っている | 深く掘るほど大きくなる鼓動。壁の向こうの足音 |
| 巨神たち（4体） | 心臓が生んだ守護者。心臓から分かたれた鼓動を体の奥に抱えて守る。背中に滅んだ古代文明を乗せている | 空や海をゆっくり歩く山のような生き物。体の奥で、何かが脈打っている |

**分かたれた鼓動（巨神の心臓）**

- 深淵の心臓は、弱りはじめたころに自分の鼓動の一部を分け、四体の巨神に一つずつ預けた。巨神はその鼓動を体の奥に抱え、守っている。
- 巨神の体の奥で脈打つこの鼓動を「巨神の心臓」と呼ぶ。**巨神の心臓が、その巨神の守護者である。** 1章で各巨神の最後に戦うのはこれで、第一の巨神では「岩鯨の心臓」になる。
- 天の鍵の欠片は、背中の民が鼓動のそばに納めたもの。巨神の心臓が止まると、はじめて手に取れる。
- 「心臓」という同じ言葉は、深淵の心臓への伏線として使う。1章ではつながりを説明しない。背中の碑文が「この鼓動は地の底から預かったもの」とほのめかすだけにする。2章で深淵の心臓の前に立ったとき、プレイヤーが「あの鼓動は借りものだった」と気づく形にする。
- 巨神の心臓を止めたことが深淵の心臓にどう響くか（鼓動が還るのか、失われるのか）は、2章で明かす。ここでは決めない。

**主人公：「留まる者」**。月が落ちて時間が巻き戻っても、記憶を保てるただ一人の存在。なぜ記憶が残るのかは、物語の核心の謎にする。

**物語の流れ**

1. 地上で異変に気づく（空の影、村人の伝承）
2. 巨神の背を巡り、体の奥の心臓を止めて「天の鍵」の欠片を集める
3. 深淵へ潜り、心臓が弱った理由と、巨神に分けた鼓動の意味を知る
4. 月へ渡り、ループの仕組みと主人公の正体を知る
5. 雲海で巡礼者と対峙する

**エンディング分岐（3種）**

- **鎮める**：心臓を癒し、均衡を取り戻す（王道エンド）
- **壊す**：心臓を破壊し、巡礼者を封じる。代償として世界が変容する
- **受け入れる**：巡礼者を地上に招き、新しい世界の始まりとする（隠しエンド、条件付き）

## 章構成とボス

全部6段階。序盤はホラー色が強く、章が進むほどRPG色が強くなる。

| 章 | 舞台 | 内容 | ボス | 報酬 |
| --- | --- | --- | --- | --- |
| 序章 | 地上（オーバーワールド） | 空の影、地鳴り、村人の異変。「見る者」の人影が前触れとして現れる | なし（気配だけ） | 最初の記憶の断片 |
| 1章 | 巨神の背 ×4体 | 背中の古代遺跡を攻略し、体の奥へ下りて天の鍵の欠片を集める。攻略順は自由 | 各巨神の守護者（4体）＝各巨神の心臓。深淵の心臓から分かたれた鼓動（岩鯨では「岩鯨の心臓」）。道中に中ボスがいてもよい | 巨神素材のセット装備、巨神での移動 |
| 2章 | 深淵（ディメンション） | 鼓動が響く地下世界。並走する足音、閉じるトンネル | 心臓の番人 | 深淵術の解放 |
| 3章 | 月（ディメンション） | 低重力の月面と内部。ループの仕組みが明かされる | 月の核 | 星術の解放、月の落下を遅らせる力 |
| 終章 | 雲海（ディメンション） | 天の階段を登り、雲の上へ | 雲上の巡礼者 | 神器 |
| 結末 | — | 選択により3種のエンディング | — | エンド別の世界変化 |

**ラスボス「雲上の巡礼者」の設計**

- 全身は画面に収まらない。手、目、胸の核など、部位ごとに戦う
- 第1形態：雲の下から伸びる巨大な手。足場の雲を削り取る
- 第2形態：雲が割れて目が現れる。視線に入るとデバフを受ける
- 第3形態：月を引き寄せ、時間が乱れる。攻撃が巻き戻ったり、過去の自分の幻影が加勢したりする
- 巨大さは「遠景の簡易モデル＋近景の部位モデル」で表現する

## ループシステム

**月の落下はゲームオーバーではなく、物語だけを巻き戻す「章の時限」として扱う。** ワールドの地形と建築は巻き戻さない。

| 巻き戻るもの | 残るもの |
| --- | --- |
| 月の位置（初日の大きさに戻る） | 地形、建築物、拠点 |
| 章内のストーリーイベント | レベル、スキル |
| NPCの状態と会話フラグ | 記憶の断片（永続強化） |
| 一部ダンジョンの宝箱と仕掛け | 攻略済みの章とボス撃破記録 |
| 章内で得た一部のクエストアイテム | 装備とインベントリ |

**仕様**

- 1ループはゲーム内で7日（設定で変更可）。月は毎夜大きくなり、7日目の夜に落ちる
- 月が落ちると全画面の演出の後、プレイヤーはリスポーン地点で「初日の朝」を迎える
- ループをより重ねるほど、NPCのセリフが変化し、新しい選択肢が開く
- 月の落下を遅らせるアイテムや儀式で、時限を伸ばせる
- 序章ではループは起きない。初めて月が落ちるのは1章の途中とし、「何かがおかしい」という驚きにする
- マルチプレイでは全員が同じループを共有する（サーバー全体で一つの月）

## RPGシステム

RPG要素は5つの柱で構成する。どれもバニラの仕組みを置き換えず、上に足す形にする。

**成長**

- レベル（上限50）。経験値は敵、探索、クエストから入る。バニラのXPとは別管理
- ステータス：筋力・敏捷・精神・耐久。レベルアップごとにポイントを振り分ける
- 記憶の断片：ループをまたいでも消えない永続強化。ボス撃破や隠し要素で手に入る

**クラスとスキル**

| クラス | 効果の元 | 代表スキルの例 | 解放 |
| --- | --- | --- | --- |
| 剣士 | 筋力 | 巨神斬り（大型敵への特効） | 最初から |
| 弓使い | 敏捷 | 雲穿ち（遠距離の貫通射撃） | 最初から |
| 星術師 | 精神 | 月光の障壁、時の遅延 | 3章 |
| 深淵術師 | 精神・耐久 | 鼓動の衝撃波、影潜り | 2章 |

- クラスは固定しない。複数のスキルツリーにポイントを振れる混合型にする
- スキルはホットバーとは別のスキルスロット（4枠）から使う。マナは独自ゲージ

**装備**

- レアリティ：コモン → アンコモン → レア → 伝説 → 神器。上位ほどランダム効果の枠が増える
- 巨神セット：巨神ごとに素材とセット効果が違う。観て分かる立体モデルにする
- 神器：ボスごとに1つ。専用スキル付き

**NPCとクエスト**

- 会話画面（顔アイコン＋選択肢）、好感度
- メインクエストとサブクエスト。クエストログ画面を用意する
- ループ前の会話を「覚えているような」NPCを数人配置する
- このModの村人は独自エンティティにする（バニラの村人はそのまま残す）

**探索**

- ダンジョンはパズル、トラップ、中ボスで構成する
- 書物や石碑を集めると「伝承の書」に登録され、世界の謎が少しずつ解ける
- ファストトラベルは「巨神に乗る」形で実現する

## ホラー演出の原則

**怖さは「世界がいつもと違う」ことから生まれる。** 敵を出すより、音が消えるほうが怖い。

- **引き算**：動物が鳴き止む、BGMが途切れる、風が止まる
- **痕跡**：削られた山頂、巨大な足跡、引きずった溝、消えた松明
- **間接**：影、地鳴り、遠い音、壁の向こうの足音。本体は見せない
- **頻度を絞る**：同じ演出は少なくとも数日は空ける。慣れたら怖くなくなる
- **段階的に強める**：月が近づくほど、章が進むほど異変が増える
- **プレイヤーを即死させない**：演出で死なせない。怖さと理不尽を混同しない
- **設定で弱められる**：ホラー演出の頻度・画面揺れをコンフィグで調整できるようにする

**導入する演出の一覧**

| 演出 | 発生条件 | 章 |
| --- | --- | --- |
| 雲上を通る巨大な影 | 晴れた昼、屋外 | 序章〜 |
| 地鳴りと画面の微振動 | 影の通過中 | 序章〜 |
| 動物がしゃがみ込む、鳴き止む | 影の通過中 | 序章〜 |
| 遠くから見ている人影（見る者） | 夜、一人でいるとき | 序章 |
| 山頂・高層建築が削られる | 影の通過後（プレイヤー建築は対象外） | 1章〜 |
| 雲の切れ間の巨大な目 | 月が半分以上近づいた夜 | 1章〜 |
| 心臓の鼓動、並走する足音 | 深い地下、深淵 | 2章〜 |
| 閉じるトンネル、消える松明 | 深淵 | 2章 |

## モデル・アート方針と品質基準

**4Dスキン級の立体感を、マイクラの世界から浮かない解像度で作る。** モデルとテクスチャはClaudeが制作し、ユーザーがBlockbenchとゲーム内で確認して修正を依頼する。

**品質基準**

| 項目 | 基準 |
| --- | --- |
| テクスチャ解像度 | バニラの2倍（1ブロック幅 = 32px）で統一。巨大ボスも同じ密度を守る |
| 形状 | ボーン階層を持つキューブモデル。角、マント、浮遊パーツなどでシルエットを崩す |
| アニメ | 待機、移動、攻撃、被弾、死亡の5種を最低限。ボスは形態変化も |
| 発光 | 目、核、模様を発光テクスチャで光らせる |
| PBR | 主要モデルとブロックに法線マップ（`_n`）とスペキュラーマップ（`_s`）を添える |
| 色調 | 章ごとにパレットを決める。地上＝自然色、深淵＝深紅と黒、月＝青白と銀、雲海＝金と白 |
| 巨大モデル | 遠景は簡易モデル、近景は部位モデルに切り替えて負荷を抑える |

**立体防具（4Dスキン風）**

- GeckoLibのアーマーレンダラーで、着ると立体シルエットになる防具を作る
- マントや装飾は動きに合わせて揺れるアニメを付ける

**制作フロー**

1. ClaudeがGeckoLib形式のモデル（`.geo.json`）、アニメ（`.animation.json`）、テクスチャ（PNG、スクリプトで生成）を作る
2. Blockbenchで開ける `.bbmodel` も同時に書き出す
3. ユーザーがBlockbenchとゲーム内で確認し、スクショと言葉で修正を依頼する
4. 品質基準を満たすまで繰り返す

注意：Claudeはコードと数値でモデルを組むため、細部の印象は実際に見て調整する必要がある。特にテクスチャの描き込みは、反復回数が品質を左右する。

| 2026-10-16 | 1章のボス「各巨神の守護者」は、各巨神の体の奥にある心臓とする。巨神の心臓は深淵の心臓から分かたれた鼓動で、巨神はそれを抱えて守っている。名前は変えない（岩鯨の最終ボスは「岩鯨の心臓」のまま）。つながりは背中の碑文でほのめかすだけにし、2章で明かす | 「心臓」が物語の核の深淵の心臓と重なり、誤解を招くという指摘（設計レビュー必須5）。名前を変えるより、重なりを2章への伏線にするほうが物語に合い、作り直しも少ないため |
| 2026-10-16 | ピースフルでは巨神の試練を祠で封じ、「巨神は目覚めない」と伝える。島を歩くことと巨神に乗ることはできる。今後の巨神もすべて同じ | 試練とボス戦は戦うことが前提で、敵だけを消すと成り立たないため（設計レビュー必須6） |
| 2026-10-16 | 巨神のダンジョンの報酬は周回で集める形にする。参加者ごとの低確率の個人抽選と天井で集め、中ボスに確定の品は置かない（10-15の「報酬は番兵長の撃破時に渡す」を置き換える。数値は02の6章） | 一度で揃わず、仲間と何度も挑む理由を作るため。中ボスで確定の品が出ると、奥の心臓まで進む意味が薄れるため |
| 2026-10-15 | 岩鯨の報酬はすべて番兵長の撃破時に個人ごとに渡す（道中の敵は経験値のみ）。鎖は胴の外へ張り出して垂らす。広間は全滅したときだけ戻る | 試遊で「ボス前に良い物が出すぎる」「上るとき鯨にぶつかる」「封印の壁から戻れてしまう」と指摘されたため |
| 2026-10-15 | 装備の第1段階を実装。個人抽選（本人だけが拾える）、巨神の記憶（5で確率2倍、8で未所持の伝説を保証。未所持を得たときだけ0に戻る）、初回クリアで伝説3種から1つ選択、共鳴の炉（+10までの強化と分解）、岩鯨の新装備5種と素材4種 | 1つのダンジョンで周回が成り立つか確かめるため。重複で天井が戻ると、欲しい物から遠のいて不公平になるため |
| 2026-10-15 | 専用装備は周回しないとそろわない設計にする（個人抽選・天井・共鳴の炉）。エンドコンテンツを多数用意する。詳細は「装備・エンドコンテンツ設計」 | クリア後に飽きないようにし、仲間と何度も挑む理由を作るため |
| 2026-10-15 | 背中の敵はすべて新しいキャラ（骨の番兵・骨棘の射手・苔這い・水路の顎・鯨骨の番兵長）。壁をすり抜ける敵は使わない。中ボスは4つの特殊な技を持つ | 強化したバニラの敵では物足りないという指摘 |
| 2026-10-15 | 東の封印の扉は一方通行。アスレと水路は毎回ランダムで、水路は休み場なし（息継ぎのみ）。背中で倒れても持ち物を失わず、休み場から再開する | 何度も挑む前提で、毎回新しく、理不尽にはしないため |
| 2026-10-15 | 背中の試練は何度でも挑める。背中に誰もいなくなって3分たつと、石・封印・広間・宝箱が元に戻る。天の鍵の欠片は台座から一人一つ | マルチプレイで、別の人や別の日にも挑めるようにするため |
| 2026-10-15 | 背中の島を拡大（全長240・幅96）。西＝3つの谷と3つの休み場を進む長いアスレ、東＝3つの広間を順に制圧する回廊（人数で番兵が増える）、下＝3×3の水路の大迷路と休みの泡。落下・死亡は直前の休み場から再開 | 一部屋で終わる試練は物足りない。広い範囲を、休憩しながらみんなで攻略する形にするため |
| 2026-10-15 | 背中ではサバイバルのブロック設置・破壊と、水バケツ・エンダーパール・ウィンドチャージ・花火ロケットなどの近道を禁止する | 試練を正面から越えてもらうため（簡単すぎるという指摘） |
| 2026-10-15 | ダンジョンを難しくする。西＝崩れる足場を含む螺旋のアスレ、東＝閉じ込められて3波の番兵を倒すまで石が応えない、下＝真っ暗な水没迷路（溺死体・下へ引く流れ・息継ぎ2か所） | 泳ぐだけ・戦わなくていい・回り込める、という指摘 |
