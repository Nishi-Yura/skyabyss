## 1. 何が困っているか（今の仕組み）

今の笛は、**本物の巨神を呼んだ人のもとへ動かす**（09 の 4.4）。岩鯨は 260 ブロック先から泳いできて鎖を垂らし、潮殻は浅瀬へ寄り、雷翼は峰へ降り、余燼は近くの陸で浮かぶ。巨神は世界に一体だけで、背の試練は巨神ごとに共有している（10 章）。そのため、

- 誰かが呼ぶと、**別のパーティが背で戦っている巨神の位置が変わる**（背の中は動かないが、外の景色・出入りの窓・停泊場所が変わる）。
- 呼ばれた巨神は 20 分その場に居座るので、ほかのパーティが「会いに行く」場所が勝手に動く。
- 旅（岩鯨・潮殻で行き先へ運ぶ）の最中は、巨神が busy になって**ほかのだれも呼べない・乗れない**。
- 巨神の近くで別の巨神を呼ぶと、巨神どうしが重なる（直しは上の「小さな直し」）。

つまり**共有の本物を、個人の用事で動かしている**のが根にある。案は、動かすものを「個人のもの」に替える。

## 2. 世界観との照らし合わせ

- **巨神は 4 体だけで、増えない**（01 の 4.3）。心臓は深淵の心臓から分かたれた「借りものの鼓動」で、止まると巨神は眠り、遠い下から鼓動が戻ると目を覚ます。**本物の幼体（新しく生まれた子）を置くと「増えない」と食い違う。** 子は「新しい命」にせず、**巨神が分けた鼓動の子**として置くのが筋が通る。
- 巨神は歌う（岩鯨の歌・潮殻の貝の音・雷翼の羽・余燼の鈴の音。笛はその歌の写し）。**笛は巨神の歌のかけらで、歌は巨神の胸から出る。** 子は、その歌にいちばん先に応える「歌のかけら」。巨神自身が動かず、歌のかけらが迎えに行く、は筋が通る。
- 「分かれた鼓動」は物語の核（深淵の心臓 → 巨神の心臓 → 子）。五章の「あの鼓動は借りものだった」へ、**借りものがさらに分かれる**と、静かに伏線を重ねられる。子は親から離れすぎると鼓動が弱る（遠くまで行けない = 乗っている間だけ現れ、着いたら歌に溶ける）という性質にすると、「4 体だけ」を壊さず、子が世界に残り続ける問題（数・保存・負荷）も出ない。
- **眠りとの整合**: 心臓が止まって巨神が眠るとき、子も眠る（笛は応えない。今の「眠っている巨神は応えない」をそのまま使える）。目覚めると子も戻る。
- 出会いの決まり（09 の 4.4）: 「一度は自分の足で会いに行った巨神だけ呼べる」は、子にもそのまま使える（会っていない巨神の子は応えない）。
- 子の見た目は「親の縮み」ではなく「親の一部が動き出したもの」: 岩鯨の子は背の石から落ちた骨と殻のかけら、潮殻の子は貝殻の中の稚貝、雷翼の子は雷羽の雛、余燼の子は燠石の仔。親の識別（形・色・材料の言葉。26 の守ること）を縮めて持つ。

## 3. 三つの案

共通の決まり（三案とも）:
- **成体の巨神は、一つのパーティの用事では動かない。** 呼び笛は成体を動かさない。巨神が動くのは、自然の周期と最初の出会いの場面だけ（今の `TitanKeeper` の出現・降下・夜の浮上のまま）。
- 子は**呼んだ本人だけのもの**（持ち主の UUID を持つ。ほかの人は乗れない・当てられない・倒せない）。ほかのパーティの景色に出るのは、飛んで行く小さな影だけ。
- 子は乗っている間だけ存在し、降ろすと歌に溶ける（保存しない。再ログインでは消えて、笛を吹き直す）。
- 眠っている巨神の子は応えない（今の眠りの断りをそのまま使う）。

### 案 A「子が成体のもとへ連れていく」（推薦の第一段）

**流れ**: 出会った巨神の笛を吹く → 子が足もとに現れる（鞍が見える。3 秒待ち）→ 乗る（右クリック。笛をもう一度吹いても可）→ 子が**その巨神が今いる場所**（停泊中・眠り・飛行中の最後の位置）へ運ぶ → 成体の乗り込み口（岩鯨の鎖・潮殻の潮門・雷翼の昇り風・余燼の口）の手前に降ろし、「ここから背へ乗れる」と告げて溶ける。成体が泳いでいるなど今は降りてこない状態なら、子は成体の近くまで行き、**その人だけに乗り込み口を開ける**（成体は動かない）。

- 行き先は、成体のいる場所だけ。はじまりの地・碑には行けない（今の旅を替えない。旅は 09 のまま、成体が動く部分だけ別途検討）。
- **マルチ**: 子は一人に一体。同じ巨神を同時に何人が呼んでも、成体は動かないので衝突しない。パーティの仲間は各自が笛を吹いて同じ場所に着く。ほかのパーティが背で戦っていても、外から見た位置は変わらない。乗り込み口が「その人だけに開く」ので、ほかの人に開きっぱなしにならない。
- **世界観**: 「歌のかけらが迎えに来る」。巨神は動かない。4 体だけ・眠りとの整合は取れる。
- **作るモデル**: 子 4 体（ラフ各 3 案 = 12 枚。低ポリ + 32px のピクセル絵、閉じた面。部品は親の部品を縮めて流用できる）。歩き・飛ぶ・乗る・溶けるの動き（geo アニメ）。
- **効果音・演出**: 現れ・溶ける音（親の歌の高い写し）、出発の短い雲の帳（空の子のみ）。
- **工数**: M。新しい乗り物の実体 4 + 経路（成体のもとへ飛ぶだけ。経路探索は直線 + 地形を避ける高さのみ）+ 乗り込み口の「その人だけ開く」。08・09 の手直し。

### 案 B「子は専用の乗り物。どの巨神のもとにも、はじまりの地にも行ける」

**流れ**: A の流れに加えて、乗ってから**海図（旅の乗り場と同じ画面）**を開き、行き先を選べる。行き先は、会った巨神のいる場所（A）、はじまりの地、立てた碑。笛はどの巨神のものでもよいが、**乗った子の得意（空・海・峰・地）に合う行き先だけ**選べる（空の子は雲の下の陸と峰、潮殻の稚貝は海辺と海辺、雷翼の雛は高い場所、余燼の仔は地上。得意でない場所へは「この子は海を渡れない」と断る）。**今の旅（成体を動かす旅の呼び）は子に置き換わる。**

- 行き先を選べるぶん、移動の用事（拠点へ帰る・知らない所の碑へ飛ぶ）は一通り満たす。今の「旅」を捨てても移動が不便にならない。
- **マルチ**: A と同じ（子は個人。成体は動かない）。碑・はじまりの地は共有の目印で、各自の子が各自で向かう。
- **世界観**: A と同じに加えて、「子は親のもとへ帰る」だけでなく「旅の相棒」になる。ただし子が親の近くを離れて遠くまで行くと、「親から離れすぎると鼓動が弱る」の設定と矛盾するので、**子の鼓動は笛の歌がつなぐ**（笛を持つ人のそばでだけ息をする）と言い換える必要がある。
- **作るモデル**: A と同じ 4 体 + 海図に子の絵（アイコン 4 つ、32px）。**子ごとに行ける所が違うので、移動の経路と断りの文が 4 通り**。
- **工数**: L。経路（空・海・峰・地ごとの地形の見方）、海図の改造（旅の画面を子用に移す）、今の旅（`TravelTitan`・`Voyage`・`SeaVoyage`）の置き換え、自己テスト。

### 案 C「笛は渡り鳥（伝令）を呼ぶ。子は物語にだけ出る」

**流れ**: 笛を吹くと、**巨神の歌を運ぶ渡り鳥**（小さな光の鳥。巨神ごとに色と鳴き声が違う）が現れて、成体のいる方向へ飛んで案内する（道しるべ: 空に細い軌跡を引き、近づくと高く鳴く）。鳥は人を乗せない。遠くの巨神へは自分の足と今の乗り物（馬・船・エリトラ）で行く。**子（幼体）は、章の物語の場面（見せ場）に出るだけ**（岩鯨の仔が一章の最初に足あとを残す、など）。

- 成体が動かない・子が運ばない。**一番邪魔にならず、一番安い**が、「移動が楽になる」という今の旅の目的は満たさない。旅の撤去で不便になったと感じる可能性がある。
- **マルチ**: 鳥は個人にだけ見える（クライアントの演出）か、持ち主の鳥だけ。衝突しない。
- **世界観**: 鳥はもともと世界にいる（序章の鳥・潮殻の海鳥・雷翼の鳥）ので説明がいらない。
- **作るモデル**: 渡り鳥 1 種（ラフ 3 案。4 色の色違い）+ 物語用に子 4 体の静止モデル（ラフ各 3 案）。動きは鳥の羽ばたきだけ。
- **工数**: S〜M。実体は鳥 1 つ。ただし移動の旅の置き換えが別途要る。

## 5. 推薦

**案 B。ただし作る順は A → B。** 理由は次のとおり。

1. 試遊の声の中心は「ほかのパーティに迷惑をかけず、移動はしたい」。移動の手段を捨てる案 C では、声の前半（移動はいい）を満たさない。
2. 子の運び先を巨神のもとだけにする案 A は、今の旅（拠点へ帰る・碑へ行く）を残すか捨てるかを別の問題にして先送りする。B なら、旅の用事を子が全部引き受けるので、成体が動く仕組みを**撤去してよい**。
3. A を先に作って遊び（成体のもとへ連れていく・その人だけに乗り込み口を開ける）、手応えを見てから海図と得意な行き先（B の部分）を足す。やり直しが小さい。

## 6. ユーザーの判断（4 つ）

選定ページで選ぶ。db の collection `choices`、文書の id は `young_1`〜`young_4`。

1. **案**: A 子が成体のもとへ連れていく／ **B 専用の乗り物（A から作る）** ／ C 渡り鳥の案内。**推薦 B**。
2. **子の正体**: **A 巨神が分けた鼓動の子（歌のかけら。乗っている間だけ現れて溶ける。巨神は 4 体のまま）** ／ B 本物の幼体（世界に残る。巨神は増える。01 の「4 体だけ」を変える）／ C 巨神の分身の幻（生き物でない。物語は軽いが重みが減る）。**推薦 A**。「4 体だけ」「心臓は借りもの」の軸を壊さず、五章への伏線を重ねられる。
3. **一度に乗れる人**: **A 一体に一人（仲間も各自が笛を吹く）** ／ B 二人まで（持ち主 + 一人）／ C パーティ全員（最大 6 人。子を大きくする）。**推薦 A**。一人一体なら持ち主の管理・座席の同期・乗り降りの衝突が最小。仲間とは同じ場所に着くので、離れ離れにはならない。
4. **今の「成体が来る呼び」と旅**: **A 撤去（成体は呼ばれても動かない。最初の出会いと自然の周期は残す）** ／ B 残す（子の案と並べて選べる。マルチの迷惑は残る）／ C ゲームルールで切り替え（既定は撤去。サーバーが選ぶ）。**推薦 A**。ゲームルールにすると、二つの経路を試す・直すコストが残る。

## 7. 実装するときの守ること（書き手の確認）

- 成体の巨神の位置・状態を、笛・子の用事で変えない（自然の周期・最初の出会い・眠りと目覚めだけ）。
- 子は持ち主だけのもの。ほかの人が乗る・倒す・当てることはできない。保存しない（再ログインで消える）。
