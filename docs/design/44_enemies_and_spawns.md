# 44. 敵と湧きの表（大陸の地上）

2026-10-26 の声「通常モブはもう出ないようにして。全敵 mod の敵。もっと敵の種類を増やしたり、どこに何がスポーンするのか等々も決めていって」。
バニラの生き物は、村人のほかは湧かない（敵も動物も魚もコウモリも。`RpgRules.vanillaEnemy`。2026-10-27 に動物も足した）。大陸の地上の敵は、この表で湧かせる（土地の湧き `RegionSpawner`。表は `data/skyabyss/spawns/<土地>.json`）。
巨神の背・心臓・深淵・章の場所の湧き台（`SiteSpawner`）は今までどおり。

## 2. 湧きの決まり

- 人のまわり 24〜56 ブロックの地面に、2 秒ごとに一度試す。人ひとりのまわりに同時に 10 体まで（群れは 1 体と数えない）。都と土地の町の中・道の上・見どころの中には湧かない。
- 湧く敵は、その場所の土地・地形・昼夜で表から重みで選ぶ。群れの敵は 2〜4 体まとめて。
- 人が 96 ブロック離れると消える（保存しない）。名のある強敵（§4）は別の決まり。
- 表の行に `near`（[島の図の名前, 半径] の並び）を書くと、その所のまわりだけで湧く。はじまりの島は全部の行がこれ（2026-10-27 の声「島に敵が出るのはおかしい。特定の場所以外」）。
- 都と土地の町に入った敵は、消さずに、いちばん近い縁の外へ押し戻す（0.25 秒ごと）。町の中の人は狙わない。
- 敵の落とし物は、この Mod の品のほか、店で売り買いする品・矢・パンだけ（`loot/ModOnlyDrops`）。
- 強さは敵ごとに決めてある（章ごとに釣り合いを取った値）。ただし §4 の新しい敵（`entity/foe` の `ContinentFoe`）は岩鯨の土地を 1 とした素の値で、湧いた土地の強さ `ContinentDanger` が掛かる（島 体力 ×0.45・攻撃 ×0.4、草原 ×0.55・×0.5、潮 ×1.3 …）。同じ野盗が島では弱く、灰の荒野の野営では強い。

## 5. 名のある強敵

土地ごとに一体の名づきの強敵（`world/continent/NamedFoes`）。
- **棲み家**: 土地ごとに決まった見どころが一つ（崩れた塔・焼けた砦・塚・環状列石・墓所……の順で、その土地にある最初のもの）。旅の地図にいつも角のある髑髏の印で出る（生きていれば赤い縁、指すと「今、棲み家にいる」/「近づくと現れる」）。
- 人が棲み家の 72 ブロック以内に来ると、その土地に生きている名づきがいなければ、棲み家に一体現れる。昼夜では閉じない。棲み家から 36 ブロックより離れると狙いを捨てて戻る（道や町まで追ってこない）。
- 生きている間は光る縁取り（壁越しにも見える）と、頭の上から空へ伸びる光の柱（160 ブロック以内の人に）。
- 名札・体力の帯（40 ブロック以内の人に）・現れたときの知らせ。倒すと 32 ブロック以内の人みなに鐘銭。その土地の次は 20 分後（離れて消えたときは 2 分後）。保存しない。
- 島 = なし（島をうろつく名のある敵は出さない。峠の野盗の場面の「峠の頭目」を倒すと、島の名のある敵の記しが付く）、草原 = 最後の旗手（骸の旗手、体力 ×2、鐘銭 40）。
- 岩鯨 = 岩背の大猪、潮 = 潮招きの大蟹、嵐 = 雷角の大羊、灰 = 灰被りの大蜥蜴（一体一案の形、`tools/rough/lowpoly/foes/`。頁 https://claude.ai/artifact/6woPDQ1R9Y6AQwZDvG73JP）。
