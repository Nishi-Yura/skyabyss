## 1. ベータの範囲

今の試遊版は **0.7.1**（`build/libs/skyabyss-0.7.1.jar`。大陸の世界。マルチの試遊の確認表は `docs/review/playtest_0.7.1.md`、遊び方は [テスター向けの遊び方](../beta_how_to_play.md)）。下の表は大陸より前の通しの順で、大陸では [40](40_rpg_world_and_start.md) の 4 章のはじめの流れのあと、土地の町から各章に入る（[42](42_story_on_the_continent.md)）。

## 3. 天の鍵

### 3.1 そろう条件

| 項目 | 決まり |
| --- | --- |
| 条件 | **自分で四体の心臓を止めた（段階 4）** かつ **天の鍵の欠片を四つ持っている**。1 秒ごとに見る |
| 理由 | 欠片はどの巨神のものも同じ品（`skyabyss:sky_key_fragment`）なので、持っている数だけでは「誰かにもらった四つ」と区別できない。段階は順番どおりに止めた心臓だけを数える（10 の 3.1 節） |
| 起きること | 欠片 4 つ（手もとの数え方。11 の 4.3）を取り、天の鍵（`skyabyss:sky_key`）を渡す。伝承「天の鍵」（`chapter1/sky_key_whole`）を記し、クエストへ合図 `sky_key_assembled`。その人の画面に場面。ワールドで最初なら、心臓を一つ以上止めたほかの人に、画面の語りで一行「〜の手の中で、天の鍵が形をとった。」。光の粒がその人の上から落ちる（ほかの人にも見える）。四章の余韻（`EmberAftermath`）に知らせ、場面の長さだけ札を待たせる |
| 記録 | `StoryData`（`skyabyss_story`）: そろえた人とその日、ワールドで最初の人。一人一回 |
| 品 | 一つだけ、火に強い、捨てられない、倒れても消えず控え帳が在りかを追う（`Keepsakes` の守る品）。鍵にしたあとは、欠片が手もとになくても「なくした」と見ない（心臓がもう一つ欠片を渡さない） |

### 3.2 品の絵

32px。下を指す柄のある鍵。欠片と同じ石の円盤に、下へ一本の柄が伸びる。円盤が欠片の続きに見え、柄が**下を指す**ので、物語（鍵は足もとを指す）と合う。四つの象嵌の色は巨神ごと（岩鯨の青、潮殻の青緑、雷翼の淡い黄、余燼の熾火）。生成は `tools/gen/story/gen_story_assets.py`。

### 3.3 場面（`client/story/SkyKeyScene`）

ゲームは止めない。Esc で終わりの札へ飛ばせる。

| 時刻 | 画面 | 音 |
| --- | --- | --- |
| 0〜1.2 秒 | 画面が暗くなる（上ほど濃い。上 94%・下 84%）。場面の間は HUD を隠す（閉じたら戻す） | — |
| 0.6〜4.4 秒 | 四つの欠片が四隅から回りながら寄っていく。それぞれの後ろに巨神の色の淡い光（細かい段の重ねで、四角い箱に見せない） | 2.95 秒から、四つの澄んだ鳴りが一つずつ |
| 4.4 秒 | 触れ合って白く光り、天の鍵になる | 鳴りが寄り合って和音、低い響き |
| 5〜19 秒 | 空から光の筋が落ちて、画面の下（足もと）へ沈む。鍵から真下へ細い光。四行の文が一つずつ | 11.4 秒と 13.6 秒に、足もとの遠い鼓動 |
| 20 秒〜 | 終わりの札。「巨神編　天の鍵」（四章の終わり＝巨神編の終わり。`scene.skyabyss.sky_key.end_title`）「ベータ版はここまでです」「遊んでくれて、ありがとう。」「この世界の N 日目」、下に「Esc かクリックで戻る（巨神の背の周回と頼みごとは、このあとも続けられる）」 | — |

四行の文:

1. 四つの欠片が、手の中で触れ合った。
2. 継ぎ目が、ひとりでに消えていく。
3. 鍵は、空を指さなかった。
4. 足もとの、ずっと下。何かが、ゆっくりと打っている。

- 音は合成（`tools/gen/story/gen_story_assets.py`。01 の「既存の音を使わない」）。`assets/skyabyss_story/sounds.json` に置き、画面だけで鳴らすので登録しない。
- 場面のあと、天の鍵を手に持っていると、14 秒ほどに一度、足もとのずっと下で小さく打つ（オーバーワールドだけ）。鍵から光の粒が一つ、下へ落ちる（`StoryClient`）。
- 01 の「言い伝えでは雲の上へ続く扉の鍵」と食い違わせない。鍵は「上の扉」を否定せず、「先に下を向いている」だけを見せる。語り部の「鍵というのは、開けたい扉のほうを向くものだよ」が五章（深淵へ潜る）への引き。

### 3.3b 場面のあとの余韻（四章の終わり。`titan/ember/EmberAftermath`）

場面（約 26 秒）が済んで、地上に出てから順に一度ずつ（13 の 17.6）。チャットには流さない。

| 順 | 出るもの |
| --- | --- |
| 1 | 余韻の札「四章　余燼　終」「灰が止んだ。拍が、ひとつだけ遅れて鳴った。」 |
| 2 | 語り部の最後の一言（画面の語り）「……よく戻ったね。その鍵は、あんたが持っておいき。上ばかり見ていたのは、わたしたちのほうだったよ。」 |
| 3 | 巨神編の終わりの合図。足もとのずっと下で鍵と同じ拍が一つ（音・ごく小さな揺れ・足もとの灰の粒） |

- 巨神編の終わりの印は、場面の最後の札のまま。五章への案内は何も押しつけない（鍵が下を指すだけ）。

### 3.4 その後の会話

| 人 | 中身 |
| --- | --- |
| 語り部（メイン「天の鍵」） | 「この鍵、下を向いて打っているよ」→ 数え歌のいつつめを思い出す「いつつ　いきづく　つちのそこ」（伝承「数え歌のいつつ」）→「むっつから先は、まだ出てこない。……鍵というのは、開けたい扉のほうを向くものだよ」 |
| イサナ（一度だけ） | 「空の扉を開ける鍵だと、ずっと思っていた。……下を向いているな」「俺はずっと、上ばかり見ていた。……足もとのことは、考えたこともなかったな」 |

数え歌の「いつつ」は、07 の「数え歌のつづき」で語り部が「ここまで出かかっているのに」と言った所の答え。むっつから先は五章以降に残す。
メインの依頼主は、雷翼 = 語り部（祖母の言い伝え。雷の晩に数えるのをやめた）、余燼 = イサナ（旅の話）。二人の役が交互になる。

## 4. 巨神をつなぐ口の約束

### 4.1 巨神の担当がつなぐ口（約束）

コードは `progress/Titans.java` の先頭のコメントにも同じことを書いてある。ここに書いた名前は変えない。雷翼・余燼は `Titans.THUNDER_WING`・`Titans.EMBER`。

| # | すること | どこを呼ぶか |
| --- | --- | --- |
| 1 | 背中のディメンションを作ったら、起動時に一行 | `Titans.bindBack(背中のキー, 巨神, 地上へ戻す関数)`。乗る資格の見回りとディメンション移動の取り消しが効く |
| 2 | 本体を出す前に、出てよいかを見る | `Progression.worldAllows(server, 巨神)`（雷翼は潮殻の心臓をワールドの誰かが止めたあと。余燼は雷翼のあと） |
| 3 | 入口（鎖・門・コマンド）で、乗れるかを見る | `Progression.checkBoard(player, 巨神)`。断るときの文は出してくれる |
| 4 | 心臓を倒したら、**報酬より先に** | `Progression.onTitanStopped(server, 参加者の UUID, 巨神)` |
| 5 | 欠片を一人一つ | `TitanMemoryData` の `record.fragment` で一人一回、`ModItems.SKY_KEY_FRAGMENT` を 1 つ。四つ目で天の鍵は自動でそろう |
| 6 | 巨神を見つけたら、伝承を記す | `Lore.unlock(player, "chapter1/thunder_wing", true)`（余燼は `"chapter1/ember"`）。メインクエストはこの項目で「見つけた」を数える |
| 7 | 心臓の伝承（「〜の鼓動が止まった」） | 各担当が自分の項目を足してよい（`chapter1/thunder_heart_stilled` など）。メインは `stilled` の条件で数えるので項目名は自由 |
| 8 | 自分の背中の周回のサブクエスト | 07 の 7 章の型。データを直接直す（生成スクリプトはない） の「言伝ての板」の節に足す。`min_stage` は 3（雷翼）・4（余燼） |

## 5. 試遊の手順と確認表

テスター向けの遊び方ページは [docs/beta_how_to_play.md](../beta_how_to_play.md)。ここは作る側の手順。

### 5.1 準備

1. 専用サーバー（`./gradlew runServer`）か、一人なら `runClient`。**新しいワールド**（背中の島は新しいワールドの起動時に一度だけ建つ。岩鯨 13〜20 秒・余燼 約 21 秒・潮殻 7〜10 秒、合わせて 1 分近くかかることがある）。
2. 2〜4 人。全員が序章から。パーティは O キー。
3. ゲームルール `skyabyssStoryGate`（巨神の順番）と `skyabyssStoryLevelCap`（レベル上限）は、既定でオン。想定した遊び方を見るなら、オンのまま渡す。
4. 時間の目安（見込み。試遊で測る）: 序章〜岩鯨 2〜3 時間、潮殻 1.5〜2 時間、雷翼・余燼は各 2 時間前後。
5. 途中を飛ばす管理者コマンド（詳しくは遊び方ページの「困ったとき」）:

| コマンド | 使いどころ |
| --- | --- |
| `/skyabyss progress grant <人> <巨神>` | 心臓を止めたことにして、次の巨神に乗れるようにする（巨神は `stone_whale`・`tide_shell`・`thunder_wing`・`ember`） |
| `/skyabyss titan summon <tide・storm・ember>` | 巨神を自分の近くに呼ぶ。`titan rest <名前>` で休ませ、`titan board <名前>` で背中へ直接渡る |
| `/skyabyss story ready <人>` | 四体を止めたことにして欠片を四つにし、天の鍵の場面まで飛ぶ |
| `/skyabyss quest next <人> <クエスト>` | メインクエストの段階を一つ進める |
| `/skyabyss titan reset <名前>` | 背中の試練を最初に戻す |
