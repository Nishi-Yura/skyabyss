### 1.1 「何かがおかしい」のほのめかしをどこまで入れるか（判断）

01 では「初めて月が落ちるのは 1 章の途中」としている。ベータにはループの本体（M4）がないので、**月は落とさない**。代わりに、すでにある異変と、次の章へ向かう引きだけを入れる。

| ほのめかし | 状態 | 何を思わせるか |
| --- | --- | --- |
| 七日目の夜の言い伝え（語り部・暦・板の紙「七日目の夜は戸を閉める」「七日に一度は確かめて」「潮は七日で満ちる」） | 済（「潮は七日で満ちる」は今回足した） | 七日という区切りがある |
| 雲の切れ間の目（月の近さの仮の値が半分を超えた夜、二つ目の月のように） | 済（06 の 10 章） | 月が近づいている |
| 削られた峰 | 済（06 の 10 章） | 空の上に、巨神よりずっと大きなもの |
| 見る者（自分に似た影） | 済 | 自分を覚えている誰か |
| 伝承の書の最初の一行、書の字が語り部の母の帳面に似ている | 済 | 前にも同じことをした |
| **天の鍵は空を指さず、足もとへ脈を打つ**。語り部が数え歌の「いつつ　いきづく　つちのそこ」を思い出す。鍵を手に持つと、ときどき足もとのずっと下で何かが打つ | **今回** | 2 章（深淵の心臓）への引き |

- 月が落ちる場面を「演出だけ」入れる案（巻き戻さずに、落ちる直前で夜が明ける）は、M4 の作りを先取りすることになり、ループの決まり（巻き戻るもの・残るもの）を試遊で誤解させるので入れない（00 の 95）。
- ベータの試遊で「七日目の夜」に何も起きないのが物足りなければ、M4 の最初の一歩として「七日目の夜だけ月が少し大きく見え、音が消える」を足す案がある（巻き戻しなし）。

## 4. 天の鍵（実装）

### 4.1 そろう条件

| 項目 | 決まり |
| --- | --- |
| 条件 | **自分で四体の心臓を止めた（段階 4）** かつ **天の鍵の欠片を四つ持っている**。1 秒ごとに見る |
| 理由 | 欠片はどの巨神のものも同じ品（`skyabyss:sky_key_fragment`）なので、持っている数だけでは「誰かにもらった四つ」と区別できない。段階は順番どおりに止めた心臓だけを数える（10 の 3.1 節） |
| 起きること | 欠片 4 つを取り、天の鍵（`skyabyss:sky_key`）を渡す。伝承「天の鍵」（`chapter1/sky_key_whole`）を記し、クエストへ合図 `sky_key_assembled`。その人の画面に場面。ワールドで最初なら、ほかの全員に一行「〜の手の中で、天の鍵が形をとった。」。光の粒がその人の上から落ちる（ほかの人にも見える） |
| 記録 | `StoryData`（`skyabyss_story`）: そろえた人とその日、ワールドで最初の人。一人一回 |
| 品 | 一つだけ、火に強い、捨てられない、倒れても消えず控え帳が在りかを追う（`Keepsakes` の守る品に足した）。鍵にしたあとは、欠片が手もとになくても「なくした」と見ない（心臓がもう一つ欠片を渡さない） |

### 4.2 品の絵

32px、3 案（`docs/review/sky_key_roughs/compare.png`、生成 `tools/gen_story_assets.py --option A|B|C`）。

| 案 | 形 | 判断 |
| --- | --- | --- |
| A | 四つが組んだ円盤（継ぎ目が十字に光る） | 欠片と同じ石の円盤で「組み上がった」が分かる。鍵には見えにくい |
| B | 四色の輪の鍵（柄が斜め下） | 鍵らしいが、柄が細く 32px で読みにくい |
| **C（仮に採用）** | A の円盤から、下へ一本の柄が伸びる | 円盤が欠片の続きに見え、柄が**下を指す**。物語（鍵は足もとを指す）と合う |

四つの象嵌の色は巨神ごと（岩鯨の青、潮殻の青緑、雷翼の淡い黄、余燼の熾火）。雷翼・余燼の色は 12・13 で決まったら合わせる。

### 4.3 場面（`client/story/SkyKeyScene`）

ゲームは止めない。Esc で終わりの札へ飛ばせる。

| 時刻 | 画面 | 音 |
| --- | --- | --- |
| 0〜1.2 秒 | 画面が暗くなる（上ほど濃い。空が暗くなる） | — |
| 0.6〜4.4 秒 | 四つの欠片が四隅から回りながら寄っていく。それぞれの後ろに巨神の色の淡い光 | 2.95 秒から、四つの澄んだ鳴りが一つずつ |
| 4.4 秒 | 触れ合って白く光り、天の鍵になる | 鳴りが寄り合って和音、低い響き |
| 5〜19 秒 | 空から光の筋が落ちて、画面の下（足もと）へ沈む。鍵から真下へ細い光。四行の文が一つずつ | 11.4 秒と 13.6 秒に、足もとの遠い鼓動 |
| 20 秒〜 | 終わりの札。「一章　天の鍵」「ベータ版はここまでです」「遊んでくれて、ありがとう。」「この世界の N 日目」、下に「Esc かクリックで戻る（巨神の背の周回と頼みごとは、このあとも続けられる）」 | — |

四行の文:

1. 四つの欠片が、手の中で触れ合った。
2. 継ぎ目が、ひとりでに消えていく。
3. 鍵は、空を指さなかった。
4. 足もとの、ずっと下。何かが、ゆっくりと打っている。

- 音は合成（`tools/gen_story_assets.py`。01 の「既存の音を使わない」）。`assets/skyabyss_story/sounds.json` に置き、画面だけで鳴らすので登録しない。
- 場面のあと、天の鍵を手に持っていると、14 秒ほどに一度、足もとのずっと下で小さく打つ（オーバーワールドだけ）。鍵から光の粒が一つ、下へ落ちる。
- 01 の「言い伝えでは雲の上へ続く扉の鍵」と食い違わせない。鍵は「上の扉」を否定せず、「先に下を向いている」だけを見せる。語り部の「鍵というのは、開けたい扉のほうを向くものだよ」が 2 章（深淵へ潜る）への引き。

### 4.4 その後の会話

| 人 | 中身 |
| --- | --- |
| 語り部（メイン「天の鍵」） | 「この鍵、下を向いて打っているよ」→ 数え歌のいつつめを思い出す「いつつ　いきづく　つちのそこ」（伝承「数え歌のいつつ」）→「むっつから先は、まだ出てこない。……鍵というのは、開けたい扉のほうを向くものだよ」 |
| イサナ（一度だけ） | 「空の扉を開ける鍵だと、ずっと思っていた。……下を向いているな」「俺はずっと、上ばかり見ていた。……足もとのことは、考えたこともなかったな」 |

数え歌の「いつつ」は、07 の「数え歌のつづき」で語り部が「ここまで出かかっているのに」と言った所の答え。むっつから先は 2 章以降に残す。

### 4.5 コマンド（管理者）

| コマンド | 内容 |
| --- | --- |
| `/skyabyss story ready <人>` | 四体の心臓を止めたことにし、欠片を四つまで足す（1 秒後に鍵がそろい、場面が出る） |
