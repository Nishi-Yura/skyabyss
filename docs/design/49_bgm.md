## 1. 決まったこと

- マインクラフトの曲は流さない。場所と戦いに合わせた Mod の曲だけを流す（Wynncraft の土地ごとの曲が手本）。
- 曲はどれも **1 周で頭へつながるループ**。曲の終わりは落ち着かせず、頭へ流れ込む形で書く。はみ出た余韻と残響は頭に重ねて書き出すので、つなぎ目でも響きが切れない。
- 楽器は生の楽器の音源（GeneralUser GS）で鳴らす。曲の作曲・編曲・書き出しは手元のスクリプトで行い、外の作曲の道具は使わない。
- 町に入ったときの鐘の合図は作らない（2026-10-30。曲だけ）。

## 3. 選び方と切り替え（`client/music/MusicDirector`）

上ほど強い。

1. タイトル画面 → `title`。
2. 見る者・空の通過・雲の目の間は無音（`hushesMusic`。01 の「引き算」。曲が鳴り続けていても消える）。
3. 曲を流すボスの帯（`setPlayBossMusic`。`MusicArea.bossBar` で付ける）が出ている → 帯の名前の鍵が `_heart` か `heart_warden` なら `heart`、ほかは `boss`。名のある野良の敵と、深淵の護衛の帯には付けない。
4. ディメンション: 深淵 → `abyss`、月 → `moon`、巨神の背（`titan_back`・`tide_back`・`storm_back`・`ember_back`）→ `back`。
5. 地上: サーバーが知らせる場所（`ContinentAreas` の読み。`MusicArea` の通信）→ 都・町・土地の曲（`MusicTracks.forArea`）。場所の境目は名前の札と同じ揺れ止め（同じ読みが 2 回続いたら替わる）。

- 曲が替わるときは、前の曲を 2 秒で消しながら次の曲を 2.5 秒で入れる。ボスと心臓へは前の曲を 0.75 秒で消す。同じ曲のままなら続ける（場所を出入りしても頭からやり直さない）。
- 音の仕組みの読み直しなどで止まったら、5 秒おいて入れ直す。
- 音量は音楽の音量（マインクラフトの設定の「音楽」）に従う。

## 4. 曲の作り方（`tools/gen/music`）

| ファイル | 役 |
| --- | --- |
| `sf2.py` | SoundFont 2 を読んで一音ずつ鳴らす（区分の選び・音程・ループ・音量の包絡・強さ・ローパス・ビブラート・左右）。外のプログラムは使わない |
| `gm.py`・`arrange.py` | 楽器の役（`ROLES`。音源の bank と program）と、曲の組み立て（旋律・和音の敷き・分散和音・低音・打楽器・根音に合わせたティンパニ・ハープの駆け上がり） |
| `score.py` | 楽譜の書き方（旋律は `F#5:2 E5:.5 D5:.5 \| …`、和音は名前）。小節ごとの拍の数を検める |
| `synth.py` | 混ぜる所（組ごとに鳴っている所の大きさをそろえる・残響・ループの折り返し・Ogg の書き出し）と、合成の楽器（予備） |
| `track_<id>.py` | 曲ごとの楽譜（`capital` は `track_capital.py`、ほかは `Song`） |
| `check.py` | 耳の代わりの検め: 楽器の音程、伴奏だけの和音の合い方、音量の流れ、割れ、ループのつなぎ目の段差、図 |
| `build_all.py` | まとめて書き出し → 検め → `install.py` で `sounds/music/<id>.ogg` と `sounds.json`（`stream`）へ |

- 音源: `tools/sources/soundfont/GeneralUser-GS.sf2`（GeneralUser GS 2.0.3。使用条件は同じ所の `LICENSE.txt`。git には入れない。入手先は同じ所の README）。ゲームに入るのは書き出した曲だけ。
- 音源の癖: 合唱は録音が 20 セント高いので下げる。ティンパニは 18 セント高いので下げる。オカリナは音程が大きくずれるので使わない。教会の鐘は低い音域で高さがぼやけるので F#4 より上で使う。手太鼓（G#3）と和太鼓（F1）は曲の主音か和音の音へずらす（`HAND_TO`・`TAIKO_TO`）。低い音域の刻みは弦の合奏でなくチェロの独奏で弾く（合奏の低い音は 30 セントほど低い）。
- 検めの目安: 伴奏だけで、和音の音に入る割合が拍ごとに 0.6 以上（残りは楽器の倍音と前の和音の余韻）。ループのつなぎ目の段差は、曲の中のふつうの段差より小さいこと。
- 作り直し: `python -X utf8 tools/gen/music/build_all.py [<id> …]`（都の曲は `track_capital.py` を直接）。

## 5. 確かめ

- 自己テスト `music`: 曲ごとの音の名前・ogg・`sounds.json` の `stream`、地上の場所（都・町 4・土地 6）がどれも曲に当たる、ボスの帯の印。
- 撮影の台本 `tools/shots/music_check.txt`: 場所・ボス・心臓・深淵・月・巨神の背・島で流れる曲と、1 周を超えて鳴り続けるか（記録の `[shots] music`）。撮影は全体の音量が 0 で、本体は鳴らさないので、台本の `music master 0.0001` で聞こえないほど小さくして鳴らす。
- マインクラフトの Ogg の読み手（`JOrbisAudioStream`）は最後のページの長さで切りそろえ、ループ（`LoopingAudioStream`）は終わりから頭へそのまま続ける。つなぎ目に無音は入らない。
