# 天と淵のあいだ 心臓の遺物の選択画面

- 文書番号: 30
- 範囲: 心臓を初めて止めたあと一度だけ選べる専用の逸品（初回の選択）を、巨神の眠りの場面が終わったときに出る専用の画面で選ばせる仕組み。画面の作り・開く時機・サーバーの決まり・入口（旅嚢・控え帳・コマンド）・自己テスト。
- 関連: [03](03_gear_and_endgame.md)（専用の逸品・図鑑・天井）、[18](18_notices.md)（暗い石板の見た目・文字の決まり）、[20](20_cinematics.md)（3.4 巨神の眠り）、[22](22_mod_pouch.md)（旅嚢の画面）、[11](11_record_screen.md)（控え帳）

試遊の声: 「心臓を倒した後、一度だけ手に入るアイテム、専用 UI を用意して、岩鯨のムービーが終わったときに出して選べるようにして。」

---

## 1. 決まり（四体とも同じ）

| 項目 | 決まり |
| --- | --- |
| 対象 | 心臓を初めて止めた人（記録 `TitanMemoryData.Record` の `firstCleared` が立つ瞬間に `choicePending` が立つ）。巨神ごとに一度 |
| 選べる品 | その巨神の装備の表（`TitanGearSets`）の専用の逸品のうち、作られている品。岩鯨は鉾・顎牙・補強板、潮殻は大鋏・銛・真珠、雷翼・余燼もそれぞれ三つ。作られていない品は外し、一つも無ければ画面を開かず「できたら選べる」とだけ知らせる |
| 一人ずつ | 記録は UUID ごと。パーティの仲間はそれぞれの画面でそれぞれ選ぶ（同じ品を選んでもよい。一人の選びがもう一人の選びを消さない） |
| 受け取りの一箇所 | `loot/reward/HeartReward.claim`。`choicePending` を倒して渡すのはここだけ。同じ人の二度目は `NOT_PENDING` で断る。コマンド `/titanmemory <巨神> choose`・パケット・自己テストはすべてここを通る |
| 持っている品 | ほかに選べる品があるあいだは `OWNED` で断る（同じ品を二つもらっても意味がない）。三つとも持っているときは、持っている品も選べる（選ぶ品がなくならない） |
| 渡し方 | 特性をその場で引いて（`AffixRules.withAffixes`）、`TitanLoot.handOver`。持ち物がいっぱい・受け取れない状態なら預かり（`/titanmemory claim`・目覚め・入ったときに渡る）。図鑑（`owned`）に記す。天井のカウンタは戻さない |
| 保存 | `choicePending` のまま記録に残る。ログアウト・サーバー再起動をまたぐ。選ぶまで消えない。サーバーだけが持ち、画面は見せるだけ |

## 2. いつ開くか

1. 心臓が止まると、各背の報酬の知らせで `choicePending` が立ち、字幕の手がかり一行（`skyabyss_reward.announce`）だけ出る。チャットは使わない。
2. 運び出し（`TitanEnd.deliver`）で地上に降ろされ、初めてなら眠りの場面 `titan_end_<巨神>` が流れる。**場面が終わったら**（最後まで見ても、スキップしても、サーバーの打ち切りでも）`HeartReward.register` が掛けた聞き手が、`OPEN_AFTER_SCENE`（50 tick。章の余韻の札と重ならないように）あとに画面を開かせる。
3. 場面が始められなかった・二回目以降で場面がない降ろしは、降ろされて `OPEN_AFTER_CARRY`（110 tick）あとに開く。
4. 開く時点で場面の最中・倒れている・まだ降ろされていない（`TitanEnd.holding`）ときは、40 tick ずつ最大 6 回待つ。抜けていれば何もしない。選び終えていれば何もしない。
5. 入り直したとき、選ぶのを待っている人には 5 秒後に一行の手がかり（`skyabyss_reward.waiting`）。自動では開かない（入った直後の画面を奪わない）。

## 3. 「あとで」と入口

- 画面で Esc を押すと、そのまま閉じずに「あとで選びますか？」の窓（いまは「いま選ぶ」が既定のつまみ）。Esc をもう一度押すと選ぶ画面へ戻る。「あとで選ぶ」を選んだときだけ閉じ、サーバーに `Later` を送る（一行の案内が出るだけ。記録は変わらない）。
- 選ぶまで、次の入口から何度でも開ける。いずれも、サーバーに `Request` を送り、サーバーが選べるかを決めて `Open` を返す。
  - 旅嚢の画面（キー I）の上の「遺物」ボタン（金の縁がゆっくり点る。選べる遺物があるときだけ出る。`State` 旗で出し入れ）
  - 控え帳の「権利」の頁の「初回の選択報酬（巨神名）」の行（選べるときは行を押せる。四体とも）
  - コマンド `/titanmemory reward`
- 遺物の祭壇（専用の置物）は作っていない。入口は上の三つで足りる（案が出たら、同じ `Request` を送る口を一つ足すだけ）。

## 4. 画面（`client/reward/HeartRewardScreen`）

見た目は暗い石板に画素の枠（18 の見た目）。題字は 18 の `TextStyle.TITLE`（光のにじみつき）、巨神ごとに題字と、枠・線の差し色が違う。

- 題字: 「岩鯨の心臓が遺したもの」「潮殻の心臓が…」「雷翼の…」「余燼の…」（`skyabyss_reward.title.<巨神>`）。その下に巨神ごとの一行（鼓動・潮・雲・熾に寄せた言い回し）。差し色は岩鯨 青灰、潮殻 青緑、雷翼 黄、余燼 橙。
- カード: 選べる品ごとに一枚。絵を 3 倍で大きく（高さが足りないときは 2 倍）、名前（階級の色）、階級 · 由来、種類（武器・防具・護符・装飾）、効果と物語の一行（装備のツールチップの 3・4 行目）、必要 Lv（足りなければ赤）、いま付けている装備の名前と、数値の比べ（攻撃力・攻撃速度・防御・強靭と、その枠に効くほかの足し算の補正。`現 → 新 ▲▼＝` を緑・赤・灰で）。装飾は同じ種類の枠に付けている品の名前。持っている品には「所持済み」の札。
- 流れ（幕 → 選ぶ → 確かめ → 待ち → 完了）:
  1. 幕（約 1.3 秒）: 暗転 → 題字が浮かぶ → カードが 0.45 秒おきに一枚ずつ上がる（小さなチャイム）。このあいだは押せない。場面の続きでうっかり押しても選ばれない。
  2. 選ぶ: マウスを重ねるか、← → / A D / ↑ ↓ / Tab / 数字キー / ホイールで見る。Enter・Space・クリックで決める。選んでいるカードは少し浮き、光る。
  3. 確かめ: 「『○○』を受け取りますか？」。受け取る / 選びなおす。入った直後の 0.5 秒は Enter もクリックも効かない（二重押しの事故防止）。Esc で選ぶへ戻る。
  4. 待ち: サーバーの返事待ち（点が動く）。断られたら理由を出して選ぶへ戻る（すでに受け取っているときは閉じる）。
  5. 完了: 選んだ品が中央で大きく光り、「『○○』を手にした」。粒と輪が広がり、約 3.5 秒で閉じる（0.7 秒後から Enter・クリックで閉じてもよい）。
- Esc は、幕・待ち・完了のあいだは何も起こさない（取りこぼし防止）。
- 一人用でもゲームを止めない（止めると統合サーバーが `Claim` を処理できない）。
- **開いている間の守り**: 画面を開いている間（と、`Open` を送ってから画面が出るまでの 8 秒）、本人は傷つかず（`/kill` と虚空は除く）、敵は本人を狙わない（`LivingIncomingDamageEvent` を取り消し、`LivingChangeTargetEvent` を取り消し、すでに狙っている敵は 1 秒に一度外す）。クライアントが画面の `tick` から 10 tick ごとに `Hold` を送り、サーバーが 2 秒ぶん延ばす。閉じて 2 秒で切れる（旗を持たないので、落ちても残らない）。
- **マウスの矢印**: 画面を開いたときと毎 tick、マウスが捕まっていれば放し、GLFW のカーソルを通常にする（場面やほかの画面のあとで矢印が出ないことがあった）。矢印の下のカードは、`mouseMoved` が来なくても毎フレーム調べて強調する（開いた時に動かさなくても付く）。
- 音は控えめ（チャイム・共鳴・トーストの完了。音量は UI 音）。`skyabyss_reward.*` の日英は `assets/skyabyss_reward/lang/`。

## 5. パケット（`loot/reward/HeartRewardNet`、版 `heart_reward-2`）

| 名前 | 向き | 中身 |
| --- | --- | --- |
| `Open` | サーバー → 持ち主 | 巨神・選べる品の ID・持っている印・自動で開いたか |
| `State` | サーバー → 持ち主 | 選べる遺物があるか（旅嚢のボタンの旗。入ったとき・選んだとき・足されたときに送る） |
| `Result` | サーバー → 持ち主 | 選んだ結果（0 = 受け取った、1 = すでに受け取り済み、2 = 選べない品、3 = 持っている） |
| `Claim` | 持ち主 → サーバー | 巨神・品の ID |
| `Request` | 持ち主 → サーバー | 選べる遺物の画面を開いて |
| `Later` | 持ち主 → サーバー | 「あとで」にした |
| `Hold` | 持ち主 → サーバー | 画面を開いている間、10 tick ごと。サーバーは 2 秒ぶん「守り」を延ばす（傷つかない・狙われない） |

## 6. 開発用

- `/skyabyss dev heartreward <titan>`: その巨神の遺物を選べる状態にして画面を開く。`/skyabyss dev heartreward reset`: 選べる状態を全部消す。
- 台本 `tools/shots/heart_reward.txt`（`heartreward focus|confirm|later|done <番号>` で見せ場まで進める。音は自動で 0）。絵は `docs/review/previews/heart_reward_ui.png`（岩鯨・日本語）。
- 自己テスト: `SKYABYSS_SELFTEST=1 SKYABYSS_SELFTEST_ONLY="heart reward" ./gradlew runServer`（`loot/reward/HeartRewardSelfTest`）。
  - 選べる品（四体とも専用の逸品・作られた品だけ）、一度だけ受け取れる（二度目は断る・持ち物に一つ・図鑑に記す）、選べない品・持っている品を断る（記録は変わらない）、入り直し（記録の保存の往復・開き直せる）、二人（別々に選べる・同じ品でもよい・取り違えない）、「あとで」で記録が変わらず、あとでも一度だけ受け取れる、パケットの往復、日英の文、場面の終わりで画面が開く（スキップでも。終わる前・終わった瞬間には開かない）。
- 画面の描画・マウス・キーの操作は窓がないと確かめられないため、台本の絵と実機（ユーザー）で見る。

## 7. まだ見ていないもの

- ユーザーの実機でのマウス・キーの操作感（ホバーの浮き、確かめの 0.5 秒の効かない時間の長さ）。コントローラーは、キーの矢印・Enter の割り当てがあるものだけ（専用の対応はしていない）。
- 英語の題字・カードの幅（英語の長い名前は 2 行に折り返す）。
