# 天と淵のあいだ 巨神編の厚み（地上の支度と背中の拡張）

巨神に会うまでの地上と、巨神の背中（ダンジョン）の中身を増やし、初回の体験を厚くする計画。**今の仕様ではなく、これから作る分の仕様（案）**。決まった分は各巨神の書類（02・08・12・13）へ移し、この書類は残りの計画だけにする。判断の項目（目標の長さ、旅装の作り方、心臓戦の死の扱い、岩鯨の降下、追憶の宝、新しいモブの順、任意の翼の報酬、旅の職人）は決まっており、本文はその答えのとおり。

## 0. 前提と方針

### 0.1 試遊で出たこと

- みんなで遊んだ人が、装備なしで岩鯨の心臓に挑み、倒れては休み場から戻る（「扉があなたを覚えていた」。02 の 4.2）のを繰り返して勝った（ゾンビ戦法）。
- 地上の章の中身（01 の 4.2）が短く、岩鯨に着くまでに「備える理由」と「備える手段」がなかった。装備はぜんぶ背中の敵と心臓から出る（03 の 8〜11 章）ので、**初めての心臓の前に手に入るのはバニラの装備だけ**だった。
- 背中は 1 周 20〜35 分。東の翼は短くしたまま（02 の 3.2）、周回で一つの試練が眠る（08 の 7.2）ので、初回にしか味わえない所が少ない。

### 0.2 方針（この書類全体の決まり）

1. **初回を特別にする。** 初回だけ長い道・場面・一度きりの宝がある。周回は今の長さのまま（背中 1 周 20〜35 分）で、眠る試練・既知の道で短くする（1.7）。
2. **地上は「支度」の章にする。** 各章の巨神の前に、遊ぶ場所・やること・人との話・手に入る品を足し、心臓の前に自然に身じたくが整う形にする。
3. **ふさがない。** 備えが足りなくても乗れる・戦える。足りなさは「見える」ことと、戦いの中の小さな重みで伝える（1.2・1.3）。
4. **巨神ごとの言葉を守る。** 敵・素材・場所は、その巨神の形と色の言葉だけで作る（岩鯨 = 骨・苔・灰青の皮・琥珀の目・茶の岩殻、潮殻 = 珊瑚・真珠層・青緑・白、雷翼 = 銅・青白い光・白い羽・灰青、余燼 = 黒玄武岩・赤橙・灰）。他の巨神の敵の使い回しに見せない。
5. **先を言わない。** 序盤の文と頼みは、心臓・深淵・巨神の眠りの理由など物語の核心を書かない（01 の 3 章、17 の 5 章と同じ）。違和感と暮らしの小さな変化だけで運ぶ。
6. **ホラーの順番を崩さない。** 新しい敵は、予兆の 3 拍（01 の 4.1）の最中には置かず、小さな場所と夜の外れに置く。ジャンプスケアは足さない。
7. **マルチでも同じ形。** 地上の場所はワールドに一つ作って近くの人と共有し、敵と進みは人・グループごとに持つ（1.5）。

### 0.3 守る既存の決まり

四つ目の試練は足さない（01 の 4.2）。レベルの上限は変えない（15・21・27・33・40）。背中の敵はすべて新しいキャラで壁をすり抜けない。背中のブロック設置・破壊と近道の禁止。倒れても持ち物を失わない。ボスの技は予告が 1 秒以上あり、跳ぶ・走る・隠れるで避けられる。人数が増えても取り分は減らさず、敵と体力が増える（02 の 4.2）。

### 1.3 心臓戦の死の扱い（ゾンビ戦法の穴を塞ぐ）

背中の復帰（倒れても持ち物を失わない）は変えない。四体の心臓の共通部品 `HeartBoss` に足す。

| 決まり | 中身 |
| --- | --- |
| 復帰の待ち | 戦いの部屋（心臓の間・中ボスの広間）で倒れた人は、前室で目を覚ましてから 20 秒たつと扉に触れて戻れる。戻る人には 3 秒の無敵の光（技の最中に入って瞬殺されない）。待ちの残りは帯に出す |
| 復帰の上限 | ゲームルール `skyabyssHeartReentryLimit`（既定 3）。人ごとに 1 回の戦いでその回数まで戻れる。使い切った人は、その戦いが終わるまで扉を通れない（観戦。前室の窓・扉の外から見える）。0 = 無制限 |
| 全滅 | 中に生きた参加者がいなくなれば、戦いは最初からやり直し（今の仕組み）。復帰の回数も 0 に戻る |
| 報酬 | 変えない（倒れても参加者のまま。02 の 4.2） |

- 目的: 装備なしで「死んで戻る」を繰り返す遊び方をふさぎ、技を避けて学ぶ遊びのほうを近道にする。心臓の強さ自体は倒れた回数では変えない（擦り切れは入れない）。
- 自己テスト `SELFTEST heart reentry`（新設）: 20 秒前は通れない・20 秒後に通れる・上限で止まる・全滅で数が戻る・ゲームルールの値。

| 2 | 刃を研ぐ | 章の小さなダンジョン（1.5）を抜ける。砥石の作り方を覚え、砥石を使った武器で番をたおす |

- 三本そろうと、章ごとの合図「備えができた」（`ch<n>_ready`）が立つ。一章だけは岩鯨の降下の条件にも使う（3.2）。

**旅の覚書**: 序章の野営地の帳面（伝承の書。05）と同じ作りの、薄い手帳（`wayfarer_notes`）。章ごとに 1 冊、備えの頼み 1 を受けたときに渡り、レシピの解放（旅装・砥石・糧・薬）と、その章の敵の見分け方（「盾の岩殻虫は後ろへ回れ」など、**背中の敵の予習**）を絵と一行ずつで見せる。レシピは覚書を開いたときに解く（レシピブックの解放。新しい画面は作らない）。

**旅の職人**: 新しい人物（役名。固有の名前は付けない。名前は重要人物だけ。07 の 3.5）。旅の道具を直し、旅装を編む。村の外れ（一章は鐘の宿りの鍛冶の脇、以降は各章の拠点の近く）に立ち、**章ごとに装いが変わる**（一章 = 灰青の外套と岩殻の前掛け、二章 = 塩で白い前掛け、三章 = 銅の針金の飾り、四章 = 煤けた腕当て）。同じ顔・同じ口調で、前のことを覚えていない（イサナの「どこかで会ったか？」と同じ方向。07 の 4.5）。

- 見た目: 1 体のモデル（低ポリ。語り部・イサナと同じ手順。07 の 3.4）に、章ごとの 4 通りの絵を重ねる。ラフは 3 案。
- 出し方: 07 の 3.2 と同じ（章が開いた人の拠点の近くに立たせる）。マルチでは近くの人と共有。

**鼓動守**（巨神ごと。装飾品の枠。03 の 6.3）: 備えの頼み 3 の報酬（一人一つ）。**戦いで一度だけ**、致命の一撃を体力 1 で耐える（人ごと、その戦いの 1 回。使うと光って消える）。補充は職人に頼む（その章の地上の素材 8 つで 1 日に 1 つまで）。深く考えなくても使える「保険」で、備えの糧の灯に 0.2 足す。心臓以外の戦いでは働かない。

### 1.6 アートと新しいモブの決まり

- 新しいモブ・人物・ブロックの見た目は、どれも**ラフ 3 案を選定ページに載せて選んでから**作る（`tools/rough/build_gallery.py`。HANDOFF の手順）。ラフを選ぶまで実装に入らない。
