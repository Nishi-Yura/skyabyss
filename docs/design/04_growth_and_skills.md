## 1. 方針

| 目標 | 具体策 |
|---|---|
| 強くなる実感 | レベルが上がるたびに力を 3 つ振り分ける。画面で数値の変化がすぐ見える |
| バニラを壊さない | ステータスの効果はすべてバニラの値への上乗せ（AttributeModifier）。武器・防具・ポーションの強さの順は変えない。筋力を上限まで上げても、ダイヤの剣なら筋力 I のポーション（+3）より小さい |
| マルチで取り合いにならない | ボスの経験値は参加者それぞれに満額。道中の敵は近くの人で分け、人数ぶん全体を少し増やす |
| 周回で上がりすぎない | 内容ごとに推奨レベルを持ち、超えた人の取り分を減らす（最低 20%）。次の巨神へ進む理由を作る |
| ループで消えない | 成長の記録はプレイヤーに付けて保存する。月が落ちても巻き戻さない（01 のループの表のとおり） |

- 経験値はバニラの経験値（エンチャントに使う緑の玉）とは別に持つ。バニラの経験値はそのまま残す。
- 01 の「RPGシステム」との食い違いはない。01 で決めていなかった数値をここで決めた。

## 2. 成長の記録

### 2.1 持つもの

| 項目 | 範囲 | 備考 |
|---|---|---|
| レベル | 1〜50 | |
| 経験値 | 0〜次のレベルに要る量 − 1 | いまのレベルの中で貯めた量。上限では 0 |
| ステータス（筋力・敏捷・精神・耐久） | 各 0〜50 | |
| 追加の力 | 0〜 | レベル以外から得た力。今は使っていない（記憶の断片やクエストの報酬に使う予定） |
| 記憶の断片 | 種類ごとの数 | 器の大きさ（はじめ 12）を超えて入らない |
| 発見の記録 | 文字列の集合 | 一度だけの経験値（新しい場所、初めての撃破）。サーバーだけが持つ |
| バニラの敵の今日の量 | 日付と量 | 日ごとの上限（3.4節）。サーバーだけが持つ |

- 未割り振りの力は持たない。「レベルからの力 + 追加の力 − 振った量」で毎回求める。数が食い違うことがない。
- 振った量が持っている力より多くなったとき（管理者がレベルを下げたなど）は、振り分けをすべて戻す。

### 2.2 保存と、消えないもの

保存は NeoForge の Data Attachment（`skyabyss:growth`）。プレイヤーのデータと一緒に保存する。

| 場面 | 扱い | 仕組み |
|---|---|---|
| 死亡 | 残る | `copyOnDeath`。復活した体へ写す |
| ディメンションの移動 | 残る | 1.21 ではプレイヤーの体がそのまま移るので、記録も一緒に移る |
| エンドの帰還 | 残る | 死亡と同じく写す |
| ログアウト・再起動 | 残る | プレイヤーのファイルに保存する |
| 月の落下（ループ） | 残る | ループの処理はこの記録に触れないこと（ループの担当への約束） |
| 背中の試練のリセット | 残る | 試練は世界の保存データだけを戻す |

- ステータスの修飾子は「保存される修飾子」にした。ログインしたとき、修飾子より先に体力が読まれて 20 に切り詰められる、ということが起きない（自己テストで確認。9章）。
- 修飾子は、ログイン・復活・ディメンションの移動・振り分けのたびに今の値で付け直す。数式を変えても次のログインで正しい値になる。

### 2.3 同期

- 記録は持ち主のクライアントにだけ送る（Data Attachment の同期。ほかの人には送らない）。発見の記録と日ごとの量は送らない。
- 「経験値を得た」ことは別の小さな知らせ（`growth_gain`：量、理由、上がったレベル数）で送る。画面の「+12」とレベルアップの文字に使う。
- 振り分けはクライアントから「4 つへの追加量」を送り、サーバーで検める（負の数、持っている力を超える、上限 50 を超える、をはねる）。

### 3.3 マルチプレイの分け方

- **道中の敵**: 倒した人と、敵から 32 ブロック以内にいた生きているプレイヤー（観戦者を除く）で分ける。n 人のとき、一人あたり **元の量 ×（1 + 0.25 ×（n − 1））÷ n**。
  - 1 人 1.0、2 人 0.625、3 人 0.5、4 人 0.4375。全体では人数が増えるほど少し多くなる（協力の得）。
  - 背中の広間は人数で敵が増える（02 の 4.2節）。第一の広間の第一波で一人あたりを比べると、1 人 42、2 人 41.3、3 人 45.0、4 人 49.9 で、ほぼ同じ（自己テストで計算）。
  - 端数は確率で切り上げる（4.4 なら 40% で 5、60% で 4）。小さな値が切り捨てで消えない。
- **ボス**: 参加者それぞれに満額。ボスは人数で強くなる（体力 ×（1 + 0.6 ×（人数 − 1）））ので、取り分は減らさない。02 の報酬（一人ずつの抽選）と同じ考え。
- **試練の踏破**: 石の近くにいた全員に満額。西のアスレのように一人が先に着いても、近くまで来ていればもらえる。
- **倒したのが飼い慣らした動物や矢**: 持ち主を「倒した人」とする。ほかの Mod の偽のプレイヤー（機械）が倒した分は数えない。

### 3.4 上がりすぎの補正・日ごとの上限

- **推奨レベル**: 内容ごとに推奨レベルを決める（岩鯨は 12）。推奨 + 3 までは満額。超えた 1 レベルごとに 10% 減り、最低 20%。
  - 岩鯨では、15 まで満額、20 で 50%、23 以上で 20%。
  - 一人ずつのレベルで決まる。高いレベルの仲間が手伝っても、低いレベルの人の取り分は減らない。
- **バニラの敵**: 1 日（ゲーム内の 20 分。昼夜の切り替えではなく経過時間で数える）に 150 までは満額、超えた分は 20%。スポナーの敵は 0。
  - 経験値の畑（トラップタワー）で一晩に何十レベルも上がる、ということを防ぐ。ふつうの冒険では上限にほとんど届かない。

背中に乗る前に地上で 400 ほど（バイオーム十数か所と夜の敵）を得たとして、岩鯨を毎回最後まで攻略した場合の計算。1 周は道中の敵 172、番兵長 100、心臓 300、試練 3 つで 120 の計 692（1 回目は発見と初回の上乗せで +480）。

| 3 | 692 | 2,956 | 12 | |
| 5 | 692 | 4,340 | 14 | |

## 4. ステータス

### 4.1 振り分け

- レベルが 1 上がるごとに力を **3** つ。レベル 50 で 147。
- ステータス一つの上限は **50**。147 あれば、3 つを上限近くまで上げられる。全部を一つに振ることはできない。
- 振り分けはステータス画面（6.3節）か `/growth add`。一度決めた振り分けは戻せない（振り直しは 11章の判断 1）。

### 4.2 効果

| ステータス | 1 あたりの効果 | 10 のとき | 27 のとき（Lv10 で全部） | 50 のとき | バニラとの比べ |
|---|---|---|---|---|---|
| 筋力 | 近接攻撃の威力 ×（1 + 0.6%） | +6% | +16.2% | +30% | ダイヤの剣 7 → 9.1。筋力 I のポーション（+3）より小さい |
| 敏捷 | 移動の速さ +0.2%、攻撃の速さ +0.2%、飛び道具の威力 +0.4% | +2% / +2% / +4% | +5.4% / +5.4% / +10.8% | +10% / +10% / +20% | 移動速度 I のポーション（+20%）の半分 |
| 精神 | 最大マナ +2（素の値 20） | 40 | 74 | 120 | マナを使う術はまだない（10.4節） |
| 耐久 | 2 につき最大体力 +0.5（ハート半分） | +2.5 | +6.5 | +12.5 | 体力増強 I（+4）のおよそ 3 段ぶん |

- 筋力は武器ごと掛かる（掛け算）ので、良い武器ほど伸びる。素手は 1 → 1.3。
- 敏捷は近接と遠距離のどちらにも少し効く。弓使いの主なステータスになる（01 のクラスの表）。
- 耐久は 2 ごとにハート半分。ハートの列が増えすぎない範囲（上限で 2 列目の半分ほど）にした。
- 精神は今は最大マナだけ。属性「最大マナ」（`skyabyss:max_mana`、素の値 20、上限 1024）をプレイヤーに持たせた。装備やスキルからも同じ属性で足せる。

### 4.3 修飾子（実装）

| 効果 | 属性 | 修飾子の ID | 掛け方 |
|---|---|---|---|
| 筋力 | 攻撃力 | `skyabyss:growth/strength_melee` | 全体に掛ける（ADD_MULTIPLIED_TOTAL） |
| 敏捷（移動） | 移動速度 | `skyabyss:growth/agility_move` | 素の値に掛ける（ADD_MULTIPLIED_BASE）。走りの +30% はその上に掛かる |
| 敏捷（攻撃の速さ） | 攻撃速度 | `skyabyss:growth/agility_attack_speed` | 全体に掛ける |
| 敏捷（飛び道具） | —（被ダメージの出来事で掛ける） | — | プレイヤーが撃った飛び道具の威力に掛ける |
| 精神 | 最大マナ | `skyabyss:growth/spirit_mana` | 足す（ADD_VALUE） |
| 耐久 | 最大体力 | `skyabyss:growth/vitality_health` | 足す |

- 値が 0 のときは修飾子を外す。
- 最大体力が増えたとき、体力が満タンだった人は新しい上限まで満たす。減ったときは上限に収める。倒れて目を覚ましたときは満タン。

### 4.4 数値の理由

- 上乗せを小さめにした。巨神の装備（03）と共鳴の炉の強化が「強くなる」の主役で、ステータスはその下支え。どちらか一方だけで攻略が決まらないようにする。
- 岩鯨の初回は Lv 9 前後（力 24）。筋力に全部振っても +14% で、心臓（体力 450、02 の 5.3節）が簡単になりすぎない。
- 一つに振り切れないようにした上限 50 は、01 の「クラスは固定しない混合型」に合わせた。

## 5. 記憶の断片（器）

- 01：「ループをまたいでも消えない永続強化。ボス撃破や隠し要素で手に入る」。03 の 5.1節：攻撃・防御・移動・回復などの枝、上限を E9 で広げる。
- 今回作ったのは **器だけ**。種類（ID）ごとの数と、器の大きさ（はじめ 12）を記録する。効果はまだない。
- 付与は `Growth.grantFragment(プレイヤー, ID, 数)`。器に入りきらない分は付けず、付けた数を返す。付けると「記憶の断片『〇〇』が器に宿った（1 / 12）」と語りの色で出る。
- 決めてある種類:

| ID | 名前 | 入手（予定） |
|---|---|---|
| `skyabyss:prologue` | 最初の記憶 | 序章の報酬（01 の章構成） |
| `skyabyss:stone_whale` | 岩鯨の鼓動 | 岩鯨の心臓（入手の条件は 11章の判断 4） |

- 知らない ID も記録できる（名前は「名もない記憶」）。種類を足すときは `MemoryFragments` に ID を並べ、lang に `fragment.skyabyss.<名前>` を足す。
- 器の大きさは記録ごとに持つので、E9（上限の解放）はこの値を増やすだけで済む。

## 6. 画面と演出

### 6.1 画面左上の小さな表示

- 「Lv 12」と、その下に幅 64 の細いバー。振り分けていない力があれば、Lv の右に金色で「✦3」。
- 経験値を得ると、バーが一瞬白く光り、その下に「+12」が出て 3 秒で薄れる。撃破が続いたら一行にまとめる。理由のあるもの（「+30 谷の上の岩室」「+10 平原」「+300 岩鯨の心臓」）は淡い青、撃破は灰色。
- バニラの経験値バー（画面の下）には重ならない。F1（画面を隠す）と F3（デバッグ）では出さない。チャットより下の層に描く。
- テクスチャ `textures/gui/growth/hud.png`（2 倍の密度）。

### 6.2 レベルアップ

| 要素 | 内容 |
|---|---|
| 音 | 独自に合成した音（`growth_level_up`）。澄んだ三つの鐘（ラ・ミ・ラ）と、底の低い響き。共鳴石に近い音にした。近くの仲間にも小さく聞こえる |
| 光 | 体のまわりに白い光の粒（エンドロッド）24 粒 |
| 画面の文字 | 画面の中ほどより少し上に、淡い青の「力が満ちた」、左右へ伸びる青緑の細い線、金の「Lv 12」（1.5 倍）。0.5 秒で現れ、2.5 秒とどまり、1.5 秒で消える。画面全体の大きなタイトルは使わない |
| チャット | 前進の色（淡い青、✦）で「レベルが 12 になった。振り分けられる力が 3 増えた。」。はじめのうち（Lv 5 まで）と、力を 9 以上ためているときだけ、手がかりの色で「J キーの画面で力を振り分けられる」を添える |
| 上限 | Lv 50 に着いたとき、語りの色で「これより先は、記憶だけが積もっていく。」 |

### 6.3 ステータス画面（J キー）

- 題は「留まる者の記録」（主人公の呼び名から）。大きさ 240×184。背景は 2 倍密度のテクスチャ（`textures/gui/growth/status.png`、`tools/gen_growth_assets.py` で生成）。骨の枠と四隅の青緑の結晶、石板の地、行のくぼみ。色は共鳴の炉の画面にそろえた。
- 上から: Lv（金、1.5 倍）と経験値のバー（重ねると、これまでの合計と 50 までの量）、振り分けられる力、4 つのステータスの行、記憶の断片の数と「戻す」「決定」。
- 各行: 印（32px の絵を 16 で描く。筋力＝鯨骨の大剣、敏捷＝風を切る羽、精神＝三日月と星、耐久＝石の殻の心臓）、名前、値、効果の一行、－ と ＋。
- ＋ で仮に振り、「決定」でサーバーへ送る。決定までは － と「戻す」で取り消せる。シフトを押しながらだと 5 ずつ。仮の値と効果は淡い青で出す。
- 行に重ねると、そのステータスの説明と上限の説明。断片の行に重ねると、器の説明と持っている断片の一覧。

## 8. 実装メモ（ほかの担当へ）

| ファイル（`jp.revati.skyabyss.rpg`） | 役割 |
|---|---|
| `Rpg` | 登録（Data Attachment `growth`、属性 `max_mana`、音 `growth_level_up`） |
| `GrowthData` | 記録の中身、保存（NBT）と同期のコーデック |
| `GrowthRules` | 数値と計算（曲線、効果、補正、分け方）。ゲームの状態に触れない |
| `Growth` | 入口: `get`、`addXp`、`setLevel`、`allocate`、`resetStats`、`applyModifiers`、`discover`、`grantFragment` |
| `GrowthRewards` | 経験値の入り口（撃破、ボス、試練、場所）、修飾子を付け直す時機、敏捷の飛び道具 |
| `MemoryFragments` | 記憶の断片の種類 |
| `GrowthCommands`、`GrowthSelfTest` | コマンド、自己テスト |
| `net/*` | `growth_gain`（サーバー→持ち主）、`growth_allocate`（持ち主→サーバー）。`ModNetwork` とは別に登録 |
| `client/*` | キー、左上の表示、レベルアップの文字、ステータス画面 |

- **経験値を渡す**: `Growth.addXp(player, 量, 理由の翻訳キー)`。理由は画面の「+量 理由」に出る（空なら数だけ）。クエストの報酬はこれを呼ぶ。
- **一度だけ**: `Growth.discover(player, "quest:…")` が true のときだけ渡す。
- **ボスを足す**: 参加者の一覧が分かるところで `GrowthRewards.onBossDefeat` と同じように満額を渡す。今は岩鯨の 2 体を `TitanLoot.onHeartDefeat`／`onCaptainDefeat` の頭で呼んでいる（共有ファイルの変更はこの 2 行だけ）。
- **新しい敵**: `GrowthRewards.MOD_ENEMIES` に ID・量・推奨レベルを足す。
- **スキルとマナ**: 最大マナは属性 `Rpg.MAX_MANA` で読む（`player.getAttributeValue(Rpg.MAX_MANA)`）。今のマナの量はまだ持っていない（10.4節）。
- **ループの担当へ**: `Rpg.GROWTH` の記録は巻き戻さない。

触った共有ファイル: `SkyAbyss.java`（登録 1 行）、`loot/TitanLoot.java`（呼び出し 2 か所）、`lang/ja_jp.json`・`lang/en_us.json`（末尾に 51 行ずつ）、`sounds.json`（末尾に 1 件）、`tools/README.md`（表に 1 行）。

| 検査 | 内容 |
|---|---|
| 曲線 | 1〜49 で増え続ける、50 で 0、10 までの合計 1,758、50 までの合計 107,898、力の合計 147 |
| レベルの計算 | 49 では上がらず 50 でちょうど上がる。一度に 4 レベル上がり端数が残る。上限で止まり、あふれた分は捨てる |
| 振り分けの検め | 空・負・持っている力を超える・長さ違い・上限超えをはねる。正しいものは通す |
| 壊れた値 | レベル 99 → 50。レベルを下げて使いすぎになったら全部戻す |
| 分け方と補正 | 人数の割合、広間の一人あたり（1〜4 人で 42・41.3・45.0・49.9）、推奨レベルの補正、端数の切り上げ、バニラの日ごとの上限 |

| 死亡 | 復活と同じ写し方（`copyAttachmentsFrom(…, true)`）で記録が写る |
| ログアウト・ログイン | プレイヤーを丸ごと保存して読み直すと、記録が戻り、体力は 22/22（耐久 9）のまま（20 に切り詰められない） |

| 記憶の断片 | 器を超えて入らない。満杯なら入らない。負の数は入らない |
