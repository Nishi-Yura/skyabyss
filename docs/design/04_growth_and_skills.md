## 1. 方針

| 目標 | 具体策 |
|---|---|
| 強くなる実感 | レベルが上がるたびに力を 3 つ振り分ける。画面で数値の変化がすぐ見える |
| バニラを壊さない | ステータスの効果はすべてバニラの値への上乗せ（AttributeModifier）。武器・防具・ポーションの強さの順は変えない。筋力を上限まで上げても、ダイヤの剣なら筋力 I のポーション（+3）より小さい |
| マルチで取り合いにならない | ボスの経験値は参加者それぞれに満額。道中の敵は近くの人で分け、人数ぶん全体を少し増やす |
| 周回で上がりすぎない | 内容ごとに推奨レベルを持ち、超えた人の取り分を減らす（最低 20%）。次の巨神へ進む理由を作る |
| ループで消えない | 成長の記録はプレイヤーに付けて保存する。月が落ちても巻き戻さない（01 のループの表のとおり） |

- 経験値はバニラの経験値（エンチャントに使う緑の玉）とは別に持つ。バニラの経験値はそのまま残す。
- レベル上限は 50。物語の進みで決まる上限（15・21・27・33・40、番人を倒すと 50）は [10](10_progression_multiplayer.md) の 5 章。

## 2. 成長の記録

### 2.1 持つもの

| 項目 | 範囲 | 備考 |
|---|---|---|
| レベル | 1〜50 | |
| 経験値 | 0〜次のレベルに要る量 − 1 | いまのレベルの中で貯めた量。上限では 0 |
| ステータス（筋力・敏捷・精神・耐久） | 各 0〜50 | |
| 追加の力 | 0〜 | レベル以外から得た力。今は使っていない（記憶の断片やクエストの報酬に使う予定） |
| 記憶の断片 | 種類ごとの数 | 器の大きさ（はじめ 12）を超えて入らない |
| 発見の記録 | 文字列の集合 | 一度だけの経験値（新しい場所、初めての撃破）。サーバーだけが持つ |
| バニラの敵の今日の量 | 日付と量 | 日ごとの上限（3.4）。サーバーだけが持つ |
| ステータスの振り直しの回数 | 数 | `GrowthData.statRespecs`。技の回数とは別 |

- 未割り振りの力は持たない。「レベルからの力 + 追加の力 − 振った量」で毎回求める。数が食い違わない。
- 振った量が持っている力より多くなったとき（管理者がレベルを下げたなど）は、振り分けをすべて戻す。

### 2.2 保存と、消えないもの

保存は NeoForge の Data Attachment（`skyabyss:growth`）。プレイヤーのデータと一緒に保存する。

| 場面 | 扱い | 仕組み |
|---|---|---|
| 死亡・エンドの帰還 | 残る | `copyOnDeath`。復活した体へ写す |
| ディメンションの移動 | 残る | 1.21 ではプレイヤーの体がそのまま移る |
| ログアウト・再起動 | 残る | プレイヤーのファイルに保存 |
| 月の落下（ループ） | 残る | ループの処理はこの記録に触れない（ループの担当への約束） |
| 背中の試練のリセット | 残る | 試練は世界の保存データだけを戻す |

- ステータスの修飾子は「保存される修飾子」。ログイン時に修飾子より先に体力が読まれて 20 に切り詰められることがない。
- 修飾子は、ログイン・復活・ディメンション移動・振り分けのたびに今の値で付け直す。数式を変えても次のログインで正しい値になる。

### 2.3 同期

- 記録は持ち主のクライアントにだけ送る（Data Attachment の同期）。発見の記録と日ごとの量は送らない。
- 「経験値を得た」ことは別の小さな知らせ `growth_gain`（量、理由、上がったレベル数）で送る。画面の「+12」とレベルアップの文字に使う。
- 振り分けはクライアントから「4 つへの追加量」を送り、サーバーで検める（負の数、持っている力を超える、上限 50 を超える、をはねる）。

### 3.3 マルチプレイの分け方

- **道中の敵**: 倒した人と、敵から 32 ブロック以内にいる生きているプレイヤー（観戦者を除く）で分ける（傷を与えた人だけにはしない。回復役・盾役にも取り分があるため）。n 人のとき、一人あたり **元の量 ×（1 + 0.25 ×（n − 1））÷ n**。
  - 1 人 1.0、2 人 0.625、3 人 0.5、4 人 0.4375。全体では人数が増えるほど少し多くなる。
  - 背中の部屋は人数で敵が増える（02）。第一の部屋の第一波で一人あたりは、1 人 42、2 人 41.3、3 人 45.0、4 人 49.9 でほぼ同じ。
  - 端数は確率で切り上げる（4.4 なら 40% で 5、60% で 4）。
- **ボス**: 参加者それぞれに満額。ボスは人数で強くなる（体力 ×（1 + 0.6 ×（人数 − 1）））ので取り分は減らさない。
- **試練の踏破**: 石の近くにいた全員に満額。
- **倒したのが飼い慣らした動物や矢**: 持ち主を「倒した人」とする。ほかの Mod の偽のプレイヤー（機械）が倒した分は数えない。
- パーティの分け前・居合わせなかった仲間の分は [10](10_progression_multiplayer.md) の 6 章。

### 3.4 上がりすぎの補正・日ごとの上限

- **推奨レベル**: 1 章の巨神は岩鯨 12・潮殻 18・雷翼 24・余燼 30。巨神ごとに固定で上げ、攻略順は自由のまま補正で低い巨神へ導く（敵をレベルに合わせて強くすると「強くなる実感」が消えるため）。推奨 + 3 までは満額。超えた 1 レベルごとに 10% 減り、最低 20%。
  - 岩鯨では 15 まで満額、20 で 50%、23 以上で 20%。
  - 一人ずつのレベルで決まる。高いレベルの仲間が手伝っても、低い人の取り分は減らない。
- **バニラの敵**: 1 日（ゲーム内の 20 分。経過時間で数える）に 100 までは満額、超えた分は 20%。スポナーの敵は 0。`GrowthRules.VANILLA_DAILY`。経験値の畑（トラップタワー）で一晩に何十レベルも上がるのを防ぐ。ふつうの冒険ではほぼ届かない。

### 3.5 想定の進み方（一人、補正込み）

背中に乗る前に地上で 400 ほど（バイオーム十数か所と夜の敵）を得たとして、岩鯨を毎回最後まで攻略した場合。1 周は道中の敵 172、番兵長 100、心臓 300、試練 3 つで 120 の計 692（1 回目は発見と初回の上乗せで +480）。

## 4. ステータス

### 4.1 上げ方

- レベルでは上がらない。4 つの基礎は**技の木の基礎の節**（1 節 = 1 点で +4）で上がる（[48](48_skill_tree_v2.md) の 2 章）。今の職の木から導いた値を `SkillManager.refreshStats` が成長の記録 `GrowthData.stats` へ写す。
- 一つの基礎の上限は **100**（`GrowthRules.STAT_CAP`。木の節の合計がこれを超えることはない）。
- `/growth add` と `GrowthAllocatePayload` は受け付けない（`Growth.allocate` は false）。

### 4.2 効果

| ステータス | 1 あたりの効果 | 10 のとき | 27 のとき（Lv10 で全部） | 50 のとき | バニラとの比べ |
|---|---|---|---|---|---|
| 筋力 | 近接攻撃の威力 ×（1 + 0.6%） | +6% | +16.2% | +30% | ダイヤの剣 7 → 9.1。筋力 I（+3）より小さい |
| 敏捷 | 移動 +0.2%、攻撃の速さ +0.2%、飛び道具の威力 +0.4% | +2% / +2% / +4% | +5.4% / +5.4% / +10.8% | +10% / +10% / +20% | 移動速度 I（+20%）の半分 |
| 精神 | 最大マナ +2（素の値 20）・魔法の威力 +0.6%（43） | 40 | 74 | 120 | 精神 20 なら巨神斬りを待ちごとに使える |
| 耐久 | 2 につき最大体力 +0.25❤（内部は +0.5 点） | +1.25❤ | +3.25❤ | +6.25❤ | 体力増強 I（+4 点 = 2❤）の約 3 段ぶん |

- 筋力は武器ごと掛かる（掛け算）ので、良い武器ほど伸びる。素手は 1 → 1.3。
- 敏捷は近接と遠距離の両方に少し効く。弓使いの主なステータス。
- 耐久は上限でもハートが 2 列目の半分ほどに収まる。
- 最大体力は、画面・チャット・ツールチップではハート（体力の点 ÷ 2、❤ 付き、小数は 2 桁まで）で見せる。内部の属性値は体力の点のまま（`Hearts` が表示を作る）。ステータス画面・記録・`/growth`・装備の特性（`vigor`）・パーティの体力はすべてこの表示。
- 精神は最大マナと、魔法（星読みの技）の威力（1 あたり +0.6%。[43](43_jobs.md)）。属性 `skyabyss:max_mana`（素の値 20、上限 1024）をプレイヤーに持たせた。装備やスキルからも同じ属性で足せる。

### 4.3 修飾子（実装）

| 効果 | 属性 | 修飾子の ID | 掛け方 |
|---|---|---|---|
| 筋力 | 攻撃力 | `skyabyss:growth/strength_melee` | 全体に掛ける（ADD_MULTIPLIED_TOTAL） |
| 敏捷（移動） | 移動速度 | `skyabyss:growth/agility_move` | 素の値に掛ける（ADD_MULTIPLIED_BASE）。走りの +30% はその上 |
| 敏捷（攻撃の速さ） | 攻撃速度 | `skyabyss:growth/agility_attack_speed` | 全体に掛ける |
| 敏捷（飛び道具） | —（被ダメージの出来事で掛ける） | — | プレイヤーが撃った飛び道具の威力に掛ける |
| 精神 | 最大マナ | `skyabyss:growth/spirit_mana` | 足す（ADD_VALUE） |
| 耐久 | 最大体力 | `skyabyss:growth/vitality_health` | 足す |

- 値が 0 のときは修飾子を外す。
- 最大体力が増えたとき、満タンだった人は新しい上限まで満たす。減ったときは上限に収める。倒れて目を覚ましたときは満タン。

### 4.4 数値の理由

- 上乗せを小さめにした。巨神の装備（03）と共鳴の炉の強化が「強くなる」の主役で、ステータスは下支え。どちらか一方だけで攻略が決まらないようにする。
- 岩鯨の初回は Lv 9 前後（力 24）。筋力に全部振っても +14% で、心臓（体力 450）が簡単になりすぎない。

### 4.5 ステータスの振り直し

- 無い。基礎は木の節なので、技の振り直し（7.9。今の職の木を戻す）で一緒に戻る。`Growth.respecStats` は使わない（管理者の `/skyabyss level resetstats` も基礎は木から写し直すだけ）。

## 5. 記憶の断片（器）

- 01: 「ループをまたいでも消えない永続強化。ボス撃破や隠し要素で手に入る」。03: 攻撃・防御・移動・回復などの枝、上限を E9 で広げる。
- 今あるのは **器だけ**。種類（ID）ごとの数と、器の大きさ（はじめ 12）を記録する。効果はまだない。**効果（枝）を決めるまで、岩鯨などで渡さない**（効果のない物を渡すと「何に使うのか」で迷わせるため。序章の報酬も伝承の書にした）。
- 付与は `Growth.grantFragment(プレイヤー, ID, 数)`。入りきらない分は付けず、付けた数を返す。付けると「記憶の断片『〇〇』が器に宿った（1 / 12）」と語りの色で出す。
- 決めてある種類:

| ID | 名前 | 入手（予定） |
|---|---|---|
| `skyabyss:prologue` | 最初の記憶 | ループと断片の効果を作るときに渡す |
| `skyabyss:stone_whale` | 岩鯨の鼓動 | 岩鯨の心臓（効果を決めたら） |

- 知らない ID も記録できる（名前は「名もない記憶」）。種類を足すときは `MemoryFragments` に ID を並べ、lang に `fragment.skyabyss.<名前>` を足す。
- 器の大きさは記録ごとに持つので、E9（上限の解放）はこの値を増やすだけで済む。

## 6. 成長の画面と演出

### 6.1 画面左上の小さな表示

- 「Lv 12」と、その下に幅 64 の細いバー。振り分けていない力があれば Lv の右に金色で「✦3」。
- 経験値を得るとバーが一瞬白く光り、その下に「+12」が出て 3 秒で薄れる。撃破が続いたら一行にまとめる。理由のあるもの（「+30 谷の上の岩室」「+10 平原」「+300 岩鯨の心臓」）は淡い青、撃破は灰色。
- バニラの経験値バー（画面の下）には重ならない。F1 と F3 では出さない。チャットより下の層に描く。テクスチャ `textures/gui/growth/hud.png`（2 倍の密度）。
- 置き場はクライアント設定 `growthHudPosition`。`TOP_LEFT`（標準）は左上。`XP_BAR` は下の経験値バーの左で、細いバーを経験値バーと同じ高さにそろえ、「+12」は Lv の上へ積む。ホットバー左の枠（オフハンド、左利きの攻撃の目盛り）があればその先へずらし、入らなければ左上に戻す。マナのバーはどちらでも成長の表示のすぐ下。`XP_BAR` のとき、クエストの追跡は左上の一番上へ上がる。

### 6.2 レベルアップ

| 要素 | 内容 |
|---|---|
| 音 | 独自合成の `growth_level_up`。澄んだ三つの鐘（ラ・ミ・ラ）と底の低い響き。共鳴石に近い。近くの仲間にも小さく聞こえる |
| 光 | 体のまわりに白い光の粒（エンドロッド）24 粒 |

### 7.7 数値の理由（強すぎ・弱すぎ、岩鯨の心臓）

岩鯨の心臓（体力 450）を一人で倒す場面で比べた。ダイヤの剣（攻撃力 7）、初回クリアの Lv 9（力 24 を筋力へ → 攻撃力 8.0）、精神 0（マナ 20）。

| 場面 | 計算 | ふつうの攻撃に対して |
|---|---|---|
| ふつうの攻撃だけ | 8.0 ÷ 0.625 秒 = 12.8 / 秒（上限の目安） | 基準 |
| 巨神斬り段 3（大きな相手） | 8.0 × 1.8 × 1.5 = 21.6。マナで縛られて 12.5 秒に 1 度 → 1.7 / 秒 | +13% |
| 返し刃段 1 | 傷を受けるたびに次の一振りが +15%。心臓の技を 6 秒に 1 度受けるとして | +1〜2% |
| 雲穿ち段 3（弓、敏捷 20） | 11 × 1.08 ≒ 12。12.5 秒に 1 度 → 1.0 / 秒。ふつうの弓（引ききり 6〜9、1 秒に 1 本）に対して | +15% |
| 鷹の目段 3 | 印の間、仲間全員の攻撃 +12% | 仲間の数だけ効く |

- 初回クリアのころ、技を足しても心臓へのダメージは 15〜20% ほどの増加。筋力を全部振ったとき（+14%）と同じくらい。強くなる実感の主役は装備（03）で、ステータスと技は下支え（4.4 と同じ考え）。
- 技を何度も使うには精神が要る（精神 20 なら巨神斬りを待ちの 8 秒ごとに使える）。筋力と精神のどちらに振るかを選ぶことになる。
- 心臓の技は避けるもので、技で受け止めて押し切るものではない。だから守りの技は、**回復・無敵・耐性は作らない**。許すのは小さな吸収ハート（1 回 3❤まで。重ねがけで増えない。高いほうだけが効く。潮歌いの「守りの唄」・巡りの唄の刻印）、マナの支え（凪の心得・巡りの唄）、狙いの引き寄せ（岩呼び）まで。跳び退きで避けやすくはなるが待ちが 3〜5 秒ある。
- 心臓の咆哮（傷を受けない間）と、殻が閉じた直後の 1.5 倍は技にもそのまま効く。人数で強くなる（受けるダメージを割る）のも同じ。
- 背中の試練（02）の決まりを崩さない: 踏み込みは「見えている敵の手前まで、足場のある所だけ」、跳び退きは「地に足が着いていて近くに敵がいるときだけ、走って跳ぶのと同じくらい」。西のアスレの谷を越える近道にならない。

03 の装備との重なり:

| 03 の効果 | 技 | 重ならない理由 |
|---|---|---|
| 共鳴の護符（回復と耐性、60 秒） | なし | 回復・耐性の技は作らない |
| 潮鳴りの護符（衝撃波、ノックバックと鈍足 II） | 鯨尾薙ぎ | 薙ぎは傷が主で、押し出しは弱く、鈍足はない |
| 嵐の護符（次の攻撃に雷 3） | 返し刃 | 返し刃は常に効き、傷を受けたあとだけ。護符は使って次の一撃 |
| 番兵長の鉾（前方の扇に届く、3 回に 1 度骨の噴出） | 巨神斬り | 鉾は武器の性質（毎回）。巨神斬りは待ちのある技で、大きな相手への特効 |
| 雷翼の羽衣（空中ダッシュ） | 踏み込み | 踏み込みは地上だけ、敵へ向かってだけ |
| 天淵開（3 秒無敵）、月光の大鎌（巻き戻し） | なし | 無敵・巻き戻しの技は作らない |

- 上の縁に「記録」「技」のつまみ。押すか J・K で行き来する。つまみの位置は画面の真ん中から決めるので、二つの画面の幅が違っても動かない。
- 左に木のつまみ 4 つ（封じた木は鎖の地と錠）。真ん中に木（3 段、線は前提を覚えていれば青緑）。印の枠の色は、届かない＝暗い灰、覚えられる＝骨、覚えた＝青緑、極めた＝金。印の下に段（1/3）、使う技は右上に小さな菱形。
- 右に説明の欄: 名前と「習得」（段を上げる・極めた）のボタン、種類と段、マナと待ち、言い伝えの一行（入りきるときだけ）、今の段の効果（覚えていなければ段 1）、足りない条件（赤紫）。次の段の効果は「習得」のボタンに重ねると出る（次の段でマナか待ちが変わるときだけその数も出す）。
- 下に技の点、マナ、4 つの枠（右下にキー）、「振り直す」（二度押し）。画面を開いてもゲームは止まらない。
- 折り返しは独自の `TextWrap`: かな・漢字の間で折り返し、行頭に「。、）％」、行末に「（」を置かない。英語は空白で折り返す。
- 振り直しを炉から離れて押したときは、画面の中（説明の欄の下）に理由を 3 秒出す。結晶不足も同じ。
- 数の書式は小数 1 桁に丸めてから出す。

**アイコン（32px。紋章案を採用）**

- 骨の縁の丸い地。地の色は木ごと（剣士＝熾の赤茶、弓使い＝空の青、星術師＝夜の藍、深淵術師＝深紅）、形は骨の白、光は碑文の淡い青。ホットバーの横の 16px でも形がはっきりし、色で木が分かる。赤茶は 01 の色調表にない（巨神の岩と熾に寄せた）。
- `tools/gen/ui/gen_skill_assets.py` の `ADOPTED` で案を選ぶ。`--roughs` でラフを作り直せる。形（10 の技、4 つの木の印、錠、封じた印）は案によらず同じ。

**光の粒と音（どれも独自）**

| 種類 | 中身 |
|---|---|
| 光の粒 `rune_spark` | 碑文の青緑の小さな十字の火花。自分で光り、少し浮いて 0.6 秒ほどで消える。剣士の技、習得 |
| 光の粒 `sky_mote` | 空の淡い菱形の粒。与えられた速さで流れる。弓使いの技（矢の尾、驟雨の降る光） |
| 音 | 巨神斬り（低い風切りと岩の割れる音、かすかな鐘）、返し刃（高い 2 つの鐘）、踏み込み（上がる風切り）、鯨尾薙ぎ（巡る風切りと低い響き）、雲穿ち（下がる笛のような音と息）、跳び退き（柔らかな風）、鷹の目（高い鐘）、天の驟雨（細かな鈴の粒と 6 度の風切り）、習得（澄んだ 3 つの鐘、レ・ファ♯・ラ）、使えない（鈍く短い音）。`tools/gen/ui/gen_skill_assets.py` で合成。よく鳴る音なので、レベルアップの音より小さめ |

- 驟雨の光は 1 tick に 2 粒、矢の尾は 1 tick に 1 粒。撃った瞬間に地面に半径 3 の輪を出し、降る光は縦に 3 粒並べ、1 度降るごとに地面ではじける光を足す。
- 巨神斬りの弧は 25 粒。当たった相手すべてに小さな火花（大きな相手には多め）。

### 7.9 振り直し

| 項目 | 内容 |
|---|---|
| 技の振り直し | Lv 15 になるまでは**どこでも無料**（炉も結晶も要らず、回数にも数えない）。そのあとは共鳴の炉から 6 ブロック以内（か訓練場の師範）で、技の画面の「振り直す」を二度押す。**いつでも共鳴の結晶 1**（師範なら鐘銭 30 枚でも） |

| クリエイティブ | 炉も結晶も要らない |
| 費用の食い違い | 画面の費用とサーバーの費用が違えば断る |

### 7.10 星術・深淵術の解放（2 章・3 章）

- 木 `star`・`abyss` は封じた状態で並ぶ。技はまだない。画面では名前と暗い印の形、目覚める章（「月へ渡るとき（3 章）に目覚める」「深淵の底（2 章）で目覚める」）だけを見せる（先に何かあると知らせる伏線。中の技の名前は見せない）。
- 開くとき（章の担当へ）: `SkillManager.get(player).unlockedTrees.add("abyss")` の後に `SkillManager.sync(player)`。技は `Skill` に木を `SkillTree.ABYSS` として足し、数値を `SkillRules`、動きを `SkillActions` に足す。アイコンは `icons.png` の升目を足す（今は 16 升すべて使用なので 256x96 に広げる）。
- 01 の例（月光の障壁、時の遅延、鼓動の衝撃波、影潜り）は 03 の天淵開・潮鳴りの護符と重なりやすいので、作るときに 7.7 の表で確かめる。

### 7.12 ビルドの仕組み（天職・刻印・型・刻み目・装備）

**2026-10-29: この節の天職・刻印の 3 択・刻み目・K の画面の作り・木のセット・タグの数の足し・条件の特性は [48](48_skill_tree_v2.md)（職ごとの技の木 v2）で置き換えた。残っているのは木の印と逸品の書き換えだけ。** 設計の根拠と技の表は [27](27_builds_and_classes.md)。

**天職（C 案）**

- 岩鯨の心臓を止めるまでは職がない。5 つの木と旅人の **1 行目だけ**が取れ（刻印はなし）、技の点は貯まる。
- 岩鯨の心臓を止め、心臓の報酬（30）を選び終えたあと、**天職を選ぶ画面**（`CallingScreen`）が開く。「あとで」にしても、K の画面の「天職を選ぶ」から選べる。ログインのとき選べるのに選んでいなければ、また開く。選べるかどうかは個人の進み（`Progression.stage`）で決め、保存する旗は持たない。
- 一つ目の天職は**専門**: その木の**要を授かる**（点なし）。**天性**が付く。その木の技の段（要・刻印は除く）**3 つぶんが 1 点ずつ安くなる**。木はどれも天職の前から全部開いている（行ごとの要るレベルと前提だけは残る。31・27 の 17 節）。「継ぐ」は二度押し。
- 二つ目の天職（**雷翼を止めたあと**）: もう 1 本の木の要を授かる。**5 つ目の枠**が開く（天性と割引はなし）。
- 天性（一つ目の天職だけ）: 岩守り「岩の肌」（強靭 +0.5、ノックバック耐性 +10%）、風読み（移動 +3%）、潮歌い「歌い手」（最大マナ +10、仲間に向ける技の範囲 +1 ブロック）、灰の鍛え人「炉の手」（武器の強化の上乗せ +10%、火の傷 −10%）、骨の射手「骨の目」（飛び道具 +5%、撃った矢の 25% は戻る）。

**刻印（ルーン）**

- 使う技のうち 10 本（巨神斬り・鯨尾薙ぎ・岩呼び・踏み込み・跳び退き・風裂き・守りの唄・引き潮・熾火の槌・雲穿ち）に 3 択の刻印があり、技の形が変わる。**技を極める（最大段）と開く**（どの木でも）。熟練 3 で 4 つ目の「熟練の刻印」（技の力 +10%・待ち −8%）が開く（27 の 17 節）。初めて選ぶのは 1 点、付け替えは戦いの外で炉・焚き火の近く、初回は無料・そのあと結晶 1。同時に効くのは 1 つ。
- **逸品の書き換え**（4 番目の刻印）: 専用の逸品の武器 8 本（ヒロイック）が、1 つの技を別の形にする（番兵長の鉾＝踏み込み、水路の顎牙＝風裂き、潮招きの大鋏＝鯨尾薙ぎ、珊瑚憑きの銛＝引き潮、雷獣の爪＝跳び退き、羽守の鉤槍＝岩呼び、鍛え手の大鎚＝熾火の槌、灰被りの火掻き＝焼き入れ）。その武器を主の手に持つあいだだけ選べて効き、外すと効かない（記録には残る）。技の画面では持っているあいだだけ行が出る。武器の説明にも書き換わる技の一行が出る。

**木の印（特性 5 種。03 の 8 章）**

- 岩・風・潮・灰・骨の印: その木の技の力（傷・持続・半径・吸収・マナ）を +5〜10%（ヒロイック以上は ×1.25）。レア以上の武器にだけ付き、1 装備に 1 つまで、5 種合わせた抽選の重みは 10。手の武器の印だけが効く（要るレベルに届いていること）。「段 +1」にはしない。

**ステータスの刻み目（15・30）**

- 4 つのステータスそれぞれ 15 と 30 に小さな分かれ目（計 8 つ。`Breakpoints`）。筋力 15: 重い武器の振り +8%、30: 範囲の技の押し出し ×1.25。敏捷 15: 予告をよけた直後 2 秒、移動 +8%、30: 踏み込み・跳び退き・風裂きの待ち −10%。精神 15: マナの回復 +10%、30: 仲間に向ける技（唄・合図）の効果 +10%。耐久 15: ノックバック耐性 +10%、30: 火・毒の傷 −15%。

**画面（K）**

- 左に木のつまみ（5 つ＋旅人。天職の印が付く）、真ん中に木（4 行・線は前提）、右に説明と「習得」・刻印の行、下に技の点・マナ・枠（4〜5）・型の保存（4）・振り直し・試着・「構え・鍵石」ページ（構え 守・疾・歌、連鎖、タグ、キーストーン 2 つまで）・天職のボタン。
- 背景は `tools/gen/ui/gen_builds_assets.py` が作る 2 倍密度のテクスチャ。文言は lang に直接書く。

### 7.13 技の稽古（都の訓練場の師範）

技が複雑に見えないよう、技の使い方を手で覚える稽古を一章の頭に置く。サブクエスト `lesson/skills`（「師範の稽古」）。データを直接直す（生成スクリプトはない）、仕組みは `tutorial.SkillLesson`、画面の案内は `client.tutorial.SkillLessonClient`。

- 始まり: 都に着いた（`main_song` が `follow_smoke` を過ぎた）ら自動で受ける。最初の目的は「訓練場の師範に稽古を頼む」。
- 段（目的の帯の一行・師範の一言・経験 10 ずつ）: ①技を覚えて枠に置く（覚えると空いた枠に入る）→ ②技を木偶に二度当てる（一回の使用で一度。マナと待ち）→ ③木偶の背後から打つ（柱の南瓜の顔と反対の側。風裂きの背後の倍率の前置き）→ ④構えを切り替える → ⑤師範に振り直しのことを聞く（Lv 15 までは無料。そのまま振り直しの節へ進める）。
- 案内: ホットバーの上の手引きの列に、今のキー設定のキー名入りの一行（K・枠のキー・構えのキー）。使う段は HUD の枠を金の縁で呼吸させる。覚える段は技の画面で覚えられる能動の技と「習得」を光らせる。木偶はその人にだけ見える光（当てる段は頭の上、背後の段は背中側）と、当たったときの火花で応える。
- 報酬: 終えると鐘銭 15（一度だけ。師範の印 `lesson_rewarded`）。
- 飛ばす: 師範の「今はいい（飛ばす）」「稽古を切り上げる」。記録を消し、印 `lesson_skip` で自動では始まらない。あとで師範に頼めば受けられる。済んだあとは「もう一度、稽古を」で頭から（報酬なし）。
- 後の章: 新しい木・要が開いたら、一段だけの稽古 `lesson/tree_*` を始めて一言を出す（橋＝橋の技が開いた、要＝Lv 20、星術師・深淵術師＝木が開いた、淵・前世＝転生）。その木の技を木偶か敵に当てれば済む（要は一つ覚えれば済む）。経験 15。

## 9. 実装

### 9.1 成長（`jp.revati.skyabyss.rpg`）

| ファイル | 役割 |
|---|---|
| `Rpg` | 登録（Data Attachment `growth`、属性 `max_mana`、音 `growth_level_up`） |
| `GrowthData` | 記録の中身、保存（NBT）と同期のコーデック |
| `GrowthRules` | 数値と計算（曲線、効果、補正、分け方）。ゲームの状態に触れない |
| `Growth` | 入口: `get`、`addXp`、`setLevel`、`allocate`、`resetStats`、`respecStats`、`applyModifiers`、`discover`、`grantFragment` |
| `GrowthRewards` | 経験値の入り口（撃破、ボス、試練、場所）、修飾子を付け直す時機、敏捷の飛び道具 |
| `MemoryFragments` | 記憶の断片の種類 |
| `GrowthCommands`、`GrowthSelfTest` | コマンド、自己テスト |
| `net/*` | `growth_gain`（サーバー→持ち主）、`growth_allocate`（持ち主→サーバー）。`ModNetwork` とは別に登録 |
| `client/*` | キー、左上の表示（`GrowthHud`）、レベルアップの文字、ステータス画面（`GrowthScreen`） |

- **経験値を渡す**: `Growth.addXp(player, 量, 理由の翻訳キー)`。理由は「+量 理由」に出る（空なら数だけ）。クエストの報酬はこれを呼ぶ。
- **一度だけ**: `Growth.discover(player, "quest:…")` が true のときだけ渡す。
- **ボスを足す**: 参加者の一覧が分かるところで `GrowthRewards.onBossDefeat` と同様に満額を渡す。今は `TitanLoot.onHeartDefeat`／`onCaptainDefeat` の頭で呼んでいる。
- **新しい敵**: `GrowthRewards.MOD_ENEMIES` に ID・量・推奨レベルを足す。
- **最大マナ**: `player.getAttributeValue(Rpg.MAX_MANA)`。今のマナの量は技の記録（`Skills.DATA`）が持つ。
- **ループの担当へ**: `Rpg.GROWTH` と `Skills.DATA` の記録は巻き戻さない（01 の表の「レベル、スキル」は残るもの）。

### 9.2 スキル（`jp.revati.skyabyss.rpg.skill`）

| ファイル | 役割 |
|---|---|
| `Skills` | 登録（Data Attachment `skills`、光の粒 2 種、音 10 種） |
| `Skill`、`SkillTree` | 技と木の一覧（段、前提、要るレベル、列と段の位置） |
| `SkillRules` | 数値と計算（技の点、マナの回復、消費とクールダウン、技ごとの値、振り直しの費用）。ゲームの状態に触れない |
| `SkillData` | 記録の中身、習得の条件、検め、保存と同期のコーデック |
| `SkillManager` | 入口: `get`、`learn`、`setSlot`、`cast`、`respec`、マナ、常に効く技の修飾子 |
| `SkillActions` | 使う技の中身、敵の選び方、雲穿ちの矢と驟雨の時間 |
| `SkillEvents` | 毎 tick（待ち・マナ）、返し刃・遠矢・鷹の目、付け直しと同期、技の点の知らせ |
| `SkillCommands`、`SkillSelfTest` | コマンド、自己テスト |
| `net/*` | `skill_cast`・`skill_learn`・`skill_slot`・`skill_respec`（持ち主→サーバー）、`skill_mana`・`skill_cast_result`（サーバー→持ち主） |
| `rpg.client.skill/*` | キー、マナのバーと枠の表示（`SkillHud`）、技の画面、記録と技のつまみ（`RpgTabs`）、光の粒、`TextWrap` |

- データ: `data/skyabyss/damage_type/sky_rain.json`（驟雨の傷。`minecraft:no_knockback` の札に足した）。
- 共有ファイル: `SkyAbyss.java`（登録）、`loot/TitanLoot.java`（呼び出し）、lang・`sounds.json`、`tools/README.md`。`Config.java` はクライアント設定 `growthHudPosition` だけ。

## 10. 自己テストと確認

### 10.1 自己テスト

`SKYABYSS_SELFTEST=1 ./gradlew runServer` で、ほかの自己テストと一緒に動く。

**`SELFTEST growth`（`GrowthSelfTest`）**

| 検査 | 内容 |
|---|---|
| 曲線 | 1〜49 で増え続ける、50 で 0、10 までの合計 1,758、50 までの合計 107,898、力の合計 147 |
| レベルの計算 | 49 では上がらず 50 でちょうど上がる。一度に 4 レベル上がり端数が残る。上限で止まりあふれは捨てる |
| 振り分けの検め | 空・負・持っている力を超える・長さ違い・上限超えをはねる。正しいものは通す |
| 壊れた値 | レベル 99 → 50。レベルを下げて使いすぎなら全部戻す |
| 分け方と補正 | 人数の割合、部屋の一人あたり、推奨レベルの補正、端数の切り上げ、バニラの日ごとの上限 |
| 保存と同期 | NBT の往復で全項目が戻る。同期のコーデックで見せる項目が戻り、発見の記録は送られない |
| 死亡 | `copyAttachmentsFrom(…, true)` で記録が写る |
| ログアウト・ログイン | プレイヤーを丸ごと保存して読み直すと記録が戻り、体力は 22/22（耐久 9）のまま |
| 修飾子 | 筋力 10 → 攻撃力 +6%、敏捷 20 → 移動 +4% と攻撃速度 +4%、精神 5 → マナ 30、耐久 9 → 体力 22。満タンなら新しい上限まで満たす。二度付けても重ならない。0 で外れ、体力は 20 に収まる |
| 記憶の断片 | 器を超えて入らない。満杯・負の数は入らない |
| ステータスの振り直し | 費用の表、何も振っていないと断る、炉が遠いと断る、初回無料、技の回数を増やさない、2 回目は結晶 1 個（`SELFTEST growth`） |

**`SELFTEST skills`（`SkillSelfTest`）**

| 検査 | 内容 |
|---|---|
| 技の点 | Lv 1・2・3・9・12・50 で 1・1・2・5・6・25。2 つの木を両方極められない（26 段 > 25 点） |
| 技の形 | 1 段目は前提なし、2・3 段目は前提あり。使う技だけに消費マナと待ち。どの段にも説明の値がある |
| 習得の条件 | Lv 1 で巨神斬りを覚えられる。踏み込みは Lv 不足・前提なしではじく。点なし、最大段超えをはじく。奥義は 2 段目のどちらか一つで足りる。封じた木は閉じていて、開くと開く |
| 検め | 知らない技を消す。常に効く技・覚えていない技・重複・知らない ID の枠を空ける。点の使いすぎと前提の崩れで全部戻す |
| 待ち・数値 | 全体の待ちと技の待ちが数え下がり 0 で消える。マナの回復（20 で 0.8 / 2.0）、振り直しの費用、遠矢の距離、雲穿ちの威力（11 / 16）、大きな相手の決まり |
| 保存と同期 | NBT と同期のコーデックの往復で全項目が戻る |

### 10.3 既知の制限

- 技の音の大きさと、英語画面での成長の画面は、耳・画面で確かめていない。
- 天の驟雨は見ている先のブロックに降るので、敵の向こうの地面を見ていると外れる（途中の敵に当たればその足もとに降る）。輪が出るので外れたことは分かる。
- 鷹の目の印（発光）と遠矢の心得は、数式を自己テストで確かめただけで、画面では見ていない。
- 天職・天性・木の印は 43・48 で削った（職がその役）。天職を返す手段・天職ごとの依頼・見切りの目の予告の縁は、対象ごと無くなった。
- 逸品の書き換えの効果（骨・三連・挟み切り・銛・雷の輪・鉤寄せ・火床・火移し）は、技の側の数式と記録を自己テストで確かめた。画面での見え方は見ていない。
