## 1. 方針

| 目標 | 具体策 |
|---|---|
| 強くなる実感 | 技の木の基礎の節を一つ取るたびに基礎が 4 上がる（レベルでは振り分けない。[48](48_skill_tree_v2.md)）。画面で数値の変化がすぐ見える |
| バニラを壊さない | ステータスの効果はすべてバニラの値への上乗せ（AttributeModifier）。武器・防具・ポーションの強さの順は変えない。筋力を上限まで上げても、ダイヤの剣なら筋力 I のポーション（+3）より小さい |
| マルチで取り合いにならない | ボスの経験値は参加者それぞれに満額。道中の敵は近くの人で分け、人数ぶん全体を少し増やす |
| 周回で上がりすぎない | 内容ごとに推奨レベルを持ち、超えた人の取り分を減らす（最低 20%）。次の巨神へ進む理由を作る |
| ループで消えない | 成長の記録はプレイヤーに付けて保存する。月が落ちても巻き戻さない（01 のループの表のとおり） |

- 経験値はバニラの経験値（エンチャントに使う緑の玉）とは別に持つ。バニラの経験値はそのまま残す。
- レベル上限は 50。物語の進みで決まる上限（15・21・27・33・40、番人を倒すと 50）は [10](10_progression_multiplayer.md) の 5 章。

## 2. 成長の記録

### 2.1 持つもの

| 項目 | 範囲 | 備考 |
|---|---|---|
| レベル | 1〜50 | |
| 経験値 | 0〜次のレベルに要る量 − 1 | いまのレベルの中で貯めた量。上限では 0 |
| ステータス（筋力・敏捷・精神・耐久） | 各 0〜50 | |
| 追加の力 | 0〜 | レベル以外から得た力。今は使っていない（記憶の断片やクエストの報酬に使う予定） |
| 記憶の断片 | 種類ごとの数 | 器の大きさ（はじめ 12）を超えて入らない |
| 発見の記録 | 文字列の集合 | 一度だけの経験値（新しい場所、初めての撃破）。サーバーだけが持つ |
| ステータスの振り直しの回数 | 数 | `GrowthData.statRespecs`。技の回数とは別 |

- 振り分ける力は持たない（`GrowthRules.POINTS_PER_LEVEL = 0`）。基礎は技の木の節から写す（[48](48_skill_tree_v2.md)）。

### 2.2 保存と、消えないもの

保存は NeoForge の Data Attachment（`skyabyss:growth`）。プレイヤーのデータと一緒に保存する。

| 場面 | 扱い | 仕組み |
|---|---|---|
| 死亡・エンドの帰還 | 残る | `copyOnDeath`。復活した体へ写す |
| ディメンションの移動 | 残る | 1.21 ではプレイヤーの体がそのまま移る |
| ログアウト・再起動 | 残る | プレイヤーのファイルに保存 |
| 月の落下（ループ） | 残る | ループの処理はこの記録に触れない（ループの担当への約束） |
| 背中の試練のリセット | 残る | 試練は世界の保存データだけを戻す |

- ステータスの修飾子は「保存される修飾子」。ログイン時に修飾子より先に体力が読まれて 20 に切り詰められることがない。
- 修飾子は、ログイン・復活・ディメンション移動・基礎が変わるたびに今の値で付け直す。数式を変えても次のログインで正しい値になる。

### 2.3 同期

- 記録は持ち主のクライアントにだけ送る（Data Attachment の同期）。発見の記録と日ごとの量は送らない。
- 「経験値を得た」ことは別の小さな知らせ `growth_gain`（量、理由、上がったレベル数）で送る。画面の「+12」とレベルアップの文字に使う。
- 振り分けの通信（`GrowthAllocatePayload`）と `Growth.allocate` は消した。基礎は `SkillManager.refreshStats` が今の職の木から写す。

### 2.4 体力のレベルの伸び（2026-11-02）

- 声「HP はレベルに応じて少しずつ上がるように（最低の基礎値が上がると、ビルドも組みやすい）」。最大体力は 20 + レベルの分（2 レベルごとに +0.5。Lv 50 で +12。`GrowthRules.levelHealth`・修飾子 `growth/level_health`）+ 耐久の分。Wynncraft も素の体力はレベルで伸び、残りは防具で伸ばす。主の硬さの見直しは試遊で。

### 3.1 曲線

レベル L から L+1 へ要る量 = **50 + 25k + 2k²**（k = L − 1）。レベル 50 までの合計は **107,898**。

### 3.3 マルチプレイの分け方

- **道中の敵**: 倒した人と、敵から 32 ブロック以内にいる生きているプレイヤー（観戦者を除く）で分ける（傷を与えた人だけにはしない。回復役・盾役にも取り分があるため）。n 人のとき、一人あたり **元の量 ×（1 + 0.25 ×（n − 1））÷ n**。
  - 1 人 1.0、2 人 0.625、3 人 0.5、4 人 0.4375。全体では人数が増えるほど少し多くなる。
  - 背中の部屋は人数で敵が増える（02）。第一の部屋の第一波で一人あたりは、1 人 42、2 人 41.3、3 人 45.0、4 人 49.9 でほぼ同じ。
  - 端数は確率で切り上げる（4.4 なら 40% で 5、60% で 4）。
- **ボス**: 参加者それぞれに満額。ボスは人数で強くなる（体力 ×（1 + 0.6 ×（人数 − 1）））ので取り分は減らさない。
- **試練の踏破**: 石の近くにいた全員に満額。
- **倒したのが飼い慣らした動物や矢**: 持ち主を「倒した人」とする。ほかの Mod の偽のプレイヤー（機械）が倒した分は数えない。
- パーティの分け前・居合わせなかった仲間の分は [10](10_progression_multiplayer.md) の 6 章。

### 3.4 上がりすぎの補正

- **推奨レベル**: 1 章の巨神は岩鯨 12・潮殻 18・雷翼 24・余燼 30。巨神ごとに固定で上げ、攻略順は自由のまま補正で低い巨神へ導く（敵をレベルに合わせて強くすると「強くなる実感」が消えるため）。推奨 + 3 までは満額。超えた 1 レベルごとに 10% 減り、最低 20%。
  - 岩鯨では 15 まで満額、20 で 50%、23 以上で 20%。
  - 一人ずつのレベルで決まる。高いレベルの仲間が手伝っても、低い人の取り分は減らない。

### 3.5 想定の進み方（一人、補正込み）

- 一章の初回クリア（本筋と主だけ）で Lv 9。脇・町の頼み・見どころ・狩りを足して章の終わりの目安 Lv 12 に届く（3.6）。一章の上限 Lv 15 に当たったら、あふれた分は貯まり、岩鯨の心臓を止めると入る（3.1）。
- 序盤（17）: 鐘の宿りで Lv2（約 10 分）、語り部のあとで Lv3（約 20 分）、骨の丘（約 1 時間）で Lv3（225）、岩鯨を見て Lv4。Lv5（休み場を巡るころ）で技の 3 つ目と二段目の技。自己テスト `growth` が積み上げて確かめる。
- 岩鯨の背の 1 周は道中の敵 約 100・番兵長 25・心臓 80・試練 3 つで 30。周回は推奨 + 3 を超えると補正（3.4）で鈍る。次の巨神へ進む流れにする。

## 4. ステータス

### 4.1 上げ方

- レベルでは上がらない。4 つの基礎は**技の木の基礎の節**（1 節 = 1 点で +4）で上がる（[48](48_skill_tree_v2.md) の 2 章）。今の職の木から導いた値を `SkillManager.refreshStats` が成長の記録 `GrowthData.stats` へ写す。
- 一つの基礎の上限は **100**（`GrowthRules.STAT_CAP`。木の節の合計がこれを超えることはない）。
- `/growth add` と振り分けの通信（`GrowthAllocatePayload`）は消した。基礎は木の節だけで上がる。

### 4.2 効果

| ステータス | 1 あたりの効果 | 10 のとき | 27 のとき（Lv10 で全部） | 50 のとき | バニラとの比べ |
|---|---|---|---|---|---|
| 筋力 | 近接攻撃の威力 ×（1 + 0.6%） | +6% | +16.2% | +30% | ダイヤの剣 7 → 9.1。筋力 I（+3）より小さい |
| 敏捷 | 移動 +0.2%、攻撃の速さ +0.2%、飛び道具の威力 +0.4% | +2% / +2% / +4% | +5.4% / +5.4% / +10.8% | +10% / +10% / +20% | 移動速度 I（+20%）の半分 |
| 精神 | 最大マナ +2（素の値 20）・魔法の威力 +0.6%（43） | 40 | 74 | 120 | 精神 20 なら巨神斬りを待ちごとに使える |
| 耐久 | 2 につき最大体力 +0.25❤（内部は +0.5 点） | +1.25❤ | +3.25❤ | +6.25❤ | 体力増強 I（+4 点 = 2❤）の約 3 段ぶん |

- 筋力は武器ごと掛かる（掛け算）ので、良い武器ほど伸びる。素手は 1 → 1.3。
- 敏捷は近接と遠距離の両方に少し効く。弓使いの主なステータス。
- 耐久は上限でもハートが 2 列目の半分ほどに収まる。
- **体力・傷・攻撃力の見せ方**（2026-11-02 の声「Wynncraft もっと攻撃力出たりしてたよね。攻撃力の迫力がない」）: 画面に出す数は中の値の **10 倍**（`Hp.SHOWN`。ハートや ❤ は使わない）。中の値（体力 20・傷 3.5・攻撃力 15）は変えない。
  - 10 倍で出すもの: 体力の帯「200/200」（`VitalsHud`）、浮く傷の数字（`DamageNumbersClient`。整数、大きい傷ほど大きく、出た瞬間に白く光って弾み、少し震える）、装備の説明の「攻撃力」「最大体力」（`AttributeShownMixin` が NeoForge の属性の行の値を倍にする）、ステータス画面・記録・`/growth`・特性の `vigor`・パーティの体力（`Hp.number`）、技の説明の体力と傷の数（守りの唄・灯の守り札の護り、雲穿ち・足止めの矢・天の驟雨の傷。`SkillRules.hp`）、報いの画面の比べ、訓練場の数字、説明文に書いた数（砥石の攻撃 +15・薬の体力 +60・野の装備・塔の装備・秘伝・前世の恵み）。
  - 倍にしないもの: マナ、防具と強靭、割合、秒、ブロック、倍率（×0.6）、数（膜の重ねは体力なので倍にした）。
- 精神は最大マナと、魔法（星読みの技）の威力（1 あたり +0.6%。[43](43_jobs.md)）。属性 `skyabyss:max_mana`（素の値 20、上限 1024）をプレイヤーに持たせた。装備やスキルからも同じ属性で足せる。

### 4.3 修飾子（実装）

| 効果 | 属性 | 修飾子の ID | 掛け方 |
|---|---|---|---|
| 筋力 | 攻撃力 | `skyabyss:growth/strength_melee` | 全体に掛ける（ADD_MULTIPLIED_TOTAL） |
| 敏捷（移動） | 移動速度 | `skyabyss:growth/agility_move` | 素の値に掛ける（ADD_MULTIPLIED_BASE）。走りの +30% はその上 |
| 敏捷（攻撃の速さ） | 攻撃速度 | `skyabyss:growth/agility_attack_speed` | 全体に掛ける |
| 敏捷（飛び道具） | —（被ダメージの出来事で掛ける） | — | プレイヤーが撃った飛び道具の威力に掛ける |
| 精神 | 最大マナ | `skyabyss:growth/spirit_mana` | 足す（ADD_VALUE） |
| 耐久 | 最大体力 | `skyabyss:growth/vitality_health` | 足す |

- 値が 0 のときは修飾子を外す。
- 最大体力が増えたとき、満タンだった人は新しい上限まで満たす。減ったときは上限に収める。倒れて目を覚ましたときは満タン。

### 4.4 数値の理由

- 上乗せを小さめにした。巨神の装備（03）と共鳴の炉の強化が「強くなる」の主役で、ステータスは下支え。どちらか一方だけで攻略が決まらないようにする。
- 岩鯨の初回は Lv 9 前後（力 24）。筋力に全部振っても +14% で、心臓（体力 450）が簡単になりすぎない。

### 4.5 ステータスの振り直し

- 無い。基礎は木の節なので、技の振り直し（7.9。今の職の木を戻す）で一緒に戻る。`Growth.respecStats` は使わない（管理者の `/skyabyss level resetstats` も基礎は木から写し直すだけ）。

## 5. 記憶の断片（器）

- 01: 「ループをまたいでも消えない永続強化。ボス撃破や隠し要素で手に入る」。03: 攻撃・防御・移動・回復などの枝、上限を E9 で広げる。
- 今あるのは **器だけ**。種類（ID）ごとの数と、器の大きさ（はじめ 12）を記録する。効果はまだない。**効果（枝）を決めるまで、岩鯨などで渡さない**（効果のない物を渡すと「何に使うのか」で迷わせるため。序章の報酬も伝承の書にした）。
- 付与は `Growth.grantFragment(プレイヤー, ID, 数)`。入りきらない分は付けず、付けた数を返す。付けると「記憶の断片『〇〇』が器に宿った（1 / 12）」と語りの色で出す。
- 決めてある種類:

| ID | 名前 | 入手（予定） |
|---|---|---|
| `skyabyss:prologue` | 最初の記憶 | ループと断片の効果を作るときに渡す |
| `skyabyss:stone_whale` | 岩鯨の鼓動 | 岩鯨の心臓（効果を決めたら） |

- 知らない ID も記録できる（名前は「名もない記憶」）。種類を足すときは `MemoryFragments` に ID を並べ、lang に `fragment.skyabyss.<名前>` を足す。
- 器の大きさは記録ごとに持つので、E9（上限の解放）はこの値を増やすだけで済む。

## 7. 技（どの職にも共通の決まり）

職の形（6 職・島の祠と職の間）は [43](43_jobs.md)、技の木（型・節・点の使い方・K の画面）は [48](48_skill_tree_v2.md)、技ごとの数値は `SkillRules` と木の JSON（`assets/skyabyss/skill_tree/<職>.json`）。ここは木の外の、どの職にも共通の決まり。

### 7.1 方針

- 技はふつうの攻撃に足すもの。剣を振る・弓を引く操作はそのまま。技の傷も防具を通り、当てる前と後で相手の無敵時間を 0 にする（技とふつうの攻撃が互いを食わない）。
- 技が当たるのは敵（モンスター）と、プレイヤーを狙っている生き物だけ。村人・家畜・飼っている動物・防具立ては巻き込まない。怒らなければ襲ってこない生き物は、プレイヤーに怒っているときだけ当たる。技はプレイヤーに当たらない（矢は PvP の設定に従う）。
- **回復・無敵・耐性の技は作らない**。許すのは小さな吸収ハート（重ねがけは高いほうだけ）、マナの支え、狙いの引き寄せまで。ボスの技は避けるもので、技で受け止めて押し切るものではない。03 の護符・神器と同じ効果の技も作らない。
- 移動の技は背の試練の決まりを崩さない: 踏み込みは見えている敵の手前まで・足場のある所だけ、跳び退きは地に足が着いていて近くに敵がいるときだけ。
- どの技のあとも 0.5 秒は次の技を使えない（全体の待ち `SkillRules.GLOBAL_COOLDOWN`）。
- 強くなる実感の主役は装備（03）で、技と基礎は下支え。つり合いの基準は岩鯨の心臓を一人で倒す時間 26 秒・番兵長 9 秒（`SkillSelfTest`）。どんなに足しを重ねた組み立てでも心臓 15 秒・番兵長 5 秒を割らない（`BuildsSelfTest`・`DeepSkillsSelfTest`）。
- サーバーが決める: 習得・枠・発動・振り直しはサーバーで検める。クライアントは頼むだけ（7.7）。

### 7.2 技の点

| 項目 | 決めたこと |
|---|---|
| もらえる数 | **1 レベルにつき 1 点**（Lv 1 で 1、Lv 50 で 50。`SkillRules.pointsForLevel`）。職ごとに別に数える。淵・前世の点は 48 の 8 章 |
| 使い方 | 職の木の節を取る（点は節の種類ごと。48 の 2.4） |
| 未割り振りの点 | 持たない。「レベルからの点 + 追加の点 − 使った節の点」で毎回求める |
| 使いすぎ | レベルを下げられるなどで使った点が持っている点より多くなったら、その職の木を空にして点を戻す（ログイン時に検める）。前提が崩れた節もそのとき外す |

- はじめての世界では Lv 1 の 1 点で幹の技を一つ取る（島の祠で職を選んだときに自動で取る）。「K キーの画面で選ぶ」の手がかりは、Lv 2 になったときに出す。

### 7.3 枠と操作

| 項目 | 内容 |
|---|---|
| 枠 | ホットバーとは別の 4 枠（`SkillRules.BASE_SLOTS`）。使う技だけを置ける。木で取った使う技は空いている枠に自動で入る |
| キー | 枠 1〜4 = **R・G・V・Z**、技の画面 = **K**（`KeyDefaults`）。キー設定の「天と淵のあいだ」で変えられる |
| 置き方 | 技の画面で技を選び、下の枠を押す（右クリックで空ける）。技を選んだまま R・G・V・Z を押しても置ける。常に効く技は枠に置かない（その旨を画面内に出す） |
| 使えないとき | 何も払わない。理由をアクションバーに拒否の色で出し、低い短い音と枠の赤紫の縁で知らせる（マナ不足ならマナのバーも光る）。待ちの間に押したときは何も送らず枠だけ小さく揺らす。チャット入力中は出ない |
| 表示 | ホットバーの右（攻撃の目盛りや左利きのオフハンドの枠があればその先）に 20×20 の枠を 4 つ。右下にキー名。待ちの間は上から暗く覆い残りの秒を出す（`SkillHud`）。マナが足りない技は青黒く沈める。使えた瞬間は白く光る。狭くて入らなければ左上のマナのバーの下に並べる |
| 出さないとき | 枠に何も置いていない人、F1・F3・観戦者 |

### 7.4 マナ

| 項目 | 内容 |
|---|---|
| 最大 | 属性 `skyabyss:max_mana`（素の値 20、精神 1 につき +2。`GrowthRules`） |
| 回復 | 1 秒に「0.4 + 最大の 2%」。5 秒のあいだ傷を受けも与えもせず技も使わなければ 2.5 倍 |
| 復活 | 倒れている人は技を使えない。目を覚ますと満タン |
| 保存 | 今のマナは記録に保存する |
| 表示 | 左上の成長の表示のすぐ下に、幅 64・高さ 4 の細いバー（月の青）。使う技を覚えていない人には、満タンのとき出さない |

- 同期: マナは変わった量が 1 以上のとき、満ちたとき、空になったときだけ持ち主へ送る（`skill_mana`）。
- 技ごとの待ちとマナの倍率は 48 の 2.5。

### 7.5 画面と演出

- K の画面の中身は 48 の 5 章。板と組み方は [56](56_ui_layout.md)。見出しの帯のつまみ（「記録」「技」「転生」「旅」）は J・K で行き来する。
- 技の変化の見え方（`SkillChanges`）: 技を変える節（紫）・武器の書き換え（橙）・秘伝の枠（水色）が今その技を変えているとき、技の帯と画面の枠の左の縁にその色の小さな菱形を並べる。説明の欄と枠の札に「いまの変化:」の行。書き換えはその武器を利き手に持つときだけ効くので、持っていなければ灰色で「(その武器を利き手に持つと効く)」と添える。
- 秘伝の枠（2 つ）は下の段、技の枠の右（`SecretArtsPayload` で持ち主へ送る）。
- 折り返しは `TextWrap`（かな・漢字の間で折り返し、行頭に「。、）％」、行末に「（」を置かない。英語は空白で）。数は小数 1 桁に丸めてから出す。
- 技の光の粒は碑文の青緑 `rune_spark`（近接の技・習得）と空の淡い菱形 `sky_mote`（弓の技）、新しい技は技ごとの FX（`FxTree`）。音は独自合成で、よく鳴るのでレベルアップの音より小さめ。

### 7.6 振り直しと型

| 項目 | 内容 |
|---|---|
| 振り直し | Lv 15 になるまでは**どこでも無料**（回数にも数えない）。そのあとは共鳴の炉から 6 ブロック以内か都の訓練場の師範の前で、技の画面の「振り直す」を二度押す。**いつでも共鳴の結晶 1**（師範なら鐘銭 30 枚でも。35 の 3.2） |
| 戻るもの | **今の職の木の節すべて**。ほかの職の木、淵・前世の技、熟練、型の保存は残る。マナと待ちはそのまま |
| 型の保存 | 職ごとに 2 つ。枠と**木の取り方**の組を保存し、戦いの外・炉などの近くで切り替える（点が足りなければ戻さない） |
| クリエイティブ | 炉も結晶も要らない |
| 費用の食い違い | 画面の費用とサーバーの費用が違えば断る |

### 7.7 マルチプレイと保存

| 場面 | 扱い |
|---|---|
| 記録 | Data Attachment `skyabyss:skills`（職ごとの節、枠、追加の点、振り直しの回数、今のマナ、待ちの残り、熟練、紋）。成長の記録とは別 |
| 死亡・ディメンション移動・ログアウト・月のループ | 残る（`copyOnDeath`）。待ちも保存する（ログアウトで待ちを消せない） |
| 同期 | 記録は持ち主にだけ送る。変わったときに送り、待ちはクライアントでも 1 tick ずつ数える（一人遊びで止めている間は数えない） |
| 要求 | 発動（枠の番号）、節を取る、置き場（枠と技）、振り直し（費用）。サーバーで、生きているか、覚えているか、待ちか、マナ、点、前提、レベル、炉の近さ、結晶を検める |
| ほかの人から見えるもの | 光の粒、音、振り、踏み込みの移動。技の傷はふつうの攻撃と同じく全員に効く |
| 常に効く技の修飾子 | 保存される修飾子（`skyabyss:skill/...`）。ログイン・復活・ディメンション移動・習得・振り直しで付け直す |

### 7.8 装備から技へ（木の印・武器の型・書き換え）

- **木の印**（特性 5 種。03 の 3 章の表 `mark_*`）: 岩・風・潮・灰・骨の印は、その印の木（技ごとに持つ岩・風・潮・灰・骨の木。`SkillTree`）の技の力（傷・持続・半径・吸収・マナ）を +5〜10%（ヒロイック以上は ×1.25）。レア以上の武器にだけ付き、1 装備に 1 つまで、5 種合わせた抽選の重みは 10。手の武器の印だけが効き、要るレベルと要る基礎（48 の 2.2）に届いていなければ効かない（`SkillMarks`）。「段 +1」にはしない。
- **武器の型**（`WeaponType`）: 武器を重・長・速・遠・守の 5 つにまとめ、合う型の武器を持つと、その技にちょっとしたおまけ（合計 +15% まで）。縛りは作らない（どの武器でも技は使える）。品の種類は名前で見分ける。
- **武器の書き換え**: 巨神のヒロイック武器・伝説・神器・深淵のアーティファクトが、一つの技の形を変える（その技を覚えていて、その武器を利き手に持つあいだだけ。選ぶ手間はない。2026-11-09）。表は [43](43_jobs.md) の「伝説の技の書き換え」「巨神のヒロイック武器の技の書き換え」と 03 の 3.5。

### 7.9 技の稽古（都の訓練場の師範）

技の使い方を手で覚える稽古を一章の頭に置く。サブクエスト `lesson/skills`（「師範の稽古」）。仕組みは `tutorial.SkillLesson`、画面の案内は `client.tutorial.SkillLessonClient`。

- 始まり: 都に着いた（`main_song` が `follow_smoke` を過ぎた）ら自動で受ける。最初の目的は「訓練場の師範に稽古を頼む」。
- 段（目的の帯の一行・師範の一言・経験 10 ずつ）: ①師範に話す（meet）→ ②技を覚えて枠に置く（learn）→ ③技を木偶に二度当てる（cast。一回の使用で一度）→ ④木偶の背後から打つ（behind。柱の南瓜の顔と反対の側）→ ⑤師範に振り直しのことを聞く（reset。Lv 15 までは無料）。
- 案内: ホットバーの上の手引きの列に、今のキー設定のキー名入りの一行。使う段は HUD の枠を金の縁で呼吸させる。覚える段は技の画面の取れる使う技と「取る」を光らせる。木偶はその人にだけ見える光と、当たったときの火花で応える。
- 報酬: 終えると鐘銭 15（一度だけ。師範の印 `lesson_rewarded`）。
- 飛ばす: 師範の「今はいい（飛ばす）」「稽古を切り上げる」。印 `lesson_skip` で自動では始まらない。あとで師範に頼めば受けられる。済んだあとは「もう一度、稽古を」で頭から（報酬なし）。
- 後の章: 新しい木・奥義が開いたら、一段だけの稽古 `lesson/tree_*`（奥義・星読み・深淵・淵・前世）を始めて一言を出す。その木の技を木偶か敵に当てれば済む。経験 15。

## 9. 実装

### 9.1 成長（`jp.revati.skyabyss.rpg`）

| ファイル | 役割 |
|---|---|
| `Rpg` | 登録（Data Attachment `growth`、属性 `max_mana`、音 `growth_level_up`） |
| `GrowthData` | 記録の中身、保存（NBT）と同期のコーデック |
| `GrowthRules` | 数値と計算（曲線、効果、補正、分け方）。ゲームの状態に触れない |
| `Growth` | 入口: `get`、`addXp`、`setLevel`、`resetStats`、`respecStats`、`applyModifiers`、`discover`、`grantFragment` |
| `GrowthRewards` | 経験値の入り口（撃破、ボス、試練、場所）、修飾子を付け直す時機、敏捷の飛び道具 |
| `MemoryFragments` | 記憶の断片の種類 |
| `GrowthCommands`、`GrowthSelfTest` | コマンド、自己テスト |
| `net/*` | `growth_gain`（サーバー→持ち主）。`ModNetwork` とは別に登録（振り分けの `growth_allocate` は消した） |
| `client/*` | キー、左上の表示（`GrowthHud`）、レベルアップの文字、ステータス画面（`GrowthScreen`） |

- **経験値を渡す**: `Growth.addXp(player, 量, 理由の翻訳キー)`。理由は「+量 理由」に出る（空なら数だけ）。クエストの報酬はこれを呼ぶ。
- **一度だけ**: `Growth.discover(player, "quest:…")` が true のときだけ渡す。
- **ボスを足す**: 参加者の一覧が分かるところで `GrowthRewards.onBossDefeat` と同様に満額を渡す。今は `TitanLoot.onHeartDefeat`／`onCaptainDefeat` の頭で呼んでいる。
- **新しい敵**: `GrowthRewards.MOD_ENEMIES` に ID・量・推奨レベルを足す。
- **最大マナ**: `player.getAttributeValue(Rpg.MAX_MANA)`。今のマナの量は技の記録（`Skills.DATA`）が持つ。
- **ループの担当へ**: `Rpg.GROWTH` と `Skills.DATA` の記録は巻き戻さない（01 の表の「レベル、スキル」は残るもの）。

### 9.2 スキル（`jp.revati.skyabyss.rpg.skill`）

| ファイル | 役割 |
|---|---|
| `Skills` | 登録（Data Attachment `skills`、光の粒 2 種、音 10 種） |
| `Skill`、`SkillTree` | 技と木の一覧（段、前提、要るレベル、列と段の位置） |
| `SkillRules` | 数値と計算（技の点、マナの回復、消費とクールダウン、技ごとの値、振り直しの費用）。ゲームの状態に触れない |
| `SkillData` | 記録の中身、習得の条件、検め、保存と同期のコーデック |

| `SkillActions` | 使う技の中身、敵の選び方、雲穿ちの矢と驟雨の時間 |
| `SkillEvents` | 毎 tick（待ち・マナ）、返し刃・遠矢・鷹の目、付け直しと同期、技の点の知らせ |

## 10. 自己テストと確認

### 10.1 自己テスト

`SKYABYSS_SELFTEST=1 ./gradlew runServer` で、ほかの自己テストと一緒に動く。

**`SELFTEST growth`（`GrowthSelfTest`）**

| 検査 | 内容 |
|---|---|
| 曲線 | 1〜49 で増え続ける、50 で 0、10 までの合計 1,758、50 までの合計 107,898、力の合計 147 |
| レベルの計算 | 49 では上がらず 50 でちょうど上がる。一度に 4 レベル上がり端数が残る。Lv 50 で止まりあふれは捨てる（物語の上限で貯める分は `SELFTEST xp table`） |
| 壊れた値 | レベル 99 → 50。レベルを下げて使いすぎなら全部戻す |
| 分け方と補正 | 人数の割合、部屋の一人あたり、推奨レベルの補正、端数の切り上げ |
| 保存と同期 | NBT の往復で全項目が戻る。同期のコーデックで見せる項目が戻り、発見の記録は送られない |
| 死亡 | `copyAttachmentsFrom(…, true)` で記録が写る |
| ログアウト・ログイン | プレイヤーを丸ごと保存して読み直すと記録が戻り、体力は 22/22（耐久 9）のまま |
| 修飾子 | 筋力 10 → 攻撃力 +6%、敏捷 20 → 移動 +4% と攻撃速度 +4%、精神 5 → マナ 30、耐久 9 → 体力 22。満タンなら新しい上限まで満たす。二度付けても重ならない。0 で外れ、体力は 20 に収まる |
| 記憶の断片 | 器を超えて入らない。満杯・負の数は入らない |
| ステータスの振り直し | 費用の表、何も振っていないと断る、炉が遠いと断る、初回無料、技の回数を増やさない、2 回目は結晶 1 個（`SELFTEST growth`） |

**`SELFTEST skills`（`SkillSelfTest`）**

| 検査 | 内容 |
|---|---|
| 技の点 | Lv 1・2・3・9・12・50 で 1・1・2・5・6・25。2 つの木を両方極められない（26 段 > 25 点） |
| 技の形 | 1 段目は前提なし、2・3 段目は前提あり。使う技だけに消費マナと待ち。どの段にも説明の値がある |
| 習得の条件 | Lv 1 で巨神斬りを覚えられる。踏み込みは Lv 不足・前提なしではじく。点なし、最大段超えをはじく。奥義は 2 段目のどちらか一つで足りる。封じた木は閉じていて、開くと開く |
| 検め | 知らない技を消す。常に効く技・覚えていない技・重複・知らない ID の枠を空ける。点の使いすぎと前提の崩れで全部戻す |
| 待ち・数値 | 全体の待ちと技の待ちが数え下がり 0 で消える。マナの回復（20 で 0.8 / 2.0）、振り直しの費用、遠矢の距離、雲穿ちの威力（11 / 16）、大きな相手の決まり |
| 保存と同期 | NBT と同期のコーデックの往復で全項目が戻る |
| プレイヤー | 習得（空いた枠に入る、段が上がる、前提のない奥義をはじく、常に効く技や知らない技を枠に置かない）、岩の構えの修飾子（防具 +2、ノックバック耐性 0.2）、マナの回復（最大を超えない） |
| 敵の選び方 | ゾンビは当たる。アイアンゴーレム・自分・怒っていないゾンビピグリンには当たらない。怒ったゾンビピグリンには当たる。ゴーレムは大きな相手、ゾンビは違う |
| 技を使う | 巨神斬りが前の敵に当たり、10 払い、待ちが始まり、無敵時間を残さない。待ち・マナ不足・空の枠ははじく。雲穿ちは弓なしで無料で断り、弓と矢で矢を 1 本使い、貫く数・重力なし・拾えない矢が飛ぶ。驟雨は 18 払って降る予定が積まれ、傷はノックバックしない。踏み込みは宙では無料で断る |
| 引き継ぎ | 死亡時の写し、保存と読み込みで記録・待ち・岩の構えの防具が戻る。忘れると修飾子と枠が消える。炉から離れていると振り直せない |

### 10.3 既知の制限

- 技の音の大きさと、英語画面での成長の画面は、耳・画面で確かめていない。
- 天の驟雨は見ている先のブロックに降るので、敵の向こうの地面を見ていると外れる（途中の敵に当たればその足もとに降る）。輪が出るので外れたことは分かる。
- 鷹の目の印（発光）と遠矢の心得は、数式を自己テストで確かめただけで、画面では見ていない。
- 天職・天性・木の印は 43・48 で削った（職がその役）。天職を返す手段・天職ごとの依頼・見切りの目の予告の縁は、対象ごと無くなった。
- 逸品の書き換えの効果（骨・三連・挟み切り・銛・雷の輪・鉤寄せ・火床・火移し）は、技の側の数式と記録を自己テストで確かめた。画面での見え方は見ていない。
