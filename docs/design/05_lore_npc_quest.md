## 1. ねらい

01 の「探索」にある「書物や石碑を集めると『伝承の書』に登録され、世界の謎が少しずつ解ける」を形にしたもの。

- **謎は少しずつ、ほのめかしで解く。** 項目の本文は、拾った人の短い書き付けと碑文の写しだけで作る。答えは書かない。複数の項目を並べて読むと、同じ方向を指していることに気づく形にする。
- **01 の「巨神編ではつながりを説明しない」を守る。** 深淵の心臓とのつながりは、碑文の「地の底から預かった」と書き手の気づき（「拍は下から来ていた」「持ち主はどこにいるのだろう」）までにとどめる。五章で深淵の心臓の前に立ったとき、書をめくり直すと意味が変わる項目を置いておく。
  - 心臓を止めたあとの拍は書かない。鼓動が還るのか失われるのかは五章で決め、そのあと「止まった鼓動」に書き足す（00 の 12）。今は「どこから来て、どこへ行ったのか」という問いで終える。
  - 深淵の心臓につながる手がかりは 4 項目（西・水路・前室の碑文、止まった鼓動）に散らし、どれも問いか感覚で終える。
- **ホラー演出の原則に合わせ、知らせは控えめにする。** 記されたときは右上に羊皮紙の札が 4 秒出て、頁をめくる音が小さく鳴るだけ。チャットには出さない。
- **一人ひとりの書にする。** 記録はプレイヤーごと。同じ宝箱の頁でも、読む人によって違う話が記される。

## 2. 書の手に入れ方

| きっかけ | 何が起きるか |
| --- | --- |
| 新しいワールドの目覚め（序章 B1。[17](17_opening_and_rpg_feel.md)） | 野営地の古い帳面（`CampBuilder` が置いた伝承の書の ItemEntity。消えない）の 2.5 ブロック以内で「拾った」とみなし、人ごとに伝承の書を渡す。帳面そのものは拾えない。野営地へ行かなくても届く: 離れて 1 分・目覚めて 5 分・野営地のない世界は 20 秒後。「荷物の中に、見覚えのない古い帳面が入っていた」 |
| 空の影を初めて見る（序章 B4） | 影の項目は書の持ち主には記さず、影が去って 3 秒後に**破れた頁**が頭上から落ちてくる（本人しか拾えない。2 分で荷物へ、14 分読まなければ自動で読む）。頁を読むと `prologue/shadow` が記される（`LoreEvents.watchSky` から `OpeningDirector.deferShadowToPage`） |
| 書を持たない人が空の影を見る（クリエイティブなどの救済） | 従来どおり影が去って 3 秒後、本人の頭上 4 ブロックから書が落ちてくる（光の粒と頁の音。本人しか拾えず消えない）。2 分拾わないと荷物へ入る。影が去るまでに地上を離れたら荷物へ入る |
| 書より先にほかの項目が記された | その場で荷物へ入る |
| 書をなくした（捨てた、燃えた） | 次に何かが記されたとき、持ち物にもエンダーチェストにもなければ荷物へ戻る。「荷物の中に、あの帳面が戻っていた」 |
| すでに書を持っている | 二冊目は渡さない（`/skyabyss lore book` だけは試すためにもう一冊渡す） |

- 書を手にすると「白紙の帳面」が記される。最初の頁の一行（「忘れないうちに書け。次は、もっと早く気づけるように」）は、主人公が「留まる者」であることへの最初のほのめかし。前のループの自分が書いた、と六章で分かる一番小さな仕掛け（00 の 6 = A。そのまま）。
- 倒れている人には渡さない（岩鯨の背では持ち物が預かられるため）。
- 書そのものには何も書き込まない。中身は持ち主の記録を映すだけ。人に渡しても中身は渡らない。作業台のレシピはない（なくしても戻る）。
- 語り部から受け取る形（00 の 44）は採らなかった。書を持つ人が語り部に帳面を見せると「この字、どこかで見た気がするよ。……いや、気のせいだろう」と一言だけ言う（不気味さを保ったまま、留まる者へのほのめかしを足す）。

## 3. 記される条件

項目は JSON の `unlock` に並べた条件の**どれか一つ**を満たすと記される。

| 種類 | 意味 | 調べ方 |
| --- | --- | --- |
| `sky_shadow` | 空の影を初めて見た | 通過中、影の中心から水平 150 ブロック以内で、頭上に空が見える。0.5 秒ごと |
| `sign` | 碑文を読んだ | 碑（`skyabyss:tablet`、[19](19_advancements_and_tablets.md)）を右クリックするか目を向ける（刻まれた文のキーで見分ける。古い看板の右クリックも読む）。巨神の背の碑文は、4.5 ブロック以内で目を向け（視線との内積 0.8 以上）、間に壁がなければ読める（光る看板は読ませたいので、目を向けるだけでよい。00 の 37）。0.25 秒ごと |
| `dimension` | その場所に入った | 1 秒ごと |
| `near_entity` | その生き物が `radius` 以内にいた | 2 秒ごと（まだ記されていない項目があるときだけ） |
| `kill` | その生き物が倒れたとき、倒した人か `radius` 以内にいた | 死亡イベント（最後に動き、取り消されたら数えない）。復活を待っている人も、その場にいれば数える |
| `item` | そのアイテムを持ち物に入れた | 1 秒ごと |
| `page` | 破れた頁を読んだ | 頁の右クリック |
| `manual` | コマンドや、ほかの仕組み（会話・クエスト・拍子の担当）からだけ記す | `Lore.unlock` |

- 毎 tick の見回りは、人ごとに時刻をずらして間引く。
- 岩鯨の試練のコード（`titan/`）には手を入れていない。碑文は看板の文と `TitanBackLayout.LORE_SIGNS` の位置、心臓と番兵長は死亡イベント、天の鍵の欠片は持ち物で拾う。空の影だけは進行中の通過を見るため `SkyEvents.activePass()`（読むだけ）を足した。
- 新しい条件の種類は `LoreTrigger.TYPES` に加え、`LoreEvents` で拾い、`gui.skyabyss.lore.hint.<種類>` の手がかりを両方の lang に書く。

## 4. 破れた頁

| 出どころ | 手に入る所 | 確率 | 記される項目 |
| --- | --- | --- | --- |
| 村 `village` | 村の宝箱（`chests/village/*` すべて） | 宝箱ごとに 25% で 1 枚 | 序章の 4 項目（数え歌・暦・峰・見る者）。4 枚で尽きる |
| 空の影 `shadow` | 影が去った 3 秒後、空から（8.1。序盤） | 必ず | 雲の上の影 |
| 岩鯨の背 `titan_back` | 背中の番兵（`GuardMob`）を倒したとき。倒した人だけが拾える。その人に未読の背の頁がなければ落ちない | 5% | 一章の 3 項目（運ばれる者・返り火・鯨の歌） |
| 雷翼の背 `storm_back` | 雷翼の背（[12](12_thunder_wing.md)） | — | 風見の帳 |
| 余燼の背 `ember_back` | 余燼の背（[13](13_ember.md)） | — | 鍛えの帳 |

- 右クリックで読むと、その出どころの項目のうち**読んだ人がまだ記していないもの**から一つを選んで記し、頁は消える。全部知っていれば「この頁に書かれたことは、もう書に記されている」と出て、頁は残る。
- 出どころはアイテムのデータ（`skyabyss:lore_page_source`）に入れる。出どころのない頁（コマンドで出したもの）は、どの頁の項目からでも選ぶ。
- 自分だけが拾える頁（落ちてくる頁、倒した人に確保された頁）は、拾える本人の画面でだけ淡い金に光る（17 の 2.3。ほかの人の画面では普通の落とし物）。
- 確率は遊んでから見直す（00 の 27 = 後程）。

## 5. 画面

見開きの古い帳面。GUI の大きさは 304×192（テクスチャは 32px 密度で 608×384）。

| 場所 | 中身 |
| --- | --- |
| 上のしおり（8 枚） | 序章・一章（岩鯨）・二章（潮殻）・三章（雷翼）・四章（余燼）・五章・六章・終章。書の幅に収めるため、しおりは重ねて並べる（見える幅 34、右のしおりが左の端に載る）。選んだ章は明るく、頁につながる。未読の項目がある章には青緑の点 |
| 左の頁 | 章の名（その章の項目が一つでも記されるまでは「？？？」）、項目の一覧（12 行、ホイールで送る）、記した数（例: 10 / 13） |
| 右の頁 | 題、碑文の写し（青緑の字と左の縦線）、本文（墨の色）、関連する項目（押すとそこへ移る。相手が伏せられていれば「？？？」で押せない） |
| 伏せた項目 | 一覧では「？？？」と白抜きの菱形。開くと、にじんだ墨の帯が数本と、手がかりを斜体で一行（例: 「どこかの碑文に刻まれている」）。五章以降の枠は「この先の頁は、まだ白い」 |
| 新しい項目 | 一覧の右に青緑の光る点。開くと消える（読んだ記録はサーバーに保存。入り直しても残る） |

- 開いたときは、まだ読んでいない一番新しい項目を開く。なければ最後に開いていた項目。
- 操作: クリック、ホイール（左の頁は一覧、右の頁は本文）、↑↓ で項目、←→ で章。
- 本文は日本語の禁則を守って折り返す（`LoreWrap`。行頭の句読点・閉じかっこ・小さい仮名は前の字と一緒に次の行へ、開きかっこは行末に残さない）。漢字や仮名の行は高さ 10、英字だけの行は 9。「た。」だけの行が出ることはある（本の組み方として普通なので残した）。
- 背景はぼかさず暗くするだけ（字を読みやすく）。選んだ行は羊皮紙の色（`PAPER`）で書く。上・下の矢印は一覧の下に並べる。
- 碑文の写しは**看板の文をそのまま使う**（JSON の `inscription_sign`）。看板を直せば書も変わる（二重に持たない）。
- 知らせ: 右上に羊皮紙の札「伝承の書に記された／見る者」。続くと縦に並ぶ。`unlock all` では札は出ず、チャットに件数だけ。

## 7. データの形

```
data/skyabyss/lore/chapter/<章>.json          {"order": 1}
data/skyabyss/lore/entry/<章>/<名前>.json      項目 (ID は "<章>/<名前>")
assets/skyabyss_lore/lang/{ja_jp,en_us}.json   伝承の文 (題・本文・碑文・章の名・手がかり・画面とコマンドの文)
```

項目の JSON（例: 西の碑文）:

```json
{
  "chapter": "chapter1",
  "order": 30,
  "inscription_sign": "sign.skyabyss.lore_west",
  "unlock": [ { "type": "sign", "target": "sign.skyabyss.lore_west" } ],
  "related": [ "chapter1/carried_people", "chapter1/inscription_below" ]
}
```

| 欄 | 意味 |
| --- | --- |
| `chapter` / `order` | 章と、章の中の並び |
| `inscription` | true なら、本文の前に `lore.skyabyss.<章>.<名前>.inscription` を碑文の写しとして置く |
| `inscription_sign` | 看板の文のキー。看板の 4 行をそのまま碑文の写しにする |
| `placeholder` | true なら枠だけ（記されない） |
| `unlock` | 条件の並び（`type`、`target`、`radius`） |
| `related` | 関連する項目の ID |
| `hint` | 伏せているときの手がかりのキー（省略すると条件の種類から決まる） |

- 文のキーは ID から決まる: `lore.skyabyss.<章>.<名前>.title` / `.body` / `.inscription`、章は `lore.skyabyss.chapter.<章>.tab` / `.name`。
- 伝承の文は本体の lang と別の名前空間（`skyabyss_lore`。巨神ごとに `skyabyss_story`・`skyabyss_storm`・`skyabyss_ember` など）の lang に置く。キーの規則は同じで、ゲームの中では区別なく読まれる（並行作業で本体の lang の末尾がぶつからないため。00 の 34 = A）。
- データパックで項目を足せる。ほかの名前空間の項目の ID は `<名前空間>:<章>/<名前>`。

**岩鯨**（`chapter1/stone_whale`）

空の向こうから、低く長い歌が聞こえた。

雲の下を、岩の山が泳いでいた。背には崩れた建物が並んでいる。山はゆっくりと身をくねらせ、向きを変えた。

目があるのかどうかも分からないのに、見られている気がした。

**背中の遺跡**（`chapter1/sky_ruins`）

鎖に引き上げられた先には、町があった。正確には、町だったものだ。

石畳は割れ、柱は倒れ、骨の門だけがまだ立っている。人の姿はない。

立ち止まっていると、石畳ごと体がわずかに持ち上がり、また下がる。ここは地面ではない。

**西の碑文**（`chapter1/inscription_west`）

> 骨の道は  
> 我らの巡礼路  
> 石は、より深い  
> 拍に合わせて歌う  

西の裂け目の先、共鳴石の岩棚にあった。巡礼路とあるが、行き先は書かれていない。

石に耳を当てると、低いうなりが聞こえた。

**東の碑文**（`chapter1/inscription_east`）

> 番兵は眠らない  
> この鼓動を  
> 返すその日まで  
> 守り続ける  

番兵長の広間、共鳴石のそばにあった。

「返す」と彫ってある。番兵たちは、その日を見ないまま骨になった。

**水路の碑文**（`chapter1/inscription_below`）

> 鯨は息をしない  
> 体を巡るのは  
> 水と、地の底から  
> 届く拍だけ  

闇の水路を抜けた先、小部屋の壁にあった。

息をしない生き物が、なぜ歌うのだろう。水の中で耳を澄ますと、拍はたしかに下のほうから来ていた。

**宝物庫の碑文**（`chapter1/inscription_vault`）

> 我らは鍵を  
> 鼓動のそばに納めた  
> いつの日か  
> 留まる者が来る  

封印の奥、宝物庫の壁にあった。

「留まる者」という言葉の脇に、爪で引っかいたような細い傷が並んでいる。数えると、七本あった。

**前室の碑文**（`chapter1/inscription_heart`）

> この鼓動は  
> 巨神のものではない  
> 深い地の底から  
> 預かったものだ  

心臓の間の手前、前室の壁にあった。

扉の向こうで、何かが脈を打っている。巨神のものでないなら、持ち主はどこにいるのだろう。

**鯨骨の番兵長**（`chapter1/captain`）

番兵長は、崩れ落ちる最後まで鉾を下ろさなかった。

骨の山の中に、すり減った留め金が一つ残っていた。表には背中の民の印。裏には小さく、名前らしきものが彫ってある。読めたのは、最初の一文字だけだった。

**止まった鼓動**（`chapter1/heart_stilled`）

岩鯨の心臓が止まった。巨神は落ちなかった。ただ一度、深く息をついた。

静かになった心臓の間に、しばらく立っていた。石の壁には、まだ温もりが残っていた。

この鼓動は、どこから来て、どこへ行ったのだろう。

**天の鍵の欠片**（`chapter1/sky_key`）

心臓が止まったとき、気づくと手の中に欠片があった。ほのかに温かく、かすかに脈を打っている。

四つそろえば雲の上へ続く扉が開く、と言い伝えにはある。残る三つは、ほかの巨神が体の奥に抱えているはずだ。

**運ばれる者**（`chapter1/carried_people`）

背中の民は、自分たちを「運ばれる者」と呼んでいたらしい。

土地を持たず、巨神の背で生まれ、背で死んだ。死者の骨は道に並べられ、やがて道そのものになった。

西の骨の道を思い出した。

**返り火**（`chapter1/return_fire`）

休み場の焚き火は青く燃える。薪をくべる者もいないのに、消えたことがない。

民はこの火を「返り火」と呼んだ。背で倒れた者は、目を覚ますとこの火のそばにいるからだ。

**鯨の歌**（`chapter1/whale_song`）

岩鯨が歌うのは、決まって雲の下へ降りる前だという。

民はその歌を、迎えの合図だと考えていた。誰を迎えに降りるのかは、頁が破れていて読めない。

**鯨追いのイサナ**（`chapter1/whale_chaser`）

村の外れで火を焚く旅人は、イサナと名乗った。古い言葉で、鯨のことだという。

名乗る前に、少しだけ間があった。前にも誰かに、同じように名乗ったことがあるような顔をしていた。

次に会ったとき、あの人は覚えているだろうか。

## 12. 実装

### 12.1 入口とファイル

アイテム、クリエイティブタブへの追加、パケット（版 `lore-1` の別の登録）、データコンポーネント、Attachment はすべて `jp.revati.skyabyss.lore`（`Lore`、`LoreManager`、`LoreEvents`、`LoreState`、`LoreCatalog`、`LoreBookItem`、`LorePageItem`、`LoreSetup`、`LoreNetwork`、`LoreWrap`、`LoreCommands`、`LoreSelfTest`、`client/`）。共有ファイルは `SkyAbyss.java`（`LoreSetup.register` の 1 行）と `sky/SkyEvents.java`（`activePass()`）だけ。

```java
Lore.unlock(player, "chapter2/abyss_gate", true);         // 一件記す (知らせつき)
Lore.fire(player, "manual", t -> t.target().equals("x")); // 条件の種類で記す
Lore.state(player).has("chapter1/heart_stilled");         // 記されているか
```

### 12.2 テスト

`SKYABYSS_SELFTEST=1 ./gradlew runServer` の `LoreSelfTest`（`SELFTEST lore PASSED/FAILED`）。

| 調べること | 内容 |
| --- | --- |
| JSON の読み込み | 読めないファイルがない。章がない・関連先がない・条件がない・枠に条件がある、がない |
| 項目の数 | 序章と一〜四章で 12〜75。五章以降は枠だけ |
| 条件の先 | 看板のキーが `LORE_SIGNS` にある。アイテム・エンティティ・ディメンションが実在する。`kill` と `near_entity` に半径がある |
| 文 | ja_jp と en_us の両方に、題・本文・碑文・章の名・手がかり・画面とコマンドの文がある。碑文の写しに使う看板の行が lang にある |
| 送る形 | 一覧を書いて読み戻すと同じ |
| 折り返し | 幅を超えない、字が欠けない、行頭に句読点・閉じかっこが来ない、行末に開きかっこが残らない。英語は語の途中で切らない |
| 解放 | 碑文を読むと記され、二度は記されない。ほかの人の記録は変わらない。初めての項目で書が渡る。すでに書を持つ人には二冊目を渡さない。書をなくすと次の項目で戻る。空の影のあとは落ちてくる書を待つ。天の鍵の欠片を持つと欠片と心臓の項目が記される。心臓の `kill` で記される。枠は記されない。読んだ印は記された項目にだけ付く |
| 頁 | 村の頁は村の項目だけ、背の頁は背の項目だけを選ぶ |
| 保存・死亡 | `skyabyss:lore_state` に書かれ、読み戻すと同じ。新しい体へ引き継ぐ（`copyAttachmentsFrom(..., true)`） |
| 村の宝箱 | 平原の家の宝箱を 400 回引いて頁が 40〜180 枚（25% の想定でおよそ 100）。出どころが `village` |

- 日本語は全項目が右の頁（147 単位）に収まる（一番長いのは宝物庫と前室の碑文で 145）。英語は 3 項目（白紙の帳面・雲の上の影・村の数え歌）が数行はみ出し、右の頁を送って読む。英語の題は一覧の幅（104 単位）に収まる長さにした。

### 12.3 ゲーム内確認と制限

- 確認済み（1600x900）: しおり（開いている章は明るく、新しい項目の章に青緑の点）、伏せ字（中身は漏れない）、リンク、折り返し、知らせの札、アイテムの絵。
- 空の影の下で頁が落ちてくる流れと、岩鯨の背で碑文に目を向けたときの読み取りの距離・角度は、実際に遊んで確かめていない。
- 本文が長くて送りが要る項目は今の文には一つもなく、右の頁の矢印は画面で見ていない。

## 13. 設計判断の理由

| 判断 | 理由 |
| --- | --- |
| 書は野営地の帳面で渡し、影のあとは破れた頁が落ちる | 最初の恐怖の直後に、正体の分からない物が空から落ちることで、怖さが「謎を解く」動機に変わる。書は序章の報酬（01 の序章の報酬は最初の記憶の断片から書に替えた。断片はループと永続強化の仕組みに属する） |
| 書の中身はプレイヤーの記録、書は窓 | 落とす・燃やす・人に渡すで中身が失われると、謎解きの積み重ねが壊れる。ループで消えない記録（留まる者の記憶）と書の意味もそろう |
| 碑文は「目を向ける」だけでも読める | 光る看板は遠くからでも読めるので、右クリックを知らない人が取りこぼさないように。壁越しには読めない |
| 文は答えを書かない | 01 の「巨神編ではつながりを説明しない」 |
| 碑文の写しは看板の文を使う | 二重に持つと、看板だけ直して書が古いまま、が起きる |
| 頁は読む人ごとに項目を選ぶ | マルチで宝箱を分け合っても、それぞれの書が進む |
| 背中の頁は倒した人だけ | 02 の報酬は個人抽選。頁も同じ流儀にした |
| 文を別の名前空間の lang に置く | 並行作業で本体の lang の末尾がぶつかるのを避けるため（00 の 34） |
