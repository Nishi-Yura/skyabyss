## 2. 伝承の書

### 2.1 ねらい

- **謎は少しずつ、ほのめかしで解く。** 項目の本文は、拾った人の短い書き付けと、碑文の写しだけで作る。答えは書かない。複数の項目を並べて読むと、同じ方向を指していることに気づく、という形にする。
- **01 の「1章ではつながりを説明しない」を守る。** 深淵の心臓とのつながりは、碑文の「地の底から預かった」と、書き手の気づき（「拍は下から来ていた」「持ち主はどこにいるのだろう」）までにとどめる。2章で深淵の心臓の前に立ったとき、書をめくり直すと意味が変わる項目を置いておく。
- **ホラー演出の原則に合わせ、知らせは控えめにする。** 記されたときは右上に羊皮紙の札が 4 秒出て、頁をめくる音が小さく鳴るだけ。チャットには出さない。
- **一人ひとりの書にする。** 記録はプレイヤーごと。同じ宝箱の頁でも、読む人によって違う話が記される。

### 2.2 書の手に入れ方

| きっかけ | 何が起きるか |
| --- | --- |
| 空の影を初めて見る（序章） | その場で「雲の上の影」が記される。影が去って 3 秒後、本人の頭上 4 ブロックから書が落ちてくる（光の粒と、頁の音）。本人しか拾えず、消えない。チャットに「影が去ったあと、空から古い帳面が一冊、落ちてきた」 |
| 落ちてきた書を 2 分拾わない | 落ちた書は消え、荷物の中に入る（その 2 分のあいだにほかの項目が記されても、二冊目は渡さない） |
| 影が去るまでに地上を離れた | 荷物の中に入る |
| 空の影より先にほかの項目が記された（先に岩鯨に乗った、ホラー演出を切っている、など） | その場で荷物の中に入る。「荷物の中に、見覚えのない古い帳面が入っていた」 |
| 書をなくした（捨てた、燃えた、置いてきた） | 次に何かが記されたとき、持ち物にもエンダーチェストにもなければ、荷物の中に戻る。「荷物の中に、あの帳面が戻っていた」 |
| すでに書を持っている（クリエイティブなど） | 二冊目は渡さない |

- 書を手にすると「白紙の帳面」が記される。最初の頁の一行（「忘れないうちに書け。次は、もっと早く気づけるように」）は、主人公が「留まる者」であることへの最初のほのめかし（5章の判断 1）。
- 倒れている人には渡さない（岩鯨の背では持ち物が預かられ、手元が空に見えるため）。
- 書そのものには何も書き込まない。中身は持ち主の記録を映すだけなので、書を人に渡しても中身は渡らない。作業台のレシピは作らない（なくしても戻るので要らない）。

### 2.3 記される条件

項目は JSON の `unlock` に並べた条件の**どれか一つ**を満たすと記される。

| 種類 | 意味 | 調べ方 |
| --- | --- | --- |
| `sky_shadow` | 空の影を初めて見た | 通過中、影の中心から水平 150 ブロック以内で、頭上に空が見える。0.5 秒ごと |
| `sign` | 碑文を読んだ | 看板を右クリック（どの看板でも、1 行目の翻訳キーで見分ける）。岩鯨の背の碑文 5 枚は、4.5 ブロック以内で目を向け（視線との内積 0.8 以上）、間に壁がなければ読める。0.25 秒ごと |
| `dimension` | その場所に入った | 1 秒ごと |
| `near_entity` | その生き物が `radius` 以内にいた | 2 秒ごと（まだ記されていない項目があるときだけ） |
| `kill` | その生き物が倒れたとき、倒した人か `radius` 以内にいた | 死亡イベント（最後に動き、取り消されたら数えない）。倒れて復活を待っている人も、その場にいれば数える |
| `item` | そのアイテムを持ち物に入れた | 1 秒ごと |
| `page` | 破れた頁を読んだ | 頁の右クリック |
| `manual` | コマンドや、ほかの仕組みからだけ記す | `Lore.unlock` |

- 毎 tick の見回りは、人ごとに時刻をずらして間引く。
- 岩鯨の試練のコード（`titan/`）には手を入れていない。碑文は看板の文と `TitanBackLayout.LORE_SIGNS` の位置、心臓と番兵長は死亡イベント、天の鍵の欠片は持ち物で拾う。空の影だけは、進行中の通過を見るために `SkyEvents.activePass()`（読むだけの公開メソッド）を足した。

### 2.4 破れた頁

| 出どころ | 手に入る所 | 確率 | 記される項目 |
| --- | --- | --- | --- |
| 村 `village` | 村の宝箱（`chests/village/*` すべて） | 宝箱ごとに 25% で 1 枚 | 序章の 4 項目（数え歌・暦・峰・見る者） |
| 岩鯨の背 `titan_back` | 背中の番兵（`GuardMob`）を倒したとき | 5%。倒した人だけが拾える。その人に未読の背の頁がなければ落ちない | 一章の 3 項目（運ばれる者・返り火・鯨の歌） |

- 右クリックで読むと、その出どころの項目のうち、**読んだ人がまだ記していないもの**から一つを選んで記し、頁は消える。もう全部知っていれば「この頁に書かれたことは、もう書に記されている」と出て、頁は残る。
- 頁の出どころはアイテムのデータ（`skyabyss:lore_page_source`）に入れる。出どころのない頁（コマンドで出したもの）は、どの頁の項目からでも選ぶ。

### 2.5 画面

見開きの古い帳面。GUI の大きさは 304×192（テクスチャは 32px 密度で 608×384）。

| 場所 | 中身 |
| --- | --- |
| 上のしおり（5 枚） | 序章・一章・二章・三章・終章。選んだ章は明るく、頁につながる。未読の項目がある章には青緑の点 |
| 左の頁 | 章の名（その章の項目が一つでも記されるまでは「？？？」）、項目の一覧（12 行、ホイールで送る）、記した数（例: 10 / 13） |
| 右の頁 | 題、碑文の写し（青緑の字と左の縦線）、本文（墨の色）、関連する項目（押すとそこへ移る。相手が伏せられていれば「？？？」で押せない） |
| 伏せた項目 | 一覧では「？？？」と白抜きの菱形。開くと、にじんだ墨の帯が数本（長さは項目ごとに決まる）と、手がかりを斜体で一行（例: 「どこかの碑文に刻まれている」）。二章以降の枠は「この先の頁は、まだ白い」 |
| 新しい項目 | 一覧の右に青緑の光る点。開くと消える（読んだ記録はサーバーに保存し、入り直しても残る） |

- 開いたときは、まだ読んでいない一番新しい項目を開く。なければ最後に開いていた項目。
- 操作: クリック、ホイール（左の頁は一覧、右の頁は本文）、↑↓ で項目、←→ で章。
- 本文は日本語の禁則を守って折り返す（`LoreWrap`。行頭の句読点・閉じかっこ・小さい仮名は前の字と一緒に次の行へ、開きかっこは行末に残さない）。漢字や仮名の行は高さ 10、英字だけの行は 9。
- 背景はぼかさず暗くするだけ（字を読みやすく）。
- 碑文の写しは、**看板の文をそのまま使う**（JSON の `inscription_sign`）。看板の文を直せば書も変わり、二重に持たない。

### 2.6 保存とマルチプレイ

| 項目 | 決まり |
| --- | --- |
| 記録の置き場所 | プレイヤーの Data Attachment `skyabyss:lore_state`（記した項目、読んだ項目、書を受け取ったか、書が落ちてくる予定） |
| 死んだとき | 引き継ぐ（`copyOnDeath`） |
| 月のループ | 消さない。ループで巻き戻るのは物語だけで、留まる者の記憶は残る（01 のループの表の「残るもの」）。ループを作る担当は、この記録に触れないこと |
| マルチ | 記録も知らせも本人だけ。落ちてくる書は本人しか拾えない。頁は読んだ人ごとに項目を選ぶ |
| 参加者への同期 | 参加したとき・`/reload` のあと・書を開いたときに、章と項目の一覧と記録をまとめて送る（`lore_sync`）。記されたときは一件だけ送る（`lore_unlocked`）。読んだ印は参加者から送る（`lore_seen`。記された項目にしか付かない） |

### 2.7 データの形

```
data/skyabyss/lore/chapter/<章>.json          {"order": 1}
data/skyabyss/lore/entry/<章>/<名前>.json      項目 (ID は "<章>/<名前>")
assets/skyabyss_lore/lang/{ja_jp,en_us}.json   伝承の文 (題・本文・碑文・章の名・手がかり・画面とコマンドの文)
```

項目の JSON（例: 西の碑文）:

```json
{
  "chapter": "chapter1",
  "order": 30,
  "inscription_sign": "sign.skyabyss.lore_west",
  "unlock": [ { "type": "sign", "target": "sign.skyabyss.lore_west" } ],
  "related": [ "chapter1/carried_people", "chapter1/inscription_below" ]
}
```

| 欄 | 意味 |
| --- | --- |
| `chapter` / `order` | 章と、章の中の並び |
| `inscription` | true なら、本文の前に `lore.skyabyss.<章>.<名前>.inscription` を碑文の写しとして置く |
| `inscription_sign` | 看板の文のキー。看板の 4 行をそのまま碑文の写しにする |
| `placeholder` | true なら枠だけ（記されない） |
| `unlock` | 条件の並び（`type`、`target`、`radius`） |
| `related` | 関連する項目の ID |
| `hint` | 伏せているときの手がかりのキー（省略すると条件の種類から決まる） |

- 文のキーは ID から決まる: `lore.skyabyss.<章>.<名前>.title` / `.body` / `.inscription`、章は `lore.skyabyss.chapter.<章>.tab` / `.name`。
- 伝承の文は、本体の lang（`assets/skyabyss/lang`）と別の名前空間 `skyabyss_lore` の lang に置いた。キーの名前は本体と同じ規則で、ゲームの中では区別なく読まれる。並行して lang を触るほかの担当とぶつからないようにするため（5章の判断 3）。
- データパックで項目を足せる。ほかの名前空間の項目の ID は `<名前空間>:<章>/<名前>`。

**白紙の帳面**（`prologue/the_book`）

> 忘れないうちに書け。  
> 次は、もっと早く気づけるように。  

最初の頁に、見覚えのない筆跡でそれだけが書いてあった。ほかの頁は白い。

古い帳面だ。表紙は石のように冷たく、角がすり減っている。いつ、どこで手に入れたのか、うまく思い出せない。

**雲の上の影**（`prologue/shadow`）

晴れた昼に、急にあたりが暗くなった。雲の上を何かが渡っていく。影は丘を一つ覆うほどだった。

羊はうずくまり、鳥は鳴くのをやめた。少し遅れて、風を打つような低い音が降ってきた。

雲の切れ間に見えたものを書こうとして、やめた。

**村の数え歌**（`prologue/counting_song`）

> ひとつ　ひるまにかげがくる  
> ふたつ　ひつじとふせなさい  
> みっつ　みあげちゃだめよ  
> よっつ　よるにはつきがくる  

村の子どもたちが手まり歌に歌っている。いつつから先は、誰も知らないという。

大人に尋ねると、話をそらされた。

**暦の書き込み**（`prologue/seventh_night`）

> 七日目の夜は、戸を閉めて外へ出ないこと。  

古い暦の余白に、同じ一文が七日おきに書きこまれていた。

村では、ずっと昔からの決まりだという。なぜ七日目なのかは、誰も知らない。

**平らな峰**（`prologue/shaved_peak`）

北の峰の頂が、ある朝なくなっていた。羊飼いの話だ。

崩れたのではないという。上から削り取ったように平らで、切り口の岩はまだ白かった。

**見る者**（`prologue/watcher`）

夜、ひとりで火の番をしていると、離れた所に誰かが立っていることがある。

声をかけると、もういない。近づいてみても、足跡は残っていない。

村の年寄りは、あれを「見る者」と呼ぶ。目を合わせなければ、何もしてこないそうだ。

**岩鯨**（`chapter1/stone_whale`）

空の向こうから、低く長い歌が聞こえた。

雲の下を、岩の山が泳いでいた。背には崩れた建物が並んでいる。山はゆっくりと身をくねらせ、向きを変えた。

目があるのかどうかも分からないのに、見られている気がした。

**背中の遺跡**（`chapter1/sky_ruins`）

鎖に引き上げられた先には、町があった。正確には、町だったものだ。

石畳は割れ、柱は倒れ、骨の門だけがまだ立っている。人の姿はない。

立ち止まっていると、石畳ごと体がわずかに持ち上がり、また下がる。ここは地面ではない。

**西の碑文**（`chapter1/inscription_west`）

> 骨の道は  
> 我らの巡礼路  
> 石は、より深い  
> 拍に合わせて歌う  

西の裂け目の先、共鳴石の岩棚にあった。巡礼路とあるが、行き先は書かれていない。

石に耳を当てると、低いうなりが聞こえた。

**東の碑文**（`chapter1/inscription_east`）

> 番兵は眠らない  
> この鼓動を  
> 返すその日まで  
> 守り続ける  

番兵長の広間、共鳴石のそばにあった。

「返す」と彫ってある。番兵たちは、その日を見ないまま骨になった。

**水路の碑文**（`chapter1/inscription_below`）

> 鯨は息をしない  
> 体を巡るのは  
> 水と、地の底から  
> 届く拍だけ  

闇の水路を抜けた先、小部屋の壁にあった。

息をしない生き物が、なぜ歌うのだろう。水の中で耳を澄ますと、拍はたしかに下のほうから来ていた。

**宝物庫の碑文**（`chapter1/inscription_vault`）

> 我らは鍵を  
> 鼓動のそばに納めた  
> いつの日か  
> 留まる者が来る  

封印の奥、宝物庫の壁にあった。

「留まる者」という言葉の脇に、爪で引っかいたような細い傷が並んでいる。数えると、七本あった。

**前室の碑文**（`chapter1/inscription_heart`）

> この鼓動は  
> 巨神のものではない  
> 深い地の底から  
> 預かったものだ  

心臓の間の手前、前室の壁にあった。

扉の向こうで、何かが脈を打っている。巨神のものでないなら、持ち主はどこにいるのだろう。

**鯨骨の番兵長**（`chapter1/captain`）

番兵長は、崩れ落ちる最後まで鉾を下ろさなかった。

骨の山の中に、すり減った留め金が一つ残っていた。表には背中の民の印。裏には小さく、名前らしきものが彫ってある。読めたのは、最初の一文字だけだった。

**止まった鼓動**（`chapter1/heart_stilled`）

岩鯨の心臓が止まった。巨神は落ちなかった。ただ一度、深く息をついた。

静かになった心臓の間に、しばらく立っていた。石の壁には、まだ温もりが残っていた。

この鼓動は、どこから来て、どこへ行ったのだろう。

### 2.13 設計判断の理由

| 判断 | 理由 |
| --- | --- |
| 書は空の影のあと、空から落ちてくる | 01 の序章は「空の影」で始まる。最初の恐怖の直後に、正体の分からない書が手に入ることで、怖さが「謎を解く」動機に変わる。01 では序章の報酬が「最初の記憶の断片」だったが、断片はループと永続強化の仕組み（M4）に属するので、ここでは書を序章の手に入るものにした（01 も 2026-10-16 にそう改めた） |
| 書の中身はプレイヤーの記録、書は窓 | 落とす・燃やす・人に渡すで中身が失われると、謎解きの積み重ねが壊れる。ループで消えない記録（留まる者の記憶）と書の物語上の意味もそろう |
| 碑文は「目を向ける」だけでも読める | 光る看板は遠くからでも読めるので、右クリックを知らない人が取りこぼさないように。壁越しには読めない |
| 文は答えを書かない | 01 の「1章ではつながりを説明しない」。深淵の心臓につながる手がかりは 4 項目（西・水路・前室の碑文、止まった鼓動）に散らし、どれも問いか感覚で終える |
| 心臓を止めたあとの拍は書かない | 01 は「鼓動が還るのか、失われるのか」を 2 章で決めるとしている。前は「下から遅れて一つだけ」拍が届く描写があったが、2 章の決定を先取りしないよう消した（5章の判断 2 = B）。今は「どこから来て、どこへ行ったのか」という問いで終える |
| 碑文の写しは看板の文を使う | 二重に持つと、看板だけ直して書が古いまま、が起きる |
| 頁は読む人ごとに項目を選ぶ | マルチで宝箱を分け合っても、それぞれの書が進む |
| 背中の頁は倒した人だけ | 02 の報酬は個人抽選。頁も同じ流儀にした |
| 文を別の名前空間の lang に置いた | 並行作業で本体の lang の末尾がぶつかるのを避けるため。ゲームの中では区別なく読まれる |
