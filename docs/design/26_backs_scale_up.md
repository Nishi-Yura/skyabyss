# 天と淵のあいだ 巨神の背を大きく・濃くする（現行の作り）

- 文書番号: 26
- 範囲: 四つの背（岩鯨・潮殻・雷翼・余燼）を、6 人で遊べる大きさに拡げた作り。倍率の決まり、部屋の拡げ方、作り方、背ごとの配置の要点、広間の広さの扱い。
- 状態: 四体とも拡大済み。背の中の流れは順路（[32](32_titan_raid_route.md)）。寸法と座標の正は各背の `*Layout`、測りは `dev backmetrics <巨神>`。この書類は決まりと考え方を書く。

## 0. 要約

- 体は**水平 ×1.6・垂直 ×1.3**（足あと ×2.6）。部屋は位置ごと拡大し、広間は約 ×1.9、心臓の間は ×1.3 にとどめる（戦いの手ごたえは 4 分のまま）。
- 背の中の道は**順路**（歩 → 智 → 闘 →（中ボス）→ 心臓）の一本。試練は一度に一つなので、2 レーンも待ち行列もない。同じ部屋はグループごとの上書き・敵の持ち主・戸で分かれる（4.4）。
- 広さは人数で変えない。少人数は敵を入口側に寄せ、罠と遮蔽で広さを使わせる（8.7）。
- 試練に時間・天気・背の状態の鍵をかけない。背に寄り道の部屋はない（寄り道と設備は地上の祠のまわり。32）。

## 1. 大きさの目標と測り方

測りは `dev backmetrics <巨神>` が `*Layout` の箱から出す（部屋の面積・通路の幅と高さ・足あとに対する割合・歩数）。目標は次のとおり。

| 項目 | 目標 |
| --- | --- |
| 試練の部屋（1 つの仕掛けの床） | 800 m² 以上（一人あたり 130 以上。細長い部屋は奥行きが幅の 2.5 倍まで） |
| 広間戦（雑魚の波） | 1,000 m² 以上 |
| 中ボスの部屋 | 750 m² 以上 |
| 心臓の間 | 1,250 m² 以上（半径 20 以上） |
| 通路・戸口 | 幅 5 以上、高さ 6 以上（本道は幅 7） |
| 足あとに対する部屋の割合 | 25〜40% |
| 見せ場（遠くまで見える所） | 各背に 5 か所以上 |

- 心臓の技の範囲は床の 4 割以下（02 の 5.4）。自己テスト `telegraph` が見る。
- 長さは実測ではなく見込み（21 の 1.1）。時間の中身は試練と戦いなので、体が大きくなっても長さはほぼ変わらない。

## 2. 拡大の決まり（四体に共通）

1. **体は水平 ×1.6、垂直 ×1.3**。足あと ×2.6、体積 ×3.4。垂直は次元の高さ（256）で決まる（4.2）。
2. **部屋は「今の部屋の拡大 + あいた所への増築」**。広間は ×1.9、心臓の間は ×1.3。
3. **体の外の形は巨神の識別を保つ**。形（頭・ひれ・翼・甲羅・火山）と色と材料の言葉は今の低ポリ案のまま、同じ形を拡大して作り直す（`gen_*` の `--scale`）。岩鯨は骨と苔と茶の殻、潮殻は珊瑚と真珠層、雷翼は銅と羽、余燼は黒玄武岩と赤橙。
4. **変えないこと**: 心臓の扉は、三つの試練のゴールと中ボス（段 3.5 を含む）を越えたグループに開く（32 の 2.1）。初回 / 周回（`keep.first_cleared`）。心臓の戦いの技・体力式。天の鍵の流れ。
5. **試練に状態の鍵をかけない**。順路の段の戸だけが、そのグループの今の段に開く。
6. **一人でも解ける**。人数ぶんの役割は①重り（持ち運べる品が板を押さえる）、②留め（止め具が仕掛けを一時的に固定する）、③時間（待てば同じことが起きる）のどれかで一人にも用意する。人数で変わるのは「同時にできる量」と「近道」で、「解けるか」は変えない。
7. **新しい敵の種類は足さない**。数は人数と部屋の広さに合わせる（一つの広間の同時の敵は 6 人で 20 体前後まで）。

## 3. 巨神ごとの配置（要点）

細部は各巨神の節（02・08・12・13）と `*Layout` が正。ここは配置の考え方だけを書く。

### 3.1 岩鯨「骨と殻の大聖堂」

- 体: 全長 約 700（ゲームの岩鯨の約 4.6 倍）。増築はほとんど足あとの内側に入る。
- 流れ: 到着（左のわき腹の台）→ 登りの階段（最初の 5 段が初回の入口）→ 入口 → 三つの試練（西の谷・闇の水路・東の翼）→ 番兵長の広間 → 心臓の回廊 → 心臓の間。鼓動の間は心臓への通り道で、中には何も置かない。
- 大きくした部屋: 鼓動の間（大聖堂の天井と肋骨の窓）、西の谷（肋骨の谷・竪穴・崩れ橋。一本の道）、東の翼（第一の広間 21×47、第二の広間は戦わない通路（射手の回廊）、番兵の詰所、番兵長の広間 13×55）、闇の水路（15×21 マス、1 マス 5×5、入口 2 つ）、心臓の間（半径 25）。
- 初回だけの部屋（`WhaleFirstRun`）: 数え歌の鐘楼・番兵の詰所・闇の水路。周回も同じ部屋を遊ぶ（32 の 7）。

### 3.2 潮殻「満ち引きの大庭」

- 体: 甲羅 約 253×325、ひれまで約 372×406、高さ y 47〜216。海面 y 63 は動かさない。台地は四段、塔の頂は y 216。
- 流れ: 潮門の廊下（到着）→ 潮門の浜 → 潮の広間 → 三つの試練（珊瑚の庭・潮見の間・群れの干潟）→ 殻の底（心臓）。
- 広間・庭・潮見・干潟は、1〜6 人で同じ部屋（仕切りは立てない。8.7）。

### 3.3 雷翼「風と雷の翼の回廊」

- 体: 翼を広げた幅 約 618、全長 約 357。骨の中の回廊は三層（凪の低い道・梁の上・嵐の高い道）が並ぶ大きさ。
- 流れ: 到着 → 羽軸の道 → 羽の広場 → 羽根の門 → 尾の間 → 風の広間 → 肩の階段（17 段）→ 肩の部屋 → 三つの試練（西 風切りの骨・東 雷の骨の回路・前 眼の間）→ 竜骨の間（心臓）。
- 広間の床の色の線（西 = 水色・東 = 金・前 = 白）が各出口へ続く。
- 大きさ: 風の広間 45×46、通路 幅 7、翼の回廊 幅 23（高さ 16）、肋の間 22×23、眼の間 23×23、首 7×41、東の回廊 長さ 123。戦いの部屋（雷獣の巣 半径 13、竜骨の間 半径 15）は大きさ据え置きで、位置だけ体に合わせた。
- 試練の仕組み（回路・肋の間・舵・眼の間）は 12 と 25 が正。

### 3.4 余燼「炉の体」

- 体: 全長 621、火山の縁 y 217。熱は人ごとなので、部屋が広くても熱の量は変わらない（灰溜まりの数を面積に合わせる）。
- 流れ: 口 → 喉（首・玄武の鱗の尾根の広間・坂）→ 炉心の広間（通り道）→ 三つの試練（灰の道・鍛えの間・火守りの谷。冷えた溶岩洞で降りる）→ 中ボス（鍛え手の間。智の段の中）→ 熾の底の門 → 熾の底（心臓）。
- 大きさ: 炉心の広間 半径 27、灰の道 39×127、鍛えの間 41×71、火守りの谷 35×75。鍛え手の間・熾の底とその前室は大きさを据え置き、位置だけ体に合わせた。
- 試練の階（29 のプールのため、広間の南東から足した。11.3）。

## 4. 作り方

### 4.1 倍率を定数に通す（`BackScale`）

- `*Layout` の箱・半径・座標は `static final` の定数で、`BackScale.S(設計単位)` で作る。倍率は版ごとのコンパイル時の定数（実行時の設定にしない。同じワールドで建て直しが毎回起きるのを防ぐ）。
- 自己テスト `scale sweep` が倍率 1.0・1.4・1.6・2.0 で、部屋が体の中に入る・部屋が重ならない・通路の幅と高さが目標以上・床面積が目標以上・詰み監査（`BackReach`）が通ることを見る。倍率を後から上げても壊れないことを守る。
- 自動で拡がるもの: 足場の谷（`CourseGenerator`・`ParkourCourses`）、迷路（`MazeBuilder`・`FloodedMaze`）、円形の戦場（`HeartArenaBuilder`・雷翼・余燼の心臓の間）、体の外形（`gen_*` の `--scale`）。
- 手で置くもの（鍛えの炉・鞴・金床、雷翼の避雷の柱・鏡の台、庭の台・祭壇、飾り）は、倍率ではなく部屋ごとに作り直す。

### 4.2 次元の高さと体の作り方

- 次元の高さは 256（y 0〜255）。垂直の倍率は四体とも ×1.3 に合わせた（潮殻・余燼は海面・灰の原から塔・火口の縁までが 125 前後で、×1.45 が上限）。
- 倍率 2.0 以上にするには次元の種類（`min_y`・`height`）を変える必要がある。既存のチャンクと食い違うので、新しい次元名の背として作る。
- 体は、深い内側を区画（16×16×16）ごとに一括で置く（`WhaleShape.job`・`BackBuildJobs.ColumnJob`）。置くのは外から数ブロックの殻と、部屋のまわりだけ。内側は石で埋め、空洞にしない（自然の湧きを増やさない）。
- 体の bin は倍率の 2 乗で大きくなる。jar と起動の読み込みは許容範囲。

### 4.3 版を上げる建て直しと引き継ぎ

- `LAYOUT_VERSION` を上げると、古い島は消して建て直す。試練の進み・休み場の記録・扉の上書きは戻る。`keep.*`（初回を済ませた・見た場面・眠る試練）と巨神の記憶・天の鍵の欠片は残る。版の数字は各背の `LAYOUT_VERSION` が正。
- 体の中にいる人は、次のログインで入口へ出る（02 の 3.6・10 の 10.6）。
- 体の中心の軸と y の基準（海面・灰の原・雲）は動かさず、外へ広げる。古い島の残りが出ないようにする。
- 墓・預かりの場所・位置の札・グループの上書き（`GroupOverlays`）・封印の扉は、すべて `*Layout` の座標から引くので、再計算で追従する。

### 4.4 グループの重なり・占有・負荷

- 背の中の試練は一度に一つのセルを使う。2 レーン・待ち行列は作らない。区画は番号で分ける（32 の 5 章）。
- 心臓の間と前室は体の中のまま共有し、グループごとの上書きと敵の持ち主で同時に戦える（02 の 7.1）。
- 敵の AI の範囲（`GuardMob`・`BackAmbientMobs`・`Telegraph`）は部屋の大きさごとに回し直す。湧きは人数の式のまま（6 人で広間に 15〜20 体）。
- 内側は空洞にしない（4.2）。

## 5. 作業の状態

- 四体とも拡大済み（岩鯨 8、潮殻 9、雷翼 10、余燼 11）。順路への作り直し（32）も済み。
- 残りは実機の確認（各背の節の「実機で見るもの」）。

## 6. 決めたこと（今の作り）

1. **倍率**: ×1.6（水平）・×1.3（垂直）。倍率は定数。2.0 以上は新しい次元名で作る。
2. **任意の翼は持たない**（32 の 0）。初回・周回の長さは 21 の見込みのまま。
3. **人数**: 部屋は 6 人基準の同じ地図。少人数は敵を入口側に寄せ、罠と柱で使わせる（8.7）。幕（仕切り）は張らない。
4. **体の外の巨神**は今の大きさ。背に立つと「見た目より大きい」。物語の「見た目より中が大きい」で通す。
5. **待ち**: 2 レーンは作らない。待つのは体の中の原型を初回の順路が使うときだけ（32 の 5 章。決定 207）。

## 7. 守ること

- 試練に状態の鍵をかけない（ボスの扉の段を除く）。
- 心臓の戦いの技と体力式、初回 / 周回（`keep.first_cleared`）は変えない。
- 新しい敵・ブロック・絵を作らない。巨神の識別（形・色・材料の言葉）を拡大でも保つ。
- 心臓の間は ×1.3 まで。
- 設計書は今の仕様だけを書く。

## 8. 岩鯨の実装

### 8.1 できたもの

- **倍率**: `titan/BackScale`（水平 ×1.6・垂直 ×1.3。腹の下端 y 58 と雲の海の基準 `BASE_Y` は動かさない。`TitanBackLayout.SCALE`）。
- **体**: `titan_back/whale.bin`（`tools/gen/items/gen_titan_back_whale.py`）。深い内側は区画ごとに直接書く（`WhaleShape.job`）。
- **測り**: `titan/BackMetrics`（`/skyabyss dev backmetrics whale`。自己テスト `whale scale` が決まりを守らせる）。
- **配置**: `TitanBackLayout`（座標の正）。通路・戸口は幅 5〜7・高さ 6。到着の台は 26×27、広場は半径 11×14 の楕円、登りの階段は 48 段（幅 5・高さ 6。背に近づくと殻を割って背へ出る）。
- **鐘楼**（`BellTower`）: 五つの鐘を 1→5 の順に叩くと、崩れ橋への戸がそのグループにだけほどける。間違えると骨鳥 2（ピースフルでは鳴るだけ）。周回も同じく叩く。
- **東の翼**: 第一の広間 → 北の戸 → 控えの間（休み場 `ce1`）→ 射手の回廊（戦わない通路）→ 前室（休み場 `ckr`）→ 番兵の詰所（盾の壁 → 老番兵。割符の戸が開く）→ 番兵長の広間。一本道で、道の途中で二つの戸が同時に開くことはない。
- **西の谷**: 谷ごとに筋の通った一本の道（飛び石 → 島（休み場）→ 骨の橋。落ちると島へ戻る。`ParkourCourses`）。
- **闇の水路**（光海）: 迷路 15×21 マス、1 マス 5×5、入口 2 つ（出口は 1 つ）。灯の台 3・灯 3。息継ぎのくぼみはどのマスからも 3 マス以内。計画は `MazePlan`、置くのは `MazeBuilder`。入口の休み場 `mz0` は魂の火鉢（煙の出ない火鉢）。詳細は 02 の 3.2 と 23 の 10・11 章。

### 8.2 確かめ・実機で見るもの

- 自己テスト（毎回新しいワールド）: `titan back`・`whale scale`・`build audit`・`camp blocks`・`ch1 back mobs`。詰み監査は到着から全部の部屋・休み場・碑まで歩いて届くことを見る。
- 実機: 歩きの長さ（到着 → 最初の試練）、広さの感じ（間延びしないか）、少人数のときの敵の寄せ方、建設時間（起動から建ち終わるまで）。

### 8.5 道しるべと材質

- 材質はゾーンごと（`ZonePalette`）: 鼓動の間 = 深層岩と骨、西の谷 = 熱で黒ずんだ磨き黒石と骨（谷の天井に肋骨の梁）、鐘楼 = 凝灰岩と緑青の銅、第一の広間 = 石レンガ・苔・黒樫（赤い旗）、射手の回廊 = 磨いた安山岩・トウヒ（縦縞の床・白い旗）、詰所 = トウヒの板張り、番兵長の広間 = 黒い磨き石と金（赤い絨毯・金の柱）、心臓の回廊 = 赤いネザーレンガと泣く黒曜石。
- 試練の中の道しるべは `GUIDE_SIGNS`（広間の名前・次の戸・割符の戸・鐘の戸）、床の灯りの道、目的の帯（`TrialGuide`）。鼓動の間と背の入口には案内の碑を置かない（32 の 7）。
- 歩く道の灯りは光度 4 以上（`build audit` の `LIGHT_DARK`）。

### 8.7 広間の広さ: 同じ広間のまま、敵を入口側に寄せ、遮蔽と罠で使わせる

広間の大きさは人数で変えない（仕切りも立てない。`Hall.cuts` は使わない）。一人・二人でも六人でも同じ地図で、隠れる所・罠の場所は攻略の話として共有できる。少人数のときは次の三つで、広さを「動く余地」と「隠れる所」にする。実装は `combat/RoomPlay`（置き場所・罠の動き・柱の段）、`titan/dungeon/RoomPlayRooms`（部屋の一覧）、`RoomPlayEvents`（5 tick ごとの走査）。人数は 29 の 2.8 と同じく「その部屋に入った人の数」。

**1. 敵を入口側に寄せる**（`RoomPlay.spawnNear`・`orderNear`・`angleNear`）。湧き場所の候補を入口に近い順に並べ、残す割合は 1 人 45%・2 人 60%・3 人 80%・4 人から全部。入口から 7 マス以内には湧かせない（残りが足りるかぎり）。番兵長・老番兵の立ち位置も、入口から広間の真ん中へ向かう道の途中（45%・60%・80%。4 人から真ん中。詰所の老番兵は常に真ん中）。骨の砲手は寄せた湧き場所から広間の内へ 2 マス。

| 部屋 | 寄せ方 |
| --- | --- |
| 第一の広間・詰所・番兵長の広間（`TitanBackTrials.spawnWave`） | 九つの湧き場所（四隅・辺の中ほど・中央）を上の割合で絞る |
| 試練の砦 W10（`W10Fort`） | 六つの口を入口に近い順に使う（4 人からもとの順）。中央の番兵は 1〜2 人で手前へ |
| 鞴持ちの炉 E10（`E10Furnace`） | 六つの口を入口に近い順に使う（4 人からもとの順） |
| 嵐の巣 S09（`S09Nest`） | 円の縁の湧きを、入口（西の渡り）の向きの左右へ（入口から 0.9 ラジアン以上離す）。3 人からは配置で回る輪のまま |
| 円い闘技場 W12・T10（`RingArenaCell`） | 幕で半分にする作りはやめた（円は全面）。湧きは入口の橋の側の候補へ寄せる。崩れた穴に落ちた敵は消える。4 人から全面 |
| 潮殻の庭（`TideGarden`） | 珊瑚憑きを置く角・水路を、入口（東の台）に近い順に絞る（4 人から庭いっぱい） |

巣・水路・炉の口から湧くことが部屋の遊びである所（干潟の巣・火床のレール・炉の口・嵐の台・棺の廊下の待ち伏せ）は、出どころを動かさない。

**2. 床の罠の板**（`RoomPlay`）。3×3 の板（ひびの入った床と、中央の芯の一枚。巨神ごとに材質は違う）を床に置く。板は敵がいる間だけ働く。人でも敵でも、板の上に 10 tick いると **40 tick（2 秒）の予告**（床に円が満ちる。`Telegraph`。半径 2.2）が出て、円の中にいる者に当たる。円の外・予告のうちに出た者は無傷。当たったあと 200 tick は眠る。

- 崩れる床と噴き上げが交互。崩れる床: 人は傷 3 と足取り 2 秒、敵は体力の 25%（6〜24）と足取り 4 秒。噴き上げ: 人は傷 3 と小さな打ち上げ、敵は同じ傷と打ち上げ（落下で追い打ち）。人への傷は 3 のみで、体力が 1 になるぶんまでしか減らさない。
- 敵を誘い込む・押し込むのに使える（敵が踏んで止まる・押し込まれて乗れば働く）。ほかの傷のある予告が同じ円に当たる前後 10 tick には始めない。罠どうしは 9 マス・入口から 9 マス・湧き場所から円の縁まで 1 マス以上離す。
- 罠の数は部屋の広さから 3〜8（140 m² につき 1）。働く数は 1 人 35%、一人増えるごとに 13%、6 人で全部（少なくとも 1 つ）。働く罠は入口に近い順。働く板には光の粒が見え、働かない板は同じ見た目で何も起きない。

**3. 遮蔽の柱**。2×2・高さ 4 の柱。広さから 4〜14（75 m² につき 1）。半分は常設、次の 3 割はそのグループが 3 人以上のとき、残りは 5 人以上のとき、そのグループにだけ立つ（封印の扉のブロック。ほかのグループには見えず、当たりもない）。壁から 2 マス・湧き場所から 3 マス・柱どうし 5 マス・罠の円から離す。

**置き場所**（`RoomPlay.layout`）。部屋の名前で乱数を決める（同じ部屋は同じ配置）。床が平らで、上と周り 1 マスが空気の所だけに置く。グループが部屋に入ったとき一度だけ世界に置き、`RoomPlayData` に覚える（建て直されていれば置き直す）。

**入っている部屋**: 岩鯨の第一の広間・詰所・番兵長の広間・砦 W10・棺の廊下 W11、余燼の炉 E10、雷翼の嵐の巣 S09。材質は巨神ごと（岩鯨: ひびの深層岩レンガと骨、潮殻: プリズマリンと海のランタン、雷翼: 酸化した銅、余燼: ひびの黒石レンガと光茸）。

確かめ: 自己テスト `room play`（`RoomPlaySelfTest`。人数ごとの湧き場所の単調さ・全部屋の置き場所が重ならない・罠と柱の数・板の予告が 40 tick・円の外と逃げた人は無傷・敵が踏むと働く・ほかの予告と 10 tick 以上離れる・柱の段）。

### 8.8 石と試練の入口の今
