# 天と淵のあいだ 巨神の背の大きさと作り

- 文書番号: 26
- 範囲: 四つの背（岩鯨・潮殻・雷翼・余燼）の外形の大きさ、倍率の決まり、背に建てるものと建てないもの、作り直しと版、グループの占有。
- 状態: 外形は拡大済み（水平 ×1.6・垂直 ×1.3）。背の中の流れは順路（[32](32_titan_raid_route.md)）。寸法と座標の正は各背の `*Layout`（`TitanBackLayout`・`TideBackLayout`・`StormBackLayout`・`EmberBackLayout`）。測りは `dev backmetrics <巨神>`。
- 関連: [02 岩鯨](02_stone_whale.md)・[08 潮殻](08_tide_shell.md)・[12 雷翼](12_thunder_wing.md)・[13 余燼](13_ember.md)・[32 順路](32_titan_raid_route.md)・[29 試練の引き方](29_trial_pool.md)・21 初回の延長

---

## 0. 要約

- 背の**外形**だけを建てる。巨神の中（体の内側の部屋・通路・試練の翼）は建てない。背は外見と、到着の台・道・広場・碑・灯り、そして体の外に置く心臓の間の入口までを持つ。
- 試練の部屋と中ボスの間と心臓の間は、体の外の**区画**（`trial/raid`・`trial/TrialSlot`）に、順路のたびに建てる閉じた部屋。背の外形とは別。
- 体は水平 ×1.6・垂直 ×1.3。足あと ×2.6。倍率は版ごとのコンパイル時の定数。
- 試練に時間・天気・背の状態の鍵をかけない。背に寄り道の部屋はない（寄り道と設備は地上の祠のまわり。32）。

## 1. 外形の大きさ

| 巨神 | 外形（正は `*Layout`） |
| --- | --- |
| 岩鯨 | 全長 約 700 |
| 潮殻 | 甲羅 約 253×325、ひれまで約 372×406。高さ y 47〜216。海面 y 63 は動かさない |
| 雷翼 | 翼を広げた幅 約 618、全長 約 357。背の高さは三層（凪の低い道・梁の上・嵐の高い道）を収める |
| 余燼 | 全長 約 621。火山の縁 y 217 |

- 次元の高さは 256（y 0〜255）。垂直の倍率は四体とも ×1.3（潮殻・余燼は海面・灰の原から塔・火口の縁までが 125 前後で、×1.45 が上限）。
- 体の外の巨神（見上げる姿）は今の大きさ。背に立つと見た目より大きい。

### 1.1 背で見せるもの

- 見せ場（遠くまで見える所）は各背に 5 か所以上。
- 巨神の形（頭・ひれ・翼・甲羅・火山）と色と材料の言葉は、拡大のあとも保つ。岩鯨は骨と苔と茶の殻、潮殻は珊瑚と真珠層、雷翼は銅と羽、余燼は黒玄武岩と赤橙。

## 2. 拡大の決まり（四体に共通）

1. **体は水平 ×1.6、垂直 ×1.3**。足あと ×2.6、体積 ×3.4。
2. **体の軸と原点は動かさない**。水平は軸から外へ広げ、垂直は腹の下端（岩鯨は y 58、潮殻は海面 y 63）を動かさず上へ伸ばす。古い島の残りが出ないように、基準の y を新しい y へ写す。
3. **外形は殻と外の飾りだけ**。体の深い内側は石で埋め、空洞にしない（自然の湧きを増やさない）。置くのは外から数ブロックの殻と、外の飾り・到着の台・道・広場。
4. **背の上の道と広場の灯りは光度 4 以上**（`build audit` の `LIGHT_DARK`）。
5. **試練に状態の鍵をかけない**。背の段の戸は、そのグループの今の段に開くだけ（32 の 2 章）。

---

## 3. 背に建てるもの

- **到着の台**（乗り込みの台）: 立って 3 秒で順路が始まる。遅れて来た人は、いまの部屋へ合流する。
- **背の道と広場**: 到着の台から、登りの階段・広場・碑・灯りまで。階段は背へ近づくと殻を割って背へ出る。
- **体の外の飾り**: 巨神の形を作る外装。
- **祠**（地上）: 順路の入口の役目。背の中の入口とは別（32 の 3.1）。
- **心臓の間**: 体の外の区画に建てる閉じた部屋（`trial/raid/InstanceArenas`）。背ごとに一つ、区画 0 番の枠（`HEART_X`・`HEART_Z` の中心）。床の高さは巨神ごとに違う。部屋のまわりは元の体の材質で詰めた箱。入口の外に、倒れた人が目を覚ます小さな前室（休み場）と大門がある。
- **試練の部屋・中ボスの間**: 順路のたびに区画の閉じた部屋として建てる（32 の 9 章・5 章）。背の外形の中には置かない。

### 3.1 流れ

背の上の道は到着の台から始まり、順路（歩・智・闘・中ボス・心臓。32 の 2 章）へつながる。流れの細部は各巨神の節（02・08・12・13）と 32 が正。

## 4. 作り方

### 4.1 倍率を定数に通す（`titan/BackScale`）

- `*Layout` の箱・半径・座標は定数で、`BackScale` の関数（水平 `s`・垂直 `dv`・垂直の座標）で作る。倍率は版ごとのコンパイル時の定数（実行時の設定にしない）。
- 自己テスト `scale sweep` が倍率 1.0 と 1.6 で、外形の内側に収まること・壊れないことを見る。
- 倍率 2.0 以上にするには次元の種類（`min_y`・`height`）を変える必要がある。既存のチャンクと食い違うので、新しい次元名の背として作る。
- 体は、深い内側を区画（16×16×16）ごとに一括で置く（`WhaleShape.job`・`BackBuildJobs.ColumnJob`）。体の bin は倍率の 2 乗で大きくなる。
- 建てるのは起動時に裏で（人がいなければ 1 tick 25 ms、いれば 10〜25 ms。`BackBuildJobs.budgetMs`）。

### 4.2 版を上げる建て直し

- 各背の `LAYOUT_VERSION` を上げると、古い島は消して建て直す。試練の進み・休み場の記録・扉の上書きは戻る。`keep.*`（初回を済ませた・見た場面・眠る試練）と巨神の記憶・天の鍵の欠片は残る。版の数字は各背の `LAYOUT_VERSION` が正。
- 体の中にいる人は、次のログインで入口へ出る（02 の 3.6・10 の 10.6）。
- 墓・預かりの場所・位置の札・グループの上書き（`GroupOverlays`）・封印の扉は、すべて `*Layout` の座標から引くので、再計算で追従する。

### 4.3 グループの占有

- 背の中の試練は、一度に一つの区画を使う。区画は番号で分ける（1〜32。小さい空きから。32 の 5 章）。2 レーン・待ち行列は作らない。
- 心臓の間と前室は区画の中のまま、グループごとの上書きと敵の持ち主で、同じ時間に別のグループが使える（02 の 7.1）。
- 敵の AI の範囲（`GuardMob`・`BackAmbientMobs`・`Telegraph`）は部屋の大きさごとに回す。湧きは人数の式（6 人で広間に 15〜20 体）。
- 心臓の技の範囲は床の 4 割以下（02 の 5.4）。自己テスト `telegraph` が見る。

---

## 5. 人数の決まり（部屋の広さ）

- 部屋の広さは人数で変えない。同じ部屋・同じ地図で、一人から六人まで。少人数は敵の寄せ方と数で合わせる（敵の数は部屋の人数で増える。32 の 9.3）。
- 一人でも解ける（重り・留め・時間のどれかを一人にも用意する）。人数で変わるのは「同時にできる量」と「近道」で、「解けるか」は変えない。
- 戦いの部屋の強さは、その試練に入った人の数で決まる（パーティの人数ではない）。
- 新しい敵の種類は足さない。数は人数と部屋の広さに合わせる。

---

## 6. 決めたこと

1. **倍率**: ×1.6（水平）・×1.3（垂直）。倍率は定数。2.0 以上は新しい次元名で作る。
2. **体の中は建てない**。外形・到着の台・道・広場・碑・灯り・体の外の飾りだけ。試練は区画の閉じた部屋で遊ぶ（32 の 2.5）。
3. **任意の翼は持たない**（32 の 0）。
4. **人数**: 部屋は同じ地図。少人数は敵を入口側に寄せ、罠と遮蔽で使わせる。幕（仕切り）は張らない。
5. **待ち**: 2 レーンは作らない。区画が空くまで待つのは、区画の数を超えたときだけ。

---

## 7. 守ること

- 試練に状態の鍵をかけない（段の戸を除く）。
- 心臓の戦いの技と体力式、初回 / 周回（`keep.first_cleared`）は変えない。
- 新しい敵・ブロック・絵を作らない。巨神の識別（形・色・材料の言葉）を拡大でも保つ。
- 心臓の間の床は、巨神の中で元の床の高さに合わせる。
- 設計書は今の仕様だけを書く。
