## 1. 概要

潮殻の心臓を誰かが止めた次の日から、ときどき遠くに「風に逆らって動く嵐」が見えるようになる。雨の幕の中で稲妻が光るたびに、巨大な翼の形が一瞬だけ浮かぶ。それが第三の巨神「雷翼の巨神」だ。嵐を衣のように纏って雲の下を飛ぶ、山のような鳥で、背中に「風の民」の遺跡を乗せている。

一日に一度、午後の「夕立の刻」になると、雷翼は近くでいちばん高い峰に降りて翼をたたむ（止まり木）。足もとから背中まで「昇り風」の柱が立ち、柱に入ったプレイヤーは風に運ばれて背中へ上がる。背中は専用ディメンション「嵐の上」。嵐の雲の天井を突き抜けた上を、雷翼は飛び続けている。

背中は**雷翼の外見と同じ形・同じ色のブロックの鳥**で、ダンジョンは**体の中**にある（01 の決定）。尾羽の上に着き、腰の「羽根の門」から体に入る。背の中の「風の広間」から三つの試練へ。

- 西（左の翼の骨の中）: 風切りの骨。上昇気流と滑空で、空洞の骨の中を手首まで渡る（4.1節）
- 東（右の翼の骨の中）: 雷の骨。落雷の予告を読み、雷を避雷の柱へ導いて骨の戸を開ける。手首の瘤で中ボス「雷獣」（4.2節、5.2節）
- 前（首と頭の中）: 眼の間。巨神の眼から差す光を羽鏡で三つの受け羽へ導く（4.3節）

三つの「風鳴り石」を鳴らすと、広間の床の「竜骨の門」が開く。胸の奥の「竜骨の間」で最終ボス「雷翼の心臓」と戦う（5.3節）。**心臓の三段階は、三つの試練で覚えたことをそれぞれ使う**（段階 1 = 避雷の柱、段階 2 = 昇り風、段階 3 = 光）。報酬は周回前提で、一人ずつの抽選と天井で集める（6章）。

### 1.1 岩鯨・潮殻との違い

三体目で、前の二体と同じ遊びを繰り返さないことを一番の条件にした。

| 観点 | 岩鯨（02） | 潮殻（08） | 雷翼（この書類） |
|---|---|---|---|
| 地上での出会い | 空から降りてくる。待てば来る | 海で見つける。干潮の刻に会いに行く | 遠くの嵐を追う。夕立の刻に、高い峰へ登って待つ |
| 乗り方 | 鎖を右クリックし、引き上げられる | 舟か泳ぎで潮門をくぐる | 止まり木の足もとの昇り風に入り、風に運ばれて上がる（高い所へ登る・風に身を任せる） |
| 背中のまわり | 白い雲の海の上（静か） | 本物の海 | 嵐の雲の天井の上。下の雲の中で稲妻が光り、強い風が流れる |
| 背中の時計 | なし | 潮（2 分。水位で道が開く・閉じる） | 嵐の拍（90 秒の凪と嵐）。地形は変えず、**力**を変える（風の強さ、落雷、敵の動き）。どの拍でも道は閉じない |
| 試練の型 | アスレ（崩れる骨を跳ぶ）・波の戦い・暗い水中迷路 | 運搬・水位の謎解き・巣を壊す野外戦 | 風に乗る移動（昇り風・滑空・横風）・雷を導く位置取り（予告線と避雷の柱）・光の道筋の謎解き |
| 敵 | 盾の番兵、射手、跳ぶ苔這い、水中の顎 | 潮で像になる珊瑚憑き、群れの磯走り、浮かせる泡吹き、巣 | 上から一直線に突っ込む羽守、帯電して連鎖する雷蛾、足もとに雷を呼ぶ雷乞い |
| 中ボス | 閉じた広間の番兵長（人型） | 干潟の大蟹（局所の満ち潮） | 避雷の柱を雷で渡る四足の獣。柱を「接地」させて落とす |
| 最終ボス | 石の殻が剥がれる。床の輪を跳ぶ | 床が満ちて島へ。引き潮と大波 | 雷を柱へ導いて翼を裂く → 昇り風で空中へ → 閃光から目を背ける |
| 避ける動き | 跳ぶ | 島へ上がる・下りる | しゃがむ（頭の高さの風の刃）、浮く（帯電の床）、目を背ける（閃光） |

### 1.2 空の影（雲上の巡礼者）と見分ける

06 の空の影も「翼を持つ鳥のような形」（翼の幅 270 ブロック前後）で、雲の切れ間の目も羽毛の顔をしている。雷翼を見た人が「あれが空の影だ」と思うのは、物語として使える（風の民も同じ誤りをした。9章）。ただし見た目は次で分ける。

| | 空の影（巡礼者） | 雷翼 |
|---|---|---|
| 居る所 | 雲の層の**上**。影と音だけ | 雲の層の**下**、自分の嵐の中。稲妻の光で姿が見える |
| 大きさ | 翼の幅 270 前後 | 翼の幅 約 225（ゲームの描画。ラフ A）。必ず影より小さく |
| 色と光 | 黒い影。光らない | 灰青と白、翼の上を稲妻の筋が光る、手首の瘤が白青と金に光る、冠は銅 |
| 振る舞い | 羽ばたいて通り過ぎる | 輪を描いて飛び、峰に止まる |

- **影から隠れる**: 空の影が 640 ブロック以内を通るあいだ、雷翼は近くの峰へ急いで降り、翼で頭を覆ってうずくまる（06 の動物と同じ怯え方）。嵐が濃くなる。巨神でさえ怯える、を一度だけ見せる見せ場にする（演出だけ。止まり木の扱いにはしない）。

## 2. 雷翼の巨神（地上での振る舞い）

### 2.1 出現

| 項目 | 内容 |
|---|---|
| 出現条件 | オーバーワールドで、ワールドの誰かが潮殻の心臓を止めたあと（10 の 3.2節。世界の進み）。止めた日の次の夜明けから。乗れるのは自分で潮殻の心臓を止めた人だけ（個人の進み） |
| 回数 | 自然な出現はワールドにつき一度。以後は見守り（2.8節）が同じ一体を保つ |
| 出現位置 | ランダムに選んだプレイヤー（観戦者を除く）から 300〜420 ブロック、高さは「まわりの最高の地表 + 60」と 150 の高い方 |
| 通知 | 10 の「どこかで、〜が目を覚ます」の一行だけ。最初の出会いは「遠くの嵐が、風に逆らって動いていた」と自分で気づく形にする。出現から最初の夕立の刻まで、外にいる人に遠雷を一度だけ鳴らす |

### 2.2 嵐の中を飛ぶ（巡航）

- 雲の層（y 192）の下を飛ぶ。高さは「前方の最高の地表 + 60」と 150 の高い方、ただし 185 まで（雲の上へ出ない）。
- 「嵐の中心」を、640 ブロック以内のプレイヤーから 160〜320 ブロック離れた点に置き、そのまわりを半径 120〜200 の大きな輪を描いて飛ぶ。速さ 0.5 ブロック/tick（毎秒 10）。岩鯨（毎秒 4）より速い。嵐の中心は毎秒 0.4 ブロックでゆっくり動く（**風の向きと関係なく動く**のが不気味さ）。
- **嵐の雲**: 雷翼のまわり半径 96 ブロックに、見た目だけの嵐。その中にいる人の画面だけ、雨と雷の空になる（06 の空の影の「その人の画面だけ天気が荒れる」と同じ作り。`SkyPassClient` の天気の部品を使う）。稲妻は光と遠い音だけで、火も傷もない。外から見ると、灰色の雨の幕と、中で瞬く光。
- 地形を削ったり、ブロックを置いたりはしない（エンティティと粒だけで表す）。高さは読み込まれているチャンクの高さマップだけで決める（同期の読み込みをしない。岩鯨と同じ）。

### 2.3 夕立の刻と止まり木

一日に一度、午後の「夕立の刻」に、近くの峰に止まる。

| 段階 | 内容 |
|---|---|
| 夕立の刻 | 時刻 7000〜10600（午後、3600 tick = 3 分）。夏の午後の夕立の見立て。時刻はゲーム内の時刻で決める |
| 止まる相手を選ぶ | 刻の 1200 tick（1 分）前に、640 ブロック以内のプレイヤーを選ぶ。風見鶏（2.6節）で呼んだ人がいれば、その人を優先する |
| 止まり木 | 選んだ人から 24〜96 ブロックの、読み込まれている地表で一番高い点（8 ブロックおきに高さマップを見る）。水の上と木の葉の上は除く。平らなワールドでも必ずどこかは選べる（平地なら平地に立つ） |
| 降りる | 刻の始まりまでに止まり木へ。翼を広げて輪を狭めながら下り、最後に翼をたたんで峰に立つ（モデルの `perch` のアニメ）。間に合わなければ刻の途中でも着いたところで止まる |
| 止まる | 刻が終わるまで動かない。頭は止まり木に近い人を見る（56 ブロック以内）。左の足もとから**昇り風**の柱が立つ（2.4節） |
| 通知 | 止まり木から 200 ブロック以内に「風が向きを変えた。嵐が、峰へ降りてくる……」（語りの色） |
| 刻の終わり | 翼を広げて飛び立ち、巡航に戻る。背中に人がいても戻る（背中から出る人は止まり木の足もとへ。2.5節） |

- 止まる峰はプレイヤーの建物の上も選びうる。足（当たり判定なし）が建物に重なっても壊さない（描画だけ）。昇り風の柱の足もとがブロックの中なら、柱の根元を上へずらす。
- 刻の外に会った人のために、巡航中も翼の稲妻の筋と手首の瘤が遠くで光る（発光のテクスチャ）。

### 2.4 乗り込み（昇り風）

- 止まり木の左の足もとから 6〜10 ブロック横に、見えない当たり判定「昇り風」（`GaleColumnEntity`。潮殻の潮門の口と同じ作り）を置く。半径 2.5、高さは地面から背中の羽根の門の高さ（モデルの `gate` 骨）まで。
- **柱に入ると、風に持ち上げられる。右クリックは要らない。** 毎秒 8 ブロックで上がり、柱の中は横へも少し動ける。しゃがむと下りる。柱から横へ出ると、低速落下 6 秒が付く（落ちて死なない）。
- 柱の上の端（門の高さ）に着くと、画面が白く一度瞬き（稲妻）、雷鳴とともに背中へ渡る。背中の島がまだ建っていなければ建て、尾羽の上（到着）へ移す。
- 目に見える印: 柱の中を雨粒と木の葉と羽根が上へ吸い上げられ、根元の草が渦の形に寝る（粒）。風の音が近いほど強い。柱の 16 ブロック以内にいる人には、2 秒ごとに「昇り風に乗ると、背中へ運ばれる」と出す（止まっている間だけ）。看板は置かない。
- 乗る資格のない人（自分で潮殻の心臓を止めていない人）は、柱の中でも持ち上がらず、理由を一行出す（10 の 3.3節の断り。3 秒は反応しない）。

#### 2.4.1 昇り風にした理由

| 理由 | 内容 |
|---|---|
| 体験を分ける | 岩鯨は「降りてきて、引き上げられる」、潮殻は「海へ出て、自分で渡る」。雷翼は「高い所へ登り、風に身を任せる」。山に登る理由と、空へ上がる気持ちよさができる |
| 主題に合う | 昇り風は西の試練と心臓の段階 2 で使う仕組みそのもの。乗る前に、このダンジョンの主題（風）を体で覚える（潮殻の潮門と同じ考え） |
| 作りやすい | 柱の中は浮遊に近い動きで、乗り込みの途中の扱い（ログアウト、死亡）が単純。巨大なモデルに当たり判定は要らない |
| 弱み | 止まり木が遠いと会えない。一日に一度しか止まらない → 風見鶏（2.6節）で和らげる |

乗り方の別案は 15 章の判断 1。

### 2.5 背中から地上へ戻る

| 方法 | 内容 |
|---|---|
| 羽根の門をくぐる | 背中の羽根の門（腰の上）の口に 0.5 秒いると戻る（潮殻の 20.12節と同じ）。巨神が止まっていれば止まり木の足もとへ、止まっていなければ最後の止まり木の足もと、記録もなければ共有スポーン地点の上 |
| 背中から落ちる | 嵐の雲の天井（y 100）より下へ落ちると、嵐に投げ返される。白い瞬きのあと、最後の休み場（なければ到着）へ戻し、低速落下 5 秒。傷は 2（試練の中では 3）。地上へは戻さない |
| コマンド | `/skyabyss titan leave` |

- 地上へ戻るときは低速落下 10 秒を付ける（止まり木は高い峰のことが多いため）。

### 2.6 風見鶏

雷翼を探す手間を減らす道具。銅の小さな風見の鶏。

| 項目 | 内容 |
|---|---|
| 入手 | 鯨追い（イサナ）のサブクエスト「鯨追いの古い地図」（10 の 8.6節の 9 番。最後の埋もれた箱に入っている）。作業台では作らない |
| 手に持つ | 鶏の向きが雷翼の方を指す（手の中のモデルが回る。風見なので文字の表示は要らない）。画面の下に、次の夕立の刻までの時間を一行。距離は「遠い・近い・すぐそこ」の三段だけ |
| 掲げる（右クリック） | 空が見え、まわり 16 ブロックで一番高い所（または y 100 以上）に立って掲げると、風見鶏に雷が落ちる（演出だけ。傷なし）。雷翼が気づき、2 分後にその人の近くの峰に止まる（夕立の刻と同じ 3 分）。ワールドで 10 分に一度まで。夕立の刻の 1 分前から刻の途中なら、その刻の止まり木をその人の近くにする |
| 低い所で掲げたとき | 「ここは低すぎる。もっと高い所で」と一行。高い所へ登る理由にする |
| マルチ | 誰かが呼べば、ほかの人の風見鶏も同じ方を指し、「○○が呼んだ」と出る |

### 2.7 巨神での移動（09）

雷翼の心臓を止めた人は「雷翼の呼び笛」を受け取る（09 と同じ仕組み）。00 の 60（巨神ごとの飛び方）を推奨（変える）で入れる: 雷翼は速く（巡航 毎秒 40。岩鯨は 28）、雲の下を飛ぶ（雲の帳の代わりに「嵐の帳」で移す）。乗り場は首の付け根、鎖ではなく昇り風で座席へ上がる。`TravelRules` を巨神ごとの値にする（09 の担当と相談。この書類の範囲では値だけ決める）。

## 3. 背中（嵐の上）と配置

### 3.1 ディメンション「嵐の上」（`skyabyss:storm_back`）

岩鯨（`titan_back`）・潮殻（`tide_back`）と分ける（08 の 3.1節と同じ理由）。

- 生成は空（ブロックを置かない平らな世界。層なし）。鳥はコードで建てる（3.2節）。
- **嵐の雲の天井**: 雲を y 100 に描く（ディメンションの特殊効果 `DimensionSpecialEffects` の雲の高さ。NeoForge の `RegisterDimensionSpecialEffectsEvent`）。雲の色は灰紫。雲の下から、ときどき稲妻の光が瞬く（クライアントの演出。雲の層の下に光る板を 0.2 秒）。描けなければ、霧の色と下からの光の粒で代える（判断 4）。
- 空は地上と同じ（時刻は地上と共有）。夜は月が見える。嵐の上なので空は晴れている。風の粒が北から南へ流れ続ける（鳥が北へ飛んでいるため）。
- 天気は晴れのまま（背中の上に雨は降らない。「嵐の上」）。風の音のループ。

### 3.2 鳥の形（巨神の形の背中）

背中は**巨神本体のモデル（採用案 A 嵐の大鷲）と同じ形・同じ色の、ブロックでできた鳥**。モデルの格子から、潮殻と同じ道具（`tools/gen_tide_back_turtle.py` を一般にした `tools/gen_storm_back_bird.py`）がブロックの配置を作る（セルの多数決、テクスチャの色に近いバニラのブロック、乱数なし）。

- 縮尺はゲームの巨神の 1.7 倍（潮殻と同じ。1 単位 = 0.85 ブロック）。頭は北（-Z）、左の翼は西（-X）。
- ただし**翼の芯の厚みだけ 1.4 倍**にする（外から見る形はほとんど変わらない）。翼の骨の中に、背の高さ 12〜16 の回廊を通すため（判断 2）。
- おおよその大きさ（ブロック）:

### 3.4 嵐の拍（背中の時計）

背中の全体に、一つの拍がある。潮殻の潮の時計（`TideClock`）を巨神ごとの周期の部品にして使う（10.2節の `BackCycle`）。

| 段階 | 長さ | 中身 |
|---|---|---|
| 凪 | 40 秒 | 風が弱い。昇り風は弱く（4 ブロックまで上がる）、横風なし、落雷なし。羽守は歩いて番をする |
| 荒れる | 5 秒 | 低い風の唸りが強まる。翼の稲妻の筋が光りはじめる |
| 嵐 | 40 秒 | 昇り風が強く（13 ブロックまで）、骨の中を横風が吹く、雷の骨で落雷、羽守が飛び上がって突っ込む、雷蛾の帯電が速い |
| 静まる | 5 秒 | 風が落ちる。高い音が一度 |

- 一周 90 秒。荒れる・静まるの 10 秒前に、それぞれ違う音（低い風の唸り、遠い高い鳴き声）を島じゅうに鳴らす。
- **風見の目盛り**（潮見の目盛りの部品 `TideGaugeHud` を一般にしたもの）: 背中にいる間、右上に小さな風見の板。矢の向きと揺れで今の拍、次に変わるまでの秒、鳴った石の数。パーティクルの設定に左右されない。
- **道は閉じない**: どの拍でも、すべての戸は開いている。嵐の拍は「近道が使える」「危ないが速い」を決めるだけで、待たなければ進めない所は作らない（潮殻の「最長 60 秒待つ」をさらに減らした）。
- 地形を変えないので、潮のような大量のブロックの置き換え（潮殻は 1 tick に 160）はない。拍で変わるのはエンティティの動きと粒と音だけ（軽い）。

## 4. 三つの試練

三つの試練は、どれから挑んでもよい。風鳴り石は、どの順でも鳴らせる（東の石だけは雷獣を倒すまで黙る）。2 周目からは、三つのうち一つが「眠る」（7.2節）。

### 4.1 西の試練 風切りの骨（風に乗る）

構成: 左の肩の門（休み場 `w0`）→ 上腕の骨（約 45 ブロック）→ 肘の関節の洞（休み場 `w1`）→ 前腕の骨（約 50 ブロック）→ 左手首の瘤（西の風鳴り石）。

鳥の骨は中が空洞で、中に細い梁が渡っている（本物の鳥の骨と同じ）。その中を、風に乗って渡る。

| 仕掛け | 内容 |
|---|---|
| 風切りの羽根 | 肩の門で手に入る試練の品（持ち物に入る。試練の外へ出ると消える）。持っていると、空中でしゃがむ間だけ**滑空**する（落ちる速さ 0.08、前へ 0.35）。背中のエリトラの禁止はそのまま。跳躍と低速落下の効き目は西の試練の中では消す（岩鯨の西の翼と同じ） |
| 昇り風の穴 | 骨の床の穴から風が吹き上がる。入ると上がる。**凪は 4 ブロックまで、嵐は 13 ブロックまで**。穴の上の粒（吸い上げられる羽根）の高さで、今どこまで上がるか見える |
| 骨の梁 | 骨の中を斜めに渡る白い梁。足場になる。横風をよける陰にもなる |
| 横風 | 嵐の拍のあいだ、6 秒ごとに手首の側から肩の側へ吹く（前へ進む人には向かい風）。1.5 秒前に雨の筋が流れはじめ、笛のような音が高まる。吹いている 2 秒は、梁の陰にいないと 0.4 ブロック/tick で押し戻される（**横へは押さない**。骨の外へは落ちない向き） |
| 割れた床 | ところどころ骨の床が割れていて、下は嵐の雲。落ちると嵐に投げ返され、最後の休み場へ（傷 3） |
| 道の形 | 上腕と前腕で三通りずつ、リセットの種で選ぶ。どれも「凪の低い道（梁を伝う、時間がかかる）」と「嵐の高い道（昇り風で上の梁へ、横風に気をつける、速い）」がある |

- **流れ**: 凪のうちに低い道を進むか、嵐を待って高い道で一気に越えるかを選ぶ。最後の瘤の中の岩棚は、嵐の昇り風でしか届かない（最長 45 秒待つ。待つあいだに瘤の中の雷蛾を落とす）。
- **岩鯨の西の翼との違い**: 崩れる骨を跳び継ぐのではなく、風を読んで乗る。跳ぶ距離の正確さではなく、拍と高さと陰の選び方の遊び。
- **一人のとき**: 横風を梁の陰でやり過ごし、凪の低い道で進める。**マルチ**: 先に行く人が高い道、ほかの人が低い道で雷蛾と羽守を引きつける。
- **理不尽にしない**: 横風は押し戻すだけで、骨の外（割れた床）へ向かっては押さない。割れた床の縁は 1 段高い。落ちても最後の休み場から（持ち物は失わない）。
- **敵**: 羽守 3（+1/人）。凪は梁の上で番をし、嵐で飛び上がって一直線に突っ込む。雷蛾 2〜4。
- 推定の所要時間: 慣れた人で 4〜6 分。

### 4.2 東の試練 雷の骨（雷を導く）

構成: 右の肩の門（休み場 `e0`）→ 雷の回廊（骨の戸 3 枚）→ 肘の関節の洞（休み場 `e1`）→ 右手首の瘤・雷獣の巣（中ボス）→ 東の風鳴り石。

右の翼の骨には、稲妻の筋が骨の中まで通っている。雷はこの骨を伝って手首の瘤へ集まる。

| 仕掛け | 内容 |
|---|---|
| 招雷（予告の輪） | 嵐の拍のあいだ、4 秒ごとに回廊の中の誰か一人（直前と別の人）の足もとに、白い輪が 1.2 秒出て、そこへ雷が落ちる（傷 11、0.5 秒の鈍足）。雷乞い（5.1節）も凪・嵐を問わず同じ輪を呼ぶ |
| 避雷の柱 | 銅の柱。**輪が柱から 3 ブロック以内なら、雷は柱へ落ちる**（人には当たらない）。柱は 3 回受けると満ち、先が光り続ける。対になる骨の戸が開く |
| 予告線（放電） | 嵐の拍のあいだ、回廊の壁から壁へ、床と壁に光る線が 1.2 秒走ってから、線の上を放電が走る（傷 12）。線は 2〜3 本が同時に、間を空けて出る。跳び越せる高さ（床から 1 段）と、しゃがんで潜る高さ（頭の上）の二種類 |
| 雷蛾 | 満ちかけの柱に寄ってきて、触れると柱の雷を 1 回分吸う（光る）。倒せば戻らない |
| 骨の戸 | 3 枚。柱が満ちると開く。一度開いたらリセットまで開いたまま |

- **流れ**: 嵐を待ち、柱のそばに立って雷を「受けさせる」。輪が自分の足もとに出たら、柱の 3 ブロック以内へ寄る。凪のあいだは雷乞いを柱のそばへ誘い出し、雷乞いの雷で柱を満たすこともできる（凪にも進められる）。
- **マルチ**: 招雷は人を替えて落ちるので、柱のそばに一人、雷乞いと雷蛾を落とす人に分かれる。**一人**: 柱のそばで嵐を待つ（一つの柱は嵐の 1 回で満ちる程度の頻度）。
- **理不尽にしない**: 輪は必ず 1.2 秒前に出る。粒は `overrideLimiter` で送り、音と、風見の目盛りの縁の光でも知らせる（岩鯨の必須4）。輪の真下に柱がないときも、3 ブロック以内に柱がある所で輪が出る（柱から離れた所にいる人は狙われない）。
- 推定の所要時間: 回廊 3〜4 分、雷獣 2〜3 分。合わせて 5〜7 分。

### 4.3 前の試練 眼の間（光を導く）

構成: 風の広間の上の回廊（嵐）か螺旋の坂（凪）→ 首の回廊・前室（休み場 `f0`）→ 眼の間 → 嘴の付け根の小部屋（前の風鳴り石）。

巨神の左の眼はガラスで、頭の中へ光が差し込む。昼は日の光、夜は月の光（色が変わるだけ。強さは同じ）。

| 仕掛け | 内容 |
|---|---|
| 眼の光 | 左の眼から、床から 2 ブロックの高さを水平に走る光の筋（ビーコンの光の筋に近い描き方。細い板と粒）。壁や柱に当たると止まる |
| 羽鏡 | 5×5 の台のうち 6〜8 台に置かれた、磨いた銅の羽の鏡。右クリックで 90 度ずつ回る（45 度の斜めの鏡の 4 つの向き）。光を直角に曲げる |
| 受け羽 | 壁の三か所の白い羽の飾り。光が当たると光り続ける（一度光れば、そのあと光が外れても消えない）。三つとも光ると前の石の戸が開く |
| 戻しの鏡 | 前室の台。引くと鏡を最初の向きに戻す（30 秒に一度）。詰んだ状態を作らない |
| 雷蛾 | 嵐の拍のあいだ、光に寄ってくる（蛾だから）。光の筋の上にいる雷蛾は光をさえぎる。倒すと通る |

- **配置**: 手で作った四つの配置（台の上の鏡の数と最初の向き、受け羽の位置）から、リセットの種で一つ。最短 4〜7 手。ワールドで初めて挑むときは、いちばんやさしい配置。自己テストで全配置を解く（潮殻の潮見の間と同じ）。
- **手がかり**: 台の縁の刻み（鏡の向きの印）。光が鏡に当たると、鏡の羽が震える音。受け羽は、光が近くを通ると少し揺れる（あと一つの鏡で届く、が分かる）。
- **岩鯨・潮殻との違い**: 潮殻の潮見の間は「量を移す」謎解き（水を溜めから溜めへ）。眼の間は「向きを決める」謎解き（光の道筋）。答えの形が違う。
- **見る者へのほのめかし**: 三つ目の受け羽の下の壁に、人の形の小さな浮き彫り（留まる者に似た四角い頭）。碑文（9 章）の「お前の顔は もう知っている」と合わせて、ここに前にも誰か（自分）が来たことをほのめかす。説明はしない。
- 推定の所要時間: 慣れた人で 3〜4 分（初めてなら 6〜8 分）。

- 岩鯨・潮殻の敵と役割がかぶらないようにした: 正面を盾で守る（番兵）、遠くから鈍足の棘（射手）、跳びつく（苔這い）、水中（顎）、像になる（珊瑚憑き）、群れ（磯走り）、浮かせる（泡吹き）は置かない。羽守は「上から一直線」、雷蛾は「離れて立て（連鎖）」、雷乞いは「足もとを見て動け（ただし柱へ誘える）」。

- 人数で増える数: 羽守 +1/人、雷蛾 +1/人、雷乞い +1/2 人（最大 4 人まで数える）。

### 5.2 中ボス「雷獣」

稲妻とともに落ちてくる獣（民話の雷獣）。灰青と青白い毛の、狼に近い四足の獣（推奨ラフ A）。右手首の瘤の中に棲み、瘤に集まる雷を食べている。体の長さ約 4.5 ブロック。

**戦場**: 直径 26 の丸い洞。避雷の柱が 6 本（中心から半径 9、60 度おき）。柱の根元に「接地の栓」（銅の取っ手）。栓を右クリックすると、その柱は 8 秒「接地」する（先の光が消え、根元が暗くなる。待ち 4 秒）。

| 技 | 条件 | 流れ | ダメージ |
|---|---|---|---|
| 雷渡り | 柱の上にいるとき、6〜9 秒ごと | 1.0 秒、今の柱から次の柱へ光る線（予告）。雷になって線の上を渡る。次の柱は「いちばん近くの人に近い柱」 | 線の上の人に 12。**着いた柱が接地していると、痺れて 4 秒落ちる（動けない、受ける傷 1.5 倍）** |
| 飛びかかり | 床にいて、距離 4〜10 | 0.8 秒身を低くし（尾の稲妻が光る）、跳びかかる | 11、少し跳ね飛ばす |
| 爪の連打 | 距離 3 未満 | 0.5 秒ごとに 3 回 | 5 ずつ |
| 雷鳴の咆哮 | HP 50% を初めて切ったとき一度 | 1.5 秒。人の足もとに招雷の輪を 6 つ、雷蛾を 2 体 | 輪 9 |
| 柱へ戻る | 床で 10 秒たつ | 一番近い柱へ跳び上がる（予告なしの移動。傷なし） | — |

- **主題**: 柱の接地。線が出てから 1.0 秒のあいだに、行き先の柱の栓を引けば落とせる。雷獣は人に近い柱へ渡るので、一人でも「自分のそばの柱で待ち、線が向いたら栓を引く」で落とせる。マルチでは柱ごとに人が立つと速い。
- 怒り（50% 以下）: 雷渡りの間隔 4〜6 秒、飛びかかりの溜め 0.6 秒。
- 体力は 430 ×（1 + 0.6 ×（参加者 − 1））（心臓と同じく、受ける傷を割る）。段階のない 10 段のバー（色は青白）。
- 痺れて落ちているあいだが大きな攻め時。張り付いて殴り続けるだけでは、爪の連打と飛びかかりで負ける（潮招きと同じ線）。

- 推定の所要時間: 一人 3〜4 分、四人 2 分前後。

## 6. 報酬（周回前提）

岩鯨・潮殻と同じ型。報酬はすべて一人ずつ別々の抽選で、持ち物へ直接入る。受け取る人は参加者。倒れていた人・持ち物がいっぱいの人の分は預かる（`TitanMemoryData`）。宝箱はない。巨神の記憶（天井）は巨神ごとに別のカウンタ（`thunder_wing`）。

| 雷翼の心臓 | 480（初回 +300） | 24 |
| 試練の踏破（風鳴り石） | 60 | 24 |

- **レベルの上限との関係**（10 の 5章）: 雷翼に乗れるのは潮殻を止めた人なので、上限は 27（= 雷翼 24 + 3）。推奨 +3 までは満額なので、雷翼の背では上限の 27 まで経験値が減らない。雷翼の心臓を止めると上限が 33 になる。27 の上限に当たった人は、心臓を止めた瞬間（報酬より先に進みを書く）から次のレベルへ進める。

## 7. 何度でも挑める仕組み

岩鯨・潮殻の仕組みをそのまま使う。違うところだけ書く。

### 7.1 試練のリセット

- 条件は同じ: 背中に誰もいなくなって 3 分、または心臓を倒したあと、竜骨の門より奥に 30 秒だれもいない。
- リセットされるもの: 三つの風鳴り石、抜け道、竜骨の門、骨の戸と避雷の柱、眼の間の鏡と配置、風切りの骨の道の形、雷獣と心臓、敵。
- 嵐の拍は、リセットのときに「凪の始まり」に戻す。
- リセットの瞬間に試練の中にいる人は、風の広間へ移す。

### 7.2 眠る試練（2 周目から）

- 潮殻と同じ部品（`TitanBackReset` の眠る試練）。ワールドで雷翼の心臓が一度でも倒されたあとは、リセットのたびに一つが眠る。同じ試練は二回続けない。
- 1 周の目安: 初回 25〜35 分、2 周目から 12〜18 分。

| 区間 | 推定（慣れた人） |
|---|---|
| 到着 → 風の広間 | 1 分 |
| 風切りの骨 | 4〜6 分 |
| 雷の骨と雷獣 | 5〜7 分 |
| 眼の間 | 3〜4 分 |
| 竜骨の門 → 心臓 | 3〜4 分 |
| 三つとも | 16〜22 分 |
| 一つ眠るとき | 12〜17 分 |

### 7.3 倒れたとき

- 持ち物と経験値の預かり、休み場からの復活は同じ（`TitanBackTrials.keepBelongings` の部品）。
- 休み場: `hub`、`w0`、`w1`、`e0`、`e1`、`f0`、`heart` の 7 つ。焚き火にしゃがんで触れると、試練をあきらめて尾の間へ戻る。
- 風切りの羽根は倒れると消え、肩の門でまた手に入る。

### 7.4 ピースフル

- 01 の決定どおり、試練は眠る。腰の回廊（尾の間から広間への道）を封じ、「巨神は目覚めない」と出す。尾の間・背の上を歩くこと、炉を使うことはできる。
- 嵐の拍はピースフルでも動かす（景色として）。

### 7.5 マルチプレイ

| 場面 | 決まり |
|---|---|
| 乗り込み | 昇り風は何人でも同時に乗れる。資格は一人ずつ見る |
| 嵐の拍 | 背中で一つ。全員が同じ拍を見る |
| 風切りの骨 | 風切りの羽根は一人一枚。高い道と低い道に分かれられる |
| 雷の骨 | 招雷は人を替えて落ちる。柱ごとに人が立つと速い。一人でも解ける |
| 眼の間 | 鏡は誰でも回せる。戻しの鏡は 30 秒に一度 |
| 雷獣 | 参加者の決まりは岩鯨と同じ（5 秒の予告、前室も入れる）。柱ごとに人が立つと落としやすい |
| 心臓 | 同じ参加の決まりと体力の式。閃光は人ごとに向きを見る |
| 報酬 | 一人ずつの抽選。人数で取り分は減らない |

## 8. 背中の決まり

`TitanBackRules` をそのまま使う（ブロックの設置と破壊、エリトラ、バケツ、エンダーパール、ウィンドチャージ、花火の禁止）。加えて:

| 追加の制限 | 理由 |
|---|---|
| 西の試練の中では、跳躍・低速落下の効き目と、羽衣の空駆けが効かない | 風に乗る遊びを、近道でなくさない（岩鯨の西の翼と同じ） |
| 三叉槍の激流・召雷は使えない | 激流は風切りの骨を飛び越せる。召雷は避雷の柱の遊びを壊す |
| 避雷針のブロックは持ち込んでも置けない（設置の禁止のとおり） | — |

- 防具のエンチャント（落下耐性）と、低速落下の薬は西の試練の外では使ってよい。

## 9. 碑文と伝承

05 の型で書く。答えは書かず、ほのめかしだけにする。碑文は 4 行、光る文字の看板。**1 行は日本語 8 字まで、英語は看板の 90 px に収まる長さ**（`SignFit` の自己テストで確かめる）。伝承の書の項目は `chapter1/storm_*`。

### 9.1 風の民（設定。プレイヤーには直接見せない）

- 雷翼の背に住んだ人々。嵐の拍を「巨神の息」と考え、凪と嵐を数えて暮らした。
- 骨の中を風で渡る術、雷を柱へ導く術、眼の光で時を読む術を持っていた。
- **空の影を、この鳥だと思っていた**。空の影が通る夜、雷翼が嵐を濃くして峰にうずくまるのを見て、はじめて違うと知った。雷翼は嵐を纏って、上の影から隠れている。
- 民がどうなったかは書かない。羽守（外套を広げたまま空洞になった番人）と雷乞い（今も雷を乞い続ける人影）が、その答えのように見えるだけにする。

### 9.2 碑文（6 枚）

| 場所 | ID | 碑文（4 行） | 英語 |
|---|---|---|---|
| 尾の間 | `lore_storm_tail` | 嵐は鳥の衣 / 衣を脱がぬのは / 見つかるからだ / 上の影に | A storm cloak / never shed / lest it be seen / by the shadow |
| 風の広間 | `lore_storm_hub` | 凪には下を / 嵐には上を / 風の民は / 息を数えた | In calm, below / In storm, above / The wind folk / counted breaths |
| 左手首の瘤 | `lore_storm_west` | 骨は空洞 / 風の通う道 / 我らは骨の中で / 飛ぶことを知った | Bones are hollow / roads for wind / Inside them we / learned to fly |
| 右手首の瘤 | `lore_storm_east` | 雷は柱を選ぶ / 柱は我らを / 守ってくれた / あの夜までは | Bolts choose rods / and the rods / kept us safe / until that night |
| 眼の間 | `lore_storm_eye` | 眼は来る者を / 覚えている / お前の顔は / もう知っている | The eye recalls / all who come / Your face it / already knows |
| 竜骨の前室 | `lore_storm_heart` | 雷は空から / 落ちてくる / この拍だけは / 下から昇る | Bolts fall / from the sky / This beat alone / rises from below |

- 英語の行は案。どの行も `SignFit`（1 行 90 px）で測って、はみ出せば詰める（伝承の担当）。
- 「分かたれた鼓動」は前室の碑文だけでほのめかす（岩鯨「地の底から預かった」、潮殻「下の深いところから」の問いの形を、雷の向きで三度目に言い換える。三体目で「どの巨神も同じだ」と確信させる）。
- 尾の間の碑文は、空の影（巡礼者）への伏線。「上の影」が何かは書かない。
- 眼の間の碑文は、見る者・留まる者（ループ）への伏線。答えは 3 章まで書かない。

**試練の入口の一言（3 枚、2 行）**: 「風切りの骨 / 風に乗れ」（"Windbone / Ride the wind"）、「雷の骨 / 雷を柱へ」（"Thunderbone / Bolts to rods"）、「眼の間 / 光を三つへ」（"Eye Hall / Light to three"）。

**最初の一度だけの囁き**（`BackWhispers` の型、`StormWhispers`）: 8 か所。尾羽の上（「羽根の門の奥で、何かが脈打っている」）、尾の間（炉・焚き火・風見の目盛りの読み方）、風の広間（凪と嵐で上へ行く道が変わる）、背の上、左の肩の門（風切りの羽根の使い方: 空中でしゃがむ）、右の肩の門（輪が柱の近くなら、雷は柱へ）、首の前室（鏡は手で回る、戻しの鏡）、竜骨の前室。最初の休み場では、焚き火であきらめられることも添える。

### 9.3 伝承の書の項目（案、10）

| ID | 題 | 記される条件 |
|---|---|---|
| `chapter1/storm_wing` | 風に逆らう嵐 | `skyabyss:thunder_wing` が 240 ブロック以内に入る、`skyabyss:storm_back` に入る |
| `chapter1/storm_ruins` | 風の民の遺跡 | `skyabyss:storm_back` に入る |
| `chapter1/inscription_storm_{tail,hub,west,east,eye,heart}` | 6 つの碑文 | 碑文を読む（潮殻と同じく碑文ごとに 1 項目） |
| `chapter1/raiju` | 雷獣 | 雷獣が倒れる |
| `chapter1/storm_stilled` | 晴れた空 | 雷翼の心臓が倒れる |
| `chapter1/wind_ledger` | 風見の帳（破れた頁） | 破れた頁（雷乞いから 5%） |
| `chapter1/storm_cower` | うずくまる巨神 | 空の影の通過中に、うずくまる雷翼を 160 ブロック以内で見る |

**風に逆らう嵐**（`chapter1/storm_wing`）

遠くの嵐が、風上へ向かって動いていた。稲妻が光るたびに、雨の幕の中に翼の形が浮かんだ。

翼は、空の影より小さかった。

**晴れた空**（`chapter1/storm_stilled`）

雷翼の心臓が止まった。胸の奥の風が、はじめて止んだ。

見上げると、背中の天窓の向こうに雲がなかった。嵐の上は、こんなにも晴れていたのか。

**風見の帳**（`chapter1/wind_ledger`）

凪と嵐が、棒の数で書き留めてある。ある日から、棒の横に小さな印が付きはじめる。上を見るな、という意味の印らしい。

最後の頁には、棒が一本もない。

**うずくまる巨神**（`chapter1/storm_cower`）

空の影が通るあいだ、雷翼は峰にしがみつき、翼で頭を覆っていた。山のような鳥が、怯えていた。

**雷獣**（`chapter1/raiju`）

獣が倒れると、瘤の中に集まっていた雷が、行き場をなくして柱を何度も行き来した。やがて、柱は静かになった。

## 11. 実装の順番と担当の分け方

ベータ（巨神 4 体を全員倒すまで）を急ぐため、**推奨ラフ（14 章）で、6 つの担当が並行に作る**。担当ごとのファイルの境界を決め、共有のファイル（登録の一覧、自己テストの一覧、lang）は各担当が一行足すだけにして、最後のまとめ役が合わせる。

### 11.1 先に決める約束（全担当）

- パッケージ: `jp.revati.skyabyss.titan.storm`（地上）、`.storm.back`（背中と試練）、`.storm.mob`（敵）、`.storm.raiju`（中ボス）、`.storm.heart`（心臓）、`jp.revati.skyabyss.item.storm`（装備）。描画は各パッケージの `.client`。

#### 17.6.5 合わせるときの手順（まとめ役へ）
