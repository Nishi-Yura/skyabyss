# 57 文言の書き方

- 範囲: Mod の中で人が読む日本語（言語ファイル `assets/*/lang/ja_jp.json`、プレイヤーに見える Java の文字列）の書き方と用語。
- 状態: 2026-11-07 の声「カタカナを使っていい。組 → パーティーのように」「日本語や文がおかしい、漢字を使いすぎ、と言われた」を受けて決めた。推敲は yomiyasu スキルの基準（意味・比重・言い切り・文の働きを変えない、足さない）で行う。
- 関連: [07](07_npc_quest.md)（会話とクエスト）、[18](18_notices.md)（知らせ）、[56](56_ui_layout.md)（文字の入る幅）。

## 1. 基本

- ゲームの仕組みを指す言葉は、ゲームでよく使うカタカナ語にする（下の用語表）。物語の地の文・会話・碑文は、場面に合う言葉のまま（無理にカタカナにしない）。
- 漢字は、ふだんの文章でひらがなで書く語をひらがなにする（例: 事 → こと、為 → ため、出来る → できる、既に → すでに、但し → ただし、殆ど → ほとんど、又 → また、及び → と、頂く（補助）→ いただく、下さい → ください、無い → ない（補助・形容）、様に → ように、所（形式）→ ところ）。
- 文はふつうの語順と助詞で書く。言葉を切りつめた電報のような文（「押して一口売る」）は、意味を変えずに自然な文に直す。
- 説明・ヒントは「〜しよう」「〜できる」など、今の書き方の文末と働きを保つ。会話は話し手の口調を保つ。
- 文字の入る幅（ボタン・札・帯・看板の 1 行）は変えない。長くなる言い換えは、幅に入るときだけ。看板 (`sign.*`) は 1 行 9 字まで。
- 書式の記号（`%s`・`%1$s`・`§`・`\n`）と数字はそのまま残す。

- そのままの語: 天職（二つ目のジョブ）、スキルツリーの「型」（系統。プリセットとは別）、職人（人）、物語の「傷」「印」「帯」。
- 常用外の漢字は、固有名詞でなければひらがな（熾 → おき火、鞴 → ふいご、鎚 → つち、籠 → かご、気嚢 → 空気袋）。

## 3. 道具（tools/dev/text）

- `lang_dump.py <ファイル> <はじめ> <件数>`: 言語ファイルを番号つきで見る。
- `lang_apply.py <ファイル> <差し替え.json> [--check]`: 差し替えを当てる。書式の記号・改行の数・看板の 1 行 9 字・短い札（元の長さ + 2 字）を確かめ、合わないものは当てない。
- `lang_review.py <フォルダ> show|apply`: 差し替えのフォルダをまとめて見る・当てる。
- `lang_terms.py [--write]`: 用語表の機械的な置き換え（クールダウン・パーティー・ページ・封印の箱・空気袋）を全部の ja_jp.json にかける。文言を足したあとに流す。
- `lang_left.py [語]`: 仕組みの文言（会話・碑文・伝承・看板を除く）に残っている古い語を数える。
