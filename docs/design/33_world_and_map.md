## 0. 要約（塩梅の決まり）

| 固定するもの（背骨） | 自由のまま（バニラ） |
| --- | --- |
| **はじまりの町**（鐘の宿り）: 目覚めの野営地から煙の先、世界に一つ。**Wynncraft の最初の町（ラグニ）と同じ大きさ（約 200×200、壁つき）**。語り部・イサナの焚き火・職人・言伝ての板・これから足す施設の区画（四つの祠は町の外） | 地形・バイオーム・鉱石・村・バニラの構造物。**バイオームは分けない、置き換えない** |
| **四つの章の跡地**: 町から見て**決まった方位**に、決まった距離の帯の中（岩鯨 = 北の丘、潮殻 = 東の海辺、雷翼 = 西の峰、余燼 = 南の灰の地）。その章の地上の場所（21）と祠（32）がここに建つ | 採掘・建築はどこでも。町の芯（48×48）と祠の台座（9×9）だけ壊せない |
| **目覚めの場所**: 砂漠・海・山に落ちない（平原か森、水が近い） | 拠点はどこに作ってもよい（町の壁の中の空き区画にも）。章の小要素（旅の跡など）は今までどおり拠点のまわりに出る |
| **道しるべ**: 町から跡地へ、石標が 40 ブロックごと（舗装しない） | 道を作るのも作らないのも自由 |

- 世界を手作りしない代わりに、**方位と距離を固定**する。どの世界でも「海は東、嵐は西、灰は南」。語り部がそう言い、地図にそう出る。
- 方位の先に合う地形がなければ、**その場所だけ**を mod が整える（入り江・峰・灰の盆地。一辺 160 まで）。バイオームの塗り替えではなく、既存の地形を削る・盛る・水を張る。
- 地図は **M で開く一枚の「旅の地図」**（画面全体）。ミニマップは持たない（UI を増やさない。目的の帯と画面の縁の矢印が既に方向を示す）。

## 1. 塩梅の考え方

1. **RPG 感は「場所の記憶」から来る**。Wynncraft が固定の世界なのは、町・道・入口を覚えられるからで、地形の美しさではない。だからこの mod は「覚える対象」（町・跡地・祠・道しるべ）だけ固定し、地形は覚える対象にしない。
2. **マイクラの自由は「どこでも掘れる・建てられる・資源が尽きない」**。バイオームを分けない・置き換えない・保護は最小、で守る。
3. **遠さの懸念は、距離の帯と移動で解く**。一章は近く（町から 300〜600）、章が進むほど遠く（最大 2,000）。一章の心臓のあとは巨神の子（09）で碑・祠へ飛べる。地図に跡地の「噂」が出るので、方角は迷わない。
4. **会えない懸念は、方位の固定と地形の手直しで解く**。潮殻は「東へ行けば海がある」を mod が保証する（なければ入り江を作る）。
5. **壊される懸念は、保護を点にして解く**。町の芯と祠の台座だけ。背（ダンジョン）は今のまま守る。

## 2. はじまりの町（鐘の宿り）

- **場所**: ワールド生成の最初に、mod が目覚めの場所と町の場所を決める。種のスポーンから 2,000 以内で、平原・森・草地（砂漠・雪原・海・山・湿地を避ける）、100 以内に水、128 以内にバニラの村・構造物がない所。見つからなければ条件を緩めて（砂漠だけ避ける）最も近い所。目覚めの野営地は町から 200〜300 の所（煙が見える距離。17 の 3.3.1 の煙の柱はそのまま）。
- **大きさ**（決定 211）: **Wynncraft の最初の町（ラグニ）と同じ約 200×200**。壁と門（四方。門は方位の跡地へ向く: 北門 岩鯨、東門 潮殻、西門 雷翼、南門 余燼）。あとから施設を足せるよう、区画を空けておく。
- **作り**: 今の鐘の宿り（17 の 3.3）を町の**芯**（鐘楼・語り部の家・広場）にし、まわりを区画で埋める。地形に馴染ませて（縁は段々に、水は残す。壁の外は普通の地形）建てる。

| --- | --- | --- |
| 芯（広場） | 大鐘楼と語り部の家（既存）、広場（井戸・市）、歌の間（鐘の地下。既存） | W1 |

- **人の少なさ**: 大きくしても NPC は語り部・イサナ・職人（と将来の施設の NPC）だけ。空き家と広い通りの静けさが序章の「人がいない」を強める。建物の種類と物語との結びつきは 2.2。
### 2.2 国家の都としての建物（物語との結びつき）

**決定（2026-10-20）: 「絶えかけの国の都」で作る。** 国は建物・名前・記録で見せ、生きた政治や群衆では見せない。序章の基盤（野営地 → 煙 → 鐘 → 語り部一人 → 影 → 足音。17）は変えず、煙の柱の先が小屋ではなく大鐘楼になるだけ。メインクエスト・拍子・NPC の筋は変えない。

この町は村ではなく、**空を見張る小さな国「鐘の国」の都**（名は決定 219）。王はいない。代々「空見」（そらみ）と呼ばれる見張りの一族が国を預かり、影が通れば鐘を鳴らし、見たものを帳面に記してきた。今はその一族が絶え、語り部が最後の鐘守として残っている。**都は大きいのに人が少ない**（空き家・静かな通り）。これが序章の「人がいない」の正体の一つで、国の大きさが「かつてはここに人がいた」を語る。NPC は語り部・イサナ・職人（と将来の施設の係）だけで、市と住まいにバニラの村人が少しいる（決定 218）。

- 町家と町家のあいだは幅 3 の路地（くっつけない）。設計図の検査 `python -I tools/capital/audit.py` が、戸の前と内側・碑の前・人の立つ所・係の人と宿の寝台とクエストの家の印・梯子（背の壁と上の降り口）・南門から歩いて届くか・建物どうしの間を調べる。ゲーム内の建築の監査は `SKYABYSS_SELFTEST_ONLY="build audit" SKYABYSS_AUDIT_ONLY=opening`（`SKYABYSS_AUDIT_STRICT=1` で飾りの階段も見る。見つけた所は `python -I tools/capital/audit_map.py <o> <r>` で設計図の座標に）。
- 施設の置き場は 35 の 2.1（見取り図 A 四つの通りの役割。東 = 交易、西 = 祈りと旅、南 = 職、裏通り）。建物と中身は `tools/capital/facilities.py`、係の人の印 `npc_<役>`・宿の寝台 `inn_bed*`・町のクエストの家 `quest_house_<n>` は 35 の 6.6。
- 大通りの 1 列目は入れる建物だけ（施設と、町のクエストの家 11 棟。家は一階の居間と、梯子で二階の寝室）。物語に関係のない町家（2 列目より奥の 43 棟）・塔・門楼には入れない（中は埋め、窓の奥は暗く、戸は壁に貼った跳ね上げ戸）。
- 碑を見ると序章の伝承に記される（`prologue/capital_skywatch`・`capital_guild_roll`・`capital_graveyard`・`capital_gates`。05 の 8.1）。語り部は「この都は、どこも戸が閉じている」で空見の一族と最後の鐘守のことを一度だけ話す（07）。

- **一つだけ**: 世界に町は一つ。遅れて入った人も同じ町に目覚める（野営地は人ごとに別の向きでもよい）。
- **見せ方**: 町は「人がいない村」のまま（17 の原則。NPC は語り部・イサナ・職人だけ。空き家は静か）。大きくしても人は増やさない。

### 3.1 「巨神が来る所」の決まりとの関係

- 岩鯨は今までどおり人のそばへ降りる（02 の 2.3。跡地は骨の丘と見張りの丘で、鎖は近くの開けた地面）。

- 雷翼は西の峰に止まる。夕立の刻の止まり木と風見鶏で呼ぶ止まりは、峰の中心から 256 以内に人がいるときだけ、峰の中心から 64 以内のいちばん高い所（`titan/storm/StormPeak`）。風見鶏は峰から遠いと「雷翼が降りるのは、都の西の峰だけだ」と返す。
- 余燼は南の灰の地で浮上する。集まりの刻の浮上と温石の頼みは、灰の地の中心から 256 以内に人がいるときだけ、中心のまわり 24〜160 の平らな陸に伏せる（`titan/ember/EmberBasin`）。温石は遠いと「余燼が浮かぶのは、都の南の灰の地だけだ」と返す。
- 呼び貝・呼び羽・呼び鈴（09 の 4.4。心臓のあと）、開発コマンド、空の影でうずくまる・眠りの峰は、跡地に限らない。

## 4. 地図（M キー「旅の地図」）

### 4.1 何を見せるか

- **印**（32×32 のドット絵、画面では 16×16。縁取りは巨神の色、ないものは骨の色）: 町（鐘の宿り）、旅の野営地、自分（向きの矢じり）、仲間（淡い青の縁）、自分の墓（朱の縁）、巨大な足跡、骨の丘、積み石（町からの道しるべの点線）、章の場所、章の跡地、巨神の祠（心臓を止めた人に）、覚えた碑、出会った巨神、いまの目的（目的の帯と同じ金のひし形）。言伝ての板の依頼は絵だけ用意してある。
