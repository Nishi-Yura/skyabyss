# 59 攻撃の見せ方の決まり

敵の攻撃とプレイヤーの技・武器の振りを、どれも同じ決まりで見せる。バニラの粒・mod の粒・模型・光を重ねすぎて見づらくなっていたのを、段ごとに係を一つに絞って作り直す。景色・町・NPC・品・歩く跡の粒は、攻撃が終わってから同じ決まりで直す。

## 1. 段ごとに係は一つ

| 段 | 係 | 使わないもの |
| --- | --- | --- |
| 予告（どこに・いつ） | 床の印（`TelegraphRenderer`） | 予告の形の中に湧く粒・ひびの粒 |
| 溜め（だれが・もうすぐ） | 光（技の元に光の筋が集まり、元が明るむ。`AttackLightFx`） | 技の元のまわりの粒 |
| 当たる物（なにが） | 模型（岩・波・炎・骨の形。`AreaFx`・`AttackProps`）。光線・息・雷は光の帯 | 当たる物を粒で描くこと |
| 当たった瞬間 | 光の輪と、mod の粒を少し（破片と光の粒） | バニラの粒・二重の粒の層 |
| 残り | mod の煙の粒を一種類だけ | 泡・灰・火花を重ねること |

- 一つの段に、ほかの係のものを足さない。足りないときは係そのものを強くする（模型を大きく、光を明るく）。
- 画面の揺れと閃光は重い一撃（主の大技・倒れる）だけ。

## 2. 粒

- 攻撃と技にはバニラの粒を使わない。mod の粒（`skyabyss:fx_<属性>_<種類>`）だけを使う。
- 属性は 7 つ: 石（岩鯨）・水（潮殻）・雷（雷翼）・熾（余燼）・深淵・月・紙（心臓のあとの主）。
- 種類は 3 つ: 破片（重さで落ちて転がる）・光の粒（浮いて薄れる）・煙（ふくらんでゆっくり昇る）。
- 絵はドット 8x8、2 色（地色と光の色）。一種につき 4 枚の変わり絵。
- 数の上限: 一つの攻撃で一度に 24 まで。一画面で 300 まで（超えたら作らない）。

## 3. 色

- 持ち主ごとに 2 色だけ（地色と光の色）。巨神は巨神の色、主は主の色。
- 危ない所を示す赤は床の印だけ。粒・模型・光に赤を足さない（熾の橙はそのまま）。

## 4. 今の状態

- 粒の絵は案 A（欠けた石の素朴なドット）。`tools/gen/ui/gen_fx_particles.py`（手で描いた形）が書く。
- 攻撃・技・景色・仕掛けの粒は、すべて mod の粒に置き換えた（`tools/once/convert_attack_particles.py`・`convert_ambient_particles.py`）。
  - 属性は場所で決める: 巨神の背・その章 = その巨神、五章・深淵 = 深淵、六章・月・塔 = 月、終章 = 紙。プレイヤーの技と、どこにも当たらないものは、元の粒が表していたものから（炎 = 熾、雷・紫 = 雷、白い光 = 月、水・凍て = 水、打撃 = 石、魂・墨 = 深淵）。
  - 当たりの粒をクライアント（AttackFx・ImpactFx・BossImpactFx）が出す技は、サーバーの当たりの粒を消した。
- 残すバニラの粒: ダンジョンの主の息の技の目印（`spray(..., ParticleTypes.X)`。技の形を選ぶために比べる。描く粒は mod の粒）。
