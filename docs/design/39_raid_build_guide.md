# 天と淵のあいだ 巨神の試練の建て方（レイドの部屋の建築の手引き）

巨神のレイドの部屋（`trial/raid/*`、`RaidKit.buildCell` で建つ閉じた一室）を、ただの箱から「その巨神の体の中・背の上にいる」と感じる場所にするための手引き。Wynncraft のレイドほかの大きな RPG サーバー・冒険マップの建築を調べ、手法を Java で建てる部屋に落とした。ブロックの id はすべて Minecraft Java 1.21.1 にあるもの（1.21.4 の淡い樫・樹脂などは使えない）。

関連: [32 巨神の順路](32_titan_raid_route.md)（部屋の流れ・区画・負荷）、[02 岩鯨](02_stone_whale.md)・[08 潮殻](08_tide_shell.md)・[12 雷翼](12_thunder_wing.md)・[13 余燼](13_ember.md)（部屋の中身）、[15 モデルのハイポリ化](15_high_poly.md)（描画の予算）。

---

## 0. 要約

- **部屋の役は一つの目印（ランドマーク）で言い切る**。入口の戸から見て、正面（北）の軸の上に、その部屋の目的の物を一番明るく・一番大きく置く。Wynncraft の部屋は「塔を守る」「台を守る」など目的が一つで、その物が部屋の真ん中で目立つ。
- **壁は背景の絵**。平らな一枚の壁をやめ、ノイズで 0〜3 ブロック凹凸をつけた「有機の壁」に、巨神ごとの濃淡（グラデーション）を高さで重ねる。
- **色の言葉を全巨神で統一する**。赤 = 危ない、金（黄）= 届け先・運ぶ物、青白 = 叩く・押す仕掛け、巨神の差し色 = 目印。Wynncraft も赤い印 = 攻撃の落ちる所、緑の床 = スイッチ、色の絨毯 = 道の区別、を一貫させている。
- **外は見せないが、奥行きは見せる**。壁の窪みに縮尺を落とした「遠景の箱庭」、銅の格子の下の雲の層、天井の明かり窓など、閉じたまま遠さを感じさせる。
- **入口の間は低く、広間は高く**（圧縮と解放）。入口の間（高さ 4）から戸が開くと広間（8〜10）が見える。これを一番の見せ場にする。
- **負荷の上限**: 殻 1.5 万ブロック前後の部屋に、飾りは 8 千ブロックまで・光る塊（明るさ 12 以上）は 40 個まで・ブロックエンティティ 24 個まで・飾りのエンティティ 16 体まで（6 章）。

## 1. 調べたもの（何を見て、何を盗むか）

### 1.1 Wynncraft のレイド（四つ）

どのレイドも「挑戦の部屋 3 → 強化の部屋（三つから一つ選ぶ）→ ボス」の形で、この mod の順路（歩・智・闘 → 中ボス → 心臓）と同じ骨組み。部屋の作りから読み取れることを並べる。

| レイド | 部屋の例（wiki の記述） | 建築で盗むところ |
| --- | --- | --- |
| 擬蛇の巣（Nest of the Grootslangs） | 粘液の台を 60 秒守る／地面の五つの色の羊毛の区画から塔がせり上がる（白い粒の輪が次の塔の予告）／色を見て天井の的を撃つ／巨蛇が掘った横長のトンネル（ボス前の間）／円い闘技場の縁が穴 | **色の羊毛 = 場所の名前**。輪の粒で「次はここ」。ボス前に「巨体が通った跡」の通路を歩かせ、ボスの大きさを先に体で知らせる |
| 峡谷の巨像（The Canyon Colossus） | 五本の溶岩の流れを水で冷やす／上下二段の台を同時に守る／迷路の四つの道を青・黄・赤・緑の絨毯で分け、中央の翼で上から見渡せる／石の巨人を護衛（青い戸 = レバー、緑の戸 = 巨人が緑の板を踏む）／巨像の手を登る／ボスは浮いた破片の上、薙ぎ払いの来る破片が赤く、安全な破片だけ青 | **戸の色 = 開け方**。**見渡し台**（迷路を上から）。**巨体そのものを足場・壁にする**（手を登る、体の前で儀式）。床の色が一瞬で危険を告げる |
| 光の結節（Orphion's Nexus of Light） | 中央の広間に三つの戸と点滅する題字／中央の塔の周りに光の結晶が六つ（寄生されると朽ちる）／金の跳ね板で塔の上へ／見えない足場の位置を上から垂れる金のブロックで教える／動く「浄めの光」の柱 | **中央の塔と周りの結晶の輪**は「守る物」の基本形。**金 = 使える足場**。目に見えない物を別の物で示す（垂れる金・粒の跡） |
| 名なき異変（The Nameless Anomaly） | 宙に浮く虚空の裂け目の真下の床に紫の点／切り株の上の紫の板に立つと時計が動く／暗い洞窟で光を持つ人の近くだけ安全／巨木の下の祭壇と四つの株、迷路の入口は白・橙・黒・青・灰の五色の洞／ボスは巨大な石板の上、周りは逆さの景色の虚空、石に古代文字で「出して」 | **床の印で宙の物を示す**。**光を持つ人 = 安全**（暗さそのものを仕掛けに）。**刻んだ文字で世界観を一言**（碑と同じ考え）。闘技場の外を「逆さの景色」にして、外が見えても虚空に見せない |

共通して分かること。

1. 部屋の目的の物（塔・台・祭壇・核）は**中央か正面の軸**にあり、色か光で一つだけ目立つ。
2. **色は役割の名札**で、飾りの色とぶつけない（羊毛・絨毯・戸の色）。
3. 巨体（巨像・巨蛇・巨木）は**部屋の壁・床・足場そのもの**になっている。背景に置くだけでなく、体の上を歩かせる。
4. ボスの前に「通り道」（巣のトンネル、結節の階段）を挟み、気持ちを切り替える。

### 1.2 ほかの例

- **Hypixel SkyBlock の地下墓地**: 小さく閉じた部屋がたくさん、凝った建築に危険と隠し物。部屋はブロックの並びで見分けられるほど一つずつ形が違う。→ 部屋ごとに一目で分かる「顔」を一つ持たせる。
- **バニラの試練の間（Trial Chambers）**: 凝灰岩の煉瓦が主材、蝋引きの銅（戸・格子・電球）が差し色、中央の大広間に大階段と噴水と壁画、三層の廊下を梯子でつなぐ。→ 主材一つ＋金属の差し色一つ、という絞り方の手本。雷翼の銅の使い方の基準にする。
- **ワンダと巨像（上田文人）**: 規模を主役にし、必要なものだけ残す引き算の世界。巨像は建築のように作られ、何もない周りとの対比で大きく見える。→ 飾りを詰めすぎない。目印の周りは空ける。
- **ランドマークの理論**: ディズニーの「ウィニー」（遠くに見えて人を引き寄せる城）、Metro Exodus の「どこからでも目印が一つは見える」、Journey の「一度隠して、近くでもう一度見せる」（Denial and Reward）、Kevin Lynch の目印による道の覚え方。→ 入口の戸を開けた瞬間に目印が見え、部屋の途中で一度隠れ、ゴールで間近に見える配置にする。
- **石の色の並べ方**: 石は明るい順に閃緑岩・石・安山岩…深層岩・玄武岩・黒石。**明るさで選び、模様の違う物を一つだけ足す**。玄武岩の六角の模様はほかにないので差し色に少しだけ。グラデーションは乱雑に混ぜず、低い所から高い所へ順に変える。

## 2. いまの部屋（RaidKit）の作りと限り

- `buildCell` は部屋全体（広間＋南の入口の間＋北の出口の間）を壁で満たし、広間をくり抜く。床の縁と十字に `trim`、天井に 8 ブロックおきに `light`。戸は鉄格子。
- 部屋の広さは `hx`・`hz` 9〜16、高さ 8〜10。14×14×9 の部屋で殻は約 31×41×12 ≒ **1.5 万ブロック**（壁で満たしてから約 7.5 千を空気でくり抜くので、書き込みは約 2.3 万回）。
- 飾りは広間の中にしか足せない（外を壊さない）。区画へはブロックごと写される（32 の 5 章。1 tick に 6 ms ずつ）。
- いまの見え方の弱さ: 壁が一種類で平ら・天井の灯りが格子状で均一・どの部屋も同じ十字の床・目的の物が部屋の色に埋もれる。

この手引きの提案（7 章）は `RaidKit` に道具を足す形で、部屋のクラスは `build` の中でそれを呼ぶだけにする。

## 3. 共通の技法

### 3.1 三つの層で奥行きを作る

閉じた部屋でも、見る距離を三つに分けると広く見える。

| 層 | 場所 | 作り | 例 |
| --- | --- | --- | --- |
| 近景 | 床・腰の高さ（y+1〜+2） | 小道具・段差・床の模様。触れる・遮る | 骨の欠片の山、鎖の杭、銅の配線 |
| 中景 | 部屋の芯（目的の物） | 一番明るい・一番大きい・差し色 | 核、台座、塔、炉 |
| 遠景 | 壁と天井 | 有機の壁、遠景の箱庭、天井の構造 | 肋骨のアーチ、雲の層、柱の列 |

- 中景の周りは半径 3 ブロック以上なにも置かない（戦う場所でもある。ワンダと巨像の「周りを空ける」）。
- 近景の小道具は壁際と隅に寄せる（戦いの導線を塞がない）。床の真ん中は模様だけ。

### 3.2 ノイズの有機の壁（作り方）

殻（`buildCell` の壁）は触らず、その**内側に 0〜3 ブロックの「肉付け」**を足す。そのため部屋は遊ぶ広さより `hx`・`hz` を 2 大きく取る。

```java
// 壁の肉付け (案: RaidKit.organicWall)。seed は部屋の id から作り、挑戦ごとに変えない
ImprovedNoise n = new ImprovedNoise(RandomSource.create(seed));
for (各壁の列 (u = 壁に沿う座標, y = 高さ)) {
    double v = n.noise(u * 0.18, y * 0.25, 0) + 0.5 * n.noise(u * 0.5, y * 0.6, 7); // 大きな波 + 細かい波
    int depth = clamp((int) Math.round(1.2 + v * 1.6), 0, maxDepth);              // 0〜3
    if (y <= 1) depth = Math.max(depth, 1);                                         // 足元は必ず一段出して床と壁の角を消す
    for (int d = 0; d < depth; d++) set(壁から内へ d, gradient.pick(y, v));
}
```

- 縦の周期を横より長く（`y * 0.25`）すると地層・筋肉の向きに見える。横を長くすると流れ（潮・風）に見える。巨神ごとに変える（4 章）。
- 天井の際（上 2 段）は深く（+1）して、天井と壁の角を丸める。角が直角のままだと箱に見える。
- 戸のまわり（幅 5・高さ 5）と碑の前は深さ 0（戸と碑を枠で囲む方は 3.5 節）。
- **乱数の種は部屋で固定**。形を覚えられることは遊びの助けで、挑戦ごとの違いは仕掛けの側（`ctx.rng()`）に任せる。`reset` で建て直しても同じ形になる。
- 費用: 周長 × 高さ × 平均の深さ。14×14 の部屋（周長約 120、高さ 9、平均 1.5）で **約 1.6 千ブロック**。

### 3.3 グラデーション（濃淡の帯）

- 高さで 4〜5 段に分け、境目はノイズでぼかす（`y + v * 1.5` で段を引く）。帯の境が一直線だと縞模様に見える。
- 一段の中で 2 種を 7:3 で混ぜる（模様違い）。3 種以上は混ぜない。
- 下が重く暗い、上が軽く明るい、が基本（余燼だけ逆。下が熱く明るい）。
- 床は壁の一番下の段と同じ系統で、少し明るくする（床と壁の角を消す）。

### 3.4 遠景の窓（外を見せずに遠さを見せる）

部屋は水密で外は空・虚空なので、本当の窓は開けない。代わりに次の四つ。

1. **箱庭の窪み**: 壁に幅 5・高さ 4・奥行き 4 の窪みを掘り、奥に縮尺を落とした景色（遠くの肋骨、遠くの炉）を置く。手前に鉄格子・鎖・色ガラスの板を一枚かけ、奥を手前より暗くする（明るさ 4〜7）。奥に行くほど小さく（3 → 2 → 1 ブロック幅）すると遠近が強まる（ディズニーの遠近を詰める手法）。費用 約 80 ブロック。
2. **床の下の層**: 床の一部を格子（銅の格子・鉄格子・足場）にして、その下 2〜4 段に雲・溶岩の色・骨の山を置き、下から照らす。「下にまだ空間がある」と感じる。費用 約 150 ブロック（5×5×4）。
3. **天井の明かり窓**: 天井に 3×3 の穴を 2〜3 段の深さで掘り、奥に明るい塊（真珠のカエルの光など）と色ガラス。空が見えるような光だけ落ちる。
4. **逆さの景色**（名なき異変の手）: 天井に床と同じ物（柱・骨）を逆さに吊る。上下が分からない不安で「体の中」を出す。余燼・岩鯨の深い部屋向け。

いずれも**本当の外へは穴を開けない**（殻の壁 1 枚は必ず残す）。

### 3.5 目的の物を枠で囲む（視線の通し方）

- **軸**: 入口の戸（南）と出口の戸（北）は x = 0 の軸の上にある。目的の物はこの軸の上か、軸から見て左右対称の位置に。入口の休み場から戸ごしに見えるようにする。
- **枠**: 目的の物の後ろの壁に、巨神の差し色で門型（アーチ・肋骨・柱二本）を立てて、正面から見ると額に入って見えるようにする。
- **明るさの序列**: 目的の物 = 明るさ 15・周りの床 10〜12・壁 6〜8・隅 3〜5。全部を 15 にしない（いまの天井の格子の灯りは部屋を平らにする）。
- **導線**: 床の模様（いまの十字の筋）を、入口から目的の物へ向かう一本の筋にする。分岐する部屋は筋の色を道ごとに変える（峡谷の巨像の絨毯）。
- **出口の戸**: 閉じている間は暗い枠、開いたら枠の灯りが点く（銅の電球・燭台を灯す）。「次はここ」を光で言う。
- **見渡し台**: 解く部屋（智）は入口の上か南の隅に 2〜3 段の台を作り、仕掛けの全体を上から見せる（WR5 の見張り台、峡谷の巨像の迷路の翼）。

### 3.6 色の言葉（全巨神で共通）

| 色 | 意味 | 使う物（例） | 飾りに使わない |
| --- | --- | --- | --- |
| 赤 | 危ない・ここに落ちる | `red_concrete`・`red_terracotta`・赤い粒 | 赤い飾りは禁止（余燼の溶岩色は橙で） |
| 金・黄 | 届け先・運ぶ物・使える足場 | `gold_block`・`yellow_glazed_terracotta`・`ochre_froglight` | 金は目的の場所だけ |
| 青白 | 叩く・押す・回す仕掛け | `light_blue_glazed_terracotta`・`soul_lantern`・`pearlescent_froglight` の縁 | 仕掛けでない物を青白く光らせない |
| 巨神の差し色 | 目印・物語 | 4 章の各表 | — |

- 色は**床か台座の縁 1 列**で示す（大きく塗らない）。
- 一つの部屋で意味の色は 2 つまで。

### 3.7 灯りの決まり

- **見える灯り**: 部屋の顔になる物だけ（燭台・ランタン・炉・電球）。
- **見えない灯り**: `minecraft:light`（明るさ 0〜15 を状態で選べる見えないブロック）で壁際・天井の陰を補う。モデルを描かないので描画が軽い。いまの天井の格子の灯りはこれに置き換えて、見える灯りは目的の物と戸に集める。
- 明るさの目安（バニラ）: 海のランタン・グロウストーン・シュルームライト・カエルの光・ランタン・エンドロッド・点いた銅の電球 15（風化で 12・8・4）、泣く黒曜石と魂のランタン 10、光る苔 7、アメジストの塊 5、マグマ 3、ろうそく 1 本 3〜4 本 12。
- 部屋の床は明るさ 1 以上に保つ（暗い床は敵が湧く）。暗さを遊びにする部屋（名なき異変の洞窟のような）だけ例外で、湧きを部屋の側で止める。

### 3.8 小道具と物語

- 部屋に一つ、**「ここで何があったか」の場面**を置く（入口の碑の近く。碑の一言と同じ話）。例: 倒れた番人の槍と兜（骨のブロック＋鉄格子＋頭）、食べかけの供え物、途中で止まった仕事。
- 小道具は 3 種類で組む（大・中・小）。大 = 1 つ（目を止める）、中 = 3〜5（場所を作る）、小 = たくさん（散らす。床の 5% まで）。
- 同じ小道具を等間隔に並べない（ノイズか乱数でずらし、向きも変える）。

## 4. 巨神ごとの手引き

各巨神で、部屋の型を四つに分ける: **運ぶ**（歩の多く）・**解く**（智）・**守る**（闘の核守り）・**闘技場**（闘の波・輪）。

### 4.1 岩鯨（石・骨・歌）

石の海を泳ぐ鯨の体の中。骨は白く、肉は石の層、歌は紫の結晶に宿る。

**色（下 → 上）**

| 段 | 主（7） | 混ぜ（3） |
| --- | --- | --- |
| 床 | `polished_tuff` | `tuff` |
| 壁 1（足元） | `cobbled_deepslate` | `deepslate` |
| 壁 2 | `tuff` | `deepslate_tiles` |
| 壁 3 | `andesite` | `stone` |
| 壁 4（天井際） | `calcite` | `diorite` |
| 天井 | `smooth_stone` | `calcite` |
| 骨（構造） | `bone_block`（軸を向ける） | `calcite`・`polished_diorite_stairs` |
| 差し色（歌） | `amethyst_block` | `amethyst_cluster`・`large_amethyst_bud` |
| 灯り | 点いた `candle`（白）、`sea_lantern` は目的の物だけ | `light` |

**形の決まり（五つ）**

1. **肋骨のアーチ**: 部屋を横切る骨のアーチを 5〜6 ブロックおき。`bone_block`（axis=x で横、axis=y で立ち上がり）、肩は `polished_diorite_stairs` で丸める。床から天井まで、北へ向かって少しずつ低くなると「奥へ狭まる喉」になる。1 本 約 40 ブロック。
2. **背骨の棟**: 天井の中央を南北に走る背骨。3 ブロックおきに椎骨（`bone_block` の十字）。
3. **石の地層の壁**: 縦の周期を長くしたノイズ（3.2 節）で、横向きの層。足元が深層岩、上が方解石。
4. **歌の脈**: 壁の中を斜めに走るアメジストの筋（1 列。15 ブロックに 1 本）。目的の物の近くで太くなる。
5. **鯨ひげの簾**: 出口の戸の上から垂れる `chain` と `bone_block` の簾。戸が開くと簾の前の燭台が灯る。

**部屋の型ごとの目印**

| 型 | 部屋 | 目印 |
| --- | --- | --- |
| 運ぶ | WR1 骨玉運び | 台座を「耳の骨の椀」に。方解石の椀（直径 5）の縁にアメジストの塊、届けた骨玉ごとに椀の縁の燭台が一つ灯る |
| 運ぶ（上る） | WR4 胃の縦穴 | 縦穴の壁を肋骨の輪で 4 段に区切る（踊り場 = 輪）。頂に海のランタンの「喉の光」。胃液の層の色は赤（危ない）で統一 |
| 解く | WR2 共鳴の骨 | 四隅の骨をパイプオルガンの管に（`bone_block` の柱 3 本の束、高さを変える、上に `bell`）。鳴る管の根元のアメジストが光る |
| 解く | WR5 床合わせ | 北の壁の見本を、壁に埋まった化石の鯨として浮き彫り（方解石の面に骨）。見張り台は肋骨の上に乗せる |
| 守る | WR3 鯨の核 | 核を肋骨の籠に入れた大きな晶洞（`amethyst_block` の殻の中に `budding_amethyst` 風の光）。籠の柱 6 本、核の上だけ天井を 2 段掘り上げる |
| 闘技場 | WR6 縮む輪 | 輪の縁に立つ椎骨の環（12 本）。輪が縮むと外の椎骨から燭台が消える |

**灯り**: 冷たい白（ろうそく・海のランタン）と紫（アメジスト）の二色。全体は暗め（6〜8）、骨が浮いて見えるよう骨の根元に見えない灯り。

**小道具**: 骨の欠片の山（`bone_block` 1 + `polished_diorite_slab`）、化石の床（`bone_block` を床に埋める）、歌い手の座（`note_block` と方解石の段）、古い祈りのろうそく、石化した小魚（`skeleton_skull` を壁に）。

**する / しない**

- する: 骨は必ず軸を合わせて置く（向きのばらばらな骨のブロックは石に見える）。骨は白、まわりは灰で、骨だけ明るく。
- する: 北へ行くほど狭く低く（喉の奥へ）。
- しない: 石の煉瓦を主材にしない（人が作った城に見える。いまの `BONE` の床・壁）。煉瓦は「背中の民が後から足した物」（碑の台・祭壇）にだけ。
- しない: アメジストを床一面に敷かない（歌は脈で、量は少なく）。

### 4.2 潮殻（珊瑚・貝殻・真珠。水の仕掛けはなし）

潮の引いたあとの殻の中。いまは乾いていて、壁の高い所の潮の線だけが「ここは海だった」と言う。

**色（下 → 上）**

| 段 | 主（7） | 混ぜ（3） |
| --- | --- | --- |
| 床 | `smooth_sandstone` | `sandstone`（模様違いに `cut_sandstone`） |
| 壁 1（足元。深い海） | `dark_prismarine` | `prismarine` |
| 壁 2 | `prismarine` | `prismarine_bricks` |
| 壁 3（潮の線の帯） | `light_blue_terracotta` | `cyan_terracotta` |
| 壁 4（真珠層） | `calcite` | `white_terracotta`・`pink_terracotta` |
| 天井 | `smooth_quartz` | `calcite` |
| 珊瑚（差し色） | `pink_terracotta`・`magenta_terracotta`・`orange_terracotta` | `purpur_block`（真珠の紫の照り） |
| 灯り | `pearlescent_froglight`（目的の物） | `sea_pickle`（1〜4 で明るさを変える）・`light` |

**珊瑚のブロックは使わない**: 生きた珊瑚のブロックは水に触れていないと少し経って死んだ珊瑚に変わる（部屋の見た目が試遊ごとに変わり、写しとも食い違う）。珊瑚の色はテラコッタで出す。死んだ珊瑚のブロック（`dead_brain_coral_block` など灰色）は「干上がった礁」として足元にだけ使ってよい。

**形の決まり（五つ）**

1. **螺旋の殻**: 部屋の一角（目的の物の後ろ）に巻貝の断面。中心から外へ、段を一つずつ上げながら弧を描く壁（`calcite` と `pink_terracotta` を交互の帯）。
2. **扇の畝**: 壁を帆立貝の殻のように放射状の畝に。ノイズの代わりに `sin(角度 × 9)` で深さ 0〜2 を作る（横の周期が短い）。
3. **真珠の座**: 開いた二枚貝（上下の殻を `smooth_quartz` の階段で弧に）の中に真珠（`pearlescent_froglight` の 3×3×3 の角を落とした球）。
4. **珊瑚の枝**: 壁と天井から伸びるテラコッタの枝（先は `end_rod` かフェンス）。枝は斜めに 1 ブロックずつずらして伸ばす。
5. **潮の線**: 壁の高さ 5 前後を一周する水色の帯（3.3 節の壁 3）。帯の上下で色を変え、帯の高さに小さな貝の殻（`turtle_egg`・`nautilus_shell` の入った額）を並べる。

**部屋の型ごとの目印**

部屋は m1-sky-pass の `TidePearlRoom`・`TideShellRoom`・`TideSaplingRoom` と、wip/raid2-tide の二案め（`TideCoralRoadRoom`・`TideLightRoom`・`TideMoonRoom`・`TideBroodRoom`）。

| 型 | 部屋 | 目印 |
| --- | --- | --- |
| 運ぶ | 真珠（Pearl） | 届け先を真珠の座に。届けた真珠の数だけ二枚貝が開く（上の殻を一段ずつ上げる） |
| 運ぶ | 珊瑚の道（CoralRoad） | 伸びる道の先に珊瑚の門（枝が絡んだアーチ）。道は珊瑚色、行き止まりは灰の死んだ珊瑚 |
| 解く | 月・潮見の暦（Moon） | 天井の明かり窓（3.4 節）に月の円盤（`smooth_quartz` と `white_concrete`）。月の六つの顔を壁の殻の窪みに並べ、いまの顔だけ真珠の光 |
| 解く | 光（Light） | 真珠層の壁の照り返し: 壁 4 の帯に `sea_pickle` を埋めて、光を貯めると帯が下から上へ灯っていく |
| 守る | 苗（Sapling）・群れ（Brood） | 守る物を螺旋の殻の中心に置く。殻の巻きが自然に敵の通り道を一本にする |
| 闘技場 | 殻（Shell） | 円い床を巻貝の断面の模様（渦の線）に。外周の珊瑚の枝が波ごとに一本ずつ灯る |

**灯り**: 下から上へ明るくなる（深い所が暗い青緑、上が真珠の白）。目的の物は桃色がかった白（`pearlescent_froglight`）。

**小道具**: 干上がった潮だまり（床の窪みに `dead_*_coral_fan` と `sea_pickle`）、殻の破片（`calcite` の階段の欠け）、真珠採りの籠（`barrel`・`scaffolding`）、古い網（`cobweb` を壁際に少しだけ）、潮の跡の筋（壁の帯）。

**する / しない**

- する: 曲線を多く（扇・螺旋・弧）。四つの巨神で一番直線が少ない部屋に。
- する: 色は淡く、彩度の高いテラコッタは珊瑚の枝の先だけ。
- しない: 水・海草・昆布を置かない（水の仕掛けはなく、昆布は水なしで消える）。
- しない: プリズマリンを全面に使わない（海底神殿に見える。いまの `TIDE`）。深い所の色に下げる。
- しない: 珊瑚色を赤に寄せない（赤は危険の色）。

### 4.3 雷翼（銅・雲・羽・雷）

雲の上を飛ぶ巨神の翼と背骨。羽は層、骨は銅、空は雲の床の下にある。

**色（下 → 上。銅は上へ行くほど空に晒されて錆びる）**

| 段 | 主（7） | 混ぜ（3） |
| --- | --- | --- |
| 床 | `waxed_cut_copper` | `waxed_copper_grate`（下の雲の層が見える所） |
| 壁 1（足元） | `waxed_copper_block` | `waxed_cut_copper` |
| 壁 2 | `waxed_exposed_cut_copper` | `waxed_exposed_copper` |
| 壁 3 | `waxed_weathered_cut_copper` | `waxed_weathered_copper` |
| 壁 4（天井際） | `waxed_oxidized_copper` | `waxed_oxidized_cut_copper` |
| 天井（雲） | `white_wool` | `white_concrete`・`snow_block` |
| 羽（構造） | `quartz_stairs`・`smooth_quartz_slab` | `white_concrete` |
| 差し色（雷） | `waxed_copper_bulb`（点灯）・`end_rod` | `lightning_rod`・`yellow_stained_glass` |
| 灯り | `waxed_copper_bulb`（錆びで明るさ 15・12・8・4 の段がつく） | `light` |

**必ず蝋引き（waxed_*）**: 蝋を引いていない銅は時間で錆びる。部屋の見た目が試遊ごとに変わり、写しとも食い違う。

**形の決まり（五つ）**

1. **羽の段**: 壁を羽の重なりに。白い階段と半ブロックを 1 段ずつずらして重ね（瓦のように）、下の段ほど長く。横の周期の長いノイズ（風の向き）で羽の長さを揺らす。
2. **銅の背骨と配線**: 床に部屋の仕掛けをつなぐ配線（`waxed_cut_copper` の筋。錆びた床に新しい銅の線が光って見える）。電気が通った線だけ電球が灯る。
3. **避雷の尖塔**: 目的の物の上に `lightning_rod` を頂いた尖塔（`waxed_copper_block` の柱）。部屋で一番高い物。
4. **雲の床の下**: 床の一部を `waxed_copper_grate` にし、下 3 段に白い羊毛の塊（雲）を置いて下から見えない灯り。高い所にいる感じを閉じたまま出す（3.4 節の 2）。
5. **稲妻の割れ目**: 天井（雲）にジグザグの溝を掘り、`end_rod` と `yellow_stained_glass` を埋める。雷の落ちる場所の予告は床の赤（3.6 節）で、天井の割れ目は飾りだけ。

**部屋の型ごとの目印**

| 型 | 部屋 | 目印 |
| --- | --- | --- |
| 運ぶ | SR1 空洞の骨（羽運び） | 届け先は翼の付け根の「羽の座」。白い羽の扇（半円、半径 4）の要に金の縁。届けた羽の数だけ扇の骨が一本ずつ銅から白に変わる |
| 解く | SR2 柱（回路） | 回路の板を床に描き、つながった線の電球が順に灯る。見渡し台から配線の全体が見える |
| 守る／闘技場 | SR3 嵐の衣（帯電の鎖） | 中央の避雷の尖塔が守る物。尖塔の周りに雲の床の円（格子）、外周に羽の壁 |

**灯り**: 冷たい白（雲）が全体、黄緑の銅の電球が点。雷の直前は電球を消して部屋を一瞬暗くする（光で予告。音と合わせる）。

**小道具**: 抜けた羽（白い旗・`white_carpet` を少し）、配線の巻き（`chain` と銅）、雷に焼かれた銅（`waxed_oxidized_copper` に黒い `coal_block` の点）、風見（`lightning_rod` の横向き）、空を渡る民の凧（`white_banner`）。

**する / しない**

- する: 錆びの段は高さに合わせる（下が新しく上が古い）。差し色の新しい銅は「人が足した・電気が通った」意味だけに。
- する: 天井を一番明るく（雲）。四つの巨神で一番明るい部屋。
- しない: 銅の電球を動く仕掛け（レッドストーンでの点け消し）にしない。点け消しは `RaidKit.set` で状態を書く。
- しない: 粉雪（`powder_snow`）を雲に使わない（沈んで凍える）。
- しない: 銅のブロックだけで全部を作らない（試練の間に見える）。白い羽と雲を 4 割入れる。

### 4.4 余燼（玄武岩・炉・熾）

眠る火の巨神の体の中の鍛冶場。下が熱く明るく、上は灰と煤で暗い。四つの巨神で灯りの向きが逆。

**色（下 → 上）**

| 段 | 主（7） | 混ぜ（3） |
| --- | --- | --- |
| 床 | `polished_blackstone` | `polished_basalt`（軸 y の六角の目） |
| 壁 1（足元。熱い） | `blackstone` | `gilded_blackstone`（金の筋。少し） |
| 壁 2 | `basalt`（軸 y） | `polished_basalt` |
| 壁 3 | `smooth_basalt` | `polished_blackstone_bricks`・`cracked_polished_blackstone_bricks` |
| 壁 4（天井際。灰） | `tuff` | `polished_tuff`・`andesite` |
| 天井 | `deepslate_tiles` | `cracked_deepslate_tiles`（煤けた天井） |
| 鍛冶（構造） | `iron_block`・`anvil`・`chain`・`iron_bars` | `heavy_core`（重い台の芯） |
| 差し色（熾） | `magma_block`（明るさ 3、踏むと傷 = 危険の床にだけ） | `shroomlight`・`ochre_froglight` |
| 灯り | 溶岩の入った `cauldron`（明るさ 15、流れない）・点いた `blast_furnace` | `light`・`campfire`（壁の高い所だけ。踏めない場所） |

**溶岩を置かない**: 流れる・燃え移る・写しが乱れる。溶岩の色は溶岩の大釜・マグマ・シュルームライトで出す。

**形の決まり（五つ）**

1. **玄武岩の柱の列**: 壁を高さの違う玄武岩の柱（軸 y）の並びに。柱の高さはノイズで、頭は `polished_basalt` で平らに。六角の目が見える柱の上面を見せるため、柱の頭は人の目より低い所にもつくる。
2. **流れの溝**: 床の縁に幅 1 の溝（深さ 1）。溝の底に溶岩の大釜・シュルームライトを並べ、上に `iron_bars` か `polished_blackstone_slab` の格子。床の灯りが溝から上がる（下から照らす）。
3. **吊り鎖と鉤**: 天井から長さの違う鎖（`chain` 3〜7 段）、先に `lantern` か `anvil`。天井の暗さを鎖の縦線で埋める。
4. **炉の口**: 目的の物の後ろの壁に、大きな炉の口（幅 5 のアーチ、奥に溶岩の大釜の列と `blast_furnace`）。部屋で一番明るい所。
5. **冷えた血の筋**: 壁を斜めに走る `crying_obsidian` と `obsidian` の筋（巨神の血が冷えた跡）。泣く黒曜石の紫は物語の色として少しだけ。

**部屋の型ごとの目印**

| 型 | 部屋 | 目印 |
| --- | --- | --- |
| 運ぶ | ER1 冷えた血（運び）・ER4 鎖の道 | 届け先は鋳型（床に掘った鍵の形の溝）。届けると溝の底が一段ずつ灯る。鎖の道は橋の両側の吊り鎖が後ろから一本ずつ落ちる |
| 解く | ER2 割った鍵・ER5 圧合わせ（七つの炉） | 七つの炉の口を半円に並べ、合った炉の口だけ大釜が溶岩で満ちる。見渡し台は鞴の上 |
| 守る | ER3 眠る巨神（炉の守り） | 中央の大きな炉（金床と重い台の芯の祭壇）。炉の上の天井を掘り上げ、煙突に鎖 |
| 闘技場 | ER6 弟子の間 | 金床の環（8 つ）。弟子が倒れるたび一つの金床の上の灯りが消える |

**灯り**: 床と溝から上へ（橙）。天井は暗い（3〜5）。目的の物は黄（`ochre_froglight`）、危険は赤い床、ほかの熾は橙で、赤と黄の間を使い分ける。

**小道具**: 打ちかけの刃（`iron_bars` と `anvil` の上の頭）、鋳型の山（`polished_blackstone_slab`）、煤けた樽（`barrel`）、冷えた溶けた金（`gilded_blackstone` と `raw_gold_block`）、鞴（`brown_wool` と `spruce_trapdoor`）、弟子の槌の掛け台（`chain` と `stone_button`）。

**する / しない**

- する: 下から照らす。天井を暗くして、部屋を実際より高く見せる。
- する: 黒の中で金の筋（金めっきの黒石）を目的の物へ向かう線に使う。
- しない: 黒石だけで壁を作らない（黒の一色はつぶれて形が消える。いまの `EMBER`）。玄武岩の縦の目と灰の上段で明るさの差をつける。
- しない: マグマを人の歩く床に敷かない（傷 = 危険の色の約束が崩れる。危険の床にだけ）。
- しない: キャンプファイアを手の届く所に置かない（踏むと燃える）。

## 6. 負荷と費用

### 6.1 ブロックの数の目安（14×14×9 の部屋）

| もの | ブロック数 |
| --- | --- |
| 殻（いま。満たす + くり抜く） | 書き込み 約 2.3 万（残るのは 約 1.5 万） |
| 有機の壁（深さ平均 1.5） | 約 1.6 千 |
| 肋骨のアーチ・羽の段など構造（5 本） | 約 200〜400 |
| 遠景の窓（箱庭 2 + 床の下 1） | 約 300 |
| 目印（核・炉・尖塔など） | 約 150〜400 |
| 小道具 | 約 200 |
| **飾りの合計の上限** | **8 千**（殻の約半分） |

- 殻を「満たしてからくり抜く」のをやめ、厚さ 2 の殻だけを書くようにすると、書き込みは約 1.2 万に減る（7 章の提案）。区画への写しと片付け（32 の 5 章）も軽くなる。
- 書き込みは `UPDATE_CLIENTS` だけ（隣の更新なし）なので、砂・砂利・コンクリートの粉など**落ちるブロックは置いた瞬間は落ちないが、隣の更新で落ちる**。使わない。

### 6.2 光と描画

- 明るさ 12 以上の塊は 1 部屋 40 個まで。光の計算は灯りの数と広がりで重くなる。補いは `light` の低い値（6〜10）で。
- ブロックエンティティ（樽・宝箱・飾り壺・旗・頭・看板・碑。金床と鎖は違う）は 24 個まで。旗と頭はとくに描画が重い。
- 飾りのエンティティ（額縁・防具立て・表示のエンティティ）は 16 体まで。動く物は使わない。
- ガラス・葉・鉄格子など透ける物は、重なると描画が重い。遠景の窓の手前の一枚だけに。

### 6.3 変わってしまうブロック（使わない・使い方に気をつける）

| ブロック | 何が起きる | 代わり |
| --- | --- | --- |
| 生きた珊瑚（ブロック・扇） | 水がないと死んだ珊瑚になる | テラコッタ、死んだ珊瑚 |
| 蝋を引いていない銅 | 錆びが進む | `waxed_*` |
| 葉 | 木から離れると散る | `persistent=true` で置く |
| 溶岩・水 | 流れる・燃える | 溶岩の大釜、マグマ、シュルームライト |
| 砂・砂利・粉のコンクリート | 落ちる | 砂岩、凝灰岩、コンクリート |
| つた・光る苔（骨粉で） | 広がる | 少しなら可。広がらない向きに |
| キャンプファイア・マグマ | 踏むと傷 | 手の届かない所、危険の床だけ |

## 7. 道具の提案（RaidKit に足すもの。実装は別の作業）

**岩鯨の部屋（WR1〜WR6・中ボスの間 WRM）は実装済み**: `trial/raid/whale/WhaleDecor`（岩鯨だけの道具。`RaidKit` は変えない）。部屋の `build` の終わりに `WhaleDecor.wr1`〜`wr6`・`wrm` を呼ぶ。

- `Kit` が部屋ごとの道具: `keep`（仕掛け・道・予告の床・運ぶ道。決して書かない）、`reserve`（戦う床・眺め。肉付けと小道具だけが避ける）、`put`（広間の空気にだけ置く）、`paint`（殻・床・天井のパレットのままのブロックを、不透明な満ちたブロックに塗り替える。殻は一枚残る）
- 道具: `organicWall`（深さの上限は場所ごと）・`floor`（凝灰岩と背骨の筋）・`fossil`・`ceiling`（格子の灯りを見えない灯りに）・`lightGrid`・`ribArch`・`spine`・`frameArch`・`vein`・`niche`（遠景の窪み。殻が一枚なので肉付けの深さ 3 の中に作る）・`bonePile`・`prayer`・`singerSeat`・`wallSkull`・`exitFrame`（鯨ひげの簾と、越えると灯る燭台 `exitLamps`）・`antechambers`（前室の煉瓦と倒れた番人の場面、出口の間のアメジスト）
- 床の下の層・天井の明かり窓は、殻が一枚（部屋の箱の外へ書けない）なので使っていない。代わりに天井の真ん中を目的の物の灯り（海のランタンとアメジスト）に塗る
- 動く飾り: WR1 は届けた骨玉ごとに椀の縁の燭台が一つ灯る。どの部屋も越えると出口の燭台が灯り、やり直しで消える
- 確かめ: 自己テスト `raid decor whale`（飾りなしと飾りありを建て比べ、仕掛けのブロックが同じ・閉じている・費用の上限・床の明るさ）。見比べの絵は `tools/shots/raid_build_whale.txt`（`/skywhaleraid show <部屋>` で順路なしに建てる）→ `docs/review/raid_build_whale/`

- **`Palette` を広げる**: いまの六つ（床・帯・壁・天井・灯り・戸）に、`wallBands`（下から上への 4〜5 段、各段 主と混ぜ）・`accent`（差し色）・`objective`（目的の物の灯り）・`hidden`（見えない灯りの明るさ）を足す。4 章の表をそのまま入れる。
- **`organicWall(ctx, depthMax, uScale, yScale, seed)`**: 3.2 節。壁と天井の際の肉付け。戸と碑の前は避ける。
- **`gradient(pal, y, noise)`**: 3.3 節の段を引く。
- **`arch(ctx, z, 材, 肩の階段)`**: 部屋を横切るアーチ（肋骨・珊瑚の門・羽の骨・炉の口）。
- **`vistaNiche(ctx, 壁, 位置, 箱庭の種類)`**: 3.4 節の 1。
- **`underFloor(ctx, 箱, 格子, 中身, 灯り)`**: 3.4 節の 2。
- **`frame(ctx, 目的の位置)`**: 3.5 節。目的の物の後ろの枠と明るさの序列。
- **`buildCell` の殻**: 満たしてくり抜くのをやめて殻だけ書く。天井の格子の灯りは `light` に置き換え、見える灯りは部屋の側で置く。
- 部屋の見た目の確かめ: 入口の休み場から北を見た絵・見渡し台からの絵・暗い隅の絵の三枚を、部屋ごとに見比べの紙に出す（いまの見比べの紙の作り方と同じ）。

## 8. 部屋を作るときの確かめ

1. 入口の戸が開いた瞬間、目的の物が額の中に見えるか。
2. 部屋の中のどこに立っても、目印（目的の物か外周の環）が一つは見えるか。
3. 意味の色（赤・金・青白）が飾りに混ざっていないか。
4. 壁に平らな面が 5×5 より大きく残っていないか。
5. 床・壁・天井の明るさの序列（15 > 10〜12 > 6〜8 > 3〜5）になっているか。
6. 外（空・虚空）が一か所も見えないか。殻の壁 1 枚が残っているか。
7. 変わるブロック（6.3 節）を使っていないか。
8. 飾りが 8 千ブロック・灯り 40・ブロックエンティティ 24・エンティティ 16 の内か。
9. 戦う床の真ん中に引っかかる段差がないか。
10. 入口の間の碑と場面が同じ話をしているか。
