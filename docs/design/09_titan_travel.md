# 天と淵のあいだ 巨神での移動

- 文書番号: 09
- 範囲: 移動の道具と決まり。出会い、呼び笛・呼び貝・呼び羽・呼び鈴、巨神の碑、空の海図、行き先、コマンド。運ぶ乗り物（巨神の子）そのものは [28](28_titan_young_carriers.md)

## 1. 概要

巨神に会った人は、その巨神の笛（潮殻は呼び貝、雷翼は呼び羽、余燼は呼び鈴）を受け取る。笛を吹くと、巨神の「子」（歌のかけら）が足もとに現れ、パーティ全員（最大 6 人）を乗せて、行き先へ運ぶ。行き先は、会った巨神のいる場所、はじまりの地、自分や仲間が立てた巨神の碑。どこへ行けるかは子の得意（岩鯨は空、潮殻は海、雷翼は峰、余燼は地）で決まる（[28](28_titan_young_carriers.md) の 3.1）。

**成体の巨神は、笛では動かない**。巨神が動くのは自然の周期（出現・降下・夜の浮上）と最初の出会いの場面だけで、一つのパーティの用事で位置は変わらない。笛はあくまで子を呼ぶ道具で、巨神の背（ダンジョン）には入れない。背へは、運ばれた先の乗り込み口（岩鯨の鎖・潮殻の潮門・雷翼の昇り風・余燼の口）から入る。

背の中でその巨神の笛（旅嚢の短押し・輪）を使ったときだけは別で、子は呼ばず「地上へ下りる？」と聞く。5 秒以内にもう一度使うと地上へ降ろされる（`ReturnBeacons.whistleInBack`。心臓のあとの帰り道と同じ仕組み）。

- 行き先は「はじまりの地」（世界の初期スポーン）、自分が触れて覚えた「巨神の碑」、出会った巨神のいる場所。碑は人が作って拠点や村に立てる。
- 単なるテレポートに見せないため、乗る・運ばれる・降りるを本物の子の上で見せる。縮めるのは遠い旅（700 ブロック超）の途中だけで、そこは雲の帳に包む。
- 四体すべての巨神で同じ仕組み。移動に昼夜・潮・嵐の刻・天気の鍵はかけない（眠っている巨神と、まだ会っていない巨神だけ断る）。

## 4. 解放と道具

### 4.1 出会い（`TravelState.met`。プレイヤーごと、死んでも引き継ぐ）

- 乗れる姿で止まっている巨神（降りて鎖を垂らした岩鯨・休む潮殻・止まった雷翼・浮かんで眠る余燼）から 200 ブロック以内に行く、またはその巨神の背へ入る、で出会いになる。心臓を倒した人は自動で出会い済み（`unlocked`）。
- 出会いの時に、その巨神の笛が一度だけ渡る（旅嚢へ。入らなければ持ち物・足もと）。語りと使い方の一行が付く。古いワールドの人にも次のログインで渡る（2 秒ごとに確認）。コマンドで認めることもできる。
- なくしたら作業台で作り直せる（岩鯨: 骨＋岩鯨の心核＋岩鯨の鱗片を斜めに。心核は心臓の初回撃破で必ず落ちる。ほかの三体もその巨神の素材）。
- 笛は大事な品として守られる（地面で消えない・奈落から戻る・在りかを控える。11 の 4.1 節）。投げ捨てられない（人に渡すなら箱を通す）。
- クエストのフック: `Quests.signal(player, "titan_travel_<巨神>")`（認められたとき）、`"titan_voyage"`（降ろされるたび）。

### 4.2 笛

| 巨神 | 笛 | 吹くと現れる子 |
|---|---|---|
| 岩鯨 | 岩鯨の呼び笛（`stone_whale_call`。鯨の骨の角笛） | 岩鯨の仔 |
| 潮殻 | 潮殻の呼び貝（`tide_shell_call`） | 潮殻の稚貝 |
| 雷翼 | 雷翼の呼び羽（`thunder_wing_call`） | 雷翼の雛 |
| 余燼 | 余燼の呼び鈴（`ember_call`） | 余燼の仔 |

- 右クリックで吹く（旅嚢にあるときは Y の輪・短押し）。出会っていない人が吹くと「笛は鳴らない。〇〇はまだ、あなたを知らない」。
- 眠っている巨神（`TitanDormancy`）は応えない（目覚めの目安を添える）。
- 呼び方と乗り方は [28](28_titan_young_carriers.md) の 3 章。

### 4.3 巨神の碑（`skyabyss:titan_waymark`）

- 深層岩の台座に立つ石の札と、鯨骨の笠。札に伝承の書と同じ菱形の星と、その下に尾びれの碑文（青緑に光る。明るさ 6）。
- 作り方: 骨ブロック・岩鯨の鱗片・磨かれた深層岩を縦に並べて 2 つ。手で壊せる（共有の `mineable` タグに触れないため。未決）。
- 置いた人は自動で覚える。ほかの人も、触れる（右クリック）と覚える。だれの碑でも覚えられる。
- 名前: 金床で名付けた碑はその名、名のない碑は土地の名で「平原の碑」のように呼ぶ。
- 碑の上に空がないと覚えられない（「屋根の下の碑は、巨神から見えない」）。オーバーワールド以外では覚えられない。
- 一人 16 まで。海図の行の × で忘れられる。
- 壊すと、覚えていた人の海図に「碑は失われた（外した）」と灰色で出て、選べない。海図を送ったときに記録から外すので、枠はすぐ空く（`Voyages.pruneLost`）。選んだあとに壊されても、その場所へ降ろす。

## 5. 画面・音

- **空の海図**（`TravelChartScreen`）: 子に乗った持ち主が開く。左は自分を中心にした丸い海図（北が上、距離は対数で縮める）、右は行き先の一覧（名前・距離・方角・理由）。選べない行き先は灰色で、理由（眠っている・まだ姿を見せていない・この子には遠すぎる・広い海は渡れない・水の上は渡れない・近くに海がない）が付く。
- **音**: 笛の音（骨の笛・貝の音・羽の音・鈴の音）、子の現れる・溶ける音（親の歌の高い写し）、出発のうなり。
- **雲の帳**: 遠い旅の途中、画面を雲の白（潮殻は深い青）で覆い、霧を寄せる。1 秒で濃くなり 1 秒で晴れる。終わりの知らせが届かなくても 20 秒で晴れる。

---

## 6. 制限と安全

- オーバーワールドだけ。別の乗り物に乗っているとき、戦闘中、水の中（潮殻の稚貝以外）は呼べない（[28](28_titan_young_carriers.md) の 3.2）。
- 乗ったまま落ちて死なない（旅の間は落下が無効。降りる地面は安全な所を探す）。
- 旅のあと 5 秒は笛を吹けない。

## 7. マルチプレイ

[28](28_titan_young_carriers.md) の 4 章。子は個人のもの（持ち主のパーティだけが乗れる）、成体は動かない。碑は共有の目印で、各自の子が各自で向かう。

## 13. テスト用コマンドと自己テスト

### 13.1 コマンド（OP。`/skyabyss travel ...`）

| コマンド | 内容 |
|---|---|
| `unlock [人]` / `lock [人]` | 認めさせる・取り消す（心臓の撃破の記録があれば認められたまま） |
| `met [人]` | 全巨神に出会ったことにする |
| `young [巨神]` | 条件を見ずに自分の子を足もとへ出す |
| `go <x> <z>` | 乗っている子の行き先を、海図を使わずに座標で決める |
| `cooldown` | 自分の旅のあとの待ちを消す |
| `status` | 今の旅と自分の記録 |
| `end` | 今の旅を打ち切る（乗っている人は降ろす） |

### 13.2 自己テスト（`SKYABYSS_SELFTEST=1`）

`SELFTEST young PASSED` と `SELFTEST young rules PASSED`（`SKYABYSS_SELFTEST_ONLY=young`）。内容は [28](28_titan_young_carriers.md) の 7 章。碑の登録・保存・解放は `SELFTEST travel`（`guide/TravelSelfTest`）。
