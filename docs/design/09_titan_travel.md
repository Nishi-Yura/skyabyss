# 天と淵のあいだ 巨神での移動 実装仕様書

- 文書番号: 09
- 対象: 1章の報酬「巨神での移動」（01 の章構成）と、探索の「ファストトラベルは巨神に乗る形で実現する」。まず岩鯨で作り、後の巨神（潮殻・雷翼・余燼）にも使える共通の仕組みにした
- 状態: 実装済み（M3）。数値はコードの定数（`titan/travel/TravelRules.java`）に基づく
- 関連: 01（全体設計）、02（岩鯨と背中の試練。2.6 節に追記した）
- コード: `jp.revati.skyabyss.titan.travel`（新規）と、`titan/` の岩鯨・見守り・鎖・背中の行き来への小さな追加

## 1. 概要

岩鯨の心臓を倒した人は、岩鯨に認められ、「岩鯨の呼び笛」を受け取る。空の見える所で笛を吹くと、岩鯨が雲の向こうから泳いできて、頭の上の乗り場から鎖を垂らす。鎖を右クリックすると頭の座席へ引き上げられ、「空の海図」で行き先を選ぶ。岩鯨は身を起こして雲の上へ昇り、雲の海の上を泳ぎ、遠い旅では雲の海へ潜って（雲の帳）時間を縮め、行き先の上空へ降りて、鎖で一人ずつ地上へ降ろす。

行き先は「はじまりの地」（世界の初期スポーン）と、自分が触れて覚えた「巨神の碑」。碑はプレイヤーが作って拠点や村に立てる。

単なるテレポートに見せないため、乗る・昇る・泳ぐ・降りるをすべて本物の岩鯨の上で見せる。縮めるのは長い巡航の途中だけで、そこは雲の白に包まれる演出にする。

## 2. 方式の比較と決定

| 案 | 内容 | よい点 | 困る点 |
|---|---|---|---|
| A. 本当に長距離を飛ぶ | 乗せたままオーバーワールドを行き先まで飛ぶ | 景色が本物。テレポートがない | 3,000 ブロックで 2 分近くかかる。途中の未生成の地形を延々と生成させ、サーバーが重くなる（花火エリトラを数分続けるのと同じ） |
| B. 背中のディメンションで時間を過ごす | 背中（`titan_back`）へ乗せ、一定時間ののち行き先の上空へ降ろす | 負荷が最も小さい。今ある乗り込みをそのまま使える | 足もとに地上が見えず、ブレない軸 2（スケールと光）の「見下ろす景色」が出ない。背中の試練中の人と混ざる。待つだけで退屈 |
| **C. 混成（採用）** | オーバーワールドの岩鯨の頭に乗せて、本当に雲の上へ昇り、泳ぐ。遠い旅は 12〜21 秒泳いだあと「雲の帳」で行き先の手前 220 ブロックへ移し、そこから本当に降りていく | 景色は本物（足もとに地上と雲、眼下に岩鯨の体）。生成するのは出だしの数百ブロックと行き先の手前だけ。旅の長さは 1 分前後に収まる | 移す瞬間がある（雲の白で隠す）。巨神を外から操縦する仕組みが要る |

**決定: C。** 理由は 3 つ。

1. 「巨神に乗っている」実感は、乗り場から見下ろす地上と、自分の下で泳ぐ巨神の体から生まれる。B ではそれが出せない。
2. A は長い旅ほど待ち時間と生成の負荷が増える。C は長さが距離にほぼよらず（30〜70 秒）、負荷も上限がある。
3. 一体だけの決まり（WhaleKeeper）を守ったまま、同じ岩鯨が本当に行き先まで「移る」。旅のあと岩鯨は行き先で休み、その地の人が背中へ乗れる。

01/02 との食い違い: 01 の決定ログ「背中は専用ディメンション」は背中の島（試練）についての決定で、移動には使わない（上の理由 1）。鎖で乗る決まりは守った（鎖は頭から垂らす）。

## 3. 体験の流れ

| 段階 | 内容 | 時間の目安 |
|---|---|---|
| 呼ぶ | 呼び笛を右クリック（ヤギの角笛と同じ吹く仕草）。骨の笛の音が鳴り、「遠くで、低い歌が応える」 | — |
| 迎え（COMING） | 岩鯨が 480 ブロック以内にいればそのまま泳いでくる。遠い・読み込まれていないときは、前にいた方角の 260 ブロック先（雲の上）へ呼び寄せ、そこから泳いでくる | 10〜20 秒 |
| 待つ（WAITING） | 呼んだ人の 2〜5 ブロック横の立てる所の真上に、頭の乗り場の鎖が来るように止まり、鎖を垂らす。止まる高さは鎖の下の地面の 30 上、まわりに丘があればその 8 上 | 最大 60 秒（呼んだ人が乗るまで）＋ 90 秒（行き先を決めるまで） |
| 乗る | 鎖を右クリック → 鎖を巻き上げられて垂れ口まで昇り、頭の丸みに沿った鎖をたどって座席へ。座ると、呼んだ人には空の海図が開く | 3〜5 秒 |
| 行き先を選ぶ | 海図で行き先を選び「出発」。決めるのは呼んだ人 | — |
| 出発の待ち（BOARDING） | 8 秒、鎖を垂らしたまま待つ（ほかの人が乗る時間）。そのあと鎖をたたむ | 8〜11 秒 |
| 昇る（ASCENT） | 行き先へ向き直りながら、雲（y=192〜196）の上の y=212 へ（地形が高ければその 50 上）。題字「岩鯨が泳ぎだす／行き先: 〇〇」 | 最大 12 秒 |
| 泳ぐ（CRUISE） | 28 ブロック/秒で雲の海の上を泳ぐ。ちぎれた雲が吹き抜け、風の音が速さに応じて強まる。画面下に「〇〇まで、あと およそ N 秒」 | 600 ブロック以下の旅はそのまま行き先へ。遠い旅は 12〜21 秒 |
| 雲の帳（VEIL） | 雲の海へ潜る。画面と霧が雲の白に包まれ（1 秒で濃くなる）、行き先の手前 220 ブロックのまわりが読み込まれたら、そこへ岩鯨ごと移す。1 秒余りで帳が晴れる | 3〜10 秒 |
| 降りる（APPROACH） | 行き先の上空へ降りていき、乗り場の鎖が降ろす場所の真上に来るよう止まる。題字は行き先の名 | 8〜12 秒 |
| 降ろす（LOWERING） | 鎖を垂らし、一人ずつ（0.4 秒おき）鎖をたどって地上へ降ろす。着いたら「岩鯨はあなたを 〇〇 に降ろし、また空へ帰っていく」 | 5〜8 秒 |
| そのあと | 岩鯨は行き先で 1 分休み、背中の鎖を垂らす（その地の人も背中の試練へ乗れる）。呼んだ人は 3 分のクールダウン | — |

試遊で測った長さ（行き先を決めてから降ろされるまで）: 1,428〜1,433 ブロックの旅で 61〜64 秒（3 回）。180 ブロックの旅は 27〜28 秒（自己テスト）。

## 4. 解放と道具

### 4.1 解放（巨神に認められる）

| 項目 | 内容 |
|---|---|
| 条件 | その巨神の心臓を倒したこと。巨神の記憶（`TitanMemoryData`）の撃破数 `clears` が 1 以上。コマンドでも認められる（`TravelState.unlocked`） |
| 確認 | 2 秒ごとにプレイヤーを調べる。古いワールドで心臓をすでに倒している人にも、次のログインで渡る |
| 渡すもの | 呼び笛を 1 つ（一度だけ。持ち物がいっぱいなら足もとに落とす）。「胸の奥で、岩鯨の歌がこだました…」と、使い方の一行 |
| クエストへのフック | 解放で `Quests.signal(player, "titan_travel_stone_whale")`、降ろされるたびに `Quests.signal(player, "titan_voyage")`。今は受けるクエストがない（07 で使える） |

### 4.2 岩鯨の呼び笛（`skyabyss:stone_whale_call`）

- 鯨の骨をくり抜いて反らせた角笛。青緑の碑文の帯が 2 本、吹き口に石の輪（32px、ラフ 3 案から A。5 章）。
- 右クリックで吹く。認められていない人が吹くと「笛は鳴らない。岩鯨はまだ、あなたを知らない」。
- 乗り場の上で吹くと、海図を開き直す（決める人だけ）。
- なくしたら作り直せる: 骨＋岩鯨の心核＋岩鯨の欠片（斜めに並べる）。心核は心臓の初回撃破で必ず落ちるので、作れるのは心臓を倒した人だけ。

### 4.3 巨神の碑（`skyabyss:titan_waymark`）

- 深層岩の台座に立つ石の札と、鯨骨の笠。札には伝承の書と同じ菱形の星と、その下に尾びれの碑文（青緑に光る。明るさ 6）。ラフ 3 案から C。
- 作り方: 骨ブロック・岩鯨の欠片・磨かれた深層岩を縦に並べて 2 つ。手で壊せる（ツルハシは要らない。共有ファイルの `mineable` タグに触れないため）。
- 置いた人は自動で覚える。ほかの人も、触れる（右クリック）と覚える。だれの碑でも覚えられる。
- 名前: 金床で名付けた碑はその名、名のない碑は土地の名で「平原の碑」のように呼ぶ。
- 碑の上に空がないと覚えられない（「屋根の下の碑は、巨神から見えない」）。オーバーワールド以外では覚えられない。
- 一人 16 まで。海図の行の × で忘れられる。
- 壊すと、覚えていた人の海図に「碑は失われた（外した）」と灰色で出て、選べない（行も印も。× も出ない）。海図を送ったときに記録から外すので、枠（16）はすぐ空き、次に開いたときには出ない（`Voyages.pruneLost`。2026-10-17、夜の見直し T4）。

## 6. 制限

| 制限 | 内容 | 断るときの文 |
|---|---|---|
| ディメンション | オーバーワールドだけ（ネザー・エンド・背中では呼べない） | 「この地の空に、岩鯨は来ない」 |
| 屋内 | 頭の上の一番高いブロックより上にいて、空が見えること（洞窟・屋根の下・木の葉の下は不可） | 「空が見えない。ここでは巨神があなたを見つけられない」 |
| 水中 | 不可 | 「水の中では、笛を吹けない」 |
| 戦闘中 | 敵に傷つけられて 10 秒、敵を傷つけて 5 秒、16 ブロック以内に自分を狙う敵がいる間 | 「戦いの最中は、笛の音が届かない」 |
| 騎乗中 | 何かに乗っている間は不可（岩鯨の乗り場の上で吹くと海図を開き直す） | 「何かに乗っていては、笛を吹けない」 |
| クールダウン | 呼んだ人だけ。着いたあと 3 分。呼んだが乗らなかった・取りやめたときは 30 秒。呼んだ人がログアウト中に終わったときは世界の記録（`TravelWorldData` の `offline_ready`）に置き、再起動を越えて次のログインで効く | 「岩鯨はまだ休んでいる（あと N 秒）」 |
| 近すぎる行き先 | 64 ブロック未満は選べない | 「ここ（近すぎる）」 |
| ピースフル | 移動はできる（試練ではないため） | — |

## 7. マルチプレイ

| 場面 | 扱い |
|---|---|
| 一体だけ | 旅は巨神ごとに一つ。岩鯨は呼ばれた本物の個体をそのまま操縦し、増やさない。呼び寄せも見守り（WhaleKeeper）の `spawn` を通すので、古い個体は読み込まれたときに取り消される |
| 同乗 | 座席は 8。迎えの鎖が垂れている間（待つ・出発の待ち）なら、だれでも鎖で乗れる。まだ認められていない人も、休んでいる（クールダウン中の）人も乗れる。行き先を決めるのは呼んだ人。ほかの人の海図には「行き先は 〇〇 が決める」 |
| 同時に呼ぶ人 | 迎えの場所から 48 ブロック以内で吹けば「岩鯨は 〇〇 の呼び声に応えている。鎖が下りたら、一緒に乗れる」。遠ければ「岩鯨は今、〇〇 のもとにいる」と断る。運んでいる最中も断る |
| 呼んだ人がいなくなる | ログアウト、または迎えの場所から水平 96 ブロックより遠くに 10 秒いると、乗っている人の一人が決める役を継ぐ（海図が開く）。だれも乗っていなければ取りやめ |
| 背中の鎖を上っている人がいる | 呼べない（「だれかが背中の鎖を上っている」）。引き上げの途中で岩鯨が去らないように |
| 背中の試練中の人 | 呼べる（長い試練で移動を止めないため）。背中の人には、出発と到着を語りで知らせる。降りるとき（錨石・端から落ちる・コマンド）、岩鯨が乗り込んだ場所から 128 ブロックより遠くにいれば、乗り込んだ場所の空へ戻す（02 の 2.6 節）。乗り込んだ場所の記録は背中で倒れても消えない。だれかが試練の途中で知らない土地へ降ろされることはない |
| 降りる | 着くまで降りられない（しゃがんでも降りず「ここから降りれば、雲の底まで落ちる」）。出発の前にしゃがむか海図の「降りる」で、鎖で地上へ降ろしてもらえる。呼んだ人が行き先を決める前に降りると、取りやめて全員を降ろす |

## 8. 理不尽をなくす仕組み（詰まり・閉じ込め・落下死）

| 起こりうること | 対策 |
|---|---|
| 乗っている人が落ちる | 着くまでは降りる操作を止める。乗客から外れた（テレポート・岩鯨が消えた）ら、宙にいればスローフォール 60 秒 |
| 乗っている人が地形に埋まる・ぶつかる | 乗っている・上り下りしている人は、壁に埋まる・落下・壁への衝突で傷つかない |
| 鎖を上り下りしている途中で詰まる | 上りは 13 秒、下りは 20 秒で打ち切る（上りは座席へ座らせる、下りはスローフォール 30 秒を付けて放す）。重力は必ず戻す |
| 降ろす場所が危ない | 行き先のまわり 10 ブロックで、空が開け、足もとが固く、溶岩・マグマ・火・サボテン・粉雪・鍾乳石・ウィザーローズのない所を選ぶ。木の葉の下は避け、見つからなければ水面、それもなければ木の上 |
| 碑が壊された | 海図で灰色に出して選べない。そのとき記録から外す（4.3 節）。選んだあとに壊されても、その場所へ降ろす |
| ログアウト・サーバーの停止（旅の途中） | ログアウトのとき乗り場から外し、降ろす場所の印（出発前は迎えの場所、出発後は行き先）を残す。次のログインで、そのチャンクを読み込んで地面の高さを測ってから、その上へ降ろす（スローフォール 10 秒）。「気がつくと、岩鯨はもう去っていた」 |
| サーバーが落ちた（印を付けられなかった） | 印は乗った時と出発の時にも付けておくので、自動保存のデータから同じように降ろす |
| バニラの「一人だけ乗せた乗り物」の扱い | バニラは一人だけを乗せた乗り物をそのプレイヤーと一緒に保存し、ログアウトで消す。岩鯨では無効にした（`hasExactlyOnePlayerPassenger` が常に false）。岩鯨が消えたり二体になったりしない |
| 岩鯨が迎えの場所で円を描いて着かない | 試遊で見つけて直した（12 章）。止まる向きを段階の初めに一度だけ決める |
| 巨神が見失われる | 旅のあいだ見守り（WhaleKeeper）は呼び直さない。本物が別の個体になったら（コマンドで呼び直したなど）、旅を打ち切って全員をゆっくり降ろす |

## 9. 負荷

| 項目 | 内容 |
|---|---|
| チャンクの読み込み | 岩鯨が泳いでいく少し先を中心に半径 3 チャンク（7x7）と、行き先のまわり半径 2 チャンクに、時間切れ付きのチケット（`skyabyss_voyage`、15 秒で切れる）を張る。旅が終われば外す |
| 地形の生成 | 生成が起きるのは、出だしの泳ぎ（最大 約 600 ブロック、花火エリトラと同じ速さ）と、行き先の手前 220 ブロックだけ。長い旅でも増えない |
| 雲の帳で移す | 出口のまわりが読み込まれてから移す（最大 10 秒待つ）。読み込まれていない所へ巨神を移すと、エンティティがチャンクの外に出て止まるため |
| 毎 tick の処理 | 旅は一つだけ。乗客は最大 8。地面の高さは読み込まれているチャンクだけを調べる |
| 通信 | 海図を開くときに行き先の一覧（最大 17 件）を一度送る。雲の帳の始まりと終わり。あとはバニラの騎乗の同期 |

## 10. 数値

| 項目 | 値 |
|---|---|
| 旅の速さ | 1.4 ブロック/tick（28 ブロック/秒） |
| 旅の高さ | y=212（雲の上）。下と前 64 ブロックの地形が高ければ、その 50 上。上限は建築の上限の 50 下 |

## 11. 後の巨神への広げ方

| 部品 | 役目 | 巨神ごとに足すもの |
|---|---|---|
| `TravelTitan`（interface） | 乗せて運べる巨神。旅の始まりと終わり、乗り場の鎖の伸び縮み、垂れ口と道すじ、座席の位置 | 巨神のエンティティが実装する（岩鯨は `StoneWhaleEntity`） |

## 13. 判断が要る点

1. **クールダウン 3 分**は短すぎないか。巨神での移動を「1 章の報酬」として気持ちよく使える長さにした。サーバー設定にするかどうか（共有ファイル `Config.java` に触れるので今回はしていない）。
2. **雲の帳で移すこと**を受け入れるか。景色は本物だが、長い旅の途中だけは移している。完全に飛ばす（A 案）に寄せるなら、泳ぐ時間の上限を延ばせばよい（負荷と待ち時間が増える）。
3. **行き先の種類**。今は「はじまりの地」と碑だけ。寝床・語り部の村・最後に乗った場所を足すか。村は語り部の村に碑を最初から置く形が自然（村の生成の担当と相談）。
4. **巨神ごとの性格**。雷翼は速く、潮殻は海の上を低く、のように速さや高さを巨神ごとに変えるか（今は共通の数値）。
5. **ログインし直すと旅が縮む**。旅の途中でログアウトすると、次のログインで行き先へ降ろされる（最大 1 分ほど縮む）。乗り直しにする手もあるが、巨神はもう去っているので、今は降ろす方を選んだ。
6. **背中の試練中でも呼べる**。試練中の人が降りると乗り込んだ場所へ戻されるが、その人がまた背中へ乗るには、岩鯨が戻ってくるのを待つ必要がある。試練中は呼べなくする方がよいか（長い試練の間、ほかの人の移動が止まる）。
7. 碑を**手で壊せる**（`mineable/pickaxe` のタグは共有ファイルなので触れていない）。ツルハシを要るようにするなら、タグへの一行の追加が要る。

## 16. 潮殻の呼び貝（海を渡る旅。2026-10-17）

14 の 3 章 4 の潮殻の分。岩鯨と同じ段階（迎え・乗る・決める・運ぶ・降ろす）を、海を歩く巨神の形でやる（`titan/travel/SeaVoyage`、`TitanKind.TIDE_SHELL`）。

### 16.1 道具と解放

| 項目 | 決めたこと |
| --- | --- |
| 品 | 潮殻の呼び貝（`skyabyss:tide_shell_call`）。珊瑚色の口の巻貝、32px（ラフ 3 案から A。`docs/review/tide_call_roughs/compare_call.png`） |
| 解放 | 潮殻の心臓を倒す（心臓の記録のフックで一度だけ渡す。岩鯨の笛と同じ）。なくしたら作り直せる（オウムガイの殻・潮殻の欠片・海洋の心、縦一列） |
| 守り | 大事な品（11 の 4 章。地面で消えない・奈落から戻る・在りかを控える）。人に渡せる |
| 吹ける所 | 空の見える海辺（迎えの浅瀬が近くにある所）。断る条件（戦闘中・水中・乗っている・休み）は岩鯨と同じ、文は潮殻の言い回し |

### 16.2 流れ

| 段階 | 潮殻 |
| --- | --- |
| 迎え | 沖から歩いてきて、呼んだ人のいちばん近い水際の沖に、潮門の側を向けて甲羅の縁を出して止まる。遠い・読み込まれていないときは沖 140〜220 の海に呼び寄せる |
| 乗る | 水際に泡の柱。入ると潮に持ち上げられ、潮門の前 → 甲羅の肩 → 塔の横 → 座席へ弧を描いて運ばれる（鎖の代わり） |
| 座席 | 甲羅の頂の真ん中は塔なので、塔の前の平らな所（前へ 11、高さ 34）と、その前の高台（前へ 17、高さ 36）に 4 人ずつ、8 人。高さは `tide_shell.geo.json` の上面から測った（ゲームでは見ていない。00 の 113） |
| 決める | 潮の海図（行き先は碑とはじまりの地、岩鯨と共通）。行き先の近くに歩ける海がなければ断る |
| 運ぶ | 沈んで歩く深さ（底が海面の 24 下、甲羅の頂が 10 出る。浅瀬では 12 下まで上がる）で 18 ブロック/秒。前方 40・80 が陸なら左右へ向きを振る |
| 潮の深み | 海だけを通る 700 ブロックまでの旅は本当に歩く。それより遠い・陸を越える旅は、歩きだして 8〜16 秒で深い潮の流れに乗り（画面が深い青）、行き先の海の手前 140 へ移る（岩鯨の雲の帳と同じ考え） |
| 降ろす | 行き先にいちばん近い海の点（地形を作らず、バイオームの数式で 1024 まで 32 刻みに探す）から行き先へ向かって最初の陸を浜とし、その沖へ寄って泡の柱で一人ずつ浜へ運ぶ。浜が行き先から 48 より遠ければ「〇〇までは、ここから北へ およそ N ブロック」 |
| 帰る | 降ろしたら沖へ帰る。旅のあいだは干潮の寄せ（`TideKeeper`）を止める |

- 潮殻の背（`tide_back`、甲羅の中の試練）の人には旅の知らせを出さない（背中の島は体とは別の場所）。
- 旅の途中では降りられない（「ここで降りれば、沖の海に落ちる。浜に着くまで待て」）。潮が届かなかったときは浜の上へ移してから放す（海に落とさない）。
