# 天と淵のあいだ 巨神での移動

- 文書番号: 09
- 範囲: 巨神に乗って行き先へ運んでもらう移動（ファストトラベル）。呼び笛・呼び貝、巨神の碑、空の海図、岩鯨（空を泳ぐ）と潮殻（海を歩く）の旅の流れ・制限・数値
- 関連: [01 全体設計](01_overview.md)、[02 岩鯨](02_stone_whale.md)、[08 潮殻](08_tide_shell.md)、[11 控え帳](11_record_screen.md)、[14 ベータ](14_beta.md)

実装: `jp.revati.skyabyss.titan.travel`（`TravelRules` の定数、`Voyage`・`Voyages`・`SeaVoyage`、`TitanKind`、`TravelTitan`）、`titan/` の岩鯨・見守り・鎖・背中の行き来への小さな追加。

---

## 1. 概要

巨神の心臓を倒した人は、その巨神に認められ、呼び笛（潮殻は呼び貝）を受け取る。空の見える所で吹くと、巨神が迎えに来て、頭の乗り場（潮殻は甲羅の座席）に乗せる。「空の海図」で行き先を選ぶと、巨神は行き先まで運び、鎖で一人ずつ地上へ降ろす。

- 行き先は「はじまりの地」（世界の初期スポーン）と、自分が触れて覚えた「巨神の碑」。碑はプレイヤーが作って拠点や村に立てる。
- 単なるテレポートに見せないため、乗る・昇る・泳ぐ・降りるをすべて本物の巨神の上で見せる。縮めるのは長い巡航の途中だけで、そこは雲の白（潮殻は深い青）に包む。
- ベータでは岩鯨と潮殻だけ。雷翼・余燼での移動はベータの後（未決）。

## 2. 方式の決定

| 案 | 内容 | よい点 | 困る点 |
|---|---|---|---|
| A. 本当に長距離を飛ぶ | 乗せたまま行き先まで | 景色が本物 | 3,000 ブロックで 2 分近く。未生成の地形を延々と生成してサーバーが重くなる |
| B. 背中のディメンションで時間を過ごす | 背中へ乗せ、一定時間ののち行き先の上空へ降ろす | 負荷が最小 | 足もとに地上が見えず「見下ろす景色」が出ない。背中の試練中の人と混ざる。退屈 |
| **C. 混成（採用）** | オーバーワールドの巨神の頭に乗せ、本当に昇って泳ぐ。遠い旅は途中で雲の帳に包み、行き先の手前 220 ブロックへ移して、そこから本当に降りる | 景色は本物。生成は出だしの数百ブロックと行き先の手前だけ。旅は 1 分前後 | 移す瞬間がある（雲の白で隠す）。巨神を外から操縦する仕組みが要る |

決定は C。理由:
1. 「乗っている」実感は、見下ろす地上と、自分の下で泳ぐ巨神の体から生まれる（B では出ない）。
2. A は長い旅ほど待ち時間と生成の負荷が増える。C は長さが距離にほぼよらず（30〜70 秒）、負荷に上限がある。
3. 一体だけの決まり（`WhaleKeeper`）を守ったまま、同じ巨神が本当に行き先へ移る。旅のあと行き先で休み、その地の人が背中へ乗れる。

背中のディメンション（01 の決定）は背中の島（試練）のためで、移動には使わない。鎖で乗る決まりは守る（鎖は頭から垂らす）。

## 3. 体験の流れ（岩鯨）

| 段階 | 内容 | 時間の目安 |
|---|---|---|
| 呼ぶ | 呼び笛を右クリック（ヤギの角笛と同じ吹く仕草）。骨の笛の音と「遠くで、低い歌が応える」。その巨神が眠っているあいだ（心臓を止めた直後。01 の 4.3）は、笛に応えず「…は深い眠りの中にいて、笛に応えない」 | — |
| 迎え（COMING） | 岩鯨が 480 ブロック以内ならそのまま泳いでくる。遠い・読み込まれていないときは、前にいた方角の 260 ブロック先（雲の上）へ呼び寄せる | 10〜20 秒 |
| 待つ（WAITING） | 呼んだ人の 2〜5 ブロック横の立てる所の真上に頭の乗り場の鎖が来るよう止まり、鎖を垂らす。止まる高さは鎖の下の地面の 30 上、まわりに丘があればその 8 上（体が丘に埋まって真っ黒になるのを防ぐ） | 最大 60 秒（乗るまで）＋ 90 秒（行き先を決めるまで） |
| 乗る | 鎖を右クリック → 巻き上げられて垂れ口まで昇り、頭の丸みに沿った鎖をたどって座席へ。呼んだ人には空の海図が開く | 3〜5 秒 |
| 行き先を選ぶ | 海図で選び「出発」。決めるのは呼んだ人 | — |
| 出発の待ち（BOARDING） | 8 秒、鎖を垂らしたまま待つ（ほかの人が乗る時間）。そのあと鎖をたたむ | 8〜11 秒 |
| 昇る（ASCENT） | 行き先へ向き直りながら、雲（y=192〜196）の上の y=212 へ（地形が高ければその 50 上）。題字「岩鯨が泳ぎだす／行き先: 〇〇」 | 最大 12 秒 |
| 泳ぐ（CRUISE） | 28 ブロック/秒で雲の海の上を泳ぐ。ちぎれた雲が吹き抜け、風の音が速さに応じて強まる。画面下に「〇〇まで、あと およそ N 秒」 | 600 ブロック以下はそのまま行き先へ。遠い旅は 12〜21 秒 |
| 雲の帳（VEIL） | 雲の海へ潜る。画面と霧が雲の白に包まれ（1 秒で濃くなる）、行き先の手前 220 ブロックのまわりが読み込まれたらそこへ岩鯨ごと移す。1 秒余りで晴れる | 3〜10 秒 |
| 降りる（APPROACH） | 行き先の上空へ降り、乗り場の鎖が降ろす場所の真上に来るよう止まる。題字は行き先の名 | 8〜12 秒 |
| 降ろす（LOWERING） | 鎖を垂らし、一人ずつ（0.4 秒おき）鎖をたどって地上へ。「岩鯨はあなたを 〇〇 に降ろし、また空へ帰っていく」 | 5〜8 秒 |
| そのあと | 岩鯨・潮殻は行き先で 20 分（`TitanStay`。`TravelRules.REST_AFTER`）休み、背中の鎖（潮門）を開けておく。休んでいるあいだに新しい旅が始まれば、そこで去る（その地の人も背中の試練へ乗れる）。呼んだ人は 3 分のクールダウン | — |

- 実測（行き先を決めてから降ろされるまで）: 1,428〜1,433 ブロックで 61〜64 秒、180 ブロックで 27〜28 秒。
- 残り秒数は、決めたときの見積もりから、たった時間を引く（段階ごとに計算し直すと昇っている間に減らないため）。
- 座席の高さは、座った体が頭から浮かないよう 0.7 ブロック下げてある。
- 止まる向きは、段階の初めに一度だけ決め、着く手前でその向きへ合わせる（今の向きで決めると向きを変えるたびに目標も回って円を描き続けるため）。

## 4. 解放と道具

### 4.1 解放（巨神に認められる）

| 項目 | 内容 |
|---|---|
| 条件 | その巨神の心臓を倒したこと。巨神の記憶（`TitanMemoryData`）の撃破数 `clears` が 1 以上。コマンドでも認められる（`TravelState.unlocked`） |
| 確認 | 2 秒ごとにプレイヤーを調べる。古いワールドで心臓を倒している人にも、次のログインで渡る |
| 渡すもの | 呼び笛を 1 つ（一度だけ。持ち物がいっぱいなら足もとに落とす）。「胸の奥で、岩鯨の歌がこだました…」と使い方の一行 |
| クエストのフック | 解放で `Quests.signal(player, "titan_travel_stone_whale")`、降ろされるたびに `Quests.signal(player, "titan_voyage")`。今は受けるクエストがない（07 で使える） |

### 4.2 岩鯨の呼び笛（`skyabyss:stone_whale_call`）

- 鯨の骨をくり抜いて反らせた角笛。青緑の碑文の帯が 2 本、吹き口に石の輪（32px、反った鯨骨の角笛。ヤギの角笛の吹く仕草に合い、鯨骨らしさが出る）。
- 右クリックで吹く。認められていない人が吹くと「笛は鳴らない。岩鯨はまだ、あなたを知らない」。
- 乗り場の上で吹くと、海図を開き直す（決める人だけ）。
- なくしたら作り直せる: 骨＋岩鯨の心核＋岩鯨の鱗片（斜めに並べる）。心核は心臓の初回撃破で必ず落ちるので、作れるのは心臓を倒した人だけ。
- 大事な品として守られる（地面で消えない・奈落から戻る・在りかを控える。11 の 4.1 節）。投げ捨てられない（人に渡すなら箱を通す）。

### 4.3 巨神の碑（`skyabyss:titan_waymark`）

- 深層岩の台座に立つ石の札と、鯨骨の笠。札に伝承の書と同じ菱形の星と、その下に尾びれの碑文（青緑に光る。明るさ 6）。
- 作り方: 骨ブロック・岩鯨の鱗片・磨かれた深層岩を縦に並べて 2 つ。手で壊せる（共有の `mineable` タグに触れないため。未決）。
- 置いた人は自動で覚える。ほかの人も、触れる（右クリック）と覚える。だれの碑でも覚えられる。
- 名前: 金床で名付けた碑はその名、名のない碑は土地の名で「平原の碑」のように呼ぶ。
- 碑の上に空がないと覚えられない（「屋根の下の碑は、巨神から見えない」）。オーバーワールド以外では覚えられない。
- 一人 16 まで。海図の行の × で忘れられる。
- 壊すと、覚えていた人の海図に「碑は失われた（外した）」と灰色で出て、選べない。海図を送ったときに記録から外すので、枠はすぐ空く（`Voyages.pruneLost`）。選んだあとに壊されても、その場所へ降ろす。

## 6. 制限

| 制限 | 内容 | 断るときの文 |
|---|---|---|
| ディメンション | オーバーワールドだけ（ネザー・エンド・背中では呼べない） | 「この地の空に、岩鯨は来ない」 |
| 屋内 | 頭の上の一番高いブロックより上にいて、空が見えること（洞窟・屋根・木の葉の下は不可） | 「空が見えない。ここでは巨神があなたを見つけられない」 |
| 水中 | 不可 | 「水の中では、笛を吹けない」 |
| 戦闘中 | 敵に傷つけられて 10 秒、敵を傷つけて 5 秒、16 ブロック以内に自分を狙う敵がいる間 | 「戦いの最中は、笛の音が届かない」 |
| 騎乗中 | 何かに乗っている間は不可（乗り場の上で吹くと海図を開き直す） | 「何かに乗っていては、笛を吹けない」 |
| クールダウン | 呼んだ人だけ。着いたあと 3 分。呼んだが乗らなかった・取りやめたときは 30 秒。呼んだ人がログアウト中に終わったときは世界の記録（`TravelWorldData` の `offline_ready`）に置き、再起動を越えて次のログインで効く | 「岩鯨はまだ休んでいる（あと N 秒）」 |
| 近すぎる行き先 | 64 ブロック未満は選べない | 「ここ（近すぎる）」 |
| ピースフル | 移動はできる（試練ではないため） | — |

## 7. マルチプレイ

| 場面 | 扱い |
|---|---|
| 一体だけ | 旅は巨神ごとに一つ。本物の個体をそのまま操縦し、増やさない。呼び寄せも `WhaleKeeper` の `spawn` を通すので、古い個体は読み込まれたときに取り消される |
| 同乗 | 座席は 8。迎えの鎖が垂れている間（待つ・出発の待ち）なら、だれでも鎖で乗れる。認められていない人も、休んでいる人も乗れる。行き先を決めるのは呼んだ人（ほかの人の海図には「行き先は 〇〇 が決める」） |
| 同時に呼ぶ人 | 迎えの場所から 48 ブロック以内で吹けば「岩鯨は 〇〇 の呼び声に応えている。鎖が下りたら、一緒に乗れる」（認められていない人にも、解放の確認より先にこれを知らせる）。遠ければ「岩鯨は今、〇〇 のもとにいる」と断る。運んでいる最中も断る |
| 呼んだ人がいなくなる | ログアウト、または迎えの場所から水平 96 ブロックより遠くに 10 秒いると、乗っている人の一人が決める役を継ぐ（海図が開く）。だれも乗っていなければ取りやめ |
| 背中の鎖を上っている人がいる | 呼べない（「だれかが背中の鎖を上っている」）。引き上げの途中で岩鯨が去らないように |
| 背中の試練中の人 | 呼べる（長い試練で移動を止めないため）。背中の人には出発と到着を語りで知らせる。降りるとき、岩鯨が乗り込んだ場所から 128 ブロックより遠くにいれば、乗り込んだ場所の空へ戻す（02 の 2.6）。試練の途中で知らない土地へ降ろされることはない |
| 降りる | 着くまで降りられない（しゃがんでも降りず「ここから降りれば、雲の底まで落ちる」）。出発の前にしゃがむか海図の「降りる」で、鎖で地上へ降ろしてもらえる。呼んだ人が行き先を決める前に降りると、取りやめて全員を降ろす |

## 8. 理不尽をなくす仕組み

| 起こりうること | 対策 |
|---|---|
| 乗っている人が落ちる | 着くまでは降りる操作を止める。乗客から外れた（テレポート・巨神が消えた）ら、宙にいればスローフォール 60 秒 |
| 地形に埋まる・ぶつかる | 乗っている・上り下りしている人は、壁に埋まる・落下・壁への衝突で傷つかない |
| 鎖の上り下りで詰まる | 上りは 13 秒、下りは 20 秒で打ち切る（上りは座席へ座らせる、下りはスローフォール 30 秒を付けて放す）。重力は必ず戻す |
| 降ろす場所が危ない | 行き先のまわり 10 ブロックで、空が開け、足もとが固く、溶岩・マグマ・火・サボテン・粉雪・鍾乳石・ウィザーローズのない所を選ぶ。木の葉の下は避け、見つからなければ水面、それもなければ木の上 |
| ログアウト・サーバー停止（旅の途中） | ログアウトのとき乗り場から外し、降ろす場所の印（出発前は迎えの場所、出発後は行き先）を残す。次のログインで、そのチャンクを読み込んで地面の高さを測ってから（読み込む前は高さが最低と返り地中に埋まる）、その上へ降ろす（スローフォール 10 秒）。「気がつくと、岩鯨はもう去っていた」。旅は最大 1 分ほど縮む |
| サーバーが落ちた（印を付けられなかった） | 印は乗った時と出発の時にも付けるので、自動保存のデータから同じように降ろす |
| バニラの「一人だけ乗せた乗り物」の扱い | バニラは一人だけを乗せた乗り物をそのプレイヤーと一緒に保存し、ログアウトで消す。岩鯨では無効にした（`hasExactlyOnePlayerPassenger` が常に false） |
| 巨神が見失われる | 旅のあいだ見守りは呼び直さない。本物が別の個体になったら、旅を打ち切って全員をゆっくり降ろす |

## 9. 負荷

| 項目 | 内容 |
|---|---|
| チャンクの読み込み | 岩鯨が泳ぐ少し先を中心に半径 3 チャンク（7x7）と、行き先のまわり半径 2 チャンクに、時間切れ付きのチケット（`skyabyss_voyage`、15 秒で切れる）。旅が終われば外す |
| 地形の生成 | 起きるのは、出だしの泳ぎ（最大 約 600 ブロック）と、行き先の手前 220 ブロックだけ。長い旅でも増えない |
| 雲の帳で移す | 出口のまわりが読み込まれてから移す（最大 10 秒待つ）。読み込まれていない所へ移すとエンティティがチャンクの外に出て止まるため |
| 毎 tick | 旅は一つだけ。乗客は最大 8。地面の高さは読み込まれているチャンクだけを調べる |
| 通信 | 海図を開くときに行き先の一覧（最大 17 件）を一度送る。雲の帳の始まりと終わり。あとはバニラの騎乗の同期 |

## 11. 他の巨神への広げ方

| 部品 | 役目 | 巨神ごとに足すもの |
|---|---|---|
| `TravelTitan`（interface） | 乗せて運べる巨神。旅の始まりと終わり、乗り場の鎖の伸び縮み、垂れ口と道すじ、座席の位置 | 巨神のエンティティが実装（岩鯨は `StoneWhaleEntity`、潮殻は `TideShellEntity`） |
| `TitanKind` | 巨神の一覧。名前、今の本物の探し方、呼び寄せ方、背中で乗り降り中か、呼び笛、旅の型（`Style.SKY`＝雲の上を泳ぐ、`Style.SEA`＝海を歩く）、巨神ごとの言い回し（`message.skyabyss.travel.<巨神>.…`、なければ共通の文）と音 | 一行足す（今は岩鯨と潮殻の二行） |
| `Voyage`（SKY）・`SeaVoyage`（SEA）・`Voyages` | 旅の操縦と、呼ぶ・乗る・決める・降りる・見張り | 動きは巨神の外から決める。型が新しいなら足す |
| 呼び笛 | `TitanCallItem` に `TitanKind` を渡す | 巨神ごとのアイテムとアイコン |
| 碑・行き先・プレイヤーの記録 | 巨神をまたいで共通 | なし |

- 解放は巨神ごと（`TravelState.unlocked` と心臓の記録）。複数持つ人は、笛ごとに違う巨神を呼ぶ。旅は巨神ごとに一つなので、潮殻と岩鯨は同時に飛べる。
- 数値（`TravelRules`）は今は共通。巨神ごとの性格（雷翼は速く、潮殻は海の上を低く）は未決。

## 12. 潮殻の呼び貝（海を渡る旅）

岩鯨と同じ段階（迎え・乗る・決める・運ぶ・降ろす）を、海を歩く巨神の形でやる（`titan/travel/SeaVoyage`、`TitanKind.TIDE_SHELL`）。

### 12.1 道具と解放

| 項目 | 内容 |
| --- | --- |
| 品 | 潮殻の呼び貝（`skyabyss:tide_shell_call`）。珊瑚色の口の巻貝、32px |
| 解放 | 潮殻の心臓を倒す（心臓の記録のフックで一度だけ渡す。岩鯨の笛と同じ）。なくしたら作り直せる（オウムガイの殻・潮殻の殻片・海洋の心、縦一列） |
| 守り | 大事な品（11 の 4.1 節）。投げ捨てられない（人に渡すなら箱を通す） |
| 吹ける所 | 空の見える海辺（迎えの浅瀬が近くにある所）。断る条件（戦闘中・水中・乗っている・休み）は岩鯨と同じ、文は潮殻の言い回し |

### 12.2 流れ

| 段階 | 潮殻 |
| --- | --- |
| 迎え | 沖から歩いてきて、呼んだ人のいちばん近い水際の沖に、潮門の側を向けて甲羅の縁を出して止まる。遠い・読み込まれていないときは沖 140〜220 の海に呼び寄せる |
| 乗る | 水際に泡の柱。入ると潮に持ち上げられ、潮門の前 → 甲羅の肩 → 塔の横 → 座席へ弧を描いて運ばれる（鎖の代わり） |
| 座席 | 8。塔の前の平らな所（前へ 11、高さ 34）と、その前の高台（前へ 17、高さ 36）に 4 人ずつ。高さは `tide_shell.geo.json` の上面から測った（ゲームでは見ていない） |
| 決める | 潮の海図（行き先は碑とはじまりの地、岩鯨と共通）。行き先の近くに歩ける海がなければ断る |
| 運ぶ | 沈んで歩く深さ（底が海面の 24 下、甲羅の頂が 10 出る。浅瀬では 12 下まで上がる）で 18 ブロック/秒。前方 40・80 が陸なら左右へ向きを振る |
| 潮の深み | 海だけを通る 700 ブロックまでの旅は本当に歩く。それより遠い・陸を越える旅は、歩きだして 8〜16 秒で深い潮の流れに乗り（画面が深い青）、行き先の海の手前 140 へ移る |
| 降ろす | 行き先にいちばん近い海の点（地形を作らず、バイオームの数式で 1024 まで 32 刻みに探す）から行き先へ向かって最初の陸を浜とし、その沖へ寄って泡の柱で一人ずつ浜へ運ぶ。浜が行き先から 48 より遠ければ「〇〇までは、ここから北へ およそ N ブロック」 |
| 帰る | 降ろしたら沖へ帰る。旅のあいだは干潮の寄せ（`TideKeeper`）を止める |

- 潮殻の背（`tide_back`）の人には旅の知らせを出さない（背中の島は体とは別の場所）。
- 旅の途中では降りられない（「ここで降りれば、沖の海に落ちる。浜に着くまで待て」）。潮が届かなかったときは浜の上へ移してから放す。

### 12.3 数値（`SeaVoyage`）

| 項目 | 値 |
| --- | --- |
| 歩く速さ | 0.9 ブロック/tick（18/秒。岩鯨 28 より遅い） |
| 歩く深さ | 海面の 24 下（浅瀬 12 下） |
| 本当に歩く旅 | 海だけ・700 ブロックまで |
| 潮の深みの出口 | 行き先の海の手前 140 |
| 迎えの浅瀬を探す範囲 | 80（水際は 10） |
| 潮が人を運ぶ速さ | 0.75 ブロック/tick |
| 遠い浜の知らせ | 行き先から 48 より遠いとき |
| 休み（次に呼べるまで） | 岩鯨と共通（`TravelRules`） |

## 13. テスト用コマンドと自己テスト

### 13.1 コマンド（OP。`/skyabyss travel ...`）

| コマンド | 内容 |
|---|---|
| `unlock [人]` / `lock [人]` | 認めさせる・取り消す（心臓の撃破の記録があれば認められたまま） |
| `call` | 条件（クールダウン・空・戦い・解放）を見ずに呼ぶ |
| `go <x> <z>` | 乗り場の上で、海図を使わずに行き先を座標で決める |
| `cooldown` | 自分のクールダウンを消す |
| `status` | 今の旅（段階・決める人・乗っている人・行き先）と、自分の記録 |
| `end` | 今の旅を打ち切る（乗っている人はゆっくり降ろす） |

### 13.2 自己テスト（`SKYABYSS_SELFTEST=1`）

`SELFTEST travel PASSED`:

| 項目 | 確かめたこと |
|---|---|
| 碑の登録 | 加える・重ねを断る・16 で満杯・忘れる |
| 保存 | プレイヤーの記録のコーデックの往復、空の記録の読み込み、世界の碑の一覧の保存・読み込み・削除 |
| 解放 | 心臓の記録 0 で呼べない、1 で呼べる、コマンドの記録で呼べる、知らない人は断られる |
| 見積もり | 距離に対して減らない、20〜90 秒に収まる、泳ぐ時間の上下限 |
| 降ろす場所 | 空高くの台で、マグマとサボテンを避けて石の上を選ぶ |
| 一体だけ・排他 | 二度呼びを断る、近くの人は「一緒に乗れる」、遠い人は断る、岩鯨は 1 体のまま、打ち切ると巨神が自由になる |
| 旅の流れ | 出だしの位置と向きを変えた 7 通り（近くで背を向けている、250 ブロック先、低い所から、など）で、迎え → 待つ → 出発 → 昇る → 泳ぐ → 降りる → 降ろす がすべて通り、寄せ直し（snap）0 回、鎖の垂れ口が降ろす場所から 2 ブロック以内、旅のあと岩鯨が自分で泳ぐのに戻る |

`SELFTEST tide travel PASSED`（登録、心臓の記録で呼び貝が一度だけ渡る、見積もり、方位、迎えの断り、迎えと降ろしの飛行）: 出現地点に近い本物の海で、呼ぶ → 柱から 32 ブロックに潮門が止まる → 乗る → 歩く → 内陸の行き先から 110 ブロックの浜に降ろす、を 28 秒（577 tick）で走らせ、潮殻が水の中で休み 1 体だけ残ることも見る。読み込みは札だけにして複数 tick に分ける。
