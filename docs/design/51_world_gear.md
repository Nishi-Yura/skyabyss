# 天と淵のあいだ 野の装備（土地ごとの武器と防具）

- 文書番号: 51
- 範囲: 物語（巨神・深淵・月・雲海）の報酬とは別に、土地の敵・名のある強敵・層の主・町の店から出る武器と防具と装飾の枠の品。Lv の帯ごとの品の数、階級、数値、能力、形、出どころ。
- 状態: 2026-10-31 に一覧を決めて実装した（品・能力・落とし物・店・形・自己テスト `wild gear`）。数値は試遊で詰める（ユーザーの声「ストーリーに沿っての物しか出ていなかったので、他にも出るようにすると、もっと戦いやすかったり、いろんな能力や、ステータスの武器がでるので、色々楽しい」）。数は職ごと（武器）・一式ごと（防具）。

## 2. 強さの線

**目安の 1 秒あたり E(L)**（必要 Lv L の巨神のエピック相当。間は直線）: Lv 1 = 8.0（祠の剣）、8 = 10.0、14 = 12.6、20 = 14.6、26 = 16.0、40 = 19.4、50 = 23.0。

**弓の矢の倍率 B(L)**（同じ相当）: Lv 1 = 1.0、8 = 1.15、14 = 1.45、20 = 1.75、26 = 1.85、40 = 2.15、50 = 2.2。

品の目安 = E(L) × 階級の係数。能力の平均の上乗せ（発動の確率 × 量）を引いた残りを、攻撃力 × 速さに置く。数値は `tools/gen/wild_gear/spec.py` が決め、`item/wild/WildGearTable`（生成）に入る。

- **人ごとの抽選**: 敵を倒したとき、傷を与えた人（と、そばの組の人）ごとに抽選し、当たった品を**その階級と帯の封の箱**にしてその人に渡す（旅嚢 → 持ち物 → 足もと、その人だけが拾える。[52](52_loot_boxes.md)）。ほかの人の当たりで自分の確率は減らない。店で買う品は箱にならない。
- **職への寄せ**: 武器が当たったら、2/3 で今の職の武器、1/3 でほかの職の武器（同じ帯・同じ階級から）。
- **名のある強敵と主**: 人ごとに初めて倒したとき、その帯のレアかエピックを一つ必ず。二度目からは 12%（ヒロイックは表の値）。
- **店**: アンコモンは鍛冶屋で鐘銭で買える（武器 12〜20、防具の部位 2〜10。帯 I は一章から、帯 II は二章から並ぶ）。
- **主の判定**: 名のある強敵の印か、画面の帯を持つ型（`MobTuning.hasBossBar`）。大きいだけの敵は主に数えない。

## 7. 作り

- 表は一つ: `tools/gen/wild_gear/spec.py`（名前・種類・階級・Lv・能力・形の説明・ja/en の言葉・出どころ）。ここから Java の表（`item/wild/WildGearTable`）・言葉・持ち方・振りの型を生成する。
- 形: 武器は `tools/rough/lowpoly/weapons/wild/`（一品一案の関数。塗りは品ごとの素材の表）、装飾の枠の品は同じ所の `o_wild_acc.py`、防具は `tools/rough/lowpoly/armor/wild/`。どれも水を漏らさないメッシュ（mesh_audit）。
- 能力: `item/wild/WildGearEvents`（能力の種類ごとの手当て。品は表の能力の種類と数で引く）。
- 落とし物: `item/wild/WildLoot`（土地・層・区画の敵、名のある強敵、主、店）。
- 自己テスト `wild gear`: 表と登録の一致、職の語、強さの線（帯の中で階級が逆転しない・同じ Lv の巨神のヒロイックを越えない）、能力の手当てが全部の種類にある、落とし物の表が全部の品を含む。
