## 2. 物語の芯

- 錨（深淵の心臓）が緩んだまま、月は空の巡礼者に引かれて寄ってくる。月の中には**時間を縛る核**があり、これまで月が落ちるたびに世界の物語だけが巻き戻ってきた。
- 留まる者（主人公）だけが巻き戻りを覚えている。**見る者は、前の巻き戻りで月に残された自分たち**。六章の芯はこの正体に気づくこと。
- 月の核を止めると、巻き戻りが止まる。だが止めた月は落ちるのをやめず、巡礼者が直に降りてくる（終章「雲海」への引き）。
- 語り部の数え歌のむっつめ「そらの　まるい　ふた」は、月が空にかぶせた蓋（核が時間を閉じている）のこと。

## 3. 決まったこと（並べた案は選ばなかったものも残す。選んだのは太字）

### 3.1 舞台（284）

| 案 | 中身 | 良い所 | 弱い所 |
| --- | --- | --- | --- |
| **A 月の面（別のディメンション）** | 青白い砂と灰色の岩の月の面。空は黒く、地上の大陸が上に浮かぶ。重さが軽い（跳びが高く、落ちが遅い）。核は月の奥 | 「月へ渡った」実感が一番強い。深淵（地の底）と対になる | ディメンションをもう一つ作る（深淵と同じ作り方で足りる） |
| B 月のまわりの欠片の島 | 月から剝がれた岩の島が、地上の空の高い所に浮かぶ。島を渡り、最後に月の中へ | 地上の空とつながって見える。雷翼の巨神（空）とも合う | 島の大きさで遊びが痩せやすい。空の上は描画が重い |
| C 月の内部だけ | 月の殻の中の、時計仕掛けのような空洞と回廊。外の面は出さない | 時間の仕掛けを作りやすい | 深淵（中の層）と似る。月らしい景色が出ない |

**決まり: A**（深淵の層と同じ作り方を使える。景色が一番違う）。

## 4. 形（たたき台。数字は作りながら決める）

- レベルの帯: 六章は Lv 50 から（転生 0〜）。深淵の後なので、敵は深淵の上の層と同じくらいから始め、区画が進むごとに上がる（数字は 36 の 4.2 の曲線を延ばす）。
- 区画の順: 新月の谷 → 上弦の崖 → 満月の野 → 下弦の淵 → 核の間。各区画: 野営（前の自分・月の溜まり）→ 探す場所 3 つ → 区画の主。
- 位相: 月の一日 20 分を 4 つに分ける（5 分ずつ）。区画の主はその区画の位相でだけ強くなる（どの位相でも戦えるが、合った位相は手応えが違う）。
- 敵: 月の砂の這うもの・殻を背負った月の兎・欠けた光の群れ・時の残像（倒した敵が数秒前の姿で一度だけ立ち上がる）など、区画ごとに 3 種（深淵と同じく三段の姿）。
- 装備: 03 の 12.2 の表を今の階級と曲線に直して作る（形は一品一案、ラフ 3 案から）。月の心核は神器の素材。
- 伝承: 前の自分の記憶の断片（12）。集めると見る者の正体と、核が時間を閉じた理由が分かる。
- マルチ: 区画の進みはパーティで共有（深淵と同じ）。月の一日は世界で一つ。
