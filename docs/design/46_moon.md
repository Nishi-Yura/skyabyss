## 2. 物語の芯

- 錨（深淵の心臓）が緩んだまま、月は空の巡礼者に引かれて寄ってくる。月の中には**時間を縛る核**があり、これまで月が落ちるたびに世界の物語だけが巻き戻ってきた。
- 留まる者（主人公）だけが巻き戻りを覚えている。**見る者は、前の巻き戻りで月に残された自分たち**。六章の芯はこの正体に気づくこと。
- 月の核を止めると、巻き戻りが止まる。だが止めた月は落ちるのをやめず、巡礼者が直に降りてくる（終章「雲海」への引き）。
- 語り部の数え歌のむっつめ「そらの　まるい　ふた」は、月が空にかぶせた蓋（核が時間を閉じている）のこと。

## 4. 形（たたき台。数字は作りながら決める）

- レベルの帯: 六章は Lv 50 から（転生 0〜）。深淵の後なので、敵は深淵の上の層と同じくらいから始め、区画が進むごとに上がる（数字は 36 の 4.2 の曲線を延ばす）。
- 区画の順: 新月の谷 → 上弦の崖 → 満月の野 → 下弦の淵 → 核の間。各区画: 野営（前の自分・月の溜まり）→ 探す場所 3 つ → 区画の主。
- 位相: 月の一日 20 分を 4 つに分ける（5 分ずつ）。区画の主はその区画の位相でだけ強くなる（どの位相でも戦えるが、合った位相は手応えが違う）。
- 敵: 月の砂の這うもの・殻を背負った月の兎・欠けた光の群れ・時の残像（倒した敵が数秒前の姿で一度だけ立ち上がる）など、区画ごとに 3 種（深淵と同じく三段の姿）。
- 装備: 03 の 12.2 の表を今の階級と曲線に直して作る（形は一品一案、ラフ 3 案から）。月の心核は神器の素材。
- 伝承: 前の自分の記憶の断片（12）。集めると見る者の正体と、核が時間を閉じた理由が分かる。
- マルチ: 区画の進みはパーティで共有（深淵と同じ）。月の一日は世界で一つ。

## 4.1 できたもの（作る順の 1）

- ディメンション `skyabyss:moon`（data/skyabyss/dimension*/moon.json、バイオーム `skyabyss:moon`「月の面」）。地面は平らな月の砂（上面 y 11）。着く所のまわり 72 に大小 26 のクレーター（底は暗い玄武岩、縁は盛り上がる。`MoonWorld.build`、一度だけ）。
- 空（`story/ch6/client/MoonClient`）: 真っ黒な空に瞬く星 1800、北北西の高い空（仰角 34 度）に地上の大陸（旅の地図の絵から作る `tools/gen/world/gen_moon_earth.py` → textures/environment/moon_earth.png。雲・球の陰・大気の輪）。雲なし、霧は闇。
- 月の一日と位相（`MoonClock`）: 月の一日 = 24000 tick（実時間 20 分）、新月・上弦・満月・下弦を 5 分ずつ。変わると月にいる人へ上の帯で位相の名と一言。開発用のずれ（`clockOffset`）で位相の頭へ進められる。
- 軽い重さ（`MoonGravity`）: 月にいる生き物に、重さ x0.4・跳び +40%・落ちても平気な高さ +8。出ると外す。
- 門（`MoonGate`）: 都の大鐘楼の鐘の間の床の天然磁石（都の設計図の印 `moon_gate`、まわりに魂の灯り 4）。天の鍵をそろえ「近づく月」を終えた人が右クリックすると、光の柱が 2 秒立って月の着く所へ（合図 `moon_gate`）。足りないときは何が足りないかを一言。月の着く所の帰りの天然磁石で門のそばへ戻る。
- メイン「月へ」（`main_moon`）: 「近づく月」が済むと始まり、鐘楼で天の鍵を掲げて月に立つまで（区画ができたら段を足す）。
- 開発用: `/skyabyss moonworld enter | leave | gate | phase [0〜3]`。自己テスト `moon world`。撮影 `tools/shots/moon_gate.txt`。
- 都の門は、新しく建てた都にだけある（前の版で建った都には印がない）。

## 4.3 区画 1「新月の谷」（作る順の 2。最初に通しで作る区画）

- 形: 着く所から南へ下る、長さ 160・幅 60 ほどの谷。両側は暗い玄武岩の崖（縦の層: 下が玄武岩、上が凝灰岩と月の砂）、谷底は月の砂と割れた岩の尖り。谷の真ん中を、底の見えない裂け目が横切る（影の橋で渡る）。
- 野営（谷の入口の岩陰）: 前のループの自分（一人目）・帰りの台・星の溜まり（星術を覚える）・寝床と荷・灯り。敵は湧かない。
- 探す場所 3（それぞれ印の台に「星の欠片」。三つで谷の奥の門が開く）:
  1. **影の橋**: 裂け目の上に、暗がりにだけ現れる黒い硝子の橋。星灯りで照らすと消えるので、照らす所を選んで渡る。
  2. **鏡の窪**: 窪みの縁の鏡の石を回して、星の光を真ん中の台に集める（三つの石。合うと台が開く）。
  3. **落ちた星の穴**: 星が落ちた深い穴。殻背の兎の巣を払い、穴の底の欠片を取る。
- 敵 3 種（深淵と同じく三段の姿。数字は 36 の 4.2 の曲線を延ばす）:
  - **砂這い**（月の砂に潜る這うもの）: 砂の下を進み、足もとから跳び出して噛む。潜っている間は砂が盛り上がる（予告）。
  - **殻背の兎**（岩の殻を背負う月の兎）: 軽い重さで高く跳び、上から落ちて殻で押し潰す（落ちる所に影の円の予告）。群れで巣を守る。
  - **影の綴じ手**（暗がりに住む細い人影）: 光の中では見えず、暗がりから腕を伸ばして引き寄せる。星灯りの中に引き出すと姿を見せ、斬れる。
- 区画の主 **「影抱き」**（新月の主）: 月の岩と影でできた大きなもの。影に潜って移り（床の影が走る予告）、暗がりから腕で掴む・影を投げる・影の波。段 2 から自分の分身を影に置く。星灯りの中に引き出すと体が固まり、斬れる。主の間は丸い窪み、まわりに灯りの台（星灯りが要る所）。
- 前のループの自分（一人目）: 顔を隠した旅人（今の主人公と同じ「初めの旅装」が月の砂で色あせた姿）。谷で何度も止まり、ここで待っていた。話すと前のループの記憶の断片 1 と、谷の探し方。主を倒すと核の間で会う約束をして消える。
