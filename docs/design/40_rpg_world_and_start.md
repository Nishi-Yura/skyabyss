## 0. 試遊の声（この書類が答えるもの）

- 全体に眠い。作業になる。当てた手ごたえがない。
- はじめが難しい。食べ物・武器・店に何があるかの説明がない。
- 文で説明しすぎる。試練が分かりにくい。
- マインクラフトと混ぜることは全部やめる。地形・生物群系・構造物は自由にいじってよい。地図は本物の地図のようにしてよい。

## 1. 手本にしたもの

- **Wynncraft**: 始まりは専用の小さな場所（ラグニの外れ）で、導入の一本道（王の募兵）を通って最初の町ラグニへ入る。導入が終わるとその場所には戻れない。ラグニのまわりには一番弱い敵、町の中には小さなクエストが集まる。世界は手作りの一枚の地図で、場所ごとに目安のレベルが書いてあり、町どうしは道（エメラルドの道）でつながる。
- **ファイナルファンタジー XIV**: はじめの数時間は、大きな導入として作られている（町を巡って施設を一つずつ使う。迷わないよう地図とクエストの種類を最初に教える）。
- 共通して言えること: **はじめの一時間は「迷わない一本道」**、**説明は文ではなく、触ってすぐ結果が出ること**、**町のすぐ外に、勝てる敵**。

## 2. 遊び方の決まり（完全な RPG）

ユーザーの言葉: 「アドベンチャーでもいい。もう壊す必要も作る必要もない」「アイテムドロップもさせなくていい」「耐久値減らす必要もない」「完全 RPG」。

| 決まり | 中身 | 切り替え（ゲームルール） |
| --- | --- | --- |
| アドベンチャー | この作品の世界のプレイヤーは、アドベンチャーで遊ぶ（ブロックを壊さない・置かない）。サバイバルで入った人は、入ったときにアドベンチャーへ。クリエイティブ・観戦者はそのまま | `skyabyssAdventure`（既定 true） |
| すり減らない | 武器・防具・道具の耐久値は減らない | `skyabyssNoWear`（既定 true） |
| 落とさない | 倒れても持ち物と経験値を落とさない（墓は作らない）。倒れた罰は「休み場へ戻る」だけ | `skyabyssDeathMode`（既定 2 = keep。墓の型は 0） |

- 敵が落とす品はそのまま（Wynncraft と同じく、倒した敵から素材と装備が出る）。
- 手に入れ方は **店で買う・敵から出る・頼みの報酬・宝箱・採集の場（右クリックで採れる場所）**。木を切る・掘る・作業台で作る・かまどで焼く、を前提にしない。
- 今のクエストのうち、マインクラフトの採集と作業に頼る目的（38 個。丸太・鉄の剣・盾・鉄の防具・舟・ダイヤモンド・薬・黒曜石・パン・糸・鱈・麦・石炭・銅・溶岩・蜂蜜・花・水・蝋燭など）は、次の決まりで置き換える:
  - **章の主の流れの装備**（鉄の剣・盾・鉄の防具・ダイヤモンドの装備）: 鍛冶屋が渡す（頼みの報酬）か、店で買う。目的は「受け取る・身に着ける」。
  - **素材**（糸・鱈・麦・石炭・銅・溶岩・骨・蜂蜜・花）: その土地の敵が落とすか、採集の場で採る。名前もこの作品の素材へ。
  - **道具**（舟・羅針盤・地図・灯り・薬）: 店で買うか、頼みの報酬。
  - **日替わり・週替わりの頼み**（薪・羊・真珠・深淵の品）: 敵の落とす品を納める形へ。
- **今の形（2026-10-25 夜）**: 目的の文は「道具屋・薬師で手に入れる」に書き換えた（42 の 4 章）。その代わり、大陸には洞窟が無く地下の鉱石が掘れないので、目的の品を**道具屋が売る**（章ごとに並ぶ。一章: 鉄の剣・盾・鉄の防具・鉄・骨・蝋燭・蜂蜜、二章: 舟・羅針盤・地図・糸、三章: 銅・避雷針・ダイヤ・ダイヤの剣と胸当て、四章: 石炭・麦・溶鉱炉・溶岩の塊・マグマクリーム、五章: 黒曜石・ブレイズロッド）。都と土地の町の道具屋のどちらでも買える。木・花・水・魚・羊は採集・釣り・野の動物でそろう。

## 3. 世界の作り — 一枚の大陸（00 の 272 = A）

- 世界は 4,000 × 4,000 ほどの一枚の大陸。外は海と雲の壁で、その先へは行けない。
- 地形は、手で描いた**高さの図**と**土地の図**（生物群系）から作る。どの世界でも同じ形。マインクラフトの村・砦・ランダムの構造物は出さない。
- 都は大陸の西寄り。北の丘陵 = 岩鯨の土地、東の海辺 = 潮殻の土地、西の嵐の高地 = 雷翼の土地、南の灰の荒野 = 余燼の土地。都の地下に深淵の入口。
- 土地ごとに小さな町（宿・店・依頼の板）が一つずつ。都とは道でつながり、道ぞいに休み場と目安のレベルの碑。
- 地図（M）は描いた地図（山・川・道・町の絵と、目安のレベル）。

### 作る順

1. 大陸の見取り図の案を 3 つ（土地の並び・町と道・目安のレベル）を描いて選ぶ。絵は `docs/review/continent_roughs/`（描くのは `tools/rough/continent_layouts.py`）。案は A 十字の大陸・B 渦の旅路・C 内海の大陸。**C に決まった**（00 の 274）。形（岬・湾・島）と土地の中のムラ（丘陵の湖や林、浜の湿地など）はもっと工夫する。あとで土地を足すときは外の海に足す（遊んだ所の地形は世界に残るので、今の大陸の形は変えない）。そのための海を空けておく。
2. 高さの図と土地の図を作る生成器（tools/gen/world/）と、その図から地形を作るワールドの種類（「天と淵の大陸」）。**できた**:
   - 生成器 `tools/gen/world/gen_continent.py`（見取り図の値は `tools/lib/continent_layout.py`）が `data/skyabyss/continent/` に高さの図・土地の図（1 升 4 ブロック、1000 × 1000 升）と座標の表 `layout.json` を書く。
   - ワールドの種類 `skyabyss:continent`（`world/continent/`）。図のとおりに地面を積み、上の数段を土地ごとの土にし、海の高さ（63）まで水を張る。洞窟とマインクラフトの構造物は出さない。木・草・鉱石は生物群系のとおり。図の外は深い海。
   - 一人で遊ぶときは、新しい世界を作る画面の既定の種類が「天と淵の大陸」。専用サーバーは `server.properties` に `level-type=skyabyss\:continent`。
   - 土地と生物群系: 都のまわり = 平原と森、外れの谷 = 草地、岩鯨の丘陵 = 平原・針葉樹・吹きさらしの丘、潮の浜 = 砂浜とサバンナ、嵐の高地 = 吹きさらしの丘・石の峰・雪の斜面、灰の荒野 = 荒野（赤い粘土の縞）と火山（玄武岩）、内海 = ぬるい海。
3. 都・章の跡地・祠・深淵の入口を、決まった座標へ置き直す。**都・野営地・四つの跡地はできた**: 大陸の世界では、野営地ははじまりの場所のそば、都は図の都の場所（Y 72 の平らな所）、跡地は図の場所のまわり 160 の中で合う地形を探し、なければそこに形を作る（`SiteFinder`・`ChapterGrounds.findNear`）。
4. 土地ごとの町と道、目安のレベルの碑。**道はできた**（`layout.json` の道を、曲線にして幅 5 の土の道として地形に刻む。縁は荒れた土と砂利）。**町もできた**:
   - 鯨見の町（岩鯨の丘陵）・汐守の港（潮の浜）・風待の里（嵐の高地）・灰炉の村（灰の荒野）。一辺 41 の町に、広場（井戸・依頼の板・街灯 4）・宿・店・家二つと、十字の道。土地ごとに色を変える（針葉樹と丸石／白樺と砂岩／石煉瓦と錆びた銅／泥煉瓦と黒い石）。
   - 部品は `tools/gen/world/gen_region_towns.py` が書く `data/skyabyss/opening/town_<土地>.json`。大陸の世界でだけ、場所を決めるときに足し、野営地や都と同じく少しずつ建てる（`world/continent/ContinentTowns`。壊せない）。
   - 宿の主人と道具屋が立つ（都の係の人の仕組み。近くに人がいれば立たせ続ける）。旅の地図に町の印と名前。
   - 広場に言伝ての板（日替わり・週替わりの頼み。都の板と同じもの）と、町の名前と目安のレベルの札。市の屋台・腰かけ・花・道の街灯。
   - 休み場: 大陸の地上で倒れ、寝台などの戻り場所を持っていない人は、倒れた所にいちばん近い休み場（町の井戸の脇・都・野営地）で目覚める（`ContinentRespawn`）。
   - 町の人の会話と頼み（土地の町に二人ずつ、近くの見どころへ行く頼み。42 の 4）。これから: その土地の敵と採集の場を使う頼みを増やす。
5. 描いた地図（M）。**できた**: 大陸の世界では、旅の地図の丸い盤に描いた大陸の絵（`textures/gui/map/continent.png`。生成器が地形の図から描く）を敷き、引いたとき（半径 700〜3,200）は土地の名前と目安のレベルを書く。外の海は透けて盤になじむ。世界の縁は一辺 4,400。

## 4. はじめの一時間（00 の 273 = A+B）

1. **外れの一本道（約 10 分）**: 目覚めの野営地から都の門まで、閉じた小さな土地。道ぞいに一つずつ: 弱い敵で戦い方 → 焚き火で食べ物 → 技を一つ覚えて撃つ → 宿り木の祠で回復。道の終わり（門の前）で岩鯨が空を渡る一場面。導入のあと外れには戻らない。
2. **都の町めぐり（約 10 分）**: 案内人の町めぐりで、鍛冶屋（武器を一つもらう）→ 宿（食べ物）→ 道具屋（一つ買う）→ 組合（依頼の板で最初の頼み）→ 門の外（弱い敵を三体）。各手順で小さな報酬。終わると一章の主の流れへ。
   - **できた（最初の形）**: 初めて都に入ると、案内の灯りの道で 鍛冶場 → 宿 → 道具屋 → 組合 の順に連れて回る（`facility/TownTour`）。戸に着くたびに鐘銭（3・3・5・5）、宿ではパン 3。帯の文は一行（「町を回ろう 1/4: 鍛冶場 へ」）。終わると「門の外の弱い敵で、腕を試そう」。一章より先へ進んでいる人はめぐらない。
   - **道の終わりの岩鯨（できた）**: 大陸の世界では、最初の空の影（巨神の通過）は、誰かが都の門の前（都の中心から 130）に着いたときに起こす。誰も来ないまま予定より一日遅れたら、いつもどおり。
   - **外れの一本道の道ぞい（できた・最初の形）**: 野営地から都への道の 4 割の所に「旅の休み場」（灯した焚き火・腰かけ・パンと焼き魚の樽・札「樽の糧を食べよう」）、7 割の所に「宿り木の祠」（そばにいると傷が癒える。札「そばで傷が癒える」）。道の脇に置き、巨大な足跡のそばは避ける（`world/continent/ContinentOutskirts`。部品は `gen_region_towns.py`）。弱い敵で戦い方を覚えるのは、外れの谷の敵の弱さ（×0.45）で受ける。
   - これから: 技を一つ覚えて撃つ所（今は都の訓練場の師範）を道ぞいへ。

共通:
- 目覚めたときに、その章の最初の武器・簡単な防具・食べ物 10 を持っている。**できた**: 初めて入った人に一度だけ、石の剣・革の防具四つ（空いている所は身に着ける）・パン 10（`RpgRules.starterKit`）。
- 都のまわりと最初の土地の敵は弱い（二〜三回で倒れる。こちらは十回ほど受けても倒れない）。**できた**: 大陸の地上のマインクラフトの敵は、現れた場所の土地で体力と攻撃が変わる（`ContinentDanger`。土地の図 `region.bin`）。都のまわり ×0.55 / ×0.5、外れの谷 ×0.45 / ×0.4、岩鯨の丘陵 ×1、潮の浜 ×1.3 / ×1.25、嵐の高地 ×1.7 / ×1.5、灰の荒野 ×2.1 / ×1.8。この作品の敵は変えない。
- 説明は触って分かる形（やってみる → すぐ結果）。文の札は一行まで。
- 店の中身は、店の前に並んだ品で見せる。

## 5. 眠さ・作業感への手当て（B3。世界とはじめの流れが決まったあとに詳しく）

- 一章あたりの「やること」を減らし、山場（巨神・中ボス・心臓）を早く・多く。素材集めの回数を半分に。
- 試練は数を減らして作り込む（各巨神 6 → 3。見て分かる仕掛け・文の札は一行まで）。**数は減らさない（各巨神 6 つのまま。00 の 275）**。代わりに、闘の試練の中で中ボスが出る形にして、中ボスだけの段はなくす（順路は 歩 → 智 → 闘（中に中ボス）→ 心臓）。闘の試練の作り直しは 32 に書く。
- 戦いの手ごたえ: 傷の数字（入れた）、当てたときの止め（ほんの一瞬の止まり）・音・敵のよろけ。

## 6. 2026-10-25 昼の作り込み（ユーザーの声:「チュートリアルは別の場所に」「大きな地図が平原ばかりで何もない。Wynncraft を手本に作り込む」「地図は円に切らなくていい」）

- **はじまりの島**: 外れの一本道は、大陸の南西の沖の島（はじまりの島）へ移した。野営地（目覚め）→ 足跡 → 旅の休み場 → 宿り木の祠 → 船着き場。桟橋の先に立つと、渡し船で鐘の都の南の門の外へ渡る（一度きり。島へ戻る船は無い）。島を出る前に倒れたら島の野営地か祠で、出たあとは大陸の休み場で目覚める（`ContinentOutskirts`・`ContinentRespawn`）。島と大陸のあいだは 370 ほどの海。
- **見どころ**: 土地ごとに Wynncraft のような見どころを 62 か所（`tools/gen/world/gen_continent_pois.py` → `continent/pois.json`、部品 `opening/poi_*.json`）。都のまわり = 風車・畑と納屋・見張りの塔・道ばたの祠、岩鯨の丘陵 = 巨神の肋骨・崩れた僧院・石の輪、潮の浜 = 灯台・打ち上げられた船・漁師の小屋、嵐の高地 = 風の民の門・避雷の塔・山小屋、灰の荒野 = 焼けた砦・炉の跡・玄武岩の門、どこにでも = 野盗の野営・崩れた家。人が 240 まで近づいたら建てる（`ContinentPois`）。宝箱（鐘銭・糧・土地の粉）、野盗の野営は人が近づくと野盗が出る（8 分おき）。建った見どころは地図に印（指すと名前）。
- **道しるべ**: 長い道の中ほどに、両端の行き先と道のりを書いた札。
- **古い塚**（小さな迷宮）: 土と石の小山に入る通路と石室。宝箱と、近づくと骨の兵。**小さな集落**: 土地の作りの家三つ・井戸・畑。**伝承の碑**: 九種類の見どころに、由来を三行で刻んだ碑（読むと伝承の碑文に数える）。見どころは全部で 75。
- **内海の渡し船**: 都の側の港（都から道がある）と汐守の港に船着き場。桟橋の先に立つと向こう岸へ（何度でも。`ContinentFerries`）。
- **はじまりの島の最初の戦い**: 島の道の脇に小さな野盗の野営（近づくと野盗。島の敵は弱い）。
- **地形**: 野と丘陵の起伏を大きくし、岩の小山を足した。地形の細かな揺らぎを、まわりの傾きからなめらかに決めるようにした（前は 4 ブロックの升ごとに切り替わり、四角い穴ができていた）。
- **町**: 入口の門（柱と梁と吊り灯り）、二階建ての宿、煙突、土地の木、畑。灯りは門と広場だけ（並びをそろえた）。
- **都**: 明るさで足していた灯りの柱をやめ、大通りの決まった並びと戸の上の灯りだけにした。鍛冶場の口は正面（南の大きく開いた面）にまとめ、横の口をなくした。
- **地図**: 大陸の世界では、丸く切らずに枠いっぱいの四角に描く。
- **見どころを足した（夕方）**: 古い坑道（木枠の小屋から階段で下る掘り場。中に骨の兵）・崩れた塔（上が欠けた丸い石の塔、はしごで上の床へ）・旅の一座の野営（幌馬車と天幕）・丘の墓所（石の柵・墓石・礼拝堂の跡。骨の兵）・大樹の小屋（太い幹のはしごで樹上の床と小屋へ）。見どころどうしの間を 170 から 140 に詰め、全部で 98。古い塚のまわりに立石を立て、遠くから塚とわかるようにした。
- **地図に見どころを全部出す**: Wynncraft の地図のように、行く前から見どころの印と名前を出す（建ったものは建った位置）。半径 650 より引くと小さな点だけ（指すと名前）、枠の外の見どころは縁に寄せない。
- **見どころの下の均し**: 地上に出る所だけを丸く均し、まわり 6 ブロックでなじませる（前は四角く均して坂に段々の台地ができ、坑道は地下の掘り場まで均していた）。
- **野の飾り**（`ContinentScatter`）: 生物群系の木や草のあとに、チャンクごとに決まった乱数で、野 = 岩・茂み・崩れた石垣、林 = 倒木（苔やきのこ）・苔むした岩、丘陵 = 岩・岩の柱、荒野 = 赤い岩の柱・玄武岩の柱、砂地 = 砂岩の岩、沼 = 倒れたマングローブ。町・跡地・見どころ・船着き場・道・はじまりの島には置かない。
- **土地の町を広げた**: 範囲を 41 から 57 四方へ。外の輪に家を足し（どの町も 13 軒ほど）、町ごとに名物: 鯨見 = 鐘のある見張りの塔と北の門の鯨の骨のアーチ、汐守 = 縞の灯台と網を干す棚、風待 = 風車二基と風見の旗、灰炉 = 黒い石の低い囲い（門に篝火）と三方の開いた鍛冶場。宿の二階の寝台が頭だけだったのを直した。
- **土地の町を村から町へ（ユーザーの声「各バイオームの町をもっと豪華に。Wynncraft を手本に」）**: 81 × 81 に作り直した（`tools/gen/world/town_arch.py`）。十字の大通りと環状の道、八角の広場（真ん中に土地の記念碑: 鯨見 = 鯨の骨の弧の泉、汐守 = 噴水、風待 = 避雷の棒の立つ風の柱、灰炉 = 炉の碑と篝火）と市の屋台四つ。四つの隅に 7 区画ずつ、石の土台・木組みの柱と梁・二〜三階・切妻か胸壁の平屋根・煙突・中の家具。土地ごとの囲い（鯨見 = 丸太の柵、汐守 = 白い低い壁、風待・灰炉 = 石の城壁）と角の塔、四つの門楼（旗と吊り灯り）。角の大きな区画に名物（見張りの塔・灯台・網の棚・風車・鍛冶場）と畑・庭。灯りは大通りの 8 ごと・環の角・広場の角・門楼だけ。宿の主人・道具屋・宿の寝台・言伝ての板の印はそのまま。目覚める所は広場（stand）。
- **桟橋を水の上まで**: 船着き場（島と内海）の置き場が岸から離れると桟橋が陸で終わっていた。建てたあと、桟橋を水の上へ 5 ブロック出るまで延ばし（最長 48。杭・柵・先の灯り）、その先を渡し船に乗る所にした（`ContinentPiers`）。はじまりの島にも野の飾りを置く（野営地と船着き場のまわりを除く）。
- **洞窟の小さな迷宮**（岩の口の洞窟）: 岩の小山の口から階段で下り、地下の広間三つを曲がった通路でつなぐ。中ほどの広間に骨の兵、奥の広間に宝箱。野・丘陵・高地に一つずつ（見どころは全部で 100）。
- **道しるべを増やした**: 道の上の都・町・跡地を節にして、節を出たところ（都 150・町 64・跡地 190）と長い区間の中ほどに一本ずつ（近すぎるものは一本に。全部で 16）。札は「この先の節と道のり / 来た節と道のり」で、途中の町も行き先に書く。地図の印は戦いの場（刀）・塔・集落（家）・そのほか（碑）で分けた。
- **小さかった見どころを作り直した**: 小さな集落・畑と納屋・漁師の小屋・山小屋を町と同じ木組みの家で（土地の色）、炉の跡を崩れた黒い石の鍛冶場と高い煙突に、道ばたの祠を屋根と灯籠と腰かけのある祠に。
- **発見（Wynncraft の Discovery）**: 見どころに初めて 20 まで近づくと、名前と「見どころを見つけた（n / 100）」の札、土地の経験値（野 20・島 10・岩鯨 30・潮殻 45・雷翼 65・余燼 85）。人ごとに覚え、倒れても消えない。地図では見つけていない見どころを薄く描き、名前に「（未発見）」。地図の印の上限を 96 から 256 へ（見どころを足して巨神や祠の印が切れていた）。見どころの印は最後に足す。
- **土地と町の名前の札**（`ContinentAreas`）: 町（中心から 45 以内、出るのは 60 より外）・鐘の都（170 / 200）・土地（鐘の野・はじまりの島・岩鯨の丘陵・潮の浜・嵐の高地・灰の荒野）に入ると、名前と「目安 Lv」の札（町は土地の名前）。境目で何度も出ないよう、同じ所が 2 秒続いたら変わったとみなす。
- **見どころの頭**: 敵の出る見どころ（野盗の野営・焼けた砦 = 野盗の頭、塚・坑道・洞窟・墓所 = 骨の番人。鉄の兜と剣）に、名札つきで体力 2.5 倍の頭が一体。倒すと土地の粉（野は岩）一つと鐘銭 4〜8 を必ず落とす。はじまりの島には出さない。
- **大陸の世界での不具合直し（自己テストを大陸でも全部回して見つけたもの）**: 建物の床が土の道や耕地に掛かると、その道を消して 1 段の隙間ができていた（土に戻すように）。はじまりの島の道のまわり 90 には野の飾りを置かない（足跡の脇に茂みが残っていた）。土地の敵の強さは、空の上と地の底（自然には湧かない所）では掛けない。自己テストは大陸の世界でも通るようにした（出現地点のチャンクを待つ・跡地の方位の帯を見ない・遠い所の試しは都から・試し建ては都の南の野）。
- **倒れても消えない一度きりの印**（`util/LifeKeep`）: 人の印の多くを、倒れると消える所に覚えていた。倒れて入り直すと、はじめの持ち物（石の剣・革の防具・パン）をもう一度もらえ、町めぐりの鐘銭も二度、暖石・潮見の殻も二度。大陸では「渡し船で都へ渡った」が消えて、はじまりの島で目覚め直すおそれがあった。倒れたときに一度きりの印（12 種）を新しい体へ写す（待ち時間など、その命の間だけの値は写さない）。

## 7. はじまりの島の谷（2026-10-26。試遊の声「始まりをもっと作り込んで」「道がおかしいときがある」「道に巨大な足跡があると邪魔」「道をそれても行けてしまう」「島から都へ急に行って話がない」。Wynncraft の King's Recruit を手本に）

- **地形**（`tools/gen/world/gen_continent.py` の `shape_island`、見取り図 `tools/lib/continent_layout.py` の `island_plan`）: 島の道は尾根に挟まれた谷を通る（谷底の半幅 7、崖は谷底から 12〜24 上がる。北ほど高い）。道の脇に開けた所（野営地・足跡の窪地・野盗の野営・休み場・祠・船着き場）と、道とつなぐ首。尾根は林。海ぎわも尾根のまま海へ落ち、歩ける浜は野営地と船着き場だけ。島の場所は `layout.json` の `island`（`ContinentLayout.island`）。
- **足跡**: 島では道の脇の窪地の決まった二か所（道から 45 以上）。部品は古く草に覆われた浅い足形 `footprint_island`（縁の盛り土を低く、岩と倒木は少なく、底は苔と草と泥と雨水。`tools/rough/opening_sites.py` の `footprint_island`）。
- **道の均し**（`world/continent/ContinentRoads`、全部の道）: 道の線に沿って高さを平均し（前後 9 点）、勾配を 1 ブロックあたり 0.34 までにし、道の幅（3.6）はその高さに、外へ 9 まで元の地形へなじませる（切り通しと盛り土）。道が合わさる所は近い点の高さを重みで平均する。水の上はならさない。
- **崖の面**: 安山岩の筋・凝灰岩・林の崖には苔のまだら。地上の水の湧き口（崖から垂れる水）は置かない。
- **島の道の目的**（`world/continent/IslandTrail`。人ごと、倒れても残る）: 野営地の帳面 → 足跡の窪地を見る → 峠の野盗を 3 人退ける（足りなければ野営に出る。退けると峠の柵が開く。柵は世界に一つ）→ 休み場の焚き火で休む → 宿り木の祠に祈る（ここで目覚める。技の画面の手がかり）→ 船着き場の渡し守と話す。
- **渡し守**（`guest_island_ferryman`。汐守の渡し守と同じ絵）: 島の道を済ませた人だけ乗せる（会話の印 `island_ready`）。まだの人には「祠に祈ってから来な」「歩くうちに名前が戻る。戻らないものもある」。
- **渡りの場面** `ferry_crossing`（22 秒）: 海の上の舟に渡し守と二人。台詞は渡し守（「そういう客は、ときどき乗せる」「鐘が鳴るうちは、都は落ちない」「漕いでいるのが誰か、は聞かないでくれ」）・主人公（「前にも、この海を渡った気がする」）・天の声（「鐘の方へ。あなたを覚えている人が、そこにいる」）。12 秒めに遠い鐘。終わると鐘の都の南の門の外（「振り返ると、渡し守の舟はもう見えなかった」）→ 都を見上げる場面 `capital_arrival`（8 秒。「ここが、鐘の都……」「大鐘楼の足もとに、語り部がいる」）。
- **物語の言い方を大陸に揃えた**: 「鐘の宿り」を「鐘の都」に、一章の「煙の立つ方へ」を「鐘の都の語り部を訪ねよう」に、イサナの居場所を鯨見の町の見張り台に、二〜四章の報告の「村へ戻る」を「都へ戻る」に、語り部の昔話の「村」を「都」に。
- 自己テスト `island trail`（道の段が 3 か所以下・足跡が道から離れている・島の目的の順・野盗で柵が開く・祠で渡し守の印・渡ると目的が消える）。撮影は `tools/shots/island_v2.txt`。
- **土地の町に初めて着く場面** `town_first_<町>`（9 秒。`ContinentAreas` が初めて着いたときに起こす）: 本人の目から町の上へ上がって広場と町並みを見渡し、目に戻る。主人公の一言と天の声（鯨見「歌を追う者が、この町の見張り台にいる」、汐守「潮の引く日を待ちなさい。島は、寄ってくる」、風待「雷の鳴る峰へ。翼は、高い所へ降りる」、灰炉「山は眠っていない。息をしている」）。
