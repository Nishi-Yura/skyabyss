## 0. 試遊の声（この書類が答えるもの）

- 全体に眠い。作業になる。当てた手ごたえがない。
- はじめが難しい。食べ物・武器・店に何があるかの説明がない。
- 文で説明しすぎる。試練が分かりにくい。
- マインクラフトと混ぜることは全部やめる。地形・生物群系・構造物は自由にいじってよい。地図は本物の地図のようにしてよい。

## 1. 手本にしたもの

- **Wynncraft**: 始まりは専用の小さな場所（ラグニの外れ）で、導入の一本道（王の募兵）を通って最初の町ラグニへ入る。導入が終わるとその場所には戻れない。ラグニのまわりには一番弱い敵、町の中には小さなクエストが集まる。世界は手作りの一枚の地図で、場所ごとに目安のレベルが書いてあり、町どうしは道（エメラルドの道）でつながる。
- **ファイナルファンタジー XIV**: はじめの数時間は、大きな導入として作られている（町を巡って施設を一つずつ使う。迷わないよう地図とクエストの種類を最初に教える）。
- 共通して言えること: **はじめの一時間は「迷わない一本道」**、**説明は文ではなく、触ってすぐ結果が出ること**、**町のすぐ外に、勝てる敵**。

## 2. 遊び方の決まり（完全な RPG）

ユーザーの言葉: 「アドベンチャーでもいい。もう壊す必要も作る必要もない」「アイテムドロップもさせなくていい」「耐久値減らす必要もない」「完全 RPG」。

| 決まり | 中身 | 切り替え（ゲームルール） |
| --- | --- | --- |
| アドベンチャー | この作品の世界のプレイヤーは、アドベンチャーで遊ぶ（ブロックを壊さない・置かない）。サバイバルで入った人は、入ったときにアドベンチャーへ。クリエイティブ・観戦者はそのまま | `skyabyssAdventure`（既定 true） |
| すり減らない | 武器・防具・道具の耐久値は減らない | `skyabyssNoWear`（既定 true） |
| 落とさない | 倒れても持ち物と経験値を落とさない（墓は作らない）。倒れた罰は「休み場へ戻る」だけ | `skyabyssKeepOnDeath`（既定 true） |

- 敵が落とす品はそのまま（Wynncraft と同じく、倒した敵から素材と装備が出る）。
- 手に入れ方は **店で買う・敵から出る・頼みの報酬・宝箱・採集の場（右クリックで採れる場所）**。木を切る・掘る・作業台で作る・かまどで焼く、を前提にしない。
- 今のクエストのうち、マインクラフトの採集と作業に頼る目的（38 個。丸太・鉄の剣・盾・鉄の防具・舟・ダイヤモンド・薬・黒曜石・パン・糸・鱈・麦・石炭・銅・溶岩・蜂蜜・花・水・蝋燭など）は、次の決まりで置き換える:
  - **章の主の流れの装備**（鉄の剣・盾・鉄の防具・ダイヤモンドの装備）: 鍛冶屋が渡す（頼みの報酬）か、店で買う。目的は「受け取る・身に着ける」。
  - **素材**（糸・鱈・麦・石炭・銅・溶岩・骨・蜂蜜・花）: その土地の敵が落とすか、採集の場で採る。名前もこの作品の素材へ。
  - **道具**（舟・羅針盤・地図・灯り・薬）: 店で買うか、頼みの報酬。
  - **日替わり・週替わりの頼み**（薪・羊・真珠・深淵の品）: 敵の落とす品を納める形へ。

## 3. 世界の作り — 一枚の大陸（00 の 272 = A）

- 世界は 4,000 × 4,000 ほどの一枚の大陸。外は海と雲の壁で、その先へは行けない。
- 地形は、手で描いた**高さの図**と**土地の図**（生物群系）から作る。どの世界でも同じ形。マインクラフトの村・砦・ランダムの構造物は出さない。
- 都は大陸の西寄り。北の丘陵 = 岩鯨の土地、東の海辺 = 潮殻の土地、西の嵐の高地 = 雷翼の土地、南の灰の荒野 = 余燼の土地。都の地下に深淵の入口。
- 土地ごとに小さな町（宿・店・依頼の板）が一つずつ。都とは道でつながり、道ぞいに休み場と目安のレベルの碑。
- 地図（M）は描いた地図（山・川・道・町の絵と、目安のレベル）。

### 作る順

1. 大陸の見取り図の案を 3 つ（土地の並び・町と道・目安のレベル）を描いて選ぶ。
2. 高さの図と土地の図を作る生成器（tools/gen/world/）と、その図から地形を作るワールドの種類（「天と淵の大陸」）。
3. 都・章の跡地・祠・深淵の入口を、決まった座標へ置き直す。
4. 土地ごとの町と道、目安のレベルの碑。
5. 描いた地図（M）。

## 4. はじめの一時間（00 の 273 = A+B）

1. **外れの一本道（約 10 分）**: 目覚めの野営地から都の門まで、閉じた小さな土地。道ぞいに一つずつ: 弱い敵で戦い方 → 焚き火で食べ物 → 技を一つ覚えて撃つ → 宿り木の祠で回復。道の終わり（門の前）で岩鯨が空を渡る一場面。導入のあと外れには戻らない。
2. **都の町めぐり（約 10 分）**: 案内人の町めぐりで、鍛冶屋（武器を一つもらう）→ 宿（食べ物）→ 道具屋（一つ買う）→ 組合（依頼の板で最初の頼み）→ 門の外（弱い敵を三体）。各手順で小さな報酬。終わると一章の主の流れへ。

共通:
- 目覚めたときに、その章の最初の武器・簡単な防具・食べ物 10 を持っている。
- 都のまわりと最初の土地の敵は弱い（二〜三回で倒れる。こちらは十回ほど受けても倒れない）。
- 説明は触って分かる形（やってみる → すぐ結果）。文の札は一行まで。
- 店の中身は、店の前に並んだ品で見せる。

## 5. 眠さ・作業感への手当て（B3。世界とはじめの流れが決まったあとに詳しく）

- 一章あたりの「やること」を減らし、山場（巨神・中ボス・心臓）を早く・多く。素材集めの回数を半分に。
- 試練は数を減らして作り込む（各巨神 6 → 3。見て分かる仕掛け・文の札は一行まで）。
- 戦いの手ごたえ: 傷の数字（入れた）、当てたときの止め（ほんの一瞬の止まり）・音・敵のよろけ。
