# 38 乗り物（笛・厩舎）

乗り物の現在の仕様。実装は `mount/`・`client/mount/`、都の建物は `tools/capital/facilities.py` の `stable`。

## 1. 遊び方

- **笛（乗り笛）**（`skyabyss:mount_whistle`。巨神の子を呼ぶ「呼び笛」とは別の名、一人一つ）: 右クリックで自分の乗り物が目の前に来る。もう一度で帰る。ワールドには保存されず、帰す・ログアウト・96 ブロック以上離れる・持ち主の死で消える。旅の番（止まり木の番）から受け取る（なくしたらまた）。都の町めぐりでは旅の番の所で渡す。
- **乗る**: 持ち主だけが乗れる（右クリック）。馬のように人が操る。飼いならし・繁殖・持ち物はない。落下で傷つかない。敵・火・溶岩では傷つくが、他の人は傷つけられない。
- **呼べない所**: 巨神の背、淵（五章の坑道の下）、ボス部屋。理由が画面の下に出る。
- 乗り物の持ち主ごとの記録（買った見た目・段・今の見た目）は人ごとの保存データ（`MountData`）。

## 3. 性能の段（`MountStats`）

速さを段 1〜8、跳びを段 1〜5 まで買う（段 0 = 馬の下の方）。値段は鐘銭で 速さ 25/50/85/130/200/300/420/600、跳び 18/36/60/95/150。速さ 0.20→0.35（段 5 = 馬の最上位）→0.44（段 8）、跳び 0.50→0.90。買うと出ている乗り物にすぐ当たる。

体力は段を持たない（2026-11-02 の声「ペットの体力を増やす仕組みはいらない」「速さはもう少し速く」）: いつも 60（前の段 5）。前に買った体力の段は、入ったときに一度だけ鐘銭で返して段を 0 にする（`upgrade/PlayerUpgrade` の段 2。保存の並び `tiers[2]` は残す）。

五章・六章・飛ぶ乗り物の見た目は 2026-11-02 に選んだ（00 の 346〜348。ラフの生成 `tools/rough/lowpoly/mounts2/roughs.py`。選ばなかった案は消した）: 灯り守の大守宮（坑道の灯り番の大守宮。平たい体・吸盤の指・肩と腰と尾の先の灯り袋が光る）、星読みの大猫（夜の青の毛に星の点・房の耳・頬の襟毛・尾の先の三日月が光る）、空鱏（菱形の体と大きな翼・二つの頭びれ・尾の先の鐘の房。背は夕べの青に金の斑、腹は雲の白、翼の先が光る）。章の見方は `MountService.chapter`（四つの心臓のあとは、物語の章 五章 = 6・六章 = 7・終章を越えた = 8）。

## 4. 乗り物の店（厩舎の番は旅の番へまとめた）

- 場所: 都の東の大通りの南、薬師の店の東（x 82..93, z 6..17、戸は北）の旧厩舎の建物は、2026-11-01 から人がいない。乗り物の店は都と四つの町の旅の番（`perch_keeper`）。
- 旅の番に話しかけて「乗り物を見る・買う」で専用の画面（`MountShopScreen`）。左に見た目の一覧（持っている・値段・章の壁）と選ぶ・買う、中に今の見た目の 3D の見本、右に 3 つの段の買うボタン。
- 開発コマンド（OP）: `/skyabyss facility mount`（画面）・`mount demo`（前に七つを 3.4 ブロックおきに並べる）。撮影 `tools/shots/mounts_v2.txt`（並び・寄り・乗った姿・駆ける姿）、絵は `docs/review/mounts_v2/`（前の箱のモデルの絵は `docs/review/mounts_v2/`）。

## 5. 作り

- モデルは低ポリ（docs/design/15 の 9）。見た目ごとに `lowpoly/mount_<id>.json`・`textures/lowpoly/mount_<id>.png`（光る見た目は `_glowmask.png`）・骨だけの `geo/entity/mount_<id>_lowpoly.geo.json`・動き `animations/entity/mount_<id>.animation.json`。`LowPoly.enabled = false` のときは骨ごとの箱の `geo/entity/mount_<id>.geo.json`。描画は `MountClient.MountRenderer`（`LowPolyGeoRenderer` の派生）。
- 生成: `python -I tools/gen/mobs/mounts_lp/build_all.py [id ...]`（一体ずつ `<id>.py`、共通は `mlp.py`）。形・鞍・あぶみ・絵・骨・動きを作って入れ、比べシート `docs/review/mounts_v2/<id>_sheet.png`（四方・乗った人・寄り・歩き/駆け/跳び/待機の帯）を書き、`MountLook` の当たり・席の高さ・乗った人の脚の向きを書き換える。メッシュは閉じていて、脚・首・尾は親に沈めてある（`tools/audit/mesh_audit.py mount_ --check`）。
- 採用した案（`docs/review/roughs_mounts/`）: 角の荷獣 C 渦角の山羊（荷袋・巻いた荷・首の鈴）、灰色の鹿 A 枝角の牡鹿、大トカゲ B 帆背のトカゲ（襟・喉袋・帆、口が開く）、岩の子鯨 A 四つ足の子鯨（フジツボの石・尾びれ・首の綱）、殻の亀 A 珊瑚の丸甲亀、雷の雛 B まるまる雛（冠・翼・尾羽の雷が光る）、炉の狐 C 三尾の熾狐（尾の先・耳の内・背の割れ目が光る）。三角形は一体 2,300 から 3,400。
- 鞍は体の表面を光線で拾って沿わせる（敷き布・座・前後の山・横の垂れ・腹帯）。席は原点の真上（`MountEntity` の乗る位置は x = z = 0）で、`seat` は鞍の上面 - 1/16 ブロック。
- 乗った人の脚: 馬の「前へ投げ出す」脚では胴の太い乗り物に脚が入るので、見た目ごとの向き（`MountLook.legPitch` 前への回し・`legSpread` 外への開き、度）で置く（`mixin/MountRiderLegsMixin`、`HumanoidModel.setupAnim` の後）。向きは生成の道具が、脚の箱の標本点が体の中に入らない向きのうち好みに近いものを選ぶ。脚を下ろす向きのときは足先にあぶみを吊る。
- 動き: 待機 `idle`（息・耳・尾・飾り）、歩き `walk`、駆け `run`、跳び `jump`（宙に 3 tick いると。終わりで止まる）。歩き・駆けの脚の運びは時間でなく歩いた距離で進む（molang の `variable.mount_dist`。`MountEntity.travel` を `MountModel.applyMolangQueries` が渡す）ので、段で速さが変わっても足が滑らない。歩き → 駆けの境は 0.2 ブロック/tick。
- 自己テスト: `SKYABYSS_SELFTEST_ONLY="mount"`（買う・章の壁・呼ぶ/帰す・性能・背と淵での断り・遠くで消える・乗る・落下無効・保存）。

## 6. 飛ぶ乗り物（空鱏）

- いつから: 終章「雲海」を越えたら（巡礼者を退けて結末を選んだ人。`FinaleEnding.chosen`）店に並ぶ（00 の 349）。
- 飛び方（00 の 350）: 乗ると宙に浮き、見ている向きへ飛ぶ（上を向けば上がる・下を向けば下がる）。跳びのキーで羽ばたいて上がる。しゃがみは今までどおり降りる。地面から 40 ブロックより上へは上がらない。地面に着いて止まれば歩く。落下で傷つかない（今の乗り物と同じ）。
- 呼べない所は今の乗り物と同じ（巨神の背・淵・主の部屋）。
- 速さの段は地上と同じ（飛ぶときは地上の速さ × 1.2）。跳びの段は羽ばたきの強さ。

## 7. 相乗り（2026-11-03。`MountEntity`）

- 持ち主が乗っているとき、同じパーティの人が乗り物を押すと後ろの席に乗る。パーティでない人には「後ろに乗れるのは同じパーティの人だけ」、席が空いていなければ「席が空いていない（乗り物の店の「人数」で増やせる）」と出す。
- **乗れる人数**（2026-11-07。`MountStats.SEATS`、見た目ごとの最大 `MountLook.maxSeats`）: はじめは 1（持ち主だけ）。乗り物の店の性能の三つめの行「人数」を上げるたびに 1 人ずつ増える（5 段。80・220・500・800・1200 鐘銭。どの見た目にも同じ段が掛かる）。見た目ごとの最大で頭打ち: 幌の荷車は 6 人、岩の子鯨・殻の亀・空の鱏は 3 人、ほかは 2 人（店の見た目の行に「最大 n 人」）。
- 操るのは前の持ち主だけ。後ろの人は乗ったまま弓・杖・近接で戦える（馬に乗ったときと同じ）。持ち主が降りる・抜けると、後ろの人も降りる。
- 後ろの席は胴の幅 × 0.42 だけ後ろ、高さは前と同じ。三人以上乗れるときは、二つめ・三つめを左右に並べ、四つめはその後ろ。撮影 `tools/shots/tandem_check.txt`・`tools/shots/mount_seats.txt`（店の人数の行）。自己テスト `mount` の中（パーティだけ・はじめ一人・人数の段で増え見た目の最大で止まる・持ち主が操る・持ち主が降りると降りる）。
- **幌の荷車**（`MountLook.CARRIAGE`。2026-11-07 の頁「二頭立ての車」の選定: 形 A・最大 6 人・四つの心臓のあと、240 鐘銭）: 角の荷獣二頭が轅と軛で引く四つ輪の荷車。荷台いっぱいの布の幌（骨の輪 5 本）、御者台・後ろに三列の腰掛け、軛に鐘、吊り角灯。形と動きは `tools/gen/mobs/mounts_lp/carriage.py`（角の荷獣の形と動きを二頭ぶん写す。骨 a_ / b_、輪 wheel_* は進んだ道のりだけ回る）。当たりは幅 2・高さ 3。席は `MountEntity.CARRIAGE_SEATS`（前の御者台が持ち主、後ろの腰掛けに 2・2・1）。乗った人は腰掛けに座る形（脚は前へ）。ラフ 3 案は `carriage_roughs.py`。撮影 `tools/shots/carriage.txt`。後ろからの眺め（肩越し）では幌で前が見えにくい。

## 8. 絆（2026-11-05 の頁 3-2。`MountData.ridden`）

- 自分の乗り物に乗って進んだ距離を数える（10 tick ごと、一度に 25 ブロックまで。運ばれた・移された分は数えない）。5 km・20 km・50 km で絆 I・II・III。強さは変えない。
- I: 笛で呼ぶと、後ろ 9〜13 の所に現れて駆け寄ってくる（道が見つからなくても 5 秒で着かなければそばへ）。
- II: 名前を付けられる（旅の番の乗り物の画面の「名付ける」。16 文字まで、色の記号は外す。空にすると外す）。呼んだときの名札が付けた名前になる。
- III: 鞍の左右に飾りの房（朱の房と金の結び目。歩くと揺れる。描き手 `MountClient.MountRenderer`）。
- 乗り物の画面の見出しに「絆 II・23.4 km」。段が上がると知らせ。開発 `/skyabyss facility mount ride <ブロック>`。自己テスト `mount`（段・名前・呼んだ乗り物の段）。
