# 38 乗り物（笛・厩舎）

乗り物の現在の仕様。実装は `mount/`・`client/mount/`、都の建物は `tools/capital/facilities.py` の `stable`。

## 1. 遊び方

- **笛**（`skyabyss:mount_whistle`、一人一つ）: 右クリックで自分の乗り物が目の前に来る。もう一度で帰る。ワールドには保存されず、帰す・ログアウト・96 ブロック以上離れる・持ち主の死で消える。厩舎の番から受け取る（なくしたらまた）。
- **乗る**: 持ち主だけが乗れる（右クリック）。馬のように人が操る。飼いならし・繁殖・持ち物はない。落下で傷つかない。敵・火・溶岩では傷つくが、他の人は傷つけられない。
- **呼べない所**: 巨神の背、淵（五章の坑道の下）、ボス部屋。理由が画面の下に出る。
- 乗り物の持ち主ごとの記録（買った見た目・段・今の見た目）は人ごとの保存データ（`MountData`）。

## 2. 見た目（`MountLook`、七つ）

| 見た目 | 開く章 | 値段 |
|---|---|---|
| 角の荷獣 | はじめから | 0（最初から持つ） |
| 灰色の鹿 | はじめから | 60 |
| 大トカゲ | はじめから | 60 |
| 岩の子鯨 | 一章を越えたら | 120 |
| 殻の亀 | 二章 | 200 |
| 雷の雛 | 三章 | 280 |
| 炉の狐 | 四章 | 360 |

見た目は一度買えば、性能の段はどの見た目にも付く（見た目を替えても段は変わらない）。見た目ごとに違うのは姿と当たりの大きさ・座る高さだけ。通貨は鐘銭（`skyabyss:bell_coin`）。

## 3. 性能の段（`MountStats`）

速さ・跳び・体力を段 1〜5 まで買う（段 0 = 馬の下の方）。値段は鐘銭で 速さ 40/80/140/220/340、跳び・体力 30/60/100/160/250。速さ 0.20→0.35、跳び 0.50→0.90、体力 20→60。買うと出ている乗り物にすぐ当たる。

## 4. 厩舎

- 場所: 都の東の大通りの南、薬師の店の東（x 82..93, z 6..17、戸は北）。厩舎の番（`stable_keeper`）が立ち、頭の上と戸の上に印と名。
- 番に話しかけて「乗り物を見る・買う」で専用の画面（`MountShopScreen`）。左に見た目の一覧（持っている・値段・章の壁）と選ぶ・買う、中に今の見た目の 3D の見本、右に 3 つの段の買うボタン。
- 開発コマンド（OP）: `/skyabyss facility mount`（画面）・`mount demo`（前に七つを並べる）。撮影 `tools/shots/mounts.txt`、絵は `docs/review/mounts/`。

## 5. 作り

- モデルは GeckoLib（`geo/entity/mount_<id>.geo.json`、絵 `textures/entity/mount_<id>.png`、動き `animations/entity/mount.animation.json`）。生成は `python -I tools/gen/mobs/gen_mounts.py install`、ラフ 3 案は `... sheets`（`docs/review/mount_roughs/<id>.png`）。ゲームには案 1 を入れてある。体は閉じた箱で、脚・頭・尾は体に沈めてある。
- 自己テスト: `SKYABYSS_SELFTEST_ONLY="mount"`（買う・章の壁・呼ぶ/帰す・性能・背と淵での断り・遠くで消える・乗る・落下無効・保存）。
