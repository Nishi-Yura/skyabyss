# 天と淵のあいだ 岩鯨と背中の試練 実装仕様書

- 文書番号: 02
- 対象: 第一の巨神「岩鯨」、その背中の島（岩鯨の背）、三つの試練、中ボス「鯨骨の番兵長」、最終ボス「岩鯨の心臓」
- 状態: 実装済みの仕様をコードから起こしたもの（数値はコードの定数に基づく）
- 関連: 全体の見直しは `docs/review/dungeon_design_review.md`、実装との突き合わせは `docs/review/whale_completeness.md`

## 1. 概要

地上の空を、巨大な鯨「岩鯨」が泳いでいる。ゲーム開始から3日目以降にオーバーワールドへ現れ（出現の条件と回数は2章）、ときどき近くのプレイヤーの上空まで降りてきて、背中の錨石から鎖を地上へ垂らす。プレイヤーは鎖を右クリックして引き上げられ、背中の島「岩鯨の背」（雲の海の上にある専用のディメンション）に乗り込む。

島では、尾の台から地表の遺跡を抜け、祠の階段で体内の鼓動の間に下り、三つの試練に挑む。

- 西の翼: 崩れる骨の足場を跳び継ぐアスレチック（4.1節）
- 東の翼: 二つの広間で番兵の波を倒す戦い。二つ目の広間で中ボス「鯨骨の番兵長」と戦う（4.2節、5.2節）
- 下の水路: 真っ暗な水没した迷路（4.3節）

西・東・下の三つの共鳴石を鳴らすと、宝物庫の封印と奥の扉が解ける。奥の回廊の先の「心臓の間」で、最終ボス「岩鯨の心臓」と戦う（5.3節）。倒すと、戦いの参加者に天の鍵の欠片（一人一つ）と装備が渡る（6章）。

島ではブロックを壊す・置くことができず、近道になる道具も使えない（8章）。倒れても持ち物は失わず、直前の休み場から再開する（7章）。難易度がピースフルのあいだは、祠の階段が封じられ、試練に入れない（7.3.2節）。試練は、心臓を倒したあと封印の奥に30秒だれもいなくなるか、島に誰もいなくなって3分たつと最初の状態に戻る（7章）。足場と迷路の形は毎回変わる。報酬は周回前提で、一度では揃わない（6章）。

## 2. 岩鯨（地上での振る舞い）

### 2.1 出現

| 項目 | 内容 |
|---|---|
| 出現条件 | オーバーワールドで、ワールドの総経過 tick が 2 日分（48000 tick）を超えてから（3日目から）。`/time set` や昼夜の停止には左右されない |
| 回数 | 自然な出現はワールドにつき一度（保存フラグで管理）。以後は 2.7 節の見守りが、同じ一体を保ち続ける |
| 出現位置 | ランダムに選んだプレイヤー（観戦者を除く）の 280 ブロック先、高度 y=200 |
| 通知 | 半径640ブロック内のプレイヤーに「遠い空で、何かが歌っている…」 |

### 2.2 巡航（CRUISE）

- 高度は「周囲の最高地表 + 75」と 170 のうち高い方（建物の上を飛ぶ）。
- 速度は 0.2 ブロック/tick。目的地に近づくと次の目的地を選ぶ。
- 目的地は、640ブロック以内のプレイヤーから 120〜260 ブロック離れた点。近くにプレイヤーがいなければ、現在地から 300 ブロック先。
- 巡航中は鎖をたたんでいる。

### 2.3 降下のタイミング

| 段階 | 内容 |
|---|---|
| 最初の降下 | 出現から 2400 tick（2分）後 |
| 次の降下 | 降下が終わってから 6000〜8999 tick（5〜7.5分）後 |
| 待機 | 水平 320 ブロック以内にプレイヤーがいなければ、1200 tick（1分）後にやり直す |
| 接近（APPROACH） | 選んだプレイヤーの約 14 ブロック横へ向かい、周囲の最高地表 + 34 の高さまで下りる。1800 tick（1.5分）たっても着かなければ、目的地から 24 ブロック以内ならその場で休息に入り、遠ければ巡航に戻って 1200 tick 後にやり直す |
| 休息（REST） | 3600 tick（3分）停泊する。通知は半径200ブロック内に「岩鯨が高度を下げてくる…」 |

### 2.4 鎖

- 錨石（モデルの chain 骨）は、岩鯨の中心から後ろ 30.5・左 10.5・上 19.5 ブロックの、左のわき腹にある（背の尾の側）。鎖は錨石の真下、上 14 ブロックの所（付け根）から真下へ垂れる。左のわき腹はこの辺りで横 9.75 ブロックなので、鎖は胴の外側を通る（`StoneWhaleEntity` の `CHAIN_BACK`・`ANCHOR_SIDE`・`ANCHOR_UP`・`CHAIN_SIDE`・`CHAIN_UP`）。
- 鎖は背中の動き（泳ぎの揺れ）に合わせない固定の位置から垂れる。
- 休息に入ると、鎖は 0.6 ブロック/tick で伸び、地面の 2.5 ブロック上で止まる。地面の高さが変わったときも、鎖は急に縮まず、伸びは 0.6、縮みは 1.2 ブロック/tick で追う。
- 描画の位置補間は、サーバーの位置送信（2tick ごと）に合わせる。以前は 10tick かけて追いかけていたため、移動中に鎖の先と当たり判定がずれていた。
- 鎖の先には、見えない当たり判定の「岩鯨の鎖」（WhaleChainEntity）が置かれる。
- 鎖の先の 12 ブロック以内にいるプレイヤーには、2 秒ごとに「鎖を右クリックすると、背中へ引き上げられる」と表示される。
- 休息が終わると、鎖は 1.2 ブロック/tick でたたまれ、当たり判定は消える。

### 2.5 乗り込み（右クリック）

1. 地面に届いている鎖を右クリックする。届いていなければ「鎖はまだ地に届いていない」と表示される。
2. プレイヤーは重力を切られ、鎖の軸へ寄りながら毎tick 0.85 ブロックの速さで上昇する。
3. 背中の縁（鎖の付け根）より 1.5 ブロック下に来るか、160 tick が過ぎると終了する。
4. 背中の島がまだ建っていなければ建て、尾の台（到着地点）へ移動する。

引き上げの途中で起きたことの扱い:

| できごと | 扱い |
|---|---|
| ログアウト（サーバーの停止を含む） | 引き上げを打ち切り、印を付けて保存する。次のログインで、そのまま背中の尾の台へ乗せる（宙から落とさない）。背中の次元がなければ、スローフォール 40 秒を付ける |
| 印を付けられずに抜けた（サーバーが落ちた） | ログイン時に重力が切れたままなら重力を戻し、宙にいればスローフォール 40 秒を付ける |
| 死亡・次元の移動・復活 | 引き上げから外す（目を覚ました後に鎖へ引っ張られない） |
| 鎖の軸から水平 16 ブロックより離れた、岩鯨が見つからない | 引き上げを打ち切り、宙にいればスローフォール 20 秒を付ける |

### 2.6 背中から地上へ戻る

| 方法 | 内容 |
|---|---|
| 錨石を右クリック | 岩鯨の鎖の付け根の 4 ブロック下へ。岩鯨が読み込まれていなければ、最後に見た位置（2.7 節）から求めた付け根の下へ。記録もなければ地上の共有スポーン地点の上へ。どれも緩やかに落ちる効果（スローフォール 40秒） |
| 島の端から落ちる | 背中の高さが y=50 を下回ると、自動的に地上へ戻される。「背から滑り落ちた」と表示される |
| コマンド | `/skyabyss titan leave` |

錨石は尾の台にある（座標は第3章の表を参照）。

### 2.7 見守り（見失わない・一体だけ）

岩鯨は普通のエンティティなので、そのままではシミュレーション距離の外で止まってしまう。`WhaleKeeper` が毎 tick 見張り、次のことをする。

| 項目 | 内容 |
|---|---|
| 記録 | `TitanWorldData`（オーバーワールドの `skyabyss_titans`）に、本物の UUID、最後に見た位置と向き、状態（モード、降下までの待ち時間など）を 1 秒ごとに残す |
| チャンクの読み込み | 水平 640 ブロック以内にプレイヤー（観戦者を除く）がいる間と、誰かが背中にいる間は、岩鯨のいるチャンクに時間切れ付きのチケット（`skyabyss_whale`、距離 2、60 tick で切れる）を張り続ける。中心の 1 チャンクがエンティティの tick に入る最小の距離。岩鯨がチャンクを移れば古いチケットを外し、条件が外れたら外す |
| 地面の調べ方 | 高さの判定は、読み込まれているチャンクだけを調べる（同期の読み込みや地形の生成を起こさない） |
| 読み込み直し | 本物が読み込まれておらず、最後の位置の 640 ブロック以内にプレイヤーがいる（または誰かが背中にいる）ときは、最後の位置にチケットを張って読み込み直す。200 tick たっても見つからなければ（`/kill` などで消えた）、そのプレイヤーのそばへ呼び直す |
| 呼び直し | 誰からも 640 ブロックより遠いまま 2400 tick（2分）たつと、オーバーワールドのプレイヤーの 280 ブロック先へ呼び直す。背中に人がいる間は呼び直さない。チケットを張っているのに 600 tick のあいだ tick が進まないときも呼び直す |
| 引き継ぎ | 呼び直した個体は前の個体の状態を引き継ぐ。巡航から始め、鎖はたたみ、降下までの待ち時間は 600〜2400 tick に収める |
| 一体だけ | UUID が記録と違う岩鯨は、ワールドに加わる時点（ディスクからの読み込みを含む）で取り消す。オーバーワールド以外の岩鯨も取り消す。記録がないとき（古いワールド）は、最初に読み込まれた個体を本物とする |
| 鎖の当たり判定 | 垂れている鎖がなくなった当たり判定は、2 秒ごとの確認で消える |

`/skyabyss titan summon` も同じ仕組みで呼ぶ。読み込まれている前の個体は消え、読み込まれていない前の個体は次に読み込まれたときに取り消されるので、二体にならない。

### 3.3 心臓の回廊と心臓の間

- **入口**: 宝物庫の奥の扉 (z=-45) は、三つの共鳴石がそろうと宝物庫の封印と一緒に開く。その先が回廊。
- **回廊**: x -1〜1、z -46〜-63。壁と天井は肉の質感（赤土器・ネザーイボ・泥煉瓦）。天井には骨の梁が渡る。
- **心臓の前室（休み場 `heart`）**: 回廊の途中を横に広げた部屋。焚き火 (0, 94, -54) に、しゃがんで触れると試練をあきらめて尾の台へ戻る（7.4節）。通ると「心臓の前室」が記録される。
- **心臓の間**: 中心 (0, 94, -80)。床の上の空間は、中心から半径 14.5 マス。壁は外側 16.5 マスまで。床は y=93、天井は y=106。天井の高さは床から 12 マス。体の表面（この位置で y=106〜108）の内側に収めるための限界で、18 マスにはできない。
- **材質**: 壁・天井・床は赤土器・茶の土器・ネザーイボ・泥煉瓦。壁の中ほど（y 99〜102）に紫水晶と海のランタンが点々と散り、脈の光に見える。
- **肋骨**: x = 中心から ±4、±8、±12 の平面に、壁ぎわから天井の中ほどへ反り上がる骨の弧。弧の下は通れる。
- **柱**: 身を隠せる柱が 4 本。中心の周り（半径 3 マス）は空けてある。
- **溝**: 床の斜めの溝に、わずかにマグマを置く（中心から 5 と 10 マスの所）。踏むと痛い。
- **入口**: (-1〜1, 94〜97, -64) の封印。心臓の間の中に人が入ると閉じ、心臓が眠る（中に生きている人がいなくなって 3 秒たつ）か、倒されると開く。一人目が入ると5秒の予告のあとに閉じ、閉じたときに中と前室にいた人が参加者になる（4.2節の決まり）。
- **戦いの範囲**: 心臓の間の内側にいる人を「中にいる」と数える。心臓が戦いの中で中心から 20 ブロックより外へ出たら、中央へ戻される。
- **出口**: 抜け道はない。入口から戻るか、心臓を倒したあとの光の柱で尾の台へ戻る（5.3節）。
- 壁・床・天井は壊せない（8章の決まり）。

## 4. 三つの試練

三つの試練は、どれから挑んでもよい。共鳴石は、西・東・下の順に限らず鳴らせる（東だけは番兵長を倒すまで黙る）。

### 4.1 西の翼（裂け目の回廊・アスレチック）

構成: 西の前室 → 肋骨の谷 → 第一の休み場 → 竪穴 → 第二の休み場 → 崩れ橋 → 西の共鳴石の岩棚。

- **足場の並び**: 肋骨の谷、竪穴、崩れ橋の三つの谷には、それぞれ毎回ちがう足場の道が生成される（CourseGenerator）。
  - 入口と出口の岩棚の位置は固定。その間の足場だけが種によって変わる。
  - 足場数: 肋骨の谷 9〜14、竪穴 8〜13、崩れ橋 7〜11。途中に寄り道の目印を置き、道が曲がりくねる。
  - 跳べる距離: 1段上へ約3.2マス、同じ高さへ4マス、1段下へ4.3マス。高さの差は ±1 まで。
  - 近道防止: 一つ前より前の足場や入口の岩棚から届く足場は作らない。足場どうしは横に2マス以上離す。
- **崩れる骨**: 足場はすべて「崩れる骨」（入口と出口の岩棚は石のまま）。乗ると 0.6秒後に崩れ、4.5秒後に元に戻る。骨の上に人がいる間は戻らない。
- **谷**: 床が抜けており、はるか下に溶岩がある。谷の底（y=90 より下、かつ 84 より上）に落ちると、直前の休み場へ戻される。
- **落下時**: 3ダメージ。直前の休み場が西の休み場（w0・w1・w2）でなければ、西の前室（w0）へ戻される。「足場を失った…」と表示。
- **休み場**: 西の前室、第一の休み場、第二の休み場の三つ。通ると「休み場『○○』にたどり着いた」と表示され、そこが記録される（記録の扱いは 7.3節）。
- **近道の禁止**: 西の翼では、跳躍とゆっくり落ちる効果が消える。背中ではエリトラで滑空できない（8章）。
- **西の共鳴石**: 岩棚の上にある。鳴らすと西の抜け道が開き、鼓動の間へ戻れる。

### 4.2 東の翼（番兵の回廊・戦い）

構成: 東の前室 → 第一の広間 → 番兵長の控えの間（休み場）→ 短い通路 → 番兵長の広間（共鳴石）。

- 2026-10-16: 1 周を短くするため、第二の広間（E2）とその先の控えの間を除いた（配置の版 2）。E2 の射手の波は、第一の広間の第二波へ移した。東の翼の推定所要時間は 5〜8 分 → **3.5〜6 分**（波 6 → 4 と番兵長。1 周の推定 20〜35 分は約 1.5〜2 分短くなる）。

- **扉**: 各広間の入口の扉は、戦いの間だけ閉じる。制圧すると、出口と入口の両方が開く（倒れて控えの間で目を覚ました仲間も、先へ進める）。番兵長の広間には出口がなく、制圧後は入口が開くので、全員が倒れても東の共鳴石へ戻れる。
- **戦いの部屋の参加の決まり**（広間と心臓の間で共通。コードは TitanBackTrials）:
  1. 部屋の内側（壁から1マス内側）に一人目が入ると、**5 秒の予告**を出す。「○秒後に扉が閉じる」とチャットに一度出し、近くの人の画面に残り秒数を出す。この間、扉は開いたまま。全員が部屋から出たら、予告は取りやめる。
  2. 扉が閉じる瞬間に、**戸口と前室にいる人も中へ入れる**（扉の内側 2 マスへ移す。封印のブロックに埋まらない）。前室は、第一の広間なら東の前室、番兵長の広間なら番兵長の控えの間とその先の通路、心臓の間なら心臓の前室から入口までの回廊。
  3. 閉じた時点で中にいた人が **参加者** になる。途中で倒れても参加者のまま。人数による強化（下の表、5.3節の心臓）と報酬（6章）は、この参加者で決まる。
  4. 参加者が倒れて前室で目を覚ましたら、戦いが続いている間は、扉に触れると内側へ戻れる（「扉があなたを覚えていた」と出る）。参加者でない人は通れない。
  5. 尾の台や島のほかの場所にいるだけの人、閉じたあとに着いた人は、参加者ではない。扉の外で待てば、次の挑戦で参加者になれる。
- **広間の流れ**:
  1. 上の決まりで扉が閉じると、参加者の人数を数え、第一波を湧かせる。波と波のあいだは 3 秒（60 tick）。
  2. 番兵が全滅したら出口と入口が開く。広間は記録され、以後は戦えない。
- **全滅・退出**: 広間の中に生きているプレイヤーがいない状態が 3 秒続くと、番兵は消え、入口が再び開く（出口は閉じたまま）。広間は最初からやり直し。
- **番兵長の強さ**: 番兵長の体力は 280 ×（1 + 0.6 ×（参加者 − 1））。心臓と同じ式（5.3節）。番兵長が倒れると、E3 の参加者に中ボスの報酬を渡す（`TitanLoot.onCaptainDefeat`）。
- **湧き場所**: 広間の四隅の内側と中央の計5か所。
- **人数による増加**: 扉が閉じたときの参加者の人数を N とし、最大 4 人まで数える。追加の人数（N が 2 以上なら、N-1 組）ごとに、以下の表の「増分」が加わる。

| 広間 | 波 | 基本の構成 | 増分（1人増えるごと） |
|---|---|---|---|
| 第一の広間（E1） | 1 | 骨の番兵 2、苔這い 2（近接の波） | 骨の番兵 +2 |
| 第一の広間（E1） | 2 | 骨棘の射手 3、骨の番兵 1（番兵の盾の後ろから射手が撃つ。旧 E2 の第一波） | 骨棘の射手 +2 |
| 番兵長の広間（E3） | 1 | 骨の番兵 2、骨棘の射手 1、苔這い 2 | 骨の番兵 +2 |
| 番兵長の広間（E3） | 2 | 鯨骨の番兵長 1 | 骨の番兵 +1、骨棘の射手 +1 |

- 例: 一人なら番兵 2 体と苔這い 2 体。四人以上で第一の広間の第一波は、番兵 8 体と苔這い 2 体。

### 4.3 下の水路（闇の水路・迷路）

構成: 鼓動の間の床の穴（(4, 93, -25) 付近）から、はしごで水面のすぐ上まで下りる。水没した迷路を進み、出口の泡の柱で小部屋へ押し上げられ、下の共鳴石を鳴らす。

- **形**: 11×15 マスの迷路。1マスは 3×3 の水の部屋で、壁の厚さは 1。どの2マスも道は一本だけ。種で毎回形が変わる。
- **入口**: 入口のマスから道が必ず二つ以上に分かれる種だけを使う。正しい道は 26 マス以上。
- **息継ぎのくぼみ**: 正しい道の 4 マスごとに、天井を 3×3 くぼませ、空気だけのくぼみを作る。ほかに明かりや陸はない。
- **流れ**: 正しい道のところどころに、下へ引く泡の流れがある（マグマブロックの上の泡柱）。流れにのると下へ引きずられる。
- **行き止まり**: 行き止まりの約 6 つに一つは「水路の顎」のスポナー。ほかの行き止まりには、シーピクルスや昆布がある。
- **出口**: 出口のマスの泡の柱が、出口の小部屋（床 y=81）へ押し上げる。小部屋の床は整えてある。
- **下の共鳴石**: 小部屋の中（13, 82, -9）。鳴らすと下の抜け道が開き、入口の通路へ戻れる。

## 6. 報酬（周回前提。2026-10-16 作り直し）

一度の踏破では揃わない。何度も背中に乗り、少しずつ集める。マルチプレイでも取り合いにならないよう、報酬はすべて**一人ずつ別々の抽選**で、持ち物へ直接入る。人数が増えても、自分の取り分は減らない。宝箱はない。

- **受け取る人**: その戦いの参加者（試練の担当 T が数える。途中で倒れて復活待ちの人も含む。島にいるだけの人は含まない）。
- **倒れていた・抜けていた人**: 抽選はその場で済ませ、品は預かる（`TitanMemoryData` に UUID ごとに保存。再起動でも消えない）。目を覚ましたとき、入り直したとき、`/titanmemory claim` で渡す。倒れている人の持ち物に直接入れると、復活時の預かり物の戻しで上書きされて消えるため、必ず預かる。
- **持ち物がいっぱい**: 入りきらない分も足もとには落とさず預かる。`/titanmemory claim` で受け取る。
- 実装: `loot/TitanLoot.java`（`onHeartDefeat`、`onCaptainDefeat`、`onGuardDrops`）。

### 6.1 道中の番兵（倒した人だけが拾える形で落とす）

背中の上で、プレイヤーが倒したときだけ。落ちた品は倒した本人にしか拾えない。波の数は人数で増えるので、一人あたりの取り分はおおむね変わらない。

| 敵 | 岩鯨の欠片 | 共鳴の欠片 | 雲上の干し肉 | そのほか |
|---|---|---|---|---|
| 骨の番兵 | 30%、1〜2 | 5%、1 | 3%、1 | 岩鯨の甲殻のどれか一部位 1% |
| 骨棘の射手 | 25%、1〜2 | 5%、1 | 3%、1 | 骨棘の矢 25%、2〜4 本 |
| 苔這い | 25%、1〜2 | 5%、1 | 3%、1 | 苔の護石 3% |
| 水路の顎 | 10%、1 | — | — | なし（スポナーで湧き続けるため） |

### 6.2 番兵長（中ボス）

必ず出る品はない。参加者それぞれに次を抽選する。

| 内容 | 確率 | 数 |
|---|---|---|

## 7. 何度でも挑める仕組み

### 7.1 試練のリセット

- 次のどちらかで、試練がリセットされる。
  - 背中の島に誰もいなくなってから **3分（3600 tick）**。途中でプレイヤーが一人でも戻ると、計時は0に戻る。
  - 心臓を倒したあと、**封印の先（宝物庫・心臓の回廊・心臓の前室・心臓の間）に誰もいない状態が 30 秒** 続いたとき。尾の台や島のほかの場所に人がいても戻る。全員に「岩鯨の心臓が、再び脈を打ち始めた」と伝える。これで、島で誰かが待っていても次の周回に挑める。
- リセットのたびに、**試練の番号**（`TitanBackData` の Epoch）が一つ進む。休み場の記録は番号つきで、番号が違う記録は無効になる（7.3節）。
- リセットの瞬間に、作り直す所や封じる所（西の翼、闇の水路、東の翼の広間・控えの間・通路、宝物庫より奥）にいる人は、鼓動の間へ移す。鼓動の間とその通路、西と東の前室、地表にいる人はそのまま。
- リセットされるもの:
  - 三つの共鳴石（すべて消灯）
  - 封印（宝物庫の封印、各抜け道）
  - 二つの広間（番兵は消え、入口は開き、出口は閉じる。制圧の記録も消える）
  - 西の足場と闇の水路の形（新しい種で作り直す）
  - 岩鯨の心臓（消えて、入口が開く）。心臓を倒した記録も消え、もう一度挑める
  - 宝物庫の封印と奥の扉の開放状態（封印に戻る）
- リセットされないもの:
  - 島そのもの（建物と地形）
  - 天の鍵の欠片を受け取った人の一覧（一人一つのまま）
- 足場と迷路は、リセットのたびに新しい種で作り直される（同じ形になることは稀）。

### 7.2 持ち物と経験値（倒れたとき）

- 背中の島で倒れると、持ち物と経験値はその場で預かられ、失わない（地面にも落ちない）。
- 預かり物は、プレイヤーの永続データ（`PlayerPersisted` の `skyabyss_kept`）に書く。死亡画面のまま「保存して終了」しても、サーバーを止めても残り、次に目を覚ましたときに返る。
- 消滅の呪いが付いた物は、バニラと同じく消える（預からない）。
- 預かり物を返す前にもう一度倒れたときは、前の預かり物を「足して返す分」に移す。目を覚ましたときに持ち物へ足し、入りきらない物は足元に置く。経験値も足す。生きたままログインしたのに預かり物が残っていたときも、同じように足して返す。
- 預かるのは、ほかの仕組みが死を取り消さなかったときだけ（死亡イベントの最後に動く）。
- 地上のリスポーン地点（ベッドなど）は変わらない。

### 7.3 背中での復活

- 背中で倒れて復活すると、記録された休み場へ戻される。休み場がない場合や、記録がリセットより前のもの（番号が違う）の場合は、尾の台へ戻される。
- 休み場の記録が消えるとき: 乗り込み（背中のディメンションに入る）、地上へ戻る（出る）、焚き火であきらめる、試練のリセット。背中で倒れて連れ戻されるときだけは消えない。
- 復活位置は、焚き火のまわりの腰掛けを避けて、中心から斜めに 2 マスの所。鼓動の間は、中央の台座（強化深層岩）を避けて南へ 6 マス。念のため、足元と頭が空いていて床が固いかを確かめ、だめなら近く（横 5 マス・上下 1 マス）で立てる場所を探す。自己テストも、すべての休み場の復活位置を調べる。
- ログインしたとき、背中にいて、最後に背中にいたときから試練の番号が変わっていて（その間にリセットされた）、体内（地表より下）にいる人は、尾の台へ移す。封印の奥でログアウトして、リセット後にそこから始めることはできない。
- 地上でのリスポーンは、通常どおりの位置。

### 7.3.1 保存して終了・再起動

- 試練で湧いた番兵、番兵長、心臓は、ディスクに保存しない（戦いの状態はメモリにしかないため）。保存して終了すると消え、再起動のあとに二体になることはない。この仕組みより前に保存された個体も、読み込まれた時点で消す。
- 再起動のあと、背中が最初に動いたときに、制圧していない広間は最初に戻し（入口を開け、出口を閉じる）、制圧した広間は入口と出口を開け、心臓の間の入口を開ける。
- 心臓の撃破を報告できるのは、いま戦っている心臓（背中のディメンションで、心臓の印が付き、試練が湧かせた個体）だけ。スポーンエッグの心臓を倒しても何も起きない。

### 7.3.2 ピースフル（試練は眠る。2026-10-16 決定）

- 難易度がピースフルのあいだは、試練に入れない。島に乗ること、地表を歩くこと、尾の台の炉を使うことはできる。
- **祠の封印**: 祠から体内へ下りる階段の 5 段目（z=19、x -1〜1、y 109〜112。祠の床の下に入った所）を封印のブロックでふさぐ。ほかの難易度に戻ると封印は消える。封印の手前まで下りると、画面に「巨神は目覚めない。（難易度がピースフルのあいだ、試練は眠っている）」と出る（チャットには出さない）。
- **体内にいる人**: ピースフルになったとき（またはピースフルのままログインしたとき）、封印より奥の体内（地表より下、島の底より上）にいる人は尾の台へ移し、同じ文をチャットに一度出す。クリエイティブと観戦者は移さない。
- **戦いの途中でピースフルになったとき**: 試練の番兵・番兵長・心臓をすべて消し、閉じた広間と心臓の間の扉を開け、広間と心臓を最初に戻す。告知（「番兵たちは、再び眠りについた」など）は出さない。制圧の記録と共鳴石はそのまま。ピースフルのあいだは、広間と心臓の間の集合も始まらない。
- 試練の個体はバニラどおりのモンスターとして振る舞う（ピースフルでは消え、攻撃はモンスターの攻撃）。以前の「ピースフルでも消えず、難易度で変わらない傷を与える」仕組みは外した。
- 心臓が撃破の報告なしに消えたときは、入口を開け、5 秒は湧かせ直さない（開け閉めとチャットの繰り返しを防ぐ）。
- コードは `TitanBackTrials`（`tickShrineSeal`・`sleepForPeaceful`）。自己テストは、ピースフルにすると封印が置かれ、番兵と心臓が消え、閉じた扉が開くこと、難易度を戻すと封印が消えることを確かめる。

### 7.4 休み場と「あきらめる」

- 休み場の焚き火（魂の焚き火）は、西の前室、第一の休み場、第二の休み場、東の前室、番兵長の控えの間、心臓の前室にある。
- 焚き火にしゃがんで右クリックすると、試練をあきらめて尾の台へ戻る。休み場の記録も消える。しゃがまずに触れると、「しゃがんで焚き火に触れると、試練をあきらめて背の入口へ戻れる」と表示される。

## 8. 背中の決まり（保護のルール）

島の中では、クリエイティブとスペクテイター以外のプレイヤーに、次の制限がかかる（コードは TitanBackRules）。

| 制限 | 内容 |
|---|---|
| ブロックを壊せない | 掘り始めることもできない（ひびも入らない） |
| ブロックを置けない | 置こうとしても拒まれる |
| 爆発で壊れない | 島の中で起きた爆発では、ブロックが壊れない（誰が起こしたものでも） |
| 近道になる道具の使用を禁止 | 下記の一覧。使おうとすると「巨神の体は、よそ者の手を拒んでいる」と表示される |
| エリトラで滑空できない | 背中のどこでも、滑空を始めるとすぐに止められる |
| ピースフルでは試練に入れない | 祠の階段が封印でふさがり、体内にいる人は尾の台へ移される（7.3.2節） |
| 西の翼で跳躍とゆっくり落ちる効果が消える | 西の前室・三つの谷・二つの休み場では、跳躍とゆっくり落ちる効果（薬、食べ物、乗り込みのときの効果）を消す |

使用を禁止するアイテム:

- バケツ類（空・水・溶岩・粉雪）
- エンダーパール、チョーラスフルーツ、風の機雷、花火ロケット、三叉槍
- 打火石、火薬玉、粉雪のバケツ、エンドクリスタル
- TNT、TNTのトロッコ、リスポーンアンカー

## 9. テスト用コマンド
