## 1. 概要

地上の空を、巨大な鯨「岩鯨」が泳いでいる。ゲーム開始から 3 日目以降にオーバーワールドへ現れ（2 章）、ときどき近くのプレイヤーの上空まで降りて、背中の錨石から鎖を地上へ垂らす。鎖を右クリックすると引き上げられ、背中の島「岩鯨の背」（雲の海の上にある専用のディメンション `titan_back`）に乗り込む。

島は、空を泳ぐ岩鯨と同じ形・同じ色のブロックでできた鯨（ゲームの岩鯨の 2.8 倍、全長 412。3.1 節）。尾の付け根の背の広場に着き、苔むした背を北へ歩いて背の中ほどの祠へ、祠の階段で体の中の鼓動の間に下り、三つの試練に挑む。試練の部屋はすべて体の中に埋まっている。

- 西の翼: 崩れる骨の足場を跳び継ぐアスレチック（4.1）
- 東の翼: 二つの広間で番兵の波を倒す戦い。二つ目の広間で中ボス「鯨骨の番兵長」（4.2、5.2）
- 下の水路: 真っ暗な水没した迷路（4.3）

西・東・下の三つの共鳴石を鳴らすと、宝物庫の封印と奥の扉が解ける。奥の回廊の先の「心臓の間」で最終ボス「岩鯨の心臓」と戦う（5.3）。倒すと、参加者に天の鍵の欠片（一人一つ）と装備が渡る（6 章）。

- 島ではブロックを壊す・置くこと、近道になる道具が使えない（8 章）。
- 倒れても持ち物は失わず、直前の休み場から再開する（7 章）。
- ピースフルのあいだは祠の階段が封じられ、試練に入れない（7.5）。
- 試練は、心臓を倒したあと封印の奥に 30 秒だれもいなくなるか、島に誰もいなくなって 3 分たつと最初の状態に戻る（7.1）。足場と迷路の形は毎回変わる。
- 報酬は周回前提で、一度では揃わない（6 章）。
- 巨神の背中のダンジョンは、巨神の外見と同じ形にして体の中に埋める。これは全巨神の方針（01、潮殻は 08）。
- 背中の敵はすべて新しいキャラ（壁をすり抜ける敵は使わない）。
- 強い品は最終ボスで出す。番兵長は欠片と経験値と、ごく低い確率の鉾だけ（6 章）。

## 2. 岩鯨（地上での振る舞い）

実装: `titan/StoneWhaleEntity`、`WhaleKeeper`、`WhaleChainEntity`、`TitanWorldData`。

### 2.1 出現

| 項目 | 内容 |
|---|---|
| 条件 | オーバーワールドで、ワールドの総経過 tick が 48000（2 日分、3 日目から）を超えてから。`/time set` や昼夜の停止には左右されない |
| 回数 | 自然な出現はワールドにつき一度（保存フラグ）。以後は 2.7 の見守りが同じ一体を保つ |
| 位置 | ランダムに選んだプレイヤー（観戦者を除く）の 280 ブロック先、高度 y=200 |
| 通知 | 半径 640 ブロック内のプレイヤーに「遠い空で、何かが歌っている…」 |

### 2.2 巡航（CRUISE）

- 高度は「周囲の最高地表 + 75」と 170 のうち高い方（建物の上を飛ぶ）。速度は 0.2 ブロック/tick。
- 目的地は、640 ブロック以内のプレイヤーから 120〜260 ブロック離れた点。近くにプレイヤーがいなければ、現在地から 300 ブロック先。近づくと次を選ぶ。
- 巡航中は鎖をたたんでいる。

### 2.3 降下のタイミング

| 段階 | 内容 |
|---|---|
| 最初の降下 | 出現から 2400 tick（2 分）後 |
| 次の降下 | 降下が終わってから 6000〜8999 tick（5〜7.5 分）後 |
| 待機 | 水平 320 ブロック以内にプレイヤーがいなければ、1200 tick（1 分）後にやり直す |
| 接近（APPROACH） | 選んだプレイヤーの約 14 ブロック横へ、周囲の最高地表 + 34 の高さまで下りる。1800 tick（1.5 分）たっても着かなければ、目的地から 24 ブロック以内ならその場で休息に入り、遠ければ巡航に戻って 1200 tick 後にやり直す |
| 休息（REST） | 3600 tick（3 分）停泊。通知は半径 200 ブロック内に「岩鯨が高度を下げてくる…」 |

### 2.4 鎖

- 錨石（モデルの chain 骨）は、岩鯨の中心から後ろ 30.5・左 10.5・上 19.5 ブロックの左のわき腹（背の尾の側）。鎖は錨石の真下、上 14 ブロックの付け根から真下へ垂れる。左のわき腹はこの辺りで横 9.75 ブロックなので、鎖は胴の外側を通る（`CHAIN_BACK`・`ANCHOR_SIDE`・`ANCHOR_UP`・`CHAIN_SIDE`・`CHAIN_UP`。胴にぶつかって上れないため）。
- 鎖は泳ぎの揺れに合わせない固定の位置から垂れる。
- 休息に入ると 0.6 ブロック/tick で伸び、地面の 2.5 ブロック上で止まる。地面の高さが変わっても急に縮まず、伸び 0.6・縮み 1.2 ブロック/tick で追う。
- 描画の位置補間はサーバーの位置送信（2 tick ごと）に合わせる（10 tick だと鎖の先と当たり判定がずれるため）。
- 鎖の先に、見えない当たり判定の「岩鯨の鎖」（`WhaleChainEntity`）。先の 12 ブロック以内のプレイヤーに 2 秒ごとに「鎖を右クリックすると、背中へ引き上げられる」と表示。
- 休息が終わると、鎖は 1.2 ブロック/tick でたたまれ、当たり判定は消える。
- 巨神での移動（09）のあいだは、鎖は背中の錨石ではなく頭の乗り場から垂れ、右クリックすると頭の座席へ引き上げられる。

### 2.5 乗り込み（右クリック）

1. 地面に届いている鎖を右クリック。届いていなければ「鎖はまだ地に届いていない」。
2. 重力を切られ、鎖の軸へ寄りながら毎 tick 0.85 ブロックで上昇。
3. 背中の縁（鎖の付け根）より 1.5 ブロック下に来るか、160 tick で終了。
4. 背中の島がまだ建っていなければ建て、尾の付け根の広場（到着地点）へ移動。

| できごと | 扱い |
|---|---|
| ログアウト（サーバーの停止を含む） | 引き上げを打ち切り、印を付けて保存。次のログインで背中の広場へ乗せる（宙から落とさない）。背中の次元がなければスローフォール 40 秒 |
| 印を付けられずに抜けた（サーバーが落ちた） | ログイン時に重力が切れたままなら戻し、宙にいればスローフォール 40 秒 |
| 死亡・次元の移動・復活 | 引き上げから外す（目を覚ました後に鎖へ引っ張られない） |
| 鎖の軸から水平 16 ブロックより離れた、岩鯨が見つからない | 打ち切り、宙にいればスローフォール 20 秒 |

### 2.6 背中から地上へ戻る

| 方法 | 内容 |
|---|---|
| 錨石を右クリック | 岩鯨の鎖の付け根の 4 ブロック下へ。岩鯨が読み込まれていなければ、最後に見た位置（2.7）から求めた付け根の下へ。記録もなければ地上の共有スポーン地点の上へ。どれもスローフォール 40 秒 |
| 島の端から落ちる | 背中の高さが y=50 を下回ると自動的に地上へ。「背から滑り落ちた」。鯨の背は丸いので、わき腹へ歩くと滑り落ちる（胸びれ・尾びれの上には立てる） |
| コマンド | `/skyabyss titan leave` |

- 錨石は尾の付け根の広場の祠にある（座標は 3.2）。
- 背中にいる間に、岩鯨が他の人に呼ばれて遠くへ泳ぐことがある。そこで乗り込んだ位置（地上）を覚え、降りるとき岩鯨がそこから水平 128 ブロックより遠くにいれば、上った場所の空へ戻す（「岩鯨は大きく回り、あなたが上った空へ戻ってから鎖を垂らした」）。上の 3 つすべてに効く。記録は `PlayerPersisted` の下にあるので、背中で倒れて復活しても消えない。実装は `TitanTravel`（09）。

### 2.7 見守り（見失わない・一体だけ）

岩鯨は普通のエンティティで、そのままではシミュレーション距離の外で止まるため、`WhaleKeeper` が毎 tick 見張る。

| 項目 | 内容 |
|---|---|
| 記録 | `TitanWorldData`（オーバーワールドの `skyabyss_titans`）に、本物の UUID、最後に見た位置と向き、状態（モード、降下までの待ち時間など）を 1 秒ごとに残す |
| チャンクの読み込み | 水平 640 ブロック以内にプレイヤー（観戦者を除く）がいる間と、誰かが背中にいる間は、岩鯨のいるチャンクに時間切れ付きのチケット（`skyabyss_whale`、距離 2、60 tick で切れる）を張り続ける。中心の 1 チャンクがエンティティ tick に入る最小の距離。チャンクを移れば古いチケットを外し、条件が外れたら外す |
| 地面の調べ方 | 読み込まれているチャンクだけを調べる（同期の読み込みや地形生成を起こさない） |
| 読み込み直し | 本物が読み込まれておらず、最後の位置の 640 ブロック以内にプレイヤーがいる（または誰かが背中にいる）とき、最後の位置にチケットを張って読み込み直す。200 tick で見つからなければ（`/kill` など）、そのプレイヤーのそばへ呼び直す |
| 呼び直し | 誰からも 640 ブロックより遠いまま 2400 tick（2 分）で、オーバーワールドのプレイヤーの 280 ブロック先へ。背中に人がいる間は呼び直さない。チケットを張っているのに 600 tick tick が進まないときも呼び直す。旅（09）のあいだは呼び直さない |
| 引き継ぎ | 呼び直した個体は前の個体の状態を引き継ぐ。巡航から始め、鎖はたたみ、降下までの待ち時間は 600〜2400 tick |
| 一体だけ | UUID が記録と違う岩鯨は、ワールドに加わる時点（ディスクからの読み込みを含む）で取り消す。オーバーワールド以外の岩鯨も取り消す。記録がない古いワールドは、最初に読み込まれた個体を本物とする |
| 鎖の当たり判定 | 垂れている鎖がなくなった当たり判定は、2 秒ごとの確認で消える |

`/skyabyss titan summon` も同じ仕組みで呼ぶ（前の個体は消える／次に読み込まれたとき取り消される）。

## 3. 背中の島の形と配置

実装: `titan/dungeon/TitanBackLayout`（座標・版）、`TitanBackBuilder`、`WhaleShape`（鯨の形の読み書き）、`TitanBackTrials`、`TitanBackRules`、`TitanBackData`。

### 3.1 形と大きさ

島は空を泳ぐ岩鯨のモデル（採用案 B）と同じ形・同じ色のブロックの鯨（頭は -Z 側、体の軸は x = -3）。三つの試練・鼓動の間・宝物庫・心臓の間は体の中（床 93）にあり、部屋の座標は鯨の形に合わせて動かさない。

- **大きさ**: ゲームの岩鯨の 2.8 倍（縮尺 1.4 ブロック/単位。全長 412・幅 82・高さ 73、約 123 万ブロック）。頭の先 z -162〜尾びれの先 z 250、背 y 131、塔の上 y 168、腹の下 y 58（雲の海は y 45）。
  - 縮尺は体の幅で決まる。試し済みの部屋は幅 74（西の谷 x -37〜東の広間 x 37）、高さ 31（水路の床 76〜心臓の間の天井 107）で、2.7 倍以下だと谷の壁が体の外に出る。1.4〜1.7 倍にするなら西と東の翼を体の長さの向きに並べ直す必要がある（試練の座標を全部作り直す）。
  - 体の軸を x = -3 に寄せる（モデルは東が少し太い）。体の中心（モデルの y 40）を y 95、モデルの z 0 を z 24 に置く。
- **背の高さ**: 背の中ほど y=128〜131、祠の床 y=128、尾の付け根の広場 y=124。
- **歩く距離**: 到着から祠まで 57 歩、鼓動の間まで 118 歩。
- **モデルからブロックへ**（`tools/gen_titan_back_whale.py`、出力 `data/skyabyss/titan_back/whale.bin`）:
  - 形の元は `install_stone_whale.build()`（ゲームの geo と同じ 0.5 単位の格子）。
  - 1 ブロックに入るセルの多数決で材料を決め、占める割合 0.45（細い部品は 0.3）以上なら置く。光る材料（刻文・目）は少しでもあれば残す。乱数なし。
  - 材料はテクスチャの色に近いバニラ: 体の石 = 磨いた凝灰岩・青緑の土器・凝灰岩レンガ・深層岩の丸石、腹 = 閃緑岩・方解石・白の土器、ひれ = 深層岩、遺跡 = 凝灰岩・石レンガ、刻文 = 海のランタン、目 = 黄土のフロッグライト、背骨 = 骨ブロック。背の上向きの面は苔。
  - 外から 5 ブロックより深い体の中は凝灰岩と深層岩（部屋は各 Builder が深層岩のレンガで掘る）。
  - 背を歩けるように、隣が 2〜3 高い所に同じ石を 1 段足してある。
  - `WhaleShape` が読んで置き、`bodyTop`・`bottom` もここから引く（`TitanBackLayout.top/bottom/shape`）。
- **背の上（外）**: モデルのまま。苔の背、背骨の骨、三つのアーチ（石の門）、刻文の光る塔、崩れた壁、岩の板。景色と少しの探索だけで、宝箱・敵は置かない。
- **落ちたとき**: 背は丸いので、わき腹へ歩くと滑り落ちる。y 50 より下で地上へ（2.6）。胸びれ・尾びれの上には立てる。
- **肋骨の窓**: 肋骨の谷の西の壁は鯨の左のわき腹の殻のすぐ内側にある。殻が 4 ブロック以内に薄い所（y 96〜103）は、4 マスごとに骨の柱を残してあいだを外の面までくり抜き、谷の壁の面にガラスをはめた。崩れる骨を跳ぶ谷から雲と空が見える（外へは出られない）。竪穴・崩れ橋は殻が厚く窓がない。

## 4. 三つの試練

どれから挑んでもよい。共鳴石は、西・東・下の順に限らず鳴らせる（東だけは番兵長を倒すまで黙る）。

### 4.1 西の翼（裂け目の回廊・アスレチック）

構成: 西の前室 → 肋骨の谷 → 第一の休み場 → 竪穴 → 第二の休み場 → 崩れ橋 → 西の共鳴石の岩棚。

- **足場の並び**: 三つの谷には、それぞれ毎回ちがう足場の道が生成される（`CourseGenerator`）。入口と出口の岩棚は固定で、その間だけ種によって変わる。
  - 足場数: 肋骨の谷 9〜14、竪穴 8〜13、崩れ橋 7〜11。途中に寄り道の目印を置き、道が曲がる。
  - 跳べる距離: 1 段上へ約 3.2、同じ高さへ 4、1 段下へ 4.3。高さの差は ±1 まで。
  - 近道防止: 一つ前より前の足場や入口の岩棚から届く足場は作らない。足場どうしは横に 2 マス以上離す。
- **崩れる骨**: 足場はすべて「崩れる骨」（入口と出口の岩棚は石）。乗ると 0.6 秒後に崩れ、4.5 秒後に戻る。骨の上に人がいる間は戻らない。毎 tick、足の裏が触れている骨をすべて調べて崩す（着地・静止・縁でも）。
- **谷**: 床が抜け、はるか下に溶岩。谷の底（y=90 より下、84 より上）に落ちると直前の休み場へ戻される。
- **落下時**: 3 ダメージ。直前の休み場が西の休み場（w0・w1・w2）でなければ西の前室（w0）へ。「足場を失った…」。
- **休み場**: 西の前室・第一・第二。通ると「休み場『○○』にたどり着いた」と表示され記録される（7.3）。
- **近道の禁止**: 西の翼では跳躍とゆっくり落ちる効果が消える（8 章）。
- **西の共鳴石**: 岩棚の上。鳴らすと西の抜け道が開き、鼓動の間へ戻れる。

### 4.2 東の翼（番兵の回廊・戦い）

構成: 東の前室 → 第一の広間 → 番兵長の控えの間（休み場）→ 短い通路 → 番兵長の広間（共鳴石）。

- **扉**: 各広間の入口の扉は戦いの間だけ閉じる。制圧すると出口と入口の両方が開く（倒れて控えの間で目を覚ました仲間も先へ進める）。番兵長の広間には出口がなく、制圧後は入口が開くので、全員が倒れても東の共鳴石へ戻れる。
- **戦いの部屋の参加の決まり**（広間と心臓の間で共通。`TitanBackTrials`）:
  1. 部屋の内側（壁から 1 マス内側）に一人目が入ると、**5 秒の予告**。「○秒後に扉が閉じる」とチャットに一度出し、近くの人の画面に残り秒数。この間、扉は開いたまま。全員が出たら取りやめる。
  2. 扉が閉じる瞬間に、**戸口と前室にいる人も中へ入れる**（扉の内側 2 マスへ。封印に埋まらない）。前室は、第一の広間なら東の前室、番兵長の広間なら控えの間とその先の通路、心臓の間なら心臓の前室から入口までの回廊。
  3. 閉じた時点で中にいた人が**参加者**。途中で倒れても参加者のまま。人数による強化（下の表、5.3 の心臓）と報酬（6 章）は参加者で決まる。
  4. 参加者が倒れて前室で目を覚ましたら、戦いが続いている間は扉に触れると内側へ戻れる（「扉があなたを覚えていた」）。参加者でない人は通れない。
  5. 広場や島の他の場所にいるだけの人、閉じたあとに着いた人は参加者ではない。扉の外で待てば次の挑戦で参加者になれる。
- **広間の流れ**: 扉が閉じたら参加者数を数え、第一波を湧かせる。波と波のあいだは 3 秒（60 tick）。番兵が全滅したら出口と入口が開き、広間は記録され以後は戦えない。湧き場所は広間の四隅の内側と中央の 5 か所。
- **全滅・退出**: 広間の中に生きているプレイヤーがいない状態が 3 秒続くと、番兵は消え、入口が再び開く（出口は閉じたまま）。広間は最初からやり直し。戦いが始まったら壁ぎわも「中にいる」と数える（壁ぎわで空と判定され入口が開くのを防ぐため）。
- **番兵長の強さ**: 体力 280 ×（1 + 0.6 ×（参加者 − 1））。心臓と同じ式（5.3）。倒れると参加者に中ボスの報酬（`TitanLoot.onCaptainDefeat`）。
- **人数による増加**: 参加者を N とし、最大 4 人まで数える。N が 2 以上なら、N-1 組ぶん「増分」が加わる。

| 広間 | 波 | 基本の構成 | 増分（1 人増えるごと） |
|---|---|---|---|
| 第一の広間（E1） | 1 | 骨の番兵 2、苔這い 2（近接の波） | 骨の番兵 +2 |
| 第一の広間（E1） | 2 | 骨棘の射手 3、骨の番兵 1（盾の後ろから射手が撃つ） | 骨棘の射手 +2 |
| 番兵長の広間（E3） | 1 | 骨の番兵 2、骨棘の射手 1、苔這い 2 | 骨の番兵 +2 |
| 番兵長の広間（E3） | 2 | 鯨骨の番兵長 1 | 骨の番兵 +1、骨棘の射手 +1 |

- 例: 一人なら番兵 2 と苔這い 2。四人以上で第一の広間の第一波は番兵 8 と苔這い 2。

### 4.3 下の水路（闇の水路・迷路）

構成: 鼓動の間の床の穴（(4, 93, -25) 付近）から、はしごで水面のすぐ上まで下りる。水没した迷路を進み、出口の泡の柱で小部屋へ押し上げられ、下の共鳴石を鳴らす。休み場はなく、息継ぎだけ。

- **形**: 11×15 マスの迷路。1 マスは 3×3 の水の部屋、壁の厚さ 1。どの 2 マスも道は一本。種で毎回変わる。
- **入口**: 入口のマスから道が必ず二つ以上に分かれる種だけを使う。正しい道は 26 マス以上。
- **息継ぎのくぼみ**: 正しい道の 4 マスごとに、天井を 3×3 くぼませた空気のくぼみ（マスの上の二段、y=80〜81 が空気）。入口の碑文に「青い光の下に息の泡がある」。床と天井に海のランタン、四隅にシーピクルスで場所が分かる。
  - くぼみへつながるすべての通路（正しい道と枝道）の一番上の段（y=80）を壁でふさぐ（`MazeBuilder.sealPocketMouths`）。空気と同じ高さで水源が接すると、流れる水が空気へ広がって数秒で埋まるため（潜鐘の形。通路の下の二段から潜って入り、浮かぶと頭が空気に出て息が戻る）。
- **流れ**: 正しい道のところどころに、下へ引く泡の流れ（マグマブロックの上の泡柱）。
- **行き止まり**: 3 つに 1 つは「水路の顎」のスポナー（水中に湧けるようにしてある）。ほかにはシーピクルスや昆布。
- **出口**: 出口のマスの泡の柱が出口の小部屋（床 y=81）へ押し上げる。
- **下の共鳴石**: 小部屋の中 (13, 82, -9)。鳴らすと下の抜け道が開き、入口の通路へ戻れる。

### 5.2 中ボス「鯨骨の番兵長」

番兵長の広間の中央に現れる。プレイヤーの近くで技を選ぶ。優先順位は、怒りの咆哮、骨の噴出、跳躍、薙ぎ払い、近づく。

| 技 | 条件 | 流れ | ダメージ |
|---|---|---|---|
| 薙ぎ払い（sweep） | 距離 4.5 未満、クールダウン明け | 22 tick。12 tick で前方 5.2・140° の扇形を斬る。1.2 ノックバック | 11 |
| 跳躍と叩きつけ（leap） | 距離 7〜18、クールダウン明け | 8 tick の溜め、跳ぶ。着地で半径 6（怒り時 7.5）の衝撃波 | 中心 9、端 4.5。上へ跳ね、2.5 秒 鈍足 II |
| 骨の噴出（erupt） | 距離 18 未満、クールダウン明けに毎 tick 40% | 30 tick、対象の足元に白い輪。骨の槍が突き上がる | 槍 1 つ 7（半径 1.3）。上へ跳ね上げる |
| 咆哮（roar） | 怒り（HP 50% 未満）に初めて入ったとき一度だけ | 16 tick で半径 6 の衝撃波、骨の番兵を 2 体呼ぶ。速さ I と筋力 I を永続 | 衝撃波 4 |

- **骨の噴出の数**: 足元に寄ったプレイヤー全員と、その周りのランダムな地点。通常 6 本、怒り時 10 本。
- **怒り**: 咆哮を一度（呼ばれた番兵も倒さないと次の波に進めない）。薙ぎ払い 25 tick、跳躍 90 tick、骨の噴出 130 tick。衝撃波は半径 7.5。
- **体力バー**: 青色の 10 段。40 ブロック以内のプレイヤーに見える。

### 5.3 最終ボス「岩鯨の心臓」

## 6. 報酬（周回前提）

一度の踏破では揃わない。何度も背中に乗り、少しずつ集める。報酬はすべて**一人ずつ別々の抽選**で持ち物へ直接入る（マルチで取り合いにならず、人数が増えても自分の取り分は減らない）。宝箱はない。実装: `loot/TitanLoot`（`onHeartDefeat`、`onCaptainDefeat`、`onGuardDrops`）。

- **受け取る人**: その戦いの参加者（途中で倒れた人も含む。島にいるだけの人は含まない）。
- **倒れていた・抜けていた人**: 抽選はその場で済ませ、品は預かる（`TitanMemoryData` に UUID ごとに保存。再起動でも消えない）。目を覚ましたとき、入り直したとき、`/titanmemory claim` で渡す。倒れている人の持ち物に直接入れると復活時の預かり物の戻しで上書きされて消えるため、必ず預かる。
- **持ち物がいっぱい**: 入りきらない分も足もとに落とさず預かる。`/titanmemory claim` で受け取る。

## 7. 何度でも挑める仕組み

### 7.1 試練のリセット

- 次のどちらかでリセットされる。
  - 島に誰もいなくなってから **3 分（3600 tick）**。途中で一人でも戻ると計時は 0 に戻る。
  - 心臓を倒したあと、**封印の先（宝物庫・心臓の回廊・前室・心臓の間）に誰もいない状態が 30 秒**続いたとき。広場や島の他の場所に人がいても戻る。全員に「岩鯨の心臓が、再び脈を打ち始めた」。これで、島で誰かが待っていても次の周回に挑める。
- 毎回、**試練の番号**（`TitanBackData` の Epoch）が一つ進む。休み場の記録は番号つきで、番号が違うと無効。
- リセットの瞬間、作り直す所や封じる所（西の翼、闇の水路、東の翼の広間・控えの間・通路、宝物庫より奥）にいる人は鼓動の間へ移す。鼓動の間とその通路、西と東の前室、地表の人はそのまま。
- リセットされるもの: 三つの共鳴石（消灯）、封印と各抜け道、二つの広間（番兵は消え、入口は開き出口は閉じ、制圧の記録も消える）、西の足場と水路の形（新しい種）、心臓（消えて入口が開き、撃破の記録も消える）、宝物庫の封印と奥の扉（封印に戻る）。
- リセットされないもの: 島そのもの、天の鍵の欠片を受け取った人の一覧。

### 7.2 持ち物と経験値（倒れたとき）

- 背中の島で倒れると、持ち物と経験値はその場で預かられ、失わない（地面にも落ちない）。
- 預かり物は `PlayerPersisted` の `skyabyss_kept` に書く。死亡画面のまま「保存して終了」しても、サーバーを止めても残り、次に目を覚ましたとき返る。
- 消滅の呪いが付いた物は消える（預からない）。
- バニラの経験値の玉も落とさない（`TitanBackTrials.onExperienceDrop`）。経験値は持ち物と一緒に預かって戻すので、玉も落とすと二重になるため。背中の次元だけの扱いで、地上などの死は別の決まり（11 の 6 章。装備は残し、残りの持ち物と経験値の玉の分は消えない墓へ）。01 の「バニラを置き換えない」の例外で、追認待ち（10 章）。
- 預かり物を返す前にもう一度倒れたときは、前の預かり物を「足して返す分」に移す。目を覚ましたとき持ち物へ足し、入りきらない物は足元に置く。経験値も足す。生きたままログインしたのに預かり物が残っていたときも同じ。
- 預かるのは、ほかの仕組みが死を取り消さなかったときだけ（死亡イベントの最後に動く）。
- 地上のリスポーン地点（ベッドなど）は変わらない。大事な品（欠片・心核・呼び笛）の守りは 11。背中の死は、倒れたときの型（11 の 6 章。ゲームルール `skyabyssDeathMode`）に関わらず、このまま預かり（墓は作らない）。

### 7.3 背中での復活

- 背中で倒れて復活すると、記録された休み場へ戻される。休み場がない場合や、記録がリセットより前（番号が違う）の場合は広場へ。
- 休み場の記録が消えるとき: 乗り込み、地上へ戻る、焚き火であきらめる、試練のリセット。背中で倒れて連れ戻されるときは消えない。
- 復活位置は、焚き火のまわりの腰掛けを避けて、中心から斜めに 2 マス。鼓動の間は、中央の台座を避けて南へ 6 マス。足元と頭が空いていて床が固いかを確かめ、だめなら近く（横 5・上下 1）で立てる場所を探す。自己テストは全休み場の復活位置を調べる。
- ログインしたとき、背中にいて、最後に背中にいたときから試練の番号が変わっていて、体内（地表より下）にいる人は広場へ移す（封印の奥でログアウトしてリセット後にそこから始めることはできない）。

### 7.4 保存して終了・再起動

- 試練で湧いた番兵・番兵長・心臓はディスクに保存しない（戦いの状態はメモリにしかないため）。保存して終了すると消え、再起動のあとに二体にならない。古い保存の個体も読み込み時に消す。
- 再起動のあと背中が最初に動いたときに、制圧していない広間は最初に戻し（入口を開け出口を閉じる）、制圧した広間は入口と出口を開け、心臓の間の入口を開ける。

### 7.5 ピースフル（試練は眠る）

- ピースフルのあいだは試練に入れない。島に乗ること、地表を歩くこと、広場の炉を使うことはできる。
- **祠の封印**: 階段の 5 段目（z=34、x -1〜1、y 124〜127）を封印ブロックでふさぐ。ほかの難易度に戻ると消える。封印の手前まで下りると画面に「巨神は目覚めない。（難易度がピースフルのあいだ、試練は眠っている）」（チャットには出さない）。
- **体内にいる人**: ピースフルになったとき（またはそのままログインしたとき）、封印より奥の体内にいる人は広場へ移し、同じ文をチャットに一度出す。クリエイティブと観戦者は移さない。
- **戦いの途中でなったとき**: 試練の番兵・番兵長・心臓をすべて消し、閉じた扉を開け、広間と心臓を最初に戻す。告知は出さない。制圧の記録と共鳴石はそのまま。ピースフルのあいだは集合も始まらない。
- 心臓が撃破の報告なしに消えたときは、入口を開け、5 秒は湧かせ直さない（開け閉めとチャットの繰り返しを防ぐ）。
- 実装: `TitanBackTrials`（`tickShrineSeal`・`sleepForPeaceful`）。

### 7.6 休み場と「あきらめる」

- 魂の焚き火は、西の前室、第一・第二の休み場、東の前室、番兵長の控えの間、心臓の前室にある。
- 焚き火にしゃがんで右クリックすると、試練をあきらめて広場へ戻る（休み場の記録も消える）。しゃがまずに触れると「しゃがんで焚き火に触れると、試練をあきらめて背の入口へ戻れる」。

## 8. 背中の決まり（保護のルール）

島の中では、クリエイティブとスペクテイター以外に次の制限がかかる（`TitanBackRules`）。

| 制限 | 内容 |
|---|---|
| ブロックを壊せない | 掘り始めることもできない |
| ブロックを置けない | 置こうとしても拒まれる |
| 爆発で壊れない | 誰が起こしたものでも |
| 近道になる道具の使用を禁止 | 下記。使おうとすると「巨神の体は、よそ者の手を拒んでいる」 |
| エリトラで滑空できない | 背中のどこでも、滑空を始めるとすぐ止められる |
| ピースフルでは試練に入れない | 7.5 |
| 西の翼で跳躍とゆっくり落ちる効果が消える | 西の前室・三つの谷・二つの休み場では、跳躍とゆっくり落ちる効果（薬、食べ物、乗り込みのときの効果）を消す |

使用を禁止するアイテム: バケツ類（空・水・溶岩・粉雪）、エンダーパール、チョーラスフルーツ、風の機雷、花火ロケット、三叉槍、打火石、火薬玉、エンドクリスタル、TNT、TNT のトロッコ、リスポーンアンカー。

## 9. テスト用コマンドと自己テスト

### 9.1 コマンド

岩鯨と背中の操作は `/skyabyss titan` 以下で、権限レベル 2（OP）。

| コマンド | 内容 |
|---|---|
| `titan summon` | いる岩鯨を消し、向いている方向 120 ブロック先、高度 200 に新しく呼ぶ。出現済みフラグを立てる |
| `titan rest` | 岩鯨を自分のすぐ近くへ降ろし、鎖を垂らさせる |
| `titan board` | 岩鯨の背へ直接乗り移る（引き上げなし） |
| `titan leave` | 背中から地上へ戻る |
| `titan reset` | 建物はそのまま試練だけを最初に戻す（7.1 と同じ） |
| `titan rebuild` | 島を建て直し、進み具合も最初に戻す。天の鍵の欠片を受け取った人の記録は残る |

- 報酬の天井: `/titanmemory`（誰でも）、`/titanmemory choose <装備>`、`/titanmemory claim`、`/skyabyss memory set <人> <0-5>`・`/skyabyss memory clear <人>`（OP）。03 の 7.3。
- 空の通過の `/skyabyss pass`・`/skyabyss next` は別の機能。巨神での移動は `/skyabyss travel`（09）。

### 9.2 自己テスト（`SKYABYSS_SELFTEST`）

- `SELFTEST titan back`（layout・`checkSigns`・`checkWhale` ほか）:
  - 碑: 背中のチャンクの碑（`TabletBlockEntity`）が `allSigns()` の 9 枚だけで、どの行も 90 px に収まり、囁きの文が lang にある。
  - 鯨の形: 頭・左右の胸びれ・左右の尾びれ・背の塔・錨石の鎖がある。
  - 背の穴: 体の最上のブロックが空で下も空の所が、祠と広場のほかに 0。
  - 体の中が外とつながっていない: 鼓動の間から空気・水・溶岩・通れるブロックを辿り（2 万 5 千セル）、祠の封印の面より先へ行かず、鯨のブロックが無い所へ出ない（肋骨の窓のガラスで閉じている）。
  - 歩ける道: 到着から祠、階段で鼓動の間まで歩ける（上り 1・下り 3 まで）。220 歩以内（今は 118）。
  - 休み場の復活位置（`rest point hub` など）に苔の敷物が落ちていない。
  - ピースフルにすると封印が置かれ、番兵と心臓が消え、閉じた扉が開く。難易度を戻すと封印が消える。
- 迷路: リセット前後とも、チャンクを読み込んだまま 100 tick 水を流してから、正しい道の息継ぎごとに 3×3×2 の空気とその下の水源を数える（`titan back (maze settled)`、`titan back (reset maze settled)`）。作った同じ tick に数えると水が流れる前で見逃すため。
- 看板の実測: 開発クライアントの `SignFitClient`（3.5）。
