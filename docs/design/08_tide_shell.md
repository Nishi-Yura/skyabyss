## 1. 概要

海の沖に、珊瑚に覆われた島が浮かんでいる。次の日に見ると、島は少し動いている。それが第二の巨神「潮殻の巨神」だ。海の底を歩く山のような大亀で、甲羅の上に「潮の民」の遺跡と珊瑚礁を乗せている。

一日に二度、朝と夕の「干潮の刻」になると、潮殻の巨神は岸に近い浅瀬へ寄り、甲羅の縁を水の上に出して休む。プレイヤーは舟か泳ぎで近づき、甲羅の縁にある古い門「潮門」をくぐって、背中の島「潮殻の背」（専用のディメンション）へ渡る。

背中の島は、2 分ごとに満ち引きする潮に支配されている。潮位で通れる道が変わる。中央の「潮の広間」から、三つの試練に挑む。

- 西: 珊瑚の庭。潮の合間をぬって、大きな真珠を祭壇まで運ぶ（4.1節）
- 東: 潮見の間。水門を開け閉めし、三段の溜めの水位を合わせる謎解き（4.2節）
- 前: 群れの干潟。干潮のあいだに群れの巣を壊す。最後に中ボス「潮招き」が現れる（4.3節、5.2節）

三つの「潮鳴り石」を鳴らすと、潮の広間の水が引ききり、床の底の門が現れる。その下の「殻の底」で、最終ボス「潮殻の心臓」と戦う（5.3節）。報酬は岩鯨と同じく周回前提で、一人ずつの抽選と天井で集める（6章）。

### 1.1 岩鯨との違い

二体目で同じ遊びを繰り返さないことを、いちばんの条件にした。

| 観点 | 岩鯨（02） | 潮殻の巨神（この書類） |
|---|---|---|
| 地上での出会い | 空から降りてくる。待っていれば向こうから来る | 海で見つける。干潮の刻に合わせて、こちらから会いに行く |
| 乗り方 | 垂れた鎖を右クリックし、引き上げられる（受け身） | 舟か泳ぎで近づき、甲羅の縁の潮門をくぐる（自分で渡る） |
| 背中の主役 | 体内の肉と骨。暗い | 潮。2 分ごとの満ち引きで、道と敵が変わる。明るい外の場所が多い |
| 試練の型 | アスレ・波の戦い・暗い水中迷路 | 運搬（時間読み）・水位の謎解き・巣を壊す野外戦 |
| 敵 | 盾の番兵、射手、跳ぶ苔這い、水中の顎 | 潮で目覚める像、群れの小蟹、人を浮かせる泡の魚、動かない巣 |
| 中ボス | 閉じた広間で戦う番兵長（薙ぎ・跳躍・噴出） | 開けた干潟で潮を呼ぶ大蟹（局所の満ち潮で地形が変わる） |
| 最終ボス | 石の殻が段階ごとに剥がれる。床の輪を跳ぶ | 床が満ちて島へ逃げる、引き潮で引き寄せられる、月の大波を島でやり過ごす |
| 道中の水 | 迷路の中を泳ぐ（溺れる怖さ） | 水は「時計」と「地形」。深く泳がせない（最大 3 マス、どこでも息ができる） |

## 2. 潮殻の巨神（地上での振る舞い）

### 2.1 出現

| 項目 | 内容 |
|---|---|
| 出現条件 | オーバーワールドで、ワールドの総経過 tick が 4 日分（96000 tick）を超え、かつ空の通過（雲上の巡礼者の影）が一度起きたあと。岩鯨を倒している必要はない（1章の攻略順は自由） |
| 回数 | 自然な出現はワールドにつき一度。以後は見守り（2.7節）が同じ一体を保つ |
| 出現位置 | ランダムに選んだプレイヤー（観戦者を除く）から 200〜320 ブロック離れた海。海のバイオーム（海・深海・暖かい海など。川は除く）で、水深 12 以上の点を、読み込まれているチャンクから探す。見つからなければ、次のプレイヤーで 1 分後にやり直す |
| 通知 | なし。最初の出会いは「沖の島が動いた」と自分で気づく形にする（ホラーの「痕跡」と「間接」）。代わりに、出現から最初の干潮の刻まで、海辺にいる人に遠い潮騒の音を一度だけ鳴らす |

### 2.2 海を歩く（巡航）

- 海の底を歩く。甲羅の頂は、海面から 4〜6 ブロック出る。遠くからは、珊瑚の生えた低い島に見える。
- 速さは 0.08 ブロック/tick（毎秒 1.6）。岩鯨（0.2）よりずっと遅い。目を離したすきに位置が変わっている、くらいの速さにする。
- 目的地は、640 ブロック以内のプレイヤーから 160〜320 ブロック離れた海の点。近くにプレイヤーがいなければ、今の場所から海の中で 300 ブロック先。
- 陸には上がらない。前方 24 ブロックの海面の高さに水がなければ、向きを変える。浅瀬（水深 6 未満）にも、休む時（2.3節）のほかは入らない。
- 高さは「前方の海底の高さ + 体の高さ」を、毎秒 0.5 ブロックまでの変化でならす。海底の高さは、読み込まれているチャンクの `OCEAN_FLOOR` の高さマップだけを使う（同期の読み込みをしない。岩鯨と同じ）。
- 足もとの海底を削ったり、ブロックを置いたりはしない（エンティティだけで表す）。

### 2.3 干潮の刻と休息

ゲーム内の一日に二回、「干潮の刻」がある。その刻に合わせて岸に寄り、休む。

| 段階 | 内容 |
|---|---|
| 干潮の刻 | 朝（時刻 23000〜2600）と夕（11000〜14600）。それぞれ 3600 tick（3 分）。昼夜の長さに合わせ、ゲーム内の時刻で決める |
| 寄る相手を選ぶ | 刻の 1200 tick（1 分）前に、海から 160 ブロック以内にいるプレイヤーを選ぶ。潮見の貝（2.6節）で呼んだ人がいれば、その人を優先する |
| 休む場所 | 選んだ人から 64 ブロック以内の海で、水深 6〜14、岸（陸のブロック）から 40 ブロック以内の点。見つからなければ、その刻は寄らない |
| 接近 | 刻が始まるまでに休む場所へ向かう。間に合わなければ、刻の途中でも着いたところで休む |
| 休息 | 刻が終わるまで止まる。体を少し持ち上げ、甲羅の縁を水面の 1〜2 ブロック上に出す。潮門（2.4節）が水から出る |
| 通知 | 休む場所から 200 ブロック以内に「潮が引いていく。沖の島が、浅瀬へ寄ってくる……」（語りの色） |
| 刻の終わり | 縁を沈め、巡航に戻る。背中に人がいても戻る（背中から出る人は、休んだ場所の岸へ戻す。2.5節） |

- 夜の干潮も、朝の干潮も、怖さの演出は足さない。海の上で大きなものが静かに寄ってくること自体を見せ場にする。
- 刻の外に遭った人のために、巡航中も甲羅の上には背中の遺跡の灯りが小さく見える（発光テクスチャ）。

### 2.4 乗り込み（潮門）

- 潮門は、甲羅の後ろ左の縁にある石の門（モデルの `gate` 骨）。休息中は、門の敷居が水面の 1 ブロック上に来る。
- 門の口に、見えない当たり判定「潮門の口」（`TideGateEntity`。岩鯨の鎖の当たり判定と同じ作り）を置く。幅 3・高さ 4・奥行き 2。
- **門の口に入ると、背中へ渡る。右クリックは要らない。** 舟か泳ぎで門まで行き、縁の段（モデルの一部。当たり判定は 2 段の階段だけ、2.4.1節）を上がって門をくぐる。
- 渡るときは、画面が水の色に 1 秒ほど沈み、潮の音が鳴る。背中の島がまだ建っていなければ建て、潮門の浜（到着地点）へ移す。
- 舟に乗ったまま門の口に入ったときは、舟から降ろしてから渡す。舟は門の前に残る。
- 門の 16 ブロック以内にいる人には、2 秒ごとに「潮門をくぐると、背中へ渡る」と出す（休息中だけ）。

#### 2.4.1 縁の段

- 門の前の 2 段の階段だけは、プレイヤーが立てる当たり判定にする（`TideGateEntity` が持つ、ボートと同じ「乗れる箱」2 つ）。休息中は巨神が動かないので、ずれない。
- 巨大なモデル全体には当たり判定を付けない（岩鯨と同じ。描画だけ）。

#### 2.4.2 鎖をやめた理由

| 理由 | 内容 |
|---|---|
| 体験を分ける | 岩鯨は「向こうから降りてきて、引き上げられる」。潮殻は「海へ出て、自分で渡る」。舟の出番と、時刻を読む楽しみができる |
| 主題に合う | 潮が引くと門が水から出る。乗る前から、このダンジョンの主題（潮）を見せられる |
| 作りやすい | 引き上げの途中の扱い（ログアウト、死亡、遠ざかる）が要らない。岩鯨の 2.5節の表の大半が不要になる。鎖の「上るとき体にぶつかる」問題も起きない |
| 弱み | 海の近くにいないと会えない。干潮の刻を待つ必要がある。→ 潮見の貝（2.6節）と、一日二回の刻で和らげる |

乗り方の別案は 15 章の判断 1。

### 2.5 背中から地上へ戻る

| 方法 | 内容 |
|---|---|
| 潮門をくぐる | 背中の潮門の浜にある門の口に入ると戻る。巨神が休んでいれば、門の前の水の上（縁の段）へ。休んでいなければ、最後に休んだ場所の岸（陸の一番近い立てる場所）へ。記録もなければ共有スポーン地点の上へ |
| 島の端から海に落ちる | 背中のまわりの海に落ちると、潮に流され、5 秒後に潮門の浜へ戻される（地上へは戻さない）。「潮に押し戻された」と出す |
| 島から遠く泳ぎ出る | 島の中心から 160 ブロックより外へ泳ぐと、潮門の浜へ戻される |
| コマンド | `/skyabyss titan leave` |

- 背中から出るときは、溺れないよう水中呼吸 10 秒を付ける（休んでいない巨神の上の海に出ることがあるため）。

### 2.6 潮見の貝

海で巨神を探す手間を減らす道具。

| 項目 | 内容 |
|---|---|
| 入手 | 鯨追いのサブクエスト「潮のにおい」（07 に足す。15 章の判断 3）、難破船と海底遺跡の宝箱（20%）。作業台では作らない |
| 手に持つ | 画面に、巨神の向き（耳に当てた貝の音の左右）と、次の干潮の刻までの時間を出す。距離は「遠い・近い・すぐそこ」の三段だけ |
| 吹く（右クリック） | 海から 32 ブロック以内で、干潮の刻の 1 分前から刻の途中までに吹くと、その刻は自分のそばへ寄るよう頼める。一つの刻に一人だけ。クールダウンは刻が変わるまで |
| マルチ | 誰か一人が吹けば、その刻の休む場所が決まる。ほかの人の貝にも「○○の近くへ寄る」と出る |

### 2.7 見守り（見失わない・一体だけ）

岩鯨の `WhaleKeeper` と同じ仕組みを使う（10 章で `TitanKeeper` に共通化する）。違いだけ書く。

| 項目 | 岩鯨 | 潮殻 |
|---|---|---|
| 呼び直しの位置 | プレイヤーの 280 ブロック先、高度 200 | プレイヤーから 200〜320 ブロックの海（2.1節と同じ探し方）。海が見つからなければ、最後の位置のまま待つ |
| 記録 | `TitanWorldData` に UUID・位置・状態 | 同じデータに、巨神ごとの項目として足す（`tide_shell`） |
| チャンクの読み込み | 640 ブロック以内に人がいる間 | 同じ。加えて、休息中は休む場所のチャンクも読み込む |

## 3. 背中の島と配置

### 3.1 ディメンション（岩鯨と分ける）

潮殻の背は、岩鯨の背（`skyabyss:titan_back`）とは別の専用ディメンション `skyabyss:tide_back` にする。

| 観点 | 共有する（同じディメンションの離れた所） | 分ける（推奨） |
|---|---|---|
| 見た目 | 空・霧・水の色が岩鯨と同じになる。岩鯨は雲の海の上、潮殻は海の上で、合わない | 生成を「平らな海」（海面 y=62 まで水）にでき、背中のまわりが本物の海になる。水の色と霧を変えられる |
| コード | 背中のデータ（`TitanBackData`）を巨神ごとに分ける作り直しが要る | `TitanBackData` はディメンションごとに保存されるので、そのまま二つ持てる。共通化（10 章）とも合う |
| 決まりの範囲 | 位置で巨神を見分ける必要がある | ディメンションで見分ければよい |
| 費用 | 登録は増えない | JSON 3 つ（dimension、dimension_type、biome）だけ |

- 生成は平らな世界: 岩盤 1 層、砂 40 層、水を海面 y=62 まで。地形も構造物も置かない。島は岩鯨と同じく、最初の乗り込みのときにコードで建てる。
- 空は地上と同じ（時刻は地上と共有）。夜は月が見える。近づいてくる月を海の上で見上げる場面にする。
- 水の色は青緑、霧はうすい青。天気は晴れのまま。

### 3.2 島の形

島は甲羅の形をした楕円（頭は -Z）。縁の高さは y=66 前後、頂は y=100。幅 128（x -64〜64）、長さ 152（z -80〜72）。岩鯨の背（長さ 240）より小さくし、到着から中央の広間まで 1 分以内で歩ける広さにする（岩鯨の「1 周が長い」の反省）。甲羅の前には首と頭が海から出ていて、首と前のひれのあいだが干潟になる。

### 3.4 潮の周期と、道が変わる仕組み

背中の島の全体に、一つの潮の時計がある。

| 段階 | 長さ | 潮位 |
|---|---|---|
| 干潮 | 50 秒 | 0（水なし） |
| 満ちる | 10 秒 | 0 → 最大へ。一段ずつ上がる |
| 満潮 | 50 秒 | 最大（場所ごとに 2〜3 マス） |
| 引く | 10 秒 | 最大 → 0 |

- 一周 2 分。満ちはじめる 10 秒前に、法螺貝のような低い音（潮鳴り）が島じゅうに鳴る。引きはじめる 10 秒前には、高い音。
- **潮見の目盛り**: 背中にいる間、画面の右上に小さな貝の目盛りを出す。今の潮位と、次に変わるまでの秒数（目盛りが減っていく）。パーティクルの設定に左右されない（岩鯨の必須4 の反省）。
- **水の置き方**: 潮で満ちるのは、壁で囲んだ「潮の溜め」だけ（広間の水盤、庭の水路、干潟）。流れる水は使わず、水の源のブロックを一段ずつ置き、一段ずつ消す。隣の更新を起こさないフラグで置く。一回の切り替えで動かすブロックは合計約 6500。10 秒に分けて、1 tick あたり 35 前後にする。
- 満ちたときに水の中にいる人は、そのまま浮かぶ。最大 3 マスなので、どこでも水面に顔を出せる（溺れない）。

**道が変わる場所（潮の広間）**

| 行き先 | 干潮 | 満潮 |
|---|---|---|
| 東・潮見の間 | 広間の壁ぞいの長い螺旋の坂を回る（約 40 秒） | 水盤に入って水面まで浮かび、上の回廊へ一段上がる（約 5 秒） |
| 前・群れの干潟 | 干潟の門が開いている（歩いて行ける） | 門は水の下で、格子が閉じる |
| 西・珊瑚の庭 | 通れる | 通れる |
| 下・潮の底の門 | 三つの石がそろうまで閉じている | 同じ |

- 待つことはあっても、閉じ込められることはない。どの潮でも、広間から浜へ戻る道と西の庭への道は開いている。干潟の側にいる人が満潮で広間へ戻れないときも、待つのは最長 60 秒で、干潟の前室の焚き火からいつでも浜へ戻れる。
- 最初の一回は、碑文と語りで「潮を待て」と教える（「水が満ちれば、上へ。引けば、前へ」）。

## 4. 三つの試練

三つの試練は、どれから挑んでもよい。潮鳴り石は、どの順でも鳴らせる（前の石だけは潮招きを倒すまで黙る）。2 周目からは、三つのうち一つが「眠る」（7.2節）。

### 4.1 西の試練 珊瑚の庭（真珠運び）

構成: 西の庭の門 → 庭の入口（休み場 `g0`）→ 大貝の淵 → 潮除けの台を渡る道 → 祭壇（西の潮鳴り石）。

**目的**: 庭の奥の淵にいる大貝から「潮の真珠」を取り出し、祭壇まで運んで据える。据えると西の石が鳴る。

| 項目 | 内容 |
|---|---|
| 潮の真珠 | 運ぶあいだは持ち物に入る、特別な品。一度に一つだけ島にある。持っている人は鈍足 I、全身がうすく光る（ほかの人から見える） |
| 道のり | 大貝から祭壇まで約 70 ブロック。途中に、高さ 4 の「潮除けの台」が 4 つ（そのうち一つが休み場 `g1`）。台と台のあいだは、干潮のあいだだけ乾いている低い水路 |
| 満潮 | 水路が 3 マス満ちる。真珠を持った人が、頭まで水に入ると、真珠は潮に引かれて大貝へ戻る（「真珠が潮に引かれていった」）。足や腰まで濡れるのはよい |
| 干潮 | 水路が乾く。代わりに、庭の珊瑚憑き（5.1節）が目を覚ます |
| 落とした・渡した | 真珠は投げて仲間に渡せる。地面に落ちた真珠は 15 秒で大貝へ戻る。庭から出ると大貝へ戻る |
| 倒れた | 持っていた人が倒れると、真珠は大貝へ戻る（預かり物には入れない） |
| 道の形 | 珊瑚の壁で、台から台への道の分かれ方を三通り用意し、リセットの種で選ぶ。どれも、干潮 50 秒で 1 区間を歩いて渡れる長さ（最長 18 ブロック）にする |

- **流れ**: 干潮で走る → 満ちる前に台へ上がる → 満潮のあいだは台の上で泡吹きの泡をしのぐ → 引いたら次の区間へ。潮の時計を読む遊び。
- **一人のとき**: 珊瑚憑きを倒しながら運ぶ。台の上で満潮を待つあいだに、次の区間の珊瑚憑きの位置を見ておける（満潮のあいだは像になって止まっている）。
- **マルチ**: 一人が運び、ほかの人が珊瑚憑きを倒す。真珠を投げ渡せば、足の速い人へ託せる。
- **理不尽にしない**: 泡吹きの泡は真上へ浮かせるだけで、横へは押さない。台から押し落とされて真珠を失うことはない。台の上には、満潮でも水が届かない。
- 推定の所要時間: 慣れた人で 4〜6 分（干潮 4 回ぶん前後）。

### 4.2 東の試練 潮見の間（水位の謎解き）

構成: 上の回廊（満潮）か螺旋の坂（干潮）→ 潮見の前室（休み場 `s0`）→ 三段の溜め → 最上段の岩棚（東の潮鳴り石）。

**目的**: 三段に重なった溜め（上・中・下）の水位を、水門の栓で動かし、浮き石を足場にして最上段の岩棚まで上がる。

| 仕掛け | 内容 |
|---|---|
| 潮の栓（3 つ） | 右クリックで開け閉めする石の栓。開けると、上の溜めの水が下の溜めへ一段ずつ移る（2 秒に一段） |
| 浮き石 | 溜めの水面に浮かぶ 3×3 の石の足場。水位と一緒に上下する。水がなくなると底に着く |
| 重石の床 | 立っている間だけ、つながった栓の向きを逆にする床。二人いると近道ができる（一人でも解ける） |
| 戻しの栓 | 前室にある。引くと、三段の溜めを最初の水位に戻す（30 秒に一度）。詰んだ状態を作らない |
| 潮から切り離す | 潮見の間の溜めは島の潮の時計とは関係なく、栓でだけ動く（潮の民が潮を手なずけた部屋、という設定） |

- **解き方の数**: 手で作った四つの配置（栓のつながりと最初の水位）から、リセットの種で一つを選ぶ。どれも最短 5〜7 手。最初の配置だけは、ワールドで初めて挑むときに必ず使う、いちばんやさしいもの。
- **手がかり**: 栓の上の石に、つながる溜めを示す刻み（溝の線）。溜めの壁に、浮き石が届く高さの目盛り。
- **敵**: 前室の手前と中の溜めの縁に泡吹きが 2〜3 体。謎解きを急かすほど多くはしない。
- 推定の所要時間: 慣れた人で 3〜5 分（初めてなら 8〜10 分）。

### 4.3 前の試練 群れの干潟（巣と群れの戦い）

構成: 干潟の門（干潮だけ開く）→ 干潟の前室（休み場 `f0`）→ 群れの干潟（巣が 3 つ）→ 潮招き（中ボス）→ 前の潮鳴り石。

**目的**: 干潟に散らばる三つの「群れの巣」を壊す。三つとも壊れると、次の干潮で中ボス「潮招き」が砂の中から現れる。倒すと前の石が鳴る。

| 項目 | 内容 |
|---|---|
| 干潟 | 48×32 の砂の干潟。高さ 3 の岩の島が 8 つ。巣の候補地は 6 か所で、リセットの種で 3 つを選ぶ |
| 干潮 | 巣が開き、5 秒ごとに磯走りを 2 体ずつ出す（一つの巣から生きているのは最大 6 体）。巣に傷が通るのは開いている間だけ |
| 満潮 | 干潟が 2 マス満ちる。巣は殻を閉じて傷が通らない。磯走りは水に入ると動きが鈍る。泡吹きが水面の上に 2 体出てくる。岩の島の上は濡れない |
| 巣の強さ | 体力 60 ×（1 + 0.6 ×（干潟にいる人 − 1））。人数は巣が最初に開いたときに数える |
| 群れの数 | 一つの巣から生きている磯走りの上限は 6、人が一人増えるごとに +2（最大 4 人まで数える） |

- **流れ**: 干潮の 50 秒で巣を叩く。満ちたら岩の島へ上がり、泡吹きを落とす。一つの巣は、一人でも干潮 1〜2 回で壊せる強さにする。
- **岩鯨の広間との違い**: 扉を閉じて波をしのぐのではなく、開けた場所で「攻める時」と「退く時」を潮が決める。巣を壊す順番と、立つ岩を選ぶ遊び。
- **中ボスの始まり**: 最後の巣が壊れると、5 秒の予告のあと、坂の下の「干潟の口」と前の抜け道が閉じる（岩鯨の参加の決まりと同じ。閉じたとき干潟と、坂と前室にいた人が参加者）。次の干潮の始まりに、潮招きが中央の砂から現れる。満潮の最中に壊したときは、引くまで待つ（最長 60 秒。「砂の下で、何かが脚を動かしている」）。
- **全滅・退出**: 干潟に生きている参加者がいなくなって 3 秒たつと、潮招きは砂に潜って消え、門が開く。壊した巣は壊れたままで、次は潮招きからやり直す。
- 推定の所要時間: 巣 2〜3 分、潮招き 2〜3 分。合わせて 5〜7 分。

### 5.2 中ボス「潮招き」

片方のはさみだけが大きな、山のような蟹。大きなはさみを振ると潮が呼ばれる。干潟の中央の砂から現れる。体の幅 4 ブロック。

| 技 | 条件 | 流れ | ダメージ |

| 大鋏の打ち下ろし | 距離 6 未満、クールダウン明け | 1.0 秒、はさみを高く上げる（音と影）。前方 幅 3・長さ 7 の帯を打つ。打ったあと、はさみが 1.5 秒 砂に刺さって抜けない | 12。刺さっている間、はさみへの傷は 1.5 倍 |
| 招き潮 | 30 秒ごと（怒り時は 20 秒） | 1.5 秒、大きなはさみを手招くように振る（低い潮鳴り、潮見の目盛りが赤く光る）。そのあと 8 秒、干潟だけが 2 マス満ちる（島の潮の時計とは別）。満ちている間、潮招きは速さ II | なし。満ちた水の中では、打ち下ろしの帯が水の線になって 2 倍の長さで走る |

### 5.3 最終ボス「潮殻の心臓」

## 7. 何度でも挑める仕組み

岩鯨の 7 章の仕組みをそのまま使う（共通化は 10 章）。違うところだけ書く。

### 7.1 試練のリセット

- 条件は岩鯨と同じ: 島に誰もいなくなって 3 分、または心臓を倒したあと、潮の底の門より奥に 30 秒だれもいない。
- リセットされるもの: 三つの潮鳴り石、抜け道、潮の底の門（閉じて、広間の水盤がまた満ち引きする）、真珠（大貝へ）、潮見の間の水位と配置、干潟の巣（新しい種で 3 か所）、潮招きと心臓、庭の道の形と珊瑚憑き。
- 潮の時計は、リセットのときに「干潮の始まり」に戻す。
- リセットの瞬間に試練の中にいる人は、潮の広間へ移す。

### 7.2 眠る試練（2 周目から）

- ワールドで潮殻の心臓が一度でも倒されたあとは、リセットのたびに三つの試練のうち一つが「眠る」。その石は最初から鳴っている。
- 選ぶのはリセットの種。同じ試練が二回続けて眠らないようにする。
- 浜の碑文の下の石盤と、乗り込みの語りで知らせる（「今宵、東の石はすでに鳴っている」）。
- 1 周の目安: 初回 25〜35 分（潮見の間と真珠運びに慣れるまで）、2 周目から 12〜18 分。

| 区間 | 推定（慣れた人） |
|---|---|
| 浜 → 潮の広間 | 1 分 |
| 珊瑚の庭 | 4〜6 分 |
| 潮見の間 | 3〜5 分 |
| 群れの干潟と潮招き | 5〜7 分 |
| 潮の底 → 心臓 | 3〜4 分 |
| 三つとも | 16〜23 分 |
| 一つ眠るとき | 12〜18 分 |

岩鯨には眠る試練がまだない。共通の部品にして、岩鯨にも入れる（15 章の判断 6）。

### 7.3 倒れたとき

- 持ち物と経験値の預かり、休み場からの復活は岩鯨と同じ（02 の 7.2〜7.3節）。
- 休み場: `hub`、`g0`、`g1`、`s0`、`f0`、`heart` の 6 つ。焚き火にしゃがんで触れると、試練をあきらめて浜へ戻る。
- 真珠を持って倒れたときは、真珠は預からず大貝へ戻す（4.1節）。

### 7.4 ピースフル

- 01 の決定どおり、試練は眠る。縁のくぐり道（浜から広間への坂）を封じ、「巨神は目覚めない」と出す。浜を歩くこと、炉を使うことはできる。
- 島の潮の時計は、ピースフルでも動かす（景色として）。
- 処理は岩鯨の `sleepForPeaceful` と同じ部品を使う。

### 7.5 マルチプレイ

| 場面 | 決まり |
|---|---|
| 乗り込み | 潮門は何人でも同時にくぐれる。誰かが潮見の貝を吹けば、その刻の休む場所が決まる |
| 潮 | 島で一つの時計。全員が同じ潮を見る |
| 珊瑚の庭 | 真珠は島に一つ。投げ渡せる。珊瑚憑きは人が一人増えるごとに +2 体（最大 4 人まで数える） |
| 潮見の間 | 栓は誰でも動かせる。重石の床で二人の近道がある。一人でも解ける |
| 群れの干潟 | 巣の体力と群れの数が人数で増える。中ボスの参加者は岩鯨の決まり（5 秒の予告、前室の人も入れる、倒れても参加者のまま） |
| 心臓 | 岩鯨と同じ参加の決まりと体力の式 |
| 報酬 | 一人ずつの抽選。人数で取り分は減らない |

## 8. 背中の決まり

岩鯨の 8 章の決まり（`TitanBackRules`）をそのまま使う。加えて次を禁止する。

| 追加の制限 | 理由 |
|---|---|
| 舟を置けない（背中の海と水路のどちらも） | 満潮の水路を舟で渡ると、真珠運びの時間読みがなくなる |
| 氷渡りのエンチャントの氷ができない | 満潮の水の上を歩けてしまう |
| イルカの好意を、真珠を持っている間は消す | 運びを速くしすぎない（ほかの時は使ってよい） |

- 水中呼吸、水中歩行、水中採掘のエンチャントや薬は使ってよい。準備した人へのごほうびにする。
- エリトラの禁止、ブロックの設置と破壊の禁止、バケツと近道の道具の禁止は、岩鯨と同じ。

### 19.8 見た目の直し: 泥色の殻 → 真珠の殻と光る三日月（2026-10-16）

ゲームの心臓が、ラフ B（淡い真珠色・灰紫の殻、段階 3 は白銀の三日月）と違って泥のような茶色に見え、段階 3 の三日月もくすんでいた。

- 原因 1（主）: 部屋の明かり。仮の部屋は閉じていて空の光が 0、ブロックの光だけ（11〜13）。この明るさの明かりの色は黄から橙に寄る（ブロックの光は弱いほど青が先に落ちる）。淡い灰紫の殻に掛かって茶色になった。
- 原因 2: テクスチャが暗い。ラフは面の向きの陰を焼き込み、揺らぎも掛けるので、殻の平均は (168, 155, 166) の灰紫。ゲームではそこへ実体の面の陰がもう一度掛かる。
- 原因 3（段階 3）: GeckoLib の `AutoGlowingGeoLayer` は光る画素を基から抜き、面の陰を受ける描き方で描く。殻を明るくすると、三日月・水滴が殻と同じ灰白に沈む（光って見えない）。
- 法線の向きの問題ではなかった（ラフと同じ向き。ゲームの読み方の確認の絵でも差はない）。

直したこと（心臓の見た目のファイルだけ。部屋は変えていない）:

- `TideHeartRenderer`: 心臓の光をブロックの光 15 で描く（`getBlockLightLevel`）。明かりの色が白になり、暖色の茶色が消える。面の陰は残るので形は読める。
- `TideHeartRenderer.GlowLayer`（`AutoGlowingGeoLayer` の代わり）: 基のテクスチャはそのまま描き、その上に `_glowmask` の色を目の光（`RenderType.eyes`: 陰なし・足し合わせ）で重ねる。発光の絵の色が足す光の強さ。光らない画素は黒。光る画素は 256 / 964 / 2192 のまま（ゼロではない）。
- `tools/install_tide_heart.py` の `pearlize`: 彩りの薄い画素（殻と心臓の真珠）を段階ごとの真珠の色へ寄せる（明るさの幅 0.72〜1.0、画素の場所でごく薄く桃と青の光沢を交互に乗せる）。珊瑚の赤・血管の紫・フジツボはそのまま。段階 1 は薄紫の真珠 (230, 220, 240)、段階 2 は真珠の白 (238, 230, 234)、段階 3 は銀青がかった白 (222, 228, 244)。
- 光る画素（基の色 + 足す光）: 段階 1・2 の核と光る部屋は青緑 (120, 236, 214) + (40, 90, 80)、段階 3 の三日月と核は白銀 (214, 226, 248) + (100, 100, 100)、水滴の輪は青みの白銀 (184, 228, 250) + (80, 88, 92)。バーの色（段階 1 青緑、段階 2 真珠の白、段階 3 銀青）と合わせた。
- 仮の部屋（海晶の箱）の明るさは足りている（明かりは 19.6節で足した）。殻が淡くなり、青緑の壁から浮いて見えるので変えていない。本番の部屋も、心臓が自分の光で描かれるので部屋の暗さに左右されない。

### 20.5 休み場・倒れたとき・リセット・ピースフル・背中の決まり

- 休み場 hub (南の段)・g0・g1 (C の台)・s0・f0・heart。記録は試練の番号つき (`TitanBackData.epoch`)。焚き火にしゃがんで触れると浜へ。倒れると持ち物と経験値は岩鯨と同じ部品 (`TitanBackTrials.keepBelongings`、預かりの判定を「背中の一覧」に広げた) で預かり、休み場で目を覚ます。真珠は預からず大貝へ。
- リセット (7.1節): 島に誰もいなくなって 3 分、または心臓のあと潮の底の門より奥に 30 秒だれもいない (心臓の担当の「部屋と前室に 30 秒」をこちらへまとめた)。石・巣・潮招き・庭の道の形・潮見の配置・潮の底の門・時計を戻し、試練の中の人は広間へ。
- 眠る試練 (7.2節): ワールドで心臓が一度倒されたあとは、リセットのたびに一つが眠る (石が鳴っている)。同じ試練は二回続けない。浜の看板と、乗り込み・リセットの一行で知らせる。
- ピースフル: くぐり道を封じ、浜の外の人は浜へ。試練の敵は消える。潮の時計は動く。
- 背中の決まり: 舟 (第一歩から)、氷渡りの氷は水に戻す、真珠を持つ間はイルカの好意を消す。

### 20.8 テスト

- コマンド (OP): `/skyabyss titan reset tide`、`titan tide <low|high|cycle>`、`titan sleep tide <west|east|front|none>`、`/skyabyss tideback go <場所> | ring <試練> | status | watch <下> <中> <上> | nests`。
