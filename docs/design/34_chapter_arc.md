## 0. 要約

- **物語の背骨**: 「鼓動を、一度、下へ返す」。四つの章で、主人公は①歌に呼ばれ（一章）、②背の民がなぜ巨神に乗ったかを知り（二章）、③自分が前にもここへ来ていたと気づき（三章）、④心臓を止めることが「殺す」ではなく「借りた鼓動を地の底へ返す」ことだと知って、鍵が下を指す理由を得る（四章）。巨神に挑む意味が、好奇心 → 使命 → 疑い → 覚悟、と章ごとに変わる。
- **前の私の足跡**: 一〜三章を貫く仕掛け。前のループの自分（見る者）が残した頁・荷・道しるべを、主人公は「誰かの跡」として辿る。支度の段はすべてこの跡を辿る形にし、**バニラの進み（鉄・エンチャント・ダイヤ・醸造）は「前の私がそうしていた」理由で勧める**。正体は三章の鏡の間で気づく（六章で確定。01 のまま）。
- **章の型（クエスト）**: 噂 → **支度（2〜3 段。ミニダンジョン 1 つ＋バニラの目標 1 つ）** → 見る（予兆） → 乗る → 背（順路。32） → 心臓 → 報告（世界の一片） → 引き。支度は勧めであって鍵ではない（備えの三灯が警告するだけ。21 の 1.2。決定 215）。一章の支度 3 段はメインの段（決定 214）。
- **一章の支度**: 鉄の跡（骨の坑で鉄 → 鉄の防具 4 部位）／折れた剣（割れ殻の洞 → 鉄の剣と砥石）／盾と糧（盾・固焼き・鼓動守）。メインを進めるだけで鉄フル・鉄剣になる。二章の柱は**船と難破船**（決定 216。エンチャントの段は入れない）。
- **五章へ**: 各章の報告で「いつつめの詩」の一行が埋まり、四章の終わりに鍵が下を指す。五章は「鍵の指す方へ掘る」から始められる。

## 1. 世界の真実と、章ごとに明かす順

01 の 3 章の世界観はそのまま。ここでは「いつ・何を・誰から」を決める。

| 章 | 主人公が知ること | 誰から・どこで | まだ言わないこと |
| --- | --- | --- | --- |
| 序章 | 人がいない。空を何かが通る。帳面の最初の一行「忘れないうちに書け」 | 野営地の帳面、語り部、空の影 | 帳面の書き手 |
| 一章 | 巨神は生きていて歌う。背に滅んだ町がある。心臓は「地の底から預かったもの」（碑文）。欠片は四つ。**自分より前に、同じ道を同じ支度で歩いた旅人がいた**（頁・荷・石標） | イサナ（追う人）、背の碑文、前の私の頁 | 旅人が自分であること |
| 二章 | **背の民はなぜ巨神に乗ったか**: 空が初めて落ちかけた遠い昔、地の底の心臓が巨神を起こし、人は巨神の背へ逃れた。巨神は鼓動を借りて歌い、月を遠ざけていた。欠片は「鍵がそろったら、下へ」という民の最後の指図 | 潮の民の碑（海辺 3 枚・甲羅の中）、塩の蔵の頁、語り部の「村の記憶」 | 心臓が弱っている理由 |
| 三章 | **前にもここへ来た者がいる**。風の民の書に「留まる者」が何度も来たと記され、眼の間の鏡に自分の姿が遅れて映る。見る者がこちらを見る理由。イサナは地上に残ると決める | 風の民の頁、眼の間、イサナ、語り部の祖母の話 | ループの仕組み、月 |
| 四章 | **心臓を止めるとは、借りた鼓動を下へ返すこと**。鼓動は地の底で保たれ、やがて巨神へ戻る（だから巨神は眠るだけ）。四つを返した者にだけ、鍵が「下」を指す。語り部とイサナは別々の答えを言う（返すべきか、巨神を眠らせてよいのか） | 灰の鍛え手（中ボス。話す前の構え）、灰の民の炉跡の頁、天の鍵の場面 | 地の底で何が待つか（五章） |

- **五章への糸**: 数え歌「いつつ　いきづく　つちのそこ」（14 の 99）の一行を四章の終わりに明かし、鍵が足もとへ脈を打つ。各章の報告で語り部が数え歌を一行ずつ取り戻す（ひとつ・ふたつ・みっつ・よっつ → いつつ）。五章は「鍵の指す方へ掘る」から始められ、巨神編の品（欠片・心核・笛・歌片）は五章でも使う。

## 2. 前の私の足跡（三章まで貫く仕掛け）

- **何か**: 前のループの自分が残したもの。今ある「破れた頁」（17）、「前の私の頁」（21 の 3.3）、鯨道の石標の一行、荷車の持ち主（失せ物の旅人）を**一つの人物の跡**にそろえる。名前は出さない。語り部は「この字、どこかで」と言い続ける（05 の 6・01 の 3）。
- **見え方の段**: 一章 = 道具と頁（「鉄を着ろ。背の風は骨まで冷える」）、二章 = 塩の蔵の壁の刻み（「潮は読める。待て」）と筏の跡の頁、三章 = 風の民の書に「留まる者は、また来た」と鏡の間の遅れた影、四章 = 炉跡の頁「四つ返したら、下へ。今度こそ」。
- **決まり**: 頁は人ごとに記される（伝承の書）。跡の荷は人ごとに一度（`SiteTreasure`）。中身は**その章のバニラの目標の「最初の一歩」**（鉄 2 個と松明、本 1 冊、銅 4 個、ブレイズパウダー 1）。全部はくれない（自分で集める理由を残す）。
- **ループの整合**: 見る者（06）はこの人物の影。三章まで正体を言わず、見る者の近さの段階（06 の 2）は変えない。

## 3. 支度の段の作り（バニラとの融合の決まり）

1. **目標はバニラの品や行為**（鉄の防具・鉄の剣・盾・エンチャント・ダイヤ・醸造）。mod の品に置き換えない。クエストは持ち物と進捗（バニラの進捗 `story/*` と mod の進捗 19）で数える。
2. **理由は物語**（前の私の頁・NPC の一言・碑文）。「作れ」だけの段は作らない。
3. **道筋は mod が示す**: 目的の帯に「鉄の防具を作ろう（2/4）」、場所の印（地図 33）、ミニダンジョンの中に素材の「最初の一歩」。
4. **鍵にしない**: 支度を飛ばしても巨神に乗れる。備えの三灯（21 の 1.2）が「鉄なし」を警告するだけ。経験値と頁は支度を済ませた人だけ。
5. **章ごとに一つの「バニラの柱」**: 一章 鉄、二章 船と難破船（海を渡る）、三章 銅と雷・ダイヤ、四章 醸造（とネザー）。これで四章までに、バニラの RPG 的な進みが一巡する。エンチャントは勧めない（自由に。決定 216）。
6. **ミニダンジョンは章に一つ**（10〜15 分、3 部屋、名づきの主。21 の型）。背の試練の予習を兼ねる（21 のまま）。
