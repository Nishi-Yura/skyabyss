## 1. 概要

雷翼の心臓が止まったあと、ある晩、畑の向こうの丘が少し近づいている。丘の背から煙が細く立ち、そのまわりにだけ灰が降る。それが第四の巨神「余燼の巨神」だ。地の中を泳ぐ、山のような火蜥蜴（ひとかげ）で、昼は土の下を進み、背の尾根だけを地上に出す。夜になると地上へ浮かび上がり、火山のように眠る。

眠っている巨神は、地面に顎を下ろし、ゆっくり息をしている。息を吸うあいだだけ、その口は開いたままになる。**プレイヤーは自分の足で、巨神の口の中へ歩いて入る**。口の奥は背中のディメンション「余燼の背」につながっていて、そこには地上で見たのと同じ形の巨神が、ブロックで横たわっている。ダンジョンはその**体の中**にある。

体の中は熱い。背中にいるあいだ、一人ずつに「熱」がたまる（3.4節）。熱は溶岩や噴気でたまり、灰溜まりで冷える。高すぎると焦げるが、ほどほどに火照っていると、灰の殻をまとった敵を割りやすい。この熱が、余燼の背の手ざわりの軸になる（潮殻の潮にあたる）。

胸の「炉心の広間」から、三つの試練に挑む。

- 西: 灰の道。溶岩の湖に灰をまいて、冷えた殻の道を自分で作り、崩れる前に渡る（4.1節）
- 東: 鍛えの間。灰の民の大炉で、熱の色を読んで「火の鍵」を鍛え、焼き入れる。鍵で扉を開くと、中ボス「灰の鍛え手」が目を覚ます（4.2節、5.2節）
- 南: 火守り。背の亀裂の底で、消えかけた火床に熾をくべて燃やし続ける。亀裂から噴く熱で、火を消しに来る敵を焼く（4.3節）

三つの「熾り石（おこりいし）」が鳴ると、広間の中央の炉が冷え、炉の底の格子が開く。その下の「熾の底（おきのそこ）」で、最終ボス「余燼の心臓」と戦う（5.3節）。報酬は岩鯨・潮殻と同じく周回前提で、一人ずつの抽選と天井で集める（6章）。

心臓が止まると、四つ目の天の鍵の欠片が手に入る。四つの欠片がそろうと一つの「天の鍵」になり、1 章が終わる（9.4節）。

### 1.2 雷翼（並行して設計中）と被らないようにしたこと

雷翼の装備案（03 の 3.3節）は「上昇気流の足場を飛び移る」「落雷の予告線を避ける」。余燼では次を避けた。

| 雷翼に近くなりそうな案 | 余燼での扱い |
|---|---|
| 噴気に乗って上へ飛ぶ（上昇気流と同じ） | 噴気は乗り物にしない。当たると熱がたまり、敵を焼く「地形の武器」にする（4.3節） |
| 噴気の予告を見て避けるだけ（落雷の予告線と同じ） | 避けるだけでなく、敵を噴気の上へ誘い込む遊びにする。噴く順は火床のまわりで決まった巡り（読める） |
| 空・光・雷の色（青白・黄白） | 黒い玄武岩・灰色の灰・赤と橙の熾・溶けた黄。青と白は使わない（焼き入れの水と湯気だけ） |
| 飛ぶ敵が主役 | 飛ぶのは小さな蛾（火の粉蛾）だけで、熱に寄る群れ。主役は地を歩く・転がる敵 |
| 高い所・落ちる怖さ | 体の中の低く熱い場所。落ちる先は溶岩（落ちても休み場へ戻るだけ） |

## 2. 余燼の巨神（地上での振る舞い）

### 2.1 出現

| 項目 | 内容 |
|---|---|
| 出現条件 | オーバーワールドで、**ワールドの誰かが雷翼の心臓を止めたあと**（10 の 3.2節）、その次の日の出。地の中を泳ぐ姿（尾根だけ）で現れ、最初の夜に初めて眠る。止めた直後に足もとから現れて驚かせないためと、最初の出会いを「昼に丘が動いた」にするため |
| 回数 | 自然な出現はワールドにつき一度。以後は見守り（2.8節）が同じ一体を保つ |
| 出現位置 | ランダムに選んだプレイヤー（観戦者を除く）から 200〜320 ブロック離れた陸。海・深海・川・凍った海のバイオームを除く。地表（`WORLD_SURFACE`）が海面より 2 以上高い点を、読み込まれているチャンクから探す。見つからなければ、次のプレイヤーで 1 分後にやり直す |
| 通知 | なし。最初の出会いは「丘が動いた」「灰が降る」と自分で気づく形にする。代わりに、出現から最初の眠りまでのあいだ、出現点から 160 ブロック以内にいる人に、地の底のうなりを一度だけ鳴らす |

### 2.2 地の中を泳ぐ（潜行）

- 昼は土の下を進む。地上に見えるのは背の尾根（背の飾りの上の部分）だけで、地面から 6〜10 ブロック出る。遠くからは、煙を上げる細長い岩の丘に見える。
- 速さは 0.06 ブロック/tick（毎秒 1.2）。三体の中でいちばん遅い。
- 目的地は、640 ブロック以内のプレイヤーから 160〜320 ブロック離れた陸の点。近くにプレイヤーがいなければ、今の場所から陸の中で 300 ブロック先。
- 高さは「前方 24 ブロックの地表の高さ − 体の沈み」を、毎秒 0.5 ブロックまでの変化でならす。地表の高さは読み込まれているチャンクの `WORLD_SURFACE` の高さマップだけを使う（同期の読み込みをしない。岩鯨・潮殻と同じ）。山は「山の下をくぐる」（尾根も一時見えなくなる）。
- 海と川の下には入らない。前方 30・60 ブロックに水面があれば向きを変える（水の下で光る尾根が泳ぐと、潮殻と見分けにくいため）。
- **ブロックは壊さず、置かない**。体はエンティティだけで、地面に埋まった部分は地形に隠れて見えない（描画の深さで自然に隠れる）。プレイヤーの建物も壊さない。
- 通るときのしるし（ホラーの「痕跡」と「間接」）:
  - 尾根の割れ目から灰色の煙（バニラの粒 `ash`・`white_ash` と煙）。
  - 48 ブロック以内の人に、低い地鳴りと画面の微振動（クライアント設定 `screenShake` で弱められる）。
  - 32 ブロック以内の動物は、尾根から離れるように逃げる（空の影の「うずくまる」とは違う反応にする）。
  - 洞窟の中にいる人には、壁の向こうを大きなものが通る音（足音ではなく、岩をこする音と遠い鼓動）。2 章「壁の向こうの足音」の先触れ。洞窟の空気に巨神の体が見えることがあるが、それはそのままにする（見てしまった、という怖さ）。

### 2.3 夜の眠り（浮かび上がる）

| 段階 | 内容 |
|---|---|
| 眠る場所を選ぶ | 日没の 1200 tick（1 分）前に、640 ブロック以内のプレイヤーを一人選ぶ。温石（2.6節）で呼んだ人がいればその人を優先する。その人から 24〜64 ブロックの陸で、口の前 16 ブロックが平ら（高さの差 3 以内）な点を 10 秒ごとに探す（見つかるまで。同じ夜で二度は寄らない） |
| 浮かび上がる | 時刻 12500 から、30 秒かけて地上へ浮かぶ。体は地面に伏せた形（腹は地表の 1〜3 ブロック下、脚は地に埋まる）、顎を地面に下ろし、口を選んだ人へ向ける。浮かぶあいだ、まわりに灰が舞い、地鳴りが強まる |
| 眠り | 時刻 23000 まで止まる。背の飾りから煙が立ち、割れ目が赤く光る。口の奥が橙に光る。息をしている（2.4節） |
| 灰の降る範囲 | 眠っているあいだ、巨神から 256 ブロック以内の人のまわりに灰（`white_ash`）が降る。近いほど多い（三段）。空がうすく赤くなる。**遠くから巨神を探す手がかり**にする（描画距離の外でも、灰はその人のまわりに降るので見える） |
| 通知 | 眠る場所から 200 ブロック以内に「土の匂いが熱い。どこかで、山が寝息をたてている……」（語りの色） |
| 夜明け | 時刻 23000 で、10 秒かけて地の中へ沈み、潜行に戻る。背中に人がいても沈む（背中から出る人は、眠った場所の口の前へ戻す。2.5節） |

- 眠る場所の点は、口の前に人の建物があっても気にしない（ブロックを壊さないので被害はない。体が建物に重なって見えるだけ）。試遊で気になれば、近くにベッド・作業台などがある点を避ける判定を足す（15 章の判断 7）。
- 夜にしたのは、熾の赤い光がいちばん映えるのが夜で、見つけやすく、怖いからだ。夜は 10 分（ゲームの一日の半分）あるので、潮殻の干潮の刻（3 分 × 2）より会いやすい。

### 2.4 息と口（乗り込み）

眠る巨神は、18 秒で一回息をする。口の前に立つと、息がはっきり分かる。

| 息 | 長さ | 口の前（口から 16 ブロック、幅 60 度の扇） |
|---|---|---|
| 吸う | 8 秒 | 灰と火の粉が口へ吸いこまれていく（粒）。低い吸気の音。口へ向かって弱く引かれる（毎 tick 0.02、歩けば逆らえる） |
| 止める | 2 秒 | 静か。口の奥の光が強まる |
| 吐く | 6 秒 | 熱い風。口の前の人を外へ押す（毎 tick 0.12）、2 秒ごとに 1 秒燃やす（バニラの燃焼。火炎耐性で防げる）。灰の粒が吹き出す |
| 間 | 2 秒 | 静か |

- **口の口（入口）**: 見えない当たり判定「熱の口」（`EmberMouthEntity`。潮殻の `TideGateEntity` と同じ作り）。舌の上、幅 5・高さ 4・奥行き 4。**吸うと止めるのあいだ（10 秒）だけ、入ると背中へ渡る**。右クリックは要らない。吐くあいだは、入ろうとしても押し出される。
- 渡るときは、画面が橙に沈み（潮殻の `Plunge` と同じ部品、色だけ変える）、呑みこむ低い音が鳴る。背中の体がまだ建っていなければ建て（サーバーの起動時に建てておくので、ふつうは建っている。3.1節）、口の中の到着点へ移す。
- 乗り物（馬・ストライダー・トロッコ・舟）に乗ったまま入ったときは、降ろしてから渡す。乗り物は口の前に残る（ストライダーで溶岩の湖を渡れないように）。
- 口の 24 ブロック以内にいる人には、吸うあいだだけ 2 秒ごとに「息を吸っているあいだに、口へ」と出す（初めて会った夜だけ。以後は出さない。看板を減らす決定と同じ考え）。
- 巨大なモデル全体には当たり判定を付けない（岩鯨・潮殻と同じ。描画だけ）。顎は地面に下りているので、地面から歩いて舌へ上がれる（舌の当たり判定は要らない。判定の箱が地面の高さから始まる）。
- 乗る資格（10 の 3.3節）: 自分で雷翼の心臓を止めていない人は、熱の口に入っても渡らず「巨神の息が、あなたを吐き出した。まだ早い」と出して押し出す。クリエイティブと観戦者は問わない。

#### 2.4.1 鎖・潮門をやめて「口」にした理由

| 理由 | 内容 |
|---|---|
| 体験を分ける | 岩鯨は「引き上げられる」、潮殻は「泳いで門をくぐる」、余燼は「息を読んで、自分の足で口に入る」。三体とも乗る前の数秒が違う |
| 主題に合う | 体の中へ入るダンジョンの入口が、そのまま口。「呑まれる」ことが、1 章の最後の山場の始まりになる |
| 作りやすい | 潮殻の門の判定（`TideGateEntity`）と画面の沈み（`Plunge`）をそのまま使える。地上にブロックを置かない |
| 弱み | 夜しか乗れない → 夜は 10 分あり、背中に入れば朝まで出なくてよい。背中にいるあいだに夜が明けても、背中から追い出さない（2.5節） |

乗り方の別案は 15 章の判断 1。

### 2.5 背中から地上へ戻る

| 方法 | 内容 |
|---|---|
| 口から出る | 背中の口の到着点の前、下の顎の先にある「見送りの段」を下り、いちばん下の光る「見送りの石」（3 × 2）に 0.5 秒いると戻る（潮殻の 20.12節の 0.5 秒と同じ）。巨神が眠っていれば口の前 6 ブロックの地面へ（巨神に背を向ける）、潜行中なら最後に眠った場所の口の前、記録もなければ共有スポーン地点 |
| 灰の原に下りる・落ちる | 見送りの石のほかの灰の原に 5 秒いると、到着点へ戻される（地上へは戻さない）。「灰に押し戻された」 |
| 遠くへ歩く | 体の中心から 220 ブロックより外へ出ると、到着点へ戻される |
| コマンド | `/skyabyss titan leave` |

- 背中から出るときは、出る位置の地表を上から探して立たせる（巨神が沈んだあと、地面の中に出ないように）。熱は 0 に戻す。

### 2.6 温石（おんじゃく）

巨神を探す手間を減らす道具。潮殻の潮見の貝と同じ仕組みで、中身だけ違う。

| 項目 | 内容 |

### 3.1 ディメンション

- 生成は平らな世界「灰の原」: 岩盤 1 層、深層岩 20 層、玄武岩 16 層、上に凝灰岩と滑らかな玄武岩の斑（高さ y=63 まで）。地形も構造物も置かない。巨神の体は、**サーバーの起動時に一度だけ**コードで建てる（潮殻の 20.12節の決定と同じ。新しいワールドで約 7〜11 秒）。

|---|---|

- **準備のごほうび**: バニラの火炎耐性の効果があると、熱のたまり方が半分。熾火の角杯（6.5節）は 0.6 倍（強いほうだけ効く）。余燼の鎧 4 部位は 0.7 倍で、これだけは重ねられる（下限 0.4 倍）。
- **火炎耐性で全部が無効にならないようにする**: 焦げの傷、噴気、心臓と鍛え手の技は、炎の傷の種類（`#is_fire`）に入れない。火炎耐性が防ぐのはバニラの燃焼と溶岩の傷だけ。溶岩に落ちたときは溶岩の傷ではなく「呑まれた」扱い（4.1節）にするので、火炎耐性で溶岩を泳いで渡ることもできない（溶岩の湖の溶岩に入ったら、すぐ休み場へ戻す）。
- **熱の目盛り**: 背中にいる間、右上に小さな火の目盛り（潮殻の `TideGaugeHud` を共通の部品 `BackGaugeHud` にして使う）。今の熱の柱と、50・85 の線、火照り・焦げの文字。パーティクルの設定に左右されない。
- 熱は背中を出ると 0 に戻す。死んだら 0。ループで消えても困らない（保存しない）。

## 4. 三つの試練

三つはどれから挑んでもよい。熾り石はどの順でも鳴らせる（東の石だけは鍛え手を倒すまで黙る）。2 周目からは、三つのうち一つが「眠る」（7.2節）。

### 4.1 西の試練 灰の道（道を作って渡る）

構成: 灰の道の口 → 入口の岸（休み場 `w0`、灰の壺を受け取る）→ 溶岩の湖と島々（中ほどの島が休み場 `w1`）→ 奥の岸（西の熾り石）。

**目的**: 溶岩の湖に灰をまいて「冷え殻」の道を作り、崩れる前に渡って、奥の岸の熾り石を鳴らす。

| 項目 | 内容 |
|---|---|
| 灰の壺 | 入口の岸の台に触れると、持ち物に入る特別な品。湖から出ると消える（台に戻る）。右クリックで、向いている先 4 ブロック以内の溶岩の面に灰をまく。**灰は 5 回分**。島の「灰溜まり」に触れると満ちる |
| 冷え殻 | 灰をまいた所の溶岩（3 × 3、表面だけ）が、黒い殻（専用のブロック `cooled_crust`）になる。上を歩ける。**12 秒で崩れる**: 8 秒までは黒、8〜11 秒で割れ目が赤く光り、ぴしぴし鳴る、11〜12 秒で沈み、溶岩に戻る |
| 島 | 湖に 7 つ。島と島のあいだは 8〜12 ブロック（灰 3〜4 回で渡れる）。島には灰溜まりがあり、熱も冷やせる。島の並びはリセットの種で 3 通りから選ぶ |
| 熱 | 冷え殻の上は 1 秒に +1、殻の縁（溶岩から 2 以内）では +3。湖を一気に渡ると火照り・焦げかけになる。島で冷やしながら進む |
| 落ちる | 溶岩に入ると「呑まれた」: すぐ、最後に立った島（なければ入口の岸）へ戻し、4 の傷と熱 +30。持ち物は失わない（溶岩の傷ではないので、品は燃えない） |
| 敵 | 火の粉蛾の群れ（5.1節）が湖の上を飛ぶ。熱に寄るので、冷え殻と火照った人を狙う。**蛾が触れた冷え殻は 3 秒早く崩れる**。大きな島には燠虫が 1〜2 体（転がって人を湖へ落とそうとする。当たると押される） |
| 道の形 | 島の並び 3 通りのどれも、灰 5 回で次の島へ届く。最短の道と、遠回りだが蛾の少ない道がある |

- **流れ**: 島で灰を満たし、熱を冷やす → 灰をまきながら次の島へ急ぐ → 蛾を払う（殻が早く崩れる）→ 島へ。島ごとに一息つける。
- **一人のとき**: 自分の道を作って渡る。蛾は叩けば一撃で落ちる（体力 8）。
- **マルチ**: 一人一つ壺を持てる。冷え殻はだれでも歩けるので、先の人の道を後の人が使える。二人で並べて道を広げる、片方が蛾を払う、の分担ができる。
- **岩鯨の西の翼との違い**: 岩鯨は「決まった崩れる足場を跳んで渡る」。灰の道は「足場を自分で作り、作った足場が崩れる」。跳ぶ腕前ではなく、灰の数・道の選び方・熱の管理の遊び。
- **潮殻の真珠運びとの違い**: 運ぶ物がない。時間を決めるのは島の時計ではなく、自分がまいた殻の寿命。
- **理不尽にしない**: 殻は少なくとも 8 秒は崩れない（蛾が触れても 5 秒は残る）。殻の上に人がいる間は、最後の 1 秒（沈む）を最大 3 秒まで待つ（足もとから急に消えない。割れ目の光と音で 3 秒前に分かる）。落ちても島へ戻るだけ。
- 推定の所要時間: 慣れた人で 3〜5 分。

### 4.2 東の試練 鍛えの間（色を読んで鍛える）

構成: 鍛えの間の口 → 前室（休み場 `e0`）→ 大炉と鞴・金床・焼き入れの槽 → 鍛え手の扉 → 中ボスの間（灰の鍛え手）→ 東の熾り石。

**目的**: 灰の民の大炉で「火の鍵」を鍛える。鞴で炉の熱を上げ、鉄の色が指示どおりの時に金床で打つ。三度打てたら焼き入れの槽へ運んで冷やし、鍵で扉を開ける。

| 仕掛け | 内容 |
|---|---|
| 大炉 | 炉の口に灰鉄の塊が載っている。炉の熱は 0〜100 で、塊の色で分かる: 黒（0〜19）→ 赤（20〜44）→ 橙（45〜69）→ 黄（70〜89）→ 白（90〜100） |
| 鞴 | 大炉の横の踏み板（2 つ）。踏む（板に乗る・跳んで乗り直す）と、炉の熱が 1 回につき +12。熱は 1 秒に −4 で下がる。**一度上がった熱はゆっくり下がる**ので、一人でも踏んでから金床へ走れる（鞴から金床まで 8 ブロック、約 2 秒） |
| 金床 | 鎚の台を右クリックすると、炉の塊を打つ。金床の上の「刻み」（3 つの色の印。光る羊毛の色）が、打つ順の色を示す（例: 赤 → 黄 → 橙）。指示の色のときに打つと一打目が入る（金床に火花、高い音）。違う色で打つとひび（2 回で塊が割れ、5 秒後に新しい塊）。白で打つと、すぐ割れる |
| 打つ順 | 手で作った 4 通り（赤黄橙、橙赤黄、黄橙赤、赤橙黄赤（四打））から、リセットの種で一つ。ワールドで初めて挑むときはいちばんやさしい「赤 → 橙 → 黄」（上げていくだけ） |
| 焼き入れ | 三打（四打）できると、塊が光る「火の鍵」になって持ち物に入る（熱 +20）。**10 秒以内に**焼き入れの槽（水）へ入れる（右クリック）。間に合わなければ鍵は冷えて割れ、塊からやり直し。鍵を持つ人は光り、火の粉蛾が寄ってくる |
| 鍛え手の扉 | 焼き入れた火の鍵を差しこむと、扉の文様が奥へ灯っていき、開く。5 秒の予告のあと、中ボスの戦いが始まる（参加の決まりは岩鯨・潮殻と同じ） |
| 炉を冷やす敵 | 灰被りが前室の奥から 2〜3 体（+1/人）。灰被りが大炉に触れると、灰をかけて炉の熱を −30 にする（「炉に灰が投げこまれた」）。鞴の踏み板の近くで戦うことになる |

- **流れ**: 鞴を踏む → 熱の色を見ながら金床へ → 打つ → 次の色へ熱を合わせる（上げるなら踏み、下げるなら待つ）→ 三打 → 槽へ走る → 扉。
- **一人のとき**: 鞴を 3〜5 回踏んで熱を作り、下がっていく途中で目当ての色に入ったら打つ。順が「黄 → 橙」のように下げる手は、待てばよいので一人のほうがやりやすい。
- **マルチ**: 一人が鞴、一人が金床、一人が灰被りを止める。声をかけ合う遊び（「黄になった、打って」）。
- **潮殻の潮見の間との違い**: 潮見の間は水の行き先を考える「場所の謎」。鍛えの間は「時の謎」（熱の上がり下がりの読みと、打つ瞬間）と分担。
- **手がかり**: 塊の色、炉の口の光の色、金床の刻み（色の印）、打てる色に入った瞬間の小さな「ちん」という音。看板は入口の一言だけ。前室の囁きで「色が合ったら打て」と一度だけ。
- **理不尽にしない**: 割れても塊は 5 秒で戻る。鍵を冷やしそこねても塊からで、打った回数は戻るが、敵は増えない。熱は 1 秒に −4 なので、白で止まり続けることはない（待てば必ず色が下がる）。
- 推定の所要時間: 鍛え 2〜4 分、鍛え手 2〜3 分。合わせて 4〜7 分。

### 4.3 南の試練 火守り（火を絶やさない戦い）

構成: 亀裂の口 → 谷の入口（休み場 `s0`）→ 背の亀裂の谷（噴気の割れ目が 10 本）→ 谷の奥の「余燼の火床」→ 南の熾り石。

**目的**: 谷の奥の火床に、消えかけの火（余燼）が残っている。火床の火を 100 まで燃やせば、南の石が鳴る。火は放っておくと消えていき、灰を運ぶ敵が消しに来る。

| 項目 | 内容 |
|---|---|
| 火床 | 火の強さ 0〜100（火床の炎の高さと色で分かる。熱の目盛りの下にも小さく出す）。始めは 20。1 秒に −0.5 で弱まる。0 になっても失敗にはしない（20 から焚き直す。「火が、また小さくなった」） |
| 熾 | 敵を倒すと「熾」が落ちる（倒した人だけでなく、だれでも拾える）。熾を持って火床に右クリックすると +8。熾は持っていると熱が 1 秒に +1 |
| 灰運び | 灰被り（5.1節）は、ここでは背に灰の籠を負う「灰運び」として、谷の手前から火床へ歩いてくる。火床に着くと灰をかけ、火を −15 にする。人を見ると戦うが、火床を優先する |
| 噴気の割れ目 | 谷の床と壁の割れ目 10 本。決まった巡り（20 秒で一周）で、2〜3 本ずつ噴く。噴く 1.5 秒前に割れ目が白く光り、しゅうと鳴る。噴気に当たると、人は熱 +25 と 6 の傷で少し上へ跳ね、**敵は 30 の傷**（灰被りの灰の殻は一度で割れる）。灰運びを噴気の上へ誘いこむと速い |
| 火の粉蛾 | 火が 60 を超えると、谷の上（亀裂）から蛾の群れが降りてくる。蛾は火床に寄り、触れた火を −2 する（数が多いと痛い）。火照った人にも寄る |
| 燠虫 | 谷の中ほどに 2 体。転がって人を噴気の割れ目へ押す |
| 人数 | 灰運びの数と火の弱まり方が人数で増える（+1 体/人、弱まり +0.2/秒/人。最大 4 人まで数える） |

- **流れ**: 灰運びの列を止める → 熾を拾って火床へ → 噴気の巡りを覚えて、敵を割れ目へ誘う → 60 を超えると蛾が来るので払う → 100。
- **岩鯨の東の翼との違い**: 閉じこめられて波をしのぐのではない。谷は開いていて、出入りは自由（入口の焚き火へ戻れる）。敵は人ではなく火を狙う。地形（噴気）が自分の武器にも害にもなる。
- **潮殻の群れの干潟との違い**: 巣を壊す（攻める）のではなく、火を守って育てる（守る）。攻める時と退く時を決めるのは潮ではなく、噴気の巡りと火の強さ。
- **雷翼との違い**: 噴気に乗って飛ばない（当たると小さく跳ねるだけ）。予告を避けるだけではなく、敵を誘いこむ。
- **理不尽にしない**: 火は 0 になっても試練は失敗しない。噴気の傷は 6 で、熱 +25 は灰溜まり（谷に 3 か所）ですぐ冷やせる。燠虫に押されても、噴く割れ目の上でなければ何も起きない。
- 推定の所要時間: 3〜5 分。

### 5.2 中ボス「灰の鍛え手」

## 13. 見直しの記録（4 周）

### 13.1 1 周目: 岩鯨・潮殻・雷翼と体験がかぶっていないか

| 気づいた点 | 直したこと |
|---|---|
| 最初の案の乗り方が「眠る巨神の尾を登って背中へ」だった。巨大なモデルに当たり判定を付けないと登れず、付けると重くずれる。体験も岩鯨の「上る」に近い | 口へ歩いて入る形にした。判定は潮門と同じ見えない箱で済み、「呑まれる」が体の中のダンジョンの入口になる |
| 噴気の試練を「噴気に乗って上の段へ」にしかけた。雷翼の上昇気流と同じ | 噴気は乗り物にせず、当たると熱がたまり、敵を焼く「地形の武器」にした（4.3節） |
| 噴気を「予告を見て避けるだけ」にすると、雷翼の落雷の予告線と同じ遊び | 敵を噴気へ誘いこむ遊びと、決まった巡り（覚えられる）にした |
| 「床が時間で崩れる」をそのまま入れると、岩鯨の西の翼の崩れる足場と同じ | 足場を自分で作り、作った足場が崩れる形にした（灰の道）。跳ぶ腕前ではなく、灰の数と熱の管理の遊び |
| 一つ目の謎解きを「溶岩の血管の弁を回して流れを繋ぐ」にしていた。潮殻の潮見の間（水の行き先）とほぼ同じ | 場所の謎をやめ、熱の色を読む「時の謎」と分担（鍛えの間）にした |
| 溶岩の中に住む敵（溶岩から跳ねる蛭）を入れていた。岩鯨の水路の顎（水の中だけの敵）と同じ役 | 外した。三種目は丸まって転がる燠虫にした |
| 心臓の段階を「殻が剥がれていく」にしかけた（岩鯨の心臓と同じ） | 段階の主題を「熱を読む → 床が欠ける → 部屋が冷える」にした。ラフの B（熔け殻）は「剥がれる」ではなく「溶けて垂れる」にした |
| 背中の時計（潮）のような島じゅうの周期を、もう一つ作りかけた | 熱は人ごと（3.4節）にした。周期を持つのは噴気の巡りと息だけで、どちらも短く局所 |

### 17.3 熱の API（`titan.ember.back.EmberHeat`）

| 呼び方 | 中身 |
|---|---|
| `add(player, 量, Reason)` | 熱をためる。量に `gainMultiplier`（B が書く倍率）がかかる。背中の外・観戦者・クリエイティブでは動かない。負の量は `cool` と同じ。新しい熱を返す |
| `cool(player, 量)` | 冷ます（倍率なし） |
| `get(player)`、`band(player)`、`flushed(player)` | 今の熱、帯（`NORMAL` 0〜49・`FLUSHED` 50〜84・`SCORCHING` 85〜99・`SCORCHED` 100）、火照りか（灰の殻 2 倍・鎧の攻撃 +10% の判定） |
| `set(player, 値)`、`reset(player)` | コマンドとテスト用、0 に戻す（背中を出た・死んだ・リセットで広間へ移した） |
| `affects(player)` | 熱が効く人か（余燼の背にいて、観戦者・クリエイティブでない） |
| `Reason` | `LAVA_NEAR`・`HOT_GROUND`・`SHAFT`・`VENT`・`MOTH`・`ROLLER_TRAIL`・`ENGULFED`・`FIRE_KEY`・`LIVE_COAL`・`SMITH`・`HEART`・`OTHER` |
| 定数 | `MAX` 100、`FLUSHED` 50、`SCORCHING` 85 |

- 骨組みの中身: 値の保持（保存しない）・0〜100 に収める・背中を出る／死ぬ／ログアウトで 0・クライアントへ同期（変わったら 5 tick ごと、変わらなくても 2 秒ごと。`EmberHeatClient.heat()`）。
- B が書く所は 2 つの空の関数: `gainMultiplier(player, reason)`（火炎耐性 0.5、角杯 0.6、鎧 0.7 など）と `tickPlayer(player)`（ふだんの冷え、溶岩のそば、灰溜まり、水、焦げの傷 `EmberIds.HEAT`、火照りの光、85 の警告 `EmberSetup.HEAT_WARN`）。
- 傷を与える側の約束: 焦げは `EmberIds.HEAT`、噴気・亀裂の噴き・心臓の地形の熱は `EmberIds.HEAT_BURST`、溶岩に落ちたときは `EmberIds.ENGULFED`（溶岩の傷を使わない）。敵の打撃（鎚・火掻き棒など）はふつうの mob の攻撃。

### 17.5 共通化の使い方

- `TitanBodyBlocks`: `new TitanBodyBlocks(EmberIds.BODY_BIN)` を static に一つ持ち、`place(level, flags, y -> y <= EmberBackLayout.PLAIN_TOP ? 灰の原の層 : 空気)` で置く。`shellTop`・`top`・`at` で地表を引く。表が置かれる前は `present()` が false。
- `BackGaugeHud`: 目盛りのクラス（`@EventBusSubscriber(value = Dist.CLIENT)`）の static 初期化で `BackGaugeHud.register(mc -> 出ているか)` を一度呼ぶ。描くときは `w = width(g, 中身の幅, 最小)`、`x = left(g, w)`、`y = top(mc)`、`frame(...)`、`text(...)`。仲間の表示は登録された板の下へ自動で並ぶ。
- `TitanGate`: `EmberTravel.PASSAGE`（`new TitanGate("ember", Titans.EMBER, 60, 10)`）。熱の口に入ったら `PASSAGE.admit(player)` が true のときだけ `EmberTravel.board`。見送りの石は `PASSAGE.dwell(player, 中にいるか, 2)`。
- 雷翼の 12 の 10.2節は同じものを `BackShape`・`BackGaugeHud` と呼んでいる。雷翼の担当が先に同じ名前のファイルを作っていたら、合わせるときに片方へ寄せる（中身は潮殻からの同じ切り出し）。

### 19.2 部屋の中身を建てる受け口（`EmberBackRooms`）

C1・C2・E・C3・F は、自分の Setup の共通の準備で一度だけ次を呼ぶ（`SkyAbyss` は触らない）。

| 呼び方 | いつ B が呼ぶか |
|---|---|
| `EmberBackRooms.register("west", (level, box) -> …)` | 体を建てるとき。B が箱を掘ったあと（箱の中はすべて空気、いちばん下の段にだけ仮の床）。部屋は west → east → smith → south → heart の順。何度呼ばれても同じ物になるように書く |
| `EmberBackRooms.onReset("west", (level, sleeping) -> …)` | 試練のリセットのたび（箱の中の人を広間へ移したあと）。`sleeping` はこの周その部屋が眠っているか（東が眠ると smith も） |

| 呼び方 | 中身 |

| `EmberBackTrials.markReady(level, Trial.EAST)` | 石を鳴らせるようにする。東は E が鍛え手を倒したとき、南は C3 が火床を 100 にしたとき。西は B が奥の岸に人が着いたのを見る |
