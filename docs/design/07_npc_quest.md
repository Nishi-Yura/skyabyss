## 2. 物語の流れ（メインクエスト「雲の下の歌」）

序章の空の影から、岩鯨の心臓を止めて天の鍵の欠片を手にするまでを、一本の道にする。

| 段 | プレイヤーが知ること | やること | 済ませ方（フック先） |
| --- | --- | --- | --- |
| 始まり | 晴れた昼に空が暗くなった | — | 空の影を初めて見る（伝承 `prologue/shadow`）か、先に岩鯨を見つける（`chapter1/stone_whale`）と自動で始まる。語り部に「空のことを」と尋ねても始まる |
| 1 | 影の年には遠い空から“歌”が聞こえる。歌を追う旅人がいる | 村の語り部に尋ねる | 語り部の節 `shadow3` に入る |
| 2 | 歌の主は空を泳ぐ岩の鯨。降りてきて鎖を垂らす | 村の外れの鯨追いに話を聞く | 鯨追いの節 `c_whale2` に入る（鯨追いは、この段のときに村の外れへ火を焚いて現れる） |
| 3 | 歌が聞こえたら空を見ろ | 岩鯨をその目で見る | 伝承 `chapter1/stone_whale`（160 ブロック以内に岩鯨） |
| 4 | 鎖をつかめば背中へ | 鎖をのぼり背中へ渡る | 伝承 `chapter1/sky_ruins`（岩鯨の背に入る） |
| 5 | 背中には崩れた町。三つの道の先に碑文 | 碑文を読む（西・東・水路、0/3） | 伝承 `chapter1/inscription_west/east/below` |
| 6 | 封印の奥で何かが脈を打つ | 心臓を止め、欠片を手にする | 伝承 `chapter1/heart_stilled` と `chapter1/sky_key` |
| 7 | 欠片はほのかに温かい | 村へ戻り、語り部か鯨追いに見せる（どちらか一つ） | 語り部 `fragment3` か鯨追い `c_fragment2` |
| 終わり | 残る三つはほかの巨神の中に | — | 経験値 200、好感度（両方 +5） |

- **目的は伝承の書の記録で数える。** 碑文・心臓・欠片・岩鯨は、伝承の書がすでに拾っている出来事なので、クエストはその記録（`Lore.state`）を読むだけにした。岩鯨の試練のコードには手を入れていない。
- **順番を外しても詰まらない。** 伝承の記録は消えないので、先に背中へ行っていた人は、その段に着いたとたんに済む。先に岩鯨を見つけた人は、1・2 段（語り部と鯨追い）を飛ばす（`skip_if`）。最後の段は語り部と鯨追いのどちらでもよい。
- **ピースフルでは 5 段で止まる。** 02 の決定どおり、ピースフルでは試練が封じられて碑文の奥へ進めない。難易度を戻せば続きから進む。

## 3. NPC

### 3.1 人物

| | 語り部（`skyabyss:storyteller`） | 鯨追い（`skyabyss:whale_chaser`） |
| --- | --- | --- |
| 人物 | 村の年寄り（老婆）。空の影、数え歌、七日目の夜、見る者を語り継ぐ。空を見上げる者を心配している | 何年も岩鯨を追っている旅人。鎖をつかめたことが一度もない。空に「呼ばれている」気がしている |
| 役目 | メインの入口と終わり。村の言い伝え（伝承の書の序章の項目）を話で記す | 岩鯨の話。背中へ行った人の話を聞きたがる。サブ「鯨のかけら」の依頼主 |
| 口調 | 「〜だね」「〜おくれ」。言い切らず、話をそらす | 短く、ぶっきらぼう。「〜だ」「〜な」 |
| ほのめかし | 書の字に見覚えがある、見る者は「覚えている」、七日目の夜を守らなかった家は残っていないだけかも | 削られた峰は「鯨じゃない、もっと大きな何か」、心臓が止まった朝に歌が少し変わった |
| 見た目 | 腰の曲がった小柄な老婆。藍の肩掛け、帯、結び目のある縄（結縄）、白髪の髷と簪（3.4 節） | 痩せて背が高い。膝下までの外套、つばの広い帽子（鯨骨の留め具と羽）、背の袋（地図・鍋） |
| 当たり判定 | 0.6 × 1.6 | 0.6 × 1.95 |

名前は付けず、役で呼ぶ（画面と名札に「語り部」「鯨追い」）。村ごとに別の語り部がいるので、固有の名前があると「同じ人がどの村にもいる」違和感が出るため（13 章の判断 2）。

### 3.2 どこに現れるか

| | 語り部 | 鯨追い |
| --- | --- | --- |
| きっかけ | オーバーワールドで、プレイヤーが村の集会所の鐘（POI `meeting`）から 48 ブロック以内に来たとき | 同じく村の近くで、そのプレイヤーの進行中のクエストが鯨追いを必要としているとき（今の段階に「鯨追いと話す」目的がある、または依頼主が鯨追い） |
| 場所 | 鐘から 2〜6 ブロック、足もとが固く 2 ブロック空いた所 | 鐘から 18〜34 ブロックの、空の見える自然の地面（土・草・砂・砂利・雪・石）。隣（2 ブロック先）に焚き火を置く。場所がなければ鐘のそば（火なし） |
| 数 | 村（鐘）ごとに一人 | 村ごとに一人（必要になった村にだけ） |
| いなくなったら | 立たせてから 1 日（24000 tick）たてば立て直す | 同じ |
| 見回り | 人ごとに 5 秒に一度。鐘のまわり 3×3 チャンクの生き物が読み込まれているときだけ（読み込み前に「いない」と見て二人目を立たせないため） | 同じ |

- 焚き火の煙が遠くからの目印になる。語り部のセリフ「煙を目印にお行き」と合わせた。
- 焚き火はワールドに置く唯一のブロック。村の家や道ではなく、自然の地面にだけ置く。
- 鐘のない村には現れない（13 章の判断 3）。

### 3.3 ふるまい

| 場面 | ふるまい |
| --- | --- |
| ふだん | 家（語り部は鐘、鯨追いは焚き火）のまわり 8 / 4 ブロックをゆっくり歩き、近くの人を見る |
| 話しかけられた | 右クリックで会話の画面が開く。足を止めて話し相手を見る。話している間は話す動き（右手を少し上げる、うなずく） |
| 空の影が近くを通る | 足を止め、影の中心の空を見上げる（06 の動物・村人と同じく、怯えて立ちつくす） |
| 叩かれた | 傷つかない。「……やめておくれ」（鯨追いは「おい、よせ。火に灰が入る」）と画面の下に出て、好感度が 3 下がる（5 秒に一度まで。クリエイティブは下がらない） |
| 敵・火・溺れ・落下 | 傷つかない（クエストの相手が死んで進めなくならないように）。`/kill` と奈落だけは効く |
| 消えない | 遠くへ離れても消えない（`removeWhenFarAway` なし、保存される） |
| 名札 | 見つめると役の名前が出る（翻訳キーなので言語を切り替えても追従） |

### 3.4 見た目（ラフ 3 案と選定）

素材: `docs/review/npc_roughs/`（比較シート、顔、画面の見本 `ui_mock.png`、選定の表 `README.md`）。生成: `tools/rough/npc.py`。

| | 案 | 選んだ理由 |
| --- | --- | --- |
| 語り部 | A 肩掛けの老婆 / B 頭巾の巫女寄り / C 背負い籠の山里の老婆 → **A改（採用）** | 肩掛け・結縄・髷が一度に見え、「村の言い伝えを数える人」が読める。B は巫女に寄りすぎ、C は山の人に見える。第 2 回までのラフは頭が 7 単位の立方体で村人の箱頭に見えたので、A を作り直した（頭を 5 単位にして首から前へ突き出し、上体を段ごとに前へずらして腰の曲がりを作る。眉・頬骨・鉤鼻・髷と簪・袂・組んだ手） |
| 鯨追い | **A 長外套・広つば（採用）** / B 山高帽 / C 裾のぎざぎざ外套 | 背の袋（丸めた地図・鍋）と遠眼鏡のケースがシルエットで読め、「旅をしている」が一目で分かる。C は A と外形がほぼ同じ |

- 立方体は 0.5 単位、重なりなし（`check_overlaps` が空）。テクスチャは 1 単位 = 2 画素（32px 密度）、面ごとの uv。光る所はないので発光層は付けない（光る画素ゼロのマスクで落ちるため）。
- 前かがみは骨の回転を使わず段のずらしで作った。GeckoLib はファイルの回転の X を反転して読むので、回転だとラフでは前かがみでもゲームで後ろへ反るおそれがある。
- 頭はコードで話し相手へ向ける（`NpcRenderer`）。root 骨が yaw 180 度なので、上下の向きは符号を反転して入れる（12 章で確かめる）。
- 顔アイコンは採用モデルの頭を正面やや斜めから描き、80×80 画素（会話画面では 40×40 の GUI 単位 = 32px 密度）。表情 3 種（ふつう・笑み・沈む）は顔の面の画素だけを差し替えた。

## 4. 会話

### 4.1 画面

| 部分 | 中身 |
| --- | --- |
| 枠 | 画面の下に横長（幅は最大 400、画面の幅 − 16）。暗い青緑の縁。背景はぼかさず、下半分を少し暗くするだけ（相手と景色が見えるように） |
| 左 | 顔（40×40、表情は節ごと）、名前（青緑）、親しさの呼び方と菱形の印（5 章） |
| 右 | 本文。一字ずつ現れる（毎秒 40 字、6 字ごとにごく小さく紙の音）。日本語の禁則を守って折り返す（伝承の書と同じ `LoreWrap`） |
| 選択肢 | 本文が出きってから並ぶ。印: クエストに関わるもの ◆（金）、物を渡す ◇（青緑）、立ち去る（灰）、ほかは番号 |
| 続き | 選択肢のない節は右下に ▼ が点滅し、押すと次の節へ |
| 操作 | クリック、数字キー、↑↓（W/S）と Enter・Space。本文の途中で押すと全文を出す。Esc で立ち去る |
| ゲーム | 止めない（マルチでも同じ）。8 ブロックより離れる・相手がいなくなる・倒れる・ディメンションを移ると閉じる |

画面の見本（ゲームの外で寸法と折り返しを再現）: `docs/review/npc_roughs/ui_mock.png`。いちばん高い枠は語り部の話題の節（話題が全部出たとき 195 / 上限 210）。

### 4.2 しくみ（サーバーが決める）

- 会話の進み方はすべてサーバーが決める。画面は今の節を映し、選んだ番号を返すだけ（改造したクライアントが条件を飛ばせない）。
- 話しかけると、会話の `entries` を上から調べ、最初に条件が合った節から始める。
- 節に入ると: 節の結果（`do`）を起こす → クエストに「この節に入った」と知らせる（`talk` の目的）→ 条件に合う選択肢だけを送る。
- 選ぶと: 送ってきた節が今の節と同じか、選択肢が見せたものか、条件がまだ合うかを確かめてから、選択肢の結果を起こし、行き先へ。食い違えば今の節を映し直す（画面が返事を待ったまま止まらない）。
- 行き先: 節の名前、`end`（閉じる）、`@entry`（入口を調べ直す。話題を選ぶ節へ戻るのに使う）。
- 一人に一つの会話。同じ NPC と二人が同時に話してもよく、それぞれの記録で分岐する。

### 4.3 データの形

```
data/<名前空間>/dialogue/<役>.json        会話 (役はエンティティの ID と同じ)
assets/skyabyss_npc/lang/{ja_jp,en_us}.json   会話・クエスト・画面の文
```

```json
{
  "npc": "skyabyss:storyteller",
  "entries": [
    { "if": { "type": "quest", "quest": "main_song", "stage": "return" }, "node": "fragment" },
    { "if": [ { "type": "loop", "min": 1 }, { "type": "remembers", "flag": "met" }, { "type": "not", "of": { "type": "flag", "flag": "met" } } ], "node": "deja_vu" },
    { "node": "menu" }
  ],
  "nodes": {
    "song1": { "face": "smile", "do": [ { "type": "flag", "flag": "song_heard" }, { "type": "lore", "entry": "prologue/counting_song" } ], "next": "song2" },
    "song2": { "options": [
      { "id": "curious", "goto": "song_curious", "do": [ { "type": "affinity", "amount": 2 } ] },
      { "id": "child", "goto": "song_child", "do": [ { "type": "affinity", "amount": -2 } ] } ] }
  }
}
```

| 欄 | 意味 |
| --- | --- |
| `entries` | 入口。上から調べ、最後の一つは条件なし（必ずどれかが開く） |
| 節の `face` | neutral / smile / grave（顔アイコンの表情） |
| 節の `do` | 入ったときの結果 |
| 節の `next` | 選択肢の代わりに「続き」（▼）。`options` とどちらか一方 |
| 選択肢の `if` / `do` / `goto` / `kind` | 出す条件、選んだときの結果、行き先、印（talk / quest / give / leave） |
| `text` | 文のキーを上書き（省略すると `dialogue.<名前空間>.<役>.<節>`、選択肢は `.<節>.<選択肢>`） |

文と構造の正本は `tools/gen_npc_content.py`。会話の JSON、クエストの JSON、lang（日本語・英語）、この書類の 7.3 節の表を一度に書き出す（キーの書き間違いと、片方の言語だけ直し忘れるのを防ぐ）。

### 4.4 条件と結果（会話とクエストで共通）

| 条件 `type` | 欄 | 意味 |
| --- | --- | --- |
| `all` / `any` / `not` | `of` | 組み合わせ。配列で書けば `all` |
| `quest` | `quest`, `is`, `stage` | クエストの状態（none / active / done / started / not_done）。`stage` を書くと「その段階にいる」 |
| `lore` | `entry` | 伝承の書にその項目が記されている |
| `affinity` | `npc`, `min`, `max` | 好感度（`npc` を省くと話している相手） |
| `flag` | `flag`, `npc` | このループで立てた会話の印 |
| `remembers` | `flag`, `npc` | 前のループまでに立てた印（4.5 節） |
| `loop` | `min`, `max` | 月のループの回数 |
| `item` | `item`, `count` | 持ち物の数 |
| `watcher` | `min` | 見る者に気づいた回数（06 の記録） |
| `day` / `level` / `night` | `min` | ワールドの経過日数、成長のレベル、夜 |

| 結果 `type` | 欄 | 意味 |
| --- | --- | --- |
| `quest_start` | `quest` | クエストを始める（始まっていれば何もしない） |
| `signal` | `signal` | クエストの「合図」の目的を進める |
| `affinity` | `amount`, `npc` | 好感度を足す |
| `flag` / `unflag` | `flag`, `npc` | このループの会話の印 |
| `lore` | `entry` | 伝承の書に記す（知らせつき） |
| `give` / `take` | `item`, `count` | 渡す（入らなければ足もとへ、本人だけが拾える）/ 受け取る（足りなければ何もしない） |
| `xp` | `amount`, `once` | 成長の経験値。`once` の鍵で一人一回だけ（会話のくり返しで稼げない） |

### 4.5 ループをまたぐ会話（「覚えているような」NPC）

器だけを作った。ループ本体（月の落下と巻き戻し）は M4。

| 項目 | 決まり |
| --- | --- |
| ループの回数 | サーバー全体で一つ（`WorldLoop`、オーバーワールドの SavedData `skyabyss_npc`）。今は 0。M4 は月が落ちたときに `WorldLoop.advance(server)` を呼ぶ |
| 巻き戻すもの | その人と NPC の、このループの会話の印・好感度・話した回数（01 の表「NPC の状態と会話フラグ」は巻き戻る） |
| 残すもの | 印は消える代わりに「記憶」（echoes）へ移る。留まる者に向けた微かな覚えとして、条件 `remembers` で読める |
| その場にいなかった人 | 次に入ったときに追いつく（記録の `loop_seen` と比べる） |
| クエスト | `loop_reset: true` のクエストのうち、まだ終えていないものだけ最初に戻す。今の 3 本はどれも `false`（伝承の記録で数えるので、戻してもすぐ追いつく） |
| セリフ | ループ 1 回目以降の最初の会話で、語り部は「前にも、その顔を見た気がするね……いや、年寄りの気のせいだ」、数え歌を聞いていた人には「あの歌の続きを聞きに来たんだろう……どうしてそう思ったんだか」。鯨追いは「どこかで会ったか？」。一ループに一度だけ（会うと印 `met` が立つ） |

伝承の書の「白紙の帳面」の一行（「次は、もっと早く気づけるように」）と、語り部の「この字、どこかで見た気がする」が、同じ方向をほのめかす。核心（留まる者がなぜ覚えているか）は言わない。

## 5. 好感度

| 項目 | 決まり |
| --- | --- |
| 単位 | プレイヤー × NPC の役（村ごとの語り部は同じ「語り部」として数える）。-100〜100 |
| 置き場所 | プレイヤーの Data Attachment `skyabyss:npc_bonds`（死んでも引き継ぎ、持ち主にだけ同期） |
| 上がる | 話題を聞く・応じる（+1〜+3）、その日の最初の会話（+1、二日目から）、クエストを終える（メイン +5、サブ +10） |
| 下がる | 突き放す選択（「子どもの歌だろう」-2、「言わずにおく」-1）、叩く（-3） |

## 6. クエスト

### 6.1 データの形

```
data/<名前空間>/quest/<名前>.json
```

| 欄 | 意味 |
| --- | --- |
| `category` | main / sub |
| `order` | ログの並び |
| `giver` | 依頼主の役（ログに「依頼: 語り部」） |
| `start_when` | この条件が真になったら自動で始まる（1 秒ごとに調べる）。省くと会話などの `quest_start` でだけ始まる |
| `loop_reset` | 月のループで、まだ終えていなければ最初に戻す |
| `stages` | 段階の並び。`id`、`mode`（all = 目的をすべて、any = どれか一つ）、`objectives`、`skip_if`（真なら着いたとたんに済ませる）、`xp`（段階を済ませた経験値）、`do`（済ませたときの結果） |
| `reward` | `xp`、`items`、`affinity`（役 → 量）、`do` |

| 目的 `type` | 欄 | 数え方 |
| --- | --- | --- |
| `talk` | `target`（役）、`topic`（節） | その NPC の会話でその節に入った（`topic` を省くと話せば何でも） |
| `kill` | `targets`、`count`、`radius` | 倒した人は距離を問わず、ほかは `radius`（既定 32）以内にいた人（倒れて復活を待つ人も含む）。取り消された死亡は数えない |
| `collect` | `target`（アイテム）、`count` | 持ち物の数（1 秒ごと。減れば戻る） |
| `lore` | `targets`、`count` | 伝承の書に記された数（既定は全部） |
| `visit` | `target`（ディメンション） | そこに入った（一度満たせば戻らない） |
| `near` | `targets`（生き物）、`radius` | 近くにいた（2 秒ごと。一度満たせば戻らない） |
| `signal` | `target` | 会話の結果やコードの `Quests.signal` |
| `condition` | `if` | 条件が真 |

文のキー: `quest.<名前空間>.<名前>.title` / `.summary` / `.done`、段階の書き付け `.<段階>.journal`、目的 `.<段階>.<目的>`。

### 6.2 進み方

- 段階の目的が満たされたら（`skip_if` が真でも）、段階の結果と経験値を渡して次へ。次の段階の「状態で決まる」目的（伝承・持ち物・場所・条件）は着いたとたんに調べ、満たされていればまとめて送る。
- **経験値と報酬は一人一回。** `Growth.discover` の鍵（`quest:<クエスト>:<段階>`、`quest:<クエスト>`）で、コマンドでやり直したり、ループで戻ったりしても二度は渡さない。経験値は `Growth.addXp`（画面に「+30 雲の下の歌」）。
- 知らせ: 始まった・進んだ・終わったときに、右上に小さな札（伝承の書の羊皮紙と見分けられる暗い石板の色。メインは金、サブは青緑の縁）とアメジストの小さな音。始まったときと終えたときはチャットにも一行（前進の淡い青）。初めてのクエストでは「K キーで、クエストログを開ける」。

### 6.3 クエストログ（K）

| 部分 | 中身 |
| --- | --- |
| 左 | 一覧: メイン（金）、サブ（青緑）、終えたもの（灰）。追跡中に ▸ |
| 右 | 題、依頼主、今の段階の書き付け（言い切らない一人称のメモ）、やること（■ 済み / □ まだ、数のあるものは 2/3）、何段目か、報酬 |
| 下 | 「知ったことは、伝承の書に。」（ログは「やること」、書は「知ったこと」）。追跡する / やめる の釦 |
| 操作 | クリック、↑↓、ホイール（右の頁）、K か Esc で閉じる |

### 6.4 左の追跡表示

成長の表示（Lv とバー）の下（画面の左、y=70）に、追跡中のクエストの題と、まだ済んでいない目的だけを小さく出す（どれか一つの段階は「または」でつなぐ）。メインは始まると必ず追跡し、サブは何も追跡していないときだけ追跡する。終えたら次の進行中のクエスト（メインが先）へ移る。ログの釦でやめられる。F1・F3・ログを開いている間は出さない。

## 11. 設計判断の理由

| 判断 | 理由 |
| --- | --- |
| 最初の二人を「語り部」と「鯨追い」にした | 序章の村の言い伝え（05 の頁: 数え歌・暦・峰・見る者）を語る人と、1 章の岩鯨へ導く人を分けると、「怖い話を聞く → 確かめに行く」の流れが自然になる。語り部は地上に残る人、鯨追いは空へ惹かれる人で、物語の「天と淵」の対にもなる |
| 語り部は村ごとに一人、鐘のそば | どの村から始めても入口がある。最初に出会う村を選ばない（マルチで別々の場所から始めても困らない） |
| 鯨追いは必要になった村にだけ、焚き火と一緒に | 「ゆうべから村の外れで火を焚いている」というセリフと合い、煙が目印になる。すべての村にいると、鯨を追う一人の旅人という人物像が崩れる |
| NPC は傷つかない | クエストの相手が死ぬと進めなくなる。叩いたときは嫌がって好感度が下がる（反応はある） |
| 目的を伝承の書の記録で数える | 伝承の書がすでに碑文・心臓・欠片・岩鯨を拾っており、記録は消えない。同じ出来事を二か所で拾うと食い違う。順番を外しても詰まらない |
| 会話はサーバーが進める | 条件（クエスト・持ち物）を画面側で判定すると、改造で飛ばせる・同期がずれる。画面は映すだけにした |
| 会話の文と構造を一つの生成スクリプトに | 節と選択肢のキーを手で合わせると書き間違える。日本語と英語、JSON と設計書の表がずれない |
| 文は言い切らない | 01 の「1 章ではつながりを説明しない」。語り部は話をそらし、鯨追いは自分の感覚しか言わない。核心（巡礼者・心臓・留まる者）は名前すら出さない |
| ループの記憶を「印が記憶へ移る」形にした | NPC の状態は巻き戻る（01）が、何を覚えていそうかは前のループで何を話したかで決まるのが自然。M4 が回数を一つ進めるだけで動く |
| 好感度は役ごと | 村ごとの語り部を別人として数えると、村を移るたびに親しさがなくなり、「人として覚えている」感じが出ない |
| 経験値と報酬は一人一回 | 会話のくり返し、コマンドでのやり直し、ループで稼げないように（04 の discover と同じ流儀） |
| 報酬の品はバニラの時計と遠眼鏡 | 03 の装備の釣り合い（周回で集める）に触れない。品そのものが「七日目」「空を見ろ」をほのめかす |
| 05 から 07 を分けた | 05 は伝承の書だけで 490 行あり、NPC とクエストを足すと読みにくい |
