# 天と淵のあいだ 封の箱と封切り師（装備は箱で落ちる）

- 文書番号: 52
- 範囲: 敵が装備（武器・防具・装飾）を直接落とすのをやめ、封をした箱を落とす形にする。箱の種類と見た目、中身の決め方、落ちる所と確率、町の封切り師（開けてくれる人）とルーレットの画面、天井（巨神の記憶）とのつなぎ。

## 3. 中身の決め方

### 3.1 巨神の箱

- 中身: その巨神の図鑑の品（鎧 4 部位・基本の武器・二つ目のエピックの品・護符と装飾・専用の逸品 3）、職の章の武器（エピック 5〜6 本）、巨神のヒロイック武器（4〜5 本）。
- 階級を先に引く: レア 45%・エピック 45%・ヒロイック 10%。その階級の品から一つ（武器は 2/3 で今の職）。
- ソフト天井（新しい品の出ない箱が 3 個以上）: 図鑑にまだない品の重みを 2 倍。ハード天井（5 個）: 図鑑にない品を必ず。図鑑が全部そろっていれば今までどおり共鳴の欠片に替わる。
- 心臓の今の確率（鎧の部位ごと 25%・エピック 20%・逸品 4%…）は、上の箱の数と階級の重みに置き換える（4 章）。一回の撃破で手に入る品の数の平均は今と同じ（約 1.5）にそろえる。

### 3.2 階級の箱

- 中身: その階級の品のうち、必要 Lv が箱の**帯**に入るもの。野の装備（51）に加えて、深淵の装備（帯 IV〜V）と月の装備（帯 V）も入れる（00 の 307）。
- 種類: 武器 60%（2/3 で今の職）・防具の部位 25%・装飾 15%（51 と同じ）。
- 帯: 落ちた所で決まる（土地・層・区画ごと。51 の 3 章の表）。名のある強敵と主の箱は、その所の帯。

### 3.3 淵の金の箱（案）

- 中身: 深淵のアーティファクト（巨神ごとに 1 点）と伝説の武器（20 本）。今の「4 回続けて出なければ保証」は箱の落ち方の天井として残す。

## 4. 落ちる所と確率（今の値からの置き換え）

| 源 | 今 | 箱にしたあと |
| --- | --- | --- |
| 巨神の心臓 | 品ごとの抽選（鎧 25%・エピック 20%・逸品 2〜4%） | その巨神の箱を 1 個必ず、2 個目 50% |
| 中ボス（番兵長・潮招き・雷獣・灰の鍛え手） | 逸品 5% | 巨神の箱 25% |
| 背の道中の敵 | 鎧の一部位 1% | 巨神の箱 1% |
| 土地の敵 | 野の装備（アンコモン 2%・レア 0.8%・エピック 0.3%・ヒロイック 0.05%） | 同じ確率で、同じ階級の箱 |
| 名のある強敵・層の主・区画の主・雲の島の主 | 初回必ず一品、二度目から 12%、ヒロイック 3% | 初回必ずレアかエピックの箱、二度目から 12%、ヒロイックの箱 3% |
| 深淵の層の主（初回の鎧の一部位）・番人・月の核 | 決まった部位・品ごとの抽選 | 初回の部位は今までどおり直接（物語の報酬）。ほかは階級の箱（番人・月の核はエピックの箱 1 個必ず、ヒロイックの箱 4%） |
| 深淵の心臓（転生 3 回から） | アーティファクト 25%、4 回で保証 | 淵の金の箱 25%、4 回で保証（案） |
| 巡礼者（終章） | 神器（初回）・心核 | 変えない |
| 見どころの宝・試練の部屋 | 装備は出ない | 変えない |

- 箱は今の品と同じ渡し方: 旅嚢 → 持ち物 → 足もと（その人だけが拾える）。倒れていた人・いっぱいの人の分は預かり（`TitanLoot` の預かり）。
- 拾ったときの知らせは「〇〇の箱を手に入れた」。ヒロイック以上の箱は光の柱と音。

## 5. 封切り師（箱を開けてくれる人）

- いる所: 都と四つの土地の町（鯨見・汐守・風待・灰炉）に一人ずつ（00 の 308 で深淵の骨の層の野営と月の降り場にも置くか決める）。店の並び（35・45）の空いた区画に、箱を積んだ台と小さな作業台。地図と町の案内（`TownGuide`）に「封切り」の印。
- 人物: 封を切る道具（小刀・てこ・封蝋の火）を腰に下げた職人。町ごとに見た目を少し変える（都 = 封蝋の匠、鯨見 = 骨の小刀の老人、汐守 = 貝の留めを外す漁師上がり、風待 = 銅線を切る機織り、灰炉 = 燠で封を焼き切る灰の民）。台詞は町ごとに一行ずつ。
- 渡し方: 話しかけると箱の画面が開く。持っている箱の一覧（種類・帯・数）から選んで「開ける」「まとめて開ける」。
- 代金: 無料（00 の 309）。

## 6. ルーレットの画面

- 開ける: 画面の真ん中に横に流れる品の帯（その箱から出うる品の絵が並ぶ。縁は階級の色）。速く流れて 3〜4 秒でゆっくり止まり、真ん中の枠に当たりが来る。止まる前の数個は「惜しい」品が通り過ぎる。
- 音: 流れるあいだは帯の品が枠を通るたびに小さな刻み、止まると階級ごとの音（ヒロイックは鐘）。光は階級の色。
- 当たり: 大きなカード（30 の心臓の遺物の画面と同じ作り）で名前・階級・特性・必要 Lv。「もう一つ開ける」「閉じる」。
- まとめて開ける: 帯を速く回し（1 個 1 秒）、最後に当たりの一覧。どこでも Esc で終わりまで飛ばせる。
- 品はルーレットが回り始める前にサーバーが渡している（画面は見せるだけ）。通信が切れても失わない。
- 組の人が近くにいれば、ヒロイック以上が出たとき頭の上に小さな光（ほかの人にも見える）。チャットには出さない（18 の決まり）。
