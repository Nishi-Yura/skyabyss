# 天と淵のあいだ 封の箱と封切り師（装備は箱で落ちる）

- 文書番号: 52
- 範囲: 敵が装備（武器・防具・装飾）を直接落とすのをやめ、封をした箱を落とす形。箱の種類と見た目、中身の決め方、渡し口、町の封切り師（開けてくれる人）とルーレットの画面、旅嚢の「封の箱」の欄、天井（巨神の記憶）とのつなぎ。
- 状態: **実装済み**（2026-10-31。ユーザーの声「今の敵が直接防具を落とすのをやめたい。Wynncraft のように低確率で箱を敵が落とす形に（同じ種類であればスタック可能）。それぞれの街に開封してくれる NPC がいて、渡すとルーレットが始まって箱に応じた武器や防具、装飾が出る。巨神の時は専用の見た目の箱をそれぞれ（計 4 種類）。その他はレア度に応じて箱を分けて」）
- 関連: [03](03_gear_and_endgame.md)（階級・個人抽選・巨神の記憶・図鑑・交換）、[51](51_world_gear.md)（野の装備）、[35](35_capital_facilities.md)（都の施設）、[22](22_mod_pouch.md)（旅嚢）
- コード: `loot/box/`（BoxKind・SealedBoxItem・LootBoxSetup・LootBoxes・LootBoxData・BoxService・BoxNetwork・BoxOpeners・BoxCommands・LootBoxSelfTest）、`client/box/`（BoxScreen・BoxPouchScreen・BoxClient）

## 1. 決まり

| # | 決まり |
| --- | --- |
| 装備は箱で | 敵・ボス・巨神の心臓の装備は、渡す直前に**封の箱**に替わる。抽選（確率・個人抽選・天井・図鑑）は今までのまま。素材・鐘銭・心核・鍵・備えの品は直接 |
| 箱の種類 | **巨神の箱 4 種**（岩鯨・潮殻・雷翼・余燼）、**階級の箱**（アンコモン・レア・エピック・ヒロイック × 帯 = 14 品）、**淵の金の箱**（アーティファクト）。計 19 品・形は 9 種。神器は箱に入れない（巡礼者を初めて退けたときの、その人の職の神器のまま。50 の 4.5） |
| 重ねる | 同じ品の箱は重なる（16 まで。旅嚢には 999 まで）。階級の箱は帯ごとに別の品（「レアの封の箱 [Lv 21-30]」）。巨神の箱と金の箱は帯を持たない |
| 中身 | 箱は中身を持たない。落ちた時点で決まった品（特性・穴つき）は、その人の**封の列**（箱の種類ごと、古い順）に並び、開けると古い方から出る。列が空の箱（渡された箱・試しの箱）は、開けるときにその箱の表から引く（3 章） |
| 開ける | 町の**封切り師**に話して「箱を開けてもらう」。ルーレットが回って一つ決まる。品はサーバーが渡してから画面に結果を送る（途中で閉じても品は手もとにある）。代金は無料 |
| 天井と図鑑 | 巨神の記憶（03 の 2.4）は今までどおり**撃破ごと**に進む（箱の数ではない）。図鑑は落ちた時点で数える。列が空の箱から出た巨神の品は、開けたときに数える |
| 知らせ | 落ちたときは「〇〇の封の箱」（品の名は開けるまで言わない。逸品のほかの人への知らせも出ない）。開けた品は画面のルーレットだけが見せる（知らせの欄に先に出すと当たりが分かるので出さない。画面のない開け方だけ一行）。ヒロイック以上は頭の上に光（近くの人に見える） |

## 2. どの品がどの箱か（`LootBoxes.kindFor`）

| 品 | 箱 |
| --- | --- |
| 野の装備（51） | その階級と帯（必要 Lv）の階級の箱 |
| 深淵・月の装備 | その階級と帯の階級の箱（帯の無い組は近い帯へ。アンコモンは帯 I〜II、エピックは II〜、ヒロイックは III〜） |
| 巨神の装備（図鑑の品・章の武器・巨神のヒロイック武器） | その巨神の箱 |
| アーティファクト（深淵のアーティファクト・伝説の武器） | 淵の金の箱 |
| 神器（雲海）・コモン・島の祠の始めの武器・物語の装い（案内の道） | 箱にならない（そのまま） |

### 2.1 箱の形（一品一案。`tools/rough/lowpoly/weapons/wild/o_boxes.py`）

| 形 | 見た目 |
| --- | --- |
| 岩鯨の箱 | 灰の流木の櫃を象牙の鯨の肋が二本抱く。ふたに苔、封は水色の石の留め |
| 潮殻の箱 | 黒い流木の櫃に、筋の広がる貝殻のふた。縁に藤壺、封は真珠 |
| 雷翼の箱 | 銅の帯を三本巻いた太鼓の形の櫃。両脇に小さな翼、封は稲妻に曲げた銅線と光る留め |
| 余燼の箱 | 黒曜と冷えた溶岩の櫃。継ぎ目に熾の光、封は燠石 |
| アンコモンの箱 | 樫の板の素朴な箱に縄の十字。緑の紐の封 |
| レアの箱 | 青く塗った箱に鉄の帯三本と角の鋲。赤い蝋の封と鉄の錠 |
| エピックの箱 | 紫の漆に銀の金具と葉の飾り。紫の印の封 |
| ヒロイックの箱 | 朱の漆に金の縁、角に小さな炎。金の鎖を正面で十字に |
| 淵の金の箱 | 金の箱のまわりに淵の欠片が浮く。ふたに淵の紋、封は金の輪と紫の石 |

縁は階級の色（アンコモン = 鉄・レア = 青い鋼・エピック = 紫の銀・ヒロイック = 朱金）。手・地面・額縁は低ポリ（`AccessoryItemRenderer`）、持ち物の画面は 32x32 の絵。階級の箱の絵には左下に帯の数字（I〜V、階級の色）。入れ方は `tools/install/install_boxes.py`。

## 3. 列が空の箱の表（`LootBoxes.pool` と `roll`）

- 巨神の箱: その巨神の品のうちレア〜ヒロイック。階級を先に引く（レア 45%・エピック 45%・ヒロイック 10%）。
- 階級の箱: その階級で、必要 Lv の帯が箱の帯と同じ品（野・深淵・月）。
- 金の箱: アーティファクト（神器のほか）。
- どの箱も、種類を先に引く（武器 60%・防具の部位 25%・装飾 15%。無い種類は外す）。武器は 2/3 で今の職の武器。出た品には特性と穴が付く。

## 4. 渡し口

| 渡し口 | 箱にしたあと |
| --- | --- |
| `TitanLoot.handOver`（巨神の心臓・中ボス・道中・深淵の層の主と番人・月の区画の主と核・伝説の機会・試練の報酬） | 並びの中の装備を箱に替え、並びも書き換える（呼び手の知らせが箱の名を言う）。預かり（倒れていた人・オフライン）も箱で |
| `WildLoot.give`（野の敵・名のある強敵・層と区画の主・雲の島の主） | 箱に替えて渡す。知らせ・音・光は品の階級のまま |
| 敵の落とし物（`LivingDropsEvent`、一番後） | ほかの仕組みが落とした装備を、倒した人の箱に替える。倒した人がいなければ落とさない |
| 包まない | 交換（炉・共鳴の欠片。`GearExchange`・`TitanLoot.exchange`）、初回の選択（`HeartReward`）、野営の返却（`CampBlocks`）は `LootBoxes.direct` の中で。深淵の層の主・月の区画の主の初回の部位（物語の報酬）は `LootBoxes.keepDirect` |

- 一回の撃破で落ちる箱の数は、今まで落ちていた装備の数と同じ。
- 箱の渡し方は品と同じ: 旅嚢 → 持ち物 → 足もと（その人だけが拾える）。

## 5. 封切り師（`AttendantRole.BOX_OPENER`）

- いる所: 都と四つの土地の町に一人ずつ。設計図の印は足さず（町の建て直しになるため）、鍛冶屋の係の人の印（`npc_smith`）から 2〜4 ブロックの、まっすぐ歩いて行ける空いた床に立つ（`BoxOpeners`）。
- 人物: 封蝋の匠。煤けた赤茶の上着に生成りの前掛け、眼鏡と口ひげ、左手に封の箱を抱える（`tools/rough/lowpoly/npc2/cast.py` の box_opener）。頭の上の印は封をした箱。
- 会話: 「箱を開けてもらう」（画面を開く）・「箱のこと」・「ここは何をする所？」・「また来る」（`data/skyabyss/dialogue/attendant_box_opener.json`）。
- 画面を開いている間、封切り師から 8 ブロック以内でだけ開けられる。

## 6. ルーレットの画面（`client/box/BoxScreen`）

- 一覧: 持っている箱（種類・帯・数）の升目。選ぶと右に名前・中身・数。「開ける」「まとめて開ける (n)」（一度に 64 まで）。
- 開ける: 真ん中に横に流れる品の帯（32 個。縁は品の階級の色）。3.8 秒で四乗のゆるみで止まり、28 個目の当たりが真ん中の枠へ来る（止まる所は枠の中で少しずれ、止まってから真ん中へ寄る）。当たりの前後は、その箱のいちばん上の階級の品（惜しい品）。
- 音: 品が枠を通るたびに刻み（だんだん高く）。止まると階級ごとの音（ヒロイック以上は鐘とファンファーレ、エピックはレベルの音）。
- 当たり: 大きなカード（品の絵 3 倍・名前・ツールチップ全部）。「もう一つ開ける」「一覧へ」。
- まとめて: 一つ 1.1 秒で回し、最後に当たりの一覧（升目、重ねると品の説明）。
- Esc: 回っている間は終わりまで飛ばす。それ以外は閉じる。

## 7. 旅嚢の「封の箱」の欄（`client/box/BoxPouchScreen`）

- 持ち物・装飾・旅嚢のつまみの四つ目「封の箱」。持っている箱を見るだけの画面（開けるのは封切り師）。
- 上に巨神の箱 4、中に階級の箱（行 = 階級、列 = 帯 I〜V）、下に金の箱。数は旅嚢と持ち物の合計。
- 箱は旅嚢の区分「封の箱」（`PouchConfig.Category.BOX`。袋の枠には並ばず、取り出せない）。倒れても旅嚢の中の箱は残る。

## 8. 試遊コマンド

- `/skyabyss play box give <種類> [数]`: 箱を出す（列は空なので、開けると表から引く）。
- `/skyabyss play box open`: 封切り師なしで、その場で封切り師の画面を開く。

## 9. 自己テスト（段 "loot boxes"）

品（19 種・重なり・旅嚢の区分・絵とモデルとメッシュ）、どの箱か（野・巨神・伝説・深淵、神器とコモンと素材は箱にならない）、表（19 種とも中身があり同じ箱に戻る。巨神の箱の階級の割合、階級の箱の種類の割合と職への寄せ）、封の列（包む・重なる・古い順・列が空なら表から・帯の当たり）、渡し口（handOver が包む、direct と keepDirect は包まない）。
