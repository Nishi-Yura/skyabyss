# 天と淵のあいだ 武器と防具の見た目の担当

- 文書番号: 60
- 範囲: 手で組む武器と防具の模型（Blockbench）の共通の決まりと、職ごと・防具の担当が守ること、許される奇抜さ、差別化。模型を作るときは、その品の担当（`.claude/agents/gear-*.md`）を呼んで組ませる。
- 状態: 決まった（2026-11-17）。全武器の作り直しの流れは 1.9（2026-11-18）。
- 関連: [16 防具と装備 3D](16_armor_design.md)（巨神ごとの素材の言葉・防具の決まり）、[43 職](43_jobs.md)、[51 野の装備](51_world_gear.md)

## 1. 共通の決まり（全担当）

### 1.0 シリーズの見た目の統一（一番大事）

- 同じシリーズ（祠の始めの武器、同じ土地・同じ帯の品、同じ巨神の品など）の品は、並べたときに一揃いに見えること。これが全ての決まりの中で一番大事。
- そろえるもの: 素材と色（主・副・差し色）、継ぎ目の隠し方、握りの作り、光る見せ所の作り、装飾の細かさ（1.7）。職ごとの違いは骨格（2 章）と、光の色ぐらいに留める。
- 新しい品を作るときは、同じシリーズの決まった品と並べた画像を必ず作り、そろって見えるかを確かめてから見せる。
- 作り直す品は、前の形（前のゲームの模型・設定の絵）の特徴も尊重する。ただしシリーズの統一の方を優先する。
- **シリーズは素材ごとの色の段階（ランプ）を共通にする**（1.8 の塗り方。2026-11-18 から）。素材（緑青・金・流木・赤い紐・鋼・宝石）ごとに 3〜5 色の段階を決め、シリーズの品はその色だけで塗る。描いた絵（長い部品の塗り分けの帯を含む）は共通の素材シートに置き、品ごとに描き直さない。
- **シリーズは共通の素材シートを使う。** 同じシリーズの品は、どれも同じ 64×64 の素材シートの絵だけで塗る（品ごとに素材の絵を描き直さない。描き手が変わると緑青・紐・宝石の色と細かさがずれる）。新しい素材が要るときはシートの空いた所に足し、同じシリーズの他の品も同じ絵を使う。
- 祠のシリーズの素材シート: `tools/models/shrine_series_tiles.png`。緑青 (16,0)・金 (24,0)・赤い紐 (32,0)・鋼の打つ面 (40,0)・星石 (48,0)・流木 (56,0) 8×32・剣の刃 (0,16)・暗い鋼 (12,0)・弓腕の流木 (16,16) 16×16・炉の橙 (32,16)・弦 (40,16)・濃い木 (0,40)・青緑の布 (8,40)・葉 (16,40)・星の板 (24,40) 16×16。
- 祠の始めの武器のシリーズ（2026-11-17 に杖・剣・鎚で決まった）: 流木・木の柄、緑青の青銅、継ぎ目と握りを締める金の帯・輪、赤い紐の握り、見せ所の光る石（星の空色。鍛冶師は火の橙）を一つ。細かさは杖・剣・鎚と同じ。

### 1.1 一番の決まり: 一目で種類がわかる

- **黒い影だけ（32 画素の大きさ）で、何の武器かわかること。** 鎚は鎚に、弓は弓に見える。飾りは種類の影を壊さない。
- 種類の影（下の 2 章の「骨格」）が全体の量の 7 割以上。飾り・光・奇抜な部品は 3 割まで。
- 見せる前に担当が自分で確かめる: 影だけの絵（単色で塗りつぶした正面）を撮り、種類を言い当てられるか。言い当てられなければ直してから見せる。
- 例（2026-11-17 の祠の鎚 C）: 頭が炉の形で、上に煙突と炎が立った。頭が縦長になり、影が「棒の上の角灯」に見えて鎚に見えなかった。鎚の頭は横長で、打つ面が影に出ていなければならない。

### 1.2 作り方

| 決まり | 中身 |

| 単位と向き | **2 倍の細かさ（2026-11-18 から全品）: Blockbench では 1 単位 = 1/32 ブロックで組み、1 画素 = 1 単位。** 元ファイルは `tools/models/x32/<id>.bbmodel` に置き、取り込みで 0.5 倍して 1/16 ブロックに直す（ゲームの中の大きさは同じ）。原点は握り、+y が先、+x が刃・打つ面の向き。1.5 の大きさと 1.7 の「1 単位」は、この 1/32 ブロックの単位で読む |

### 1.3 進め方

1. 担当が品の設定（51・43・各巨神の書類）と、同じシリーズの決まった品を読む。
2. 担当が 3 案を並べて作り、1.0・1.1・1.7 と 2 章に一番合う案を自分で選ぶ（理由を一行で残す）。
3. 選んだ案を清書し、両面・斜めから確かめ、ゲームに入れて撮る（ラフをそのまま入れない）。
4. **ユーザーにはシリーズの全品の清書が終わってから、一度にまとめて見せる**（品ごとには見せない。2026-11-18）。見せる画像は、シリーズの全品を同じ撮り方で並べたもの。
5. 「変」「気になる」と言われたら、どこかを聞いてから直す。推測で一つだけ直さない。

### 1.4 見た目の禁止

- 色違い・同じ骨組みの使い回し（一品一案。51 の 1 章）
- 段々のノイズ（1 単位より細かい段・乱れた段で角を丸めること。1 単位の方眼にそろえて意図して置いたドット絵の輪郭の段は、1.8 の作法として認める）、全部の面の縁に同じ明るい線、大きな光の暈
- 傾けた箱が継ぎ目から外へ出ること（継ぎ目は輪・玉・台で隠す）。継ぎ目を埋めるための球も禁止
- 中が見える模型（閉じた形にする）
- 白い小さな箱一つ（実・粒）。小さく白いものは「何かのゴミ」に見える
- 単色の面（1.7。どの面にもテクスチャを入れる）
- 大きな面を光らせること、細い光る溝（刃の窓に見える）

### 1.5 大きさの目安

2 倍の細かさでは、下の数をすべて 2 倍にして読む（例: 剣の先まで 52〜60 単位、鎚の頭の幅 20 まで）。ゲームの中の大きさは同じ。

| 種類 | 長さ（握りから先、単位） | 幅の上限 |
| --- | --- | --- |
| 剣・鉾 | 先まで 26〜30、柄頭まで −9 | 鍔 14 |
| 大剣・槍 | 先まで 30〜36 | 鍔 16 |
| 鎚・斧 | 頭の中心 15〜18、石突き −9 | 頭 10 |
| 杖・鈴杖 | 先まで 22〜25、石突き −15 | 14 |
| 弓 | 上下の端 ±14〜16 | 前後 8 |
| 短剣・牙・爪 | 先まで 14〜18 | 8 |

### 1.6 階級の見た目

- 参照（1.8）が決めるのは**作りの水準**（塗り・形・立体感）で、**豪華さではない**。豪華さ（金の量・宝石の大きさ・飾りの数）は階級で決める（2026-11-18、ユーザー「最初の武器にしては豪華じゃない？」）。
- 始めの武器（ふつうの階級・Lv 1）: 素朴な道具の品。金は細い輪 2 本まで、宝石は小さな石 1 つまで（3〜4 画素、台座なし）、飾りの冠や大きな輪郭は付けない。立体感は形（段・面取り・くびれ・太さの変化）で出す。
- 始めの武器は**全品、木が基調**（2026-11-18、ユーザー「最初の武器は全部木が基調でいいんじゃない」）。頭・刃・弓腕などの主な塊も木（流木・濃い木）で作り、金属は留め具（輪・帯金・口金）と、刃の縁のような働く所だけにする。鋼や緑青の大きな面は持たない。

- アンコモン・レア: 骨格と素材だけ。飾りは一点まで。
- エピック: 光る一点（宝石・炎・割れ目）を足してよい。
- ヒロイック: 骨格を一回り大きく・奇抜な輪郭を一つ足してよい（ただし 1.1 の 7 割は守る）。
- 巨神・深淵・神器の品: 巨神の素材の言葉（16 の 2.4）を一点繰り返す。

### 1.7 装飾の細かさ（全品でそろえる）

- 基準は決まった品（祠の杖・祠の剣）。迷ったら、この 2 本と同じ角度で並べて比べ、細かさがそろって見えるか確かめる。
- テクスチャは 1 画素 = 1 単位（例外は小さな宝石だけ: 宝石は縁と光の点のある宝石の絵を丸ごと貼る。1 画素 = 1 単位にすると 1〜2 画素の単色になるため）。模様の線は 1 画素以上、模様の中の形は 3 画素以上。1 単位より細かい描き込みはしない。
- 箱は 1 単位以上（輪・縁・板の厚さだけ 0.5 まで）。鋲（小さな粒の箱）は使わない。
- 飾りは「見せ所 1 つ + 金の帯・輪 3 つまで」。光る所は 2 か所まで。
- 格子・ひび・紋などの模様は 1 面に 1 つまで、線は 3 本まで。面いっぱいの細かい網や格子は描かない。
- 部品の数は 1 品で 15〜30 個が目安。
- **単色の面は作らない。** どの面にも何かしらのテクスチャを入れる（陰影の縁・木目・地の色むら・模様のどれか）。宝石も縁の濃い色と光の点を描く。一つの面だけ単色だと、そこだけ急に違和感が出る（2026-11-17、祠の弓の緑青と星石が「のっぺり」）。
- 例（2026-11-17 の祠の鎚 v4）: 正面一面の細いひびの網・細い格子・四隅の鋲・重ねた板で、杖と剣より細かくなりすぎた。

### 1.8 目指す水準（2026-11-18 の参照から）

- 参照は今の模型の約 2 倍細かい画素で作られている（水晶の斧の柄は幅 4 画素）。そのため 2026-11-18 に全品を 2 倍の細かさ（1 画素 = 1/32 ブロック）にした（1.2）。1/16 ブロックの細かさでは、参照の台座・輪郭の飾り・帯の巻きを描く余地がない（鎚の試作で確かめた）。

参照: `docs/review/refs_1118/`（炎の杖・水晶の斧・弓・杖・水晶の蜘蛛・杖を作るタイムラプス）。ユーザーの目標は「全部このレベル」。

| 項目 | 参照がしていること | 決まり |
| --- | --- | --- |
| 塗り | 部品ごとに 3〜5 色の段階で塗り分ける（柄が紫→青へ移る、金が明→暗）。縁に濃い 1 画素、角に明るい点が数個 | 面は単色の地＋1 本の明るい縁ではなく、素材の色の段階で塗り分ける。暗い所の隣に明るい差し色を置いてコントラストを出す |
| 飾り | 飾り（光線の輪・三日月の爪・巻いた腕）は、1 単位の箱を方眼に並べたドット絵の輪郭を、厚み 1〜2 で立体にしたもの | 細かさは輪郭（影）で出す。面の上に細い格子や網を描き込まない（1.7）。方眼にそろった段はよい |
| 見せ所 | 頭と柄の継ぎ目に、面取りした宝石の台座。宝石は濃い縁・中・明るい芯の段階と光る芯 | 品ごとに、継ぎ目の台座と宝石を一つ作る（光るのは宝石の芯） |
| 柄 | 濃い帯と明るい帯が 1〜2 画素ずつ交互に並ぶ巻き | 柄は帯のリズムで塗る（赤い紐でも帯の明暗を付ける） |
| 作り方 | 色を塗った設定画を背景に置き、単色の箱で形を組み、最後に塗る | 担当は先に正面の設定画（色付きの PNG、模型と同じ大きさの方眼）を描いてから組む。設定画をそのまま押し出して模型にはしない（2026-11-17 に却下） |
| 確認 | — | 担当の報告には、作った品を参照と同じ大きさで並べた画像を必ず付ける |

- 参照と比べて足りなかったもの（2026-11-18 の祠の鎚）: ①丸い物（丸太・柄・輪）は角を落とす（大小 2 つの箱を十字に重ねて断面を八角にする） ②丸い物の面は片側を明るく、反対側を暗く塗る（縁の 1 画素だけでは丸く見えない） ③色の段階は色相をずらす（影は赤紫へ、光は黄へ。同じ色相のまま暗くすると泥のように見える） ④小さな石も光の点を 1 つ入れる（3×3 画素以上）。塗りの決まりは `tools/gen/pixel/paint_cubes.py` にまとめた。

### 1.9 全武器の作り直しの流れ（2026-11-18 から）

ユーザー「武器をすべて新しくして。すべて完成してから、シリーズごとにまとめて見せて」。祠の 6 品で決めた作り方を、全武器（台帳 `tools/models/x32/manifest.json`、人が読む表 `docs/review/gear_manifest.md`。`python -I tools/gen/pixel/gear_manifest.py` が作る）に広げる。

| 決まり | 中身 |
| --- | --- |
| 道具（2026-11-18 夜から） | **Blockbench の中で作る**（ユーザー「ちゃんと Blockbench で作って」。スクリプトで作った鯨・潮・嵐・火の品も作り直す。祠の 6 品はそのまま）。箱は MCP の `place_cube` で置き、塗りは下地の絵の上に `paint_with_brush` で手を入れる（ひび・欠け・苔・打ち傷・光の点）。保存は `export_model` で `tools/models/x32/<id>.bbmodel` へ直接書く。Blockbench は一つなので、品は一つずつ順番に作る（担当を同時に何人も動かさない）。`*_parts.py` は形の下地としてだけ使う |
| 形 | `tools/models/x32/<id>_parts.py` に箱の座標を手で書く（`seg` で斜め・曲線、`("mesh", 名前, 素材, 頂点, 面, 塗り方)` で刃の尖り）。前の模型（`lowpoly/items/<id>/`、`look_lineup` と同じ描き方で見る）の影と特徴を残し、作りの水準を上げる（「形は前のままで」2026-11-18 の剣）。前の模型を箱に置き換えるスクリプトは書かない（2026-11-17 に却下） |
| 塗り | `paint_cubes.py` の共通の色の段階（RAMPS）と塗り方。シリーズの色は、そのシリーズの品の形の決まりに `RAMPS = {...}` を同じ中身で書く（共通の名前を上書きしてよい。品ごとに変えない） |
| 豪華さ | 階級で決める（1.6）。木が基調なのは始めの武器だけ |
| 原点と向き | 原点 = 握りの真ん中（手が握る所）。+y が先。**片刃の武器（短剣・牙・爪・斧・鎌・鎚）は刃・打つ面を +x に作る**（描く時に種類で半回転する: `WeaponItemRenderer.singleEdge`） |
| 弓 | 弓腕は +x へ張り出し、弦は -x。**握りの真ん中は (12, 15)**（一人称の縮小と三人称の倒し方の回転の中心がここ）。引きの 3 段は `VARIANTS` で同じ形から書く（`shrine_bow_parts.py` が手本） |
| 持ち方 | 種類の決まりは `tools/gen/pixel/look_holds.py`（振る武器は前で上へ構える）。古い取り込み（tools/install）を流したら必ずこれも流す |
| 作って入れる | `python -I tools/gen/pixel/paint_cubes.py <parts.py> <bbmodel>` → `python -I tools/gen/pixel/bb_import.py <bbmodel>`。入れた品は既定で見える（武器の既定が look a） |
| 確かめる | `look_lineup.py` でシリーズの品・祠の品と並べる（表と裏）。シリーズが揃ったらゲームで撮る（近く・全身・一人称・振りの途中） |
| 道具を直したら | `bash tools/models/x32/build_shrine.sh` で祠の 6 品を作り直し、`git status` で `look/a/shrine_*` に差分が出ないことを確かめる |
| 進め方 | シリーズごと: ①シリーズの色と見せ所の言葉を決める ②品を作る ③並べて直す ④シリーズを 1 つずつコミット（main には入れない）。ユーザーには全シリーズが終わってから、シリーズごとの画像で見せる |

## 2. 担当ごと


### 2.1 戦士の担当（岩守り）— 剣・大剣・鉾・槍・盾

| 項目 | 中身 |
| --- | --- |
| 骨格（守る影） | 刃は握りから先へまっすぐ一本の線。鍔（横の棒）で刃と柄が分かれる。槍は長い柄の先に穂先 |
| 気配 | 重く、人を守る。刃は幅広・厚い背、鍔は盾のように張り出す |
| 許される奇抜さ | 刃の形（木の葉・幅が変わる・段）、鍔の翼や角、刃の根元の金具 |
| 許されない | 刃の大きな反り（暗殺者の領分）、浮いて離れた部品（魔法使いの領分）、刃に光る溝 |
| 差別化 | 職の中で一番「面」が広い。ほかの職の刃物より太く、鍔が大きい |
| 祠の剣で決めたこと | 木の葉の広刃（六角断面のメッシュ・斜めの光の帯）、付け根の金の輪、緑青の三日月の鍔、星石、赤い紐、輪の柄頭 |

### 2.2 鍛冶師の担当（灰の鍛え人）— 鎚・斧

| 項目 | 中身 |
| --- | --- |
| 骨格（守る影） | **柄に直角の頭が、柄の上端に乗る。頭は横長（横の長さ ≥ 縦の 1.5 倍）。片側に平らな打つ面（鎚）か刃（斧）が影に出る** |
| 気配 | 道具が武器になった重さ。炉・火・煤・焼き入れの色 |
| 許される奇抜さ | 頭の中の炉の窓・割れ目の光、背の爪や鉤、頭の帯や鋲、頭から細く上がる煙（頭の高さを越えない） |
| 許されない | 頭が縦長・箱形になること（角灯・ランタンに見える）、頭より高い煙突や炎、柄の途中の大きな飾り |
| 差別化 | 一番重い職。頭の量が全体の 3 割以上。火の色（橙）はこの職だけが主に使う |
| 祠の鎚で決めたこと | 戦鎚（両端に張り出した鋼の打つ面、緑青の頭に金の上下の枠、背に両脇が橙に光る鋼の錐）、柄は流木、面の格子は無し |

### 2.3 魔法使いの担当（星読み）— 杖

| 項目 | 中身 |
| --- | --- |
| 骨格（守る影） | 長い縦の柄の上に、枠・股・籠で囲んだ「焦点」（星・宝石）がある |
| 気配 | 星と空。軽く、上へ向かう |
| 許される奇抜さ | **浮く部品はこの職だけ**（枠の中に浮く星・回る輪）。光は全職で一番多くてよい（ただし小さい核） |
| 許されない | 刃、下へ垂れる飾り（呪術師の領分）、柄の太さが頭より目立つこと |
| 差別化 | 焦点は上に向けて「掲げる」。呪術師は下に「吊るす」 |
| 祠の杖で決めたこと | 流木の竪琴の股、外へ巻く先、金の輪で継ぎ目を隠す、光る星石と十字の星の板、葉は立体の板、白い実は置かない、握りはシリーズの赤い紐 |

### 2.4 弓使いの担当（骨の射手）— 弓・クロスボウ

| 項目 | 中身 |
| --- | --- |
| 骨格（守る影） | 握りから上下へ反る 2 本の弓腕と、端を結ぶ細い弦。引いた形（`_pull0〜2`）でも弓に見える |
| 気配 | 骨・流木・羽・雲。乾いて軽い |
| 許される奇抜さ | 弓腕の反り返り（リカーブ）、骨の節、羽飾り、左右非対称 |
| 許されない | 太い弦・光る弓腕、弓腕を隠す大きな飾り、弦の位置がずれて見えること |
| 差別化 | 唯一の「線」の武器。面を広げず、輪郭の曲線で見せる |
| 祠の弓で決めたこと | リカーブの流木弓（弓腕は曲線のメッシュ）、先は緑青、継ぎ目に金の輪、握りに金の台と貫く星石 1 つ（両面から見える）、2 色の弦、引きの 3 段 |

### 2.5 暗殺者の担当（風読み）— 短剣・牙・爪

| 項目 | 中身 |
| --- | --- |
| 骨格（守る影） | 短い刃（先まで 18 以下）。反り・鉤・牙の形 |
| 気配 | 速い・鋭い・影。くすんだ色に一点だけ鋭い差し色 |
| 許される奇抜さ | 強い反り、鉤、逆手向きの刃、風を流す鰭や布、左右非対称 |
| 許されない | 大きな鍔、金を多く使うこと、長い刃、光る大きな宝石 |
| 差別化 | 一番小さく、一番曲線が強い刃物。戦士の剣とは「短い・反る・暗い」で分ける |
| 祠の短剣で決めたこと | 細い一本の曲線の刃（六角断面のメッシュ）が先で鉤に反り、鋭い牙の先。金の鍔、赤い紐、緑青の柄頭に星石 |

### 2.6 呪術師の担当（潮歌い）— 鈴・祭具

| 項目 | 中身 |
| --- | --- |
| 骨格（守る影） | 柄の先が鉤・曲がりになり、そこから鈴（と紐・札）が**下へ吊り下がる** |
| 気配 | 潮・祭り・呪い。青緑と黒紫、紐・紙・鈴 |
| 許される奇抜さ | 揺れる紐、札、複数の鈴、骨や貝の飾り |
| 許されない | 上に掲げた星や浮く焦点（魔法使いの領分）、刃 |
| 差別化 | 魔法使いの杖は「掲げる」、呪術師は「吊るす」。影の重心が先の下側に来る |
| 祠の鈴杖で決めたこと | 流木の柄の先に緑青の鉤（曲線のメッシュ）、赤い紐で緑青の鈴（口が広がる回転体）が下がる。星石は鈴の舌として口の下に光る |

### 2.7 防具の担当

| 項目 | 中身 |
| --- | --- |
| 骨格 | 16 の 1 章の基盤（重ね板の騎士）と 2 章の決まりに従う。兜・胴・脚・靴の 4 部位で一つの意匠 |
