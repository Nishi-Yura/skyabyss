# 天と淵のあいだ 防具と装備 3D のデザイン

- 文書番号: 16
- 範囲: 巨神ごとの立体防具 4 組（岩鯨の甲殻・潮殻の鎧・雷翼の羽衣・余燼の鎧）の今の形と、これから作る全ての装備 3D（防具と、手に持つ武器の 3D）に使うデザインの決まり・手順・検査
- 関連: [15 ハイポリ化](15_high_poly.md)（面の予算・hpkit・描画の測り方）、[03 装備](03_gear_and_endgame.md)、[14 ベータ](14_beta.md)

## 1. 基盤

- 基盤は **重ね板（lamellae）の枠 + 巨神ごとの輪郭の飾り 1 つ + 素材の言葉**。傾けた板・扇・反った角を使い、肩・兜・背・腰の輪郭をプレイヤーの箱から外す。
- 理由（ユーザーの指摘「防具がダサすぎる。ハイポリを活かせていない。基盤を変えないと変わらない。今後の装備モデルも注意」）: 最初の作りは、体の箱に同じ幅の箱をかぶせ、縁とリベットを足しただけで、輪郭はプレイヤーと同じ四角、部位は別々の箱、テクスチャは均一な粒、巨神らしさは色と小さな飾りだけだった。直し方は 2 章の決まりになっている。
- 方向は 3 つ（A 重ね板の騎士 / B 生き物の外殻 / C 祭具と衣の重ね）を岩鯨で作り比べ、**A を採った**。A は、4 巨神の素材（岩・珊瑚・羽・割れた板）が全て「重なる板」で表せる、傾けた板で輪郭が箱から外れる、部品と面が最も少なく一式の関係を保ちやすい、が理由。B の「生き物の一点」は通常の飾りとして A の枠に足し、C の布・環はレア以上で足す（2.10）。B は離れた部品が浮いて散らかる、C は体の輪郭が箱のままで胴に布を垂らすと脚が貫く、が採らなかった理由。
- 道具: `tools/rough/armor_kit.py`（傾けた板・扇・反り角・材質の描き込み・重なりの検査・姿勢の検査）、部品 `tools/rough/armor_v2_parts.py`（兜・胴・肩・脚・靴）、4 組の形 `tools/rough/armor_v2_sets.py`、書き込み `tools/install_armor_v2.py`（決定的。`geo/armor`・`textures/armor` の 4 組 x 3 ファイルとアイコン 16 枚を書く。重なり・光る画素・面の予算を検査して通らなければ書かない）。
- 退役した最初の作り（`gen_armor_model.py`、`install_{tide,storm,ember}_armor.py` ほか）の中身は git の履歴にある。

## 2. 設計の決まり（全装備に使う）

### 2.1 輪郭（シルエット）

| 決まり | 内容 | 検査 |
| --- | --- | --- |
| 輪郭が先 | 先に輪郭を決め、材質と細部は後。輪郭を黒く塗りつぶしても、どの巨神か分かること | 比較画像の正面・横・背中を、灰色にして見る |
| 部位ごとに別の輪郭 | 肩（横に張る・せり上がる）、兜（頭上に伸びる）、背（後ろに張る）、腰とすね（すそが開く）で、プレイヤーの箱から外す | 正面・横・背中の 3 方向で、箱の四角に見えない |
| 左右非対称の一点 | 1 組に 1 つだけ、左右を変える（岩鯨は右肩の牙、余燼は左だけ大肩、潮殻と雷翼は冠・背で変える） | 4 組で重ならない |
| 傾ける | 板は 8〜16 度傾ける（肩は外が上がる、すそは外・前に開く）。軸に平行のままの板は、胴・脚の殻だけ | `rotation` を持つ部品が全体の 3 割以上（今: 岩鯨 45%・潮殻 42%・雷翼 52%・余燼 34%） |
| 縦の線を作る | 兜の冠・背の飾りで、プレイヤーより頭上を **4〜5** 伸ばす（8〜10 は「一角獣」になったので控えた。2.12） | 2.9 の表 |

### 2.2 大・中・小の階層

| 階層 | 例 | 割合の目安 |
| --- | --- | --- |
| 大（輪郭を決める） | 肩の板の重ね、冠・背の扇・尾びれ、兜の殻、胴の殻 | 見える面積の 6 割 |
| 中（まとまりを作る） | 縁の帯（腰・襟・兜の帯）、胸の肋・格子・稲妻、膝の板、裾の重ね板 | 3 割 |
| 小（焦点に置く） | 浮き枠の角の鋲、宝石、牙の先、羽の先 | 1 割。兜の前・胸の中央・腰・足首に集める。全面に散らさない |

### 2.3 一式で一つの意匠に見せる

| 決まり | 内容 |
| --- | --- |
| 同じ枠 | 4 部位とも `armor_v2_parts.py` の部品を使う。重ね板の段・縁の帯・浮き枠の寸法がそろう |
| 縁の帯 | 兜の帯・襟・腰の帯・袖口・膝・靴の折り返しが同じ材質（骨・真珠層・銀・煤けた鉄）で、一式を縦に結ぶ |
| 光の位置 | 兜の額の小さな宝石（余燼は折れ角の先）・胸・腰の宝石・膝と足首の宝石。全 4 部位に光る画素があること（装備した部位だけでも光る） |
| 輪郭の繰り返し | 岩鯨は「肋と背びれ（弧）」、潮殻は「枝と帆立の筋」、雷翼は「羽の放射」、余燼は「割れた板と一本の角」を、兜・肩・背で繰り返す |

### 2.4 巨神ごとの素材の言葉と輪郭の飾り

| 巨神 | 素材の言葉 | 主 / 副 / 縁 | 輪郭の飾り（一点） | 光 |
| --- | --- | --- | --- | --- |
| 岩鯨 | 鯨骨と岩の殻 | 青灰の岩（割れ・鋲の板）/ 同色の畝 / 骨（年輪） | 兜の低い背びれ冠（後ろへ流す）、胸の肋の弧、右肩にせり上がる牙、腰の尾びれ | 水色（核） |
| 潮殻 | 珊瑚と真珠層 | 青緑の珊瑚（穴）/ 畝の貝 / 真珠層（虹の差し色） | 兜の珊瑚の角（低い・先で枝分かれ）、帆立の畝を持つ肩、背の珊瑚の房、足首の鰭 | 桃色（真珠） |
| 雷翼 | 羽と嵐の金具 | 紺の鋼（ブラシ）/ 羽 / 銀 | 背の羽（肩甲骨に沿う 1 層・3 枚ずつ、横 ±10 以内）、羽の兜（短い羽 2 枚ずつ）、胸の稲妻、長い腰の羽 | 白青（稲妻） |
| 余燼 | 熾火の割れた板と煤けた鉄 | 灰黒の板（割れ目が光る）/ 煤けた鉄 / 煤色の縁 / ぼろ布 | 兜の折れた角（低い）、左だけの大肩（2 層）、胸の炉の格子、ぼろの腰 | 橙（割れ目・格子） |

### 2.5 プレイヤーの体の動きとの干渉

| 決まり | 内容 |
| --- | --- |
| 休めの姿勢で重なり 0 | 体の殻と腕の殻の境は x = ±4.6 で接する。腰の幅 ±4.6 より外は脚の骨で持つ |
| 腕を振っても埋まらない | 肩の板は腕の骨に付ける（腕と一緒に動く）。頭に近い板は x ≤ -5.4（内端が頬の板より外）。体に近い張り出しは作らない |
| 背の張り出しは y ≥ 15 | 腕を後ろへ 30 度振ると手は z = 5（y 13 付近）。背の翼・びれは y 17 以上、z 5.8 以上 |
| 垂れる布は脚の骨 | 胴の骨に長い布を垂らすと、歩くときに脚が貫く。布は脚の骨に左右 2 枚に分けて付ける |
| 姿勢の検査 | `armor_kit.Armor.pose_collisions()` が 10 の姿勢（歩き 2・腕上げ・腕を横に 45 度・腕を後ろ・首を回す・上下・かがむ・座る）で別の骨どうしの食い込みを測る。関節の食い込みは 2.5 以下、それより深いものは報告 |

### 2.6 材質・色・光（テクスチャ）

| 決まり | 内容 |
| --- | --- |
| 光を焼かない | 面ごとの向きの陰影はゲームが足す。絵には焼かない（焼くと二重になる） |
| 焼くもの | 材質の描き込み（岩の割れ・骨の年輪・羽の筋・熾火の割れ・真珠層・穴・畝・ブラシ）、縁の明るい 1 画素と暗い 1 画素、下に向かう暗さ、大きな面の彫り込み枠（凹んだ線）と鋲 |
| 明るさ 5 段 | 暗い巨神（余燼・岩鯨）でも、主の材質の最明段を 150 前後まで上げ、縁の材質（骨・煤の金具）を 1〜2 段明るくして形を読ませる |
| 材質は 3〜5 | 主・副・縁 + 光 + （珊瑚・銅・ぼろ布のどれか 1 つ）。それ以上は増やさない |
| 光る画素（glowmask） | 光る面は材質 `glow` の面と、割れ目（余燼の `plate_cracked`）。全 4 部位に 1 画素以上。光らせない面を光らせない（背中・脚の殻は光らせない） |
| 光る色 | 岩鯨 水色 / 潮殻 桃 / 雷翼 白青 / 余燼 橙。他の巨神と混ぜない |
| テクスチャの大きさ | 面の寸法 x 4 texel。4 組とも 512x512 |

### 2.7 ハイポリの使いどころ

| 手 | 使う場所 | しない場所 |
| --- | --- | --- |
| 面取り（0.5 の 1 段） | 胴・肩・兜の殻の角。傾けた板も面取りする（`hpkit.round_cube`） | 厚さ 1 未満の薄い板・細い牙 |
| 浮き枠（四辺の帯 + 四隅の鋲、高さ 0.4〜0.7） | 胸の前（飾りのない巨神）、背、腕の外、脚の後ろ、靴の脛 | 肋・格子・稲妻など別の飾りを置く面 |
| 重ね（大・中・小の段差） | 肩 3 段、兜 2 段 + 帯、腰 3 枚 | 段差が見えない後ろ側 |
| 反り角（`Armor.spike`） | 冠・牙・珊瑚・羽。節ごとに少しずつ曲げる（6〜7 度/節） | 曲げが急な角（節が積み石に見える） |
| 彫り | 板の彫り込み枠（テクスチャ） | 彫りのための細かい穴（面が増える割に見えない） |

### 2.10 レアと伝説の見た目の差（決まりだけ。実装はない）

| 段 | 差の付け方 | 例 |
| --- | --- | --- |
| 通常 | 枠（重ね板・浮き枠）+ 巨神の飾り 1 つ | 今の 4 組 |
| レア | 光る部分を増やす（縁の帯に光の筋、冠の先、肩の板に光る割れ目）。飾りを 1 つ足す（左右どちらかの肩） | 面 +10% 以内 |
| 伝説 | 飾りを全部足す + 背の大きな一点（翼・びれ・環・熾火の大肩の対）+ 布（祭具の帯・環）を足す | 面 +30% 以内。2.9 の限度は守る |
| 見分け方 | 輪郭の違いが先（光の量は 2 番目）。同じ巨神でも段が違えば輪郭が違うこと | 灰色の輪郭で見分けられる |

### 2.11 手に持つ武器の 3D への適用

| 決まり | 武器での意味 |
| --- | --- |
| 輪郭が先 | 持ち手から先まで、直線 1 本にしない。刃・穂先・槌頭に傾き・反り・段を付ける（`Armor.spike`・傾けた板） |
| 大・中・小 | 刃や槌頭（大）、鍔・帯・巻き輪（中）、鋲・宝石・光る刃先（小） |
| 一点の飾り | 巨神の飾りを 1 つ繰り返す（岩鯨の武器は骨の反り、潮殻は枝、雷翼は羽、余燼は割れ目） |
| 材質 | 防具と同じ材質の言葉・同じ描き込み（`armor_kit.Mat`）を使う。アイテムの絵（32px）に従う、が先 |
| 面の予算 | gear は 600 面以内（15 の予算）。面取りは厚さ 1 以上の部分だけ |
| 重なり | 軸に平行は 0、傾けた板は食い込み 0.35 以下 |
| 手の受け口 | 骨の名前・pivot は変えない（`socket_main` ほか） |
| 検査 | 同じ姿勢の検査・光る画素の検査をかける。`armor_kit` は gear の geo にも使える（骨の名前だけ差し替える） |

### 2.12 顔を隠さない兜と、飾りの大きさの上限（全装備）

理由: 兜の前が「光る細い窓」だとロボットのバイザーに見え、巨神の素材・静かなホラーに合わない。雷翼の背の羽の扇はハリネズミ、岩鯨の頭頂の角は一角獣のように見えた。

| 決まり | 内容 | 検査 |
| --- | --- | --- |
| 顔を開ける | 兜はプレイヤーの顔（頭の箱の前面 \|x\| < 4、y 24〜29.6、z -4）の前に何も置かない。額当て（y ≥ 29.6）・耳当て（頭の横 x ±4〜4.6）・後頭部の殻・鼻当て（幅 1、目の間）・頬の板（顔の横の外側）で顔を囲む。あごと口は開ける | 正面・3/4 の比較画像でスキンの顔が見える。`armor_v2_parts.kabuto` の「顔の前」に箱を足さない |
| 光る窓の禁止 | 兜の前面に細長い光る窓（バイザー）を置かない。光は額の小さな宝石（幅 1.4〜1.6 x 高さ 0.6〜0.8）か、角の先などごく一部 | 兜の光る画素は 1 以上（兜に光が無くなるなら glow の部位を別に残す） |
| 兜の飾りの高さ | 兜の上端（y 32.6）から +5 まで。冠・角は低く、後ろへ流す（反りを使う）。1 本が細く真上に立つ形（一角獣・アンテナ）にしない | `ext` の頭上 ≤ 37.6 |
| 背の飾りの幅 | 腕と肩の幅の内側（±10.5）。羽・びれ・房は肩甲骨に沿わせ、放射状に広げない。本数は片側 3 まで、1 層 | 背中の比較画像で輪郭がハリネズミにならない |
| 肩の張り出し | ±13（垂れる飾りの先は ±14）まで。非対称の大肩でも 2 層で足りる | 2.9 の表 |
| 腕を上げても兜に入らない | 肩の飾りは腕を横に 45 度上げた姿勢でも、兜・襟に 2.5 以上食い込まない | `pose_collisions(tol=2.5)` の報告が 0 |
| 世界観 | 古代の巨神の素材を、静かに身に着けた姿。機械・ロボットに見える面（横一文字の窓・パイプ・目）を作らない | 灰色の輪郭と顔の見え方を比べる |

## 3. GeckoLib の防具の骨と、実機で測ったこと

骨は 8 本（`armorHead`, `armorBody`, `armorRightArm`, `armorLeftArm`, `armorRightLeg`, `armorLeftLeg`, `armorRightBoot`, `armorLeftBoot`）。骨の名前・pivot は変えない。キューブの回転は各キューブの `pivot`（そのキューブの中心）まわり。アニメ（`animations/armor/*`）、バニラ層（`textures/models/armor/*_layer_{1,2}.png`）、item モデル（`models/item/*`）は触らない。

| 骨 | pivot | 範囲（休めの姿勢） | 属する部品 |
| --- | --- | --- | --- |
| armorHead | (0, 24, 0) | x ±4.9、z ±4.9、y 25.2〜32.6（冠・角は頭上へ） | 兜の殻・帯・目・頬・冠・角・首の板 |
| armorBody | (0, 24, 0) | x ±4.6、z -3.4〜3.1、y 12.4〜25（背と尾びれは後ろへ） | 胸・腹・帯・襟・肋・背の飾り・尾びれ・翼 |
| armorRightArm / LeftArm | (-5, 22, 0) / (5, 22, 0) | x ±4.6〜8.9、y 11.4〜23（肩の板は上へ・外へ） | 腕の殻・袖口・肩の重ね板・牙 |
| armorRightLeg / LeftLeg | (-1.9, 12, 0) / (1.9, 12, 0) | y 4.6〜12 | 腿の殻・腰の帯・裾の板・膝の板 |
| armorRightBoot / LeftBoot | 同上 | y 0〜4.6 | 靴・折り返し・つま先・足首の鰭 |

回転の符号（棒を傾けた試験の防具を台本で撮り、ラフの描画と見比べて測った）:

| 軸 | 結果 |
| --- | --- |
| x の回転（前後に傾ける）、y の回転（ひねる） | ラフの描画と一致 |
| z の回転（横に傾ける） | **逆向きに回る**。geo には z の符号を反転して書く（`armor_kit.Armor.build` が反転、プレビューは `flip_z` で戻す）。ラフで見た形が実機と同じになる |

人気の立体防具 mod も「骨の名前と pivot を守り、キューブを足して肩・すそ・飾りを作る」作りで、輪郭・階層・繰り返しの考えは一般のゲームキャラ設計と同じ。参考: [Shape language in game character design (RocketBrush)](https://rocketbrush.com/blog/shape-language-in-game-character-design-how-to-make-characters-readable-and-consistent)、[Warframe Basic Art Guide](https://warframe.com/steamworkshop/basic-art-guide)、[Armor Model API (Modrinth)](https://modrinth.com/project/armor-model-api)、[GeckoLib Armor wiki](https://github.com/bernie-g/geckolib/wiki/Geckolib-Armor-(Geckolib3))。

- 光る画素は 4 組 x 4 部位全てにある。
- **ゲームで使っているのは低ポリの C 骨組み**（[15](15_high_poly.md) の 4.6.3）。この章の表は元のキューブ版（`LowPolyArmor.enabled = false` で戻る）。低ポリ版の三角形は一式で通常 627〜864、レア 699〜980、伝説 804〜1,080（予算: 伝説 1,100 以下）。岩鯨・雷翼の伝説は背の環を軽くし、レアより増える背の弧・羽の 3 組目をやめて収めた。アトラスに面の向きの陰影が焼いてあるので、描画では法線を真上へ 0.4 寄せ、腕を上げた防具立てで肩の板が暗く沈まないようにしている。

## 5. 作る手順（これから防具・武器を作るとき）

1. 巨神の素材の言葉と輪郭の飾りを 2.4 に 1 行足す（これが先）。
2. `armor_v2_sets.py` に組を足す（材質 `Mat`、`armor_v2_parts` の部品、飾り 1 つ）。武器は `armor_kit.Armor` で gear の骨名を使う。
3. `python tools/rough/armor_v2_sets.py <名前>` で比較シート（正面・横・背・3/4・腕上げ・歩き・振り）。3 方向以上で作る場合は並べて選ぶ。比較シートの道具は `tools/rough/armor_v3_compare.py`・`armor_v3_icons_compare.py`、画像は `docs/review/armor_v2_roughs/`。
4. `python tools/install_armor_v2.py` で検査と書き込み（アイコンも）。
5. `./gradlew runShots -Pscript=tools/shots/armor_v2.txt -PshotsName=<名前>` で実機を撮る（防具立て 4 つ、正面・横・背・歩き・腕上げ・近景。OS の入力は使わない）。

## 7. 既知の問題・制限

- 防具立ての頭は小さな木の頭で、プレイヤーのスキンの顔は実機で確かめていない（ラフのマネキンの顔は見える。兜が顔の前に箱を持たないことは寸法で確認）。一人称の腕、スニーク、馬・船に乗る姿勢も実機で確かめていない（試遊 14 で見る）。
- 雷翼の背の羽は 3 枚ずつでもまだ「羽の扇」に見える。さらに減らすなら 2 枚。岩鯨の冠は正面から細い角に見える（横からは後ろへ流れた背びれ）。
- 脚と靴のアイコンは、部位が短い（脚 y 4.6〜12、靴 y 0〜4.6）ので横長の対になり、縦長のズボンの絵より読みにくい。3D に忠実なままにしてある。
- 立体防具を着たプレイヤーが多い場面の描画負荷は測っていない（面は少ない。15 の測り方で測る）。
