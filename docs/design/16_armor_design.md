# 16 防具と装備 3D のデザイン基盤

担当: 防具の作り直し。対象は巨神ごとの立体防具 4 組 (岩鯨の甲殻・潮殻の鎧・雷翼の羽衣・余燼の鎧)。ここに書く「設計の決まり」は、**これから作る全ての装備 3D (防具と、手に持つ武器の 3D)** に使う。
経緯: ユーザーの指摘「防具がダサすぎる。ハイポリを活かせていない。防具のデザイン基盤を変えないとこのダサさは変わらない。今後の装備モデルも注意」。
(00 は編集しない。判断が要る点は 11 章。)

## 0. 要約

| 項目 | 内容 |
|---|---|
| 何がダサかったか | 体の箱に、同じ幅の箱をかぶせ、縁とリベットを足しただけだった。輪郭はプレイヤーと同じ四角、部位は別々の箱、テクスチャは均一な粒、巨神らしさは色と小さな飾りだけ (2 章) |
| 基盤を何に変えたか | **重ね板 (lamellae) の枠 + 巨神ごとの輪郭の飾り 1 つ + 素材の言葉** に変えた。傾けた板・扇・反った角を使い、肩・兜・背・腰の輪郭をプレイヤーの箱から外す (3〜4 章) |
| 3 つの方向 | A 重ね板の騎士 / B 生き物の外殻 / C 祭具と衣の重ね。岩鯨で 3 つ作り比べた (6 章)。**推奨は A**。A の枠に、B の「生き物の一点」と C の「布・環」を飾りとして足せる |
| 作り直した 4 組 | 岩鯨 (背びれの冠・肋・せり上がる牙・尾びれ)、潮殻 (珊瑚の角・帆立の肩・背の珊瑚)、雷翼 (背の羽の扇・羽の兜・稲妻)、余燼 (折れた角・左だけの大肩・炉の格子・ぼろの腰) (7 章) |
| 数字 | 4 組とも 重なり 0、光る画素あり (全 16 部位)、面 1,304〜1,755 (前の 1,634〜2,180 より少ない。5 部位合計 3,000 の内) |
| 道具 | `tools/rough/armor_kit.py` (傾けた板・扇・反り角・材質の描き込み・重なりの検査・姿勢の検査)、`tools/install_armor_v2.py` |

## 2. 何がダサかったか (診断)

| # | 見えたこと | 原因 (v1 の作り) | 直し方 (この章の決まり) |
|---|---|---|---|
| 1 | 体に箱を貼っただけ。肩も胸も腰もプレイヤーの箱を 0.5〜1 太らせた箱 | 立方体は全て軸に平行。回転した板が 1 枚もない | 傾けた板・扇・反り角を使う (3.1) |
| 2 | 輪郭がプレイヤーと同じ四角 (横 ±10.5、頭上 +6) | 肩当てが体の幅の内側。頭の上に飾りがほぼない。背・腰に張り出しがない | 肩・兜・背・腰で輪郭を変える。大きさの上限を決める (3.1, 3.9) |
| 3 | 部位がばらばら。兜は兜、胸は胸で、一式に見えない | 部位ごとに独立した箱の組。共通の形も飾りもない | 4 部位とも同じ枠 (重ね板) と、巨神の一つの飾りを繰り返す (3.3, 3.4) |
| 4 | 素材感がない。石も骨も「4 段の濃淡 + 粒」 | 面の向きの光を絵に焼き込み (ゲームも面ごとに陰影を足すので二重)、模様は一様な粒 | 光は焼かない。材質ごとの描き込み (割れ・年輪・羽・熾火・真珠層)、縁と影だけ焼く (3.6) |
| 5 | 巨神らしさが色と小さな飾りだけ | 岩鯨も潮殻も雷翼も余燼も同じ箱の組で、色と 2〜3 個の飾りだけ違う | 巨神ごとに「輪郭の飾り」を一つ決める (3.4) |
| 6 | ハイポリにしたのに変わって見えない | 0.25 の縁とリベットを足しただけ。大きな面が平らなまま | 大きな面に浮き枠・角の面取り・段差を足し、面の陰影で形を出す (3.7) |
| 7 | 真っ黒・真っ暗に近い | 余燼は黒 + 少しの橙、岩鯨は暗い紺で、面ごとの差が小さい | 暗い巨神でも 5 段の明るさと明るい縁取り (骨・熾火) で形を読ませる (3.6) |
| 8 | 腕を振ると一枚の板がぶれる。肩の板が体と同じ動き | 肩当てが胴の骨にも腕の骨にも属さない箱で、動きの設計がない | 肩の板は腕の骨に付ける。張り出しは骨ごとに範囲を決める (4 章) |

## 3. 設計の決まり (全装備に使う)

### 3.1 輪郭 (シルエット)

| 決まり | 内容 | 検査 |
|---|---|---|
| 輪郭が先 | 先に輪郭を決め、材質と細部は後。輪郭を黒く塗りつぶしても、どの巨神か分かること | 比較画像の正面・横・背中を、灰色にして見る |
| 部位ごとに別の輪郭 | 肩 (横に張る・せり上がる)、兜 (頭上に伸びる)、背 (後ろに張る)、腰とすね (すそが開く) で、プレイヤーの箱から外す | 正面・横・背中の 3 方向で、箱の四角に見えない |
| 左右非対称の一点 | 1 組に 1 つだけ、左右を変える (岩鯨は右肩の牙、余燼は左だけ大肩、潮殻と雷翼は冠・背で変える) | 4 組で重ならない |
| 傾ける | 板は 8〜16 度傾ける (肩は外が上がる、すそは外・前に開く)。軸に平行のままの板は、胴・脚の殻だけ | `rotation` を持つ部品が全体の 3 割以上 (今: 岩鯨 45%・潮殻 42%・雷翼 52%・余燼 34%。面取り前の部品数は 132・127・156・116) |
| 縦の線を作る | 兜の冠・背の飾りで、プレイヤーより頭上を **4〜5** 伸ばす (v2 の 8〜10 は「一角獣」になったので v3 で控えた。3.12) | 3.9 の表 |

### 3.2 大・中・小の階層

| 階層 | 例 | 割合の目安 |
|---|---|---|
| 大 (輪郭を決める) | 肩の板の重ね、冠・背の扇・尾びれ、兜の殻、胴の殻 | 見える面積の 6 割 |
| 中 (まとまりを作る) | 縁の帯 (腰・襟・兜の帯)、胸の肋・格子・稲妻、膝の板、裾の重ね板 | 3 割 |
| 小 (焦点に置く) | 浮き枠の角の鋲、宝石、牙の先、羽の先 | 1 割。兜の前・胸の中央・腰・足首に集める。全面に散らさない |

### 3.3 一式で一つの意匠に見せる (部位どうしのつながり)

| 決まり | 内容 |
|---|---|
| 同じ枠 | 4 部位とも `tools/rough/armor_v2_parts.py` の部品 (兜・胴・肩・脚・靴) を使う。重ね板の段・縁の帯・浮き枠の寸法がそろう |
| 縁の帯 | 兜の帯・襟・腰の帯・袖口・膝・靴の折り返しが同じ材質 (骨・真珠層・銀・煤けた鉄) で、一式を縦に結ぶ |
| 光の位置 | 兜の額の小さな宝石 (余燼は折れ角の先)・胸・腰の宝石・膝と足首の宝石。全 4 部位に光る画素があること (装備した部位だけでも光る)。**兜の「光る横一文字の窓」は禁止** (3.12) |
| 輪郭の繰り返し | 岩鯨は「肋と背びれ (弧)」、潮殻は「枝と帆立の筋」、雷翼は「羽の放射」、余燼は「割れた板と一本の角」を、兜・肩・背で繰り返す |

### 3.4 巨神ごとの素材の言葉と輪郭の飾り

| 巨神 | 素材の言葉 | 主 / 副 / 縁 | 輪郭の飾り (一点) | 光 |
|---|---|---|---|---|
| 岩鯨 | 鯨骨と岩の殻 | 青灰の岩 (割れ・鋲の板) / 同色の畝 / 骨 (年輪) | 兜の低い背びれ冠 (後ろへ流す)、胸の肋の弧、右肩にせり上がる牙、腰の尾びれ | 水色 (核) |
| 潮殻 | 珊瑚と真珠層 | 青緑の珊瑚 (穴) / 畝の貝 / 真珠層 (虹の差し色) | 兜の珊瑚の角 (低い・先で枝分かれ)、帆立の畝を持つ肩、背の珊瑚の房、足首の鰭 | 桃色 (真珠) |
| 雷翼 | 羽と嵐の金具 | 紺の鋼 (ブラシ) / 羽 / 銀 | 背の羽 (肩甲骨に沿う 1 層・3 枚ずつ、横 ±10 以内)、羽の兜 (短い羽 2 枚ずつ)、胸の稲妻、長い腰の羽 | 白青 (稲妻) |
| 余燼 | 熾火の割れた板と煤けた鉄 | 灰黒の板 (割れ目が光る) / 煤けた鉄 / 煤色の縁 / ぼろ布 | 兜の折れた角 (低い)、左だけの大肩 (2 層)、胸の炉の格子、ぼろの腰 | 橙 (割れ目・格子) |

### 3.5 プレイヤーの体の動きとの干渉

GeckoLib の防具は 8 本の骨 (`armorHead`, `armorBody`, `armorRightArm`, `armorLeftArm`, `armorRightLeg`, `armorLeftLeg`, `armorRightBoot`, `armorLeftBoot`) に付け、骨の名前・pivot は変えない (4 章)。

| 決まり | 内容 |
|---|---|
| 休めの姿勢で重なり 0 | 体の殻と腕の殻の境は x = ±4.6 で接する。腰の幅 ±4.6 より外は脚の骨で持つ |
| 腕を振っても埋まらない | 肩の板は腕の骨に付ける (腕と一緒に動く)。頭に近い板は x ≤ -5.4 (内端が頬の板より外)。体に近い張り出しは作らない |
| 背の張り出しは y ≥ 15 | 腕を後ろへ 30 度振ると手は z = 5 (y 13 付近)。背の翼・びれは y 17 以上、z 5.8 以上 |
| 垂れる布は脚の骨 | 胴の骨に長い布を垂らすと、歩くときに脚が貫く。布は脚の骨に左右 2 枚に分けて付ける |
| 姿勢の検査 | `armor_kit.Armor.pose_collisions()` が 10 の姿勢 (歩き 2・腕上げ・腕を横に 45 度・腕を後ろ・首を回す・上下・かがむ・座る) で別の骨どうしの食い込みを測る。関節の食い込みは 2.5 以下、それより深いものは報告 (8 章) |

### 3.6 材質・色・光 (テクスチャ)

| 決まり | 内容 |
|---|---|
| 光を焼かない | 面ごとの向きの陰影はゲームが足す。絵には焼かない (v1 は焼いて二重だった) |
| 焼くもの | 材質の描き込み (岩の割れ・骨の年輪・羽の筋・熾火の割れ・真珠層・穴・畝・ブラシ)、縁の明るい 1 画素と暗い 1 画素、下に向かう暗さ、大きな面の彫り込み枠 (凹んだ線) と鋲 |
| 明るさ 5 段 | 暗い巨神 (余燼・岩鯨) でも、主の材質の最明段を 150 前後まで上げ、縁の材質 (骨・煤の金具) を 1〜2 段明るくして形を読ませる |
| 材質は 3〜5 | 主・副・縁 + 光 + (珊瑚・銅・ぼろ布のどれか 1 つ)。それ以上は増やさない |
| 光る画素 (glowmask) | 光る面は材質 `glow` の面と、割れ目 (余燼の `plate_cracked`)。全 4 部位に 1 画素以上。光らせない面を光らせない (背中・脚の殻は光らせない) |
| 光る色 | 岩鯨 水色 / 潮殻 桃 / 雷翼 白青 / 余燼 橙。他の巨神と混ぜない |
| テクスチャの大きさ | 面の寸法 x 4 texel。4 組とも 512x512 (v1 は岩鯨だけ 256x113) |

### 3.7 ハイポリの使いどころ

| 手 | 使う場所 | しない場所 |
|---|---|---|
| 面取り (0.5 の 1 段) | 胴・肩・兜の殻の角。傾けた板も面取りする (`hpkit.round_cube`) | 厚さ 1 未満の薄い板・細い牙 |
| 浮き枠 (四辺の帯 + 四隅の鋲、高さ 0.4〜0.7) | 胸の前 (飾りのない巨神)、背、腕の外、脚の後ろ、靴の脛 | 肋・格子・稲妻など別の飾りを置く面 |
| 重ね (大・中・小の段差) | 肩 3 段、兜 2 段 + 帯、腰 3 枚 | 段差が見えない後ろ側 |
| 反り角 (`Armor.spike`) | 冠・牙・珊瑚・羽。節ごとに少しずつ曲げる (6〜7 度/節) | 曲げが急な角 (節が積み石に見える) |
| 彫り | 板の彫り込み枠 (テクスチャ) | 彫りのための細かい穴 (面が増える割に見えない) |

### 3.10 レアと伝説の見た目の差 (これから)

| 段 | 差の付け方 | 例 |
|---|---|---|
| 通常 | 枠 (重ね板・浮き枠) + 巨神の飾り 1 つ | 今回の 4 組 |
| レア | 光る部分を増やす (縁の帯に光の筋、冠の先、肩の板に光る割れ目)。飾りを 1 つ足す (左右どちらかの肩) | 面 +10% 以内 |
| 伝説 | 飾りを全部足す + 背の大きな一点 (翼・びれ・環・熾火の大肩の対) + 布 (C の祭具の帯・環) を足す | 面 +30% 以内。3.9 の限度は守る |
| 見分け方 | 輪郭の違いが先 (光の量は 2 番目)。同じ巨神でも段が違えば輪郭が違うこと | 灰色の輪郭で見分けられる |

### 3.11 手に持つ武器の 3D への適用

| 決まり | 武器での意味 |
|---|---|
| 輪郭が先 | 持ち手から先まで、直線 1 本にしない。刃・穂先・槌頭に傾き・反り・段を付ける (`Armor.spike`・傾けた板) |
| 大・中・小 | 刃や槌頭 (大)、鍔・帯・巻き輪 (中)、鋲・宝石・光る刃先 (小) |
| 一点の飾り | 巨神の飾りを 1 つ繰り返す (岩鯨の武器は骨の反り、潮殻は枝、雷翼は羽、余燼は割れ目) |
| 材質 | 防具と同じ材質の言葉・同じ描き込み (`armor_kit.Mat`) を使う。アイテムの絵 (32px) に従う、が先 |
| 面の予算 | gear は 600 面以内 (15 の予算)。面取りは厚さ 1 以上の部分だけ |
| 重なり | 軸に平行は 0、傾けた板は食い込み 0.35 以下 (7 章の検査と同じ) |
| 手の受け口 | 骨の名前・pivot は変えない (`socket_main` ほか) |
| 検査 | 同じ姿勢の検査・光る画素の検査をかける。`armor_kit` は gear の geo にも使える (骨の名前だけ差し替える) |

### 3.12 顔を隠さない兜と、飾りの大きさの上限 (v3 の決まり。全装備)

| 決まり | 内容 | 検査 |
|---|---|---|
| 顔を開ける | 兜はプレイヤーの顔 (頭の箱の前面 \|x\| < 4、y 24〜29.6、z -4) の前に何も置かない。額当て (y ≥ 29.6)・耳当て (頭の横 x ±4〜4.6)・後頭部の殻・鼻当て (幅 1、目の間)・頬の板 (顔の横の外側) で顔を囲む。あごと口は開ける | 正面・3/4 の比較画像でスキンの顔が見える。`armor_v2_parts.kabuto` の「顔の前」に箱を足さない |
| 光る窓の禁止 | 兜の前面に細長い光る窓 (バイザー) を置かない。ロボットに見える。光は額の小さな宝石 (幅 1.4〜1.6 x 高さ 0.6〜0.8) か、角の先などごく一部 | 兜の光る画素は 1 以上 (全 4 部位に光が必要なので、兜に光が無くなるなら glow の部位を別に残す) |
| 兜の飾りの高さ | 兜の上端 (y 32.6) から +5 まで。冠・角は低く、後ろへ流す (反りを使う)。1 本が細く真上に立つ形 (一角獣・アンテナ) にしない | `ext` の頭上 ≤ 37.6 |
| 背の飾りの幅 | 腕と肩の幅の内側 (±10.5)。羽・びれ・房は肩甲骨に沿わせ、放射状に大きく広げない。本数は片側 3 まで、1 層 | 背中の比較画像で輪郭がハリネズミにならない |
| 肩の張り出し | ±13 (垂れる飾りの先は ±14) まで。非対称の大肩でも 2 層で足りる | 3.9 の表 |
| 腕を上げても兜に入らない | 肩の飾りは腕を横に 45 度上げた姿勢でも、兜・襟に 2.5 以上食い込まない。肩の外へ出す・層を減らす・低くする | `pose_collisions(tol=2.5)` の報告が 0 |
| 世界観 | 古代の巨神の素材を、静かに身に着けた姿。機械・ロボットに見える面 (横一文字の窓・パイプ・目) を作らない | 灰色の輪郭と顔の見え方を比べる |

## 4. GeckoLib の防具の骨と、測ったこと

## 6. 3 つの方向のラフと推奨 (岩鯨の甲殻)

比較画像: `docs/review/armor_v2_roughs/whale_three_bases.png` (前の姿・A・B・C・推奨の 5 行、正面・横・背・3/4・腕上げ・歩き・振りの 7 列)。ラフの生成: `python tools/rough/armor_v2_whale.py A B C --out <一時>`。ラフは重なりを詰めていない (A 4、B 5、C 6 か所、食い込みは最大 0.85)。

| 案 | 基盤の考え | 箱/面 | 長所 | 短所 |
|---|---|---|---|---|
| A 重ね板の騎士 | 小さな板を重ね、傾けて、肩・腰・すそを広げる。一式を同じ段で結ぶ | 196/1,038 | 部位がそろう。どの巨神にも「素材の板」で当てはめられる。傾けた板が多いので輪郭が出る。動いても板の関係が崩れない | 3 方向とも「武者」に寄る。巨神の個性は飾りで足す必要がある |
| B 生き物の外殻 | 鯨の体の一部が生えたように見せる (肋・背びれ・牙・びれ) | 220/1,184 | 一番「岩鯨」に見える。左右非対称 | 離れた部品 (背の板・腕の牙) が浮いて見え、散らかる。他の巨神に流用しにくい |

推奨 A の理由: (1) 4 つの巨神の素材 (岩・珊瑚・羽・割れた板) が全て「重なる板」で表せる。(2) 傾けた板で輪郭がプレイヤーの箱から外れる。(3) 部品の数と面が最も少なく、一式の関係 (3.3) を保ちやすい。

## 9. 手順 (これから防具・武器を作るとき)

1. 巨神の素材の言葉と輪郭の飾りを 3.4 に 1 行足す (これが先)。
2. `armor_v2_sets.py` に組を足す (材質 `Mat`、`armor_v2_parts` の部品、飾り 1 つ)。武器は `armor_kit.Armor` で gear の骨名を使う。
3. `python tools/rough/armor_v2_sets.py <名前>` で比較シート (正面・横・背・3/4・腕上げ・歩き・振り)。3 方向以上で作る場合は 6 章のように並べる。
4. `python tools/install_armor_v2.py` で検査と書き込み (アイコンも)。
5. `./gradlew runShots -Pscript=tools/shots/armor_v2.txt -PshotsName=<名前>` で実機の前後を撮る (OS の入力は使わない)。

## 12. v3 の直し (顔の見える兜・飾りを控えめに)
