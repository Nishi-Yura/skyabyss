## 0. 試遊の感想と、コードで確かめた原因

感想（要点）: 村が見つからない。空の影が来ないまま鯨に会った。鯨に会うまでが何もなく、mod を入れた感じがしない。岩鯨の前に飽きた。ストーリーを感じない。レベルアップなどの文がチャットに流れて見づらい。

望み: 始まった瞬間から mod の世界だと感じたい。世界観を忘れさせず、物語を大事に。ところどころ精神的にくるホラー（最初は見えない大きな生き物、巨神。大きさで怖がらせる）。RPG 感を強く、ただし芯はぶれず、引き算で。

| 感想 | コードで確かめた原因 |
| --- | --- |
| 空の影が来ない | `SkyEvents` は、ワールド最初の tick から 2〜4 日後に最初の通過を予約する。条件は「オーバーワールドが昼で、雨でなく、空の見えるプレイヤーがいる」。合わなければ 1 分後に再判定するだけで、期限がない。雨・夜・洞窟にいた人は、ずっと見ないことがある |
| 影より先に鯨に会う | `TitanEvents` は、ワールドの総 tick が 2 日分（3 日目）を超えれば、空の影も村も見ていない人の近くにも岩鯨を出す。影・語り部・鯨追いとの順番を縛っていない |
| 村が見つからない | 語り部は「村の鐘（POI `meeting`）から 48 ブロック以内」でだけ立つ。鯨追いも村の近く。村が近くになければ、物語の入口がない（`/skyabyss npc village` は OP 専用） |
| 何もない | 序盤に「mod の物」は、空の影（2〜4 日おき）と見る者（初見から 2〜3 日後以降）だけ。最初の数十分には、mod 固有の物も場所も音もない |
| ストーリーを感じない | 書は空の影のあとに初めて渡る。最初の一行（「忘れないうちに書け」）が出るのは、早くても最初の影のあと |
| チャットが読めない | 通知を `sendSystemMessage` で流している箇所が 87 ファイルある。レベルアップは 1 回で 2〜3 行（`Growth.celebrate`）、クエスト開始と終了、伝承の記録、パーティ、報酬、装備が全部チャットに混ざる。HUD の層（`growth_hud`、`skill_hud`）はあるが、通知の層はない |

結論: **「偶然を待つ」作りが原因**。序盤は、偶然ではなく**必ず起きる拍子**に作り替える。

### 1.2 大きさの恐怖・静かな恐怖・通知の見せ方

| 題 | 何が面白いか（効くか） | このmodに合うか | 引き算で捨てるもの |

| 静かな心理的ホラー | 「何もないのに変だ」が一番残る。音が消える、動物が固まる、同じ物が少し違う。頻度を絞る。ジャンプスケアに頼らない | 01 のホラー原則と一致 | ジャンプスケア、BGM で脅かす、死なせる罠 |

## 2. 設計の柱

| 柱 | 内容 |
| --- | --- |
| 偶然に頼らない | 序盤の拍子は、**プレイヤーごとの状態**（何を見たか、何を読んだか）で必ず起こす。確率は、起きる**時刻の幅**にだけ使う |
| 順番は ①痕跡 → ②間接 → ③一部 → ④巨神 | 巨神の体が見えるのは、岩鯨の初登場（3.9）が最初。それより先には、足跡・骨・音・星の欠けだけ |
| 一度に一つ | 同時に二つの拍子を起こさない。拍子の間は静か（歩く・集める・建てる時間） |
| 常に目的が分かる | 画面の隅に、今のメインの目的を一行で出す（5.3）。迷ったらそこを見る |
| 見せる量を絞る | 足す物は、構造物 4・演出 5・画面の仕組み 3 まで（引き算） |
| 殺さない | 拍子は、ダメージ・拘束・ジャンプスケアを一切含まない。戦闘中・体力が低いときは後ろへずらす |

### 3.4 最初の人（語り部）に必ず会えるようにする（B2、B5）

- 語り部の家を、**野営地から 140〜220 ブロックの陸**に、ワールド開始時に必ず 1 つ建てる（4.2）。ここには村の「鐘」ブロック（バニラ）を置くので、既存の `NpcSpawner`（鐘から 48 ブロック以内で語り部を立たせる）がそのまま使える。鯨追いも既存の仕組みで、鐘から 18〜34 ブロックの所に焚き火と一緒に立つ。
- 本物の村に着いた場合も、語り部は立つ（既存のまま）。ただし**物語の入口は、鐘の宿り一本**にする。村が見つかる・見つからないに左右されない。
- 煙・鐘の音・積み石・目的の帯の方角で、迷わず着ける。それでも日 2 の朝までに着かなければ、目的の帯に**距離**を足して出す（5.3）。さらに日 3 の朝になっても着かなければ、野営地の帳面に一行「鐘の方へ」が増える（判断 5）。

### 3.5 最初の夜の足音（B6）

| 項目 | 内容 |
| --- | --- |
| 狙い | 「見えないが、ものすごく大きい何かがすぐそばを歩いている」 |
| 起きる時刻 | 夜（tick 13000〜）から 60〜180 秒のうち、無作為な一時点 |
| 条件 | 初めての夜／B4 を済ませたあと／プレイヤーが寝ていない・戦っていない・水中にいない |
| 動き | ① 5 秒かけて環境音と動物の声が消える ② 3 秒おきに 3 回、低い地響き（画面の揺れはわずか、足が地面に沈むような音。1 回ごとに大きく、遠のく向き） ③ 5 秒の無音 ④ 虫の音がゆっくり戻る。伝承の書に「夜の足音」が記される |

| 同じ夜 | 見る者（既存）は、日 3 以降に初めて出る。夜 1 と夜 2 には重ねない |

### 3.6 巨神の骨（B8）と足跡（B3）の意味

- 足跡：**どの巨神のものか、今は決めない**（判断 3）。余燼（地面の中を歩く）のものに読める案を勧める。章 1 の終わりに「あの足跡は、この巨神のものだったのか」と気づく回収ができる。
- あばら骨：岩鯨でも潮殻でもなく、**ずっと前に死んだ何か**の骨に読めるようにする（巨神は 4 体で、心臓が分けた守護者。骨の主は決めない。「巨神にも終わりがある」という含みだけ）。足もとの石板の一行：「歌はここで止まった」。

### 3.7 夜 2 の歌と星の欠け（B9）

| 項目 | 内容 |
| --- | --- |
| 狙い | 「上に、見えない大きなものがいる」 |
| 歌 | 低く長い音（鯨の歌）、40 秒。音量は小さい。方向はなく、空全体から。クエスト「雲の下の歌」の歌と同じ |
| 星の欠け | 夜空の星が、幅 40〜60 度の帯の形で、30 秒かけて西から東へ消えて、また戻る。月は残る。雲があれば「雲が一筋、暗くなる」に代える |
| 実装の方針 | 06 の「空の影」の影の描き方（夜に出した帯）と、雲の層の描き方をそのまま使う（新しい描画は作らない） |
| 条件 | 夜 2、B6（足音）を済ませたあと。寝ていて見逃したら、次の夜 |
| あと | 次の昼に、語り部とイサナの会話に「昨夜の歌」の分岐が出る |

### 3.9 岩鯨の初登場の条件（B10）

## 5. RPG 感：見せ方

### 5.1 チャットをやめる（通知の仕分け）

今の `ModText` の 5 種類（lore／hint／progress／deny／battle）に、見せ方を割り当てる。実装は、サーバーから 1 つの窓口（仮に `Notify`）で送り、クライアントが種類ごとに描く。

| 種類 | 例 | 新しい見せ方 | チャット |
| --- | --- | --- | --- |
| 大きな出来事 | レベルアップ、章の区切り、巨神を倒した、新しい技を覚えた | 画面上部中央の**帯**（1.8 秒。題字と一行の説明。フェードで入り、静かに消える）。専用の音 | 出さない（記録は「記録の窓」へ） |
| 小さな出来事 | 新しい頁が記された、クエストが進んだ、アイテムを受け取った | 画面右上の**札**（2.5 秒。一行、頁の絵）。重なるときは列にして、最大 3 枚 | 出さない |
| 手がかり | 「J でステータスを開ける」 | 画面下の細い**ヒント**（初めの数回だけ。同じ内容は二度出さない） | 出さない |
| 拒否・注意 | 必要レベル不足、乗れない | アクションバー（足もと）に一行 | 出さない |
| 戦果 | 経験値、報酬、装備の取得 | 戦いのあとの**まとめの札**（1 つにまとめて、数行を縦に） | 出さない（控え帳に履歴を残す） |
| 会話 | NPC のセリフ | 既存の会話画面 | 会話画面だけ |
| 管理者向け | コマンドの出力 | チャット（今のまま） | 出す |

- チャットに残すのは、**プレイヤー同士の会話・管理者のコマンド・バニラの死亡メッセージ**だけ。
- 見直しのために、全通知を**記録の窓**（B の控え帳か K の隣）に時刻つきで残す。見逃しても読み返せる（チャットを消すための条件）。
- 設定 `notifyMode`（クライアント）：`toast`（既定）／`chat`（今までどおり）／`both`。
- 置き換えは機械的にできる。87 か所の `sendSystemMessage` を、種類ごとに `Notify.to(player, kind, …)` に直す。管理者向けは触らない。

### 5.2 レベルアップを気持ちよく

| 要素 | 内容 | いまの状態 |
| --- | --- | --- |
| 帯 | 「Lv 3」の大きい数字と、増えた物の一行（「力の点 +3、技の点 +1」）。1.8 秒 | チャット 2〜3 行 |
| 音と光 | 既存の鈴の音と光の粒（`Growth.celebrate`）を残す。足もとに輪が広がる | 済 |
| 技 | **序盤の 1 時間で、必ず技を 1 つ覚える**（Lv 2 または 3 で技の点が出る）。K を開くと、覚えられる技が光る | 木は 04 にある。初回の誘導が要る |
| 数字 | ステータス画面（J）の開き方を、最初のレベルアップで一度だけ画面に出す（hint） | チャットで一行出していた |
| 経験値 | 敵を倒すたびのチャット表示をやめ、経験値バー（HUD）が伸びるだけにする | HUD はある |
| 進み具合 | 「次のレベルまで」を HUD のバーに出す | 済（確認） |

### 5.3 メインの目的を常に出す

| 項目 | 内容 |
| --- | --- |
| 場所 | 画面左上、HUD の邪魔にならない小さな帯（`SkillHud`、`GrowthHud` と同じ層の仕組みで描く） |
| 中身 | 目的 1 行（例：「煙を追う」「鐘の宿りの語り部と話す」「空を見ていなさい」「岩鯨を見る」）。小さく、距離（約 100 ブロック単位）と方角（八方位）を右に |
| 更新 | 変わるとき、帯が一度だけ光る |
| 消す | 設定（`objectiveStrip`）で消せる。U のクエストログに全文 |
| 出さない時 | 戦闘中、会話中、ホラー演出（足音・歌・影）の最中は薄くする（雰囲気を壊さない） |
| 材料 | `quest/` のメインの目的の文は既存。方角と距離は、目的ごとに位置を返す小さな口を足す（宿り・骨の丘・岩鯨） |

### 5.4 物語の断片の置き方

- 伝承の書の新しい頁は、**札で通知**し、頁そのものは書で読む（今のまま）。
- 序盤で記される頁（新規は太字）：書を手にした／**旅の野営地**／**巨大な足跡**／雲の上の影／**夜の足音**／**骨の丘**／**空の歌**／岩鯨（既存の `chapter1/stone_whale`）。
- 頁の本文は短く（2〜3 行）。説明しない。**問いで終える**（「誰が、ここで足を止めたのか」）。本文は担当 4（語り）が書き、数字・名前は 06・07 に合わせる。
- 装備の説明文にも一行の断片を足す案（後で。判断 8）。

## 6. 精神的なホラーの拍子（まとめ）

| 段階 | 拍子 | 見せるもの | 強さ | 回数 |
| --- | --- | --- | --- | --- |
| 1 痕跡 | B3 足跡、B8 骨 | 地形の痕跡。読めば分かる | 弱〜中 | 一度ずつ（見つけるのは任意） |
| 2 間接（音・揺れ） | B6 足音 | 音が消え、地面が揺れる | 強 | 夜 1 に一度 |
| 3 間接（空） | B4 影、B9 歌と星の欠け | 影・歌・星の欠け | 中、強 | 影は日 1、歌は夜 2 に一度 |
| 4 一部 | B10 岩鯨の初登場 | 遠くの体の一部 → 近づく | 中（驚きより畏れ） | 一度 |
| 5 そのあと | 既存（影・見る者・目） | 章に応じて | 既存 | 既存の頻度 |

守ること:

| 原則 | 内容 |
| --- | --- |
| ジャンプスケア禁止 | 急な大音量・急に出る顔は入れない。音は 5 秒かけて消す・戻す |
| 殺さない | 拍子はダメージを与えない。戦闘中・体力が半分以下・敵が 8 ブロック以内にいるときは、最大 2 分ずらす |
| 慣らさない | 足音と歌は**一度だけ**。以後は影・見る者・目の既存の頻度。「同じ演出は数日空ける」 |
| 弱められる | `horrorEventFrequency` が 0 で、拍子の恐怖（B6、B9）と影は起こさない。誘導（煙・鐘・目的）は残す。画面の揺れ・効果は既存の設定 |
| 自分だけ | 足音・歌・星の欠けは、拍子の対象の人にだけ。ほかの人には起こさない |
| 吐き気の注意 | 画面の揺れは小さく（ふだんの影より弱く） |

- 担当 1 と 3 は共有ファイルに触る。担当 1 は `sendSystemMessage` の置き換え、担当 3 は `SkyEvents`・`TitanEvents` に限る。重ならない。
- 音は新しく要る（足音、歌、鐘、帯の音）。既存の音の作り方（スクリプトで生成しているなら、それ）に従い、担当 3 が `sounds.json` と音の素材を持つ。担当 1 の帯の音は既存のレベルアップ音を流用する。
- ラフが要るのは、**構造物 4 つ**（担当 2）。ラフを 3 案ずつ作り、レビューページで選ぶ（美術の方針どおり）。選ぶ前に建設を作り込まない。
- 合計の目安は約 14 日分（並列なら、約 5 日で一通り動く）。

## 9. 判断が要る点（ユーザーへ）

| 番号 | 問い | 案 | 勧め |
| --- | --- | --- | --- |
| 17-1 | 序盤の新しい構造物を足してよいか（野営地・鐘の宿り・足跡・骨の 4 つ） | A: 4 つ（この書類）／B: 野営地と宿りの 2 つだけ（足跡と骨はあとで）／C: 足さない（演出だけ） | **A** |
| 17-2 | 伝承の書を野営地の帳面で渡し、空から落ちるのを「破れた頁」にしてよいか | A: そうする／B: 書は今のまま（影のあとに空から）、帳面は別の物 | **A** |
| 17-3 | 巨大な足跡は誰のものか | A: 余燼（章 1 の終わりで回収）／B: 決めない／C: 雲上の巡礼者 | **A** |
| 17-4 | 巨神の骨の主 | A: 決めない（巨神にも終わりがある、という含みだけ）／B: 余燼以外の巨神の旧い個体 | **A** |
| 17-5 | 日 3 になっても宿りに着かない人への手当て | A: 目的の帯に距離を足す＋帳面に一行／B: 語り部が野営地まで迎えに来る／C: 何もしない | **A** |
| 17-6 | 最初の空の影を、複数人のとき誰の窓に合わせるか | A: 最初に条件がそろった人。あとから入った人には日 2 の窓で別に起こす／B: 全員が見るまで待つ／C: 影は 1 本だけで、遅れて入った人は見ない（伝承の書は手動で記す） | **A** |
| 17-7 | 雨の日にも最初の影を出してよいか | A: 出す（暗さが増す）／B: 晴れを待つ | **A** |
| 17-8 | 装備の説明文に物語の一行を足してよいか（Elden Ring 風） | A: あとで足す／B: 今回に入れる／C: 足さない | **A** |
| 17-9 | チャットの通知を、既定で画面の演出にしてよいか（`notifyMode` の既定を `toast` に） | A: toast／B: both | **A** |
| 17-10 | 序盤のサブクエストを、イサナと会うまで出さないことにしてよいか | A: 出さない（目的を一本に）／B: 今のまま | **A** |
| 17-11 | 構造物を置くために、スポーン地点を動かしてよいか（海の真ん中の場合など） | A: 近い陸へ動かす／B: 動かさず、野営地を作れる所だけに置く | **A** |
| 17-12 | 画面の演出（帯・札・目的の帯）の見た目のラフは、先に 3 案作ってレビューページで選ぶか | A: 作る（美術の方針どおり）／B: そのまま作る | **A** |
