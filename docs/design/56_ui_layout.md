# 56 画面の組み方（黄金比）

mod の画面はすべて、この書類の決まりで組む。寸法と描き方の部品は `client/ui/Golden.java` にあり、画面はそこから寸法を取る。

## 1. 決まり

| 決まり | 寸法 | 中身 |
| --- | --- | --- |
| 板の形 | 横:縦 = 1.618 : 1 | 大 356×220、中 288×178、小 233×144 の三つだけ。大は記録・技・旅・クエスト・手帳・プロフィール・職選び・知らせ・パーティ・墓・店など（読む・選ぶ中身のある画面）。中は中身の少ない画面。小は確かめの窓。地図と伝承の書は今の形のまま |
| 縁 | 8 | 板の外から中身まで（骨の縁 5 + 余白 3） |
| 見出しの帯 | 21 | 板の上の端。題とつまみを置く。帯に小さな星、帯の下に金の細い線と真ん中の菱形 |
| 下の段 | 21 か 34 | 釦一列なら 21、二列や技の枠なら 34。下の段の左右の区切りは中身の列の境目にそろえる |
| 列 | 0.618 と 0.382 | 中身を主の列（木・読む中身・一覧の本体）と脇の列（説明・選ぶ一覧・まとめ）に分ける。あいだは 5。大きい板なら 207 と 128 |
| 余白 | 3・5・8・13・21・34・55 | これ以外の余白は使わない（フィボナッチの段） |
| 字 | 等倍だけ | 文は「…」で省かず、流しもしない（2026-11-09 の声「何書いてるかわからない」、11-10 の声「動いてるのは気持ち悪い」）: 入らなければ枠を広げる・折り返す・文を短くする。それでも入らない一行は `Marquee.draw` が縮めて収める（0.7 倍まで。足りなければ横だけ詰める。横を 0.8 倍より詰めた文は開発の起動のログ `[marquee]` に出るので、文を短くする手がかりにする）。撮影の検査 `tools/shots/overlap_audit.txt` が省かれた字を `ellipsis` として書き出す（`FitText` の「…」は最後の安全網）。強弱は大きさでなく色で: 金（見出し・選んだもの）、空色（節の見出し）、生成り（本文）、淡い青灰（補い）、青灰（手がかり・まだ使えない） |
| 行 | 13 | 文と一覧の一行（字の高さ 8 × φ） |
| 釦 | 高さ 13 | 幅は 21・34・55・89 から |
| 倍率 | 画素ちょうど | 板を窓に合わせて大きくするとき、字の 1 画素が画面の整数の画素になる倍率だけを使う（`UiFit.pixelExact`。GUI 3 なら 1 倍か 4/3 倍、GUI 4 なら 0.75・1・1.25 倍）。1280×720 の GUI 3 と 1920×1080 の GUI 4 では、大きい板がちょうど 1 倍で入る。動かせる盤（`PanZoomCanvas.setPixelUnit`）の拡大も 1/画素 の刻みにそろえる |

## 2. 絵柄（夜空の硝子）

板・欄・つまみ・釦・品の枠・HUD の枠は、どれも `client/ui/Golden` がコードで描く（絵のファイルにもリソースパックにも頼らない）。色は `Golden` の定数で、画面は直書きしない。

| 部品 | 描き方 |
| --- | --- |
| 板（`panel`） | 藍の半透明の地（上 `GLASS_TOP` から下 `GLASS_BOTTOM` へ。後ろの景色が少し透ける）、外の暗い線、2 内側に金の細い線（`LINE`）、四隅に金の菱形、見出しの帯に小さな星 |
| 欄（`recess`） | 一段暗い地に青灰の細い縁 |
| 選んだ行（`selected`） | 空色の薄い地と、左に金の 2 画素の印 |
| つまみ（`tab`） | 選んでいれば金の字・薄い金の地・下に金の線。ほかは淡い字だけ |
| 釦（`button`） | 高さ 13。主の釦は金の地に暗い字、ほかは金の細い縁に生成りの字。押せない釦は青灰 |
| 品の枠（`slot`） | 暗い地に青灰の縁。選んだ枠は金の縁 |
| HUD の枠（`hudFrame`） | 板より透ける藍の地に、外の暗い線と金の細い線 |
| 空の欄（`empty`） | 中身が無いときは、何をすると埋まるかの一行を欄の真ん中に淡い字で |
| ツールチップ | 藍の地に金の細い縁。品のレア度は縁でなく名前の色で見せる |

施設の画面の部品（`FacilityUi.panel` と `well`）も同じ板と欄を描く。伝承の書と地図は紙のまま。

持ち物・装飾・旅袋・封印の箱・箱（預かり所）・共鳴の炉も大きい板（4 章）。mod の画面に置いたバニラの釦（`Button.builder`）は、`mixin/GlassButtonMixin` が板と同じ釦の絵柄で描く（バニラの画面の釦はそのまま）。

## 3. 記録・スキル・旅のつまみ

記録・スキル・転生・旅の画面は同じ大きい板で、つまみ（幅 34・高さ 13）は見出しの帯の左に並ぶ（`RpgTabs.addHead`）。行き来しても板もつまみも動かない。転生のつまみは Lv 40 か転生のあと、旅は Lv 10 から出る。

## 4.1 板の決まりの外の画面

- 地図（旅の地図）と、窓いっぱいの場面（場面・天の鍵・物語の巻物・作り直しの待ち・心臓の遺物の選択）は、板ではなく窓いっぱいに描く。字の倍率は `TextStyle.scale()` で画素ちょうど。
- 輪の画面（技の輪・旅袋の輪）は輪の形のまま。

## 5. 会話の帯と HUD

- 会話の帯は画面の下の帯のまま。幅は大きい板と同じ 356（一行 28 字ほど）、縁は板と同じ絵柄、左に顔の欄（一段暗い欄。顔と名前・親しさ・印）、右に本文と選択肢（行 13）。
- 挑んでいる所の帯（`client/hud/ChallengeHud`、`trial/ChallengeBand`）: ダンジョン・巨神のルートの中にいるあいだ、右上の板の一番上（誓いの帯の上）に、金の名前・今の層や部屋・効いている変化の札（深く潜る・今日の様子・人数・中ボスの部屋・崩れた回数）を右寄せで出す。札は幅に入らなければ次の行へ折り返す。
- 下の一枚の帯（`client/hud/BandHud`）: 体力・マナ・持ち物・スキルを一つの枠にまとめる。枠はホットバーの左 3 から、スキルの枠の右 3 まで（スキルがホットバーのすぐ右に置けないときはホットバーの右 3 まで）。高さ 38。
  - 上の段（高さ 10）: 体力の帯（幅 81。数は右寄せ。吸収は上辺の金の線と「+数」、毒・衰弱・凍えは帯の色、四分の一以下で脈打つ）、Lv の札（幅 18。振っていない点があれば右上に金の点）、マナの帯（幅 81）。スキルの上には型の溜め。
  - 経験値は段のあいだの 1 画素の金の線（Lv 50 では今のジョブの熟練の進み）。
  - 下の段（高さ 20）: 持ち物の 9 枠（選んだ枠は金の縁）、区切りの線、スキルの枠と護符の枠。
  - 守りは枠の左上につく札（盾と数。守りが 0 なら出ない）、息は枠の右上につく札（水の中だけ）。逆手は持っているときだけ枠の外に一枠。
  - バニラのホットバーの層は止めて帯が描く。設定 `styledVitals` を切った人・クリエイティブ・見物はバニラのまま（そのときは左上に Lv と経験値の帯）。場面のあいだは出さない。
- 左上は 得た経験値の列・章・目的・追跡中のクエスト。Lv と経験値の帯は下の帯へ移した。
- 得た品は左の列に品の絵と数だけ（`notice/GainFeed`。同じ tick に渡した品を一つの札にまとめる）。「〜を手に入れた」の文は知らせの記録（N）にだけ残す。
- 残りの敵の数は右上の「挑んでいる所の帯」にだけ出す（ダンジョンの部屋・大事件の前触れ・深淵の群れ）。画面の下の一行には出さない。
- 縮めた字は使わない（旅袋の札のキー名は等倍、新しい品の札は字のない小さな菱形の印）。見出しの大きな字（場所の名前 1.5 倍・題字 2.2 倍）は `TextStyle.scale()` が画素ちょうどの倍率に丸める（GUI 3 なら 5/3 倍・7/3 倍）。仲間の頭の上の札は、画素ちょうどの小さな字のまま。
