# 56 画面の組み方（黄金比）

mod の画面はすべて、この書類の決まりで組む。寸法と描き方の部品は `client/ui/Golden.java` にあり、画面はそこから寸法を取る。

## 1. 決まり

| 決まり | 寸法 | 中身 |
| --- | --- | --- |
| 板の形 | 横:縦 = 1.618 : 1 | 大 356×220、中 288×178、小 233×144 の三つだけ。大は記録・技・旅・クエスト・手帳・プロフィール・職選び・店など。中は一覧だけの画面。小は確かめの窓。地図と伝承の書は今の形のまま |
| 縁 | 8 | 板の外から中身まで（骨の縁 5 + 余白 3） |
| 見出しの帯 | 21 | 板の上の端。題とつまみを置く。帯の下に青緑の線と小さな玉 |
| 下の段 | 21 か 34 | 釦一列なら 21、二列や技の枠なら 34。下の段の左右の区切りは中身の列の境目にそろえる |
| 列 | 0.618 と 0.382 | 中身を主の列（木・読む中身・一覧の本体）と脇の列（説明・選ぶ一覧・まとめ）に分ける。あいだは 5。大きい板なら 207 と 128 |
| 余白 | 3・5・8・13・21・34・55 | これ以外の余白は使わない（フィボナッチの段） |
| 字 | 等倍だけ | 縮めた字は使わない。入らない字は「…」で切る（`FitText`）。強弱は大きさでなく色で: 金（見出し・選んだもの）、水色（題・節の見出し）、本文、淡い灰（補い）、暗い灰（手がかり・まだ使えない） |
| 行 | 13 | 文と一覧の一行（字の高さ 8 × φ） |
| 釦 | 高さ 13 | 幅は 21・34・55・89 から |
| 倍率 | 画素ちょうど | 板を窓に合わせて大きくするとき、字の 1 画素が画面の整数の画素になる倍率だけを使う（`UiFit.pixelExact`。GUI 3 なら 1 倍か 4/3 倍、GUI 4 なら 0.75・1・1.25 倍）。1280×720 の GUI 3 と 1920×1080 の GUI 4 では、大きい板がちょうど 1 倍で入る。動かせる盤（`PanZoomCanvas.setPixelUnit`）の拡大も 1/画素 の刻みにそろえる |

## 2. 絵柄

板は一つの絵柄にそろえる: 外の暗い線、骨の縁（上と左は明るく、右と下は暗い 3 画素）、内の暗い線、暗い石の地（64×64 を並べる。`tools/gen/ui/gen_golden_assets.py`）、21 ごとの刻み、四隅の青緑の玉。欄は一段暗い石に、左上が暗く右下が明るい縁。縁・玉・線はコードで 1 画素ずつ描くので、どの大きさの板も同じ太さになる。伝承の書と地図は紙のまま。

## 3. 記録・技・旅のつまみ

記録・技・転生・旅の画面は同じ大きい板で、つまみ（幅 34・高さ 13）は見出しの帯の左に並ぶ（`RpgTabs.addHead`）。行き来しても板もつまみも動かない。転生のつまみは Lv 40 か転生のあと、旅は Lv 10 から出る。
