# 56 画面の組み方（黄金比）

mod の画面はすべて、この書類の決まりで組む。寸法と描き方の部品は `client/ui/Golden.java` にあり、画面はそこから寸法を取る。

## 1. 決まり

| 決まり | 寸法 | 中身 |
| --- | --- | --- |
| 板の形 | 横:縦 = 1.618 : 1 | 大 356×220、中 288×178、小 233×144 の三つだけ。大は記録・技・旅・クエスト・手帳・プロフィール・職選び・知らせ・パーティ・墓・店など（読む・選ぶ中身のある画面）。中は中身の少ない画面。小は確かめの窓。地図と伝承の書は今の形のまま |
| 縁 | 8 | 板の外から中身まで（骨の縁 5 + 余白 3） |
| 見出しの帯 | 21 | 板の上の端。題とつまみを置く。帯に小さな星、帯の下に金の細い線と真ん中の菱形 |
| 下の段 | 21 か 34 | 釦一列なら 21、二列や技の枠なら 34。下の段の左右の区切りは中身の列の境目にそろえる |
| 列 | 0.618 と 0.382 | 中身を主の列（木・読む中身・一覧の本体）と脇の列（説明・選ぶ一覧・まとめ）に分ける。あいだは 5。大きい板なら 207 と 128 |
| 余白 | 3・5・8・13・21・34・55 | これ以外の余白は使わない（フィボナッチの段） |
| 字 | 等倍だけ | 文は「…」で省かず、流しもしない（2026-11-09 の声「何書いてるかわからない」、11-10 の声「動いてるのは気持ち悪い」）: 入らなければ枠を広げる・折り返す・文を短くする。それでも入らない一行は `Marquee.draw` が縮めて収める（0.7 倍まで。足りなければ横だけ詰める。横を 0.8 倍より詰めた文は開発の起動のログ `[marquee]` に出るので、文を短くする手がかりにする）。撮影の検査 `tools/shots/overlap_audit.txt` が省かれた字を `ellipsis` として書き出す（`FitText` の「…」は最後の安全網）。強弱は大きさでなく色で: 金（見出し・選んだもの）、空色（節の見出し）、生成り（本文）、淡い青灰（補い）、青灰（手がかり・まだ使えない） |
| 行 | 13 | 文と一覧の一行（字の高さ 8 × φ） |
| 釦 | 高さ 13 | 幅は 21・34・55・89 から |
| 倍率 | 画素ちょうど | 板を窓に合わせて大きくするとき、字の 1 画素が画面の整数の画素になる倍率だけを使う（`UiFit.pixelExact`。GUI 3 なら 1 倍か 4/3 倍、GUI 4 なら 0.75・1・1.25 倍）。1280×720 の GUI 3 と 1920×1080 の GUI 4 では、大きい板がちょうど 1 倍で入る。動かせる盤（`PanZoomCanvas.setPixelUnit`）の拡大も 1/画素 の刻みにそろえる |

## 2. 部品の入り口（`Golden`）

画面は `client/ui/Golden` の関数（panel・recess・tab・button・slot・hudFrame）を通して部品を描き、色は直書きしない。中で 2.1 の絵柄（`Plate`）へ渡る。下の表は部品の役目（色と形は 2.1 が正）。

| 部品（`Golden` の関数） | 役目 |
| --- | --- |
| 板（`panel`） | 画面の地。論理の 0,0 に置いた大中小の板は、開くときに濃くなる |
| 欄（`recess`） | 一覧や読む中身を入れる沈んだ面 |
| 選んだ行（`selected`） | 選んでいる行の地と、左の印 |
| つまみ（`tab`）・釦（`button`） | 高さ 13。主の釦は一画面に一つ |
| 品の枠（`slot`） | 品を置く升 |
| HUD の枠（`hudFrame`） | HUD の札の地 |
| 空の欄（`empty`） | 中身が無いときは、何をすると埋まるかの一行を欄の真ん中に淡い字で |
| ツールチップ | 品のレア度は縁でなく名前の色で見せる |

施設の画面の部品（`FacilityUi.panel` と `well`）も同じ板と欄を描く。

持ち物・旅袋・封印の箱・箱（預かり所）・共鳴の炉は、真ん中がバニラと同じ形の板で、MOD の要素は左右の横の板（4 章の「持ち物の組み方」）。mod の画面に置いたバニラの釦（`Button.builder`）は、`mixin/GlassButtonMixin` が板と同じ釦の絵柄で描く（バニラの画面の釦はそのまま）。

## 2.1 鐘の銅（画素の板）

mod の画面の絵柄は「鐘の銅」（2026-11-24 にユーザーが 3 案から選んだ。絵 `docs/review/plate_ui/`）。深い石の板に銅の縁、下の角に緑青。色は世界の色調（01 の 8 章）から取る。描くのは `client/ui/Plate`（絵柄はこの一つだけ。切り絵の経路・見比べの案 B・C・色の写しは 2026-11-25 に消した）。

- 画素の格子: 枠・升・絵・字を、字と同じ画素の刻みで描く。傾けない・丸めない。絵は `Paper.draw` が名前ごとに一度塗って使い回す。画面の側の色は、はじめから板の色で書く（`Paper` の色の名前は切り絵のときの名前のまま、値は板の色。生成り `CREAM`・`CREAM_HI` だけは生成りのまま残る：本の頁・地図の絵・経験の帯）。
- 色（`Plate.Pal`）: 板の石 `#181C28`、欄 `#10131C`、銅の縁 `#F2C47C`・`#C48A44`・`#83502A`・`#4C2C1A`、緑青 `#5FB8A8`・`#2F8076`。字は地の文 = 骨色 `#ECE6D6`、添え = `#A9ABB8`、まだ使えない = `#6C7084`、見出し = 鐘の金 `#F2C47C`、値や読みどころ = 碑文の青緑 `#8FE0D0`。足りない・断るは赤 `#F0607A`。品の稀さ・土地の色などの意味の色は替えない。
- 職の色（`Plate.job`）: 戦士 = 鐘の金、鍛冶師 = 熾火、魔法使い = 月、弓使い = 苔、暗殺者 = 淵の紅、呪術師 = 碑文の青緑。職を選ぶ画面の名の札・役目の行・目盛り・選んだ升・見せ絵に使う。ほかの画面の差し色は鐘の金（`Plate.GOLD`）。

- 後ろの景色: 板は窓の端まで敷かず、真ん中に一枚。後ろの世界はバニラのぼかしと薄い暗がりで見せる（`Plate.blur`・`Plate.backdrop`）。

## 2.2 型ごとの並び

並びは型ごとに決めてある（3 案からユーザーが選んだ。下の項）。下の項は切り絵のときの言葉で書いてあるので、次のように読み替える。傾き・手で切った辺・桃色の山・漂う菱は無い。

| 下の項の言葉 | 今の絵柄 |
| --- | --- |
| 黒い紙・窓の端まで敷く | 舞台の大きさ（論理の 408×228）の板を一枚 |
| 生成りの帳面・帯・台紙 | 沈んだ欄 |
| 生成りの札（傾けた札・扇の札） | まっすぐな升 |
| 桃色の紙・桃色の札・付箋 | 灯った升（金の線） |
| 桃色の字・桃色の菱 | 鐘の金の字・金の菱 |
| 墨の字 | 骨色の字 |
| 判が押される・札が回りながら配られる | 傾けずに、ずれて入る |


切り絵のときに組み直した画面と、その並び。組み直したのは職を選ぶ画面・スキルの木と、3 周目で型ごとに組み直した画面（「部品だけ」だった画面は全部）。小さな窓は部品と色だけで、組み方は四角い板のまま（進み具合は `docs/review/paper_ui/progress.md`、数える道具 `tools/dev/paper_audit.py`）。HUD・知らせ・演出（作り直しの読み込み・空の鍵の場・シネマの暗がり・報いの祭壇）も切り絵で、夜空の色・ぼかしの帯は残っていない（`paper_audit.py` が 0）。画面の大中小の板（論理の 0,0 に置いた Layout）は黒い紙と桃色の山を窓の端まで敷き、それ以外の板は手で切った黒い紙を一枚。

- 中身は論理の 408×228 に置いて画素ちょうどで大きくする（1280×720・GUI 3 でも 1 倍で入る）。黒い紙と下の桃色の山は窓の端まで。
- 型ごとの組み方（3 周目。型ごとに 3 案からユーザーが選んだ。ラフ `docs/review/paper_ui/round3/`）。舞台はどれも論理の 408×228:
  - 店「帳面と台」（`client/ui/ShopStage`）: 左に少し傾けた生成りの帳面、上の辺につまみの栞。品は帳面に墨で書いた行（名前 …… 値段、桃色の点線）、乗せた行は桃色の紙。右の黒い紙に乗せた品を 4 倍で桃色の台に立て、名前・値段・説明。店の名前は右上、手持ちは山の上の黒い札。
  - 帳「黒に書いて、目録は帯に」（`client/ui/LedgerStage`）: 読む中身は左の黒い紙にじかに（題は桃色の菱と濃い桃色の線）。一覧とつまみは右の縦長の生成りの帯（目録）、選んだ行は帯から左へはみ出す桃色の付箋。下の段は左下の山の上。
  - 集まり「扇に並ぶ顔札」（`client/ui/PartyStage`）: 左上に題と物語、人は扇の札（顔・名前・Lv）。長の札は桃色で上に菱。右に生成りの帯（招待できる人など）、届いた招待は右上から差し込む桃色の紙。パーティー募集（`PartyFinderScreen`）は 2 倍の題と募集の数の判子。札は開くと・めくると一枚ずつ配られ、乗せると浮いて音。「加わる」は札が止まってから出る。募集を出すと帯に「募集中」の判が押される。
  - 選ぶ「三枚を扇に」（`client/ui/PickStage`、祠は `TrialBoardScreen`）: 選ぶものは背の高い札を扇に、乗せた札は桃色で持ち上がる。稀さは札の右上の菱。祠のつまみは右の端に縦の短冊。祠の板は、小さな題（巨神の祠・周目）と 2 倍の巨神の名、称号は名の右に判子。三枚の札は開くと下から回りながら配られ、修飾の下が空けば枠の絵を大きく置く。つまみは右から順に入り、頁を替えると中身が滑りこむ。「仲間と渡る」は二度押し（一度目で「もう一度」と減る帯）。誓いを立てる・降ろすと、その行の菱に判が押される。報いの棚の持っていない品は沈んだ升。歌片は 2 倍の数。心得の頁は、見出しを桃色の菱と一行で、その下に文を字下げして置く。
  - 帳・店・集まり・会話の共通の動き（v2）: 題は入れば 2 倍で、開くと左から入る（`LedgerStage.kTitle/pageTitle`・`ShopStage.title`・`PartyStage.title`。続く字は `PartyStage.titleWidth` で並べる）。帳の選んだ行の付箋と、店の乗せた行の紙は、前の行から滑って移る（乗せた行が替わると小さな音）。店の台の品は替わると跳ねて立ち、ゆっくり浮き沈みする。手持ちが変わると「-n」「+n」が浮いて消える。会話は開くと帯と顔の札がせり上がり、名前の短冊が押される。
  - 選ぶの舞台の共通（`PickStage`）: 題は入れば 2 倍で、左から入る（添えの一行はその下）。札を描くときは `deal(g, i, n)` 〜 `undeal(g)` で囲むと一枚ずつ配られ、`hover(i)` で乗せたときに音が鳴る（加護・深い層の選び。開いた画面は `PickStage` が覚える）。
  - 会話「立ち札」（`DialogueScreen`）: 窓の幅いっぱいの黒い帯、左に傾けた顔の札（帯の上へはみ出す）と名前の桃色の短冊、真ん中に本文、右に選択肢の短冊を縦に。
  - 帳の K の頁（Growth・Journey・Soul）は、記録・スキル・旅のつまみをスキルの木と同じ左上に置き（`LedgerStage.K_HEAD`）、題はその右（`LedgerStage.kTitle`）、中身は y 32 から。Profile・Rebirth・狩人の手帳はつまみなしで、題は左上。
  - 一行が長い一覧（取引所の市と申請・言伝ての板）は、帳面には短く書き（渡す → もらえる、題 …… 状態）、乗せた行のくわしいことと釦は右の黒い紙に出す。
  - 作業台（共鳴の炉・箱の画面。3 案からユーザーが A を選んだ）も店の「帳面と台」: 箱の画面は大きくできないので、舞台を GUI の等倍で真ん中に置き、枠の場所は画面の側で動かす（`Slot.x/y`）。窓が舞台の 1.5 倍より大きい（GUI 2 など）ときは、窓の端まで敷かずに舞台の大きさの一枚の紙。炉は帳面に つまみ・中身・細工の列、右に題・素材・桃色の台に立てた装備の枠・装備の説明・持ち物。箱は帳面に題・数・箱の枠（預かり所の頁は帳面の上のつまみ）、右に袋。
  - くじの幕（巡りの報い・封切り師のルーレットと当たりとまとめ）は選ぶ類の舞台。品は生成りの札で、影を階級の色にする（意味の色を黒の側に）。光のにじみの代わりに、箱の後ろで階級の色の紙の菱が育つ。
- スキルの木: 上に記録・スキル・旅のつまみ（この画面だけ切り絵の札。`RpgTabs.addHead(…, true)`）、その右に職と木の名前、右端にツリー・名残のつまみ。左の黒い紙の上に盤。下の桃色の山の上に SP（小さな字と 2 倍の数）・マナ・技の枠（傾けた生成りの札。置いた枠は桃色）・秘伝・型の保存・振り直し・試着。部品は `SkillStage`。
  - 右は、節を選んでいなければ黒の上に木の表紙（職の小さな題・2 倍の木の名・効果の元の判子・説明 5 行まで・発動スキルの菱・型の力の行（乗せると全文）・「？ 遊び方」の札（乗せると遊び方と盤の動かし方））。節を選ぶと少し傾けた生成りの札が右から入り、上に 2 倍の名・種類の判子・段の菱・熟練か要る SP の札・マナと待ちの黒い札、その下に送れる本文、下の端に「取る」。札の高さは中身に合わせて縮む。
  - 試着の間は盤を桃色の点線で囲む（線は少しずつ流れる）。
  - 節: 技は切り抜きの円、要は大きな菱、小さな節は菱。縁は取った = 桃色・取れる = 生成り・まだ = 暗い灰。選んだ節は持ち上げて（濃い桃色の影を大きくずらす）上の端に桃色の菱を留める。線は取った道 = 桃色の糸、手前を取った道 = 生成りの点線、まだ = 暗い点線、マウスの下の節へつながる線 = 明るい桃色の太い糸。
  - 説明の字は行に明るい色が焼いてあるので、生成りに描く所だけ墨・濃い桃色へ写す（`SkillScreen.ink`）。囲み（ツールチップ）は暗い地なので写さない。
  - 名残のページ: 左上に 2 倍の題「名残の祭壇」、その下に五つの枠を角に置いた生成りの五角の台紙（真ん中に桃色の菱と職の木の絵）、台紙の下に「付けている」と菱（開いた枠の数）・レジェンドまでの回数。右の黒い紙に棚。見出しの下の線は集めた割合の帯（桃色）。まだ見つけていない品は「？」ではなく沈んだ黒い升に小さな菱。開くと祭壇が跳ね、枠が順に、棚の段が順に入る。付けると枠に判が押される。品は少し傾けた紙の札で、稀さは右上の菱（レア = 灰・エピック = 桃色・レジェンド = 大きな明るい桃色）、付けた品は持ち上げて桃色の菱を留める。試練の板の札も同じ紙の札（`SkillScreenAccess.aspectTile`）。

## 4.1 板の決まりの外の画面

- 地図（旅の地図）と、窓いっぱいの場面（場面・天の鍵・物語の巻物・作り直しの待ち）は、板ではなく窓いっぱいに描く。字の倍率は `TextStyle.scale()` で画素ちょうど。
- 旅の地図（`TravelMapScreen`）の地図のまわりの部品は鐘の銅（前後の絵 `docs/review/plate_ui/map_frame_clean.png`、台本 `tools/shots/map_frame.txt`）。板と一覧の欄は窓の大きさで変わるので `Plate.panelFor`・`wellFor`（名前ごとに一枚だけ持ち、大きさが変わったら塗り直す）。石板の見た目は窓の端から 10 内側に板、羊皮紙は同じ板の縁の内側（5）に羊皮紙を敷く、墨は窓の四隅に銅の菱（`Plate.gem`）。縮尺の +/− は小さな升（押せないときは平ら、印は鐘の金）、目盛りの線とつまみは銅。「地図に出す」の箱は HUD の札の地（`Plate.hudCard`）に HUD の字の色、入り切りの四角は銅。空の海図の行き先は沈んだ欄（`Plate.well`）に升（選んだ行は灯った升）、送りの矢印は鐘の金、出発は主の釦・降りるは石の釦。題は石板と墨では鐘の金、羊皮紙は墨。地図の絵そのもの（大陸・道・印・方位盤・自分の輪・光る印）は替えない。
- 輪の画面（技の輪・旅袋の輪）は輪の形のまま。

## 5. 会話の帯と HUD

- 会話の帯は画面の下の帯のまま。幅は大きい板と同じ 356（一行 28 字ほど）、縁は板と同じ絵柄、左に顔の欄（一段暗い欄。顔と名前・親しさ・印）、右に本文と選択肢（行 13）。
- HUD の部品（`client/ui/Plate` の「HUD の部品」。前後の絵 `docs/review/plate_ui/hud_bronze.png`）: HUD の札・帯・印は、どれも同じ部品で描く。色は `Plate.Pal` からじかに取り、切り絵の色の写し（`Plate.paint`）には頼らない。置き場と寸法は `hud/HudLayout` と下の各項のまま。
  - 札の地（`Plate.hudCard`。筋なしは `Plate.hud`）: 少し透ける石の板（濃さ `0xDC`）。上の端に銅の線（左の 3 画素は明るい）、その下に一段明るい石の一行、下の端に暗い縁、右と下に 1 画素の影、角は 1 画素落とす。左の端の 2 画素の筋は意味の色（目的・主の筋のクエスト・まだの手引き = 鐘の金、ほかのクエスト・灯りの帯・済んだ手引き = 骨色、知らせ = 種類の色、巨神の背の札 = 巨神の色、章 = 暗い金）。真ん中寄せ・右寄せの札（語り・知らせの一行・技の名・挑みの帯・誓いの帯）には筋を付けない。
  - 帯（`Plate.bar`）: 溝の中に塗り。塗りは上の一行が光、下の一行が暗い縁、先の 1 画素が明るい。減った分は明るい影で残り、遅れて縮む。高さ 7 以上は銅の縁つき（体力・マナ・中ボス）、細い帯（経験値・吸収・息・型の溜め・淵の声・技の残り）は縁なしの溝（上と左が暗く、下が明るい）。目盛りは `Plate.barTicks`。
  - 小さな部品: 菱の印（`Plate.pip`。5×5）、出入りする升（`Plate.hudSlot`。縁は稀さの色）、札の中の区切り（`Plate.hudRule`）。字の色は `Plate.hudHead`（見出し = 鐘の金）・`hudText`（地の文 = 骨色）・`hudSoft`（添え = 灰）・`hudValue`（距離などの値 = 碑文の青緑）。
  - 意味の色は替えない: 体力 = 赤 `#D8505C`、マナ = 青 `#4E8AE0`、毒 = 黄緑・衰弱 = 灰・凍え = 水色、経験値 = 緑、品の稀さ、巨神の色、中ボスごとの色、仲間の体力の緑・黄・赤。
  - 動くのは意味のあるときだけ: 打たれた（縁と印が白く光り、減った分が遅れて縮む）、残りが少ない（塗りと縁が赤く脈打つ）、目的が替わった・クエストが進んだ（札の上の銅の線が白く光って消える）、知らせの一行が来た（札が左右へ開き、上の線を白い光が一度渡る）、技の待ちが明けた（升の縁を銅の光が一周する）。
- 挑んでいる所の帯（`client/hud/ChallengeHud`、`trial/ChallengeBand`）: ダンジョン・巨神のルートの中にいるあいだ、右上の板の一番上（誓いの帯の上）に、金の名前・今の層や部屋・効いている変化の札（深く潜る・今日の様子・人数・中ボスの部屋・崩れた回数）を右寄せで出す。札は幅に入らなければ次の行へ折り返す。 行の後ろに札の地を敷く（字の幅に合わせて右寄せ）。誓いの帯（`client/vow/VowHud`）も同じ。
- 画面の下（`client/hud/BandHud`・`VitalsHud`。置き場は 2026-11-11 の案 B）: 手もとの 9 枠・選んだ枠・逆手・攻撃の目盛りはバニラのホットバーの絵のまま。
  - 体力の帯はハートの場所、マナの帯は満腹度の場所（どちらも幅 81・高さ 9）。左の端に印の升（幅 11。体力 = 心臓、マナ = しずく）、その右に銅の縁の溝と塗り。数は右寄せで黒の縁取り。二つの帯のあいだ（幅 20）は Lv の札で、三つが一続きの帯に見える。減った分は明るい影で残り、0.3 秒待ってから縮む。回復は少しずつ伸びる。打たれた・マナが足りなかった瞬間は縁と印が白く光る。毒・衰弱・凍えは塗りと印がその色、四分の一以下は塗りと縁が赤く脈打つ。吸収は体力の帯のすぐ上の細い金の帯（数は出さない）。
  - 経験値はバニラの経験値のバーの場所（幅 182・高さ 5）に、縁なしの溝と緑の塗り、十等分の目盛り（Lv 50 では今のジョブの熟練の進み）。得た瞬間は塗りが白く光る。Lv の数は Lv の札の中に、バニラと同じ緑の縁取りの字。振っていない点があれば札の上に金の菱。
  - スキルの枠と護符の枠は手もとの右の札の地の上。技や護符の入った枠は升（`Plate.tile`）、空の枠は欄。待ちは深い石の色が上から覆い、下の端に明るい銅の線、残りの秒は縁取りの字。キーは枠の右下に明るい縁取りの字。型の溜めはスキルの枠の上の細い溝（点で数えるものは升、量は帯）。
  - 守りの札は体力の帯の左上（守りが 0 なら出ない。盾の印と数）、息の札はマナの帯の右上（水の中だけ。細い帯と秒）。どちらも札の地。
  - 手早く使う札（`client/pouch/QuickCard`）は手もとの左の札の地。道具の名前を出している間の長い行は、手もとの枠と体力の帯にかからないよう手前で止める。
