# 天と淵のあいだ 岩鯨の下の水路（光海）

- 文書番号: 23
- 範囲: 岩鯨の背の下の水路（光海。灯りの台・出口の戸・息継ぎのくぼみ・水路の顎）。
- 関連: [32 巨神の順路](32_titan_raid_route.md)（任意の翼の扱い。7 章）、[02 岩鯨の背](02_stone_whale.md)
- 状態: **現行の背にはない。** 水路は順路の外の任意の翼で、今の背には置かない（32 の 7 章）。鼓動の間は心臓への通り道だけで、中には何も置かない。

---

## 1. 現行の扱い

- 鼓動の間の床から水路へ下りる入口は無い。背の順路は到着の台 → 入口 → 三つの試練 → 中ボス → 心臓だけ（32 の 0 章・2 章）。
- 水路の仕様（迷路・灯りの台と灯・出口の戸・苗床・魚の湧き・戻る抜け道）は、現行の背に無いので書かない。
- 水路の顎（魚）と共鳴石の合図は、この水路の仕様として持たない。02 の 4.3 の水路の節は、このファイルでなく 32 に従って読む。
