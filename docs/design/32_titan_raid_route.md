## 0. 要約

- **順路**: 背に入ったグループは、**歩 → 智 → 闘 →（中ボス）→ 心臓** の順に一つずつ進む。次へは歩かず、越えた 4 秒後に次の試練の入口へ運ばれる。
- **背の中に、順路以外のものは置かない**。鼓動の間の板・碑・誓い・炉・任意の翼・今週の試練・骨の書庫・胸びれの道・尾の展望は消した。背は「到着の台 → 入口 → 三つの試練（とそのセルの前の広間）→ 中ボス → 心臓」だけ。鼓動の間の部屋は心臓への通り道として残る（中には何も置かない）。
- **物語（初回）**: 地上の支度 → 乗り込み口（鎖・潮門・昇り風・口）→ 到着の台 → **入口**（岩鯨なら今の上へ向かう階段）に入ると、その場で順路が始まる。パーティは**全員が入口に入る**。三つは原型（初回の延長つき）。
- **周回（二回目から）**: 地上の**巨神の祠**から**だけ**挑む（乗り込み口は閉じる）。祠は場所が固定で、いつでも行ける（時間・天気・巨神の状態で閉じない）。入るには**専用の品が一つ**要る（3.2）。
- **巨神は、その章を遊んでいる人（とそのパーティ）にしか見えない**（重さ対策。3.3）。章を終えた人には空を泳ぐ姿も鎖も見えず、祠だけが残る。
- **待ちを作らない**: 一つの順路は**区画**（番号 1〜32。`TrialSlot`）で動く。背の次元の遠くの区画に、引いた三つのうち新作のセルを写して建て、グループはその写しだけを使う（5 章）。原型は体の中のまま、グループごとの上書きで共有する。待つのは、体の中の原型を初回の順路が二組同時に使うときだけ（決定 207）。
- **引き方は 29 のまま**: 周回 1 は原型の三つ、周回 2 からはプールから各枠一つ。修飾・稀さ・深淵・図鑑・報いも変えない。読む場所は板ではなく、段の札・目的の帯・控え帳。
- **あきらめ**: 全員の同意で順路が終わり、**全員が背の外へ出される**（段 0 に戻るだけではない）。一人の操作では戻らない。
- **守ること**: 時間・天気・背の状態で閉じない。どの順路も一人で解ける。装備の確率と天井は変えない。心臓の戦いの内容は変えない。

## 1. なぜ順路にするか

| 今（29 の 2.4） | 困ること | 順路 |
| --- | --- | --- |
| 鼓動の間から三つの広間へ歩き、引いた三つのセルの入口を自分で探して入る | 試練の階が広く、「どこへ行けばいいか」と「移動」に時間がかかる | 入口に入れば次が来る。行き先を探さない |
| 三つを好きな順で遊べる。パーティが分かれて別々の試練に入れる | 試練ごとの山場が作れない。分かれて進むとパーティで遊ぶ意味が薄い | 歩で体を温め、智で頭を使い、闘で武器を振って心臓へ |
| 十二のセルを常設し、引いていない戸は閉じて見える。世界が変わるセルは 2 レーンで、三つ目のグループは待つ | 閉じた戸の列は見かけが死んでいる。待ちが出る | 区画ごとに引いた三つだけ建てる。待ちなし |
| 鼓動の間に板・誓い・炉・今週の試練、背に任意の翼 | 背の中に寄り道が多く、順路の緊張が切れる。建設も長い | 背は順路だけ。寄り道と設備は地上（祠のまわり）へ |

## 2. 順路の決まり

### 2.1 段

| 段 | 場所 | 入り方 | 越え方 | 越えたあと |
| --- | --- | --- | --- | --- |
| 0 入口 | 到着の台と入口（初回）／祠（周回） | 初回: 乗り込み口から到着の台へ。周回: 祠で品を使う | グループ全員が入口に入る（2.2） | 段 1 へ |
| 1 歩 | 引いた歩の試練（周回 1 は原型。岩鯨 W01、潮殻 T01、雷翼 S01、余燼 E01） | 入口の休み場へ運ばれる | ゴールの光る印に着く（`TrialGoal`） | 4 秒待って段 2 へ |
| 2 智 | 引いた智の試練（原型 W05・T05・S05） | 同上 | 同上 | 4 秒待って段 3 へ |
| 3 闘 | 引いた闘の試練（原型 W09・T09・E09。雷翼は初回だけ S06 眼の間） | 同上 | 同上 | 4 秒待って段 3.5 へ |
| 3.5 中ボス | 番兵長・潮招き・雷獣・鍛え手の前室（`TrialMidBoss`） | 前室へ運ばれる（手前の仕掛けはそのグループには済んだことになる） | 中ボスを倒す | 段 4 へ。**中ボスのいる原型（岩鯨 W09・潮殻 T09・雷翼 S05・余燼 E05）を引いていない周に挟む**（決定 201） |
| 4 心臓 | 心臓の前室（休み場 `heart`）→ 大門 → 心臓の間 | 前室へ運ばれる。備えの三灯・碑の囁きは今のまま | 心臓を止める | 眠りと運び出し（02 の 2.11）。周回数 +1 |

- 枠の順は **歩 → 智 → 闘** で固定（決定 200）。三つの類はいつも違う（29 の 2.2 の 3）。
- 中ボスは原型の試練の中にいる（岩鯨・潮殻は闘の原型の終わり、雷翼・余燼は智の原型の中）。その原型を引いた周（周回 1 を含む）は、試練の中で中ボスと戦うので段 3.5 は無い。
- 一周の長さの目安: 初回は今と同じ（21 の 1.1）。周回は 25〜35 分。セルを太らせたら（4 章）40 分まで。

### 2.2 入口（全員で入る）

- **初回の入口**は、到着の台から体の中へ入る口の箱（`TrialRoute.entryBox`。岩鯨: 台の北寄りから東へ上る階段の最初の 5 段。潮殻: 潮門の内側の段。雷翼: 尾の広場の北の端。余燼: 口の奥の喉の降り口。座標は仮で、実機で確かめる）。入口の箱に**グループ全員**が入ると、5 秒の予告のあと順路が始まる（帯に「仲間を待っている 2/4」「試練が始まる…… 5」）。そのグループが周回（その背の心臓を一度止めている）なら始まらず、「祠から挑む」と出る。ほかのグループの初回の順路が体の中で動いているあいだは「ほかの一行が…待つ」と出て始まらない（決定 207）。
- 「全員」は、そのグループのうち**その背の次元にいる人**（観戦者・創造モードは数えない）。地上に残っている仲間は数えない。
- **途中からは入れない**。順路の参加者は始めたときにその背にいた人（`keep.trial.party`）。あとからその背へ来た仲間は運ばれず、入口の箱で「仲間は順路の途中にいる。終わるまで、ここで待つ」と出る。終わると（心臓を止める・あきらめ・背を出る・リセット）入れる。
- **周回の入口**は祠（3 章）。祠で品を使った瞬間に全員がその区画の段 1 の入口へ運ばれるので、入口の箱は要らない。

### 2.3 運ばれ方

- 「越えた → 4 秒 → 次の入口」は `TrialRoute`（石の合図 `TrialSteles.onRung` → `TrialRoute.onCleared`）。今の段の試練の石だけを数え、越えた順が前後しても段は戻らない。運ばれるのは**順路の参加者のうち、その背にいる人**。行き先は次の段の入口の休み場（原型は今までの入口の休み場、新作はセルの最初の休み場。`TrialRoute.entryRest`）。
- 運ぶ前の 4 秒に、ゴールの演出・報い・「越えた。次は〇〇」の一行（帯）。運ばれた瞬間に段の札（6 章）と、ビーコンの音。試練を越えた人には紋が一つ（31 の A14）。
- 心臓の前室へ運ばれたあとは今の決まり（大門の 5 秒の予告・参加者の数え方・再入場。02 の 3.4・5.x）。

### 2.4 休み場・倒れたとき・あきらめ・終わり

- 倒れると、今いる段の試練の休み場で目を覚ます（`RespawnGuard`・休み場の番号つきの記録。02 の 7.3）。段は戻らない。
- **あきらめ**（決定 202）: 焚き火にしゃがんで触れた人が「あきらめる」を**提案**する。グループ全員の画面に札（「〇〇が順路をあきらめようとしている」。はい／いいえ）。**全員がはい**で成立。一人でもいいえ、または 30 秒で返事がなければ流れる（提案は 2 分に一度）。成立すると、そのグループの順路は終わり、**全員が背の外へ出される**（初回: 到着の台の外の地上、巨神の影の下。周回: 祠）。使った品は戻らない。一人のときは自分の返事だけで成立。
- 参加者が一人も背にいなくなって 10 秒たつと（背を出る・ログアウト）順路は終わる。3 分の不在のリセット（02 の 7.1）でも終わる。終わると、そのグループの試練の進み（石・休み場・戦い）は戻り、誓いは降りる。引いた三つと修飾は同じ周のうちは変わらない（29 の 2.2 の 7）ので、次に祠で挑むと同じ三つが来る（品はもう一つ要る）。
- 段の記録はグループの記録 `keep.trial.step`（0〜4）・`keep.trial.mid`（段 3.5）・`keep.trial.route`（引いた三つの順）・`keep.trial.party`（参加者）・`keep.trial.start`（始めた時刻）・`keep.trial.slot`（区画の番号。5 章）。順路を終えるときに明示的に消す。

| | 物語（周回 1） | 周回（周回 2〜） |
| --- | --- | --- |
| 入口 | 地上の支度 → 乗り込み口 → 到着の台 → 入口（2.2）。歩く（章の中身は 21） | **祠だけ**（決定 204）。乗り込み口は閉じる（心臓を止めた人には鎖・潮門・昇り風・口が出ない） |
| 要る品 | なし | 専用の品が一つ（3.2） |
| 三つ | 原型の三つ（初回の延長つき） | プールから引いた三つ |
| 場面 | 背の初見・中ボス・心臓の登場・眠り（20。人ごとに初回） | 出ない |

### 3.1 巨神の祠（`titan_shrine`。周回の入口）

- **何か**: その巨神の歌が宿る石の祠。深層岩の台座（9×9）の上に、巨神ごとの材質の輪（半径 3。岩鯨 = 骨、潮殻 = 海晶の煉瓦、雷翼 = 錆びた銅、余燼 = 金の黒石）と、中央に碑（`titan_shrine`。巨神の碑（09 の 4.3）と同じ形で、笠がその巨神の材質）。四隅に灯り、東の縁に共鳴の炉。台座は壊せない（クリエイティブを除く）。
- **どこに建つか**: **場所は固定**。本当の置き場（と、まわりの地形）は、地図表示と地形生成（33 の W2）で決める。それまでは仮に、はじまりの都の鐘から、その巨神の跡地の方位（33 の 3 章: 岩鯨 北・潮殻 東・雷翼 西・余燼 南）へ、距離の帯の近い端（300・800・1,000・1,200）の地表に、世界で一つ建てる（`TitanShrine.ensure`）。誰かがその巨神の心臓を初めて止めたときに建つ。
- **いつでも行ける**: 時間・天気・潮・嵐・巨神の眠りで閉じない。遠くても巨神の子（09・28）の海図の行き先に「〇〇の祠」が出る（その巨神の心臓を止めた人だけ）。その巨神の心臓を一度止めた人だけが使える（「まだ、この祠はあなたを知らない」）。
- **使い方**: 右クリックで祠の画面（6 章）。パーティ全員（一人なら一人）が輪の中に立ち、その巨神の**歌片**（3.2）を手に持った人が碑を長押し（右クリックを 1.5 秒続ける。帯に「巨神の歌が、足もとから満ちてくる」）。品が一つ減る → 雲の帳（潮殻は青。1.5 秒）→ 輪の中の人がその背へ運ばれ、順路の段 1 の入口へ（`TrialRoute.start`）。輪の外の仲間は運ばれない（「〇〇が祠から順路へ呼ばれた。輪の外にいたので、あなたは残った」）。
- **断るとき**: 使う人か輪にいる誰かがその巨神の心臓をまだ止めていない／品を手に持っていない／そのグループの順路がもう動いている。理由を一行。
- **祠のまわり**（背から外したものの行き先）: 共鳴の炉（03 の 4.1。台座の東の縁）、順位の石と飾り板（31 の C11・C21。輪の外の半径 5〜9）。**誓い**（21 の 1.8）は周回の縛りとして祠で選ぶ: 碑をしゃがんで右クリックすると誓いの一覧（チャットの [+] [-]）が出る。選び直せるのは祠のそば（8 マス）で、順路が動いていないあいだだけ（背の中では変えられない）。数字・報いは 21 の 1.8 のまま。順路が終わると降りる。
- **物語の整合**: 歌のかけら（巨神の子。28）と同じ「歌」の仕組み。「巨神は自分を止めた者を覚え、歌で背へ呼ぶ」。祠を初めて使うと伝承の書に一頁（`chapter1/shrine_<巨神>`）。
- 自由なモードの依頼「順路を越える」（`weekly_route`。週替わり。岩鯨の心臓を止めると受けられる。順路を心臓まで越えると済む。決定 203。07 の 8 章）。

### 3.2 歌片（順路の鍵）

- 巨神ごとに一種類（岩鯨の歌片 `song_shard_stone_whale`・潮殻の歌片・雷翼の歌片・余燼の歌片）。旅嚢の固定枠（22。鍵の欄、64 まで）。**一度の順路に一つ**、祠で使った人のものが減る（パーティの代表が一つ払う）。初回（物語）には要らない。
- 手に入れ方（決定 206）: その巨神の心臓を止めるたびに戦った人全員に一つ（次の周の分。初回の心臓でも渡すので、二周目はすぐ挑める）、その巨神の背の敵から 2.5%（倒した人だけが拾える。`SongShardDrops`）、依頼「順路を越える」の報い（岩鯨の歌片）、祠の画面の「歌片を作る」（祠の炉の役目。その巨神の素材 24 と共鳴の欠片 6 で一つ。祠のそばで、その巨神の心臓を止めた人だけ）。
- あきらめ・リセットで戻らない（Wynncraft の鍵と同じ）。投げ捨てられない・倒れても残る（11 の大事な品。`Keepsakes`）。

### 3.3 巨神の見え方（重さ対策）

- 空・海・嵐・地を泳ぐ**成体の巨神は、その章を遊んでいる人（まだその心臓を止めていない人）と、その人のパーティ（同じグループのオンラインの人）にしか見えない**（`TitanVisibility`）。見えない人には、本体・鎖・昇り風・口の実体をサーバーが送らない（各実体の `broadcastToPlayer`。クライアントに存在しないので描画されない）。歌・鎖の音・地鳴り・息は見える人にだけ鳴らす。見えない巨神には体の当たり（`TitanSolids`）がなく、乗り込み口（鎖・陣・潮門・昇り風・口）も働かず、巨神は見えない人のところへ呼び直されて来ない（`TitanKeeper.pickTarget`）。判定は 1 秒ごとに見直す。
- 物語の決まり（ゲームルール `skyabyssStoryGate`）を切っているとき、観戦者・クリエイティブには、いつも見える。
- 序章・一章の空の影（06・17）はワールドの出来事のまま（影は巨神ではなく「何か」）。
- 巨神の子（28）は持ち主のパーティにしか見えない（今のまま）。
- 眠りの場面（20 の 3.4）は初回に止めた人だけが見る（今のまま）。章を終えた人のそばで別のパーティがその巨神を止めても、何も見えない（巨神そのものが見えないので）。
- サーバーに巨神は種類ごとに一体のまま（`TitanKeeper`）。

## 4. 一つの試練を大きくする（順路の効き目）

- 今のセルの箱（M・L）は「三つが同時に開く」前提。順路では一度に一つなので、**各セルを長さ 1.5〜2 倍**（歩は道のりを、智は仕掛けの段を、闘は波の数を）へ太らせられる。一人で解ける・猶予の最短は守る。
- 太らせる順（R5。8 章）: 原型の三つ × 四体 → 29 の ★2・★3 の新作。既知の道は消したので、周回でも初回の部屋（鐘楼・詰所など）はそのまま遊ぶ部屋。
- 広さの目安（`dev backmetrics` で測る）: 歩 60〜90 × 20、智 40 × 40、闘 50 × 50（床）。

## 5. 区画（インスタンス）と負荷

Wynncraft はパーティごとに別の世界を作る。この mod（NeoForge 1.21.1、追加ライブラリなし）では、実行中に次元を増やすのは支えられていないので、**同じ背の次元の中で、順路ごとに「区画」を分ける**。

- **区画**（`TrialSlot`）: 一つの順路につき番号を一つ（1〜32、小さい空きから）。順路を始めるときに取り、終わると返す（返した番号は 3 分のあいだ別の順路に渡さない。ほかに空きがなければ渡す）。記録は `keep.trial.slot`。
- **区画に建てるもの**: 引いた三つのうち新作のセル（36 すべて。`TrialCell.relocatable`）を、背の中の手本の部屋（試練の階・甲板）から区画へブロックごと写す（`TrialSlot.build`。箱はセルの床の範囲・休み場・戸・ゴール・光る床を囲んで 3 広げたもの。入口の休み場が戸の前の広間のセル（W06・W07）は広間も）。写すのは順路を始めた瞬間で、三つで数万ブロック、一瞬で終わる。順路が終わると空気に戻す。原型（体の中の翼）と中ボス・心臓は写さない。
- **写しの動かし方**: セルの決まりは手本の座標で書いてあるので、写しのセルを動かすときは、写しの中のそのグループの人と敵をいったん手本の座標へ移して決まりを呼び、終わったら写しへ戻す（`TrialWindow`。通信は出ない）。そのあいだ戸・音・粒・雷・敵の道・見かけは写しの座標へずらす（`TrialFrame`）。手本の部屋のチャンクは写しが動いているあいだ読み込んでおく。小人数の罠と柱（`RoomPlay`）と雷翼の巣の柱（S09）も写しで動く。倒れて手本の休み場で目を覚ましたら、写しへ戻す。
- **待ち**: 写しはグループごとなので、物理のセル（世界が変わる）も二組が混ざらない。2 レーン・待ち行列は無い。手本の部屋は、写しを使わないとき（開発の確かめ）だけ使う。
- **心臓の間と前室**は体の中のまま共有（グループごとの上書きと敵の持ち主で同時に戦える。02 の 7.1）。中ボスも原型の中のまま。
- **初回（物語）**: 原型の三つは体の中（初回の延長の部屋ごと）。体の中の原型には、初回の順路が一度に一グループだけ入る（ほかのグループの初回の順路が動いているあいだは、入口で待つ。初回同士が同時に重なることは稀）。（決定 207）
- 戦いの強さは「その試練に入った人の数」（29 の 2.8）。順路ではグループ全員が同じ試練にいるので、実質パーティの人数。
- 負荷: 同時に動く仕掛けはグループにつき一セル。背の体の中から鼓動の間の板と碑・任意の翼が消えたので、起動時の建設は短い。

## 6. 画面・知らせ

- **目的の帯**（18）: 背の中で順路が動いているあいだ「第一の試練 〇〇（歩）」「第二の試練 〇〇（智）」「第三の試練 〇〇（闘）」「〇〇を倒そう」（中ボス）「心臓へ」。原型の試練の中の次の目的（岩鯨の `TrialGuide` など）があれば「：」のあとに続ける。サーバーが段の変わり目と 10 秒ごとに `RouteState` を送る。
- **段の札**（18 の札。上の帯）: 段が始まるとき（運ばれたとき）、試練の名前と枠（「第一の試練　〇〇（歩）」）、下の行に段の星・稀さ・修飾のチップ（四つまで）。周回は「〇周目」を添える。中ボスは「〇〇を倒そう」、心臓は「心臓へ」（`RouteCard`）。
- **祠の画面**（碑を右クリック。旧「試練の板」の画面）: 引いてある三つ（名前・枠・類・段・修飾・図鑑のしるし）、周回の番号、深淵のつまみ（29 の 2.9）、「歌片を作る」、図鑑の頁、順路の記録（越えた回数・最速）、持っている歌片の数、称号。
- **控え帳**（11）の巨神の頁に「順路」の行: 今の段（まだ／第 n / 3 の試練／中ボス／心臓へ）と、引いてある三つ・周回・越えた回数と最速。
- **パーティの札**（10 の 6.4）: 同じ背にいる仲間の名前の前に「段 n」。
- **音**: 入口が開く（紫水晶の響き）・次へ運ばれる（ビーコン）・あきらめの札（鐘の響き）。どれも既存の音。
