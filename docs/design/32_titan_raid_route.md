## 0. 要約

- **順路**: 背に入ったグループは、**歩 → 智 → 闘 →（中ボス）→ 心臓** の順に一つずつ進む。次へは歩かず、越えた 4 秒後に次の試練の入口へ運ばれる。
- **背の中に、順路以外のものは置かない**。鼓動の間・試練の板・誓い・炉・任意の翼・今週の試練・骨の書庫・胸びれの道・尾の展望は**消す**。背は「到着の台 → 入口 → 三つの試練 → 中ボス → 心臓」だけ。
- **物語（初回）**: 地上の支度 → 乗り込み口（鎖・潮門・昇り風・口）→ 到着の台 → **入口**（岩鯨なら今の上へ向かう階段）に入ると、その場で順路が始まる。パーティは**全員が入口に入る**。三つは原型（初回の延長つき）。
- **周回（二回目から）**: 地上の**巨神の祠**から**だけ**挑む（乗り込み口は閉じる）。祠は場所が固定で、いつでも行ける（時間・天気・巨神の状態で閉じない）。入るには**専用の品が一つ**要る（3.2）。
- **巨神は、その章を遊んでいる人（とそのパーティ）にしか見えない**（重さ対策。3.3）。章を終えた人には空を泳ぐ姿も鎖も見えず、祠だけが残る。
- **待ちを作らない**: 一つの順路は**区画（インスタンス）**で動く。背の次元の遠くに区画を一つ取り、引いた三つのセルをそこへ建て、グループはその区画だけを使う。ほかのグループの試練と触れない。心臓の間は今のまま（グループごとの上書きで同じ部屋に同時にいられる）。
- **引き方は 29 のまま**: 周回 1 は原型の三つ、周回 2 からはプールから各枠一つ。修飾・稀さ・深淵・図鑑・報いも変えない。読む場所は板ではなく、段の札・目的の帯・控え帳。
- **あきらめ**: 全員の同意で順路が終わり、**全員が背の外へ出される**（段 0 に戻るだけではない）。一人の操作では戻らない。
- **守ること**: 時間・天気・背の状態で閉じない。どの順路も一人で解ける。装備の確率と天井は変えない。心臓の戦いの内容は変えない。

## 1. なぜ順路にするか

| 今（29 の 2.4） | 困ること | 順路 |
| --- | --- | --- |
| 鼓動の間から三つの広間へ歩き、引いた三つのセルの入口を自分で探して入る | 試練の階が広く、「どこへ行けばいいか」と「移動」に時間がかかる | 入口に入れば次が来る。行き先を探さない |
| 三つを好きな順で遊べる。パーティが分かれて別々の試練に入れる | 試練ごとの山場が作れない。分かれて進むとパーティで遊ぶ意味が薄い | 歩で体を温め、智で頭を使い、闘で武器を振って心臓へ |
| 十二のセルを常設し、引いていない戸は閉じて見える。世界が変わるセルは 2 レーンで、三つ目のグループは待つ | 閉じた戸の列は見かけが死んでいる。待ちが出る | 区画ごとに引いた三つだけ建てる。待ちなし |
| 鼓動の間に板・誓い・炉・今週の試練、背に任意の翼 | 背の中に寄り道が多く、順路の緊張が切れる。建設も長い | 背は順路だけ。寄り道と設備は地上（祠のまわり）へ |

## 2. 順路の決まり

### 2.1 段

| 段 | 場所 | 入り方 | 越え方 | 越えたあと |
| --- | --- | --- | --- | --- |
| 0 入口 | 到着の台と入口（初回）／祠（周回） | 初回: 乗り込み口から到着の台へ。周回: 祠で品を使う | グループ全員が入口に入る（2.2） | 段 1 へ |
| 1 歩 | 引いた歩の試練（周回 1 は原型。岩鯨 W01、潮殻 T01、雷翼 S01、余燼 E01） | 入口の休み場へ運ばれる | ゴールの光る印に着く（`TrialGoal`） | 4 秒待って段 2 へ |
| 2 智 | 引いた智の試練（原型 W05・T05・S05） | 同上 | 同上 | 4 秒待って段 3 へ |
| 3 闘 | 引いた闘の試練（原型 W09・T09・E09。雷翼は初回だけ S06 眼の間） | 同上 | 同上 | 4 秒待って段 3.5 へ |
| 3.5 中ボス | 番兵長・潮招き・雷獣・鍛え手の間 | 前室へ運ばれる | 中ボスを倒す | 段 4 へ。**周回で闘に新作が引かれた周も挟む**（決定 201） |
| 4 心臓 | 心臓の前室（休み場 `heart`）→ 大門 → 心臓の間 | 前室へ運ばれる。備えの三灯・碑の囁きは今のまま | 心臓を止める | 眠りと運び出し（02 の 2.11）。周回数 +1 |

- 枠の順は **歩 → 智 → 闘** で固定（決定 200）。三つの類はいつも違う（29 の 2.2 の 3）。
- 闘の原型は終わりに中ボスがいるので、周回 1 と「闘に原型が引かれた周」は段 3 と 3.5 が続けて一つの部屋。
- 一周の長さの目安: 初回は今と同じ（21 の 1.1）。周回は 25〜35 分。セルを太らせたら（4 章）40 分まで。

### 2.2 入口（全員で入る）

- **初回の入口**は、到着の台から体の中へ入る口（岩鯨: 台の北寄りから東へ上る階段の最初の 5 段。潮殻: 潮門の内側の段。雷翼: 止まり木の昇り風の降り口。余燼: 口の奥の喉）。入口の箱に**グループ全員**が入ると、5 秒の予告のあと順路が始まる（画面の帯に「仲間を待っている 2/4」。入った人は動かない）。
- 「全員」は、そのグループのうち**その背の次元にいる人**（観戦者・創造モードは数えない）。地上に残っている仲間は数えない。
- **途中からは入れない**。順路が始まったあとにその背へ来た仲間（鎖を上って来た・祠を使った）は、到着の台に「順路の途中。終わるまで待つ」と出て、入口は閉じている。終わると（心臓を止める・あきらめ・リセット）開く。
- **周回の入口**は祠（3 章）。祠で品を使った瞬間に全員がその区画の段 1 の入口へ運ばれるので、入口の箱は要らない。

### 2.3 運ばれ方

- 「越えた → 4 秒 → 次の入口」は今の `TrialRuntime.weeklyBack` の運びと同じ仕組みで、行き先だけが次の試練の入口の休み場。運ばれるのは**そのグループの、その試練の中にいる人**（`TrialRegions`）と、同じ区画の休み場で待つ人。順路は一つ、置いていかない。
- 運ぶ前の 4 秒に、ゴールの演出・報い・「次は〇〇」の一行（目的の帯）。画面は 0.5 秒だけ暗くなる。
- 心臓の前室へ運ばれたあとは今の決まり（大門の 5 秒の予告・参加者の数え方・再入場。02 の 3.4・5.x）。

### 2.4 休み場・倒れたとき・あきらめ・終わり

- 倒れると、今いる段の試練の休み場で目を覚ます（`RespawnGuard`・休み場の番号つきの記録。02 の 7.3）。段は戻らない。
- **あきらめ**（決定 202）: 焚き火にしゃがんで触れた人が「あきらめる」を**提案**する。グループ全員の画面に札（「〇〇が順路をあきらめようとしている」。はい／いいえ）。**全員がはい**で成立。一人でもいいえ、または 30 秒で返事がなければ流れる（提案は 2 分に一度）。成立すると、そのグループの順路は終わり、**全員が背の外へ出される**（初回: 到着の台の外の地上、巨神の影の下。周回: 祠）。使った品は戻らない。一人のときは自分の返事だけで成立。
- 背を出る・ログアウト・3 分の不在のリセット（02 の 7.1）で、そのグループの順路も終わる。引いた三つと修飾は同じ周のうちは変わらない（29 の 2.2 の 7）ので、次に祠で挑むと同じ三つが来る（品はもう一つ要る）。
- 段の記録はグループの記録 `keep.trial.step`（0〜4）と `keep.trial.route`（引いた三つの順）と `keep.trial.slot`（区画の番号。5 章）。順路を終えるときに明示的に消す。

## 3. 物語（初回）と周回

| | 物語（周回 1） | 周回（周回 2〜） |
| --- | --- | --- |
| 入口 | 地上の支度 → 乗り込み口 → 到着の台 → 入口（2.2）。歩く（章の中身は 21） | **祠だけ**（決定 204）。乗り込み口は閉じる（心臓を止めた人には鎖・潮門・昇り風・口が出ない） |
| 要る品 | なし | 専用の品が一つ（3.2） |
| 三つ | 原型の三つ（初回の延長つき） | プールから引いた三つ |
| 場面 | 背の初見・中ボス・心臓の登場・眠り（20。人ごとに初回） | 出ない |
| 中ボス | 闘の原型の終わり | 段 3.5（2.1） |
| 長さ | 21 の 1.1（岩鯨 75〜95 分） | 25〜35 分 |

### 3.1 巨神の祠（`titan_shrine`。周回の入口）

- **何か**: その巨神の歌が宿る石の祠。深層岩の台座の上に、巨神ごとの材質の輪（半径 3）と、中央に碑。巨神の碑（09 の 4.3）と同じ系統で、ひと回り大きい。壊せない。
- **どこに建つか**: **場所は固定**。四つの祠の置き場（と、まわりの地形）は、あとで作る専用の地図表示と地形生成（Wynncraft のように世界の地図が決まっている形）で決める。それまでは仮に、その章の跡地（岩鯨 = 巨神の骨の脇、潮殻 = 難破船の浜、雷翼 = 止まり木の峰の足もと、余燼 = 火口の縁）に、世界で一つ建てる。
- **いつでも行ける**: 時間・天気・潮・嵐・巨神の眠りで閉じない。遠くても巨神の子（09・28。海図の行き先に「〇〇の祠」）で着ける。祠は 04 の章（進み）で開く: その巨神の心臓を一度止めた人だけが使える（乗る資格。10 の 3.3。段階が足りない人は「まだ、この祠はあなたを知らない」）。
- **使い方**: パーティ全員（一人なら一人）が輪の中に立ち、持ち主（パーティの長、または一人）が**専用の品**（3.2）を手に持って中央の碑を長押し（1.5 秒）。品が一つ減る。「巨神の歌が、足もとから満ちてくる」→ 雲の帳（潮殻は青）→ その順路の区画の段 1 の入口へ。輪の外の仲間は運ばれない（名前つきの一行。運ばれた側は 2.2 の「途中からは入れない」）。
- **断るとき**: 輪にいる誰かがその巨神の心臓をまだ止めていない／品がない／そのグループの順路がもう動いている（終わるまで）。理由を一行。
- **祠のまわり**（背から外したものの行き先）: 共鳴の炉（03 の 4.1。背の到着の台から移す）、控え帳で読む図鑑、順路の記録（6 章）。誓い（21 の 1.8）と今週の試練（29 の 4.4）は**消す**（未決 205 で、誓いだけ祠の「縛り」として残す案もある）。
- **物語の整合**: 歌のかけら（巨神の子。28）と同じ「歌」の仕組み。「巨神は自分を止めた者を覚え、歌で背へ呼ぶ」。碑文一行（伝承の書に記される。05）。
- 自由なモードの依頼に「順路を越える」を足す（決定 203。週替わり。07 の 8 章・10 の 8.2）。

### 3.2 専用の品（順路の鍵。名前は仮に「〇〇の歌片」）

- 巨神ごとに一種類（岩鯨の歌片・潮殻の歌片・雷翼の歌片・余燼の歌片）。旅嚢の固定枠（22）。**一度の順路に一つ**、祠で使った人のものが減る（パーティの代表が一つ払う）。初回（物語）には要らない。
- 手に入れ方（推奨。未決 206）: その巨神の心臓を止めるたびに参加者全員に一つ（次の周の分）、その章の地上の敵（骨の番兵・磯走り・雷乞い・灰被りなど）から 2〜3%、自由なモードの日替わりの依頼の報い、共鳴の炉でその巨神の素材から作る（高め）。初回の心臓でも一つ渡すので、二周目はすぐ挑める。
- あきらめ・リセットで戻らない（Wynncraft の鍵と同じ）。投げ捨てられない（11 の大事な品）。

### 3.3 巨神の見え方（重さ対策）

- 空・海・嵐・地を泳ぐ**成体の巨神は、その章を遊んでいる人（まだその心臓を止めていない人）と、その人のパーティにしか見えない**。章を終えた人（心臓を止めた人）には、巨神の本体・鎖・潮門・昇り風・口・影・歌・足もとの揺れが出ない。サーバーの判断で、見えない人にはその実体を送らない（クライアントに存在しないので描画も音も鳴らない。`ChunkMap.TrackedEntity` の送り先を絞る mixin、または `EntityTrackingEvent` の代わり）。
- 序章・一章の空の影（06・17）はワールドの出来事のまま（影は巨神ではなく「何か」）。
- 巨神の子（28）は持ち主のパーティにしか見えない（今のまま）。
- 眠りの場面（20 の 3.4）は初回に止めた人だけが見る（今のまま）。章を終えた人のそばで別のパーティがその巨神を止めても、何も見えない（巨神そのものが見えないので）。
- サーバーに巨神は種類ごとに一体のまま（`TitanKeeper`）。見える人がいないときは、動きを止めてよい（負荷）。

## 4. 一つの試練を大きくする（順路の効き目）

- 今のセルの箱（M・L）は「三つが同時に開く」前提。順路では一度に一つなので、**各セルを長さ 1.5〜2 倍**（歩は道のりを、智は仕掛けの段を、闘は波の数を）へ太らせられる。一人で解ける・猶予の最短は守る。
- 太らせる順（P4。8 章）: 原型の三つ × 四体 → 29 の ★2・★3 の新作。原型は初回の延長（21）をそのまま含むので、周回では「初回の部屋が静かな通路」になっていた区間を**周回でも遊ぶ部屋**に戻してよい（既知の道を消すので）。
- 広さの目安（`dev backmetrics` で測る）: 歩 60〜90 × 20、智 40 × 40、闘 50 × 50（床）。

## 5. 区画（インスタンス）と負荷

Wynncraft はパーティごとに別の世界を作る。この mod（NeoForge 1.21.1、追加ライブラリなし）では、実行中に次元を増やすのは支えられていないので、**同じ背の次元の中に「区画」を取って同じことをする**。

- **区画**（`TrialSlot`）: 背の次元の、体から遠く離れた所（x = 4096 + 番号 × 1024、z = 4096）に取る 512 × 512 の四角。一つの順路につき一つ。番号は小さい空きから。使い終わると（順路が終わって 3 分）空気に戻して空ける。上限は同時 32（足りなければ待つが、ふつうは当たらない）。
- **区画に建てるもの**: 引いた三つのセル（入口の休み場・ゴール・休み場つき。`TrialCell.build`）と、中ボスの間（闘の原型でないとき）。**物理のセル**（世界が変わる。29 の 3 章）も、そうでないセルも、全部この区画に建てる（共有しないので上書き・2 レーン・待ち行列の仕組みは要らない）。
- **建てる時機**: 祠で品を使った瞬間（初回は入口に全員が入った瞬間）に段 1 のセルを建て、建ち終わるまで（2〜4 秒。`BackBuildJobs` で tick を分ける）雲の帳を続ける。段 2・3 のセルは段 1 を遊んでいるあいだに建てる（運ばれる前に必ず終わる）。
- **心臓の間と前室**は体の中のまま共有（グループごとの上書きと敵の持ち主で同時に戦える。02 の 7.1）。中ボスの間も、原型の闘の終わりにあるものは体の中のまま。
- **初回（物語）**: 原型の三つは体の中に建ててある（初回の延長の部屋ごと）。初回も区画に建ててよいが、体の中の原型は 21 の延長・場面・碑文が結びついているので、**初回は体の中、周回は区画**とする。体の中の原型には、一度に一グループだけ入る（初回のグループが同じ背で重なったら、二つ目は到着の台で待つ。初回同士が同時に重なることは稀）。未決 207 で「初回も区画」を選べる。
- 戦いの強さは「その試練に入った人の数」（29 の 2.8）。順路ではグループ全員が同じ試練にいるので、実質パーティの人数。
- 負荷: 同時に動く仕掛けはグループにつき一セル。建設は区画ごとに 3〜4 セル（セル一つ 60×60×20 ≒ 7 万ブロック。四体の起動時の建設 41 秒より軽い）。背の体の中から鼓動の間・試練の階・任意の翼が消えるので、起動時の建設は短くなる。
