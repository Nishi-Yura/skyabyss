## 0. 要約

- **順路**: 背に入ったグループは、**歩 → 智 → 闘 → 中ボス → 心臓** の順に一つずつ進む。どれも区画（体の外の遠い所）に建てた閉じた部屋で、次へは歩かず、越えた 4 秒後に**次の部屋の中へ**運ばれる。三つ目のあとは中ボスの間の中、中ボスを倒すと心臓の間の中へ直に運ばれる（前室を歩かない）。
- **巨神の中は建てない**（2.5）。背の次元にあるのは巨神の体（外見）と、背の上の飾り・到着の台だけ。試練の翼・鼓動の間・甲板・番兵長の広間・心臓の回廊などの体の中の建築はない（5.3）。
- **物語（初回）**: 地上の支度 → 乗り込み口（鎖・潮門・昇り風・口）→ 到着の台に着く → その場で 3 秒の予告のあと、グループ全員が部屋 1 の入口の休み場へ運ばれる（2.2）。
- **周回（二回目から）**: 地上の**巨神の祠**から**だけ**挑む（乗り込み口は閉じる）。祠は場所が固定で、いつでも行ける（時間・天気・巨神の状態で閉じない）。入るには**専用の品が一つ**要る（3.2）。
- **巨神は、その章を遊んでいる人（とそのパーティ）にしか見えない**（重さ対策。3.3）。
- **待ちを作らない**: 一つの順路は**区画**（番号 1〜32。`TrialSlot`）で動き、部屋 1〜3 と中ボスの間はその区画に建つ。心臓の間は背ごとに一つ（区画 0 番の枠）で、グループごとの上書きで同時に戦える（5 章）。
- **どの部屋も一人で越えられ、何をすればよいかが一目で分かる**（9 章）: 二人が要る所には一人の道を足し、運ぶ部屋は届け先に光の柱と、帯に矢印と距離を出す。
- **あきらめ**: 全員の同意で順路が終わり、**全員が背の外へ出される**。
- **守ること**: 時間・天気・背の状態で閉じない。装備の確率と天井は変えない。心臓と中ボスの戦いの内容は変えない。

## 1. 順路の方針

- 入口に入ると試練が始まる。段は歩 → 智 → 闘 → 中ボス → 心臓の一本道。
- 三つの試練は順番に越える。パーティは一つの順路を全員で遊ぶ。
- 試練の戸を探して歩かない。越えると次の段の入口の休み場へ運ばれる。
- 祠は地上で場所固定・いつでも入れる。入るには歌片が要る。
- 待たせない。同じ背の別のグループは区画（5 章）で分ける。
- 背に寄り道（鼓動の間の板・誓いの炉・週替わりの試練・背の任意の翼）は置かない。

### 2.2 入口（到着の台）

- **到着の台**は乗り込みで着く体の外の台（岩鯨: 左のわき腹の台、潮殻: 潮門の到着の段、雷翼: 尾羽の上の台、余燼: 口）。台のまわりの箱（`TrialRoute.entryBox`。台の足の位置 `RouteSeals.safeFeet` から ±6）が入口で、そこにそのグループの**背にいる全員**がそろうと 3 秒（`ENTRY_WAIT`）の予告のあと順路が始まり、全員が部屋 1 の中へ運ばれる（歩かない）。帯に「仲間を待っている 1/2」「試練が始まる…… 3」。
- 周回のグループ（その背の心臓を一度止めている）なら始まらず、「祠から挑む」と出る（乗り込み口がそもそも働かない）。
- **途中から乗り込んだ仲間**（順路が動いてから到着の台に着いた人）は参加者に加わり、仲間のいる今の部屋（中ボスの間・心臓の間を含む）の入口へそのまま運ばれる（`TrialRoute.rejoin`）。次の部屋へ運ばれる 4 秒のあいだに着いた人は、その運びで一緒に運ばれる。
- **周回の入口**は祠（3 章）。祠で品を使った瞬間に全員がその区画の部屋 1 の入口へ運ばれる。

### 2.3 運ばれ方

- 「越えた → 4 秒 → 次の部屋の中」は `TrialRoute`（`RaidRun.complete` → `TrialRoute.onCleared(..., raid)`）。運ばれるのは**順路の参加者のうち、その背にいる人**。行き先は次の部屋の入口の休み場（`RaidKit.buildCell` が部屋ごとに建てる）。
- 三つ目の部屋を越えると中ボスの間の中（`RaidRun.enterMid`）へ、中ボスを倒すと心臓の間の中（`InstanceArenas.heartEntry`、大門のすぐ内側で中心を向く）へ運ぶ。前室を歩く所はない。
- 運ぶ前の 4 秒に、出口の戸が開く・報い・「越えた。次は〇〇」の一行（帯）。運ばれた瞬間に段の札（6 章）と、ビーコンの音。
- 部屋を越えたときは、四体とも同じ口（`GrowthRewards.onRouteTrialCleared`）で、試練の経験値（岩鯨 40・潮殻 50・雷翼 60・余燼 60、推奨レベルで減る）・依頼の合図 `back_trial_cleared`（進捗 `trial:<巨神>`）・巨神ごとの試練の合図（部屋 1〜3 の順に `storm_trial_west/east/front` など。`TrialSteles.signalsOf`）を渡す。試練を越えた人には紋が一つ（31 の A14）。素材・共鳴の欠片・称号は 9.4。岩鯨の部屋 1〜3 を越えると、碑文 `inscription_west`・`inscription_east`・`inscription_below` を記す。どの部屋も、越えるとその部屋の入口の碑の項目を記す（`RaidLore.SIGNS` → `chapter1/inscription_<碑>`）。二章・三章のメインの碑文の段（`main_tide.inscriptions`・`main_thunder.trials.read`）は、その巨神の六部屋の碑（潮殻 TR1・TR4・TR5・TR6・TR3・TR7、雷翼 SR1・SR4・SR2・SR5・SR3・SR6）から二つを数えるので、枠ごとの引きがどうなっても三部屋で済む（心臓を止めれば飛ぶ）。どの引きでも済むことは `SELFTEST raid lore` が全部の組で確かめる。

### 2.4 休み場・倒れたとき・あきらめ・終わり

- 仲間が近くで「使う」を 1.5 秒押し続けると起こせる（`party/Downed`。10 の 10.12）。
- 部屋の中では死なない: 全員が倒れると全滅として、全員を起こしてその部屋の入口の休み場へ戻し、部屋を最初から（9 章）。心臓の間で倒れると、心臓の前室（間の大門の外の小部屋。休み場 `heart`）で目を覚まし、20 秒たつと大門から戻れる（02 の 4.2）。
- 背の中で人を「戻す」所（グループが変わった・リセット・心臓のあとの光・休み場の記録が無いとき）は、すべて**到着の台**（`RouteSeals.safeFeet`）。台に立てば今の部屋へ運び直される（2.2）。
- **あきらめ**（決定 202）: 休み場の焚き火にしゃがんで触れた人が提案し、全員の「はい」で成立。一人でもいいえ、または 30 秒で返事がなければ流れる（提案は 2 分に一度）。成立すると、そのグループの順路は終わり、**全員が背の外へ出される**（初回: 地上の巨神の影の下。周回: 祠）。一人のときは自分の返事だけで成立。
- 参加者が一人も背にいなくなって 10 秒たつと（背を出る・ログアウト）順路は終わる。3 分の不在のリセット（02 の 7.1）でも終わる。引いた部屋と修飾は同じ周のうちは変わらない（29 の 1.2 の 7）。
- 段の記録はグループの記録 `keep.trial.step`（0〜4）・`keep.trial.mid`（段 3.5）・`keep.trial.route`（引いた三つの順）・`keep.trial.party`（参加者）・`keep.trial.start`（始めた時刻）・`keep.trial.slot`（区画の番号。5 章）。順路を終えるときに明示的に消す。

### 2.5 巨神の中は建てない（外見だけ）

- 背の次元に建てるのは、巨神の体のブロック（空を泳ぐ巨神と同じ形・同じ色。中は体の芯の石で埋まったまま）と、外から見える飾りだけ:
  - 岩鯨: 体・背の上の踏み跡と灯り・錨石の鎖・尾の付け根の広場・左のわき腹の到着の台。
  - 潮殻: 体・甲羅の上の溝の手直し・小さな縦穴の埋め・潮門の到着の段（地上へ戻る潮門の口）。
  - 雷翼: 体・尾羽の上の到着の台・羽軸の道・羽の広場・肋の尖塔の外の姿・背の小さな縦穴の埋め。
  - 余燼: 体・地の下・皮の割れ目の栓・口（顔。到着の所）。
- 建てないもの: 体の中を掘る・部屋と通路・原型の試練の翼（岩鯨の西と東の翼・闇の水路、潮殻の庭・潮見・干潟、雷翼の西・東・首・眼・竜骨の道、余燼の喉・管・脇の部屋）・試練の甲板と 29 の新作のセル・鼓動の間・番兵長の広間・心臓の回廊・休み場・碑文・灯り・封じ（`RouteSeals.place`）・体の中の詰みの修復・歩く道の灯り。部屋を動かす仕組み（庭・潮見・干潟の水・戸・道しるべ・嵐の角笛と計器）も背の次元では動かさない（潮と嵐の時計だけ進む）。
- 古い世界は、版が変わったので起動時に一度建て直す（体を置き直すと、掘った所は体の石で埋まる）。
- 人がいる所は、到着の台・区画の部屋・中ボスの間・心臓の間（とその前室）だけ。どれも閉じた部屋で、壊せず置けない。

### 3.1 巨神の祠（`titan_shrine`。周回の入口）

- **何か**: その巨神の歌が宿る石の祠。深層岩の台座（9×9）の上に、巨神ごとの材質の輪（半径 3。岩鯨 = 骨、潮殻 = 海晶の煉瓦、雷翼 = 錆びた銅、余燼 = 金の黒石）と、中央に碑（`titan_shrine`。巨神の碑（09 の 4.3）と同じ形で、笠がその巨神の材質）。四隅に灯り、東の縁に共鳴の炉。台座は壊せない（クリエイティブを除く）。
- **どこに建つか**: **場所は固定**。その巨神の跡地（33 の 3.2）の中心のそばに、跡地を決めたときに取っておいた平らな所（`ChapterGrounds.shrineSpot`）に、世界で一つ建てる（`TitanShrine.ensure`）。跡地がまだ決まっていない世界だけ、都の鐘から跡地の方位の帯の近い端（300・800・1,000・1,200）の地表に建てる。誰かがその巨神の心臓を初めて止めたときに建つ。
- **いつでも行ける**: 時間・天気・潮・嵐・巨神の眠りで閉じない。遠くても巨神の子（09・28）の海図の行き先に「〇〇の祠」が出る（その巨神の心臓を止めた人だけ）。その巨神の心臓を一度止めた人だけが使える（「まだ、この祠はあなたを知らない」）。
- **使い方**: 右クリックで祠の画面（6 章）。パーティ全員（一人なら一人）が輪の中に立ち、その巨神の**歌片**（3.2）を手に持った人が碑を長押し（右クリックを 1.5 秒続ける。帯に「巨神の歌が、足もとから満ちてくる」）。品が一つ減る → 雲の帳（潮殻は青。1.5 秒）→ 輪の中の人がその背へ運ばれ、順路の段 1 の入口へ（`TrialRoute.start`）。輪の外の仲間は運ばれない（「〇〇が祠から順路へ呼ばれた。輪の外にいたので、あなたは残った」）。
- **断るとき**: 使う人か輪にいる誰かがその巨神の心臓をまだ止めていない／品を手に持っていない／そのグループの順路がもう動いている。理由を一行。
- **祠のまわり**（背から外したものの行き先）: 共鳴の炉（03 の 4.1。台座の東の縁）、順位の石と飾り板（31 の C11・C21。輪の外の半径 5〜9）。**誓い**（21 の 1.8）は周回の縛りとして祠で選ぶ: 碑をしゃがんで右クリックすると誓いの一覧（チャットの [+] [-]）が出る。選び直せるのは祠のそば（8 マス）で、順路が動いていないあいだだけ（背の中では変えられない）。数字・報いは 21 の 1.8 のまま。順路が終わると降りる。
- **物語の整合**: 歌のかけら（巨神の子。28）と同じ「歌」の仕組み。「巨神は自分を止めた者を覚え、歌で背へ呼ぶ」。祠を初めて使うと伝承の書に一頁（`chapter1/shrine_<巨神>`）。
- 自由なモードの依頼「順路を越える」（`weekly_route`。週替わり。岩鯨の心臓を止めると受けられる。順路を心臓まで越えると済む。決定 203。07 の 8 章）。

### 3.2 歌片（順路の鍵）

- 巨神ごとに一種類（岩鯨の歌片 `song_shard_stone_whale`・潮殻の歌片・雷翼の歌片・余燼の歌片）。旅嚢の固定枠（22。鍵の欄、64 まで）。**一度の順路に一つ**、祠で使った人のものが減る（パーティの代表が一つ払う）。初回（物語）には要らない。
- 手に入れ方（決定 206）: その巨神の心臓を止めるたびに戦った人全員に一つ（次の周の分。初回の心臓でも渡すので、二周目はすぐ挑める）、その巨神の背の敵から 2.5%（倒した人だけが拾える。`SongShardDrops`）、依頼「順路を越える」の報い（岩鯨の歌片）、祠の画面の「歌片を作る」（祠の炉の役目。その巨神の素材 24 と共鳴の欠片 6 で一つ。祠のそばで、その巨神の心臓を止めた人だけ）。
- あきらめ・リセットで戻らない（Wynncraft の鍵と同じ）。投げ捨てられない・倒れても残る（11 の大事な品。`Keepsakes`）。

### 3.3 巨神の見え方（重さ対策）

- 空・海・嵐・地を泳ぐ**成体の巨神は、その章を遊んでいる人（まだその心臓を止めていない人）と、その人のパーティ（同じグループのオンラインの人）にしか見えない**（`TitanVisibility`）。見えない人には、本体・鎖・昇り風・口の実体をサーバーが送らない（各実体の `broadcastToPlayer`。クライアントに存在しないので描画されない）。歌・鎖の音・地鳴り・息は見える人にだけ鳴らす。見えない巨神には体の当たり（`TitanSolids`）がなく、乗り込み口（鎖・陣・潮門・昇り風・口）も働かず、巨神は見えない人のところへ呼び直されて来ない（`TitanKeeper.pickTarget`）。判定は 1 秒ごとに見直し、送り先もそのたびに合わせ直す（`TitanVisibility.resync`。バニラは区画をまたいだときしか見直さないので、止まって待つ巨神が、心臓を止めた人に送られたまま残っていた）。心臓を止めた人の判定はその場で捨てる。
- 物語の決まり（ゲームルール `skyabyssStoryGate`）を切っているとき、観戦者・クリエイティブには、いつも見える。
- 序章・一章の空の影（06・17）はワールドの出来事のまま（影は巨神ではなく「何か」）。
- 巨神の子（28）は持ち主のパーティにしか見えない（今のまま）。

## 5. 区画（インスタンス）と負荷

### 5.1 区画

- **区画**（`TrialSlot`）: 一つの順路につき番号を一つ（1〜32、小さい空きから）。順路を始めるときに取り、終わると返す（返した番号は 3 分のあいだ別の順路に渡さない。ほかに空きがなければ渡す）。記録は `keep.trial.slot`。区画 n の枠は x = 4096 + n × 1024、z = 4096。
- **区画に建てるもの**: 段 s の部屋を `RaidRun.originOf(slot, s)`（枠の x + (s − 1) × 96、床 y 64）に、運ぶときに建てる（`RaidRoom.build`）。中ボスの間は段 4 の場所。順路が終わると空気に戻す（`RaidRun.onFinish`）。
- グループごとに別の部屋なので、どの部屋の仕掛けも二組が混ざらない。待ちはない。

### 5.2 心臓の間（体の外。`trial/raid/InstanceArenas`）

- 四体とも、心臓の間とその前室（休み場 `heart`・大門）を、背の次元の区画 0 番の枠（中心 x 4352、z 4096。床の高さは元のまま）に**封じた一室**として建てる（体の石の箱を置いてから、元の間の形を同じに掘る）。心臓の戦いの座標はこのずれ（`HEART_DX`・`HEART_DZ`）だけ動かし、技・範囲・仕掛けは元のまま。
- 心臓の間は背ごとに一つで、グループごとの上書きと敵の持ち主（02 の 7.1）で同時に戦える。部屋の物理が変わる心臓の間は今までどおり一度に一グループ（`RoomLocks`）。
- 自己テスト `trial route`・`route rooms`・`titan back`・`domain room` が、運ばれた先が間の中・間が封じてある・領域の仕掛けが歩いて届くことを見る。

### 5.3 建てる重さ

- 背の次元を建てるのは新しいワールドの起動時と版が変わったときだけ（`titan/BackBuildJobs` で tick に分ける）。体の中を建てなくなったので、体を置いたあとの仕上げ（部屋を掘る・中身・修復・灯り・封じ）がほぼ無くなった。
- 測った数（自己テスト `back builds`。新しいワールドで、起動時に四体を裏で建て終えるまで。`Built the … in the background` の仕事の ms と、いちばん長い tick）:

| 背 | 前（中も建てる） | 今（外見だけ） |
| --- | --- | --- |
| 岩鯨 | 5,676 ms（最長の tick 131 ms） | 1,691 ms（42 ms） |
| 潮殻 | 3,270 ms（148 ms） | 2,202 ms（84 ms） |
| 雷翼 | 3,503 ms（238 ms） | 1,235 ms（113 ms） |
| 余燼 | 6,407 ms（371 ms） | 3,410 ms（350 ms） |
| 計 | 18,856 ms | 8,538 ms（−55%） |

- 残りはほぼ体のブロックを置く時間（`build work … body`）。心臓の間のまわりの箱は列ごとに tick に分けて詰める（`InstanceArenas.Fill`）。
- 建て直しの ms は自己テスト `titan back (rebuild)` が記録に出す（`SELFTEST titan back build ms`）。
- 起動時に裏で建てる予算は、人がいなければ 1 tick 25 ms、人がいれば tick の余り次第で 10〜25 ms（`BackBuildJobs.budgetMs`）。

## 9. レイドの部屋（歩・智・闘は巨神ごとに固定。`trial/raid/`）

順路の段 1〜3 は、巨神ごとに枠（歩・智・闘）ごとに二案ある部屋から、周ごとに一つずつ引いた三つ。そのあとに中ボスの間（9.2）・心臓の間（5.2）。部屋の中の配置・敵の数・順は挑戦ごとの乱数（`ctx.rng()`）で少しだけ変わるが、遊ぶ内容は毎回同じ。

- **場所**: 巨神の体の外。区画（5 章）の遠い島に、閉じた一室（床・壁・天井・入口の戸・出口の戸・入口の休み場）を建てる（`RaidKit.buildCell`）。壁は水密で、中のブロックは壊せず置けない。
- **流れ**: 段に着くと入口の休み場で 3 秒の準備 → 戸が開いて始まる。越えると出口の戸が開き、順路の「越えた」（`TrialRoute.onCleared`）が呼ばれて 4 秒後に次の段へ。
- **全滅（全員が倒れる）または部屋が失敗を宣言（核が壊れた）**: 全員を起こして、その部屋の入口の休み場へ戻し、部屋を最初から（敵・床の物・仕掛け・進みを戻す）。段は戻らない。
- **目的の帯**: 部屋の名前・いまやること・数（2/3）・二つ目の数（核の体力など）・残り時間を、`RaidHudNet` で部屋の人へ送り、既存の目的の帯に出す。越えたら数秒で消える。
- **二案め**: 同じ巨神・同じ枠に部屋を二つ登録すると（`RaidRooms.register`）、周ごとに一つ引く（`drawOf`。同じ周なら同じ）。余燼は歩 ER1/ER4・智 ER2/ER5・闘 ER3/ER6（13 の 19.3b）。部屋ごとの碑は `RaidLore.SIGNS` に一行足す。
- **一人でも解け、仲間で手分けすると早い**（9.3）。敵の数は部屋の人数で増える。
- **分かりやすさ**: 目的の帯の一行目は、着いた瞬間に「何をすればよいか」をそのまま書く（例「光る骨玉を北の台座へ運ぶ」）。運ぶ部屋は行き先の印（`RaidRoom.guideTarget`）を持ち、`RaidRun` がそこに床から天井までの光の柱（白い粒と根元の輪）を立て、帯に矢印と距離を出す（だれも持っていないときは次に拾う物、持っているときは届け先）。謎解きの部屋は進み（合った数 n/m）を帯に出す（どれが合っているかは教えない）。
- **部屋の物語**（`RaidLore`）: 入口の間の西の壁に碑が一枚（背中の民の言葉）。目を向けるか右クリックで読め、伝承の碑文の項目が記される。入口へ運ばれたとき、心の声を二行（`message.skyabyss.raid_lore.<部屋>.1/.2`）。越えたら、読んでいなくても同じ項目が記される。部屋と碑: WR1 西（骨の道）・WR2 下（息をしない鯨）・WR3 東（返す日）・WR4 胃（鯨のものではない拍）・WR5 床・WR6 輪（鍵は鼓動のそば・留まる者が来る）／TR1 西（真珠）・TR3 前（この拍は誰が押すのか）・TR4 珊瑚（道を編む）・TR5 光（真珠は光を貯める）・TR6 暦（月の六つの顔）・TR7 群れ（母と足跡）／SR1 西（空洞の骨）・SR2 東（柱）・SR3 尾（嵐の衣）・SR4 雷柱（来る者の顔を覚えている）・SR5 拍子（足で数えた拍）・SR6 嵐の目（兜の奥の誰か）／ER1 西（冷えた血）・ER2 東（割った鍵）・ER3 南（眠る巨神）・ER4 鎖の道・ER5 圧合わせ・ER6 弟子の間（分けた者は まだ 下にいる）。分かたれた鼓動の糸は枠ごとに二部屋とも同じ一つを運ぶ（どの引きでも同じ順に出る。34 の 1.1）。自己テスト `raid lore`
- **枠組み**: `RaidRoom`（部屋の基底。build・start・tick・isComplete・reset・onUse）・`RaidRooms`（巨神ごとに歩・智・闘を登録。三つそろうとレイドの順路）・`RaidKit`（部屋の箱・戸・床の道具）・`RaidCtx`（部屋・人・敵・乱数・失敗の宣言）・`RaidRun`（段の進行・全滅・帯・入力）・`RaidBootstrap`（登録の一覧）。

#### 9.3 一人で越えられる

- どの部屋も、二人が要る所（同時に押す・運ぶ人と守る人・片方が仕掛けに残る など）を持たない。二人のときの速さは変えずに、一人の道を足す: 二つ同時の音は 8 秒のうちに続けて叩けばよい（WR2）、一人のときは核の削れが遅い（WR3: 0.55 倍）、一人のときは敵が炉の火を消す間隔が長い（ER3: 2 秒に一度）。運ぶ物は手放せて拾い直せ、落とした物は元の場所へ戻る。仕掛けは一人で順に回れる（栓・突起・弁・石板）。
- 自己テスト `raid solo`（`trial/raid/RaidSoloSelfTest`）: 登録したレイドの部屋すべてと四つの中ボスの間を、偽の人一人ずつで同時に建てて、部屋ごとの台本（`RaidSolo.register`。人ができることだけ: 歩く・叩く・使う・拾う・敵を叩く。読むのはよい）で最後まで越える。体力は毎 tick 戻す（避ける・食べるの代わり）。倒れる・部屋の失敗はやり直しとして数え、3 回まで。建てた部屋が閉じていること（休み場から空気を辿って箱の外へ抜けない）と、帯の一行目の文が lang にあることも見る。戦いの部屋で台本がないものは近い敵から叩く既定の台本（`RaidSolo.FIGHT`）。

### 9.5 闘の試練に中ボスを入れる（00 の 275・277。決定）
