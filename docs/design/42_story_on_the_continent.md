## 0. 変わったことと、物語が困る所

| 変わったこと | 今の物語の困る所 |
| --- | --- |
| はじまりの島から渡し船で都へ（一度きり） | 序章の「煙の立つ方へ」は都の煙を目指して歩く前提。足跡は野営地から都への道ぞい |
| 土地ごとの町（鯨見・汐守・風待・灰炉）と、そこで目覚められる宿 | 各章の支度は都とイサナの焚き火が起点。土地の町に人も頼みも無い |
| 採らない・作らない（店で買う・敵が落とす・粉） | 支度の段が「鉄を作る」「ダイヤを掘る」「醸造する」（34 の 3 章の「バニラの柱」） |
| 章の跡地は土地の奥、都から 900〜1,900 | 「跡地は都から方位と距離で」と言う台詞・地図の噂 |

## 1. 案（推奨: 町を章の入口にする）

### 1.1 序章（はじまりの島 → 鐘の都）

- 目覚め: 島の野営地。帳面「忘れないうちに書け」。島に人はいない（静かな怖さはそのまま）。
- 足跡: 島の道ぞいの巨大な足跡は「海から上がって、また海へ戻った何か」。足跡の最後は船着き場の先の海へ消える（巨神が島を通ったという最初の手がかり）。
- 船着き場: 渡し守はいない。舟だけが待っている（誰が用意したのか — 前の私の気配）。渡ると都の南の門。門の前で空を岩鯨が渡る（できた）。
- 都: 町めぐり（できた）→ 語り部（鐘のそば）。語り部「島から来たのかい。あの島から人が来るのは、ずいぶん久しぶりだ」。

### 1.2 章の型（土地の町が入口）

噂（都の語り部）→ **土地の町へ旅する**（道しるべと地図の印で迷わない）→ 町の人の頼みで支度（町の宿で目覚める場所を決められる）→ 跡地（見る・乗る）→ 背（順路）→ 心臓 → 町へ報告 → 都の語り部へ。

| 章 | 町 | 町の人（新しく立てる） | 支度（作らない形に） |
| --- | --- | --- | --- |
| 一章 岩鯨 | 鯨見の町（北の丘陵） | イサナ（鯨追い。町はずれの見張り台にいる）・宿の主人 | 鉄の装備は鯨見の道具屋で買うか、町の鍛冶の頼みで受け取る（作らない）。骨の坑・割れ殻の洞は丘陵の見どころへ |
| 二章 潮殻 | 汐守の港（東の浜） | 渡し守（都 → 汐守の渡し船）・灯台守 | 「船」は渡し船に乗ること。難破船は浜の見どころ（打ち上げられた船）を使う |
| 三章 雷翼 | 風待の里（西の高地） | 風の民の末（里の長）・山小屋の番 | 銅とダイヤは里の店。避雷の塔・風の民の門の見どころを、風の民の頁の置き場にする |
| 四章 余燼 | 灰炉の村（南の荒野） | 灰の民の生き残り・焼けた砦の見張り | 醸造は村の薬師から薬を受け取る形に。炉の跡の見どころを「炉跡の頁」に |
| 五章 深淵 | 鐘の都（地下） | 今のまま | ネザーの支度は無くす（ブレイズロッド・黒曜石は都の店） |

### 1.3 前の私の足跡（34 の 2 章）を大陸に置く

- 一章: 島の野営地の帳面 → 鯨見の見張り台の荷 → 岩鯨の跡地の石標。
- 二章: 汐守の灯台の壁の刻み「潮は読める。待て」。
- 三章: 風の民の門の鏡（竜骨の間の前にもう一つ）。
- 四章: 炉の跡の頁「四つ返したら、下へ。今度こそ」。
- 置き場は見どころ（40 の 6 章）を使うので、新しい建物は少ない。

### 1.4 台詞の直し（主なもの）

- 「北の丘」「東の海辺」など方位で言う台詞は、町の名前で言う（「鯨見の町の北」）。
- 「鉄を作れ」「ダイヤを掘れ」は「鯨見の鍛冶に頼め」「里の店にある」へ。
- 地図の噂（跡地の霞んだ印）は、町に着いたら本当の印になる。

## 2. ほかの案

- **B 都を拠点に、町は休み場だけ**: 今の物語をほぼそのまま使い、台詞だけ直す。作る量は少ないが、町に話が無く「ただの休み場」になる。
- **C 章ごとに島や大陸を渡る**: 章が進むと新しい土地（外の海の向こう）へ渡る形。今の大陸の形と合わない（のちの土地の話として取っておく）。

## 3. 作る順（A に決まったら）

1. 序章の島（足跡の向きと最後、舟、語り部の台詞）。
2. 一章: イサナを鯨見へ、支度の段を「受け取る・身に着ける」に（34 の 4.2 を書き換え）。
3. 二〜四章の町の人と台詞。
4. 地図の噂と町の印のつながり。

## 4. 作ったもの（2026-10-25 夜）

- 序章: 足跡の伝承は「海から上がって島を横切り、船着き場の先で海へ消える」。渡し船に乗ると「渡し守はいない。舟だけが、ひとりぶんの重さを待っていた」。語り部は「島から来たのかい。あの島から人が来るのは、ずいぶん久しぶりだ」。都の数え歌・見る者・門の碑の文を都と土地の町の言い方に。
- 一章: イサナ（鯨追い）は鯨見の町の見張りの塔の前（焚き火のそば）に立つ（`ContinentTowns.CHASER_MARK`、`NpcSpawner.keepTownChaser`）。大陸では都の鐘のそばには立たない。目的の帯は「鯨見の町の見張り台にいる鯨追いに話しかけよう」で、そこを指す。語り部の案内とイサナの台詞は「北門を出て鯨見へ」「鉄は町の道具屋で」に。
- 残り: 二〜四章の町の人と台詞（3）、地図の噂と町の印のつながり（4）。
