## 2. 空の影

### 2.1 発生

| 項目 | 値 |
| --- | --- |
| 間隔 | 2〜4日（ゲーム内の時間。ホラー演出の頻度の倍率で割る） |
| 条件 | オーバーワールドが昼で雨が降っていない。生きていて観戦モードでない、空の見えるプレイヤーが一人でもいる |
| 条件が合わないとき | 1分後にもう一度調べる |
| 場所 | 条件の合うプレイヤーから無作為に一人を選び、その人の近くを通す |
| 数 | オーバーワールド全体で同時に1つ |

### 2.2 最初の影と序盤の保証

試遊で「空の影が来ないまま岩鯨に会った」ため、最初の影を必ず見せ、岩鯨はそのあとにする（序盤の流れは 17）。

| 保証 | 内容 |
| --- | --- |
| 最初の影 | 初日の正午（tick 6000、始めたのがそれより遅ければ 2 分後）に予約し、条件が合わなければ 10 秒おきに調べ直す。**最初の一回は雨でも起こす**（雨の中の影は暗さが増す）。丸一日遅れたら、空の見えない所にいる人の上にも起こす。頻度を下げた設定で始めた古い予約も、早い予定に引き直す（`SkyEvents.firstPassTime`、`SkyEventData.firstPassTick`） |
| 最初の影のあとに入った人 | 目覚めた翌日の窓（一日の時刻 1000〜9000）に、その人のために影を起こす（`SkyEvents.startFor`）。世界の影は全員に見えるので済んでいる人にも通るが、破れた頁は記されていない人にだけ落ちる |
| 影のあとに落ちる物 | 書を持っている人（野営地の帳面で渡している）には、空から**破れた頁**（出どころ `shadow`）が落ちる。読むと `prologue/shadow` が記される。`LoreEvents.watchSky` は、書を持っている人には影を見ても記さず頁に任せる（`OpeningDirector.deferShadowToPage`）。頁は 2 分で荷物へ、14 分読まなければ自動で読む |
| 書 | 影が済んだのに書を受け取っていない人（クリエイティブなど、屋内で見なかった・途中参加）には、従来どおり影が去った 3 秒後に書が落ちる。水・溶岩・乗り物の上など拾えない所では荷物の中へ（`LoreEvents.bookOwed`） |
| 岩鯨 | 自然に出てよいのは、最初の影が済んで半日たち、だれかが語り部と話していて、夕方（11000〜12500）のとき。さらにワールド開始から 4 日分（5 日目）までは、**影・歌・イサナを済ませた人がオーバーワールドにいるときだけ**、その人の近くへ出る（`OpeningLogic.whaleGateOpen`）。詰み止め: 4 日分を過ぎたら、条件も時刻も問わず出る。頻度 0（影を起こさない設定）のときは門を開けておく（`TitanEvents.whaleMayAppear`）。OP の `titan summon` は今のまま |
| 語り部 | 村の方角の知らせ、鐘のない所への旅の語り部の野営は 07 の 3.1 節（`opening/OpeningBeats`） |

- 実装: `opening/OpeningState`（人ごとの拍子の状態）、`OpeningDirector`。OP コマンド `/skyabyss opening <拍子>`（進める）、`back <拍子>`（戻す）、`reset`、`status`。
- 自己テスト `SELFTEST opening beats`（最初の影の時刻、書の保証、鯨の門、案内の順番、平らな草地での野営と語り部）、`SELFTEST opening`。

### 2.3 通過の形

| 項目 | 値 |
| --- | --- |
| 進路 | 無作為な向き。選んだプレイヤーの220ブロック手前から、真上から最大30ブロック横へずれた線を通る |
| 速さ | 0.35ブロック/tick。通過全体で約1257tick（約63秒） |
| 影の形 | 胴体・首・頭・細くなる尾と、胴につながった左右の巨大な翼。輪郭までの距離でひと続きに作る |
| 大きさ | 翼を広げきって幅270ブロック前後（片側135）。振り上げると片側85まで細くなる。判定の範囲は中心から165ブロック |
| 羽ばたき | 70tickに1回。影の輪郭は前後5ブロックをぼかす |
| 呼び声 | 通過の38%と62%の時点で、雲の上から声が降り、雲の中が一瞬光る |
| 空の荒れ | 通過の5%から25%かけて雲が厚くなり、80%から晴れていく |

### 2.4 プレイヤーが受ける演出（クライアント）

各プレイヤーが自分と影との距離で演出を受ける。天気はそのプレイヤーの画面だけが荒れる（サーバーの天気は変えない）。

| 演出 | 内容 |
| --- | --- |
| 地面の影 | 地形に沿ってひと続きに落ちる（濃さ0.6、半径112ブロックの範囲を描く） |
| 雲の切れ間の姿 | 厚い雲の層（バニラの雲の26下、半径320）の切れ間から、暗い姿がのぞく。姿は輪郭までの距離（`SkyPass.outlineDistance`）から作る 3 層で、高さが違うので動くと層がずれて奥行きが出る: 上（雲の5下）は広くぼやけた明るい半透明の縁（ひれ・肢のうすい部分）、中（10下）は本体、下（17下）は胴と翼の付け根だけが沈む一段濃い芯。輪郭は姿に付いたノイズで崩れ、翼を波が伝わって、ゆっくりうねる。濃淡のむらも姿に付いて動く（頂点の色だけで描く） |
| 雲への影響 | 姿の近くの雲の層は、姿から押しのけられるように模様が外へずれ、上の影を受けて暗く沈む（最大で 55% 暗く） |
| 音 | 羽ばたき（影の翼が広がりきる瞬間に音の山が来る）、通過中ずっと続く低い唸り、呼び声。300ブロック以内で聞こえる |
| 天気 | 380ブロック以内で、雨と雷が強まる（雨は荒れ具合の0.7倍まで） |
| 画面の揺れ | 近いほど空気が細かく震え、羽ばたきのたびに揺れる（設定で切れる） |
| 画面効果 | 影の下ほど暗く、縁が暗くなり、霧が迫り、色が冷たい青紫に沈み、羽ばたきに合わせて視野がわずかに狭まる（設定で弱められる） |
| 引き算 | 近くを通る間は、音楽と動物の鳴き声（`*.ambient`、オウム）が止む |

### 2.5 影の下の動物と村人

対象は動物（家畜・ペットなど Animal）と村人（行商人を含む）。

| 項目 | 内容 |
| --- | --- |
| 足を止めて見上げる（サーバー） | 影の下と、80tick先に影が来る場所で、2tickごとに足を止め、空を見上げ、鈍化（強さ6）で動かなくなる |
| うずくまる（クライアント） | 影の濃さ（今の影と80tick先の影の濃い方）×1.5 に合わせて、体を縦に最大26%縮め、横に8%広げる。身をかがめるのは速く（1tickに差の12%）、起き上がるのはゆっくり（3.5%） |
| 震える | うずくまっている間、横にごく小さく速く揺れる（最大0.012ブロック） |
| 範囲 | 自分から96ブロック以内。影の形はサーバーと同じ計算なので、パケットは要らない |
| 鳴き止む | 2.4節 |

うずくまりは見た目だけで、当たり判定や動きは変えない。ほかの Mod が描画を取り消しても落ちないよう、姿勢の積み重ね（push/pop）を使わずに変形して戻す。

### 2.6 設定とコマンド

| 種類 | 名前 | 範囲・既定 | 内容 |
| --- | --- | --- | --- |
| サーバー | horrorEventFrequency | 0〜3、1 | ホラー演出全体の頻度の倍率。0で空の影も見る者も起きない |
| クライアント | screenShake | true | 画面を揺らすか |
| クライアント | screenEffectStrength | 0〜1.5、1 | 影の下の画面効果の強さ |

- `/skyabyss pass [player]`：すぐに通過を起こす（OP）
- `/skyabyss next`：次の通過までの秒数

### 2.7 マルチプレイ

通過はサーバーに一つで、オーバーワールドの全員に送る（途中でログインした人、ネザーなどから戻った人にも送る）。音・天気・画面効果は各自の距離で決まるので、遠くの人には遠くの出来事として届く。

## 3. 見る者

### 3.1 位置付けと役目

夜、一人で外にいると、遠くの丘の上に人が立っていて、こちらを見ている。近づこうとすると、見つめ続けると、目を離すと、いなくなる。攻撃しない、近づいてこない、音で驚かせない。序章の「前触れ」で、正体は明かさない。

- 正体（00 の 5 = a）: 前のループの自分（留まる者）が残した影。伝承の書の最初の一行と、プレイヤーに似た見た目がほのめかしになる。
- 役目（01 の「過去の自分の幻影」への伏線）:

| 章 | 見る者 | 実装 |
| --- | --- | --- |
| 序章〜2章 | 遠くから見ているだけ。目を合わせる・近づく・見つめ続けると消える。攻撃しない | 段階は見た回数で 0→2 と近づく |
| 1章以降 | 現れ続けるが、段階 2（42〜56 ブロック）より近くには来ない（00 の 2 = B） | `WatcherStage.of(見た回数, 月, 章)`、`CHAPTER_CAP = 2`。章は `ChapterSky.inChapterOne` |
| 3章（月） | ループの仕組みが明かされ、見る者が「前のループの自分が残した影」だと気づく | 未実装 |
| 終章（ラスボス第3形態） | 幻影はこれまでの見る者たち。このときはじめて近くに来て、一緒に戦う | 未実装 |

- 見る者は裏ボスにしない。正体がラスボス第3形態と重なるため（00 の 64）。

### 3.2 現れる条件

サーバーが1秒ごとに、オーバーワールドの各プレイヤーについて調べる。

| 条件 | 値 |
| --- | --- |
| 時期 | そのプレイヤーの「次に現れうる時刻」を過ぎている（3.5節） |
| 序盤 | 目覚めて最初の二晩と、足音・歌の最中は出さない（17 の足音・歌を邪魔しないため。`WatcherEvents.ineligible` → `OpeningDirector.quietNight`） |
| 時刻 | 夜（一日の13000〜22800。日没直後の明るさが残るうちと、夜明け前は避ける） |
| 天気 | 雷雨でない（雨はよい） |
| 場所 | 屋外（頭の上に空が見える）、水中でない |
| 状態 | 生きている、観戦モードでない、寝ていない |
| 一人 | 96ブロック以内に、ほかのプレイヤー（観戦モード以外）がいない |
| 確率 | 条件がそろっている間、1秒ごとに1%（平均100秒待つ。夜になった瞬間には出ない） |
| 同時に | 一人につき一体まで |

### 3.3 立ち位置

`prologue/WatcherSpot` が48か所を試し、条件に合う中から一番良い所を選ぶ。

| 項目 | 内容 |
| --- | --- |
| 距離 | 段階で決まる（3.4節）。初めては58〜70ブロック、慣れるほど近く、最も近くて42ブロック |
| 向き | 今見ている向きから左右75度より外（横か後ろ）。気づく前に視界の真ん中へ急に現れないため |
| 地面 | 葉と液体を除く固い地面の上。体の入る3ブロックが空いている |
| 明るさ | ブロックの光が5以下（松明の明かりの中には立たない）。頭の上に空がある |
| 高さ | 目の高さより12ブロック低い所から32ブロック高い所まで |
| 見通し | 目から、見る者の頭（光る目の高さ。足もとから1.95）と胸（1.2）まで、見えるブロックがない（ガラス越しは見える） |
| 選び方 | 背後が空になる場所（稜線に影が浮かぶ）を強く好み（+6）、少し高い所を好む（高さの差×0.5、-4〜+12で頭打ち） |
| 体の向き | こちらを向いて立つ |

### 3.4 段階

見る者に気づいた回数で、少しずつ近く、長く立つようになる。月の近さ（0〜1）が0.5以上になると一段進む（ループと月が入ったときのための入口で、`WatcherEvents.moonNearness` は今は常に 0。M4 で `ChapterSky.moonNearness` につなぐ）。

| 段階 | 気づいた回数 | 距離 | 見つめて消えるまで | 気づかれないまま消えるまで | 首のかしげ |
| --- | --- | --- | --- | --- | --- |
| 0 | 0 | 58〜70 | 4.0秒 | 120秒 | 6度 |
| 1 | 1〜2 | 50〜64 | 3.5秒 | 140秒 | 10度 |
| 2 | 3以上 | 42〜56 | 3.0秒 | 160秒 | 14度 |

### 3.5 頻度

| 項目 | 値 |
| --- | --- |
| 初めて | そのプレイヤーをこのワールドで初めて見かけてから2〜3日後以降 |
| 次まで | 現れたら3〜5日空ける。月が近いほど最大3割短くなる |
| 気づかれなかったとき | 0.75〜1.25日後にもう一度。続けて2回まで（3回目からは通常の間隔） |
| 倍率 | 日数はすべて「ホラー演出の頻度 × 見る者の頻度」で割る。どちらかが0なら現れない |

日数はゲーム内の経過時間（寝て夜を飛ばした分は数えない）。寝てばかりいる人には現れにくいが、それは「夜に一人でいると」という条件どおりとした。

### 3.6 ふるまいと消え方（クライアント）

人影は見せる相手のクライアントの中にだけ置く（サーバーには存在しない）。ふるまいと消え方もクライアントで決め、終わったらサーバーに「どう消えたか」を知らせる。

| 場面 | ふるまい |
| --- | --- |
| 立った直後 | 音楽が途切れ、動物の鳴き声と洞窟の環境音が止む（引き算の兆し。「音が消えるほうが怖い」、00 の 32）。敵の音は止めない |
| 3秒後 | 本人から20ブロック以内の動物（最大12匹）が、人影の方を向いて足を止める（気づくための手がかり。00 の 33） |
| 届く前に振り向いていた | もう画面の中なら、闇から3秒かけて浮かび上がる（急に出さない） |
| 気づく（画面の中で、遮るものなく0.3秒見えた） | かすかな耳鳴りが始まる |
| 見ている間 | 頭だけがゆっくりこちらを追う（左右60度まで。越えたら体ごと向き直る）。見下ろす・見上げる角度も追う |
| 見つめる（視線の中心から8度以内） | 首が少しずつかしぎ、目の光が少し強まり、耳鳴りが少し大きくなる |
| 見つめ続ける（段階の秒数。長いと「ただのモブ」に慣れるため短め、00 の 29） | 体から2秒かけて薄れ、目の光が最後に消える。息をのむような小さな音 |
| 目を離す（画面の外へ・物陰に入る、0.4秒） | その間に音もなく消える。振り向くと、もういない |
| 近づく（最初の距離から16ブロック寄るか、26ブロックより近い） | 0.7秒で薄れて消える（小さな音） |
| 気づかないまま近くへ来た／時間切れ／朝になった／目が見えない | 何もなかったように消える |
| 気づいたまま時間切れ（段階の時間の1.5倍）／朝になった | 見つめ続けたときと同じく薄れる |

攻撃しない、触れない（当たり判定も選択もない）、押せない、保存されない。死なせる・持ち物を奪うことはない。

### 3.7 見た目

見た目は「自分に似た影」（00 の 8 = E）。v1 の「留まる者の影」（黒く細長い体に横並びの2つの目）は、ゲームの夜でバニラのエンダーマンにそっくりに見えたので作り直した。エンダーマンと分ける決まり: 背丈は 2.1（エンダーマン 2.9）、腕と脚の隙間を見せない一続きの布、目は縦の光が 1 つ（エンダーマンは横の紫 2 つ）、色は夜霧に溶ける青灰（エンダーマンは真っ黒）。

| 項目 | 内容 |
| --- | --- |
| モデル | GeckoLib。立方体56個、0.5単位、重なりなし。骨は body・hem（裾）・mantle（外套）・head・eyes（光る目）・mist（霧のかけら） |
| 形 | プレイヤーと同じ四角い頭（7単位）が、横へずれていく長い首（3単位の太さの布。外套のえりで付け根を巻く）に載って傾く。四角い肩（13単位）、細い腰、少し広がる裾。外套は左が肘まで、右だけ腿まで垂れ（片腕だけ長く見える）、背の外套も腿まで |
| テクスチャ | 256×58、1ブロック=32px。夜霧の青灰（`#252D38`〜`#53606F`）の布で、縦のひだとまだら。裾の下端は淡くほつれる |
| 光るマスク | 目（`#D5E6F6`）、肩と頭の上の面（月明かりの縁）、裾のほつれ。ほかの布にもごくかすかな霧の光（12,15,20）を一様に足し、真っ暗な夜空でも人の形がうっすら残る |
| 目 | 顔の左の目の位置にだけ、縦の細い光（0.5×1.5単位）が一つ。もう片方の目も口もない（目が 2 つの顔は「かわいく」見えたため）。eyes 骨の小さな立方体で、顔の面からわずかに浮く |
| 遠くの目の光 | 目の立方体の真ん中に、縦長の光のにじみを重ねる（横の半径=距離×0.0032×0.6、縦=×1.8。最小0.03ブロック）。40〜70ブロック先で「縦の白い点」に見え、エンダーマンの紫の2点と分かれる。顔がこちらを向いていないときは弱める。カメラ向きの板は、表と裏の両方の巻き順で出す（`RenderType.eyes` が裏面を描かないため）。位置は eyes 骨の立方体の頂点の平均（骨の支点は X の向きが焼いた立方体と合わない）。顔の面から1/16ブロック前に出す |
| 消え方 | 体は半透明で描き、薄れて消える。目の光は体より遅れて消える |
| 動き | 待機の1種類だけ（6秒周期の呼吸のような揺れ、裾と外套のわずかなゆらぎ、霧のかけらの上下）。頭の向き・見下ろし・首のかしげはコードで入れる |
| 影 | 足もとの丸い影は出さない |

- 夜の見え方: 真夜中の空はほぼ黒で、体は草地と同じくらいに沈み、手がかりは目の縦の点になる。「闇に目だけが浮かぶ」静かなホラーとして、体を明るくはしていない。
- 差し替え: `tools/rough/watcher_v2.py` の `CHOSEN` を変えて `python tools/rough/watcher_v2.py --install`（D 頭巾の留まる者・F 喪の鐘。目を eyes 骨の立方体にする必要あり）。ラフの比較シートは `docs/review/watcher_roughs/v2/watcher_v2_roughs.png`、v1 の 3 案は `tools/rough/watcher.py`。

### 3.8 音

既存の音は使わず、`tools/gen_watcher_sounds.py` で合成した。音量はどちらも環境音（AMBIENT）の音量設定に従う。

| 音 | 内容 | 大きさ |
| --- | --- | --- |
| `watcher_presence`（8秒ループ） | 頭の中で鳴るような耳鳴り（5200Hzが2秒周期でうなる）、その下の細い音、36Hz前後の空気の圧、遠い空気のさざめき | 気づくと数秒かけて0.12まで上がり、見つめるほど0.28まで。消えたら引いていく |
| `watcher_fade`（約2.6秒＋残響） | 息を吸い込むように少しずつ強くなり、ふっと途切れる。奥で細い音が900Hzから610Hzへ下がる。鋭い立ち上がりはない | 見つめて消えたとき0.3、近づいて消えたとき0.45 |

目を離して消えたときは音を鳴らさない（耳鳴りが引いていくだけ）。

### 3.9 マルチプレイ

- 人影は見せる一人にだけパケットで送り、その人のクライアントの中にだけ置く。ほかの人には見えない（「自分だけが見た」怖さ）
- 「一人」の条件（96ブロック以内にほかの人がいない）があるので、二人で歩いている間は現れない
- 記録（次に現れうる時刻、気づいた回数）はプレイヤーごとにオーバーワールドへ保存する（死んでも、入り直しても続く）
- 動物が向きを変えるのはサーバーの動物なので、近くにほかの人がいれば見える
- クライアントからの「どう消えたか」は、今立っている人影の番号と合うときだけ受け付ける。改造したクライアントが送っても、自分の段階が進むだけ

### 4.2 削られた山頂

**見え方。** 影が雲の上を通った日、その経路の下の高い峰の頂が、巨大なものが擦っていったように平らに削れる。切り口は進む向きへ少しずつ下がり、数本の溝が斜面を引きずったように伸び、その先に砕けた岩が散る。削れる瞬間、遠くで岩の擦れる低い音がする。プレイヤーは音を聞くか、あとで見慣れた峰の形が変わっているのに気づく。伝承の「平らな峰」（上から削り取ったように平らで、切り口の岩は白い）と同じ姿にした。

| 項目 | 値 |
| --- | --- |
| きっかけ | 空の影の通過が始まったとき。経路の真ん中に一番近いプレイヤー（目撃者、120ブロック以内）が1章に入っていれば |
| 確率 | 通過1回につき `peakScarChance`（既定0.6）。`horrorEventFrequency` が1未満ならそれも掛ける。0なら削らない。峰が見つからない通過も多く、実際は通過3〜4回に1回ほど |
| 探す範囲 | 経路（長さ440）の左右64ブロック。8ブロックおきに見て、近くの一番高い所まで登る。読み込み済みのチャンクだけ |
| 峰の条件 | 頂が y110 以上。半径14の8点の平均より6以上高く、8点のうち6点以上が3以上低い（山頂と尾根は通り、台地の縁や崖の上は通らない） |
| 削る時刻 | 高い順に5つまで候補にし、影がその真上を過ぎる順に試す。最初に安全だった1つだけを削る（通過1回で最大1か所） |
| 形（月の近さ s） | 進む向きに長い楕円。長さの半分 7+4s、幅の半分 3+1.2s。頂から深さ 2+2s（2〜4）で平らに切り、進む向きへ1ブロックにつき0.15下げる |
| 溝 | 2本（s≥0.5で3本）。切り口の中で1段深く、その先の斜面へ 9+7s ブロック、地表を1段削る（先へ行くほど途切れる）。雪は3段まで掘り抜いて岩を見せる |
| 切り口の色 | 岩の峰：切り口の石の4分の3を方解石（白）に。雪の峰（切り口の地表の4割以上が雪）：白くせず、底に残った雪を石・安山岩（灰色）に（白い雪に紛れて見えないため）。どちらも周りと色が違って見える |
| 散った岩 | 溝の先の地面に 6+6s 個（丸石・方解石・安山岩）。空気か草花の所にだけ置く |
| 量 | 消すブロックは16〜700。多すぎれば浅くして作り直す。ゲーム内では 190〜290 だった |
| 音 | `peak_scrape`（約12秒）。削り始めに頂から鳴り、360ブロックまで届く（320で聞こえなくなる線形の減衰）。近くでは方解石の砕けた粒が舞う |
| 負荷 | 候補探しは通過1回に一度。安全の確かめは1tickに候補1つ。削るのは1tickに48ブロックまで（10tick前後で終わる） |
| 記録 | 削り跡を64か所まで覚える（`/skyabyss scar list`）。前の跡から64以内は削らない |

### 4.3 プレイヤーの建築を壊さないための安全策

最優先の決まり（ブレない軸3）。疑わしいときは削らない。

| # | 安全策 | 内容 |
| --- | --- | --- |
| 1 | 消すのは自然の地形だけ | 石・花崗岩・閃緑岩・安山岩・凝灰岩・深層岩・方解石・土・草・粗い土・ポドゾル・根付いた土・雪・粉雪・砂利・氷塊・鉱石と、草・シダ・枯れ木・小さな花・雪の層だけ。タグではなく名前の一覧で決める（他の Mod がタグに建材を足しても入らない） |
| 2 | 周りに人の手がないこと | 削る範囲（溝と岩の先まで）から横に16、切り口の下12〜各列の一番上の何か（WORLD_SURFACE）まで、全ブロックを調べる。上の一覧と、空気・水・溶岩・氷・青氷・つた・ヒカリゴケ・スイートベリー・苔のじゅうたん・自然の葉（persistent でない）以外が一つでもあれば削らない。松明・作業台・ベッド・板材・丸石・石レンガ・ガラス・柵・扉・はしご・羊毛・耕地・土の道・はいだ原木などはすべてここで弾く |
| 3 | 原木は自然の木だけ | 原木は、幹をたどった一番上のまわりに自然の葉が3つ以上あるときだけ「自然の木」として周りにあってよい。プレイヤーは persistent でない葉を置けないので、原木だけの柱や小屋は弾かれる。削る所そのものに木があれば削らない |
| 4 | 持ち物がないこと | 範囲のブロックエンティティ（チェスト・看板・かまど等）、生き物でないエンティティ（防具立て・額縁・絵・ボート・トロッコ）、飼いならした・名前の付いた・消えない設定の・リードでつないだ・乗り物になっている生き物、観戦モード以外のプレイヤーがいれば削らない |
| 5 | プレイヤーが置いた・掘った所でないこと | プレイヤーがブロックを置いたチャンク（`BlockEvent.EntityPlaceEvent`。ベッド・扉の `EntityMultiPlaceEvent`、他の Mod の FakePlayer も含む）と、固いブロックを掘ったチャンク（`BreakEvent`。草花・雪の層など歩くだけで壊れるものは数えない。山をくり抜いた住まいのため）を、この Mod が入ってからずっと記録する（`ChapterSkyData`、オーバーワールドの data に保存）。外の範囲（横に40）にかかるチャンクに一つでもあれば削らない。`/setblock`・`/fill` で置いたものは記録されない（形と周りの判定で拾う） |
| 6 | 長く過ごした所でないこと | 外の範囲にかかるチャンクの InhabitedTime（近くにプレイヤーがいた時間）が1時間（72000tick）を超えていれば削らない。Mod を入れる前からあった古いチャンク（置いた記録がない）は **5分（6000tick）** で削らない。新しく生成されたチャンクには `skyabyss:fresh_chunk` の印（チャンクと一緒に保存）を付けて見分ける |
| 6b | 人が積んだ形がないこと | 自然のブロック（石・土・草）だけでも、自然の地形では出ない形があれば削らない（`PeakScar.builtShape`）。調べるのは 2 と同じ範囲：草ブロックの上に固いブロック（草は上がふさがると土に変わり、生成では草の上に何も積まれない）／草ブロックのすぐ下が空き（3段以内に床があるときだけ数える。宙に浮いた草・張り出しの縁は自然にある）／四方が空きの細い柱4段（塔・足場）／両側が空きの厚さ1の壁 縦3×横3（小屋の壁・塀）／上が平らな4×4で四方の側面が3段切り立つ箱・台／雪以外の同じブロックの平らな床 7×7／砂漠・荒野・浜の地表の草や土（運び込まれた土）。しきい値は、生成された本物の山（石の峰・尖った峰・凍った峰、15区画・39の計画）で一度も当たらない大きさにした。柱3段・厚さ1の壁 縦2・平らな面 5×5〜6×6・まっすぐな垂直の面・宙に浮いた薄い板は、自然の山でもよく当たったので使わない |
| 6c | さらに外にも人の気配がないこと | 削る範囲から横に **40** まで、峰の高さ（切り口の下15より上）にある地表を見る。地表のすぐ上にブロックの光（松明・ランタン・ジャック・オ・ランタン・光る石など。溶岩やヒカリゴケの光でも、安全側で削らない）があるか、地表から4段に自然でないブロックがあれば削らない |
| 7 | 人のいる・いた所から離れていること | ワールドの初期スポーンから160、だれかの復活地点（ベッド・アンカー。ログイン・ログアウト・設定のたびに覚えるので、ログアウト中の人の分も）から128、観戦モード以外のプレイヤーから24ブロック以内は削らない |
| 8 | 構造物・水に触れないこと | 村や遺跡などの構造物の部品にかかれば削らない。消すブロックの周り2ブロックに水か溶岩があれば削らない（流れ込ませない） |
| 9 | 読み込みを起こさない | 範囲のチャンクがすべて読み込み済みのときだけ調べる |
| 10 | 削る最中も確かめる | 一つずつ「計画したときと同じブロックか」を確かめ、違えば（だれかが置いた・掘った）そこで止める。近くへの更新は起こさない（砂が落ちる・水が流れる・物が壊れて落ちる、をしない）。物は落とさない |
| 11 | 切れる | `peakScarChance` を0にするか、`horrorEventFrequency` を0にする |

残る危険: 石や土だけで積んだもののうち、上の形のどれにも当たらない小さなもの（草が土に変わったあとの 2×2 の土の山、高さ3までの柱、6×6 までの台など）が、Mod を入れる前に置かれ、周り40ブロックに光も人工物もなく、プレイヤーがその近くで5分も過ごしていない場合だけは、削られうる。Mod を入れたあとに置いたものは、置いたチャンクの記録で必ず避ける。

### 4.4 雲の切れ間の巨大な目

**見え方。** 月が近い夜、ふと音楽と動物の声が止み、雲の上の深い気配が低く鳴りはじめる。視界の端の雲が集まり、2.5秒かけて上下に割れて、雲の奥に月のように白い瞳が開く。瞳ははじめ地上を探すように動き、やがてこちらを向く。見つめると、その瞬間に気配の音がすっと消え（雨音も止む）、静けさの中で目は閉じる。見ないでいると、数秒で閉じて雲が引く。攻撃しない、近づかない、大きな音を出さない。

| 項目 | 値 |
| --- | --- |
| 条件 | 1章に入っている、月の近さ0.5以上（仮の値では各ループの4〜7日目）、夜（一日の14000〜22000）、雷雨でない、屋外（頭上に空）、起きている、生きている、観戦モードでない |
| 確率 | 条件がそろっている間、1秒ごとに1/300（平均5分。一晩でおよそ74%） |
| 間隔 | 開いたら2〜3日空ける（月が近いほど最大2割短く）。見逃したら1日後にもう一度（続けて1回まで）。打ち切り（屋内に入ったなど）なら1分後から。日数は `horrorEventFrequency × cloudEyeFrequency` で割る |
| 見せる相手 | 本人の画面だけ（パケットで一人に送り、クライアントの中だけで描く） |
| 置く所 | 今見ている向きから左右に外した向き（段階0で60〜110度）、見上げる角度34〜60度の「方向」（天体と同じく距離を持たない。歩いても飛んでも空の同じ所にある）。雲の層の上や中（雲まで46ブロック未満）では開かない。月の通り道（東西）と重なりにくい側を選ぶ |
| 流れ（tick） | 気配30（音楽・動物・環境音が止み、雲が集まる）→開く50→開いたまま50〜90→閉じる45（視線が合ったときは、こちらを見たまま24待ってから30で閉じる）→雲が引く40。全体で約11秒 |
| 視線が合う | 目が3分の1以上開いていて、遮るものがなく、瞳のあたり（目の幅の15%、最低5度。段階0で6度）以内に0.4秒 |
| 見た | 画面の中に0.5秒入った（開いている間） |
| 音 | `sky_eye_presence`（8秒のループ）。目の方向から聞こえるが距離では小さくならない。最大0.5（`cloudEyeIntensity` を掛ける）。視線が合うとすぐ消える。合ったあと15秒は、音楽・動物の声・環境音を止めたままにする |
| 大きさ | 視野の角度で決める。段階0〜2で目の幅40・48・55度（段階の幅44・52・60 × 0.92）。画面の横のおよそ3〜4割。瞳だけで月の3倍以上。まわりの雲のかたまりはその2.2倍に広がるが、目そのものは切れ間からしか見えない |
| ジャンプスケアにしない | 急に開かない（気配1.5秒＋開くのに2.5秒）、視界の真ん中には開かない、大きな音を出さない、顔を出さない。視線が合うと「止む」ほうで怖がらせる |

**段階**（見た回数：0／1〜2／3以上。月の近さ0.85以上で一段進む）

| 段階 | 幅 | 開いたまま | 見上げる角度 | 左右に外す角度 | 瞳がこちらを向く |
| --- | --- | --- | --- | --- | --- |
| 0 | 44 | 50tick | 46〜60度 | 60〜110度 | 開いている時間の後半 |
| 1 | 52 | 70tick | 40〜55度 | 45〜95度 | 後半 |
| 2 | 60 | 90tick | 34〜50度 | 35〜80度 | すぐ（2割の時点） |

**見た目（採用: B 月蝕の瞳、描画 v2）。** 白目は雲の奥の青灰の暗がりで、瞳の近くだけ金の光が筋になって滲む。瞳は月のように白い円で、黒い瞳孔のまわりに金の細い輪。一目では月か雲の切れ間の光に見え、瞳が動いてこちらを向いたとき初めて「目だ」と分かる（見せない恐怖）。本物の月の横に開くと「月が二つ」になる。巡礼者の金と白に合い、白目が暗いので夜に輪郭線が出ない。選ばれなかった案: A 金環の瞳（はじめから目と読めて絵の紋章のよう）、C 縦の瞳孔（猫や爬虫類の「怪物」に寄る）。

- 描画（シェーダーなし）: 空を描いた直後（`AFTER_SKY`）に、こちらを向いた板を重ねる。バニラの雲・地形はそのあとで描かれるので必ず手前を流れ、目を切る（「雲の向こうにいる」。バニラの雲より手前に描く案は前後が分かりにくく、幅1.15倍の案は段階2で69度になり画面の大半を占めるため退けた）。
- 層: ①顔（目のまわりの皮膚と羽毛、閉じた瞼。`face.png` 192×112、羽毛は目から外へ流れる鱗の重なりで、雲の切れ間のすぐ外で透けて消える。閉じた瞼は周りより少し暗い皮膚で、真ん中に細い合わせ目）②白目と③瞳（瞼の間のアーモンド形の切れ間にだけ、縦の帯48本で切り取って貼る）④瞼の縁の影 ⑤空気の霞（青灰。目の色を空気の色に4割寄せ、上から霞を0.5重ねる。瞳の白も最大0.72まで）⑥雲のかたまり ⑦割れた雲の内側の縁の明るみ（青灰）。
- 雲のかたまり: 26本の柱（バニラの雲の一マスに近い幅）で、柱ごとに割れる時がずれ（最大35%遅れ）、縁は段々（0.028W刻み。W＝目の幅）。切れ間は目より短く（半分の長さ0.41W）、中心を横に0.06〜0.1Wずらし、片方の目尻は必ず雲に隠れる。色は夜の雲の色の0.8倍、濃さ0.8。
- 動き: 瞳の探す速さ0.018、こちらを向く速さ0.025（合ったとき0.09）。重い瞼（開くとき最初の0.4秒は動かず、閉じるのは残りが小さいほど遅い）。開いている時間が70tick以上の段階（1・2）では、途中で一度だけ6割まで下りる重い瞬き（下り1.1秒、戻り1.5秒）。

### 4.5 設定とコマンド

| 種類 | 名前 | 範囲・既定 | 内容 |
| --- | --- | --- | --- |
| サーバー | peakScarChance | 0〜1、0.6 | 通過1回で山頂を削る確率。0で削らない |
| サーバー | cloudEyeFrequency | 0〜3、1 | 雲の目の頻度の倍率。0で開かない。horrorEventFrequency にも掛かる |
| クライアント | cloudEyeVisible | true | 自分の画面に雲の目を出すか。false ならサーバーに「見せない設定」と知らせる（間隔はそのまま） |
| クライアント | cloudEyeIntensity | 0.3〜1、1 | 雲の目の光と音の強さ |

テスト用コマンド（OP）:

- `/skyabyss scar check`：見ている向きの前後96ブロックの峰を探し、削れるか・削れない理由を出す（削らない）
- `/skyabyss scar here`：そのうち最初に安全だった峰を今すぐ削る。確率と1章の条件は問わない。安全の確かめは同じで、近くの人の距離だけ24→8に緩める
- `/skyabyss scar list`：削り跡の一覧
- `/skyabyss eye show [player]`：今すぐ雲の目を開く（夜・月・1章・屋外を問わない）。向きと見上げる角度も出す（`/tp @s ~ ~ ~ <向き> <-角度>` で向ける）
- `/skyabyss eye next [player]`／`eye reset [player]`：次に開きうるまでの秒数・見た回数・今開けない理由／記録を消す
- `/skyabyss moon`／`moon set <0〜1>`／`moon clear`：月の近さを見る／固定する／戻す
- `/skyabyss chapter1 [player]`／`chapter1 set <player> <true|false>`：1章に入っているか／「巨神の背に乗った」を変える
- 撮影用: `-Dskyabyss.eyeHold=true`（`JAVA_TOOL_OPTIONS` で渡す）で、目が開いたまま閉じない

### 4.6 マルチプレイ

- 削られた山頂はワールドの出来事。音は360ブロック以内の全員に届く。目撃者が1章でなければ起きない。どのプレイヤーからも24ブロック以内（範囲の中にいればもっと遠くても）では削らない
- 雲の目は一人ずつ。見せる人にだけ送り、ほかの人には見えない（隣にいる仲間は何も見ていない）。記録（次の時刻、見た回数、1章の印、復活地点）は人ごとにオーバーワールドへ保存する
- クライアントからの「どう閉じたか」は、今開いている目の番号と合うときだけ受け付ける。改造したクライアントが送っても、自分の段階と間隔が変わるだけ

## 6. 既知の問題・制限

- 見る者: 夜の暗さでは、遠くの体は草地と同じくらいに沈み、手がかりは目の縦の点になる（意図どおり）。横へ歩いて頭が追う様子と、稜線に立ったときの影の形は、開けた平地でもう一度見たい。耳鳴り・肩掛けの揺れ・音の大きさはゲーム内で聴いていない。
- 雲の目: 夕方・明け方に近い明るい雲の色での見え方、Iris＋シェーダーでの見え方（`AFTER_SKY` に重ねた板が消える・空に負ける恐れ）、雲の設定がオフのとき（自前の雲のかたまりだけになる）は未確認。気配の音の大きさも聴いていない。
- 削られた山頂: 4.3 節末の「残る危険」。凍った峰の平らな面・蜂の巣などは安全側で削らない。
