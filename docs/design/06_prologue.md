## 2. 空の影（実装済みの仕様）

### 2.1 発生

| 項目 | 値 |
| --- | --- |
| 間隔 | 2〜4日（ゲーム内の時間。ホラー演出の頻度の倍率で割る） |
| 条件 | オーバーワールドが昼で雨が降っていない。生きていて観戦モードでない、空の見えるプレイヤーが一人でもいる |
| 条件が合わないとき | 1分後にもう一度調べる |
| 場所 | 条件の合うプレイヤーから無作為に一人を選び、その人の近くを通す |
| 数 | オーバーワールド全体で同時に1つ |

### 2.2 通過の形

| 項目 | 値 |
| --- | --- |
| 進路 | 無作為な向き。選んだプレイヤーの220ブロック手前から、真上から最大30ブロック横へずれた線を通る |
| 速さ | 0.35ブロック/tick。通過全体で約1257tick（約63秒） |
| 影の形 | 胴体・首・頭・細くなる尾と、胴につながった左右の巨大な翼。輪郭までの距離でひと続きに作る |
| 大きさ | 翼を広げきって幅270ブロック前後（片側135）。振り上げると片側85まで細くなる。判定の範囲は中心から165ブロック |
| 羽ばたき | 70tickに1回。影の輪郭は前後5ブロックをぼかす |
| 呼び声 | 通過の38%と62%の時点で、雲の上から声が降り、雲の中が一瞬光る |
| 空の荒れ | 通過の5%から25%かけて雲が厚くなり、80%から晴れていく |

### 2.3 プレイヤーが受ける演出（クライアント）

各プレイヤーが自分と影との距離で演出を受ける。天気はそのプレイヤーの画面だけが荒れる（サーバーの天気は変えない）。

| 演出 | 内容 |
| --- | --- |
| 地面の影 | 地形に沿ってひと続きに落ちる（濃さ0.6、半径112ブロックの範囲を描く） |
| 雲の切れ間の姿 | 厚い雲の層（バニラの雲の26下、半径320）の切れ間から、暗い姿（バニラの雲の10下）がのぞく |
| 音 | 羽ばたき（影の翼が広がりきる瞬間に音の山が来る）、通過中ずっと続く低い唸り、呼び声。300ブロック以内で聞こえる |
| 天気 | 380ブロック以内で、雨と雷が強まる（雨は荒れ具合の0.7倍まで） |
| 画面の揺れ | 近いほど空気が細かく震え、羽ばたきのたびに揺れる（設定で切れる） |
| 画面効果 | 影の下ほど暗く、縁が暗くなり、霧が迫り、色が冷たい青紫に沈み、羽ばたきに合わせて視野がわずかに狭まる（設定で弱められる） |
| 引き算 | 近くを通る間は、音楽と動物の鳴き声（`*.ambient`、オウム）が止む |

### 2.4 動物（サーバー）

影の下と、80tick先に影が来る場所の動物は、2tickごとに足を止め、空を見上げ、鈍化（強さ6）で動かなくなる。今回、村人（行商人を含む）も同じように怯えるようにした。

### 2.5 設定とコマンド

| 種類 | 名前 | 範囲・既定 | 内容 |
| --- | --- | --- | --- |
| サーバー | horrorEventFrequency | 0〜3、1 | ホラー演出全体の頻度の倍率。0で空の影も見る者も起きない |
| クライアント | screenShake | true | 画面を揺らすか |
| クライアント | screenEffectStrength | 0〜1.5、1 | 影の下の画面効果の強さ |

- `/skyabyss pass [player]`：すぐに通過を起こす（OP）
- `/skyabyss next`：次の通過までの秒数

### 2.6 マルチプレイ

通過はサーバーに一つで、オーバーワールドの全員に送る（途中でログインした人、ネザーなどから戻った人にも送る）。音・天気・画面効果は各自の距離で決まるので、遠くの人には遠くの出来事として届く。

## 3. 見る者

### 3.1 位置付け

夜、一人で外にいると、遠くの丘の上に人が立っていて、こちらを見ている。近づこうとすると、見つめ続けると、目を離すと、いなくなる。攻撃しない、近づいてこない、音で驚かせない。序章の「前触れ」で、正体は明かさない。

見た目は「自分に似た影」（5.2節のラフE。v1 の B「留まる者の影」はゲームの夜でエンダーマンに見えたので作り直した）。プレイヤーと同じ四角い頭が長すぎる首に載って横へ傾き、四角い肩から外套が垂れて足もとまでひと続きになる。背丈は2.1ブロックで、人より少し高いだけ。顔はのっぺりとして、片目の位置にだけ縦の光が一つある。色は夜霧に溶ける青灰。物語の上では、ループを重ねた「留まる者」自身の影（3章の「過去の自分の幻影」への伏線）として読めるようにしてある。プレイヤーに似ているのはそのため。正体をどう扱うかは8章の判断1。

### 3.2 現れる条件

サーバーが1秒ごとに、オーバーワールドの各プレイヤーについて調べる。

| 条件 | 値 |
| --- | --- |
| 時期 | そのプレイヤーの「次に現れうる時刻」を過ぎている（3.5節） |
| 時刻 | 夜（一日の13000〜22800。日没直後の明るさが残るうちと、夜明け前は避ける） |
| 天気 | 雷雨でない（雨はよい） |
| 場所 | 屋外（頭の上に空が見える）、水中でない |
| 状態 | 生きている、観戦モードでない、寝ていない |
| 一人 | 96ブロック以内に、ほかのプレイヤー（観戦モード以外）がいない |
| 確率 | 条件がそろっている間、1秒ごとに1%（平均100秒待つ。夜になった瞬間には出ない） |
| 同時に | 一人につき一体まで |

### 3.3 立ち位置

`prologue/WatcherSpot` が48か所を試し、条件に合う中から一番良い所を選ぶ。

| 項目 | 内容 |
| --- | --- |
| 距離 | 段階で決まる（3.4節）。初めては58〜70ブロック、慣れるほど近く、最も近くて42ブロック |
| 向き | 今見ている向きから左右75度より外（横か後ろ）。気づく前に視界の真ん中へ急に現れないため |
| 地面 | 葉と液体を除く固い地面の上。体の入る3ブロックが空いている |
| 明るさ | ブロックの光が5以下（松明の明かりの中には立たない）。頭の上に空がある |
| 高さ | 目の高さより12ブロック低い所から32ブロック高い所まで |
| 見通し | 目から、見る者の頭（光る目の高さ。足もとから1.95）と胸（1.2）まで、見えるブロックがない（ガラス越しは見える） |
| 選び方 | 背後が空になる場所（稜線に影が浮かぶ）を強く好み（+6）、少し高い所を好む（高さの差×0.5、-4〜+12で頭打ち） |
| 体の向き | こちらを向いて立つ |

### 3.4 段階

見る者に気づいた回数で、少しずつ近く、長く立つようになる。月の近さ（0〜1）が0.5以上になると一段進む（ループと月が入ったときのための入口で、今は常に0）。

| 段階 | 気づいた回数 | 距離 | 見つめて消えるまで | 気づかれないまま消えるまで | 首のかしげ |
| --- | --- | --- | --- | --- | --- |
| 0 | 0 | 58〜70 | 4.0秒 | 120秒 | 6度 |
| 1 | 1〜2 | 50〜64 | 3.5秒 | 140秒 | 10度 |
| 2 | 3以上 | 42〜56 | 3.0秒 | 160秒 | 14度 |

### 3.5 頻度

| 項目 | 値 |
| --- | --- |
| 初めて | そのプレイヤーをこのワールドで初めて見かけてから2〜3日後以降 |
| 次まで | 現れたら3〜5日空ける。月が近いほど最大3割短くなる |
| 気づかれなかったとき | 0.75〜1.25日後にもう一度。続けて2回まで（3回目からは通常の間隔） |
| 倍率 | 日数はすべて「ホラー演出の頻度 × 見る者の頻度」で割る。どちらかが0なら現れない |

日数はゲーム内の経過時間（寝て夜を飛ばした分は数えない）。寝てばかりいる人には現れにくいが、それは「夜に一人でいると」という条件どおりとした。

### 3.6 ふるまいと消え方（クライアント）

人影は見せる相手のクライアントの中にだけ置く（サーバーには存在しない）。ふるまいと消え方もクライアントで決め、終わったらサーバーに「どう消えたか」を知らせる。

| 場面 | ふるまい |
| --- | --- |
| 立った直後 | 音楽が途切れ、動物の鳴き声と洞窟の環境音が止む（引き算の兆し）。敵の音は止めない |
| 3秒後 | 本人から20ブロック以内の動物（最大12匹）が、人影の方を向いて足を止める（気づくための手がかり） |
| 届く前に振り向いていた | もう画面の中なら、闇から3秒かけて浮かび上がる（急に出さない） |
| 気づく（画面の中で、遮るものなく0.3秒見えた） | かすかな耳鳴りが始まる |
| 見ている間 | 頭だけがゆっくりこちらを追う（左右60度まで。越えたら体ごと向き直る）。見下ろす・見上げる角度も追う |
| 見つめる（視線の中心から8度以内） | 首が少しずつかしぎ、目の光が少し強まり、耳鳴りが少し大きくなる |
| 見つめ続ける（段階の秒数） | 体から2秒かけて薄れ、目の光が最後に消える。息をのむような小さな音 |
| 目を離す（画面の外へ・物陰に入る、0.4秒） | その間に音もなく消える。振り向くと、もういない |
| 近づく（最初の距離から16ブロック寄るか、26ブロックより近い） | 0.7秒で薄れて消える（小さな音） |
| 気づかないまま近くへ来た／時間切れ／朝になった／目が見えない | 何もなかったように消える |
| 気づいたまま時間切れ（段階の時間の1.5倍）／朝になった | 見つめ続けたときと同じく薄れる |

攻撃しない、触れない（当たり判定も選択もない）、押せない、保存されない。死なせる・持ち物を奪うことはない。

### 3.7 見た目

| 項目 | 内容 |
| --- | --- |
| モデル | GeckoLib。立方体56個、0.5単位、重なりなし。背丈2.1ブロック（エンダーマンは2.9）。骨は body・hem（裾）・mantle（外套）・head・eyes（光る目）・mist（霧のかけら） |
| 形 | 四角い頭（7単位）が、横へずれていく長い首に載る。四角い肩（13単位）、細い腰、少し広がる裾。外套は左が肘まで、右だけ腿まで垂れ（片腕だけ長く見える）、背の外套も腿まで。腕と脚の隙間は見せない |
| テクスチャ | 256×58、1ブロック=32px。夜霧の青灰（`#252D38`〜`#53606F`）の布で、縦のひだとまだら。裾の下端は淡くほつれる |
| 光るマスク | 目（`#D5E6F6`）、肩と頭の上の面（月明かりの縁）、裾のほつれ。ほかの布にもごくかすかな霧の光（12,15,20）を一様に足し、真っ暗な夜空でも人の形がうっすら残る |

| 遠くの目の光 | 目の立方体の真ん中に、縦長の光のにじみを重ねる（横の半径=距離×0.0032×0.6、縦=×1.8。最小0.03ブロック）。40〜70ブロック先で「縦の白い点」に見え、エンダーマンの横に並んだ2つの紫の点と分かれる。顔がこちらを向いていないときは弱める |
| 消え方 | 体は半透明で描き、薄れて消える。目の光は体より遅れて消える |

| 影 | 足もとの丸い影は出さない |

### 3.8 音

既存の音は使わず、`tools/gen_watcher_sounds.py` で合成した。音量はどちらも環境音（AMBIENT）の音量設定に従う。

| 音 | 内容 | 大きさ |
| --- | --- | --- |
| `watcher_presence`（8秒ループ） | 頭の中で鳴るような耳鳴り（5200Hzが2秒周期でうなる）、その下の細い音、36Hz前後の空気の圧、遠い空気のさざめき | 気づくと数秒かけて0.12まで上がり、見つめるほど0.28まで。消えたら引いていく |
| `watcher_fade`（約2.6秒＋残響） | 息を吸い込むように少しずつ強くなり、ふっと途切れる。奥で細い音が900Hzから610Hzへ下がる。鋭い立ち上がりはない | 見つめて消えたとき0.3、近づいて消えたとき0.45 |

目を離して消えたときは音を鳴らさない（耳鳴りが引いていくだけ）。

### 3.9 マルチプレイ

- 人影は見せる一人にだけパケットで送り、その人のクライアントの中にだけ置く。ほかの人には見えない
- 「一人」の条件（96ブロック以内にほかの人がいない）があるので、二人で歩いている間は現れない
- 記録（次に現れうる時刻、気づいた回数）はプレイヤーごとにオーバーワールドへ保存する（死んでも、入り直しても続く）
- 動物が向きを変えるのはサーバーの動物なので、近くにほかの人がいれば見える（ただし「一人」の条件で、普通は誰もいない）
- クライアントからの「どう消えたか」は、今立っている人影の番号と合うときだけ受け付ける。改造したクライアントが送っても、自分の段階が進むだけ

### 3.10 設定

| 種類 | 名前 | 範囲・既定 | 内容 |
| --- | --- | --- | --- |
| サーバー | watcherFrequency | 0〜3、1 | 見る者の頻度の倍率（0で現れない）。horrorEventFrequency にも掛かる |
| クライアント | watcherVisible | true | 自分の画面に見る者を出すか。false にすると現れず、サーバーには「見せない設定」と知らせる（間隔はそのまま進む） |

### 3.11 テスト用コマンド（OP）

- `/skyabyss watcher show [player]`：今すぐ立たせる。夜・一人・屋外・向きの条件を問わない（立ち位置が見つからなければ、32ブロックより遠い所をどの向きからでも探す）。昼に立たせたものは朝で消えない
- `/skyabyss watcher next [player]`：次に現れうるまでの秒数、気づいた回数、今その人に出せない理由（出せるなら ok）
- `/skyabyss watcher reset [player]`：記録を消す（すぐに現れうる状態、気づいた回数0）

## 4. 影の下の動物と村人

| 項目 | 内容 |
| --- | --- |
| 対象 | 動物（家畜・ペットなど Animal）と村人（行商人を含む） |
| 足を止めて見上げる（サーバー） | 2.4節。今回、村人も対象にした |
| うずくまる（クライアント） | 影の濃さ（今の影と80tick先の影の濃い方）×1.5 に合わせて、体を縦に最大26%縮め、横に8%広げる。身をかがめるのは速く（1tickに差の12%）、起き上がるのはゆっくり（3.5%） |
| 震える | うずくまっている間、横にごく小さく速く揺れる（最大0.012ブロック） |
| 範囲 | 自分から96ブロック以内。影の形はサーバーと同じ計算なので、パケットは要らない |
| 鳴き止む | 2.3節（既存） |

うずくまりは見た目だけで、当たり判定や動きは変えない。ほかの Mod が描画を取り消しても落ちないよう、姿勢の積み重ね（push/pop）を使わずに変形して戻す。

## 5. 見る者のラフと選定

### 5.1 v1：ラフ3案（A・B・C）と B の採用

**v1 でBを選んだ理由**

1. **遠くの人影として一番怖い。** マイクラで一人で遊んでいるとき、遠くに「人」が立っているのが最も不気味。Bは60ブロック先でもすぐ人だと分かり、近づいて確かめたくなる。そして近づけば消える。Aは「頭巾の人物」というキャラクターに見え、Cは光が目立ちすぎて怖さより派手さが出る
2. **夜に溶ける。** ほぼ黒の体で、稜線に立つと空を切り抜いたシルエットになる。光るのは目の2点だけで、01の「見せない恐怖」「目だけかすかに光る」に合う
3. **物語の伏線になる。** 留まる者（主人公）だけがループの記憶を持つ、という核心の謎と、3章の「過去の自分の幻影」に、後からつなげられる。序章では何も説明しない
4. **作りが単純で、差し替えやすい。** 立方体76個、待機の動き1種類

**v1 でBに直したこと（ラフの見直し）**

- 1回目は頭がただの立方体で、体がまだらの点だらけだった。頭を細長くし（あご・頭頂を一段細く）、目を前板の穴の奥に下げて眉の張り出しの影に入れた。体のまだらを減らし、焼けた紙の縁のような細い筋だけを残した
- 胸骨の浮き、なで肩、腿の付け根の太さ、肩から前に垂れる短いぼろを足して、近くで見たときの起伏を作った
- 体の明るい縁取りが強く、近くで見ると格子に見えたので、材質の明るい段を暗くした
- 肩掛けの揺れは、向きの取り違えがあっても体に食い込まないよう、前後に±1.5度だけにした

2. **主人公の謎の伏線になる。** 見る者はループを重ねた留まる者の影という設定（8章の判断1(a)）。プレイヤーと同じ頭の形をしていることで、あとで「あれは自分だった」とつなげられる。序章では何も説明しない
3. **エンダーマンと一目で分かれる。** 背丈2.1（エンダーマン2.9）、青灰の布、縦の光1つ。ゲーム内で並べると、遠くでは「白い縦の点が1つ」と「紫の点が2つ」、望遠鏡や近くでは背丈と頭の形がまるで違う（7.5節）
4. **夜に溶ける。** 青灰の体は真夜中の草地と同じくらいの暗さに沈み、目の光だけが残る

**Eで直したこと（ラフとゲーム内の見直し）**

- 首が細い棒で、四角い頭と合わせて人形やロボットに見えた。首を3単位の太さの布にし、外套のえりで付け根を巻いた
- 胴が一枚の板に見えたので、腰を細くし、裾を少し広げた。外套は左を肘まで、右だけ腿まで垂らし（片腕だけ長く見える）、背にも腿までの外套を足した
- 右の目を暗い穴にしていたら、近くで見ると「目が2つの顔」になり、かわいく見えた。片目の光だけを残し、もう片方の目も口もなくした
- 布全体にかすかな霧の光を足すと、比較シートでは全身が光って見えた（シートのにじみのせい）。シートのにじみは目だけにし、ゲームの霧の光は一様に弱く（12,15,20）した。明るい画素だけに足す案は、ひだのまだらが点々と光ったのでやめた
- 光る目を eyes 骨の小さな立方体にした（目の光のにじみの位置を、この立方体から取るため。7.5節）

### 5.3 案を差し替えるとき

`tools/rough/watcher_v2.py` の `CHOSEN` を `"d"` か `"f"` にして `python tools/rough/watcher_v2.py --install` を実行する（`watcher.py --install` も同じものを書き出す）。geo・テクスチャ・光るマスク・目の光のにじみ・動き（その案にある骨の分だけ）が書き換わる。目の光の位置は geo の `eyes` 骨の立方体（なければ骨の支点）から読むので、Java は変えなくてよい。ただし D と F の目は顔に塗っただけで `eyes` 骨に立方体がないので、差し替えるなら E と同じく目を立方体にする。v1 の A・B・C は `watcher.py` に残してある。

## 8. 判断が要る点

| # | 点 | 選択肢 | 推奨 |
