## 1. ねらい

天の鍵の欠片や心核のように「なくすと困る品」の在りかと取り戻し方、巨神の記憶（天井）、図鑑、技の点、好感度を、コマンドの文字ではなくゲームの中の一冊の「控え帳」にまとめる。本人はいつでも、管理者はテスト用コマンドのあとすぐ確かめられる。

## 2. 開き方

| 開き方 | 誰が | 中身 |
| --- | --- | --- |
| **B キー**（既定。キー設定で変えられる） | 本人 | 自分の控え帳 |
| `/skyrecord [つまみ]` | 誰でも | 自分の控え帳。つまみは `keepsakes`・`titans`・`growth`・`bonds` |
| `/skyabyss inspect <人> [つまみ]` | 管理者（権限 2） | ほかの人の控え帳（受け取りのボタンは出さない） |
| `/titanmemory`・`/growth` のあと | 本人 | チャットに「控え帳で見る」のリンクが一行付く |

- B にした理由: この Mod の J（ステータス）・K（技）・U（クエスト）・R/G/V/Z（技の枠）・O（パーティ）・H（護符）と、バニラの既定キーにぶつからない。
- コマンドを `/skyabyss me` にせず `/skyrecord` にした理由: `/skyabyss` は他のテスト用コマンドがすべて管理者向けとして登録しており、根元を誰でも使えるようにするとそれらの見え方が変わるため。

鯨骨の枠に一枚の羊皮紙。上につまみ 4 つ、左に行の一覧、右に選んだ行の詳しい頁。32px 密度、碑文の青緑、伝承の書と同じ墨の色。

### 3.1 巨神のつまみ（4 体ぶん）

つまみの下に小さなつまみを並べる。「一覧」と、巨神の順（`progress.Titans.all()`、岩鯨・潮殻・雷翼・余燼）の頁。巨神が増えれば頁も自動で増える。

| 頁 | 中身 |
| --- | --- |
| 一覧 | 止めた心臓（段階 n / 4 とレベルの上限）、巨神ごとに一行（絵＝心核、なければその巨神の素材。値＝「止めた（n 回）」「挑める（推奨 Lv n）」「まだ現れない」「まだ見ぬ巨神」）、巨神の旅（乗せてくれる巨神、覚えた碑、運ばれた回数、次に呼べるまで） |
| 巨神ごと | 先頭に**備え**の行（身・刃・糧の三灯。9 章）、続けて**この章の進み**（9.4）。**試練の石**の行（石のある巨神だけ。自分が鳴らした数・仲間が鳴らした数・まだの数、石ごとに「あなたが鳴らした／○○ が鳴らした／まだ」。10 の 10.9）。巨神の記憶（天井の帯）・撃破の回数・図鑑（持っている／まだ。表の順、専用伝説は持つまで伏せ字）・欠片の受け取り・交換した回数・その巨神の旅（呼び笛の有無）。**倒れた回数の札**の行（心臓・中ボスそれぞれの、勝った戦いの倒れた回数の最良と札の名前。まだなら「まだ勝っていない」。10 の 10.14。札は見た目だけ） |
| まだ見ぬ巨神 | つまみの名前も「？」。頁は枠と伏せ字だけ（名前・図鑑の数を漏らさない） |
| 順番は来たが本体がない（ベータの雷翼・余燼） | 名前と推奨 Lv、「まだ現れない」（備えの行は出る） |

- 頁の中身は `record/TitanPages`。登録のある巨神だけ図鑑を出す。岩鯨は `TitanLoot`、潮殻は装備の表（`TitanGearSets`）から作る（`TitanPages.fromGearSet`）。後の巨神は、本体（心臓）ができたら起動時に `TitanPages.register(TitanPages.fromGearSet(巨神))` を呼ぶ。

### 3.2 管理者の「変わった値」

管理者が `/skyabyss …` を実行すると、その前後でオンラインの全員の控え帳を比べ、変わった行をチャットに出す（例: 「控え帳の変化: Dev ［控え帳で見る］／成長 › 経験値: 534 / 1247 → 1134 / 1247」）。マナと「次に呼べるまで」のように時間で勝手に動く値は数えない。一度に 10 行まで、残りは「ほか n 件」。

## 4. 大事な品の守り

地面に落ちた守りの品（欠片・鍵）は、持ち主の画面でだけ水色に光る（17 の 2.3 の発光。ほかの人の画面では普通の落とし物）。

### 4.1 既存の仕組みとの分担と、足した守り

| 既存の仕組み | 扱い |
| --- | --- |
| 伝承の書は、なくしても次の項目で荷物に戻る（05） | 守りを足さない。画面には在りかと戻り方だけ出す |
| 背中の島で倒れると持ち物は預かられる（02 の 7.2） | そのまま。画面の「背中で倒れたときの預かり」に数える |
| 倒れていた人・持ち物がいっぱいの人の報酬は預かる（02 の 6 章） | そのまま。在りかの「報酬の預かり」に数え、画面から受け取れる |

足した守り（天の鍵の欠片・岩鯨の心核・呼び笛。潮殻の呼び貝も同じ）:

1. 地面に落ちても時間で消えない、燃えない、爆発やサボテンで壊れない。
2. 奈落へ落ちたら、消える前に持ち主の持ち物へ戻す。持ち主が倒れている・いないときは報酬の預かりへ入れる。
3. 落ちている場所を控える（`DropLedger`、オーバーワールドに保存）。読み込まれていない所にあっても、画面に座標を出す。
4. **守る品（天の鍵の欠片・天の鍵・心核・呼び笛 / 呼び貝）は投げ捨てられない**（Q キーや画面の外へ投げると拒んで戻す。クリエイティブは別）。**旅嚢（[22](22_mod_pouch.md)）に入った守る品は、そもそも投げ捨て・箱・渡しの手段がなく（取り出し不可。ゲームルール `skyabyssPouchWithdraw` が 0）、倒れても残る**ので、この守りは旅嚢に入りきらなかった品（上限・掃除前の 1 秒）の備えになる。人に渡すのは、旅嚢の外にある品だけ箱を通す。
   - 拒むのは、投げた人が付いている品（自分で投げたもの）だけ。`/give` は拾う動きを見せるため品を「投げた」扱いで落とすので、それを拒むと品が 1 つ増える。入りきらず足もとへ出る品も拒まない（拒むと消えるため）。

倒れたとき、大事な品は**持ち物に残る**（どの型でも。6 章）。1〜3 の守りは、残らない失い方（人に渡した、箱で忘れた、溶岩、投げた）のために残してある。

### 4.2 欠片と天の鍵を持ち主に結ぶ（`record/KeepsakeBonds`・`BondData`）

4.1 の守りで防げない失い方（溶岩・他人の箱・壊したシュルカー箱など）でも、**一人一つを壊さずに**戻す。欠片はどの巨神のものも同じ品なので、「誰の・何代目の」品かを品に書いて見分ける。

| 仕組み | 決めたこと |
| --- | --- |
| 結ぶ | 持ち物とエンダーチェストにある欠片・天の鍵に、持ち主と「代」を書く（1 秒ごと。心臓・コマンドで渡った品も） |
| 帰る | ほかの人の持ち物に入った品は、持ち主の手もとへ帰る（いなければ報酬の預かりへ）。渡しても意味がない |
| 箱 | 箱を閉じたとき、中の品を数えて在りかを控える（控え帳に「箱の中 (x, y, z)」）。しまって忘れても、なくしたことにならない |
| なくした | 受け取った数（巨神ごとの欠片の記録の数。鍵にしたあとは欠片 0・鍵 1）より、在りかの分かる品が少ない。**数で見る**ので、4 つのうち 1 つだけなくしても気づく |
| 戻り方 1 | その巨神の心臓をもう一度倒す（撃破の記録が増えたのを見て、鼓動のそばで再び見つかる）。どの巨神も同じ（巨神ごとに書く行は要らない） |
| 戻り方 2 | 控え帳の欠片・天の鍵の行の「呼び戻す」。代償と待ちはない（未決） |
| 一人一つ | どちらの戻り方も代を一つ進め、手もとの品は新しい代に書き直し、足りない分だけ渡す。前の代の品は、見つかった所（持ち物・箱を開けたとき・地面に出たとき）で砂になって崩れる。同時に二つにはならない |

天の鍵をそろえる場面（14 の 3 章）は段階 4 と欠片 4 つの両方を見るので、この数え方と食い違わない。

### 4.3 在りかの数え方

持ち物（防具・左手・つかんでいる品を含む）、持ち物の袋や箱の中（一段）、エンダーチェスト（中の箱も一段）、**ほかの仕組みの枠**、報酬の預かり、背中で倒れたときの預かり、地面。前の四つを「手もと」とする。

天の鍵がそろう条件（段階 4 と欠片 4 つ。14 の 4）も、この「手もと」の数え方で欠片を数える（エンダーチェストや箱・袋の中、枠に入れたままでもそろう）。そろうときは同じ範囲（持ち物 → 袋・箱 → エンダーチェスト → 枠）から 4 つ取り除く（`Keepsakes.take`。枠は `Holder.take` を実装したときだけ取り出せる）。会話の最中と戦いの直後（5 秒）は、そろっても場面を出さず、終わってから組む。

**装飾品の枠への備え**: 装飾品の専用スロット（`skyabyss:accessories`）は、起動時に次の一行を呼べば在りかに「装飾の枠 ×n」と並び、手もとに数えられる（文 `skyabyss_record.d.place_accessory` は用意済み）。

```java
Keepsakes.registerHolder("accessory", (player, item) -> /* その枠にある item の数 */);
```

## 5. 自己テスト（`SKYABYSS_SELFTEST=1`、`SELFTEST record PASSED`）

- 中身の符号化、在りかの数え方（持ち物・袋・エンダーチェスト・預かり・背中の預かり・ほかの枠）、変わった値の見つけ方、見てよい人の決まり。
- 落ちた品の守り（消えない・燃えない・奈落から戻る・控え）、投げ捨ての拒み、`/give` で増えない。
- 巨神のつまみが一覧 + 4 頁、まだ見ぬ巨神の名前が漏れない、大事な品に巨神ごとの欠片・鍵・呼び笛の行。
- 欠片が他人から帰る、箱が在りかになる、呼び戻し、前の代が箱を開けたとき崩れる、前の代は地面に出られない、心臓をもう一度倒すと足りない分だけ戻る、鍵にしたあとは鍵を見る。
- 倒れたときと墓（`SELFTEST grave PASSED`）: 型ごとの死（grave・vanilla・keep・ledger・keepInventory）、大事な品がどの型でも手もとに残る、墓の中身がちょうど、二つにならない・消えない、持ち主だけが開ける・ゲームルールで誰でも、持ち物がいっぱいのとき墓に残る、複数の墓と救い（いちばん古い墓・墓の選択（一覧は古い順・選んだ墓だけ救う・開いていなければ／人の墓／もうない墓／0% は断る）・割合・預かりへ・0% で無効・会話から）、奈落・溶岩・壁・水・穴・宙づりの死（墓はブロックを壊さず置き換えない・置ける所がなければ預かりへ・仕掛けの床と戦いの部屋は避ける）、耐久の減り（0・100%）、装備を残さない設定、時間で崩れる・壊すと落ちる・控えのない墓が消える、背中の死は変わらない、控え帳の「墓」の行、日英の文。
- ゲーム画面で確かめたのは B キー、4 つのつまみ、`/skyabyss inspect`、「変わった値」、欠片を投げると拒まれる、`/give` で 1 つだけ入る。巨神 4 体ぶんのつまみと欠片の結び付きはゲーム画面では見ていない。

## 6. 倒れたとき（墓）

巨神の背中の外（地上・ネザー・エンドなど）で倒れたときの持ち物と経験値の扱い。背中の死は 02 の 7 章のまま（持ち物と経験値を預かり、休み場から再開。ここは何もしない）。ベータの感想「全ロスは萎える。取りに行くのも面倒で離脱されたくない」への答えで、選んだ案は「装備は残し、残りは消えない墓」（Core Keeper・Valheim 型。比較は `docs/review/death_penalty_options.md`）。実装は `jp.revati.skyabyss.grave`（`DeathRules`・`DeathEvents`・`Graves`・`GraveData`・`GraveBlock`・`GraveRescue`）。絵とモデルと会話は `tools/gen_grave_assets.py`。

### 6.1 型とゲームルール

| ゲームルール | 値 | 既定 |
| --- | --- | --- |
| `skyabyssDeathMode` | 0 `grave`（墓）／1 `vanilla`（バニラのとおり散らばる）／2 `keep`（全部残る）／3 `ledger`（全部残る。耐久の減りだけが代償） | 0 |
| `skyabyssGraveKeepGear` | `grave` のとき、装備中の防具・左手・装飾品・ホットバーを持って復活する | true |
| `skyabyssGraveOwnerOnly` | 墓を持ち主だけが開けられる。false なら誰でも | true |
| `skyabyssGraveExpire` | 墓が崩れるまでの分。0 = 消えない。崩れるときは中身が足もとに散らばる | 0 |
| `skyabyssGraveRescue` | 語り部の救いで戻る割合（%、0〜100）。0 で救いなし | 50 |
| `skyabyssDeathDurability` | `grave`・`keep`・`ledger` で、残した品の耐久が減る割合（%） | 10 |

- ゲームルールは整数と真偽しか持てないので、型は番号。範囲外の番号は `grave` に読む。
- バニラの `keepInventory` が true なら、これらより優先してバニラのとおり（全部残り、経験値も残る。耐久は減らない）。
- 型の切り替えは、背中の外の死だけに効く。

### 6.2 持ち物の分け方

倒れた瞬間（`LivingDeathEvent` の最後。ほかの仕組みが死を取り消したときは動かない）に、持ち物を「持って復活する分」と「墓へ入れる分」に分ける。持って復活する分は、預かり（`PlayerPersisted` の `skyabyss_death_keep`。枠の並びのまま）に入れて持ち物から外し、新しい体（`PlayerEvent.Clone`）へ同じ枠に戻す。墓へ入れる分も持ち物から外すので、バニラの散らかしは何も散らかさず、経験値の玉も落ちない。

| 型 | 持って復活する | 墓へ | 経験値 |
| --- | --- | --- | --- |
| `grave`（装備を残す） | 大事な品、装備中の防具、左手、ホットバー（0〜8）、装飾品の枠 | 残りの持ち物（主な持ち物の 27 枠） | バニラが玉で落とす量（レベル × 7、最大 100）を墓へ。玉は落とさない |
| `grave`（装備を残さない設定） | 大事な品だけ | 残り全部（装備・装飾品も） | 同上 |
| `vanilla` | 大事な品だけ | なし（残りはバニラのとおり散らばる。消滅の呪いもバニラが消す） | バニラのとおり |
| `keep`・`ledger` | 全部 | なし | 全部残る（レベルも）。玉は落とさない |

- **大事な品は、どの型でも手もとに残る**（旅嚢に入った品は旅嚢が守り、旅嚢の外の品は持ち物に残る）（`Keepsakes.guarded`: 天の鍵の欠片・天の鍵・巨神ごとの心核・呼び笛・呼び貝）。これで 00 の 88「倒れたとき大事な品を残すか」は「全部残す」で決まり。袋やシュルカーボックスの中の品は、その袋ごとに分ける（袋が墓へ行けば中の品も墓へ行く。欠片は `KeepsakeBonds` が持ち主に結んでいるので、墓から出ても一人一つは崩れない）。伝承の書は 05 の仕組み（次の項目で戻る）のまま。
- `grave` の消滅の呪いの品は、バニラと同じく消える（墓へ入れない）。`keep`・`ledger` ではバニラの `keepInventory` と同じく残る。
- 耐久: 残した品のうち耐久のある物が、最大耐久の `skyabyssDeathDurability`% ぶん減る（最低 1。壊れる手前（残り 1）で止める。壊れない品は減らない）。装飾品と墓の中の品は減らない。
- 持ち物の画面のカーソルでつかんでいた品や、クラフト枠の品は、バニラのとおり（死ぬと足もとへ落ちる）。

### 6.3 墓

- 見た目: 苔むした石の積み石（下 12×4×12、中 9×3×9、上 5×2×5）。中の段の四方に、かすかに光る青緑の古い印の板。明るさ 5、ときどき小さな光の粒が昇る。32×32 のテクスチャ 2 枚（`grave_stone`・`grave_glow`）。品としては作れない（持ち物に入らない。クリエイティブでも `/setblock` で置く）。
- **消えない**: `skyabyssGraveExpire` が 0 の間は、時間でも、爆発・液体・ピストンでも消えない。生存モードでは壊せない（クリエイティブで壊した・コマンドで消したときは、中身が足もとに散らばる。失われない）。
- **複数あってよい**: 倒れるたびに一つ立つ。前の墓は消えない（二度目の死でも）。墓ごとに座標と中身が控えられる。
- **中身は控えが持つ**（`GraveData`。オーバーワールドに保存）。ブロックは目印と入口なので、チャンクが読み込まれていなくても、控え帳に座標を出せて、語り部の救いも使える。中身を渡す・救う・落とすときは、必ず控えから消してから渡す（二つにならない）。
- **開ける**: 右クリック。開けてよいのは持ち主（`skyabyssGraveOwnerOnly` が false なら誰でも。クリエイティブの管理者もよい）。中身は持ち物へ移り、経験値は全部渡る。持ち物がいっぱいで入らない品は墓に残る（空にしてからもう一度）。空になった墓は消える。パーティの仲間も、既定では他人の墓を開けられない。
- **見回り**: 墓は 10 秒ごとに自分を確かめる。控えのない墓（救いのあと、チャンクが読み込まれていなかった墓）は消える。時間の設定で期限が来た墓は崩れる。

#### 置き場所

死んだ場所のそばで、**墓を置いてよい所**を、近い順（同じ高さを優先）に探す。**墓はブロックを一つも壊さず、置き換えない**（草・雪・花・水などの上にも置かない。本物の空気のマスだけ）。置いてよい所の条件: 本物の空気で、液体・ブロックエンティティがなく、足もとが固いブロック（仕掛けのブロックや危険な床でない。`CampBlocks.isMechanism`）、溶岩・火のそばでなく、戦いの部屋・試練の足場の中でない（`CampBlocks.inArena`）、ワールドの端と建築高さの内。順番:

1. 死んだ場所の周り（横 8・上下 6）。壁や土の中で倒れたときは、いちばん近い空気の地表。溶岩の中で倒れたときは、溶岩のそばを避けた岸。水の中で倒れたときは岸。
2. 最後に安全だった場所（足が固い地面にあり、液体と火のそばでないとき、1 秒ごとに控える。`skyabyss_last_safe`）の周り（4）。奈落に落ちたとき。
3. 死んだ柱の地表（高さ地図）の周り（8）。宙づりのときは真下の地面。
4. オーバーワールドの世界の初めの場所の周り（16）。エンドの奈落などで、同じ世界に置けないとき。
5. どこにも置けなければ墓は作らない（ブロックは決して壊さない）。品と経験値は報酬の預かり（`TitanMemoryData` の `pending`）へ入り、控え帳で受け取れる。復活したとき WARN で知らせる（`skyabyss_grave.no_spot`）。

### 6.4 語り部の救い

取りに行けない墓（遠い、危険、見つからない）のために、語り部（`skyabyss:storyteller`）の話題に「なくしたものがある。」を足した（`data/skyabyss/dialogue/storyteller_aa_grave.json`。語り部の足し書き）。中の選択肢は「取りに行けない墓がある。」（**自分の墓があるとき**だけ。条件 `grave`）と、二章以降の「潮見の貝をなくしてしまった。」（08 の 2.8節）。話題の枠は 13 までなので、二つを一つの話題にまとめてある（入口は、どちらかの条件が合うときだけ出る）。

1. 話題から「取りに行けない墓がある。」を選ぶと、語り部が決まりを話す（どの墓かは自分で選ぶ・一つずつ・決まった分だけ戻り、残りは土に還り、墓は消える）。「お願いする」「やめておく」。
2. 「お願いする」で、**墓の一覧の画面**が開く（結果 `grave_choose`。会話はここで終わる）。一覧は古い順に、一行に場所（地上・ネザー・エンドと x, y, z）・品の数・経験値・経った時間（たった今 / 分 / 時間 / 日）と「呼び戻す」を並べる（6 行まで。多いときはホイールで送る。見出しに戻る割合）。選んだ墓を救う（`GraveChooser`、パケット `grave-1`）。中身の `skyabyssGraveRescue`%（既定 50）が戻る。墓は消える（ブロックも控えも）。残りは失う。救ったあと、墓が残っていれば一覧が更新されて開いたまま、なくなれば閉じる。サーバーは、会話から開いて 5 分以内か、自分の墓か、まだあるか、割合が 0 でないかを確かめる（満たさなければ断って一覧を送り直す）。画面なしで一番古い墓を救う結果 `grave_rescue` も残してある。
3. 割合は、墓の品を並べた個数の通し番号で等しく間引く（積み上げた個数 × 割合の差。数は切り捨て。全部で `個数 × % ÷ 100` 個）。経験値も同じ割合。
4. 持ち物に入りきらない分は、**報酬の預かり**へ入れる（`TitanMemoryData`。控え帳の「預かっている報酬」から受け取れる）。消さない。
5. 割合が 0 のワールドでは、話題が出ない（救いなし）。

墓が複数あっても、一回の救いは一つ。何度でも頼める（墓があるかぎり）。控え帳の「墓」の行に、この決まりと割合が書いてある。

## 9. 備えの三灯（`readiness/`。21 の 1.2 の実装）

心臓を止める前に、自分の備えが見える。**乗ることも戦うことも妨げない**（赤でも乗れて、戦える。戦いの中の重みは 21 の 1.3 だけ）。式はクライアントとサーバーのどちらも同じ `Readiness.of(player, titan)`。値の基準は 03 の 5.5（`GearCurve.STAGES`）。

### 9.1 式としきい値

| 灯 | 見るもの | 式 |
| --- | --- | --- |
| 身 | 防具と体力 | 0.6 × min(1.1, (着ている防御 + 強靭) ÷ (その段の防具 +0 の防御 + 強靭)) + 0.4 × min(1.1, 最大体力 ÷ 目安の体力)。防御・強靭・最大体力はプレイヤーの属性（旅装・特性・体力増強が自然に入る） |
| 刃 | 手持ちの武器 | 持ち物（ホットバーとメイン、オフハンド）の中で一番強い武器の 1 秒あたり ÷ その段の武器 +0（`dps0`）。1 秒あたり = (攻撃力の修飾子 + 砥石の上乗せ) × 攻撃速度。番兵長の鉾の噴出は `GearCurve.pikeProc`、水路の顎牙の出血は `fangBleed` で足す。攻撃力の修飾子のない品は数えない |
| 糧 | 持ち物の回復と護り | 回復・吸収の合計（体力の点）÷ 24（12❤ で 1.0）+ 鼓動守を持っていれば 0.2。数える品: 水薬の即時回復（4 << 段）・再生（(50 >> 段) tick に 1 点）・吸収（4 × (段 + 1)）、食べ物の同じ効果（確率を掛ける。金のリンゴは 8 点）。数は個数を掛ける |

- どの灯も最大 1.1 で頭打ち。**色**: 0.9 以上は緑、0.7 以上 0.9 未満は黄、0.7 未満は赤。色だけに頼らず、**形**でも分ける（● 緑、▲ 黄、■ 赤）。
- 目安の体力（❤）: 岩鯨 13、潮殻 15、雷翼 17、余燼 19（`Readiness.goalHearts`）。素の 10❤ は岩鯨で 0.77（身の体力の項）。
- 例: 防具なし・武器なし・回復なしは三つとも赤。ダイヤの防具一式（20 / 8）+ 素の体力は岩鯨で身が 0.91（緑）、余燼で 0.65（赤）。ダイヤの剣（11.2）は岩鯨で刃 0.97（緑）、余燼で赤。一章の旅装（17 / 5）+ 素の体力は岩鯨で身 0.78（黄）。
- **足し込み口**（品が入ってから 1 行で足せる。式は変えない）: `Readiness.registerWhetstone`（砥石。いまの攻撃の上乗せを返す。一章の岩の砥石は `guide/TravelGear` が「効いているか持ち歩いているとき +1.5」で登録済み）、`registerProvision`（効果で表せない糧と薬の 1 個あたりの点）、`registerCharm`（鼓動守。`guide/HeartbeatWard` が「装飾の枠に付けている」で登録済み。持ち物にあるだけでは足さない）、`registerRemedy`（灯が赤・黄のときに「〇〇を作ろう」と出す品の名前。9.2 の 1。`HeartbeatWard` が糧に「鼓動守（職人に頼む）」、`TravelGear` が身に「鯨道の旅装」・刃に「岩の砥石」・糧に「道の固焼き」「苔の軟膏」を登録済み。名前は章で切り替えず、一章の品が出る）。旅装は防御・強靭の属性なので登録なしで身に入り、糧と薬は食べ物・水薬の効果なら登録なしで糧に入る。

### 9.2 見せる所（どれも 18 の `Notice` の枠。チャットに流さない）

1. **控え帳（B）の「備え」の行**: 巨神の頁の先頭（`RecordBuilder.readinessRow`、キー `readiness`）。値は三灯（「身● 刃▲ 糧■」の色つき）、印は一番悪い色（赤＝赤紫の印、黄＝金、緑＝青緑）。右の詳細に、灯ごとに一行（足りない灯は **理由 + 手段**、`ReadinessAdvice`。「■ 刃: 今の武器は目安の 62%。今より強い武器を作るか、共鳴の炉で強化しよう」。身は防具と体力の低い方を言い分ける（「今の防具は目安の 50%」「体力が目安の 70%」）。何も持たないときは「武器を持っていない」「回復の品を持っていない」。手段は**今ある物だけ**を勧める（より良い防具・武器を作る／拾う、共鳴の炉での強化、調理した食べ物・金のリンゴ・水薬、装飾品）。`registerRemedy` に品が登録されると「今より強い武器を作るか、〇〇を用意しよう」「回復の品を持つか、鼓動守を用意しよう」と品の名前に切り替わり、`registerWhetstone` が一つでも登録されると刃は「砥石で鍛えるか、今より強い武器を作ろう」に切り替わる（旅装・砥石・職人が入るまで、その名前は出さない）。体力が低いときは「体力が上がる装飾品や食べ物を探そう」）。足りている灯は「● 身 100%  身は足りている」。さらに、「赤でも乗れるし、戦える」の注記。まだ見ぬ巨神の頁には出さない。ほかの人の控え帳（管理者）では、その人の持ち物から出す。
2. **乗り込みの一言と二度押しの確認**（`BoardReadiness`）: 乗り込み口に触れると、乗る資格のある人の字幕に「備え　身● 刃● 糧●」。赤が一つもなければそのまま乗る（緑・黄のときの一行は 5 秒に一度まで）。**赤が一つでもあれば**一度は乗らず、三灯の一行と、一番低い赤の灯の「理由 + 手段」の一行（字幕。A7）を出し、アクションバーに「このまま乗る？」を出して、**5 秒（100 tick）以内の二度目**で乗る。窓が切れたら一度目からやり直し。別の巨神の確認は引き継がない。確認の待ちの間に灯が整えば（赤が消えれば）そのまま乗る。
   - 岩鯨の鎖（`TitanTravel.startLift`）: 右クリックで乗る口。二度目も右クリック（4 tick 以内の二重の発火は数えない）。
   - 潮殻の潮門・余燼の口（`TitanGate.admit`）と雷翼の昇り風（`GaleColumnEntity`）: 入ると乗る口。一度目のあと、**出て入り直す**のが二度目（入ったままの連続は数えない。途切れが 12 tick 超）。昇り風は持ち上げる前に聞くので、途中で止まらない。
   - 管理者（クリエイティブ・観戦）と、自己テストの偽プレイヤーは確認を挟まない。コマンドの `board` は確認を挟まない（資格の確認だけ）。
3. **心臓の前室（休み場 `heart`）の碑の囁き**（`ReadinessWhisper`）: 前室に初めて入ったとき最初の一度だけ（人ごと・巨神ごと。倒れても残る永続の印）、一番低い灯を一行（「前室の石が、あなたの身を測る。薄い」。黄は「もうひと息」）。全部が緑なら何も言わず、「聞いた」ことにする。碑文の本文は変えない。画面は `Notice.narrate`（字幕）。前室は 4 体それぞれの範囲（岩鯨 `HEART_REST`・潮殻 `HEART_REST`・雷翼 `KEEL_ANTE`・余燼 `HEART_ANTE`）。
4. **扉が閉まる 5 秒の予告の準備確認**（`ReadinessSummary`。A2）: 心臓・番兵長・中ボスの集合（`GroupBossRoom` の 5 秒、`TitanBackTrials` の広間の 5 秒）のあいだ、中にいる人と近く（24 ブロック）のそのグループの人の画面に出す。1 秒ごとにアクションバー「扉が閉まるまで N 秒　備え　身● 刃■ 糧▲」（扉までの秒も同じ一行に入れ、ほかの秒の表示を置き換える）。**赤の灯のある本人**には、予告の最初に一度だけ、一番低い赤の灯の「理由 + 手段」の一行を字幕で足す。**赤でない人**には、グループのだれかが赤のとき一行の末尾に「仲間の誰かの備えが低い」だけを足す（名前も人数も出さない。赤の本人には足さない）。ふさがない・押させない。管理者・偽プレイヤーは数えず、背中の外では出ない。開発の撮影用: `/skyabyss dev readiness summary <red|others>`。
5. イサナと職人の台詞への分岐は、旅の職人（21 の P4）が入るときに足す（未実装）。
