# 55 スキンのモデル（パーツ構成。2026-11-01）

目指す質は「バニラのスキン風」ではなく、Yes Steve Model で作るような高密度・高解像度のアニメ調のモデル（2026-11-01 の声）。

- 0.5px 単位の細かいキューブで作り込む（px = バニラの 1 画素 = 1/16 ブロック）。
- 髪は前髪・横髪・後ろ髪を、段差のある別のパーツで重ねる。
- 服は体から浮かせた別の層で厚みを出す。ベルトや金具も立体にする。
- 絵は陰影とハイライトを描き込んだ HD 寄り（顔の前の面で 64×64 ほど）。
- 体から離れた浮かぶパーツで、シルエットに特徴を出す。

12 着すべてをこの作りにする。仕組み（`client/FullSkinLayer`・`tools/rough/skinbox`）はこのまま使う。

## 1. 共通の素体

全部のスキンは同じ素体と同じ骨の名前で作る。動き（歩く・振る・しゃがむ）はバニラの体と同じ。当たり判定と目の高さもバニラのまま。

| 部分 | 大きさ（px） | 作り |
| --- | --- | --- |
| 頭 | 8×8×8 | 芯の箱。顔の面（前）だけ 0.25 引っ込め、髪と帽子の下地にする |
| 首 | 2×1.5×2 | 頭と胴のすき間を埋める |
| 胸 | 6.5×5×3.5 | 細身。胸から腰へ 0.5 ずつ細くする |
| 腰のくびれ | 5.5×3×3 | |
| 腰 | 6.5×3.5×3.5 | |
| 上の腕 | 2.5×5.5×2.5 | 付け根はバニラと同じ（±5, 22） |
| 前の腕 | 2.25×4.5×2.25 | |
| 手 | 2×2.5×1.5 | 親指 0.5 角。持つ品はバニラの手の位置 |
| 腿 | 3×6×3.25 | 付け根はバニラと同じ（±1.9, 12） |
| 脛 | 2.75×5×2.75 | |
| 足 | 2.75×1.5×4 | 靴はスキンごと |

背の高さはバニラと同じ 32px、頭は 8、細身で約 4 頭身（2026-11-01 に決めた。前の見本の 9 の頭は大きすぎた）。

**顔**（2026-11-01 に決めた）: スキンによって、顔を描くものと、着ている人のマイクラのスキンの顔を貼るものに分ける。

- 自分の顔を貼るもの: 頭の芯の箱に、その人のスキンの頭の絵（8×8 の 6 面）をそのまま使う。重ね着の層（帽子の層）は使わない（その人の前髪がモデルの前髪とぶつかるため）。首と手もその人のスキンの色を使う（首 = 頭の下の面の真ん中、手 = 腕の前の面の下の 2〜3 行）。骨の名前は `own_` で始める。
- 顔を描くもの: 顔の前の面を 64×64 で描く。目は小さく低め（参考画像寄り）。肌の色もモデルの色。

## 2. 層の重ね方（厚み）

| 層 | 体からの浮き | 中身 |
| --- | --- | --- |
| 0 素体 | 0 | 肌、体にぴったりの下着や靴下 |
| 1 内の服 | +0.25〜0.5 | シャツ、着物の襟、ベスト |
| 2 外の服 | +0.5〜1 | コート、鎧、ドレス。縁は 0.5 の別キューブで折り返しや縁取りを立てる |
| 3 装具 | +1〜 | ベルト（厚み 0.5〜1）、留め金（縁と爪を 0.5 角で）、ボタン 0.5 角、鋲、袋、紐、鞘 |
| 4 揺れもの | 子の骨 | 髪・裾・スカート・外套・リボン・羽飾り（名前で揺れ方が決まる: hair・cloth・cape・ribbon・tail・plate・skirt） |
| 5 浮かぶもの | 体から離す | float（上下に揺れる）・orbit（体のまわりを回る）・wing（羽ばたく） |

同じ面がぴったり重なるところは作らない（ちらつく）。重なる層は必ず 0.25 以上ずらす。

## 3. 髪の作り（全スキン共通の組み方。2026-11-01 の見直し）

細い縦の房を並べると「棒を並べたかつら」に見える（見本との比べで分かった）。髪は**大きな板を少しずつ違う向きに傾けて重ね**、頭より 1〜2px 外までかさを出す。一束はキューブの鎖で作る（メッシュは使わない）。絵は筋の縞を描かず、上から下へのなめらかな陰と、天使の輪の光一本だけ。

一束の作り（`tools/rough/skinbox/body.py` の `lock`。長い束は 6 個、短い束は 5 個）:

- 先へ行くほど小さく: 長さ 3.4 → 3.2 → 3.0 → 2.6 → 2.2 → 1.6（長さ 16 のとき）、幅と厚みは一段ごとに約 0.85 倍（幅 3.0 → 0.8、厚み 1.5 → 0.6）。
- 少しずつ回す: 各キューブは前のキューブを回した後の下の端を付け根にして回し、上の端を 0.5 だけ前に食い込ませる（曲がってもすき間が出ない）。隣どうしの角度の差は 6 度以内。
- 外への開きは S 字（最大の角度に対して 0.33 → 0.67 → 0.89 → 1 → 0.83 → 0.5。外へ開いて毛先は戻る）、横への流れは 0 → 0.12 → 0.29 → 0.47 → 0.71 → 1 と少しずつ増やす。

例（後ろ髪 1 束、長さ 16・根元の幅 3。単位 px、y が上、後頭部の面が z = +4、回転は付け根のまわりの度）:

| # | 大きさ（幅×長さ×厚み） | 付け根 (x, y, z) | 回転 (X, Y, Z) |
| --- | --- | --- | --- |
| 1 | 3.0 × 3.4 × 1.5 | (0.00, 30.00, 4.75) | (-6, 0, 0) |
| 2 | 2.6 × 3.7 × 1.35 | (0.00, 26.62, 5.11) | (-12, 0, 2) |
| 3 | 2.2 × 3.5 × 1.2 | (0.11, 23.49, 5.77) | (-16, 0, 5) |
| 4 | 1.8 × 3.1 × 1.0 | (0.37, 20.62, 6.59) | (-18, 0, 8) |
| 5 | 1.3 × 2.7 × 0.8 | (0.73, 18.17, 7.39) | (-15, 0, 12) |
| 6 | 0.8 × 2.1 × 0.6 | (1.19, 16.09, 7.95) | (-9, 0, 17) |

服も同じ考えで、角ばった箱をそのまま見せない: 太い箱は四隅に 45 度回した細いキューブを足して断面を八角にし、ふくらんだ袖や広がる袖口・スカートは斜めの板を輪に並べて作る（`Model.ring`）。

## 4. 絵の描き方

- 細かさ: 1px あたり 8 画素（顔の前の面 = 64×64）。アトラスは 1 着 1024 か 2048。
- 塗り: アニメ塗りの 3 段（明・中・影）に、なだらかな陰を重ねる。上の縁に細い光、下と内側に影、重なりの根元を暗くする。
- 布: ひだの明暗、縫い目、縁の線。金属: 斜めの光の筋と強い照り返し。革: しわと擦れ。髪: 筋の明暗、毛先ほど暗く、天使の輪。
- 光るもの（目の光る飾り、灯り、宝石）は光る画素の絵（`_glow`）に分ける。
