## 4. 島の祠で職を選ぶ

- 島の道の 5 つ目（宿り木の祠）で祈ると、職を選ぶ画面: 六つの得物（始めの武器）が台に並び、職の名前・副題・役目の一行・技の絵。選ぶとその武器を受け取り、その職の 1 行目の技を一つ覚える（Lv 1 の 1 点）。
- 始めの武器: 戦士 = 鉄の剣、鍛冶師 = 鉄の斧、弓使い = 弓と矢 32、魔法使い = 宿り木の杖、暗殺者 = 宿り木の短剣、呪術師 = 祠の鈴杖（どれもふつうの階級・必要 Lv 1）。祠の 3 品の形はラフ 3 案から選んだ（杖 = A 枝の籠、鈴杖 = B 鉤の一鈴、短剣 = C 鉤の牙。docs/review/roughs_starter/）。
- 祠のそばに立つと画面が開く（離れて戻るともう一度）。「あとで」で閉じられる。選ぶまで島の道の 5 つ目は済まない。選んだ職は倒れても残る。
- 選び直し: 都の訓練場の師範で、ほかの職の始めの武器をもらえる（無料。一つの職につき一度。会話の「ほかの職の武器」）。
- それまでの戦い（峠の野盗）は、はじめの持ち物の石の剣で（戦士の武器だが、技はまだない）。

## 5. 作る順

1. 削る（3 節）。今の 5 つの木を職の名前に（戦士・鍛冶師・弓使い・暗殺者・呪術師）。持った武器で職を決める仕組み。技は今の職の木の技だけ使える。
2. 職ごとの点・型の保存・技の画面（K）を職の木一本に。
3. 島の祠の職を選ぶ画面と始めの武器（今ある品で足りない杖・鈴・短剣は、絵のラフ 3 案から選んでもらう）。
4. 魔法使いの木（新しい技 4）と、新しい技（炉の踏み・霧隠れ・呪いの印・灯の守り札）。
5. 章ごとの杖・鈴（巨神の装備の流れ。ラフ 3 案）。

1〜5 は済み（2026-10-26）。

## 6. 今の木の形（1〜4 段目のあと）

- 木は 4 行（Lv 1・5・12・20）。1 行目 = 使う技（左）と常に効く技（右）、2 行目 = その下、3 行目 = 奥義（真ん中）、4 行目 = 要。職の 4 つ目の技は 3 行目の左右に置く。
- 魔法使い（星読み）: 雷の矢（24 ブロックの稲妻。3 段で近くの敵へ跳ねる）・星読みの心得（杖を持つとマナの戻り +15%/段）・熾火の玉（ゆっくり飛び、当たると 3 ブロックに弾けて燃やす）・凍て潮（まわり 5〜6 ブロックに傷と強い鈍足）・転移（8〜11 ブロック跳ぶ）・星の誓い（要。星読みの技の傷 +25%・マナ +25%）。
- 魔法の傷 = 手の武器の攻撃力 × 倍率 × (1 + 精神 × 0.6%)。精神は最大マナと魔法の威力に効く。
- 鍛冶師の 4 つ目 = 炉の踏み（3 行目の右。炉の記憶の下）。暗殺者 = 霧隠れ（3 行目の右。先読みの下）。呪術師 = 呪いの印（3 行目の左。引き潮の下）と灯の守り札（3 行目の右。波紋の下）。
- 戦士の 4 つ目 = 盾の踏み込み（3 行目の右。岩の構えの下）、弓使い = 射手の跳び退き（3 行目の右。鷹の目の下）。風読みの踏み込み・跳び退きと同じ動きの、職の木の技（木をまたいで共有はしない。刻印は付かない）。
- これで 6 職とも使う技が 4 つ以上（呪術師は 5 つ。枠は 4）。

## 8. 全職の専用武器

- どの職でも、祠の始めの武器と、各章の巨神の図鑑に専用の武器が一つ以上ある（2026-10-26 の声「全職専用の武器モデルに」）。
- 祠: 祠の剣（戦士）・祠の鎚（鍛冶師）・宿り木の杖（魔法使い）・祠の弓（弓使い）・宿り木の短剣（暗殺者）・祠の鈴杖（呪術師）。強さは 1 秒あたり 6〜8.6 で、一章のエピックの武器を上回らない。
- 章の空きを足した品（表と数値は `item/ChapterGear`）: 一章 鯨骨の鎚・鯨肋の弓、二章 潮殻の鎚・潮殻の弓、三章 雷の鎚、四章 熾火の大剣・灰の弓・熾の短剣。2026-10-27 に残りの空き 4 か所（一章 鯨歯の短剣、二章 馬刀貝の短剣、三章 雷翼の剣・稲妻の短剣）を一品一案で足し、どの章にも 6 職の武器がそろった（表は 03 の 1.4.1）。どれもエピック、心臓での確率 20%。
- 図鑑は 岩鯨 13・潮殻 14・雷翼 13・余燼 15 品。
- 形はユーザーが選んだ: 祠の剣 A（祠の直剣）・祠の鎚 C（鎚と鉤）・祠の弓 A（流木の弓）・鯨骨の鎚 A・鯨肋の弓 A・潮殻の鎚 A・潮殻の弓 C（真珠の先）・雷の鎚 A・熾火の大剣 A（玄武岩）・灰の弓 B（玄武岩の板弓）・熾の短剣 B（玄武岩の欠片）。入れ直しは `tools/install/install_job_weapons.py --option <品>=<案>`。手に持った姿の見直しは `tools/shots/job_weapons_review.txt`。
- 武器の説明に「職: 魔法使い（星読み）」の一行（Wynncraft の Class Req と同じ）。いまの職なら金色、違えば灰色。祠の品の由来は「島の祠の武器」。

- **一人称の見せ方**（`client/weapon/WeaponClient.show`。2026-10-27 の声「一人称で武器をもう少し見せて。邪魔にならない程度に」）: 構えていないときだけ、型ごとに手元をずらす。短剣・爪は内へ上げて一回り大きく（×1.18）、杖は少し内へ、弓は内へ上げる。大剣・鎚・斧は画面をふさがないよう少し下げる。振っている間は動きの混ぜ具合の分だけ元へ戻す（振りの動きは変えない）。
