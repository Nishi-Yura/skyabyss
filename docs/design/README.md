# 天と淵のあいだ 設計書の索引

Minecraft Java 1.21.1（NeoForge）の RPG mod「天と淵のあいだ」の設計書。どの書類も**今の仕様**を書く（経緯・決定ログは持たない。経緯は git の履歴にある）。物語の核心を含む。

## 読み方

- まず [01 全体設計](01_overview.md) を読む（軸・世界観・章・RPG の柱・ホラーの原則・アートの基準・ロードマップ）。
- 次に、作業する話題の書類だけを読む（下の表）。
- まだ決まっていないことは [00](00_decisions_needed.md) にだけある。各書類の最後の「未決」は 00 の番号を指す。
- 各書類の最後の「旧節番号の対応」は、コードのコメントが指す古い節番号（例: 「13 の 10.2節」）を今の節へ引き当てる表。
- 書類と実装が食い違うときは、コード（`src/main/java/jp/revati/skyabyss/`）が正。気づいたら書類を直す。

## 用語

| 言葉 | 意味 |
| --- | --- |
| 留まる者 | 主人公。ループで記憶が残るただ一人 |
| 見る者 | 夜、遠くに立つ自分に似た人影。前のループの自分が残した影 |
| 雲上の巡礼者 | ラスボス。空を飛ぶ古き神。全身は見せない |
| 深淵の心臓 | 地の底の錨。巨神の心臓はここから分かたれた鼓動 |
| 巨神 | 巨神編の 4 体。順に 岩鯨 → 潮殻 → 雷翼 → 余燼 |
| 章 | 巨神 1 体につき 1 章。**序章**（日 1）→ **一章** 岩鯨 → **二章** 潮殻 → **三章** 雷翼 → **四章** 余燼 → **五章** 深淵 → **六章** 月 → **終章** 雲海。章は個人の段階から導く（01 の 4。題字・余韻の札、予兆の枠、小要素の基盤、空の段などの共通の部品と、一〜四章の中身はできている。残りは 01 の 4.1 の「まだ作っていない」） |
| 巨神編 | 一〜四章の総称（巨神 4 体を止めて天の鍵をそろえるまで）。コードや伝承の ID の `chapter1` はこれを指す（ID は変えない）。旧版の「1 章」はこの意味。旧「2 章（深淵）」は五章、旧「3 章（月）」は六章 |
| 章の型 | 全章に共通の部品: 題字、小要素 3〜5、予兆 3 拍、中盤の出来事、試練、心臓、余韻、次への引き（01 の 4.1） |
| 小要素 | 章が開いたときにその人の拠点の近くに置く、小さな頼み・跡・謎（旅の跡、歌石、潮見の貝など） |
| 予兆 3 拍 | 巨神が現れる前の ①痕跡 → ②間接 → ③一部。人ごとに数える |
| 巨神の心臓 | 各巨神の守護者（最終ボス） |
| 背中 | 巨神ごとの専用ディメンションにあるダンジョン。巨神の外見と同じ形で、試練は体の中 |
| 三つの試練 | 背中の三つの区画。越えると中ボスと心臓へ進める |
| 休み場 | 背中の再開地点。倒れるとここから |
| 眠る試練 | 2 周目から、三つの試練の一つが休む仕組み（周を短くする） |
| 天の鍵／欠片 | 心臓のそばの欠片。四つで一つの鍵になり、足もとを指す |
| 語り部 | 鐘のそばに立つ NPC（役名） |
| イサナ | 鯨追い。巨神へ導く旅人（固有の名前を持つ唯一の NPC） |
| 鐘の宿り | 序盤に必ず着く、語り部のいる場所 |
| 伝承の書 | 見たもの・読んだ碑文・聞いた話が記される書。野営地の帳面で手に入る |
| 控え帳 | 巨神の進み・大事な品の在りかの画面（B） |
| 共鳴の炉 | 強化・分解・再鍛造・交換・振り直しの台 |
| 共鳴の結晶／共鳴の欠片 | 再鍛造・振り直しの費用／交換の通貨 |
| 巨神の記憶 | 報酬の天井のカウンタ |
| 特性 | レア以上の武器・防具に付くランダム効果 |
| 手ごたえ | 強さの曲線の指標（ボスを倒すのに要る手間の目安。03） |
| 目的の帯 | 画面に出る今のメインの目的の一行（18） |
| 旅嚢 | mod の品専用の持ち物。品ごとの決まった枠。拾うと勝手に入り、倒れても残る。キー Y の輪で道具を使い、画面の「作り直し」で袋の素材から作る（22） |
| 拍子 | 序盤に必ず起こす出来事の単位（B0〜B10。17）。B0〜B6 が序章、B7〜が一章 |
