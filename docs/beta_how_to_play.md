# 天と淵のあいだ ベータ版 遊び方

遊んでくださってありがとうございます。このページは、ベータ版（序章から、四体の巨神を倒して「天の鍵」がそろうまで）を遊ぶ人のための案内です。物語の中身は書いていません。迷ったときの手がかりだけを載せています。

ベータ版は、遊んで確かめてもらうための版です。足りない所や直しかけの所があります（「既知の問題」を見てください）。気づいたことは、いちばん下の欄に書いてもらえると助かります。

| もの | 内容 |

## 2. 最初にすること

ゲームを始めると、画面が暗いところから始まります。題字が出て、目が覚めるように視界が戻ります。ここからが序盤です。順番はゆるく決まっていますが、詰まらないように、次の流れを目安にしてください。画面の**左上の「目的の帯」**に、いま向かうところが一行で出ます。迷ったら、まずそれを見てください。

1. **野営地で目覚める。** 目を開けた場所は、人が去ったあとの野営地です。まわりを見回してください。落ちている**古い帳面**を拾うと、**伝承の書**の最初の頁になります。見たこと、読んだ物、聞いた話が、少しずつ書に記されていきます（持って右クリックで開きます）。
2. **煙と鐘の音を追う。** 帳面を拾うと、遠くに細い煙の柱が見えます。ときどき鐘の音も聞こえます。道には積み石が並んでいます。煙の下が**鐘の宿り**です。遠いので、木を切ったり道具をつくったりしながら向かって構いません。
3. **語り部に話しかける。** 鐘の宿りにいます。空のこと、歌のことを聞いてください。道すがらに見たものも、話すと反応があります。宿が見つからないときは、目的の帯に方角と距離が出ます。それでも困ったら、管理者に `/skyabyss npc village` を頼めます。
4. **道の脇の、巨大な足跡を見る。** 道から少し外れた所に、足の形をした大きなくぼみが並んでいます。見つけると、書に記されます（寄り道です）。
5. **最初の空の影を見る。** 一日目の昼ごろ、空を大きな影が通ります。雨の日でも通ります。外にいると見えます。屋内や洞窟にいると、先に小さな地鳴りで知らせるので、外へ出てください。通りすぎたあと、空から**破れた頁**が落ちてきます。拾ってください。見られなかった人にも、頁は届きます。
6. **最初の夜に、耳をすます。** 日が落ちてしばらくすると、静かになり、地面が揺れます。見えるものは何もありません。慌てず、やり過ごしてください（寝ていると気づかないことがあります。その場合は次の夜です）。
7. **鯨追いのイサナに会う。** 語り部の話が進むと、村（または宿）の外れに焚き火が現れて、旅の人が座っています。空を泳ぐ岩の鯨のことを教えてくれます。
8. **骨の丘へ寄る（寄り道）。** 二日目あたりに、目的の帯が丘の方角を指すことがあります。丘の上に巨大な骨が立っています。足もとの石板も読んでみてください。
9. **二日目の夜、空を見上げる。** 空から低い歌が聞こえて、星が帯のかたちで欠けていくことがあります。外にいると見えます。
10. **岩鯨を見る。** 影・歌・イサナの話を済ませた人は、三日目の夕方に、遠い空の高い所を大きな鯨が泳ぎはじめます。ときどき降りてきて、背中の鎖を地上へ垂らします。済ませていなくても、五日目の夕方には現れます。
11. **岩鯨の背中に乗る。** 鎖を右クリックすると、引き上げられます。背中の島に、三つの試練と、奥に心臓があります。

メインクエストは **U キー**のクエストログで見られます。何をすればいいか分からなくなったら、目的の帯か U を見てください。

### 章と、地上の小さな仕掛け

物語は、巨神 1 体ごとに「章」に分かれています。**序章 → 一章 岩鯨 → 二章 潮殻 → 三章 雷翼 → 四章 余燼**。章が替わると、画面の上に**題字の札**（「二章　引く海」のような一行）が一度だけ出ます。章の終わり（巨神の心臓を止めたあと）にも、短い「章の終わり」の札と語り部の一言が出ます。どちらもチャットには流れません。

- 章は、自分が止めた心臓の数で決まります。仲間より遅れていても、自分の章から始まります。前から続けている世界で入り直しても、過去の章の札はもう出ません。
- 章が開くと、自分の拠点（ベッド、なければ復活地点）の近くに、その章の**小さな仕掛け**が現れます。積み石、見晴らしの丘、荷、石の碑、炉跡など。近づいて読む・調べると、短い話や伝承の頁、ちょっとしたごほうびがあります。歩いて探してください。敵は出ません。
- 巨神が現れる前には、**予兆**が三つ、少しずつ起きます（石の粉が降る、遠くで貝が鳴る、地面がほんのり温かい、など）。画面の下に一行だけ出ます。怖がらせるためのものではなく、「何かが近づいている」ことを知らせるものです。
- 章ごとに空の色もごくわずか変わります（月が少しだけ近く見えるようになります）。
- **二章の「潮見の貝」**: 二章で、海辺に流れ着いた荷から一つ拾えます。手に持つと、画面の下に巨神のいる向き（八方位）、距離（遠い・近い・すぐそこ）、次の干潮までの分が出ます。干潮の少し前に海の近くで右クリックして吹くと、巨神がそばへ寄るよう頼めます（一つの干潮に一人）。

### 画面の知らせ

チャットには、人の声とコマンドの返事だけが流れます。ゲームの中の知らせは、種類ごとに画面の決まった場所に出ます。

| 場所 | 出るもの |
| --- | --- |
| 下の中央 | 語りの字幕（見たものの言葉）と、手がかり（灰色の字） |
| 右上の札 | 手に入れたもの（「獲得」）、先へ進んだこと（「進展」） |
| 画面の上のほう | 場所の名前の大きな題字、戦いの区切りの一行 |
| 画面の中央 | レベルが上がったときの一行 |
| 足もと（アクションバー） | できなかった理由、行動のたびの手応え |
| 左上 | 目的の帯 |

見逃したときは、**N キー**の「知らせの記録」で、流れた語り・獲得・場所の名前を新しい順に読み返せます（この遊びのあいだの 200 件まで）。
設定ファイルの `notifyMode`（`TOAST` は画面の演出だけ、`CHAT` は従来どおりチャット、`BOTH` は両方）、`noticeSpeed`（表示の長さ）、`objectiveStrip`（目的の帯の有無）で、見せ方を変えられます。

## 3. 操作キー

| キー | 画面・動き |
| --- | --- |
| **J** | ステータス（レベル、力の振り分け、振り直し） |
| **K** | 技の画面（技を覚える、四つの枠に置く） |
| **U** | クエストログ（メインとサブ、追跡の切り替え） |
| **B** | 控え帳（巨神の進み、大事な品の在りか、呼び戻し）。チャットの `/skyrecord` でも開けます |
| **N** | 知らせの記録（流れた語り・獲得・場所の名前を読み返す） |
| **O** | パーティ（仲間の招待、一覧） |
| **H** | 護符を使う（護符の枠に付けた護符。使うと待ち時間があります） |
| **R・G・V・Z** | 技の枠 1〜4 の技を使う |

- キーは、設定の「操作」の中にある **「天と淵のあいだ」** の項目で、自由に変えられます。ほかの mod とぶつかったら、ここで直してください。
- 技は、レベルが上がるごとに増える「技の点」で覚えます（K）。最初は剣士か弓使いの木から選びます。
- 装飾品（護符、護石、補強板など）は、持っているだけでは効きません。持ち物の画面の右上の「装飾」のつまみを押して開く、専用の枠に付けたときだけ効きます。
- 装備には「必要レベル」があります。足りないと、防具は着られず、武器は持てても力が出ません。説明文の「必要 Lv」を見てください。

チャットで使える、誰でも使えるコマンド:

| コマンド | 内容 |
| --- | --- |
| `/story` | 自分の物語の進み、今のレベルの上限、巨神ごとの進み |
| `/growth`、`/skill` | レベル・力・技の一覧 |
| `/skyrecord` | 控え帳を開く |
| `/titanmemory` | 巨神ごとの記録と、装備の図鑑 |
| `/party`（`invite`・`accept`・`leave` など） | パーティ |

## 3b. このバージョンで新しくなったところ

- 章に分かれました（題字の札、章の終わりの札、各章の小さな仕掛けと予兆）。
- 二章で**潮見の貝**を拾えます。潮殻の場所探しに使ってください。なくしたら、語り部の「なくしたものがある」で新しい貝をもらえます。
- 一章の岩鯨が初めて降りる場面（歌がやむ）、二章の大干潮、三章の巨神が影から隠れる場面、四章の夜の浮上が加わりました。
- 地上で倒れると**墓**ができます。装備中の防具や大事な品は持ったまま復活します。残りと経験値は墓に入り、場所は B キーの控え帳で分かります。取りに行けないときは、**語り部に頼む**と、墓の一覧から選んだ墓の中身の半分が戻ります（9 章）。
- 長く遊んでいる世界でも、今の章から始まります（過去の章の札や予兆は出ません）。
- **倒れたあとの再入場**（7 章）、**床の予告**（7 章。橙は傷、青白い破線は安全な筋、灰は押すだけ）、**備えの三灯**（5 章。乗り込み口の身・刃・糧）が入りました。
- **停まっている時間**は約 20 分です。残り 2 分と 30 秒に知らせが出ます（5 章）。
- **背中の目印と道具**: 野営の道具を背中に置けます（6 章）。墓の目印は 9 章、仲間の頭の札と矢印は 8 章です。
- **落ちている品**（頁や書など）は、拾える本人の画面でだけ光ります。
- **控え帳（B）の「試練の石」**: 石のある巨神の頁に、自分と仲間が鳴らした数が出ます。

## 4. 巨神の順番、推奨レベル、レベルの上限

巨神は 4 体います。**この順番で**倒していきます。前の巨神の心臓を止めると、次の巨神が世界に現れます。

| 順 | 巨神 | 推奨レベル | どこにいるか |
| --- | --- | --- | --- |
| 1 | 岩鯨 | 12 | 空 |
| 2 | 潮殻 | 18 | 海 |
| 3 | 雷翼 | 24 | 空の嵐と、高い峰 |
| 4 | 余燼 | 30 | 陸の地面の中 |

- 強さの目安です。推奨より 3 レベルを超えて上だと、倒したときの経験値が減ります。足りないレベルで挑むこともできますが、かなり厳しくなります。
- **物語の進みで、レベルの上限が決まっています。** 最初は 15 まで。岩鯨の心臓を止めると 21、潮殻のあとは 27、雷翼のあとは 33、余燼のあとは 40 まで上がります。あふれた経験値は 1 レベル分まで貯まります。
- 巨神に乗れるのは、**自分で前の巨神の心臓を止めた人**です。先に進んだ仲間に連れていってもらうことはできません。追いつくには、一緒に前の心臓を止めに行ってください。
- ワールドの誰かが前の心臓を止めるまで、次の巨神は現れません。

## 5. 巨神への乗り方

巨神ごとに乗り方が違います。**どれも近づけば、案内の一行が出ます。** 乗れるとき（その巨神に乗る資格があり、巨神が眠っていないとき）は、乗り込み口が遠くからでも**ほのかに脈打つ光**で分かります（岩鯨の鎖、潮殻の潮門、雷翼の昇り風、余燼の口）。

| 巨神 | 乗り方 |
| --- | --- |
| **岩鯨（鎖）** | 岩鯨が降りてくると、左のわき腹から鎖が垂れます。鎖を右クリックすると、背中へ引き上げられます。降りるときは、背中の錨石を右クリックします |
| **潮殻（潮門）** | 潮殻は、干潮のころに浅瀬へ寄ってきて休みます。甲羅の脇にできる**潮門**（水の門）を、泳ぐか舟で行ってくぐります。海の噂と、イサナの話が手がかりです |
| **雷翼（昇り風）** | 午後の夕立のころ、雷翼が近くの高い峰に降りて止まります。足もとに**昇り風**の柱が立つので、中に入ると背中へ運ばれます。風見鶏（イサナの「古い地図」のサブクエストで手に入ります）を持つと、次の夕立までの時間と距離が分かります |
| **余燼（口）** | 余燼は夜、地面に顎を下ろして眠ります。息を吸っているあいだだけ、口が開きます。**吸うあいだに、自分の足で口の中へ歩いて入ります**。雷翼を倒すと渡される**温石**を手に持つと、巨神のいる向きと距離が分かります。日没のころに握ると、その夜は自分のそばで眠ってくれます |

**備えの三灯**: 乗り込み口に近づくと、今の備えが三つの灯で出ます。**身**（防具）・**刃**（武器）・**糧**（回復と護りの品）です。緑は足りている、黄は少し足りない、赤は足りない。どれかが足りないときは「このまま乗る？」と聞かれます。もう一度、5 秒以内に同じ操作をすると乗れます。足りない灯の言い回しは、控え帳（B）の「備え」の行と、心臓の前室の碑にあります。

**停まっている時間**: 巨神は、止まってから約 20 分のあいだ乗れます。残り 2 分と 30 秒に、画面で知らせます。20 分たつと去ります。呼び笛で旅に出るときは、出発の前に 60 秒の待ちがあり、画面に帯が出ます。乗っている全員がそろったら、待ちを切り上げて出発します。

乗る前に、食べ物や回復の品を持っておきましょう。背中で休めるのは、休み場の焚き火だけです。

## 6. 背中の決まり

巨神の背中は、専用の場所です。次の決まりがあります。

- **ブロックを壊せません。置けません。**（サバイバルのとき。爆発でも壊れません。）ただし、作業台・かまど・金床・たいまつ・チェストなどの**野営の道具**は、仕掛けや戦いの場所から離れた地面になら、一人 8 個まで置けます。置いた人（とパーティの仲間）はすぐ外せて、背中を出ると中身ごと手もとへ戻ります。
- エリトラ、エンダーパール、ウィンドチャージ、花火、バケツなど、試練を飛ばせてしまう物は使えません。使おうとすると「巨神の体は、よそ者の手を拒んでいる」と出ます。
- **倒れても、持ち物と経験値は残ります。** 休み場の焚き火から再開します。休み場の記録がないときは、背中の入口へ戻ります。
- **休み場**は、背中のところどころにある焚き火です。そばに寄るだけで、その場所が記録されます。
- **端から落ちたとき**: 岩鯨は地上へ滑空して戻ります。潮殻は潮に流されて潮門の浜へ、雷翼は嵐に投げ返されて休み場へ、余燼は灰に押し戻されて到着の場所へ戻ります。
- 試練は何度でも挑めます。自分のパーティの誰も背中にいなくなって 3 分ほどたつと、そのパーティの試練は最初に戻ります。
- 戦いの途中で保存して終了すると、その戦いは最初に戻ります。

## 7. 試練と心臓

どの巨神の背中にも、**三つの試練**と、奥の**心臓**があります。三つの試練を終えると、心臓の部屋が開きます。

- 試練は一人で挑めますが、人数に合わせて敵が増えるものがあります。
- **倒れたあとの再入場**: 戦いの中で倒れたら、前室で目を覚まします。**20 秒たつと扉から戻れます**。一つの戦いで戻れるのは **3 回まで**（ゲームルール `skyabyssHeartReentryLimit`。既定 3、0 で数えない）。戻った人は 3 秒のあいだ光って傷を受けません。回数を使い切ったら、戦いが終わる（倒す・やり直す）まで中へ入れません。
- **床の予告**: 敵の技は、床に範囲が出てから来ます。**橙から赤へ満ちる山形の印は傷が出る所**、**青白い破線は安全な筋**（輪が抜けていく道）、**灰色は押されるだけ**で傷はありません。印の外に立てば傷を受けません。見え方は、クライアントの設定 `telegraphStyle`（`DECAL` は床の印、`PARTICLES` は点線の粒、`BOTH` は両方。既定は床の印）で変えられます。
- 心臓を倒すと、参加した人それぞれに**天の鍵の欠片**と、経験値、装備が渡ります。欠片は、一人に一つだけです。

- 心臓を止めても、巨神は死にません。巨神の鼓動が止まって、**深い眠り**につきます。少し静かになって背中が震えたあと（約 10 秒）、**戦った人と、そのパーティの人**は画面が暗くなって、巨神の足もとの地面に降ろされます（背中に残った人はそのままです）。初めて止めたときは、眠りにつく巨神を地上から見る場面があります（Space 長押しでスキップできます）。巨神は眠っているあいだ、動かず、歌わず、光らず、乗れません。鼓動が遠い下から戻ると、また目を覚まして動きだします（背中の試練が元に戻るのと同じころです）。
- 周回すると、専用の装備がそろっていきます。装備は、**共鳴の炉**（岩鯨の背に着いた左のわき腹の台などにあります）で強化・分解・再鍛造・交換ができます。
- 四つの欠片がそろい、四体の心臓を自分で止めると、欠片が一つの鍵になります。これがベータ版の終わりです。そのあとも、背中の周回や頼みごとは続けられます。

## 8. マルチプレイ

- **パーティ**を組めます（O キー、または `/party invite <名前>`）。人数は 6 人までです。仲間の位置は、壁の向こうでも頭の上の札（名前と距離）や画面の端の矢印で分かります（別の背中にいる仲間は右の一覧に「別の場所」）。設定 `partyMarkers` で消せます。
- 道中の敵の経験値は、近くにいる全員で分けます。ボスは参加者それぞれに満額です。その場にいなかった仲間にも、いくらかの分け前が入ります。
- 乗れるのは、自分で前の心臓を止めた人です。「乗れない」と出たら、前の巨神を一緒に倒しに行きましょう。
- 背中の試練は、6 人までを想定した敵の数です。
- **背中の進みはパーティごと**です。開けた扉、鳴らした石、倒した心臓、試練のリセットは、パーティ（パーティに入っていない人は一人のパーティ）ごとに持ちます。同じ背中に別のパーティがいても、扉や敵は混ざりません（ほかのパーティの敵は見えず、狙われもしません）。水や足場が動く部屋は、一度に一つのパーティだけが入れます。使っているときは「別のパーティーがこの試練に挑んでいる」と出るので、出てくるのを待ってください。
- 途中でパーティを組む・抜けると、背中の進みはパーティの記録に切り替わります。体の中にいるときは、広間へ戻されます。
- 全員が同じ順番で進みます。ほかの人が先に進んでも、遅れた人は自分の順番で進めます。

## 9. 困ったとき

### 大事な品をなくした

天の鍵の欠片、心核、呼び笛などの**大事な品は、倒れても手もとに残ります**。ほかの人に渡したり、箱へしまって忘れたりしてなくしたときは、**B キーの控え帳**を開いてください。品の在りかと、「呼び戻す」ボタンがあります。これらの大事な品は、Q キーなどで投げ捨てることができません（人に渡すときは箱を通してください）。

### 地上で倒れたとき（墓）

巨神の背中の外で倒れると、**装備中の防具・左手・装飾品・ホットバー・大事な品は持ったまま**復活します（耐久は 1 割ほど減ります）。残りの持ち物と経験値は、倒れた場所のそばに立つ**苔むした積み石の「墓」**に入ります。墓は時間で消えず、持ち主だけが開けられます（右クリックで中身が戻ります）。場所は B キーの控え帳の「墓」に出ます。奈落・溶岩・壁の中で倒れたときは、近くの安全な地面に立ちます。取りに行けないときは、**語り部に「なくしたものがある」→「取りに行けない墓がある」と頼む**と、一覧から選んだ墓の中身の半分が戻ります（墓は消えます）。

### 試練で詰まった

- 休み場の焚き火に**しゃがんで右クリック**すると、試練をあきらめて背中の入口へ戻れます。
- 地上へ戻りたいとき: 岩鯨は錨石を右クリック、潮殻は潮門、雷翼は羽根の門、余燼は口の前の「見送りの石」に立ちます。うまく出られないときは、管理者に `/skyabyss titan leave` を頼めます。
- 次の巨神が見つからないとき: U のクエストログに手がかりがあります。語り部とイサナは、話を聞くたびに少しずつ教えてくれます。

### 管理者（OP）のコマンド

テストに役立つものだけを載せます。サーバーの管理者か、チートを許可したワールドで使えます。`<人>` はプレイヤー名です。

| コマンド | 使いどころ |
| --- | --- |
| `/skyabyss progress show <人>` | 物語の進みを見る |
| `/skyabyss progress grant <人> <巨神>` | その巨神の心臓を止めたことにして、次の巨神に乗れるようにする。巨神は `stone_whale`・`tide_shell`・`thunder_wing`・`ember` |
| `/skyabyss progress world grant <巨神>` | ワールドの進みだけ進めて、次の巨神を出す |
| `/skyabyss level set <人> <1-50>`、`level addxp <人> <量>` | レベルを決める、経験値を足す |
| `/skyabyss quest list <人>`、`quest next <人> <クエスト>` | クエストの進みを見る、一段進める |
| `/skyabyss cinematic play <場面> [人]`、`cinematic stop [人]`、`cinematic reset [人]` | 場面（`opening`・`whale_first_sight`・`heart_<巨神>`・`titan_end_<巨神>`）を流す・止める・「見た記録」を消す。`[人]` は `@a` や名前（省くと自分）。マルチで他の人に見せたいときに |
| `/skyabyss titan summon <名前>` | 巨神を近くに呼ぶ。名前は `tide`・`storm`・`ember`（省略すると岩鯨） |
| `/skyabyss titan rest <名前>`（`here` を足すとその場で） | 巨神をすぐ休ませる（乗るため） |
| `/skyabyss titan board <名前>`、`titan leave` | 背中へ直接渡る、背中から地上へ戻る |
| `/skyabyss titan reset <名前>` | 背中の試練を最初に戻す |
| `/skyabyss titan storm calm`・`storm`・`cycle` | 雷翼の背の風を凪・嵐に止める、元に戻す（雷翼の背の中で） |
| `/skyabyss tideheart start`・`win`・`reset`（`stormheart`・`emberheart` も同じ） | 心臓の戦いをすぐ始める、倒したことにする、最初に戻す |
| `/skyabyss story ready <人>` | 四体を止めたことにして欠片を四つにし、天の鍵の場面を見る |
| `/skyabyss lore book`、`lore unlock <人> all` | 伝承の書を渡す、項目をすべて記す |
| `/skyabyss pass` | 空の影をすぐ通す |
| `/skyabyss opening status [人]`、`opening <拍子> [人]`、`opening reset [人]` | 序盤の進みを見る、その拍子へ進める、最初に戻す。拍子は `awake`・`camp`・`trail`・`footprints`・`shadow`・`storyteller`・`footsteps`・`isana`・`bones`・`song`・`whale` |
| `/skyabyss npc village` | 近くの村に語り部を立たせる。`npc spawn <storyteller|whale_chaser>` で足もとにも立てられる |
| `/skyabyss inspect <人>` | ほかの人の控え帳を見る |
| `/skyabyss affix show`、`affix reroll` | 手の装備の特性を見る、抽選し直す |

  - `skyabyssStoryGate false` … 巨神の順番と乗る資格の決まりを切る（好きな順に乗れる）
  - `skyabyssStoryLevelCap false` … 物語の進みのレベル上限を切る
  - `skyabyssHeartReentryLimit`（既定 3。0 で数えない）… 一つの戦いで倒れた人が、20 秒のあとに戻れる回数
  - `skyabyssPartyShare`（50〜80）… その場にいなかった仲間への分け前（％）
  - `skyabyssDeathMode`（0 墓 / 1 バニラ / 2 全部残す / 3 耐久だけ減る。既定 0）… 地上で倒れたときの型。バニラの `keepInventory true` はそのまま優先
  - `skyabyssGraveKeepGear`（既定 true）、`skyabyssGraveOwnerOnly`（既定 true。false で誰でも開けられる）、`skyabyssGraveExpire`（分。0 で消えない）、`skyabyssGraveRescue`（語り部の救いで戻る％。0 で救いなし）、`skyabyssDeathDurability`（耐久の減る％）
- 設定ファイルで、見る者・雲の目などの頻度を変えられます（`horrorEventFrequency`、`watcherFrequency`、`cloudEyeFrequency`。0 で出なくなります）。`horrorEventFrequency` を 0 にすると、最初の夜の足音と二日目の夜の歌、空の影は起こりません（煙・鐘・目的の帯はそのままです）。画面の揺れや暗さは、クライアント設定で弱められます。

## 10. 既知の問題

ベータ版で、すでに分かっていることです。

- **余燼の背中**は、部屋のつなぎ目と、歩いて行ける道を作る側で監査して直しました。まだ人が最後まで通しで遊んだことはありません。部屋と部屋のあいだで噛み合わない所、行けない所があれば教えてください。そのときは、管理者に `/skyabyss titan reset ember` か、`/skyabyss emberheart start` を頼んでください。
- 雷翼と余燼では、巨神での移動（呼び笛で巨神に連れていってもらう旅）がまだできません。
- 章の小さな仕掛けや、巨神が現れる前の予兆は、人が通しで遊んで確かめていません。濃さ（出すぎる・気づかない）の感想をください。見る者が巨神の方を向く場面や、章ごとの村の小さな変化は、まだ作っていません。
- 風見鶏や潮の真珠の絵は、仮のものです。
- 世界を開いた直後の数分は、裏で背中の島を建てているので、動きが少し重いことがあります。そのあいだに岩鯨の背中へ乗ろうとすると、一瞬止まることがあります。
- 序盤の演出（暗転・足音・歌と星の欠け・骨の丘など）は、通しで人が遊んで確かめていません。鳴るはずの所で音が鳴らない、目的の帯の方角が合わない、拍子が起きない、などがあれば教えてください。起きないときは、管理者に `/skyabyss opening <拍子>` を頼めます。
- 知らせの記録（N）は、その遊びのあいだだけの記録です。ゲームを閉じると消えます。
- 天の鍵の場面は、そろえた本人の画面にだけ出ます。
- 倒した巨神の心臓の欠片が 4 つそろわないときは、控え帳（B）の「呼び戻す」を使ってください。
- ほかにも、作ったばかりで、人が通しで遊んでいない所があります。詰まったり、おかしな動きを見つけたりしたら、ぜひ教えてください。
