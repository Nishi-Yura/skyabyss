# 天と淵のあいだ 遊び方

遊んでくださってありがとうございます。このページは、天と淵のあいだ（序章から、四体の巨神と深淵・月を越えて、終章「雲海」の結末まで）を遊ぶ人のための案内です。物語の中身は書いていません。迷ったときの手がかりだけを載せています。

不具合や気づいたことは、いちばん下の「不具合・感想の伝え方」の項目で知らせてもらえると助かります。

---

## 1. 遊ぶための準備

| もの | 内容 |
| --- | --- |
| Minecraft | Java 版 1.21.1 |
| 導入先 | NeoForge 1.21.1（21.1.259 で確かめています） |
| 必要な mod | GeckoLib（NeoForge 1.21.1 用。4.9.3 で確かめています）。モデルの動きに使っています |
| Java | 21 |

| 置き場所 | 本体の jar と GeckoLib の jar を、どちらも **`mods` フォルダ**に入れます（サーバーで遊ぶときは、サーバーの `mods` にも同じものを） |

- **新しいワールド**で遊んでください。巨神の背中の島は、世界を開いたあと、**裏で少しずつ**建ちます（岩鯨・潮殻・雷翼・余燼の四つ）。建つあいだも遊べますが、パソコンによっては最初の数分、動きが少し重く感じられることがあります。止まったように見えても、待てば進みます。
- 難易度は **ピースフル以外**にしてください。ピースフルでは巨神の背中の試練が眠ったままで、戦えません。
- 一人でも遊べます。仲間と遊ぶとき（パーティは 6 人まで）は、背中の試練の人数に合わせて敵が増えます。

## 2. 最初にすること

ゲームを始めると、ドット絵の短い語り（紙芝居）が流れ、そのあと目が覚めます（語りは飛ばせます）。画面の**左上の「目的の帯」**に、いま向かうところが一行で出ます。迷ったら、まずそれを見てください。

### はじまりの島

大陸の南西の沖の小さな島から始まります。島の道を進むと、遊び方が一つずつ分かります。

1. **野営地で職を選ぶ。** 目を開けた野営地のそばに立つと、職を選ぶ画面が開きます。戦士・鍛冶師・魔法使い・弓使い・暗殺者・呪術師の六つから一つ。始めの武器と最初の技がもらえます（職は持った武器で決まり、あとで別の職の武器を持てばその職になります）。
2. **野営地の帳面を拾う。** **伝承の書**の最初の頁になります（持って右クリックで開きます）。
3. **足跡の窪地を見る。** 道の脇の窪地に、古い巨大な足跡があります。
4. **峠の野盗を退ける。** 峠に野盗がいます。三人退けると次へ進みます。
5. **旅の休み場の焚き火で休む**、**宿り木の祠に祈る**（ここで目覚めるようになります）。
6. **船着き場の渡し守と話す。** ここまで済ませた人だけ、鐘の都へ渡してくれます（島へ戻る船はありません）。

島の場所はどれも、遊び方を一つずつ教えるためのものです（寄り道はありません）。

### 鐘の都と土地の町

1. **都の町めぐり。** 初めて都に入ると、灯りの道が鍛冶場 → 宿 → 道具屋 → 組合と案内します。着くたびに鐘銭がもらえます。
2. **土地の町へ。** 大陸には土地ごとに町が四つ（鯨見・汐守・風待・灰炉）。都から土の道が各町の門まで続き、道の途中には道しるべと見どころがあります。地図は **M**。
3. **章を進める。** 各章は土地の町が入口です。町の人の話から、巨神に会うための支度へ進みます。メインクエストは **U キー**のクエストログで見られます。

### 章

物語は、巨神 1 体ごとに「章」に分かれています。**序章 → 一章 岩鯨 → 二章 潮殻 → 三章 雷翼 → 四章 余燼**（その先に五章 深淵）。章が替わると、ドット絵の語りのあとに**題字の札**（「二章　引く海」のような一行）が一度だけ出ます。

- 章は、自分が止めた心臓の数で決まります。仲間より遅れていても、自分の章から始まります。
- この版では、作業台で物は作りません。武器・防具・道具は、店・頼みの報酬・敵・巨神から手に入ります。物はすり減らず、ブロックは壊せません（アドベンチャー）。
- 敵はこの Mod の敵だけです（ゾンビやクリーパーは出ません）。土地ごとに強さが違い、ときどき名札つきの強敵が現れます。

### 画面の知らせ

チャットには、人の声とコマンドの返事だけが流れます。ゲームの中の知らせは、種類ごとに画面の決まった場所に出ます。

| 場所 | 出るもの |
| --- | --- |
| 下の中央 | 語りの字幕（見たものの言葉）と、手がかり（灰色の字） |
| 右上の札 | 手に入れたもの（「獲得」）、先へ進んだこと（「進展」） |
| 画面の上のほう | 場所の名前の大きな題字、戦いの区切りの一行 |
| 画面の中央 | レベルが上がったときの一行 |
| 足もと（アクションバー） | できなかった理由、行動のたびの手応え |
| 左上 | 目的の帯 |

見逃したときは、**N キー**の「知らせの記録」で、流れた語り・獲得・場所の名前を新しい順に読み返せます（この遊びのあいだの 200 件まで）。
設定ファイルの `notifyMode`（`TOAST` は画面の演出だけ、`CHAT` は従来どおりチャット、`BOTH` は両方）、`noticeSpeed`（表示の長さ）、`objectiveStrip`（目的の帯の有無）で、見せ方を変えられます。

| キー | 画面・動き |

| **K** | 技の画面（今の職の木。技を覚える、四つの枠に置く） |
| **L** | 記し（この Mod の進捗。旅・巨神・強敵・成長・町） |

| **B** | 控え帳（巨神の進み、大事な品の在りか、呼び戻し）。チャットの `/skyrecord` でも開けます |

| **O** | パーティ（仲間の招待、一覧） |
| **H** | 護符を使う（護符の枠に付けた護符。使うと待ち時間があります） |

| **F5** | 視点（一人称 ↔ この mod の三人称（肩越し））。三人称では画面の真ん中に照準が出て、殴る・技・弓は照準の所へ当たります |
| **F6** | 三人称の肩（左右）を替える |

- キーは、設定の「操作」の中にある **「天と淵のあいだ」** の項目で、自由に変えられます。ほかの mod とぶつかったら、ここで直してください。
- 技は、レベルが上がるごとに増える職ごとの「技の点」で覚えます（K）。木は持っている武器の職のものが開きます。
- 装飾品（護符、護石、補強板など）は、持っているだけでは効きません。持ち物の画面の右上の「装飾」のつまみを押して開く、専用の枠に付けたときだけ効きます。
- 装備には「必要レベル」があります。足りないと、防具は着られず、武器は持てても力が出ません。説明文の「必要 Lv」を見てください。

## 3b. このバージョンで新しくなったところ（1.0〜1.1）

- 前の版の世界は、そのまま続けられます。大陸の地上（地形・道・見どころ）は開いたときに作り直し、クエスト・持ち物・見つけた場所は残ります。管理者は `/skyabyss admin version` で版を見られます。
- 戦い: 近接は溜めた分だけ強くなります（照準のまわりに溜めの輪）。回復と武器の効果は、溜めきった一撃だけに乗ります。主と名のある敵は、ボスの帯の下の**崩しの帯**を削りきると崩れ、そのあいだ大きく削れます。
- 倒れても、持ち物と経験値はなくなりません。目を覚ましてから 2 分は「弱り」（与える傷 −15%・受ける傷 +15%。宿で休むと治ります）。夜の野には、頭のいる手ごわい群れが出ます。
- 物語: イサナが二章から五章まで港・風待の里・地下の門で待ち、各章に小さな手がかりがあります。巨神は、その章を進めている人にだけ見えます。結末のあとに、語り部とイサナが話します。
- 見どころは、どれも名前のある一か所ずつになりました（道しるべ 6 か所・野盗の頭目の兄弟・野営の旅人）。訪れた町で起き上がれ、磁石石に名札が付きます。
- 地下のダンジョンが四つあります（町の案内人の「噂を聞く」から）。乗り物は空を飛べる空鱏などが増えました。旅の地図が見やすくなり、F5 で肩越しの三人称（F6 で肩を替える）になります。
- 画面を黄金比の形にそろえ、技の木は使う技 4 本と金の要の節の形になりました。クエストログの先頭に「今日・今週」の頁があり、記録は七つのつまみの一つの画面にまとまりました。
- やり込み: 土地ごとの巡り路の野営地（三日ごとに替わる報酬）、神器の目覚め、目に見える粉の技、ダンジョンの深潜りと日替わり、封の箱のヒント、魚の注文と釣り場、乗り物の早駆けの道と絆、祝福・狩人の手記・二人乗り・秘密・珍しい獣。

0.9 までに入ったもの:

- 五章「深淵」（都の下の入口。天の鍵が下を指すと開きます）、六章「月」（都の大鐘楼の上の門。四つの区画と月の核、クリア後の位相の挑戦）、終章「雲海」（月の核のあと語り部に話すと始まります。四つの雲の島 → 巡礼者の座。結末は三つから選べ、座に触れると選び直せます。神器は職ごとに一つ、クリア後は巡礼の試し）。
- 技は職ごとの**木**（K）。基礎（筋力・敏捷・精神・耐久）は木の「基礎の節」で上がります。職は町の**職の間**（訓練場の師範）で替えられます。今の職の武器でないものでは戦えません（武器の札の「職」の行が赤紫になります）。
- 巨神は四体とも決まった居場所で休み続けます。心臓を止めると、土地の町を出た道ばたに祠が建ち、周回はそこから挑みます。試練の部屋には時間切れがあります（歩・智 5 分、闘 6 分。全滅ごとに +1 分）。
- 心臓を止めるたびに、職ごとのヒロイック武器が低い確率で手に入ります。月と深淵にも職ごとのレアとヒロイックがあります。
- 世界は一枚の大陸。はじまりの島 → 渡し船 → 鐘の都 → 土地の町。敵はこの Mod の敵だけ、作業台で物は作りません、ブロックは壊せません。
- BGM（場所と戦いごとの 17 曲）、記し（L）、名札つきの強敵。

## 4. 巨神の順番、推奨レベル、レベルの上限

巨神は 4 体います。**この順番で**倒していきます。巨神はそれぞれの土地の決まった居場所で休んでいて、章は土地の町の人の話から始まります。

| 順 | 巨神 | 推奨レベル | どこにいるか |
| --- | --- | --- | --- |
| 1 | 岩鯨 | 12 | 空 |
| 2 | 潮殻 | 18 | 海 |
| 3 | 雷翼 | 24 | 空の嵐と、高い峰 |
| 4 | 余燼 | 30 | 陸の地面の中 |

- 強さの目安です。推奨より 3 レベルを超えて上だと、倒したときの経験値が減ります。足りないレベルで挑むこともできますが、かなり厳しくなります。
- **物語の進みで、レベルの上限が決まっています。** 最初は 15 まで。岩鯨の心臓を止めると 21、潮殻のあとは 27、雷翼のあとは 33、余燼のあとは 40 まで上がります。あふれた経験値は 1 レベル分まで貯まります。
- 巨神に乗れるのは、**自分で前の巨神の心臓を止めた人**です。先に進んだ仲間に連れていってもらうことはできません。追いつくには、一緒に前の心臓を止めに行ってください。

## 5. 巨神への乗り方

巨神ごとに乗り方が違います。**どれも近づけば、案内の一行が出ます。** 乗れるとき（その巨神に乗る資格があり、巨神が眠っていないとき）は、乗り込み口が遠くからでも**ほのかに脈打つ光**で分かります（岩鯨の鎖、潮殻の潮門、雷翼の昇り風、余燼の口）。

| 巨神 | 乗り方 |
| --- | --- |
| **岩鯨（鎖）** | 岩鯨が降りてくると、左のわき腹から鎖が垂れます。鎖を右クリックすると、背中へ引き上げられます。降りるときは、背中の錨石を右クリックします |
| **潮殻（潮門）** | 潮殻は、干潮のころに浅瀬へ寄ってきて休みます。甲羅の脇にできる**潮門**（水の門）を、泳ぐか舟で行ってくぐります。海の噂と、イサナの話が手がかりです |
| **雷翼（昇り風）** | 午後の夕立のころ、雷翼が近くの高い峰に降りて止まります。足もとに**昇り風**の柱が立つので、中に入ると背中へ運ばれます。風見鶏（イサナの「古い地図」のサブクエストで手に入ります）を持つと、次の夕立までの時間と距離が分かります |
| **余燼（口）** | 余燼は夜、地面に顎を下ろして眠ります。息を吸っているあいだだけ、口が開きます。**吸うあいだに、自分の足で口の中へ歩いて入ります**。雷翼を倒すと渡される**温石**を手に持つと、巨神のいる向きと距離が分かります。日没のころに握ると、その夜は自分のそばで眠ってくれます |

**備えの三灯**: 乗り込み口に近づくと、今の備えが三つの灯で出ます。**身**（防具）・**刃**（武器）・**糧**（回復と護りの品）です。緑は足りている、黄は少し足りない、赤は足りない。どれかが足りないときは「このまま乗る？」と聞かれます。もう一度、5 秒以内に同じ操作をすると乗れます。足りない灯の言い回しは、控え帳（B）の「備え」の行と、心臓の前室の碑にあります。

**停まっている時間**: 巨神は、止まってから約 20 分のあいだ乗れます。残り 2 分と 30 秒に、画面で知らせます。20 分たつと去ります。呼び笛で旅に出るときは、出発の前に 60 秒の待ちがあり、画面に帯が出ます。乗っている全員がそろったら、待ちを切り上げて出発します。

乗る前に、食べ物や回復の品を持っておきましょう。背中で休めるのは、休み場の焚き火だけです。

## 6. 背中の決まり

巨神の背中は、専用の場所です。次の決まりがあります。

- **ブロックを壊せません。置けません。**（サバイバルのとき。爆発でも壊れません。）ただし、作業台・かまど・金床・たいまつ・チェストなどの**野営の道具**は、仕掛けや戦いの場所から離れた地面になら、一人 8 個まで置けます。置いた人（とパーティの仲間）はすぐ外せて、背中を出ると中身ごと手もとへ戻ります。
- エリトラ、エンダーパール、ウィンドチャージ、花火、バケツなど、試練を飛ばせてしまう物は使えません。使おうとすると「巨神の体は、よそ者の手を拒んでいる」と出ます。
- **倒れても、持ち物と経験値は残ります。** 休み場の焚き火から再開します。休み場の記録がないときは、背中の入口へ戻ります。
- **休み場**は、背中のところどころにある焚き火です。そばに寄るだけで、その場所が記録されます。
- **端から落ちたとき**: 岩鯨は地上へ滑空して戻ります。潮殻は潮に流されて潮門の浜へ、雷翼は嵐に投げ返されて休み場へ、余燼は灰に押し戻されて到着の場所へ戻ります。
- 試練は何度でも挑めます。自分のパーティの誰も背中にいなくなって 3 分ほどたつと、そのパーティの試練は最初に戻ります。
- 戦いの途中で保存して終了すると、その戦いは最初に戻ります。

## 7. 試練と心臓

どの巨神の背中にも、**三つの試練**と、奥の**心臓**があります。三つの試練を終えると、心臓の部屋が開きます。

- 試練は一人で挑めますが、人数に合わせて敵が増えるものがあります。
- **倒れたあとの再入場**: 戦いの中で倒れたら、前室で目を覚まします。**20 秒たつと扉から戻れます**。一つの戦いで戻れるのは **3 回まで**（ゲームルール `skyabyssHeartReentryLimit`。既定 3、0 で数えない）。戻った人は 3 秒のあいだ光って傷を受けません。回数を使い切ったら、戦いが終わる（倒す・やり直す）まで中へ入れません。
- **床の予告**: 敵の技は、床に範囲が出てから来ます。**橙から赤へ満ちる実線の縁の印は傷が出る所**、**青白い破線は安全な筋**（輪が抜けていく道）、**灰色は押されるだけ**で傷はありません。印の外に立てば傷を受けません。見え方は、クライアントの設定 `telegraphStyle`（`DECAL` は床の印、`PARTICLES` は点線の粒、`BOTH` は両方。既定は床の印）で変えられます。
- **技の名前**: 心臓・中ボス・番兵の技は、始まるとボスバーのすぐ下に小さな名前の一行が出ます（設定 `bossAttackNames` で大きく・消すこともできます）。
- **一方向に回り続けるだけでは勝てません**: 同じ向きに回りつづけると、心臓が先回りの円・行く手をふさぐ扇・追いかける薙ぎを出してきます。どれも床に予告が出るので、止まる・逆へ回る・跳ぶ・内外へ出る、で避けられます。
- **心臓の領域**: 心臓の体力が半分を切ると、一度だけ、心臓が領域を広げます（岩鯨「石の海」・潮殻「満ち潮」・雷翼「雷の檻」・余燼「炉心」）。4 秒の宣言（題字と天の声の一行。そのあいだ心臓は傷を受けません）のあと、35 秒のあいだ、部屋の色が変わり、領域だけの床の決まりが回ります。予告はどれも床に出ます。領域のあいだに心臓へ与えた傷が最大体力の 6% に届くと領域が砕けて、心臓は 5 秒のあいだ傷を 1.5 倍受けます。届かなくても 35 秒で終わります。ボスバーの下に残りの秒と、砕く進みが出ます。
- 心臓を倒すと、参加した人それぞれに**天の鍵の欠片**と、経験値、装備が渡ります。欠片は、一人に一つだけです。

- 心臓を止めても、巨神は死にません。巨神の鼓動が止まって、**深い眠り**につきます。少し静かになって背中が震えたあと（約 10 秒）、**戦った人と、そのパーティの人**は画面が暗くなって、巨神の足もとの地面に降ろされます（背中に残った人はそのままです）。初めて止めたときは、眠りにつく巨神を地上から見る場面があります（Enter 長押しでスキップできます）。巨神は眠っているあいだ、動かず、歌わず、光らず、乗れません。鼓動が遠い下から戻ると、また目を覚まして動きだします（背中の試練が元に戻るのと同じころです）。
- 周回すると、専用の装備がそろっていきます。装備は、**共鳴の炉**（岩鯨の背に着いた左のわき腹の台などにあります）で強化・分解・再鍛造・交換ができます。
- 四つの欠片がそろい、四体の心臓を自分で止めると、欠片が一つの鍵になります。ここで四体の巨神の章が終わり、物語は次へ進みます（U のクエストログに次の目的が出ます）。そのあとも、背中の周回や頼みごとは続けられます。

## 8. マルチプレイ

- **パーティ**を組めます（O キー、または `/party invite <名前>`）。人数は 6 人までです。仲間の位置は、壁の向こうでも頭の上の札（名前と距離）や画面の端の矢印で分かります（別の背中にいる仲間は右の一覧に「別の場所」）。設定 `partyMarkers` で消せます。
- 道中の敵の経験値は、近くにいる全員で分けます。ボスは参加者それぞれに満額です。その場にいなかった仲間にも、いくらかの分け前が入ります。
- 乗れるのは、自分で前の心臓を止めた人です。「乗れない」と出たら、前の巨神を一緒に倒しに行きましょう。
- 背中の試練は、6 人までを想定した敵の数です。
- **背中の進みはパーティごと**です。開けた扉、鳴らした石、倒した心臓、試練のリセットは、パーティ（パーティに入っていない人は一人のパーティ）ごとに持ちます。同じ背中に別のパーティがいても、扉や敵は混ざりません（ほかのパーティの敵は見えず、狙われもしません）。水や足場が動く部屋は、一度に一つのパーティだけが入れます。使っているときは「別のパーティーがこの試練に挑んでいる」と出るので、出てくるのを待ってください。
- 途中でパーティを組む・抜けると、背中の進みはパーティの記録に切り替わります。体の中にいるときは、広間へ戻されます。
- 全員が同じ順番で進みます。ほかの人が先に進んでも、遅れた人は自分の順番で進めます。

## 9. 困ったとき

### 大事な品をなくした

天の鍵の欠片、心核、呼び笛などの**大事な品は、倒れても手もとに残ります**。ほかの人に渡したり、箱へしまって忘れたりしてなくしたときは、**B キーの控え帳**を開いてください。品の在りかと、「呼び戻す」ボタンがあります。これらの大事な品は、Q キーなどで投げ捨てることができません（人に渡すときは箱を通してください）。

### 地上で倒れたとき

巨神の背中の外で倒れても、**持ち物と経験値はなくなりません**（装備もすり減りません）。起き上がる場所（訪れた町など）で目を覚まし、2 分のあいだ「弱り」（与える傷 −15%・受ける傷 +15%）が付きます。宿の主人に「休む」と頼むと治ります。前の版で残っていた墓は、開いたときに中身が持ち主へ戻ります。

### 試練で詰まった

- 休み場の焚き火に**しゃがんで右クリック**すると、試練をあきらめて背中の入口へ戻れます。
- 地上へ戻りたいとき: 岩鯨は錨石を右クリック、潮殻は潮門、雷翼は羽根の門、余燼は口の前の「見送りの石」に立ちます。うまく出られないときは、管理者に `/skyabyss admin goto overworld <人>` を頼めます。
- 次の巨神が見つからないとき: U のクエストログに手がかりがあります。語り部とイサナは、話を聞くたびに少しずつ教えてくれます。

### コマンド（遊ぶ人と管理者）

配布の jar で使えるのは `/skyabyss admin …` と `/skyabyss inspect …` の二つだけです（ほかの開発用のコマンドは隠れています）。サーバーの管理者か、チートを許可したワールドで使えます。`[人]` はプレイヤー名か `@a`（省くと自分）。全部の一覧は `/skyabyss admin help`。

## 10. 既知の問題

すでに分かっていることです。

- 月・雲海・塔・深み・地下のダンジョンの主の強さは、遊んだ声で合わせていきます。長すぎる・短すぎるを教えてください。
- 日替わり・週替わり（言伝ての板・店の品揃え・組合の頼み・巡り路・塔・旗取り・釣り大会）は、どれも実時間の朝 5 時・月曜で替わります。ゲームの中で寝ても替わりません。
- 余燼の背は、部屋のつなぎ目と歩ける道を作る側で監査して直しました。噛み合わない所があれば、管理者に `/skyabyss admin raid ember <部屋>` か `/skyabyss admin boss ember` を頼んでください。
- 世界を開いた直後の数分は、裏で背中の島を建てているので、動きが少し重いことがあります。そのあいだに岩鯨の背中へ乗ろうとすると、一瞬止まることがあります。
- 序盤の演出（暗転・足音・歌と星の欠け・骨の丘など）で、鳴るはずの所で音が鳴らない、目的の帯の方角が合わない、拍子が起きない、などがあれば教えてください。起きないときは、管理者に `/skyabyss admin now <人>` を頼めます。
- 知らせの記録（N）は、その遊びのあいだだけの記録です。ゲームを閉じると消えます。
- 天の鍵の場面は、そろえた本人の画面にだけ出ます。
- 倒した巨神の心臓の欠片が 4 つそろわないときは、控え帳（B）の「呼び戻す」を使ってください。
- 詰まったり、おかしな動きを見つけたりしたら、ぜひ教えてください。
